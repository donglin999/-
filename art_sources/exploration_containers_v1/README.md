# 容器素材 v1 生成记录

2026-09-30，built-in imagegen 模式；三个独立图集请求，透明背景。

## 提示词规格

- `containers-a.png`：3 列 ×4 行，列为关闭/打开有物/打开取空；行是药箱、干粮箱、有盖干粮桶、浅衣箱。药箱只装包药、干粮只装布包、衣箱只装粗衣。南宋武侠探索场景、三分之四俯视、暖褐木材、暗铁扣、上左光、清楚像素簇，同一行基座尺寸和落点一致。透明背景，单件，无字、无人物、无 UI、无蓝光、无金银堆、无现代器具。
- `containers-b.png`：同列约定，四行是客宿高衣柜、洞中矮衣柜、破漂来木匣、墙根小藏匣。高衣柜内有灰蓝粗衣；矮衣柜粗衣与小钱袋；破匣少量铜钱；藏匣小钱袋；最后一列均空。其余投影、材质、光线、透明和禁止项同上。
- `wine-barrel.png`：横向三格，专用酒桶，闭盖/开盖有陶酒瓶/同一开盖酒瓶移除；没有布包、食品、铜钱，不能把干粮桶换个名称当酒桶。与探索家具一致的木纹、铁箍、投影、地面接触点。

## 处理与审核

`tools_scene/build_containers.py` 使用现有 `build_scene.pixelize` 对透明单元裁切、按关闭基座统一比例缩小、40 色无抖动、硬 alpha，统一落脚锚点 (40,94)，组为 80×100 单元。输出 `assets/containers_v1.webp`、`js/container-art.js` 和 `atlas-metadata.json`。衣柜开门宽度可以增加，但基座碰撞固定采用闭门占地。

候选图先检视用途与三状态，再看本机实机大小、昼夜、取后变化；现有地图不换整体画风。原始生成图保留为输入，运行图集才由游戏加载。审批依据为用户确认的强化淡蓝 GIF；光点完全由代码绘制，素材不烘焙光点。
