# 守军战斗精灵来源

`model.png` 与 `gen/{base,atk,move}.png` 由内置 imagegen 生成，参考了 `assets/s_soldier_bright.webp` 的身份设定与 `assets/b_bandit.webp` 的战斗像素画风。定妆图提示约束：暗钢片甲、朱红饰边、尖顶铁盔、长枪，成年六头身、右向、透明背景、硬像素簇。三组四姿势提示分别要求待机/运功/受击/倒地、蓄势/突刺/追击/回防、跑动/二段蓄势/二段突刺/跪地。每组锁定同一角色身份、朝向、画风与装备。

运行 `python3 art_sources/soldier_battle_20260930/pack.py` 可重新生成 `assets/b_soldier.webp`。打包脚本按 alpha 连通域分离长枪跨越列界的姿势，将可见身体缩到与山贼、老僧接近的 57 美术像素，共用 27 色盘、加深色外描边、二值化透明度，再以最近邻输出严格 3× 像素网格。源图保留原始半透明边缘；最终表只含 alpha 0/255。

`actions.png` 为 18 帧在暗色战斗底上的复核图；`compare.png` 为守军、山贼、老僧待机同比例图。动作索引与敌人表一致：0–3 待机、4–5 冲刺、6–9 攻击、10–11 二段攻击、12 受击、13–14 运功、15–16 破势、17 倒地。
