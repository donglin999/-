# 剑技形态复核：停止重复月牙

状态：历史　最后核对：2026-10-19（2026-10-19 归档，只供追溯）

[评审目录](sword-studies.md) · [打击感调研](sword-impact-research.md)

2026-10-01：用户指出高阶版本表现单一，重复弧片像西瓜皮。高阶锋刃组暂列为不通过的探索样例；丙级单剑的反馈节奏仍可复用，不把它的月牙轮廓推广到所有招式。

## 本次实际查看的资料

### Eli Todd · Magic Sword Charge Effect

[作者页面与演示](https://elisatodd.github.io/Portfolio/vfx/sword-vfx.html)

通过浏览器打开原页视频（约 7.57 秒），定位查看约 0.91、2.57、4.24、5.90 秒画面。看到剑周的红色尖状碎光、逐步覆盖剑体的螺旋能量带、后方不规则暗色烟团和发光边缘。作者说明以 UE5 Niagara 和自定义材质制作，灵感来自 Blasphemous。

采用：蓄势的形态要与攻击刃口不同；暗面、实体/纹理面和亮粒子承担不同作用。只借鉴分层及变化关系，不直接使用作品剑模和贴图。

### Alexander Clark · Hail of Swords

[作者演示与拆解](https://www.alexanderclarkportfolio.com/post/hail-of-swords-vfx-breakdown)

本次在原网页实际查看动态图连续截图，看到地面星点标记、上空多个圆形开口、细长剑体分批出现及下落、落地局部金色爆点与剑体短暂保留的阶段。结合作者实现说明：剑体控制发射序列和速度曲线，碰撞驱动爆点与碎星、地面裂纹。

采用：剑阵由可识别的长直剑形组成，阵列、剑体、地面标记和接触爆发轮廓不同。多剑排列只负责组织空间，不将每一层都替换为同一个弯月。

### Hazel Stagner · Stylized Sword Slashes

[作者分层说明](https://glairedaggers.artstation.com/projects/GaGnLQ)

读取作者公开文字：斩击层下方放暗色轮廓提高对比，火焰配暗烟；命中点有亮斑，碎屑区分全向爆发和定向喷射，另用长粒子表达切割。浏览器页面遇到安全检查，未继续尝试绕过，因此不宣称看过该作品的动态演示。

采用：亮暗对比、不同形状和不同运动职责共同塑造效果。纯叠加发光和同轮廓复制都不足以支撑丰富高阶技能。

## 当前代码的具体问题

1. `SlashImpact.makeAtlas()` 只有一种抛物线月牙，9 帧只是侵蚀变化；`HighSlash` 的三套颜色仍为同一张轮廓。
2. 所谓剑阵也用这张弧片缩小排布，缺少真正的长剑/直刺形态。
3. 大小、旋转、颜色改变了，动作仍是同一种弧片从右方平移；高阶不存在独立招式结构。
4. 连续亮边和规则斜纹强化厚壳/瓜皮感觉。轮廓的改变应先于噪声、粒子数量和音效。

## 下一轮需要分开的六种形态

| 模块 | 主轮廓 | 运动方式 | 用途 |
| --- | --- | --- | --- |
| 凝剑 | 长直尖剑/不完整细剑影 | 从碎点拼合，缓慢悬浮 | 蓄势、剑阵 |
| 突刺 | 短粗尖头，后接细长拖尾 | 直线迅速贯穿 | 首击、群剑 |
| 快斩 | 两端尖、中段变化的不规则切痕 | 瞬间扫出，沿切口侵蚀 | 横斩、交叉斩 |
| 剑雨 | 多把细长剑体 | 错列下坠、局部命中爆裂 | 高阶中段 |
| 终结切面 | 短暂大范围不对称裂口 | 突然展开，分块错开再破碎 | 绝学终结 |
| 命中碎裂 | 星芒、尖碎片、短裂痕 | 先短闪、再定向崩开 | 所有接触点 |

避免所有模块拥有同一弯曲轨迹、同一寿命和同一亮边。像素风转换保留大轮廓与亮暗分工，减少三维材质细节；不照搬照片级烟雾。

## 新编排方向

直刺、快斩、剑雨、裂空四种单体（已删除）现已实现。下列等级组合尚未制作。

- 乙：直刺开场 → 两道短快斩 → 扇形三剑穿透。三种轮廓形成连招。
- 甲：细长剑影成阵 → 分批直线突进 → 交叉切痕破开 → 剑雨收尾。阵列用直剑而非弧片。
- 绝：剑影分层悬停 → 同时收锋并短暂静止 → 多方向贯穿 → 短暂停顿 → 贯场不规则裂口 → 分层崩解。大范围以切面构图和残留裂痕表现，禁止把丙级月牙简单放大成全屏。

先在同一页验证“直刺、快斩、落剑、裂空”四种不同单体轮廓，确认每个都能独立辨认后组合。既有丙级的命中事件、定向碎屑、受击回弹继续复用。
