# 甲等剑法 · 紫阙星河

状态：历史　最后核对：2026-10-19（2026-10-19 归档，只供追溯）

[评审入口](sword-studies.md) · [绝等脚本](sword-grade-ultimate.md) · [参考与分级](sword-vfx-direction.md)

## 核心画面

两股粗厚粒子气流在角色后方反向盘旋；八路剑气从上、下两个平面加速汇入目标。连击结束留出一拍，两道更宽的斜向剑潮先后切入，形成交叉收束。仍以用户认可的颗粒、碎流和低亮外层呈现。

## 时间脚本（6.1 秒，含消散）

| 时间 | 动作与构图 | 速度、层级和听觉 |
| --- | --- | --- |
| 0.10–1.68 s | 双流在人物后方绕行；横向半径 165、纵向 80，第二股晚 130 ms 出现 | 慢速，青蓝和低亮蓝紫；粒子生命 650 ms，保持碎裂尾迹；不提前播放命中声 |
| 1.00–3.12 s | 八路剑气由上下交替位置进入，同一落点汇击；主发射散布 38 | 每路飞行 1050 ms，前慢后快；命中间隔逐步压缩，前段气流尚未散尽时首剑开始 |
| 3.12–3.55 s | 连剑收束；3.29 s 第一条重斩开始聚成，3.41 s 第二条跟进 | 两条重斩各用 260 ms 快速释放；这一拍保持残光，减少前段主体遮挡 |
| 3.55 / 3.67 s | 两道交叉重斩先后命中：右上、右下进入同一点 | 发射散布分别 78 / 68；第二击更重，音效也比前八击突出 |
| 3.67–6.10 s | 两层地面粒子浪、悬浮金色碎屑依次散去 | 压力前缘较快，后层较慢且稍粗；角色重新露出，全部粒子在结束前清理 |

所有尺寸均基于 640×360 内部画布；散布参数不是最终可见光带直径。

## 命中合同

命中毫秒：`2050, 2350, 2590, 2770, 2900, 2990, 3060, 3120, 3550, 3670`。

视觉命中、目标闪亮、剑声和受击声共用这一数组。评审页不结算伤害，未来实战中视觉连击数量与伤害段数需要单独声明。

## 层次与速度

- 后景：双流保持人物轮廓可读，普通透明混合，核心少量叠加发光。
- 中景：八路剑气，保留上、下路径空隙；末段两条主斩成为唯一视觉重心。
- 前景：晚于命中的压力浪和掉落碎屑，不和主斩同帧全部出现。
- 发射进度采用 `q=0.07u+0.93u^3.6`；同样的飞行路径在末段显著加速。
- 当前实现是按加速路径连续发射粒子，出生后的粒子由惯性、阻尼和扰动运动；不是整批粒子锁死在一条曲线上。

## 验收画面

1. 1.3 s 能看到双流展开，人物不被盖住。
2. 2.7 s 能区分来自上下的剑气及集中命中点。
3. 3.7 s 交叉双斩明显强于前段单条剑气。
4. 6.1 s 没有残留粒子，停止或切换立即停音、清空。
