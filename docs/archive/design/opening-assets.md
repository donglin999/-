## 1. 当前角色分类与制作包

| 角色 | 分类／当前阶段 | 当前必需包与限制 |
| --- | --- | --- |
| 萧白 | player；后山现代装、借来乡村便衣 | 两阶段同脸。按 player 包核对身份基准、菜单、六种对白语义、头像与实际地图／战斗包。求助、木杆挡护、查看纸页、扶物等按场景选基础图、关键姿态或 CG，不每阶段强派三张姿态。后山当前为独立固定小场景，现代装有四向待机与20帧临时木杆战斗表，不制作／注册行走；不开放现代装自由移动；乡村便衣核对实际移动；扶办公桌、失去意识、苏醒与开机查信号素材暂缓。村中只有木杆自保，不能复用有剑身体 |
| 叶蘅 | companion；乡村医者 | 现有初始阶段完整对白状态（旧七张记录仅追溯）、菜单图、四向站立／行走、20 帧战斗与角色语音已接入；基础角色包已齐，第一章优先复用。不默认再派三张姿态、独立跑步或新菜单。护箱画入章节 CG，药布用已有立绘，拒绝用 firm 表情；开篇战斗能力和菜单背景仍按具体使用核对。见[叶蘅实例](../../design/character-card-ye.json) |
| 周砚 | important_npc；独立游侠 | 身份基准、头像、基础／坚定／担忧对白、所需站立与步行。「查看纸页」先以基础图＋道具界面表达，确需独立展示才画姿态。只在 CG 中制止护院，不新增真实战斗表 |
| 陆衡 | companion（未来招募）；本章护运者，临时参战 | 上述重要人物包；护路行为先以站位／已有图表达，有明确缺口才补独立姿态。另需临时我方战斗专用包，不能把普通村民表当成已完成 |
| 徐令仪、岑霜、沈雁回 | companion；本章初识与交涉，未来正式招募 | 各自身份基准、头像、6个动作与表情合一的透明对白状态，按人设选态、所需地图站立；当前既有状态先核查复用。三人未参加真实回合战，不提前派招募期战斗或跟随包；新稿已按当前阶段核查复用接入，后续招募仍不提前派包 |
| 乌魁 | important_npc；现场抢匣者 | 既有身份、头像与实际对白站立；抢物画入静态CG，不按未来队友派完整包 |
| 程铎 | important_npc；委办发出、复核监督者，本章不在现场 | 本次不因新稿生成在场立绘、移动或救援动作；已有素材留作后续衙署会面 |
| 周婶、陈伯、药商、店家、村口老人、差役、采办使／随从、管事／护院 | ordinary_npc；有姓名或职务仍按普通人物制作 | 简短外观卡、所需站立／小头像或可复用同职业图；**不单列剧情动作、表情全集与菜单立绘**。两名实际挡路帮众使用合格普通敌方战斗包 |
| 山犬 | enemy；野犬教学 | 地图单向静态 + 复用野犬战斗表；身份与教学实际使用的敌方／驱离表现；不是可加入大黄，不派宠物菜单、亲密或护主包 |

上表是每个人的本章需求来源。会参战、会移动的标记必须落实到角色卡；未使用的未来阶段和未开放的归烬堂／巡江司培养内容不生成。

现代同事随现代开场（已删除）暂缓，当前不需要其素材或语音。

## 4. 背景、道具与复用

- 场景需求：后山相遇与下山场景、栖河村共用探索场景、药棚室内背景、邻村暂住背景、山居院落、通用客房背景。现代工位背景暂缓。夜间优先通用明暗／灯状态，不每个时段重生地图。
- 村中院、客栈、药棚与村口先由一个布局明确的村庄场景串联；只有实际进入独立室内才增背景。CG 不能替代可走地图与碰撞。
- 关键物：手机与现代衣包、询价字条、叶家药箱、《归元诀》残页、玄曜玉匣、续脉散封存样品／药签。先统一外观，人物姿态和 CG 中复用；字条与药签文字由 UI 显示。
- 通用物：碗、布、竹篮、普通药包、车、旧绳、木杆、灯台、油罐、桌凳优先复用已定稿单体。没有交互需求的普通物不强制生成独立背包图标。
- 姿态图、CG 的手部互动画完整，道具归属与剧本一致；不以「物件文件尚缺」把遗物改成临时别的东西。
