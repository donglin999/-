## 2. 上一版具体问题（本项目判断）

1. 北侧店铺近乎同一基线，南侧四栋外景几乎同尺寸，街道长期保持等宽：玩家看到的空间节奏过于重复。
2. 建筑被当作独立矩形一字摆开，没有组成院落、街角或完整街坊。客栈的空间身份只有门牌，缺少落脚院与生活区。
3. 救治区是规整留白框，周围的摊位、证人、来往人流未形成可信的市场边缘。
4. 城门到街心动线接近十字路口，缺少街口收束、转角揭示与地标引导。
5. 建筑功能和尺寸分别成立，但建筑关系、轮廓与空间体验没有一起设计。

城防轴线需要规整；商业、居民空间需要体现不同活动和形成过程。为每栋建筑随意加旋转或坐标偏移，同样缺少设计依据。

## 3. 适用于襄阳的设计方法（项目推导）

### 从活动、街坊与路径开始

先定义“进城盘查、商旅落脚、茶市救人、居民取水、工匠作业”五种活动空间，再画其连接和边界。街坊作为整体设计，房屋、院墙、门、工作区共同组成单元。补参数时量每个单元的占地与通路，不能默认所有房子填一个尺寸模板。

### 街道有层级和节奏

进城短直段保留城防秩序；商街在客栈院墙处转折，再打开到街心。救治空间是市集活动形成的局部扩宽；支巷从摊位边缘进入居民区。使用“入口收束→转角→街心展开→巷口收束→公井小院”的连续体验；狭段仍满足脚底、队友和双向通行要求。

### 用错位、院落与街角塑造轮廓

药铺前留诊疗接近区，客栈有短进深院落，铁匠有作业棚与货物侧口。不同建筑按活动需要产生进退和形体差异；转角可用院墙、门廊、摊棚组成边界。镜头保持原基准，侧向门口需要对应的立面素材，不旋转整张南向图片冒充新朝向。

### 看得懂并且值得绕行

进城能辨认门楼与客栈招幌；到茶市能读出救治位置和药铺方向；到巷口能识别井边地标。主街连接关键任务，短巷／院边提供一次可理解的绕行再接回主路。支路尽头给明确的住户、服务或事件；路径变化避免以迷路增加时长。

### 生活细节跟随活动

客栈门前安排行李与候客，药铺侧院安排晾药，铁匠棚摆工具与料架，公井边留取水、等候与居民交流的空间。明确主人和公共／私人边界，容器价值随用途确定；装饰不能占掉已经评审的净空。

### 按实际镜头判断构图

平面图之后补实际俯视角构图稿，分别看入城、街心、药铺门、井边四个关键画面。检查屋顶轮廓、前后层次、任务可见性与人物遮挡。二维地图不机械照搬三维城市的长街视线、地形高差与摄像机技巧。

## 4. 襄阳下一版应交付什么

- **两个布局候选**：保留规整入城主轴的街坊方案，以及经客栈院墙转折进入茶市的方案。比较实际走路长度、辨识度、空间疏密与建筑功能；两者均不采用整排等宽房屋。
- **同尺功能平面**：保留2640×1560街市、2400×1440南门、2400×1320偏巷作为第一轮画布约束；重排有依据后再评估是否改尺寸。
- **街坊与建筑造型稿**：街角、药铺、客栈院落、铁匠棚、公井院落；展示实际屋顶、门口和院墙关系。
- **四张关键镜头构图稿**：入城、街心、药铺入口、公井。现有人物或成人尺作占位。
- **同源参数表**：道路分段净宽、拐角展开、建筑画面与实体、院口、门口、站位和遮挡。成人92、脚底半宽14、mask2、nav8等技术基线可复用；上一稿各店铺坐标、道路220等设计数值重新评估。
- **灰盒实走**：带同伴往返；确认自然转折没有增加空气墙、遮挡或交互困难。布局与构图评审通过才扩生成素材。

## 5. 当前稿的处理

[上一版尺寸稿](../../art_sources/xiangyang_city_v3_plan/README.md)继续保留作对比，标记“布局待重设计，不可直接作为生产布置”。它的坐标与宽度是旧提案，不是用户认可的最终标准。现有运行游戏本次未改动。

流程更新为：**资料与活动依据→两版街坊布局→参数与关键镜头构图→建筑功能／剧情状态→灰盒→同风格素材样板→接入→设计、画质、通行与剧情分项验收**。
