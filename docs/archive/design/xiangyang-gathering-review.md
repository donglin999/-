## 为什么各方能同城相见

建议举办“襄阳老镖师寿宴”：主人是退隐镖局前辈，曾在运粮、护送、救灾中帮助不同阵营，姓名待定。寿宴期间同时办理旧友聚会、弟子试艺及赈济物资交接。各方为不同事务而来，不必全是寿主至交，也不必都进入宴席。

- 周砚受旧友邀请，带萧白叶蘅见世面；未来归烬堂线随岑霜办理货路与赔偿，巡江司线由沈雁回接洽、在程铎许可范围内随队维护秩序。三条入口最终汇合于同一公共活动。
- 正道盟与门派弟子拜寿、切磋；白鹇谷苏芷来交接药材并看诊；陆衡与商队护送贺礼。
- 岑霜以有明确通行约定的交涉代表出现，受约束且有人反对其入席。其他归烬堂成员可在城中会面；不让通缉犯毫无解释公开赴宴。
- 官府来维护秩序、交接公务，有人顺带贺寿。朝廷采办和地方巡检仍是不同职责。

主人保持公共中介身份，不默认也是最终黑手或叶父密友。登场的是多数重要人物和各方代表，不要求天下掌门、隐秘反派全部到齐。

## 一次相识怎样留下印象

首轮建议 8 组势力、约 12—16 名重点人物，分区域和场次出现。只设 3—4 场短的必达群像情节，其余交给自由活动，避免逐一自报姓名。

| 流程 | 内容与目的 |
| --- | --- |
| 入城至赴宴前 | 明确告知集合地点，玩家准备好再前往；街市、客栈、校场、码头自由拜访。某剑派弟子输了不服气，拳门弟子替苦力扛货，差役因手续拦下药车，各自先做一件事 |
| 青蚨散救治 | 沿用老周中毒、苏芷叶蘅共同救人，主线完成救治和保底责任查证；深追仍可选。不是全宴宾客集体中毒，也不把所有门派拉来破案 |
| 试艺与宴席 | 通过比赛争执、座次与交谈看出门派关系；萧白仍是初学者，可观看、帮忙或参加新手项目，不凭空挑战掌门 |
| 次日核验 | 中立主人见证徐、岑、沈核验转件经手、补证传播路径，接续栖河已有对证；争议记录、赔偿与追责各自落实 |
| 离城前 | 交换邀约、约定下次比试或帮忙，引出三年闲逛；深追地方案件另占出行安排，不用寿宴自由时段无限完成全部任务 |

关键代表通过公共场面保证“见过”；主动交谈才能更熟。错过个别人物，后续来访、书信或下一次闲逛可补初识。宴前探索不设隐形倒计时；正式时间和占期在排期稿中核算。

## 三方如何意识到被算计

保留旧因果：裴嵩通过药商散讯、想逼叶家求庇护；三方各自逐利造成现场升级。消息拼接与对证已写入2026-10-06开始部分稿；裴嵩动机仍是作者层设定，不成为角色已知结论。襄阳回查仍是后续提案。

1. **村火后必达对证**：徐、岑、沈三份附页引同一旧药罐底单、约同一时地，却写三种授权；陈伯提供原单，叶蘅否认并展示药签。已能判断消息有意拼接利用，不能指出换件人或主谋。
2. **襄阳补查传播链**：三方拿出原始传讯、经手人证言及时间记录，相互印证同一传播渠道向各方提供片面消息；确认有人利用抢先心理挑拨。三份材料不必都有伪造公印，也不能仅凭相同字迹定罪。
3. **第二年追究责任**：继续查药商为何传讯、谁授意、谁明知而利用；最终认定裴嵩责任需要互证，不因怀疑就定案。

三方共同承认被利用，不代表认定每个内部人员无辜。可公开核验结果并通知各自主事人，形成停止报复、允许交涉的有限约定；各阵营仍有不服者。

## 缓和到什么程度

- 岑霜需落实对抢匣与乌魁行为的处置、补偿；玉匣归属可以继续谈，不能继续强夺。
- 正道盟来人承担强索、拔剑及现场行为的责任；不把所有责任推给一个药商。
- 采办随从的堵路与越权单独记录；沈雁回救人不能替上级免责，程铎接回报继续监督，也无权单人撤销采办命令。
- 已定起火动作链保持：乌魁抢箱、护院拔剑、采办随从推架堵路，随后躲闪撞灯台与退步撞油棚引火。不是有人奉命烧村。
- 常态关系是讥讽、竞争、拒绝分享秘传、有限合作；遇到具体侵害仍可冲突。主角与某个弟子要好，不强行要求村民原谅其组织。

这样能同时保留村祸重量与后续交往空间。灾后对证已纳入开始部分，赴襄阳理由沿培养四月剧本；襄阳传播链核验仍待写完整对白。
