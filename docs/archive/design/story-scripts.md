## 两章的体验

- **序章**：让玩家先认识一个会怕、会求助的萧白，以及愿意救人、也有自己生活和边界的叶蘅。晚间字条使「借住一晚」变成两人共同面对的事。
- **第一章**：通过可选准备和三次强制接触，逐渐让小村挤满不肯退让的来者。玩家能减轻损失、照应具体的人；这版主线中的村火仍会发生。
- **章末**：山居是明确可住下来的地方。二人接受周砚的住处与日后学习机会；不在这一夜完成拜师、练成招式、选定叶蘅路线或建立恋爱关系。

精修安排、人物说话方式、信息边界与复核结果见[开篇精修说明](opening-polish.md)。

## 读稿约定

- `P-xx` 为序章，`C1-xx` 为第一章，`C1-Ax` 为活动。台词完整 ID 为「场景 ID + 行号」，如 `P-01-04`；选项分支用 `A01/B01`；本轮新增共用句用 `N01` 起，按文档顺序插入，沿用所处节点位置，不重编号既有对白。动作行也保留编号，配音只取实际人物对白。
- 方括号内是演出、条件或结果，不向玩家朗读。无标记的对白为该节点完整文本；分支后从合流点接回，不再重播共用对白。
- 方括号的动作描写先按[剧情表现规范](../../design/story-presentation.md)转换为对白、静态姿态、CG 或场景结果；不自动成为 NPC 专属动画需求。具体制作范围见[开篇素材需求](opening-assets.md)。
- 所有选项无倒计时；来历回答、礼貌措辞没有隐藏好感惩罚。灾难现场的选择也给足阅读时间。
- 主角对白先保留文字与表演，不安排角色配音；其他剧情人物的重点句在[交接规则](../../design/opening-state.md)列为候选，审稿后再入语音清单。
- 本稿采用旧稿的「村中三天、六个半日行动」节奏。这是开篇事件时间，**不占三年培养的体力或日历时段**，更不是旧十二日培养的恢复。

## 本轮相对旧稿的改动

1. 主角统一为萧白，保留现代程序员身份（现代时 24 岁），穿越后身体回到 17 岁、记忆保留；他没有古代师承和佩剑。
2. 周砚采用当前归云谷掌门与温行舟旧识设定。徐令仪亲自主持正道盟索谱；周砚因旧友传闻来村，不代表正道盟，不以父亲旧同门身份要求交物。第一章只提供暂住，入谷首月才正式收萧白为徒。
3. 保留周婶、陈伯、陆衡、乌魁等开篇人物；三方主事改为徐令仪、岑霜、沈雁回，程铎留在衙署发出委办与复核。三人襄阳再次会面，不重播初识。
4. 保留章末三选一：正派师友、归烬堂、巡江司；当前只开放周砚山居，另外两项可看介绍、不能确认。完整规则见[三条去向](../../design/opening-routes.md)，不恢复已删除的栖灯馆。
5. 新增旧稿缺少的上山、安排独立住处、安放药箱和饭桌场景，使第一章在「安身」处完整收尾。

裴嵩散讯、父亲遇难、玉匣来历是作者掌握的后续真相，本次不提前揭给人物。三件遗物的流转、选项效果和待实现检查统一看[两章交接规则](../../design/opening-state.md)。

## 审阅时可先看

序章是否足够让人愿意留下帮忙；三方来者的不同诉求是否清楚；火灾是否有看得见的因果；山居结尾是否让人愿意继续与这几个人相处。对白、节奏和具体分支仍可修改。
