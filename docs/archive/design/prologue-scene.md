## 交互与剧情状态

`S.prologue.errands` 分别记录还碗、取布和送药；`carry` 只装受托物件，不进可出售背包；`heard` 独立记录三条旁听。所有小事可跳过，不发钱、装备、经验或好感奖励，不重复交物。

- 周婶可接取小事、收回布包和竹篮。
- 陈伯交碗后，可选择旁听功法传闻。
- 布包未受托不准取；取布后可旁听玉匣出售传闻。
- 老人收药后返还竹篮；可旁听验药疑点。
- 叶家药箱是协助整理点，归叶蘅，不作为免费战利品，不解锁武学。
- 药箱整理完成才可歇息；未办理完先确认，可取消继续。歇息关闭未完成的小事，不伪造已交付；字条读实际旁听状态。
- 终点记录序章交接，不串到旧襄阳入口，也不进入尚未实现的第一章。

角色交谈用现有对话框，暂不挂正式立绘。布包、药箱、歇息点只在当前可交互时显示局部淡蓝星芒；不使用整屏发光。交互结束、接取和完成提示释放移动。

### 清晰度修订

用户实玩指出首批画面模糊。原因是把约 1672×941 原稿 BOX 缩至 640×360、再量化为 160 色，运行时放大，损失了瓦片、草地与木纹细节。现已移除生产素材的该降采样和量化步骤，直接从原稿最近邻采样至 1920×1080；所有深度片也从同一高分辨率底图切出，按 propK=1 绘制。布局、锚点和 mask 不变。1920 的输出不是新增细节，只是保留原稿已有细节。人物仍为既有占位精灵。

### 通行与遮挡修订（2026-09-30）

用户实玩指出人物嵌入与空气墙，说明首批路线验收不足。定位到三类原因：矩形前景切片包含周围地面，遮住走在空地上的角色；部分手绘碰撞与屋身、墙脚不一致；寻路惯性、节点跳过与 NPC 避让规则不一致，导致转角切入或停住。

- 前景切片必须有物件轮廓 alpha 蒙版，包围矩形仅用于裁切，不得将矩形内地面整体覆盖人物。树冠遮挡与树干碰撞分别定义。
- 药棚封闭屋身补足碰撞，南侧开放廊下保留通行；老人院北墙去除多余草地阻挡。歇息落点移至布局坐标 (169,102)，避免与药箱脚底范围相交。地图版本为 2，旧预览存档进入时重新检查角色位置。
- 精细导航启用扫掠检测、节点限步和 NPC 一致性检查；相关参数只对本场景启用，其他地图保持默认。
- 新场景验收必须同时检查边界、往返折角、有人物时的路径和透明遮挡，不能只证明交互点可达。生成图仍需人工定义实体轮廓，画面好看不能作为可玩性通过依据。

最终构建通过 `tests/prologue-village.test.cjs` 和新增 `tests/prologue-collision.test.cjs`。后者检查 157 个障碍边缘、20,096 帧高速物理移动、24 次正反向路线，并检查前景 alpha；另通过本地 HTTP 标题入口、真实画布点击、E 键交互和菜单开关。统计由本次测试输出获得，不代表每个屏幕位置均经过人工实玩。证据位于 `review/prologue-courtyard/runtime/acceptance.json` 与 `collision-acceptance.json`。本次修订仅在本地。
