## 分组与区分

| 功法 | 兵器与主色 | 主体形态 |
| --- | --- | --- |

| 留灯伞护法 | 伞面莲粉，灯点暖白 | 伞影、伞骨垂线；护弧与灯点 |
| 邀锋扇法 | 扇骨红金，袖势绯红 | 折扇实物与骨线；白线与步点；安席 |
| 雀步短刃法 | 刃锋青白；阴劲黛紫 | 雀喙短锋、雀尾风痕、青弧与缺口；防线光壁 |
| 护行刀法 | 刀身褐金 | 横刀、劲气屏、归路 |
| 校铁锤法 | 雷劲电金，锤身铁灰 | 方块锤劲与铁环 |

几组容易混的：
- **循隙针、截脉三针、归息断潮**都是针：循隙针是两针并行钻一道**裂隙**；截脉三针是三针从三个角度钉**三处穴点**连成圈；归息断潮的主体是**潮影和一道横切金线**，针只是收尾。
- **撑篙截流、伞下容身、扇骨截招、横刀护途**都是丙级护卫：分别是斜撑的篙与水屏、头顶的伞、身前的扇骨与来锋、横刀与身后的归路，挡的位置和实物各不相同。
- **回舟接客、雨住留灯、邀锋护席**都是甲级护卫：一个在脚边（水弧与扁舟），一个在头顶（护弧与雨），一个在身前身后（大扇与安席）。

护卫、治疗、增益招全部不震屏、不闪白；只有 6 招攻击有震屏，其中 3 招甲级攻击有淡闪与推镜。

## 逐招

### 1. 随行照护（`yh_s0`，丁，辅助，随行救护法）

- **独有母题**：一缕回流托住一片小叶脉。
- **分段**：起手 0–110 掌间聚起温白回流 → 出手 110–340 回流弧线飘到同伴腰侧 → 命中 340 绕伤处半圈，托出一片接上的小叶，医绿光点 → 收势 480–760 回流散去，小叶上飘淡出。
- **本组素材**：`ren_yh_swirl`、`ren_yh_leaflet`。
- **复用其他包**：无。

### 2. 循隙针（`yh_n1`，丙，攻击，循脉针诀）

- **独有母题**：两束针路并行，钻进同一道裂隙。
- **分段**：起手 0–150 指间两点冷金并排亮起，目标身上显出一道竖裂隙 → 出手 150–520 两束针一前一后射出，身后拉细金线 → 命中 420／520 各一个针点与金屑，裂隙随针张开（末针震 3）→ 余波 520–860 金屑从裂隙向外溢，针路光线自入口向外淡出 → 收势 760–1000 裂隙合拢。
- **本组素材**：`ren_yh_pin`、`ren_yh_rift`、`ren_yh_pinhit`。
- **复用其他包**：`kit_thrust` 着冷金，只作针路淡出时的辅助光线。

### 3. 截脉三针（`yh_n2`，乙，攻击，循脉针诀）

- **独有母题**：三针从三个角度钉三处穴点，连成一圈，截断一段脉流。
- **分段**：起手 0–200 三针扇形排开；目标身上一段黛紫脉流流动，三处赭红穴点隐现 → 出手 200–680 三针沿上、中、下三条弧线先后射出 → 命中 480／580／680 穴点逐一被钉住放大（末针震 2，弹“封穴”）→ 截脉 720 靛蓝细线连成一圈，脉流变成被截断的暗流，弹“攻势 −15%” → 收势 1020–1320 细线向针点收缩后熄灭。
- **本组素材**：`ren_yh_acupoint`、`ren_yh_tri_seal`、`ren_yh_vein_dim`。
- **复用其他包**：`bh_needle_yin`（白鹇谷镇魄针的阴劲金针；叶蘅出身白鹇谷，是同一种针）。

### 4. 归息断潮（`yh_n3`，甲，攻击，循脉针诀）

- **独有母题**：一道金线切断厚重的潮影，留下一段平稳的呼吸。
- **分段**：起手 0–320 压暗、轻推镜，白色气息收向胸口 → 涌潮 150–800 目标身前一道黛紫潮影涌起 → 切断 700–800 纤锐金线自右向左横贯；800 命中，潮影断成上下两截向两侧退散（震 8、淡金闪、推镜 0.1）→ 收针 860–1120 两束金针沿切口跟进，末针多一圈金环 → 余波 1200–1900 潮沫落定，身后一段淡白呼吸线缓缓展开。
- **本组素材**：`ren_yh_tide`、`ren_yh_cutline`、`ren_yh_tide_half`、`ren_yh_breath`；本人 `ren_yh_pin`、`ren_yh_pinhit`。
- **复用其他包**：`kit_ring` 着金，只作末针的金色细环。

### 5. 温络行针（`yh_m1`，丙，辅助，和脉医法）

- **独有母题**：叶脉路线上两处节点依次点亮。
- **分段**：起手 0–150 指尖一缕温青针气 → 出手 150–480 针气飘到同伴身上 → 命中 480／640 身上浮出叶脉路线，上下两处白色节点先后点亮（弹“持续恢复”与治疗数字）→ 流转 480–940 暖意沿叶脉在两点之间流动 → 收势 900–1080 叶脉淡成一枚小徽记。
- **本组素材**：`ren_yh_leafpath`、`ren_yh_warm_needle`、`ren_yh_node`；本人 `ren_yh_badge`。
- **复用其他包**：无。

### 6. 和脉同息（`yh_m2`，乙，辅助，和脉医法）

- **独有母题**：医绿与温金两股柔流并行、三次交会，缠上兵器留一层金边。
- **分段**：起手 0–220 两股光点自掌间升起 → 出手 200–620 双流并行伸向同伴，三个交点依次亮起温金 → 命中 620 柔流缠上兵器，弹“伤害 +15%” → 金边 600–1260 兵器上一层柔和金边轻轻闪动，金屑上飘 → 收势 1100–1320 柔流淡去，金边收成一点。
- **本组素材**：`ren_yh_twin`、`ren_yh_cross`、`ren_yh_edge`。
- **复用其他包**：无。

### 7. 归息续照（`yh_m3`，甲，辅助，和脉医法）

- **独有母题**：将熄的叶脉环被一段新流接上断口，整环重亮，仍留一个缺口。
- **分段**：起手 0–320 压暗；同伴身周叶脉环将熄、光屑零落；掌心一段暖白新流盘起 → 出手 300–850 新流沿弧线飞向环上的断口 → 命中 850 接口亮起，整环重新亮起并缓缓转动（弹“增益延续”），脚下升起一道辅助光 → 运转 850–1450 光点沿环流转，小叶飘落 → 收拢 1450–1650 叶脉环收向胸口 → 收势 1600–1850 留下一枚徽记，边缘闪一下。
- **本组素材**：`ren_yh_ring_dim`、`ren_yh_ring_lit`、`ren_yh_newflow`、`ren_yh_badge`；本人 `ren_yh_cross`、`ren_yh_leaflet`。
- **复用其他包**：`kit_rise` 着医绿，只作环亮起时自脚下升起的辅助光。

### 8. 飞燕点枝（`yl_s1`，丙，攻击，飞燕投刃法）

- **独有母题**：两片燕尾飞锋一高一低走弧线。
- **分段**：起手 0–120 两片杏金飞锋在指间错开 → 出手 120–520 一高一低沿弧线先后掷出，身后拖杏金弧形轨迹 → 命中 400／520 各一个短促切点，迸金屑与暗红（末段震 3，弹“流血”）→ 收势 580–980 飞锋化光，沿原路飞回袖中。
- **本组素材**：`ren_yl_dart`、`ren_yl_nick`、`ren_yl_trail`。
- **复用其他包**：`kit_slash` 着杏金，只作切点上的辅助切痕。

### 9. 满场惊鸿（`yl_s2`，甲，攻击，飞燕投刃法）

- **独有母题**：三只风凝的飞燕衔着飞锋，沿高中低三路掠过整个敌阵。
- **分段**：起手 0–420 压暗；两层青绿风带绕身旋转 → 出手 320–1220 三只飞燕先后出手，沿三路横贯敌阵，身后拖风纹带与杏金羽片 → 命中 820 起（每个目标间隔 90）风屑炸点逐个炸开（首个震 8、淡闪、推镜）→ 满场风 700–1350 风线横扫全场 → 收势 1320–1900 后跃落定，身前一层淡青卸力影，弹“卸力”。
- **本组素材**：`ren_yl_whirl`、`ren_yl_swallow`、`ren_yl_burst`、`ren_yl_veil`；本人 `ren_yl_dart`、`ren_yl_nick`、`ren_yl_trail`。
- **复用其他包**：`wind_band`（第一批松涛合阵的青绿风纹带；同为风劲流线，只作飞燕身后的尾流）。

### 10. 撑篙截流（`qx_s1`，丙，辅助，长篙）

- **独有母题**：长篙斜撑，篙尖顶出一面半圆水屏。
- **分段**：起手 0–150 篙尾点地，脚边一圈水纹 → 出手 60–450 长篙自篙尾向篙尖显出，气柱沿篙身撑向同伴身前 → 命中 450 篙尖顶出半圆水势屏，上下两朵水花、水珠四溅，弹“援护” → 持守 450–820 水屏微微起伏，水珠滴落 → 收势 800–1020 水屏收落，长篙淡出。
- **本组素材**：`ren_qx_pole`、`ren_qx_arc`、`ren_qx_splash`。
- **复用其他包**：无。

### 11. 回舟接客（`qx_s2`，甲，辅助，长篙）

- **本组素材**：`ren_qx_sweep`、`ren_qx_turb`、`ren_qx_boat`、`ren_qx_wake`；本人 `ren_qx_arc`、`ren_qx_splash`。
