# 内功主动逐招特效设计表（20 门 v3 心法）

状态：历史　最后核对：2026-10-19（2026-10-19 归档，只供追溯）

本页覆盖 20 门 v3 心法的主动技（编排 id 为 `xf_<心法>`；运行时技能 id 为 `inner_<心法>`，战斗接入层按 `innerId` 找到 `xf_<心法>`）。旧原型心法（玉泉心经等 12 门）仍用通用模板 `heart_<效果>` 兜底，未改动。

- 概念帧：`art_sources/fx_xf/concepts/`（31 帧：丁丙各 1 帧，乙甲绝各 2 帧；`spec.json` 的 `concepts`）

## 共同约定

- **只在角色身上流转**：内功主动不做大范围演出（伤害数字规范 §6）。唯一的例外是绝级万壑归元诀生效之后的“境界展开”一段（2026-10-11 按标杆升级要求加入），万壑远景画在角色身后的地面层，不挡双方角色。主体都贴着施法者或同伴的身体，尺寸按“舞台尺度角色约 125 特效像素高”设计，主体覆盖躯干并超出轮廓（约 0.7–1.1 个角色高）；实战约 0.75 倍显示，所以统一 `boost:1.15`。
- **作用目标**：
  - 自身招：`side:'ally'`，锚点取施法者（`fx.A.hand` 推出胸口，`fx.A.foot` 为脚下）。战斗中 `fx.allies()` 即施法者本人。
  - 同伴招（青囊养元经、营卫心经、负岳功、同气连枝篇）：对 `fx.allies()` 每一名落位；同伴就是施法者本人时，引线改为绕过头顶回落。
  - 看破招（观岚诀、静练功、地籁诀）：无 `side`，对 `fx.targets()` 每个目标点亮破绽。
- **起手**：每招都有自己的起手表现，统一 `leadAura:false`，不叠引擎的手部起手光。
- **镜头**：丁丙不压暗；乙轻压暗（0.22–0.3）；甲（归藏息经）压暗＋暗角＋轻推镜；绝（万壑归元诀）压暗＋暗角，但仍只在自身周围。2026-10-11 起**全部不震屏、不闪白**（辅助防御招的统一要求）：承梁真劲的反击、负岳功的承重原来的短震，改用地纹外荡、落尘和梁身下压回弹来表现。
- **浮字**：回内用天蓝 `+N 内`（`#8CCBFF`）；治疗用翠绿 `+N`；解除用白字“解除·异常名”；看破用白字“看破”。战斗中浮字由 `bui.js` 出，特效层 `quiet`。
- **素材复用**：主体全部是本门自己画的素材。复用只用在辅助层，逐招理由见“按标杆升级”一节的表：组件库中性素材（`kit_ground` 脚下地纹、`kit_ring` 荡开的环、`kit_rise` 回春升气、`kit_cleanse` 拂去异常、`kit_guard` 身前护影、`kit_mark` 破绽锁定、`kit_step` 步痕、`kit_wave` 声浪、`kit_qi` 掌间气旋、`kit_burst` 光爆）一律用 `L.tinted` 着成本招主色；另有几处意象一致的公共素材：`rock_debris`（山石石屑）、`smoke`（落地尘烟）、`cloud_mist`（云气、山岚）、`river_glint`（江面粼光）、`frost_star`（霜花）、`wave_moon`（月白音波）。

## 按标杆升级（2026-10-11）

任务说明见 [特效按标杆升级](upgrade-20261011.md)，量化口径见 [特效等级量化](../../../design/vfx/metrics/fx-grades.md)。内功主动都是辅助防御招，只计覆盖、粒子、素材种类、节拍、时长七项；及格线 75，万壑归元诀按绝级标杆、及格线 90。

**做法**

- 每招沿用原来的母题和主体素材，在其上加层次：**地面层**（脚下地纹）、**身体层**（原主体）、**上升或环绕粒子**（内息的流向）、**生效时的荡开**、**余波**（收束、沉降或再脉动）。每一层在画面上表现什么，见下表。
- 分段至少四段：起手、运转、生效、余波。万壑归元诀六段，生效之后有一段“境界展开”。
- **时间换算**：各招的小节（§1–§20）里的时间点仍是原来的“编排时间”。运行时由 `fx-xf.js` 的 `def` 按 `aw=[编排命中时刻, 编排总时长]` 换算：命中前等比压到新的 `hitAt`，命中后的余波等比拉长到新的 `dur`，保证 `hitAt` 不晚于时长一半。下表的时间是换算后的真实时间。万壑归元诀整招重写，直接按真实时间编排。
- 不震屏、不闪白。归藏息经保留原有的轻推镜（4.5%），万壑归元诀境界展开时轻推 3%。
- 粒子预算：丙 420、乙 600、甲 900、绝 3200。
- 新增素材 7 个（`codex exec` 内置生图，服务端选模型，提示词里带了 gpt-image-2.5 的要求，未经核实）：万壑归元诀 6 个、归藏息经 1 个，见各自小节。

## 1. 吐故纳新篇（xf_tuna，丁 F1，回内，自身）

- **独有母题**：一吐一纳——长短两条呼吸丝带一放一收。
- **与同门的区别**：回内三招里唯一以“呼吸丝带”为主体；没有地面层，也没有外来的流向。
- **主色**：呼吸纸白，丹田天蓝（色带 `white`／`sky`）。
- **作用目标**：施法者。
- **复用**：无。
- **素材**：`xf_tuna_long`（长息环带）、`xf_tuna_short`（短息环带）、`xf_tuna_dot`（丹田天蓝光点）。
- **时长**：700ms，hitAt 420，预算 160。

| 拍 | 时间 | 画面 |
| --- | --- | --- |
| 起手 | 0–110ms | 胸口一缩：白色细光点向胸口聚拢，两条丝带淡入 |
| 出手 | 110–420ms | 长息外放（变大、向右上舒展），短息内收（变小），沿两条椭圆轨道各有一粒白光在走 |
| 命中 | 420ms | 两条丝带一起收进丹田，亮一点天蓝，8 粒天蓝细光点，“+N 内”；不震屏 |
| 收势 | 420–700ms | 丝带淡出，两肩各升起两粒白点（肩头一松） |

## 2. 出岫心经（xf_guiyun，丙 F2，定神＋守势，自身）

- **独有母题**：云出于岫而不离山——竹青云流上下往复，中间留白。
- **与同门的区别**：增益四招里唯一“云”形；动势是竖直的一上一下两道，其余三招分别是火核、编结、弦线。
- **主色**：竹青（`jade`）。
