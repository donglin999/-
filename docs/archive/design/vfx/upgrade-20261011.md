# 特效按标杆升级（2026-10-11）

状态：历史　最后核对：2026-10-19（2026-10-19 归档，只供追溯）

## 1. 用户要求

- “你现在的技能特效区别太大了，例如开门见山和裂石就差了很多很多，你量化一下这个特效的等级，尽量可以丰富一点。”
- 标杆：绝级云开见山（用户说的“开门见山”），“只能比这个更好”；甲级推山填壑；乙级问隙挑灯（用户说的“问隙点灯”）；丙级燃隙刀；丁级先不管。
- 绝级功法的三招全部按绝级标杆，“第三招需要更好的特效”。

## 2. 量化办法

口径、权重、标杆数值和逐招现状见 [特效等级量化](../../../design/vfx/metrics/fx-grades.md)。

| 类型 | 及格线 |
| --- | --- |
| 攻击招 | 100 分 |
| 绝级功法第三招（真正的绝招） | 115 分，并且至少比同门前两招高 5 分 |
| 辅助防御招 | 75 分（绝招 90 分），不计震屏、闪白、推镜 |

工具（需要本机文档服务 `http://127.0.0.1:8797` 在跑）：

```bash
tools_fx/fx_measure.sh gy_s5a,gy_s5b        # 只测这几招，打印得分与各项数值，不改报告
tools_fx/fx_shot.sh gy_s5a 900 /tmp/a.png   # 渲染该招 900 毫秒时的一帧（带背景与角色），用来看图自查；群体招第 4 个参数填 3
```

全量测量（不带参数的 `fx_measure.sh`）会改写总报告，只由主会话在收尾时跑。

## 3. 设计要求

分数只是下限，画面好看、看得懂才算完成。逐招专属设计的规则仍以 [逐招专属特效规范](../../../design/v4-vfx-per-skill.md) 为准，另加：

1. **丰富度要看得见**。不许用看不见的东西凑分：透明度极低的粒子、画在角色身后被挡住的大片素材、出画的粒子、空的 `once` 事件都不算。每加一层都要说得出它在画面上表现什么。
2. **每招有自己的母题和分段**。至少分起手、出手、命中、余波四段；绝级功法的招式要有五段以上，命中之后还要有一段“画面定格或境界展开”的高潮。同门招式的主体形态不能只是换颜色、换大小。
3. **打在正确的单位上**。命中主体要盖过目标躯干；群体招每个目标都有完整命中；起手在施法者身上看得见。大面积素材不能把双方角色完全盖住。
4. **时长参考**（时长只占 10 分，不必为了分数硬拖）：

   | 档位 | 时长 |
   | --- | --- |
   | 绝级功法第三招 | 3.2–4.0 秒 |
   | 绝级功法前两招 | 2.2–2.8 秒 |
   | 甲 | 1.6–2.0 秒 |
   | 乙 | 1.2–1.5 秒 |
   | 丙 | 0.9–1.1 秒 |

   `hitAt`（伤害结算时刻）不要晚于时长的一半，`lead` 相应调整，粒子预算 `budget` 按需要提高。
5. **辅助防御招**不震屏、不闪白，靠素材层次、粒子和覆盖面达标；治疗、护卫的画面要柔和，落在我方身上。
6. **素材**：现有素材不够就补画。按规则 R-生图-01（用登记表当前源）出图，流程用 `tools_fx/fx_pipeline.py`（concepts / elements / build），提示词必须带 `Model: gpt-image-2.5（使用 gpt-image-2.5 生图模型）`，记录里不能写“已确认由 gpt-image-2.5 生成”。意象一致的素材可以复用，要在设计表里写明理由。
