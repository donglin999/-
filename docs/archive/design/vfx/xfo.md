# 旧原型心法主动逐门特效设计表（12 门）

状态：历史　最后核对：2026-10-19（2026-10-19 归档，只供追溯）

本页覆盖运行时 12 门**旧原型心法**的主动技，以及 6 个通用内功模板 `heart_<效果>`（第 13 节）。12 门（玉泉寺、丐帮、鹿门书院、太和观、京湖义勇、白鹇谷旧心法）。心法数据在 `js/menu.js` 的 `XINFA`，主动效果在 `js/martial-structure.js` 的 specs 表。编排 id 直接用心法 id（如 `yq_xin`）；战斗接入层按 `SKILLS['inner_<id>'].innerId` 找到它，优先于通用模板 `heart_<效果>`。

- 概念帧：`art_sources/fx_xfo/concepts/`（12 帧，每门 1 帧；`spec.json` 的 `concepts`）
- 单体素材：原图在 `art_sources/fx_xfo/elements/`，运行时素材在 `assets/fx/xfo_v1/`（66 个：首批 37 个，2026-10-11 补画 29 个；`spec.json` 的 `elements`）
- 编排：`js/fx/fx-xfo.js`
- 生图通道：`codex exec` 内置生图，由服务端选模型；提示词里带了 gpt-image-2.5 的要求，未经核实。

## 共同约定

- **档位**：旧原型心法没有品阶，统一按丙级处理（1.05–1.15s，四段：起手、运转、生效、余波；`hitAt` 不晚于时长一半；丙级本不压暗，只有看破招辨机与玄息轻压暗 0.22，用来托住朱砂笔意与玄阴气带）。
- **作用目标**：11 门作用于施法者自身（`side:'ally'`，对 `fx.allies()` 每一名落位，战斗中即施法者；评审舞台的默认锚点已校正到施法者身体中线）。博闻·辨机看破敌人，无 `side`，对 `fx.targets()` 每个目标画朱批圈。
- **尺度**：主体贴着施法者，按“舞台尺度角色约 125 特效像素高”设计，竖向主体统一用 `fitH` 按目标高度缩放（约 120–150，覆盖全身并超出轮廓），统一 `boost:1.15`。
- **起手**：每门都有自己的起手，统一 `leadAura:false`。
- **镜头**：全部不推镜、不加暗角、不震屏、不闪白（2026-10-11 起去掉石守、振气、守阵原有的震屏和石守的淡金闪，改用素材与粒子表现“沉、擂、砸”）。
- **浮字**：定神用暖金“定神”；防御用钢青灰“防御”；回血用翠绿数字；回内用天蓝“+N 内”；解除用白字“解除·流血／中毒”（异常色描边）；看破用白字“看破”。实战中特效层 `quiet`，数字与浮字由 `bui.js` 出。
- **素材复用**：主体全部本门新画。2026-10-11 起少量复用做辅助层，逐招写明理由：组件库中性素材（`kit_ring`、`kit_ground`、`kit_rise`、`kit_cleanse`、`kit_qi`、`kit_mark`，一律按本招色带着色）、第一批公共素材（`lotus_glow`、`meridian_lines`）、本包内意象一致的素材互用（书页、淡墨、烟丝）。

同为**防御**的三门靠主体形态区分：石守是**贴身石壳**（自下而上合拢、整体一沉），市隐是**身形虚化＋斜杖**（向两侧滑出的残影，轻），守阵是**身前一排立盾＋身后军旗**（自上而下砸落、排成一线）。
同为**回血**的三门：百衲是**多块补丁从四周飞来贴身**，振气是**胸前一点向外三次脉冲**，养元是**地面生长、药气上行**。三者的运动方向分别是由外向内、由内向外、由下向上。
同为**定神**的澄心与正心：前者主体在**脚下**（井与涟漪，水平铺开），后者主体在**身后与中轴**（竹简弧、竖直光柱）。
同为**解除流血中毒**的忘虑与清秽：前者是**自上而下的雾帘洗过**（虚、空），后者是**三处针点向外抽丝**收进葫芦（实、精细）。
与 v3 心法的区别：负岳功是挡到同伴身前的**山形气团**，石守是**贴身环抱的竖石片**；青囊养元经是药青**枝脉与光苞**，养元是**整株药草从地面长出**；归藏息经是内圈接续、杂气外推，忘虑是雾帘洗过。

## 1–12. 十二门专属心法（2026-10-11 升级后）

每门时间轴统一为：起手 0–160ms，运转 160–520ms，生效 520–560ms（即 `hitAt`），余波到结束。预算统一 420。下表“新增”是 2026-10-11 补画的素材，“复用”写明理由；未列出的素材沿用首批。

### 1. 玉泉心经·澄心（yq_xin，定神，自身；1100ms，hitAt 540）

- **母题**：心如古井——一滴泉珠落入静止的井水。主体铺在脚下，全表唯一以水面为主体。主色暖金，水面淡青。
- **素材**：`xfo_yqxin_well`、`xfo_yqxin_drop`、`xfo_yqxin_ring`、`xfo_yqxin_aura`；新增 `xfo_yqxin_splash`（王冠状水花）。复用：无。

| 段 | 画面 |
| --- | --- |
| 起手 | 井栏由小铺开（放大到 1.3 倍，盖住脚下一圈），井沿浮起淡青、暖金光点，金光点向胸口聚拢 |
| 运转 | 胸口凝出泉珠并加速坠向井心，泉珠拖金屑；井面两次轻涟漪、水汽光点上浮；定神光罩淡淡浮起 |
| 生效 | 泉珠入水：水花冠溅起，三圈涟漪先后扩开（不出井沿），金青水珠抛起落下；光罩一亮，暖金光点绕身上升 |
| 余波 | 一圈淡涟漪，金屑沿井沿打转，井面留一团淡青反光后淡出 |
