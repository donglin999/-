# 归烬堂逐招特效设计表

状态：历史　最后核对：2026-10-19（2026-10-19 归档，只供追溯）

本页覆盖玄烛会·归烬堂 6 招：藏锋短刺、燃隙刀、断烬回身、残火截锋、烬里藏锋、回灰护影。已有专属编排的焚契破阵（`gj_s4`）、余烬留生（`gj_s5`）不在本页，未改动。

- 概念帧：`art_sources/fx_gj/concepts/`（10 帧，`spec.json` 的 `concepts`）
- 单体素材：原图在 `art_sources/fx_gj/elements/`，运行时素材在 `assets/fx/gj_v1/`（19 个，`spec.json` 的 `elements`）
- 编排：`js/fx/fx-gj.js`
- 生图通道：`codex exec` 内置生图，由服务端选模型；提示词里带了 gpt-image-2.5 的要求，未经核实。

## 门内区分

归烬堂的意象是灰烬、余火、暗刃与“以暴露换强击”。同为刀、同为炎或阴的招，靠刀光的**形状与轨迹**区分：

| 招式 | 主体形态 | 作用位置 |
| --- | --- | --- |
| 藏锋短刺 | 墨紫折角阴影里探出的一截短刺锋 | 目标 |
| 燃隙刀 | 一条加粗的铜红斩弧，尾部断成两截 | 目标；施法者身上闪暴露 |
| 断烬回身 | 两道中段带折角、方向相背的黛紫折刃 | 目标；施法者身前卸力影 |
| 残火截锋 | 贴地火痕 → J 形上撩 → 竖立火墙斩痕 | 目标正前方 |
| 烬里藏锋 | 一片斜飘的灰烬层，灰中一点寒光，带毒雾的直刺 | 目标；双方暴露 |
| 回灰护影 | 一片灰烬织成的薄幕斜覆在同伴身前 | 同伴 |

与已有两招的区别：焚契破阵是火刀高举加契约纸卷、大弧火痕；余烬留生是朱红裂锋加温白归路。本页没有一招使用纸卷、大弧或归路。

## 1. 藏锋短刺（gj_s1，丁 F1，单体，刀·无属性，流血）

- **独有母题**：锋藏在折角阴影里，最后一刻才从目标身侧的阴影中探出。
- **与同门的区别**：全门唯一“刀从目标身边冒出来”的招，主形是硬朗的墨紫折角块加一截短锋，不发光弧。
- **主色**：刀锋铁青，刃口暗红，无属性；数字米白（`plain`）。
- **作用目标**：`fx.targets()[0]`。
- **复用**：无。
- **素材**：`gj_fold_shade`（折角阴影，实体透明底）、`gj_short_stab`（短刺锋）、`gj_stab_burst`（刺击命中光）。

| 拍 | 时间 | 画面 |
| --- | --- | --- |
| 起手 | 0–100ms | 施法者手边一点暗红，身前浮起折角阴影 |
| 出手 | 100–260ms | 目标身侧也翻出一块折角阴影，短刺锋从中偏斜刺出，路线短 |
| 命中 | 260ms | 一道短促刺痕、铁青碎光、两粒暗红；“流血 ×1”；不震屏 |
| 收势 | 260–600ms | 刺锋缩回阴影，阴影合上淡出 |

## 2. 燃隙刀（gj_s2，丙 F2，单体，刀·炎）

- **独有母题**：护身气势敞开一个缺口，换来一条加粗的铜红斩弧。
- **与同门的区别**：弧比一般刀光粗一倍、尾部断成两截余烬；施法者身上同时出现缺口气环（暴露）。焚契破阵的大火弧没有断尾，也没有自身暴露。
- **主色**：炎劲朱橙 `#FF6A3D`（色带 `fire`），刀身铜红。
- **作用目标**：`fx.targets()[0]`；暴露提示在施法者胸口。
- **复用**：无（`gj_expose` 是本招的新素材，烬里藏锋、回灰护影复用它）。
- **素材**：`gj_thick_arc`（厚斩弧）、`gj_ember_halves`（断成两截的余烬）、`gj_expose`（暴露光斑：缺口气环加裂痕）。

| 拍 | 时间 | 画面 |
| --- | --- | --- |
| 起手 | 0–150ms | 抡刀过肩，手边火舌上窜；施法者胸口气环敞开缺口（暴露） |
| 出手 | 150–380ms | 厚斩弧从目标右上方向左下展开 |
| 命中 | 380ms | 火舌一卷，约 12 粒余烬，3px 震 |
| 收势 | 380–900ms | 斩弧淡去，尾部两截余烬下坠熄灭 |

## 3. 断烬回身（gj_s3，乙 F3，单体两段，刀·阴，流血，自身卸力）

- **独有母题**：两道背向的折刃，一前刺、一回撩，中间留出撤出的空隙；施法者沿空隙后撤，身前留一层卸力影。
- **与同门的区别**：全门唯一两段、刀光带折角的招；最后落点在施法者自己身上（卸力影、地面拖痕）。
- **主色**：阴劲黛紫 `#B79CFF`（色带 `yin`）。
- **作用目标**：`fx.targets()[0]` 两段；卸力影在施法者。
- **复用**：组件库光爆 `kit_burst`（着黛紫色），只做每段命中的辅助闪光，主体是折刃。
- **素材**：`gj_fold_blade`（折刃，两段分别正向、上下翻转使用）、`gj_veil_shade`（卸力影）、`gj_drag_trail`（地面拖痕）。

| 拍 | 时间 | 画面 |
| --- | --- | --- |
| 起手 | 0–200ms | 轻压暗；手边一缕暗紫影翻转 |
| 出手 | 200–420ms | 第一道折刃向前刺出 |
| 命中 1 | 420ms | 短刺痕、黛紫碎影、暗红；“流血 ×1”；3px 震 |
| 出手 2 | 460–640ms | 第二道折刃上下翻转，从目标下方反撩，与第一道方向相背 |
| 命中 2 | 640ms | 同上 |
| 收势 | 640–1150ms | 施法者身前立起淡紫卸力影，脚下拖痕向后拉出，随后淡去 |

## 4. 残火截锋（gj_s4b，甲 F4，单体，刀·炎）

- **独有母题**：刀尖拖地起火，贴地冲到目标脚前猛然上撩，立起一道竖直火墙截断去路。
- **与同门的区别**：全门唯一贴地、竖直向上的轨迹。燃隙刀是自上而下的斜弧，焚契破阵是大弧加纸卷。
- **主色**：炎劲朱橙 `#FF6A3D`（色带 `fire`）。
- **作用目标**：`fx.targets()[0]`。
- **复用**：无。
- **素材**：`gj_ground_sparks`（地面火痕）、`gj_upcut`（J 形上撩刀光）、`gj_fire_wall_cut`（竖立火墙斩痕）、`gj_spark_fan`（两侧扇形火星）。

| 拍 | 时间 | 画面 |
| --- | --- | --- |
| 起手 | 0–380ms | 压暗、暗角、镜头微推；刀尖拖地，地面火痕从施法者脚下向左延伸，火星向后上方飞溅 |
| 出手 | 380–700ms | J 形刀光贴地冲到目标脚前后上撩 |
| 命中 | 700ms | 目标正前方立起竖直火墙斩痕（高过目标），火星向左右扇形迸散，6px 震、推镜 |
| 收势 | 700–1500ms | 火星落地即熄，火墙与地面火痕变暗淡出 |

## 5. 烬里藏锋（gj_s5a，甲 F4，单体，刀·阴，中毒，双方暴露）

- **独有母题**：扬起一片灰烬，灰中一点寒光；短刀从灰里斜刺而出，拖着黛紫毒雾。
- **与同门的区别**：全门唯一以“灰烬幕”起手、刀光冷白而非火色的招，命中时目标泛毒绿。断烬回身同为阴劲，但那是两道折刃、没有灰幕和毒雾。
- **主色**：阴劲黛紫 `#B79CFF`（色带 `yin`），灰烬灰白，中毒毒绿 `#8BD45E`。
- **作用目标**：`fx.targets()[0]`；暴露提示在目标与施法者胸口各一次。
- **复用**：`gj_expose`（燃隙刀的暴露光斑）。两招的“暴露”是同一个规则状态，用同一个提示。
- **素材**：`gj_ash_veil`（灰烬层，实体透明底）、`gj_cold_glint`（灰中寒光）、`gj_poison_thrust`（带毒雾的刀光）、`gj_poison_bloom`（毒伤命中爆散）。

| 拍 | 时间 | 画面 |
| --- | --- | --- |
| 起手 | 0–400ms | 压暗、暗角、镜头微推；施法者身前扬起灰烬层，灰中寒光一闪一闪 |
| 出手 | 400–760ms | 冷白刀光从灰烬里直刺目标，后拖黛紫毒雾 |
| 命中 | 760ms | 灰烬与黛紫碎影爆散，目标泛毒绿；“中毒 ×2”；双方胸口各闪暴露；3px 震 |
| 收势 | 760–1500ms | 灰烬缓缓落下，寒光隐去 |

## 6. 回灰护影（gj_s5b，甲 F4，我方单体，卸力并解除暴露）

- **独有母题**：反手扬出一片灰烬织成的薄幕，斜覆到同伴身前，盖住同伴身上的暴露光斑。
- **与同门的区别**：全门唯一作用在同伴身上的招；主体是布幕状的实体，边缘一线铁青刀光，不是刀光本身。
- **主色**：灰幕灰白，刀锋铁青，无属性（色带 `mist`）。
- **作用目标**：`fx.allies()[0]`。
- **复用**：`gj_expose`（被盖住、消散的暴露光斑），理由同上。
- **素材**：`gj_ash_curtain`（灰幕，实体透明底）、`gj_steel_edge`（幕边铁青刀光）。

| 拍 | 时间 | 画面 |
| --- | --- | --- |
| 起手 | 0–300ms | 压暗、暗角；施法者反手一扬，灰烬从袖底飞出；同伴胸口亮着暴露光斑 |
| 出手 | 300–750ms | 灰幕斜斜飘到同伴身前，由小变大 |
| 命中 | 750ms | 灰幕落定，幕边铁青刀光一亮；暴露光斑被盖住后缩小消散，约 15 粒灰烬；弹“解除·暴露”；不震屏 |
| 收势 | 750–1400ms | 灰幕以淡影轻轻飘动，随后散去 |

### 断烬回身 `gj_s3`

- **母题不变**：两道方向相背的折刃，施法者沿空隙后撤。折刃加长，各留一道残刃；第二刃斩断处落下两截暗紫余烬；后撤时带起一线灰烬，卸力影多一层淡影。
- **分段**（1250ms，`hitAt` 420）：起手 0–200 聚气；第一刃 200–420；第二刃 460–640，命中处落两截余烬；回身 600–900 卸力影、地面拖痕、灰烬；余波至 1250。
- **复用**：`gj_ember_halves`（燃隙刀尾部的两截余烬，同是“断烬”，这里染成阴色）。

### 残火截锋 `gj_s4b`

- **母题**：刀尖拖地起火、J 形上撩、**一堵火墙截断去路**。原来的“火墙”只是一道细斩痕，现在补了真正的火墙主体。
- **分段**（1700ms，`hitAt` 700）：点火 0–380 刀尖拖地火星；贴地冲 380–700 J 形刀光；上撩命中 700 火星扇面、竖斩痕；火墙拔起 820（高潮）两层火墙（后层在目标身后，前层挡在目标与施法者之间、不盖住目标）、地面火线、震屏；火落 1240 起火墙矮下去，余烬落地。
- **新素材**：`gj_flame_wall`（竖立火墙）。**复用**：`ring_fire`（焚契破阵的贴地火线，同为地面火）。

### 焚契破阵 `gj_s4`

- **母题不变**：举刀燃火，斩断敌阵上空的契约纸卷。新加“焚契”（契卷先自下沿烧起、飘纸灰）与“破阵”（每名敌人身后各拔起一道火）两段。
- **分段**（1800ms，`hitAt` 760，群体：每名敌人各有伤害数字、惊惧浮字、火星扇面和身后的火）：举火 0–300；焚契 300–760；斩契 760 弧形火痕、契卷断成两截；破阵 880 每名敌人身后起火；烬落 1350 起。
- **素材**：沿用第一批的 `blade_fire`、`scroll_contract`、`scroll_half`、`arc_fire`、`ring_fire`。**复用**：`gj_flame_wall`（残火截锋的火墙，同门同为刀火）、`gj_spark_fan`、`kit_ground`（染火色，仅作契卷下沿的火苗辅助层）。

### 绝级功法三招的共同底子

- `gj_ash_field`（新）：灰烬烟云横幅，680 像素宽，底部透着暗红余火，铺在双方身后。三招共用，是“烬”的底。
- 横幅位置按“施法者与目标的中点、脚下地平线”取；回灰护影只在同伴身后垫一层缩小的。

### 烬里藏锋 `gj_s5a`

- **母题**：灰烬里藏着刀。高潮是藏在灰里的短锋从四面同时刺到。
- **与同门区别**：唯一靠“遮蔽”的一招，主色灰白＋冷白寒光＋毒绿。
- **分段**（2600ms，`hitAt` 1150）：
  1. 扬灰 0–500：身后灰烬烟云铺开，满场浮灰，施法者身前一片斜飘灰层。
  2. 灰涡 200–900：灰烬绕着施法者脚下与目标身周各旋成一圈。
  3. 寒光 560–1150：灰里先亮一点，再同时亮七八点。
  4. 直刺 800–1150：带毒雾的冷白刀光刺出，1150 命中，毒花绽开，弹“中毒 ×2”；1300 双方各亮一枚暴露光环。
  5. 万锋齐出 1380–1820（高潮）：寒光再亮一轮，六道短锋从四面依次刺到并停在目标身周；1820 毒花二次绽开、第二次伤害数字，弹“双方暴露”。
  6. 余波 1900 起：毒雾贴地漫开，浮灰落定。
- **新素材**：`gj_ash_vortex`（灰涡）、`gj_glint_swarm`（群点寒光）、`gj_poison_mist`（贴地毒雾）。**复用**：`gj_short_stab`（藏锋短刺的短锋，同是“藏锋”，这里六道成群）、`kit_burst`（染阴色，辅助层）。

### 回灰护影 `gj_s5b`

- **母题**：一片灰幕飞过去，落成一顶罩住同伴的灰罩。
- **与同门区别**：唯一落在我方的一招；柔和，不震屏、不闪白、不推镜。
- **分段**（2600ms，`hitAt` 900）：
  1. 扬灰 0–500：反手一把灰，手边一小圈灰涡。

### 与第一路的区别

第一路是刀：主体是斩弧、折刃、火墙、刀光。烬砂路**不出刀光**，主体全是“撒出去的东西”，命中是“落上去、烧起来”，没有斩痕形的主体：

| 招式 | 主体形态 | 动作 | 作用位置 |
| --- | --- | --- | --- |
| 扬灰 | 一把灰的扇面 | 自手边扇形扬开，罩住面门 | 每个敌人上身 |
| 火鸦镖 | 一枚带鸦翅火尾的短镖 | 走弧线斜飞，钉上肩头，沿路掉火羽 | 单体肩胸 |
| 烬雨 | 斜落的红砂雨幕 | 先抛向半空，再自右上斜落 | 每个敌人身上与脚边 |
| 引火线 | 贴地的一条火线与火头 | 撒线、点火、火头贴地烧过去，另一头烧回自己 | 双方脚下 |
| 爆烬 | 散在敌阵里的余烬滩 | 风吹亮，同时炸开，周围此起彼伏 | 每个敌人脚下与四周 |
| 阴火附骨 | 贴身的黛紫冷焰与骨里的火纹 | 三撮砂沾身，外焰往里收 | 单体全身，由外向内 |
| 回燃 | 火折、一粒火星、沿伤痕窜起的火 | 火星飘过去，旧伤一道道重新着起来 | 单体旧伤处 |
| 流火焚夜 | 夜空的裂口与成群斜坠的流火 | 火鸦冲天烧开夜空，流火逐颗坠地 | 全场，逐人命中 |

炎劲五招靠**形态与节奏**区分：镖（一枚、走弧线）、雨（成片、自上而下）、线（贴地、一路烧过去）、滩（先铺好、原地炸）、流火（自天而降、逐颗砸地）。
