## 门内区分

巡江司用长棍，意象是“拦、钩、锁”：江上设卡，拦住去路，把人扣在原地。四招攻击靠**气劲形状与动作**区分，不靠换色：

| 招式 | 主体形态 | 动作 | 作用位置 |
| --- | --- | --- | --- |
| 横江拦步 | 一道齐腰深蓝横栏 | 平推、前端短钩、推完后撤 | 目标身前 |
| 回杆卸势 | 回钩弧裹铁灰冲击楔 | 斜下撞击，再在目标兵器上缠一圈 | 目标胸口与手中兵器 |
| 断渡擒锋 | 两道霜蓝横栏，一高一低 | 先后交错拦截，第二道钩回 | 目标上下两处 |
| 锁江擒拿 | 一根电金长棍形气劲 | 横推后两端弯成上下双钩，扣住后绕身锁环 | 目标全身 |
| 风雨护归 | 头顶一道深蓝气梁 | 截住斜雨、理顺脚下回流、身前护影 | 全体同伴 |

横江拦步和断渡擒锋都是“横栏”：前者是**一道**深蓝、齐腰、只拦一次；后者是**两道**霜蓝、一高一低带倾角交错、栏身结霜、两段命中，收势化霜雾落地。

无属性招的主色按规范 §1-6“长兵木色与尘”：棍身深褐，气劲深蓝（横江拦步、风雨护归）或铁灰（回杆卸势）。本门文件新增两条粒子色带：`river`（深蓝）与 `steel`（铁灰），只供本门用。伤害数字仍按属性规范：无属性米白，寒劲霜蓝，雷劲电金。

## 1. 横江拦步（pj_s1，丁 F1，敌方单体）

- **独有母题**：一道横栏截住去路。
- **与同门的区别**：全门最简单的形，一道平直的深蓝横栏，只拦一次、不缠不锁。
- **主色**：深蓝气栏，命中米白数字。
- **作用目标**：`fx.targets()[0]`。
- **复用**：无。
- **素材**：`pj_bar_blue`（前端带短钩的深蓝气栏）、`pj_block_mark`（横向拦击痕）。
- 时长 650ms，预算 160，`hitAt` 300，`boost` 1.2。

| 拍 | 时间 | 画面 |
| --- | --- | --- |
| 起手 | 0–100ms | 棍身两端各起一点深蓝星芒 |
| 出手 | 100–300ms | 深蓝横栏齐腰平推向目标，带两道残影 |
| 命中 | 300ms | 目标身前一道横向拦击痕，8 粒尘屑，2px 震；米白数字 |
| 收势 | 330–650ms | 横栏向后撤回并从前端收短，淡出 |

## 2. 回杆卸势（pj_s2，丙 F2，敌方单体，削弱下一击）

- **独有母题**：回钩卸力，缠住对手的兵器。
- **与同门的区别**：全门唯一斜向（自右上向左下）撞击的招；唯一作用到对手兵器上的招（钢灰缠环落在目标手部，兵器处飘灰暗粒子表示被卸力）。
- **主色**：铁灰冲击，棍身深褐；米白数字。
- **作用目标**：`fx.targets()[0]`，缠环位置在胸口右前方（持兵器的手）。
- **复用**：无。
- **素材**：`pj_hook_arc`（回钩弧）、`pj_iron_wedge`（铁灰冲击楔）、`pj_bind_coil`（钢灰缠环）。
- 时长 900ms，预算 260，`hitAt` 420，`boost` 1.2。

| 拍 | 时间 | 画面 |
| --- | --- | --- |
| 起手 | 0–150ms | 手边回钩弧由右向左显出，先下压再回拉 |
| 出手 | 150–420ms | 回钩弧裹着冲击楔沿上拱弧线送向目标，铁灰碎屑 |
| 命中 | 420ms | 冲击楔撞上目标并放大消散，12 粒尘屑，3px 震；米白数字；钢灰缠环在目标兵器处收紧，灰暗粒子缓缓下沉 |
| 收势 | 720–900ms | 缠环松开淡出 |

## 3. 断渡擒锋（pj_s3，乙 F3，敌方单体，两段，寒劲，封穴）

- **独有母题**：两道渡口横栏一高一低截住来势。
- **与同门的区别**：见上文与横江拦步的对比；全门唯一两段命中。
- **主色**：寒劲霜蓝 `#8FD8FF`；封穴靛蓝细环；轻度压暗。
- **作用目标**：`fx.targets()[0]`，两段分别落在胸口上方与腰部。
- **复用**：`seal_ring`（封穴细环）。理由：封穴全游戏统一用这一圈靛蓝细环。
- **素材**：`pj_bar_frost`（结霜横栏）、`pj_frost_mark`（霜蓝拦击痕与冰屑）、`pj_frost_mist`（落地霜雾，也用作起手脚下白雾）。
- 时长 1250ms，预算 480，`hitAt` 520，`boost` 1.2。

| 拍 | 时间 | 画面 |
| --- | --- | --- |
| 起手 | 0–200ms | 轻度压暗；脚下一线霜雾，手边两道短霜栏凝出 |
| 出手 | 200–700ms | 第一道霜栏（高、微上倾）、第二道（低、微下倾）先后平推，交错拦向目标 |
| 命中 | 520ms、700ms | 每段一道霜蓝拦击痕与冰屑，3px 震，霜蓝 30 号数字；第二段霜栏向后钩回，靛蓝封穴细环收紧，弹“封穴”，旁边灰白小字“共 2” |
| 收势 | 780–1250ms | 霜栏淡去，目标脚下霜雾铺开，冰屑缓缓下落 |

## 4. 风雨护归（pj_s4，甲 F4，全体同伴，解除迟滞，卸力）

- **独有母题**：一道横梁截住斜雨，底下的乱流被理顺。
- **与同门的区别**：全门唯一的守护招，没有攻击动作、没有震屏；唯一用到“天气”（斜雨）的招。
- **主色**：深蓝气梁与护影，雨线深蓝带白；乱流青灰（迟滞色）。场景压暗、暗角、轻推镜。
- **作用目标**：`fx.allies()` 全体。斜雨与气梁按全队横向范围铺开（宽度随同伴分布拉伸）；脚下回流与护影每人一份，按顺序错开 50ms。
- **复用**：无。
- **素材**：`pj_rain_slant`（斜雨）、`pj_beam_roof`（横向气梁）、`pj_current_flow`（理顺的水流）、`pj_guard_veil`（身前护影）。前三个按全队范围拉伸，不参与 boost。
- 时长 1700ms，预算 900，`hitAt` 900，`boost` 1.1。

| 拍 | 时间 | 画面 |
| --- | --- | --- |
| 起手 | 0–320ms | 镜头轻推；施法者立棍，脚下一圈深蓝涟漪；全队头顶斜雨落下，每人脚下青灰乱流打转 |
| 出手 | 560–880ms | 深蓝气梁自中间向两端展开并升到全队头顶，斜雨落到梁上溅开，梁下不再有雨 |
| 命中 | 900ms 起（每人间隔 50ms） | 每人身前立起深蓝护影，约 10 粒雨滴光点；脚下水流由右向左理顺；弹“解除·迟滞”；无数字、不震屏 |
| 收势 | 1100–1700ms | 斜雨停歇，气梁降为淡影，护影与水流淡出 |

## 5. 锁江擒拿（pj_s4b，甲 F4，敌方单体，雷劲，封穴）

- **独有母题**：长棍横锁，两端钩回扣人。
- **与同门的区别**：全门唯一“扣住”目标的招：上下双钩加绕身锁环，是本门最重的命中；雷劲电金只表现为短促弯弧，不画闪电。
- **主色**：雷劲电金 `#FFE25A`，深紫描边；封穴靛蓝细环。场景压暗、暗角、推镜。
- **作用目标**：`fx.targets()[0]`。
- **复用**：`seal_ring`（封穴细环），理由同上。
- **素材**：`pj_staff_thunder`（两端带金紫短弧的长棍形气劲）、`pj_hook_thunder`（弧光钩，上下各一只，下钩翻转）、`pj_coil_thunder`（绕身锁环）。
- 时长 1700ms，预算 900，`hitAt` 760，`boost` 1.15。

| 拍 | 时间 | 画面 |
| --- | --- | --- |
| 起手 | 0–320ms | 压暗、微推；长棍形电金气劲在手边横举，两端跳金紫短弧 |
| 出手 | 320–620ms | 气劲横推到目标身前，两端短弧随行 |
| 命中 | 600–760ms 双钩合拢；760ms 主命中 | 上下两只电金弧钩向内合拢扣住目标；760ms 电金锁环绕身收紧，25 粒电屑，5px 震，推镜；电金数字，靛蓝封穴细环，弹“封穴” |
| 收势 | 1100–1700ms | 双钩松开向后退回，锁环与长棍淡出 |

### 回杆卸势 `pj_s2`（丙，85 → 119）

- **母题不变**：回钩弧裹着铁灰冲击楔，缠住对方兵器。

### 与第一路的区别

第一路是长棍：拦、钩、锁，主体是气栏、回钩、锁环，雷劲只有弯弧。腰刀路的主体是**直而利落的刀光**：出鞘、斜斩、横断、自上而下的一刀。寒劲表现为刀痕处结冰（冰缝、冰凌、薄冰、冰枷），雷劲表现为电金刀光与贴水的雷光带（只有短促弧光，不画闪电）。场面意象是江：缆绳、江流、夜江、怒澜。

| 招式 | 主体形态 | 动作 | 作用位置 |
| --- | --- | --- | --- |
| 出鞘示警 | 出鞘半尺的一截刀身 | 出鞘、一线刀光、推回鞘里 | 腰间与目标身前 |
| 截缆 | 一根绷紧的缆与一道斜斩 | 缆被斩断，两截垂落、缆头甩开 | 目标身前 |
| 寒江断流 | 一道横向霜蓝刀光 | 横掠，刀痕处凝成冰缝、竖起冰凌 | 目标腰间与脚下 |
| 连环追缉 | 两道电金月牙刀光 | 第一刀越过对手立成刀屏封路，第二刀贴地追上 | 目标身后与身上 |
| 封江 | 一道宽阔的横贯刀光 | 横扫全部敌人，脚下结冰 | 全体敌人膝下 |
| 雷行水上 | 贴水滚动的雷光长带 | 自右向左滚过去再折回，脚下窜起雷柱 | 全场水面，逐人命中 |
| 缴械 | 刀背的钝击与刀尖的细弧 | 磕腕、挑刃、兵刃飞起落地、冰枷合上 | 目标持刀的手与颈间 |
| 一刀镇澜 | 自天而下的巨大刀光 | 怒澜压顶，一刀劈开，江面平成镜子 | 目标与整片江面 |

两招寒劲横斩的区别：寒江断流是**单体**、刀光在腰间、结果是脚下一道冰缝和竖起的冰凌；封江是**群体**、刀光贴着膝下横贯全场、结果是一条薄冰带和每人脚踝上的冰。

### 出鞘示警 `pj_d1`（丁，单体）

- **母题**：腰刀出鞘三寸先示警。
- **分段**：起手 0–120 腰间刀身自鞘口滑出一截，刃口冷光 → 出手 150–290 一线铁青刀光自刀口掠到对手身前 → 命中 290 一道短斜刀痕、6 粒铁青碎光，不震屏 → 收势 360–680 刀推回鞘里。
- **新素材**：`pj_d_draw_glint`、`pj_d_short_cut`。
- **复用**：无。

### 截缆 `pj_d2`（丙，单体，流血）

- **母题**：一刀截断绷紧的缆绳。
- **分段**：起手 0–150 腰间刃口一亮，对手身前绷起一根粗缆，微微发颤 → 出手 230–400 铁青斜斩自右上劈下 → 命中 400 缆断：两截缆松垮垂落，缆头甩开，麻丝四散，3.5px 震 → 余波 560 断缆回抽，尘起。
- **新素材**：`pj_d_rope_taut`、`pj_d_rope_end`、`pj_d_steel_slash`。
- **复用**：`pj_d_draw_glint`（出鞘示警的刀身寒光；同一把腰刀）。

### 寒江断流 `pj_d3`（乙，单体，寒劲，对气血不足一半的目标加伤）

- **母题**：一刀横断江流，水在刀痕处凝住。
- **分段**：起手 0–200 轻度压暗，对手脚下浮出流动的江水 → 出手 200–520 霜蓝刀光带两道残影横掠过去 → 命中 520 刀过水断，脚下凝出一道冰缝，水流停住并结霜，4px 震 → 凝冰 640 冰缝上竖起两丛冰凌，三朵霜花 → 余波 900 霜雾贴着冰缝，冰屑飘落。
- **新素材**：`pj_d_frost_slash`、`pj_d_ice_seam`、`pj_d_ice_spikes`。
- **复用**：`pj_current_flow`（风雨护归的水流；同门水纹，刀过后染成霜色表示冻住）、`river_glint`（江面波光）、`pj_frost_mist`（断渡擒锋的霜雾；同门寒劲）、`frost_star`（六角霜花，寒劲凝霜通用）。

### 连环追缉 `pj_d4a`（甲，单体两段，雷劲，对迟滞目标加伤）

- **母题**：一刀封路、一刀拿人；后一刀追上前一刀。
- **分段**：起手 0–320 压暗、暗角，刃口电金 → 第一刀 320–640 月牙刀光走弧线飞到对手右上方，560–640 自右上斜斩到左下（620 第一段命中：一道完整的斜向刀光、电金光爆与沿刀路迸出的电屑，5.5px 震），680 余势落在其身后立成一道刀屏 → 第二刀 760–1000 贴地疾影追上，刀光横过来 → 命中 1000 横斩，与第一刀的斜斩交成十字，8.5px 震、闪白、推镜，旁注“共 2” → 拿 1140 电金锁环一收 → 余波 1300 刀屏碎落。
- 两段刀路不同：第一刀自右上斜斩向左下，第二刀贴地追上后横斩。（2026-10-11 主会话看图后返修：原来第一段只有白剪影和数字，看不到刀光。）
- **新素材**：`pj_d_thunder_cut`、`pj_d_chase_dash`、`pj_d_thunder_cross`、`pj_d_blade_screen`。
- **复用**：`pj_coil_thunder`（锁江擒拿的雷劲锁环；同门同是“拿人”）、`kit_burst`（通用光爆，染成电金，作第一段命中的火花，辅助层）。

### 封江 `pj_d4b`（甲，敌方全体，寒劲，迟滞）

- **母题**：封江设卡，刀光横在江面，谁也别想过。
- **分段**：起手 0–320 压暗，敌阵脚下江水流着 → 出手 320–760 一道宽阔的霜蓝刀光自右向左横贯敌阵 → 命中 760 每人各一次命中，8px 震、闪白、推镜 → 封冻 880 刀过处结出一条薄冰带，每人脚踝被冰封住，水不流了 → 冰裂 1080 冰面迸起碎冰 → 余波 1300 霜雾。
- **新素材**：`pj_d_seal_blade`、`pj_d_ice_sheet`、`pj_d_ice_shackle`。
- **复用**：`river_glint`、`pj_current_flow`、`pj_frost_mist`、`frost_star`（理由同寒江断流）。

### 雷行水上 `pj_d5a`（绝级功法第一招，敌方全体，雷劲，对迟滞目标加伤）

- **母题**：雷声贴着水面滚过去，被困在江上的人无处可躲。
- **与同功法另两招的区别**：唯一的雷劲、唯一的群体；主体是**横向**贴水的雷光带，另两招一个是近身小动作，一个是自上而下的一刀。
- **分段**（7 段）：① 夜江 0–500 夜色江面、压顶的云、斜雨 → ② 引雷 500 举起电金官刀，云里亮了一下 → ③ 雷行 800–1150 一刀挥下，雷光贴着水面自右向左滚过去，水面被照亮 → ④ 命中 1150 雷到脚下，自水面窜起雷柱 → ⑤ 困雷 1400–1700 雷光折回来再滚一遍，脚下一圈锁环，1520／1650 弧光在水面上窜 → ⑥ 雷光照江（高潮，定格）1800 整片江面亮成金色，云被映亮，雷柱再起，9.5px 震、闪白、推镜 → ⑦ 余波 2200 雷声远去，水面暗下来。
- **新素材**：`pj_d_river_night`、`pj_d_storm_cloud`、`pj_d_thunder_run`、`pj_d_water_lit`、`pj_d_thunder_pillar`、`pj_d_blade_thunder`。
- **复用**：`pj_d_thunder_cut`（连环追缉的电金刀光；同一把刀）、`pj_rain_slant`（风雨护归的斜雨；同门）、`pj_coil_thunder`（同门雷劲锁环）。

### 缴械 `pj_d5b`（绝级功法第二招，单体，寒劲，封穴，削弱下一击）

- **母题**：刀背磕腕、刀尖挑刃，差役拿人不伤命的手法。
- **与同功法另两招的区别**：全功法最“小”的动作，作用点在对手持刀的手；高潮不是更大的一刀，而是兵刃落地、冰枷合上。
- **分段**（8 段）：① 寒雾 0–500 夜江边寒雾漫开，刀横过来、刀背朝前 → ② 欺身 500–850 → ③ 磕腕 850 刀背磕在持刀的腕上，钝击光，腕上结一圈霜 → ④ 挑刃 1100（命中）刀尖一挑，一道细弧，兵刃脱手旋飞上半空，弹“封穴” → ⑤ 1300 腕上缠一圈削弱环、胸口封穴细环，弹“下一击 -20%” → ⑥ 悬刃 1500–1710 兵刃在半空慢慢转，镜头缓推 → ⑦ 落枷（高潮）1850 兵刃钉进地里，一副冰枷合在对手颈间，9.5px 震、闪白、推镜 → ⑧ 余波 寒雾贴地。
- **新素材**：`pj_d_frost_field`、`pj_d_back_knock`、`pj_d_wrist_frost`、`pj_d_tip_flick`、`pj_d_flying_blade`、`pj_d_ice_cangue`。
- **复用**：`pj_d_river_night`（本功法共用的夜江）、`pj_d_blade_raise`（一刀镇澜的官刀寒光；同一把刀）、`pj_bind_coil`（回杆卸势的卸力缠环，染成霜色；同门同是“削弱下一击”）、`seal_ring`（封穴细环，全游戏统一）、`burst_frost`（通用霜爆）、`pj_frost_mist`。

### 一刀镇澜 `pj_d5`（绝招，单体，寒劲，对气血不足三成的目标加伤）

- **母题**：风浪再大，一刀下去江面就平了。
- **与同功法另两招的区别**：唯一**自上而下**的一刀；前两招的江只是场面，这一招的江是对手——先是怒澜压顶，一刀之后平成镜子，动与静的反差是这一招的主体。
- **分段**（7 段）：① 怒澜 0–700 夜江翻涌，横幅巨浪起伏，对手身前身后各一个浪头，风雨交加 → ② 举刀 700 官刀举过头顶，寒光暴长，脚下的水先静了一圈 → ③ 浪压顶 1300–1750 浪越涌越高，画面发颤 → ④ 一刀 1750（命中）巨大的霜蓝刀光自天而下，12.5px 震、闪白、推镜 → ⑤ 浪分 1750–2300 巨浪自刀口分成两半向两边塌，水墙掀起，1900 半空冻成两道冰浪 → ⑥ 镇澜（境界展开，画面静下来）2300 云开雨歇，江面平成一面冰蓝的镜子，映着一线刀光，静水纹一圈圈展开 → ⑦ 余波 3300 冰浪碎成霜屑。
- **新素材**：`pj_d_wave_surge`、`pj_d_wave_crest`、`pj_d_blade_raise`、`pj_d_zhenlan_blade`、`pj_d_ice_wave`、`pj_d_mirror_river`、`pj_d_calm_ring`。
- **复用**：`pj_d_river_night`、`pj_d_storm_cloud`（本功法共用）、`water_wall`（一剑澄江的水墙；同是“一击劈开江水掀起的水墙”）、`burst_frost`（通用霜爆）、`river_glint`（江面波光）、`pj_rain_slant`（同门斜雨）。
