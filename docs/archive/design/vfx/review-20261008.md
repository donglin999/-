- **组件库模板（61 招 + 全部内功主动）：全部不合格**。实战中主体过小、形态雷同，画面上只剩伤害数字与受击闪白。按用户要求逐招专属重做（各门派设计文档见本目录）。
- **专属编排 20 招**：9 招合格；11 招偏小/偏弱，已加强（下表“处理”）。
- **引擎**：战斗中按角色等比缩到 0.5 → 下限改为 0.75；专属编排起手阶段统一加施法者内息光；新增逐招“主体放大”参数；防御强化招在选“防御”时播放其特效；新增确定性评审接口 `WuxiaBattle.preview`。
- **目标**：逐条核对后，命中都落在正确单位上（敌方招打敌、群体招每个目标都有命中、治疗与援护落在同伴、自身招在施法者）；此前怀疑的叠岚掌错位经坐标核对为误判。

## 重做后实战验收（2026-10-08 第二轮）

**范围**：6 个代理按门派逐招专属重做，共 61 招加 20 门 v3 内功主动。每招都按这个流程做：设计表 → 概念帧 → 单体素材 → 编排 → 评审。设计表和评审记录见本目录的 gy、am、bh、pj、zc、hc、sf、gj、hui、xf 各篇。

**验收方法**：
- 主会话用 `WuxiaBattle.preview` 按实战站位截图。
- 阵容：萧白、苏芷两名我方，对黑风喽啰两名和野狼。
- 113 条逐条看起手、命中、收势三个时刻。

**结论**：
- **专属编排**：101 条（v4 编排 96 条，剑法套 5 条），主体清楚，命中都落在正确单位上：
  - 群体招每个目标都有命中。千帆照水按时刻核对过，从第一个匪徒依次扫到野狼。
  - 治疗、援护落在苏芷身上。
  - 自身招和防御强化招在萧白身上。
- **复查中修正的 8 招**：
  - **断渡擒锋**：霜栏素材有锯齿状冰棱，动起来像闪电（禁止意象）。已重画成平滑的霜栏光带，旧图留作 `.replaced-20261008`。
  - **勾弦**：命中环是两圈正圆加四向亮点，看起来像准星。已重画成不规则的扁波纹。
  - **同担一线、一息相续、万壑回响第一段、百工养气诀、希声诀、江潮调息法**：主体偏弱，已放大并复查。
- **12 门旧原型心法**（玉泉寺、丐帮、鹿门书院、太和观、京湖义勇、白鹇谷旧心法）：原先用通用模板，已另派代理逐门专属重做（`docs/design/vfx/xfo.md`）。

**仍需战斗层配合**：各篇设计文档末尾都有记录，主要是以下几类：
- 延后发生的特效：援护承伤、反击、持续标记。
- 按实际状态变化的表现：被解除的异常名、是否消耗守势、施法者是否暴露。
- 选两名同伴的招式：目前战斗只传一名。
