状态：历史　最后核对：2026-10-19（2026-10-19 归档，只供追溯）

2026-10-16。本轮按用户“自主调整人物、剧情，并补全第三第四部分城市与游戏性”的要求形成的**当前设计方案，未实装**。四部分统一为**开始（栖河）、培养（三年）、游历、终局**；叶家旧事在培养末完整结清。本页负责后两部分的地点内容、入口、活动循环、公共推进和制作范围，人物身份与三方权限引用[势力与人物](faction-cast.md)，姓名、年龄和招募资格不在本页另定。

机器可读合同：[regions.json](../../../design/story-rework-20261016/regions.json)。总方位由[大地图](../../../design/world-map-layout.md)维护；培养中的外出规则由[整月历练](../../../design/world-map-journeys.md)维护。当前地图生产仍执行[现行地图规范](../../../design/map-development-standard.md)；战斗执行[表现边界](../../../design/combat-presentation-boundary.md)。以下 ID 是设计稳定键，不表示正式存档已有相应字段或场景。

## 2. 城市里具体能走到什么

### 汉皋：九街区复用，生活仍然继续

沿[汉皋空间合同](../../../design/hangao-city-spaces.md)的九街区与栖月楼入口制作，不另造一套汉皋。大地图进入南门或东门；渡船进入码头河街。正道盟方向官道统一接南门，取消“可能再增西门”的悬案。

| 可玩位置 | 本轮增加的用途 | 人物与个人篇 | 状态改变与返回 |
| --- | --- | --- | --- |
| 南关、迎客店 | 接行程、编队、补给与离城；终局显示当前可走路线 | 陆衡决定继续接镖还是给主角留出行程；叶蘅另报自己的安排 | 管制只改变指定出口；至少一个明示接应点可去主行动和休息 |
| 鼓楼、远山镖局、告示墙 | 三地区公开入口、收到缺席人物的约见、地方承诺表 | 徐令仪等在约定节点出现；不长期同时复制三个人站位 | 每个公共节点更新一批有限委托；旧任务不因切图消失 |
| 东市与霍记 | 有来源的器械修复、战前配装、普通采购 | 霍逐尘选择把工坊所得留给学徒还是支援外出；阮青雀以查验/修锁承担善后 | 修复物成为后续固定通道或一次准备项，不全是金钱奖励 |
| 西市、花巷、栖月楼 | 有观众与用途的试艺/公开演出、柳/秦各自解约与工作安排 | 晏小楼处理说唱中的真实当事人；柳、秦各自决定是否同行 | 冲突期仍保留普通演出或改为义演；闭店必须有原因与替代约见点 |
| 衙前街、码头、坊巷 | 查验、听证、安置、居民实际需求；`TRV-COMMON`在此汇合 | 沈雁回是民间委办，不能在此自己发布调兵令；裴知古记录亲历者 | 终局选择后门禁、货架、通航、居民位置分别保存，不统一换为废墟 |

固定夜景场所正常访问；特殊剧情夜进入限定区域。没有全城等待天黑的操作。栖月楼楼梯保留外形，走到楼梯入口按进入切换楼层；室内不能使用实时爬楼作为任务条件。

## 3. 三条地区主线可以不同顺序完成

`TRV-START`要求培养结束、叶家真相收束与正常出谷交接完成。玩家在汉皋选择去向；任务页清楚标出当前三地发生什么。各条链的 01→02→03→DONE 是固定因果，链与链之间不锁顺序，不要求全部同伴入队。

| 地区 / 节点 | 发生的事与玩家行动 | 非战斗路径 / 技能替代 | 战斗、失败与地区结果 |
| --- | --- | --- | --- |
| 北线 01：征船有据 | 营地议事房见严奉钧与真实征调文书，再去樊城埠亲眼见船户被留船；得到具体运量与停征条件 | 沈在场补充权责；沈不在由营中接待引见，严本人说明范围；梁尚在外救援，不提前登场 | 无开场强制战；接受任务不等于加入官府 |
| 北线 02：一船三用 | 梁定川救援归营后说明缺援通道，再用固定载额在粮食、伤员、修路物中选择；踏勘可开放第二条运输安排 | 乔/霍/闻提供不同捷径；缺席时看已标路线或请本地匠人，不能卡专长 | 物资分配只在本任务有限批次内结算；不生造全局粮秣经营值 |
| 北线 03：断援口 | 走正路突破劫运者，或先沿堤接回斥候取得绕行落点 | 选绕路需实走河岸并处理绞盘；修复小游戏可跳过按普通完成 | 普通小队战败退回营地保留已交接物；伤员晚到的后果在继续前明示，允许再试 |
| 北线 DONE：到粮之后 | 粮到与人员伤亡成为申请缓征的依据；严奉钧可坚持有限征调，梁提出替代 | 玩家交付书面方案并实际办成一项替代；裴知古缺席仍可由本人出面 | 输出`bounded_requisition / expanded_requisition / costly_relief`；三者都可继续主线，绝不假写全方满意 |
| 水路 01：工钱与人头 | 合川的护运人突然被列进归烬堂统合名单；拳门合同和堂务同时落地 | 段/石解释同门处境；未招募可在拳门院直接见当事人 | 玩家可支持合约、争取退出或暂不表态，均能见庄照尘 |
| 水路 02：谁要留下 | 烬渡堂院面对真实强征；决定保哪些人，自己出面或联名交涉 | 岑/戚在场有亲历回应；缺席可向堂口提出任务申请，由韩受理 | 不因私交高直接消除强征；同意统合也保留伤害与责任 |
| 水路 03：开渡 | 先修牵引、取得放人凭据或准备接应，再做夺回渡头/守撤离队的战斗 | 明示三种准备任选一项；阮/乔/秦能减少一个风险节点，缺席有公开工院办法 | `win/lose/flee`分别写主控人、扣押者、通航；失败可换陆路谈换押，不用读档才能继续 |
| 水路 DONE：谁守渡口 | 确定归烬堂保留自主、受统合控制或以武力扩张；归还被借商船或记具体欠约 | 账目核对只是善后之一，还须真的放人/还船/补工钱 | 输出`local_compact / unified_control / coercive_expansion`；无赔偿者不能获得同一友好结局 |
| 山门 01：借兵请帖 | 谢承岳持代表授权向照川支院索要联防人手，部分弟子愿去 | 徐/唐各能说本方顾虑；两人缺席仍由在院代表和弟子陈述 | 拒绝只引发条件谈判，不立刻举派追杀 |
| 山门 02：校场定约 | 通过有限试艺检验护路能力，或承接一段实务替代人员征调 | 比试失败仍可选择修道/亲自护一程；闻可踏勘，陆可组织接应 | 试艺用`noLose`，只判方案是否足够可靠，不能赢了就夺取支院产权 |
| 山门 03：离院或留守 | 履行获同意的轮值，或保护明确拒调者带物离开；对强拦者作小队战 | 先获得自愿名单和集合点；无人需要被救时不强行制造绑架 | 失败保留人仍在院的状态，可公开交涉再走普通出口；进入高风险突破前说明后果 |
| 山门 DONE：签下谁的名字 | 联防变有限轮值、继续强制借兵或支院分迁；谢/徐对结果作不同回应 | 代表承诺与弟子同意分别核对；不以好感替代签署 | 输出`voluntary_rotation / forced_levy / split_relocation`；余下责任进入终局 |

`DONE`表示地区事件已经有明确结果，包含有代价的结果；不把“圆满胜利”作为唯一通行证。退出一条未结案地区任务不会伪造DONE。

## 4. 六种可复用的游玩循环

| 循环 | 玩家真正操作 | 明示反馈与收益 | 限制与复用 |
| --- | --- | --- | --- |
| 武学试艺与配装 | 看对手意图/弱点→调整当前已学功法与同伴→回合战→复盘 | 首胜彩头、已登记师承的一次指点或招式熟练；输了也能继续交涉 | 学习仍须正式武学目录，不新造“入门剑法”；重赛不重复发奖 |
| 修造与路线恢复 | 观察破损→找普通材料或请匠人→按图修复/选择跳过→实际通行 | 开一条明确入口、减少一次险路、恢复一件具体物 | 使用霍记已有设计；不要求新增物理桥梁/船体模拟 |
| 物资安排与生活善后 | 看公开需求→用固定批次的装载格安排→送到交接点→看受益/缺额 | 营地补给、伤员安置与地方服务状态改变 | 装载格只属于任务，不覆盖背包负重；缺口有别的任务办法补，不能无限刷 |
| 公开演出与立场交涉 | 选讲哪一段、请谁作证、决定是否公开姓名→听当事人回应→完成承诺 | 一次听证机会、人员自愿留下、下一段公开邀约 | 柳/秦/晏有不同职业作用；没有艺人则用书肆/告示墙公开说明，不能拿演出控制全城民心 |
| 踏勘与探索 | 从清楚标注的两条路选择→实走关键路口→辨看地形/危险→建立返程点 | 替代通道、有限材料、怪物或匪徒可选挑战 | 普通行走即可完成；闻的图提高信息质量，不以隐藏身法数值锁主线 |
| 据点访问与共同生活 | 回访师门/栖月楼/船坞→做人物正在做的事→商量这次同行范围→登记下一约见 | 新对白、特定支援、人物自己的职业进展与再会 | 不强制全员常驻酒馆，不把个人经历都变成接单跑腿或最终战buff |

物资任务示例：北线首批载额为6格，粮3、伤员2、修路器具2。玩家先送粮+伤员（5格），就需要以河岸踏勘后的人力运具完成修路；先送粮+器具（5格），则需自己走医棚—河岸接伤员；先送伤员+器具（4格），营地缺粮，需要额外走转运库交付。三个组合都有可行续接，只有承诺后主动拒绝补缺口才进入有代价结果。该数值是任务关卡方案，不改物品重量、不扣培养体力、不制造现实倒计时。

## 5. 同伴让路线不同，缺席也能通

个人篇的具体节点引用[同伴重构](../../../design/story-rework-20261016/companions.md)；此表只登记地区接口与缺席替代，不重新写招募门槛。

| 地区接口 | 有相关同伴时 | 未招募、外出或主动不同行时 |
| --- | --- | --- |
| 汉皋工作与演出 | 柳处理曲目归属，秦安排台前后台职责，晏决定如何说当事人的故事；不能三人同功能 | 有各自常驻/约见地点；主线公开说明可在书肆完成；不自动代写她们同意加入 |
| 合川护运 | 段谈同门责任、石处理轮值与工伤、陆给出护送计划 | 本地拳门接任务，同门本人作决定；普通护送由萧白完成，不免费赠入队NPC |
| 烬渡统合 | 岑选择保人范围、戚坚持对账落实、乔/霍处理不同修造、阮检查具体锁具 | 韩仍接见任务当事人；修造工院提供公开材料方案；有权人员放行优先于开锁 |
| 襄樊委任 | 沈梳理授权、叶/苏协助医案、裴记亲历、乔处理船只可用性 | 营地接待给原文；医棚医者完成基本处置；主角可提交亲眼经历，无需代替医生 |
| 鹿门与山路 | 徐负责代表交涉、唐对同门发声、闻给路线图、殷说明师门能担多大责任 | 公开名册和当地路标可见；代表在约见点受理；既有师门联系人给有限支持 |
| 终局行动 | 同伴依已完成的个人承诺提供一项独特帮助，或明说不参加哪种伤害 | 任何路线都有公开筹备任务；不要求19人全齐，不借神秘代言/匿名信替缺席者说话 |

每个关键场景要有`present`、`invited`、`remote_notice`三个集合：只有`present`能现场说话；电话式即时隔空对话不成立。需要同行者到另一城时，以接受本次同行及过场登记位置，不在原城留一份同人NPC。若个人篇涉及两人，做单人在场版本或预约再谈，不能把普通路人替成缺席同伴的脸。

## 6. 游历到终局的推进门槛

```text
培养结束与叶家结案
  → TRV-START（汉皋重整行装，三条公开邀请）
  → 北线 / 水路 / 山门：任选顺序；至少两条抵达 DONE
  → TRV-COMMON（汉皋交接受牵连者，亲历遗漏一方的真实行动）
  → TRV-CLOSE（已做过的选择造成局势变化，显示三方将采取的行动）
  → END-CHOICE（看清责任、受影响的人与可回访范围，自选承诺）
  → END-ACT-ALLIANCE / GUIJIN / COURT / FREE
  → END-RESOLVE（履约、追责和地方状态）→ 尾声
```

`TRV-COMMON`不是三封假信：汉皋公开交接同一批受影响者。若遗漏北线，由有权差役到场执行真实限定征船，梁/沈按实际在场配置；若遗漏水路，由庄的办事队要求点人，岑未到也保留当事人自述；若遗漏山门，由联防队提出接收条件。玩家须完成一项释放、担保、改运或拒绝交人的实际选择，才能结束公共节点。三条都做过则使用汇总版本，不重复同一场扣押。

第三条未完地区链仍留在任务页。进入终局时，对其中可能改写的节点逐项提示；开放的后续改为当下结果的补救/回访，不重放旧强征。只有玩家确认最终行动`END-COMMIT`才暂时限制远行，界面展示限行地图、会关闭或改写的具体任务，以及“先留下”按钮。普通旅行和休息不会悄悄触发。

## 7. 四种终局行动都能在有限地图内落地

终局不是四套新城市。每线由**两项公开筹备任务、一个2—3场小队战以内的主行动、一次履约收尾**构成；允许非战斗替代其中一场，关键武力对峙仍保留。准备项来自明确已完成承诺或当前可接公开任务，界面显示“缺哪项、去哪里补”，不读隐藏好感。

| 路线 ID | 筹备与主要场景 | 主行动 / 对手 | 必须支付的代价与结局差异 |
| --- | --- | --- | --- |
| `END-ACT-ALLIANCE` | 鹿门争取两项可履行承诺：自愿轮值名单、地方供给；唐/徐可帮助，但公开代表也能办理 | 公议堂落实授权上限→支院阻止越权索人→山岔守住实际撤离；谢若拒绝停令则为当段对手，若已接受限制则是另一支越权队 | 接受长期护路轮值和按约供给；保住盟内约束或选择强势号令，两种民众/同门结果不同 |
| `END-ACT-GUIJIN` | 先明确自主或扩张授权、实际参与者，再落实船具和事后承担；两种分支见下表，任何特定同伴均非必要 | 自主在烬渡反强征；扩张随庄夺合川码头的一段护运经营权，主要对手和任务不同 | 自主承担赔偿与禁掠；扩张造成失业/失去通行权并改变部分伙伴支持，不能同得守护好名声 |
| `END-ACT-COURT` | 实交一批军需、实走一条替代运路，再由严奉钧在议事房作本次复核；沈提供经验，不拥有发令权 | 严同意则按限定额度护运；拒绝后继续执行原额度，或在最终承诺前公开拒命转独立护人；不靠神秘上级新令 | 继续原额度承担民生代价；公开拒命不拿官府委任奖励。已越权伤人的事实不能通过重选路线洗掉 |
| `END-ACT-FREE` | 汉皋选择要护的一批人、一个落脚点；另准备可用通道和医食安排。两项都能通过普通任务取得 | 坊巷集合→芦花渡或松风山岔撤离→面对当前追索队（由地区结果决定，不固定谢承岳） | 只保一处通路和约定人员，无力平定三方所有争端；需要长期安置，玩家必须放弃至少一项同时争地的机会 |

### 官府行动的公开复核，限定到谁能决定什么

1. `END-COURT-SUPPLY`：从襄阳转运库领用本次已封存的一批任务军需，走普通渡船/北路交到樊城本营。任务货不要求主角自己出钱购买；交付清单与营中接收事实写入同一事务。被截时处理当前小队，不在水上驾驶战船。
2. `END-COURT-ALTROUTE`：从樊城埠经河岸实走到断援口，完成一次绞盘修复或人力搬运，实际把一组自愿民户带到集合点。霍/乔/闻缺席时用普通工院材料与路标。梁只承诺本营控制的接应点与有限护送，不擅撤严的征令。
3. 两项完成后立刻可在营地议事房触发`END-COURT-REVIEW`。严核对真正到粮与可用线路，只调整他本人获授权范围内的额度/期限。普通休息不会触发，玩家也不用等现实几天或反复刷关系。程/沈可以整理事实，不能代严发令。
4. 严同意：形成`review_reduced`，按新限额进入`END-ACT-COURT`。严拒绝：形成`review_refused`，界面明示原额会占用哪些民船、影响哪些家庭；玩家可接受原额继续委任，或在`END-COMMIT`前公开拒命，计划路线改为`END-ACT-FREE`，不删除交粮/勘路成果，也不自动获得独立路线仍缺的医食与落脚许可。
5. 本轮不把“神秘上级下新令/停职严”列为已能完成的解决办法。程可留存转呈，回复只在后续另有明确剧情时进入游戏。已经执行扣人、伤害或强制过线的玩家，即使以后拒命，相关责任仍留档；不能重新选善意菜单同时拿两条路线的名誉和奖励。

### 归烬终局的两个实质分支

| 分支 | 地点与目标 | 敌我及战斗 | 受害者、同伴与结果 |
| --- | --- | --- | --- |
| `GUIJIN-AUTONOMY` 分堂自主 | 烬渡堂屋确定放人名单→扣押房放行→烬渡埠守撤离→归还船具 | 庄拒绝撤强征时，其直属执行队是对手；庄接受限额时改为阻止仍抗令的扣人队。韩只承诺本堂范围 | 岑/戚可参加；缺席由公开堂口交接和萧白行动完成。结果是本堂有限自主、受害者赔付和后续轮值，玄烛会仍存在 |
| `GUIJIN-EXPANSION` 随总堂扩张 | 烬渡获得本次行动授权与队伍范围→合川账房送达接管条件→合川码头夺取一段护运/收费点→留下经营与补偿安排 | 庄为本次行动盟友；拒绝交出经营权的当地护运守队为对手，用现有护运教习/普通守队模板，不把他们揭成共同黑手。战斗取胜只解除现场阻挡，控制范围依已落地协议/强制结果 | 受损者是失去工作与通行权的船户及合川拳门学徒。段/石拒绝攻击本门护运；岑若被要求扣无辜人为担保则拒参。警告在确认前出现，装备与成长保留，按本人约见点分头行动。没有这些人可由萧白及其他自愿同伴完成；总堂队伍仅为场外配合，不赠永久同伴 |

扩张分支仍允许在交涉前撤回，改走自主或独立护人；攻击接管点后不能同时领取自主救人的地方结局。赢后拒绝赔付会导致码头基础商业以外的熟客委托、拳门协作中止，具体失去哪些服务在行动前展示。赔付能补物损，不能令对方自动赞成归属变化。两种分支共享地图预算，但不能使用同一场“打败庄照尘”的战斗换结尾文字。

`END-COMMIT`前显示队伍、可用补给、行动目标、已承诺对象及暂不能去的地点；主角加最多三名人类战斗同伴，宠物遵现行名额，不额外塞入第五位人类。单人玩家不凭空获得具名永久同伴：公开准备任务可减少敌方一名普通敌人或跳过一次战斗，最低队伍可达性须以后用真实数值快照验证。

## 8. 战斗目标、失败与工程边界

先使用现有回合战能正确返回的`win / lose / flee`和任务前后场景状态，变更目标不要暗装成已有功能。

| 叙事目标 | 首次接入方式 | 后续扩展及条件 |
| --- | --- | --- |
| 突破、夺渡 | 击败当前截路小队，胜后开放对应入口 | 不需要地图即时混战 |
| 守住撤离 | 撤离人员先在探索对白中逐批离开，玩家与追击队交战；赢后确认其离开 | 若做“坚持N回合”，须新增明确胜利条件、UI和回归测试，未实现不得写成可玩 |
| 救人 | 先解除扣押/开门，战斗保护撤离；人质不用敌人模板挤占战斗目标 | 若增加可攻击保护对象须另写护送单位合同；本轮不依赖 |
| 收服、止战 | 在任务外选择接受投降；战斗胜利不等于已经杀死所有敌人 | “留活口”依剧情选择而非要求玩家猜最后一刀伤害 |
| 比试 | 无致死失败返回，失败后改实务方案或复赛 | 重复比试不发重复剧情奖励 |

每个主行动最多3场连续小队战；场间可选择撤回补给点，撤回不会把已救出的人送回牢房。地图中的大队兵马只作远景/声音/过场，主角处理的始终是一个门口、一个渡头或一队追击者。功法原位施放、目标特效命中；不新增技能近身冲刺、海战、城墙攀爬、实时万人攻城、全城火灾模拟。

失败分三种：普通比试可重试；地区实战失利可明示接受有代价结果或准备后再试；最终主行动败北返回行动前检查点，不吞存档和重复扣整批准备物。技术报错必须回滚事务，不能伪装成剧情败北。当前旧战斗默认扣一半钱并回庙的行为不适用于本合同的受控主线，接入时必须显式覆盖并验证，不能只写文档。

## 9. 回访、服务与奖励

地区保存`ruler / access / detainees / supply / localPromises / unresolved`等离散结果，具体状态合同见JSON；不追加一个包办所有变化的“天下稳定度”。襄樊征调范围、烬渡主控、照川弟子去向分别独立。

- 伤害与承诺回响至少包含一段本地对白、一处可见场景变化和一项实际服务/入口结果；不能只在尾声字幕里出现。
- 主线所需的公开求见、替代道路和基础休息保留无钱方案；钱币全作使用“文”，不重新引入“两”或兑换。
- 有限委托、首胜、教材、制作物沿城市一次性实例结算；不以切图、睡觉、拖延剧情补货或刷永久属性。
- 本轮确定奖励的**来源与用途**：有效通路、师承许可、制作权限、地区承诺、有限材料。永久数值和功法ID必须映射现行表并做预算，未映射的奖励不进入游戏。不会凭剧情一句“察言+3”增加无用途字段。
- 终局后开放的是“结局后回访”状态；如暂未制作，最终行动前必须说明当前版本返回菜单/读取战前档的边界，不能谎称可自由游玩尾声。

## 11. 接入前必须验证的路径

1. 三地区的三种“任选两条”组合均能进入`TRV-COMMON`；完成全三条仍只结算一次公共节点。
2. 19位候选全部未招募、对应三位代表不同行时，三条地区主线与四种终局至少各有一条公开可达路径；后续需真实战斗数值验证，不把静态依赖通过称为单人实战通过。
3. 每条地区一次失败/逃跑后仍能到补给点和一个合法出口；旧门禁不盖掉唯一回程。
4. 有关同伴在远方、在队中、拒绝本次行动三种状态的说话者/在场表均成立；个人篇不会被自动标完成。
5. `END-COMMIT`取消无状态变化，确认后只扣一次任务准备物；重载恢复同一行动，不重复发奖励。
6. 每张图真实行走进出、入口与返回点、家具量尺、NPC遮挡均通过视觉和运行验收，再标可玩。当前本页与JSON只通过文档结构核对，不具备这些实机证据。
