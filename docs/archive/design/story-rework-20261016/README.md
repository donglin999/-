## 先看调整后的游戏

**开始**在栖河认识人、经历争物和村祸；**培养**在归云谷度过三年，完成叶家家事并结交伙伴；**游历**真正进入各派、襄樊、合川与烬渡的生活和冲突；**终局**按玩家承担的立场完成不同目标，留下具体地方和人物结果。

旧稿把栖河与培养并入第一篇，形成了与2026-10-10决定不一致的四篇二十章。本轮按既有规则改回开始、培养、游历、终局。旧框架、旧终局候选有[原样快照](../../../design/archive/story-framework-before-20261016/README.md)，运行代码的旧事件ID不在本次擅自改写。

## 人物增减

可招募名册按现行采用内容修正为**19人，15女4男**。殷红缨已经有游戏入口，只是旧图谱漏记；裴知古已有培养期相识和五月同行，后续六节点调整为成长，不再作为首次加入门票。岑霜等武器与职责按各自最新负责页对齐。

本轮不额外增加可招募角色。现有19人的职业、战斗和人生问题可以区分，新增三方剧情应让他们有更深的行动。新增三名非招募剧情人物：玄烛统合者庄照尘、军需督办严奉钧、守备负责人梁定川；谢承岳从原有候选补成有权限边界的人物登记。沿用蒋闻礼、韩烬川、程铎等既有人物，不再堆一套副盟主、长老和官员。

## 地图与玩法取舍

保留汉皋作为生活和回访中心，展开襄阳樊城双城、合川—芦花渡—烬渡、鹿门—照川支院—松风山路。江夏方向仍预留，本轮不再开同质大城。归云谷、白鹇谷、清徽阁与栖河按自己的内容继续可访。

地区合同给出武学试艺与配装、修造恢复路线、有限物资安排、公开演出与交涉、踏勘探索、据点共同生活六种循环。任务胜负与选择改变通路、守卫、服务和人物去向；缺席同伴只失去其独特方法，主线保留公开路径。局势升级前展示受影响内容，不用隐藏计时逼玩家清完支线。

第四部分使用正道盟、归烬堂、官府、独立护人四条行动道路。归烬道路中的自主与扩张还需读实际选择决定敌我，不能一面支持统合一面仍强制打同一个首领。各线共用有限地点，通过不同目标和状态变化控制制作量。

## 本轮验证与制作边界

检查记录见[整合核对](validation.md)。自动检查关注登记和结构，人工核对关注动机、权限、年龄阶段、本人意愿与因果，二者都不能代替美术和游戏实测。

本轮没有制作新角色图片、语音或地图，也没有把第三、第四部分标成可玩。新增任务仍需逐场对白、在场安排、灰盒、素材、战斗标定和存档接入；培养期新伏笔须进入既有排期流程，不能悄悄增加强制日历占用。原正式素材、培养数值与存档不因文档调整改变。
