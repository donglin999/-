# 三方行动与剧情人物调整

状态：历史　最后核对：2026-10-19（2026-10-19 归档，只供追溯）

2026-10-16。本轮按用户“自主调整人物增减、补足游历与终局游戏内容”的授权落实设计。**这是新的负责设计，具体姓名、关卡与结果并非用户逐项确认；运行文本、地图与角色素材尚未接入。** 现行结构为开始、培养、游历、终局四部分；年龄以开篇同年登记，游历实际亮相按三年增长。

本页负责新增四位剧情人物的完整人物卡、三方独立行动、既有配角的职能调整。组织权限由[正道盟](../../../design/factions/alliance.md)、[玄烛会总堂](../../../design/factions/xuanzhuhui.md)、[归烬堂](../../../design/factions/guijintang.md)、[军需与守备](../../../design/factions/court.md)、[巡江司](../../../design/factions/patrol.md)负责；可入队人物以各自人物页为准。地区节点使用本轮地区设计的 `TRV-*` / `END-*` 编号。初稿登记交接数据为[faction-atlas-delta.json](../../../design/story-rework-20261016/faction-atlas-delta.json)，最终人物事实仍以主登记为准。

### 每方必须让玩家见到的实质高潮

- **正道盟**：`TRV-SECT-02` 校场条件比试只决定交接方式；`-03` 真正保护自愿离开的弟子，或按谈妥轮值完成交接。退出时要守住通道，不能“出示证据→全体散去”。终局谢若拒撤，打掉守点护阵、护送代表离开或阻断越权调度成为胜利目标。
- **玄烛会**：`TRV-RIVER-03` 打开扣人仓、保护撤离船或争取退兵。庄本人是高阶威胁，游历可胜在救人撤出；不能让低阶玩家必须杀败 78 级人物才见到后续。终局自主支路可与庄完整对决以救人还船；扩张支路则与庄合作，攻击合川外埠拒绝兼并的护运守队，使用既有守队模板。岑、段、石等可拒绝伤害船户或学徒，玩家有基础兵力仍能执行并承担关系与民生后果；不能两支都固定与庄作战。
- **官府**：`TRV-NORTH-03` 与梁分守断援口，保住粮车与民户通道，袭击者为趁隙劫掠的现有地方武装模板；严随后真有权拒绝降低征额。终局官府线以交足军需、验证替代路、营地当面复核落实可能的减额；若拒绝，选择原额护运并承担民生代价，或在 `END-COMMIT` 前公开拒命转独立护人。独立路线的破封/护人有后果，严不变成会绝学的最终 Boss，也不承诺未设计上级到场解围。

三方都有能解决的现实问题，也有由其主动决定造成的伤害。既有善行不抵消后续责任；上层施压不代替当地执行者的选择。

## 四、新增与补登记人物卡

**当前表现边界**：遵守[普攻接触、功法特效命中](../../../design/combat-presentation-boundary.md)。下列接近、接触和回站只属于普通攻击；全部功法施者原位简短 `cast`，以目标特效和状态反馈表现生效，不冲到敌前。复杂身体连段只保留为远期角色动作方向，不是本轮制作门槛或新战斗系统承诺。没有专属特效时记录缺项，不能用近身普攻动画冒充。完整能力等级由[等级负责表](../../../design/character-levels-100.md#2026年10月16日新增三方人物目标值)维护，本页不再独立设定数值。

### 谢承岳：联防发起人

- **身份与时间**：男，开篇同年基线 52 岁；培养第三年末实际亮相约 55 岁。不可招募。现有候选本轮正式纳入设计，属正道盟合作体系中有自身师承、护队与声望的前辈；他能带队，不是全权盟主。
- **形象**：宽额、眉尾下垂、鼻梁旧折痕，鬓发灰白整束。石灰长行衣配靛青斜搭护肩、左腕旧绑带；朴素剑鞘，可拆公议牌。宽肩沉稳，起身先扶旧伤左膝。与周砚的闲居衣、蒋的办公背心、庄的硬肩长刀区分。
- **生活与性格**：知道每个死伤护院家里还有谁，常亲手查验旧护具。听见人手不足会自己留下；也因此越来越认为旁人欠他一次服从。赞扬年轻人时常说“这段路交给你”，比公开训话有效，也形成压力。
- **愿望与弱点**：希望小派不用每次孤立求援，却逐渐把统一调度看得比被保护者的选择更重要。承诺能兑现，越权同样确实发生；不能靠突然承认“我只为野心”解释转变。
- **关系**：徐曾因其护运实绩支持联防，后来反对用未成年人补人手；蒋怕撤回授权导致联防停摆；唐认可护送必要，但反对弟子被当人头。与庄有地盘和伤亡矛盾，与严有兵权分歧，三人不是同一阵营。
- **首次演出**：培养末汉皋联络院，他把受伤护院送回后才入席；当徐问赈济是否附带轮值，他把替补名单推给她要求一同解决。主角只听懂当前差事，不立即推知未来争权。
- **动作与战斗**：完整能力目标见等级负责表。普攻定脚接锋后短步接触、回原位；功法原位持剑蓄势，以援护目标和反击目标的特效、状态显示其“先护后压”特点。远期可扩充侧身援护、借势回斩身体动作，当前不据此实现功法位移。正式招式名称、SP/BP 预算与特效另入武学负责文档，不盗用徐个人协锋招。
- **结局分歧**：可接受期限和退出条款，保留其护运实绩；可失去代表授权仍保一处险道；若坚持扣人扩权，成为有明确目的的对手。无论何种去向，庄和严继续根据自己的目标行动。
- **删去的负担**：不负责制造每宗假药案、栖月楼旧渡案和所有村祸。本轮不采用其主使叶家追杀的候选联系；叶家直接责任以培养末真相负责稿为准。

### 庄照尘：玄烛会统合使

- **身份与时间**：男，开篇同年基线 43 岁；第三部分游历实见约 46 岁。不可招募。经总堂议定来荆襄统合指定分堂，掌直属卫队及获授权抽调额。总堂其他人不为本轮再开完整人物包。
- **形象**：长方脸、较深眼窝、左眉一道平直旧疤；贴头黑发束短髻。暗褐硬肩短外袍、铁灰内衣、单侧束袖，分段铜扣与直属调队牌，佩长刀。修长臂长，交涉站侧而不摊坐。
- **生活与性格**：曾随队多次撤离失地，习惯在出发前问家眷安置和粮数；记得救过的人，却也把这份记忆用来索要服从。不会为气派把自己的卫队饿死，战败会主动丢弃货财保精锐。
- **愿望与弱点**：相信分堂各守一摊最终都会被逐个吞掉，想建立可守的地盘；容得下利益谈判，容不下公开退出。初次救回家眷是实绩；随后扣住不同意被抽调的新人也是他的责任。
- **关系**：韩受过上层护航与抚恤，不能只说自己从未得益；邢倾向交出无后台者保关系；岑提出自己带来的新人不能充额，但也须处理赔偿与旧罪；戚要求真正的分账与伤亡补偿。
- **首次演出**：`TRV-RIVER-02` 烬渡点名。先让一船失散家眷下船，把外衣交给哭闹孩子；转身按册点人，拒绝者被收兵刃留在仓院。照料与强征在同一场实际发生，不只靠人物自述。
- **动作与战斗**：完整能力目标见等级负责表。普攻短步长刀接触后回站；功法原位持刀短蓄，通过目标侧的迫退感轨迹、断阵命中特效与可见蓄势标记区分。断阵的预告/破势窗口须由回合规则落实，不靠玩家实时躲避动画。踏步追逼、多段身体连刀只作远期动作方向。游历打看守执行队并救人脱离，庄本人压阵不作为必须击倒的目标；相应终局才使用完整对决。不得套岑软鞭或韩的厚重普攻。
- **结局分歧**：保有统合权但接受分堂退出期限；因抽调超额与失地失势；或通过玩家支持取得更多据点，同时产生必须写出的受害者与关系损失。不默认本人败北等于玄烛会灭亡。

### 严奉钧：军需督办

- **身份与时间**：男，开篇同年基线 49 岁；第三部分游历实见约 52 岁。不可招募。架空转运体系中受委任的军需督办，来办指定沿线征运与补给；官位全称后续考据，不先画补子与等级章。
- **形象**：瘦长脸、低平眉、深眼下纹与短直髭；藏蓝圆领便服、黑软巾，深褐短披衣与硬文匣。靴缘带泥，显示他看过仓、船和道路；不能只用绫罗大肚贪官脸。
- **生活与性格**：每日核对船是否真正发出，厌恶只报喜不解决事的人。他会调走原本给自己驻所的炭粮补军仓，随后仍把船户困境归为可以稍后处理的损失。苦处说得再动人，也需要能送到粮的替代方案。
- **愿望与弱点**：按期保住补给、让地方武装受约束，并保住自己的整饬权。他的问题是主动选择让最弱者承担损失，而非所有文书都是伪造。不得写成开篇延寿传闻的总设计者。
- **关系**：梁确实需要他的粮却不赞成无限扣船；程必须面对真实上命；沈能指出事实但不能命令他；谢希望官粮支撑联防却不愿交出队伍；庄愿谈招安，也要保留自己的直属人手。
- **首次演出**：`TRV-NORTH-01` 樊城营地议事房，随后去北埠现场检查。先调度存放在襄阳转运库的军粮，现场查看迟到的粮车与停航的船；随后明确划定征船额。玩家能当场看见小船户比大商队更难拒绝，后续争议有事实起点。
- **动作与战斗**：非战斗主事人。交涉动作是拉近船图、指向未归粮车的位置、合上不能兑现的方案。官府线先完成公开的实际军需交付与替代运路验证，再到营地议事房触发当面复核；不需现实等待，不等待一个未定义的更高官员出现。独立路线如需阻止其扣船决定，战斗对象为有来源的封渡卫队/押运护卫。
- **结局分歧**：自改授权内征额并限定期限；或拒绝减额，玩家继续原额度护运并承担明确民生代价。玩家可在 `END-COMMIT` 前公开拒命转独立护人，交过军需、伤亡、违令等事实全部保留；过线后不允许换阵营清除责任。本轮不承诺上级直接停职严或撤全军令，程仅留存转呈。沈可能失去委办资格，但失败不等于全天下通缉，追责范围依具体行为明确。

### 梁定川：襄樊守备营统领

- **身份与时间**：男，开篇同年基线 38 岁；第三部分游历实见约 41 岁。不可招募。带一营守路与换防，军队番号和职衔细名在历史考据前不杜撰；不是军需督办的私人家将，也不替代程铎。
- **形象**：方脸、粗短眉、左耳旧缺、风吹黧肤与短乱须；铁灰札甲、褪色赭褐内袄、旧布护颈、短兵帽，长枪握处缠布。厚实的肩臂与短促行动有军旅疲惫，无华丽大将披风。
- **生活与性格**：吃饭先数未归的人，答应换防会说清哪队、哪条路。曾亲自救回失散民户，也批准扣住船户防止征运落空；不会因一场救援变成从未伤人的完人。
- **愿望与弱点**：守住路口并让守卒活着回家。缺粮和失员时会把拒役解释为逃避共同责任，须亲眼面对被扣家庭的代价；不由沈一句“百姓也苦”就放弃守备职责。
- **关系**：与严既合作又争执。支持玩家的上限取决于可兑现的补给、接应和换防；可与陆衡、乔、段、石合作，但每人都有可承担的量，不免费交出整条商路或全门弟子。
- **首次演出**：`TRV-NORTH-02` 前出救援归营，先指认一段仍缺人的通道，再谈征船。后续 `-03` 主角守缺口、梁带本营守另一处，不安排他无故消失等主角救全军。
- **动作与战斗**：完整能力目标见等级负责表。普攻以长枪单次刺击或枪尾近身接触后回站，出手前看队列；功法原位立枪施放，在受护者或攻击目标处表现守备/命中效果。低扫截步、移步让队列通过等复杂身体组合留作远期方向，当前不新增功法接触动作或实时走位系统。采用现有小队轮次和明确护送目标结算。
- **结局分歧**：获得有限补给后开放一条民户通道；支持改征但仍守军事必经口；玩家袭击守卒时可能成为对手，但击败其护队不默认杀死本人。其承诺范围必须能在地图状态上看见。

## 六、招募、在场与分歧合同

1. 徐反对伪造代表同意、用未成年人充兵额；岑拒绝绑无辜船户作退路且必须兑现赔偿；沈可履行有期限的核验但会为伤者撤离争取延缓。私人好感高不能令她们突然同意底线行为。
2. 角色拒绝当前行动先明确说出具体原因，保留继续交涉或分头行动；不因一次政治选择自动清空好感、装备与成长。永久关系变化必须在选择前提示可理解的后果。
3. 有相关人物且在队，使用本人反应；已结识但异地，提前邀约或独立场景交代，不能借空立绘发言；尚未结识，由负责本事的在场 NPC 提供必要信息，不代说同伴私事。
4. 拒绝部署的同伴不计入战场战力，已承诺却被另处占用的人不可同时出现在两城。每次大战只展示少数可信战点，其余由已建立承诺承接。
5. 不招齐同伴仍能完成每条主线：盟中代表/船户/地方差役提供基础路径；同伴带来更好的局部结果、独特关系回收与战术便利，不垄断唯一通关钥匙。
