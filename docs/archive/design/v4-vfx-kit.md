状态：**已实装，2026-10-08**。用户要求“完成现阶段的所有设计，包括特效”。

本页说明全部招式与内功主动的特效怎么覆盖：

## 2. 组件素材（`assets/fx/kit_v1/`）

20 个素材，都是纯黑底上的白到灰单色光，由 `tools_fx/gen_vfx_kit_elements.py` 生成、`tools_fx/build_vfx_kit_assets.py` 整理。运行时 `tinted(id, 色带)` 按素材亮度对色带（0 描边暗 … 5 白芯）做渐变映射着色，结果以 `id@色带` 缓存。所以一张素材可以出 8 种颜色。

| 类别 | 素材 |
| --- | --- |
| 出手主体 | kit_slash 剑气月牙、kit_thrust 直刺剑光、kit_blade 宽厚刀痕、kit_palm 掌形气劲、kit_fist 拳劲、kit_sweep 长兵扫弧、kit_needle 细针、kit_wave 音波 |
| 命中与地面 | kit_burst 命中光爆、kit_ring 冲击环、kit_ground 地面光环、kit_crack 地面崩裂 |
| 辅助 | kit_shield 护体光罩、kit_guard 弧形气墙、kit_rise 上升光流、kit_down 下压暗纹、kit_cleanse 净化涟漪、kit_mark 破绽光点、kit_qi 内息流转、kit_step 身法残影 |

## 3. 规格（`js/wuxia-kit-data.js`）

规格由 `tools_fx/build_vfx_kit_specs.py` 从设计数据导出，每招一条。

| 字段 | 来源与说明 |
| --- | --- |
| tier | 品阶：丁 F1、丙 F2、乙 F3、甲 F4、绝 F5 |
| wc | 兵器类：剑、刀、拳掌、长兵、暗器、音律、医、通用、内 |
| el | 属性 |
| role | 用途（见下） |
| side | 作用方：敌方 / 我方 / 自身 |
| group | 是否群体 |
| hits | 段数 |
| st | 可能施加的异常 |
| cleanse | 是否带解除 |

**用途的判定**：
- **招式**：先看段数和战斗定位，再看效果描述里的关键词。描述末尾的“弱点类型”不参与判断。
  - 段数大于 0：伤害。
  - 其余按定位和关键词归为：治疗、净化、护卫（卸力、承担、减伤）、看破、控制（有异常）、增益（BP、提前、鼓舞、协同）。
  - 防御强化招式单列。
- **内功主动**：只看“短名称：效果”那一句，依次判断看破、解除、回复内力、回复气血、定神或增伤，其余归为护卫。描述里带“同伴”的作用于我方。

**分类结果**：

| 类别 | 数量 |
| --- | --- |
| 伤害 | 62 |
| 护卫 | 19 |
| 治疗 | 13 |
| 净化 | 11 |
| 增益 | 5 |
| 防御强化 | 4 |
| 定神 | 4 |
| 看破 | 3 |
| 回内 | 2 |

## 4. 模板编排（`js/wuxia-fx.js` 的 `kitDef`）

**颜色**：
- 有属性的用属性色带：炎 fire、寒 frost、雷 thunder、风 wind、阳 sun、阴 yin。
- 无属性的伤害：剑用冷银（white），其余兵器用米白（plain）。
- 辅助类按用途：

  | 用途 | 色带 |
  | --- | --- |
  | 治疗 | heal |
  | 净化 | jade |
  | 护卫、防御强化 | mist |
  | 增益、定神 | gold |
  | 回内、看破 | sky |
  | 控制 | yin |

**档位参数**：

| 档 | 起手 | 飞行 | 收势 | 粒子预算 | 主体缩放 | 命中震屏 | 镜头 |
| --- | --- | --- | --- | --- | --- | --- | --- |
| F1 | 100ms | 160ms | 350ms | 150 | 0.60 | 1 | 无 |
| F2 | 160ms | 200ms | 450ms | 250 | 0.72 | 1.5 | 无 |
| F3 | 220ms | 240ms | 560ms | 400 | 0.86 | 2.5 | 轻压暗 |
| F4 | 320ms | 280ms | 720ms | 600 | 1.00 | 4 | 压暗、暗角、末段闪白 |

起手时手部有聚气粒子和内息光（kit_qi）。BP 加强沿用第一批的通用机制。

**按兵器类出手**：

| 兵器类 | 出手 |
| --- | --- |
| 剑 | 月牙剑气沿弧线飞出，多段时左右交替。名字带刺、点、挑、穿、隙的改用直刺剑光 |
| 暗器 | 三枚细针并行 |
| 拳掌 | 名字带“掌”的用掌形气劲，其余用拳劲；F4 加地面崩裂 |
| 音律 | 三圈音波由近及远 |
| 刀、长兵 | 在目标处由近及远显出刀痕或扫弧（裁切揭示），多段时左右镜像 |

**命中**：
- 主色光爆和斩击火花。
- F2 起加冲击环，F3 起加地面涟漪。
- 伤害数字按属性色。第一段弹出异常字样，用异常色。
- 控制类不出伤害数字，只出命中火花、下压暗纹和异常字样。

**辅助类**（作用于每个目标）：

| 用途 | 表现 |
| --- | --- |
| 治疗 | 地面光环、上升光流、翠绿 +N；带解除时加“解除” |
| 净化 | 净化涟漪、驱散的暗色细线、“解除” |
| 护卫、防御强化 | 护体光罩，加朝敌方一侧的弧形气墙 |
| 增益、定神 | 身后升起金色光流 |
| 回内 | 内息流转、天蓝“+N 内” |
| 看破 | 破绽光点、“看破” |

**群体**：每个目标各出一套命中，最多 4 个，相邻目标错开 50ms。

**内功主动**：
- v3 心法按 `xf_<心法>` 的规格编排。
- 运行时旧原型心法（玉泉心经等）按主动效果类型使用通用模板 `heart_mp`、`heart_heal`、`heart_ding`、`heart_guard`、`heart_reveal`、`heart_cleanse`。

## 6. 接入战斗

`js/wuxia-battle.js` 的查找顺序：
1. 专属编排（v4、剑法套）。
2. 组件库模板（kit）。
3. 内功主动：先找 `xf_<心法>`，没有就按主动效果类型找 `heart_<效果>`。

作用于我方或自身的编排不受朝向限制。素材包加载 `sword_v1`、`v4_v1`、`kit_v1` 三套。
