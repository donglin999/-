# 主角与重要角色：立绘、表情与静态动作设计

状态：历史　最后核对：2026-10-19（2026-10-19 归档，只供追溯）（原记：**开发与美术设计规范**。2026-10-04。可加入人类固定准备六个完整对白状态（来源：`companion-performance.md`），逐人身体语言（来源：`companion-performance/index.md`）与完整提示词已列出。人物事实以人物（来源：`cast.md`）为准；画风以已固定立绘标准（来源：`character-portrait-style.md`）为准；每类角色的必需素材与基数以[角色类型](role-assets.md)为准；普通 NPC 的制作限制以剧情表现（来源：`story-presentation.md`）为准。）

2026-10-03，用户明确要求培养Q版的人物反应同时改变表情和动作，按培养Q版规范（来源：`cultivation-q-portraits.md`）制作。该媒介允许手势、头肩与重心随情绪变化，不受下文纯表情图的固定握物手及固定眼线要求限制；同一身份、服饰设计和道具归属仍须一致。

## 1. 设计目的

人物画面首先让玩家认出「是谁、处于哪个阶段、正在做什么、此刻怎样回应」。美貌、气势与细节服务于身份和生活处境。角色成长由服装、姿态、视线和对他人的行为逐渐体现，不靠每章换一张更华丽的脸。

重要人物使用同一个身份基准：脸型、五官位置、发际线、发色、身高关系、肩背和体型固定。每个阶段另列服装与道具，表情和姿态都从**该阶段同一基准图**派生，不从上一张差分继续生成。

所有重要角色都需要能持续使用的设计档案；不等于现在为所有人物、所有阶段一次生出整套图。当前生产范围以章节需求清单为准。

## 2. 四种图分别承担什么

| 类型 | 设计理念 | 构图与使用 |
| --- | --- | --- |
| 带背景菜单立绘 | 像一幅属于这个人的当前生活画面；背景反映处境与心境 | 按固定风格（来源：`character-portrait-style.md`）使用 2:3 全身竖图、淡雅真实情境；无 UI 烘焙。此图不拿来挡住剧情 CG |
| 透明对话立绘 | 让神情与说话姿态清楚，方便在不同场景使用 | 同阶段画布与身体尺度稳定；头肩位置允许符合情绪的自然变化；同脸同装；不携带菜单的背景。人物大小不因透明留白而跳变 |
| 完整对白状态 | 一张图中全身与神情一起表现回应 | 可加入角色统一六状态，切换整图；同情绪连说几句沿用 |
| 静态动作／姿态 | 将反复出现的意图画成可读的一个关键瞬间 | 抱箱、查看纸页、挡护等需要看清手、肩、重心与物件。多人接触或一次性劳动通常交给 CG，不把其拆成每人一套姿态 |

剧情 CG 另按事件构图，仍锁定上述身份。探索像素人物与战斗人物用各自的画法与比例规范，但发型、服色、医具和已获得的装备仍必须对应同一角色阶段。

## 3. 每个人的表现逻辑

| 人物／阶段 | 立绘和身体语言的核心 | 表情重点 | 可复用静态动作方向 |
| --- | --- | --- | --- |
| 萧白·现代与初入村 | 24 岁成年程序员，疲惫、不熟悉环境，先看清再试；现代装与借来便衣同脸，站姿尚不熟练 | 留意、困惑、紧张、犹豫、短暂松弛；不把分析写成永远冷静的高人脸 | 挡住木杆而非挥剑、扶住轻物、查看纸页、疲惫坐姿。无剑、无门派徽记、无归元诀运功姿态 |
| 萧白·后续修习阶段 | 逐步站稳、动作节制；学过什么就能表现什么 | 专注、克制的坚定、与熟人相处时的自然笑意 | 学剑后才列剑姿；阶段未发生时不借用襄阳持剑图当开篇全身图 |
| 叶蘅·初始乡村医者 | 22 岁，清秀、偏瘦、朴素干爽；比苏芷年轻，成人骨相；对病人主动，对家传物有明确边界 | 专注、担忧、发现异常、拒绝强索、照护后的释然；亲近反应不过度幼态 | 护住药箱、整理普通布药、平手示意暂停。施救的手部接触可放进 CG；初始不摆后续进攻针法架势 |
| 叶蘅·同行针攻 | 同脸同身形，轻行装呼应萧白；视线主动锁定对手，出手利落 | 决断、警醒、配合；不演成阴狠刺客 | 取针、探位与出针关键姿态，仍能做基础照护。只在路线与技能实际展开后列入生产 |
| 叶蘅·白鹇谷医师 | 浅色与青绿呼应苏芷，衣层更轻、年资较低、动作灵动 | 判断、鼓励、施治时的专注、病者稳定后的放松 | 示意调息、整理针囊、施治支援；不直接复制苏芷的衣服、体型和成熟姿势 |
| 苏芷 | 成熟游方医师，稳定、干净、动作准确；先看病人，再开口 | 专注、审慎、轻微认可、发现错误时的严肃 | 察看脉象、持针待施、确认药物、收针；重心稳，医具位置清楚。两章未登场，不加入开篇清单 |
| 周砚 | 独立游侠、生活朴素，先让人站稳、说清楚；有经验但不摆全知高人姿态 | 留意、制止、思考、日常放松 | 伸手挡止、查看一页笔记、招呼人坐下。山居私人身份，不带被删除门派的标识 |
| 陆衡 | 护运者，身体先照应路与人，话短，安全时才轻松 | 警觉、指导、招呼、稍放松 | 护路站姿、指路、扶稳普通行李。多人救援动作可画入 CG，不为一次扛包做整套动作 |
| 岑霜及重要对立人物 | 立场、行动和限制同时可见，服装道具匹配职务 | 强硬、克制、审视；不人人恶笑或夸张怒吼 | 挡止或指示等代表行为，先检查已有立绘与事件 CG 是否足够；确需反复独立展示才补姿态，不按出场人数凑图 |

周婶、陈伯、店家、老人、差役等本轮仍属于普通剧情 NPC。他们可以在 CG 里有具体姿势，不单独制作表情全集、动作差分或精细全身菜单图。

## 4. 可加入角色合并为完整状态

可加入人类每个当前阶段采用6张完整对白状态（来源：`companion-performance.md`）：常态、开心、担忧、愤怒、惊讶、本人专属情绪。身体手势、肩身、重心、头方向与眉眼嘴一起变化，切图就是换整个人，不单独管理纯表情图，也不预制动作×表情矩阵。

医者护住医具、船工收住工具、曲师抱琴设界，职业身份进入情绪身体语言。悲伤或愤怒仍欢迎、邀约或开心是退回项。旧表情图只作为候选，经过整图协调复验才能使用。主角与重要NPC的已交付包沿其分类，普通NPC不追加同伴六张配额。

## 5. 姿态卡必须写清楚

每张静态姿态需要：角色／阶段、用途与场景 ID、视角、视线目标、重心与承重脚、左右手分别做什么、握持物及归属、与基础立绘的画布锚点、可复用范围、回退图。

例如叶蘅「抱箱」：乡村便衣；箱子为她所有；双手抓住提带与箱侧，身体略收护住箱子，目光看向索物者；不改成攻击前倾，不加针攻路线服饰。它可用于索物、避险等待；不能用来表示已经把箱子赠给对方。

静态图可以有动作的张力，但肢体必须能完成该动作。人物受伤或疲惫时按当前状态画克制的肩背、神情和衣物痕迹，不擅自新增伤口、眼泪、断肢或既定死亡。

## 6. 交付与验收

源 PNG 保留原尺寸与基准图出处；运行图等比处理。对话表情一组使用同一画布和锚点，不能各自裁到脸的边缘。静态姿态在深、浅背景检查透明边，并在两种实际游戏视口检查人物、手和道具是否可读。

采用前与基准并排检查同脸、服装层次、体型、持物、阶段与媒介；接入后检查切换不跳位、姿态不遮住正文、CG 中不重复叠加人物。源图正确不等于已经通过运行画面验收。需求、提示词、文件和状态记录按素材需求规范（来源：`asset-requirements.md`）维护。
