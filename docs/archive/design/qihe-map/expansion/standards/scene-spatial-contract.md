# 场景画板与空间合同

状态：历史　最后核对：2026-10-19（2026-10-19 归档，只供追溯）

<!-- map-standard: supporting -->

本文负责占地、遮挡和对象空间规则；版本、硬参数、制作顺序与参考图以[现行地图开发规范](map-development-standard.md)为准。旧序章和襄阳实现记录只作迁移追溯。

## 制作顺序与交付门槛

地图首先按[大中小分级与分区验收](map-size-review.md)划分。小图可整体检查；中、大图必须全覆盖分区、96像素重叠与独立接缝检查，围墙另有连续路径、合法开口和端柱合同。整体连通、几条路线或一张实机图不能代替结构和局部视觉验收。

1. **画板先行**：固定镜头、世界尺寸、成人脚底及身高。标明主路、院门、封闭屋身、可走廊下、NPC 与交互站位。用同尺寸灰盒与占位人物走通，再生成美术。
2. **逐物件定义空间**：每个对象有唯一 ID、地面占地多边形、可见遮挡轮廓、脚底排序线、遮挡类型和交互接近点。空地、草色与投影不得用于推断碰撞；树冠与树干、桌面与桌腿分别定义。
3. **按用途选图层**：先整体预览、再分区生产；静态底图原型可按同源轮廓重绘前景。需要淡化或动态变化的树、屋顶、墙、家具必须有干净底层和独立透明素材。生成器以画板坐标与尺度约束素材，不能以生成结果反过来随意挪动门和道路。完成后将素材轮廓与画板叠加，越界即退回处理。
4. **统一构建**：同一份 authoring-board.json 生成碰撞、深度片、交互锚点与调试画板，不在运行代码另写一份近似边界。必须有轮廓，禁止缺失轮廓时默认为整块矩形。
5. **进入游戏前验收**：先看占地叠图，再看遮挡叠图和带成人轮廓的净宽。双向走过门、墙角、树边、桌边、NPC 接近点；最后检查实际游戏截图。单纯“符合 mask”只能验证程序，不能验证 mask 是否正确。

## 占地、遮挡和排序

### 高差场景扩展（按场景核查能力）

按襄阳高差设计（来源：`xiangyang-elevation-design.md`）补充表面ID、层、高度、台阶踏面与显式连接；人物、NPC、队友、阴影、拾取命中及存档同步所在表面。每层独立可走区域，层间只通过楼梯／桥头等连接。平台侧缘有可见挡面，桥边有栏杆。单层mask与y排序不能当作桥上桥下同时通行的实现。独立室内楼层使用本地高度0，建筑楼层高度仅描述外部关系。

| 对象 | 占地 | 遮挡与排序 |
| --- | --- | --- |
| 地面、低草、投影 | 可走 | 不遮挡 |
| 树 | 树干脚底 | 树冠透明轮廓按树干基线排序；遮住主角时显示被遮挡部分的低透明人物提示 |
| 横墙 | 墙脚实体 | 墙体轮廓按当地墙脚排序 |
| 纵墙、长围栏 | 连续实体，开门处显式断开 | 必须沿长度拆段，各段按自己的脚底排序；不得以整面墙最南端排序 |
| 房屋 | 封闭房间不可走，开放廊下独立定义 | 屋顶、房身、柱分层；廊下若允许走，要能看见主角所在位置 |
| 桌、椅、桶、篮 | 每件实体独立定义 | 物件精确 alpha，桌面遮挡不能带一整条地面 |
| NPC、交互点 | 成人脚底与实体留净空 | 接近点不能落在家具、墙脚或其他人物脚底范围内 |

通路净宽按角色脚底宽加两侧安全余量检查。当前序章角色脚底宽 28 世界像素，普通通道与住宅门净宽至少56、主要门与主路至少84，门洞净高至少100；新制作执行硬门槛，旧不足项登记整改。头肩短暂被树冠遮住可以成立；水平矩形裁断、无实体空气墙、脚落墙体或家具内部不能通过。

## 遮挡可读性

正式分层素材可以对前景局部淡化，但必须有干净地面层，否则淡化仍会露出底图烘焙的同一物件。旧整图迁移使用仅在前景真实 alpha 与人物重合处绘制半透明人物提示，保留前后关系；不能用整幅人物置顶掩盖错误碰撞。轮廓外地面禁止覆盖人物。主角与交互 NPC 均需检查。

## 同画板的画质合同

画板同时约束构图与像素内容。新场景画板必须附统一参考图、镜头、输出尺寸、世界像素密度、物件尺度、边缘颗粒、色板、材质与光源，不得只给“精美”“像素风”等泛词。成人 92 世界像素作为所有建筑、门、桌椅与树的尺度尺；人物暂用占位，不生成新人物。

- 统一高三分之四近正交视角、按现行参考校准；世界尺寸由场景规划冻结，不能沿用旧1920×1080作为通用尺寸。灰蓝瓦、灰米墙、灰绿草、土褐地，上左柔光。
- 新整幅地面原稿有效尺寸至少 1920×1080；独立物件按最终世界占地至少 1:1 生产。更高分辨率只允许同批次一次统一采样，禁止某件像素颗粒粗、某件平滑写实。扩大文件尺寸不能当作新增细节。
- 在标准画布的 100% 和实际游戏缩放下共同审核门、瓦片、墙缝、草边、桌椅，以及占位人物高度。高分辨率与画风一致分别判断；清晰也可能不合风格。
- 地面与物件共享色板、纹理尺度、边缘处理、光源和调色。接缝、透明边缘和半透明阴影必须检查；禁止带地面底色的切片叠上另一层地面。
- 当前像素风使用最近邻采样及 lossless 输出，不做单件颜色量化。若以后改成精细手绘，需要先改整套合同与统一渲染方式，不能只替换部分素材。
- 画板建立固定物件比较区：同一地面上并列建筑、树、桌、桶、墙与成人占位尺，过审后再批量生产。物件放入地图后不得通过随意缩放补救不符合尺度的原稿。

历史1672×941旧整图是明确的迁移例外：1920 输出保留已有细节，不能称为原生 1920 素材。占位人物的像素颗粒与场景还不能作为正式统一美术验收通过依据。`authoring-board.json.artContract` 记录本批限制与目标。


### 历史序章重做的画风校准纠正

重做首批独立素材被用户指出风格偏离，已退稿：正面立面比重偏大、瓦片/木纹过密、树叶趋向细碎写实。序章改以既有 `art_sources/prologue_village_v1/terrain-source.png` 为直接图像参考，优先按原物件分离与补全，而非根据文字重新设计建筑。必须在相同运行宽度下对比原图与透明样板的屋顶/立面比例、纹理颗粒和调色，再扩展其他对象。独立分层不构成更改画风的授权。源尺寸提高也不能改变像素颗粒与复杂度。
