# 制作、验收与实施顺序

状态：历史　最后核对：2026-10-19（2026-10-19 归档，只供追溯）

本页冻结本分支扩展使用的规则摘要。来源为主目录2026-10-04地图开发规范、角色分类/四向质量、动画白模管线；实际文件及SHA见[核查记录](../../../../design/qihe-map/expansion/asset-audit.json)。来源用于追溯，规则摘要在本分支内可读；实施前导入完整专项文档及相关依赖，不能依赖开发者机器的绝对路径。

## 地图仍按现在的逻辑生成

1. **先功能、再灰盒**：从人物去向、货物进出、居民生活和撤离路线定道路，不先出风景图再找地方放NPC。每个建筑/树组/货物组有ID、主人或用途。
2. **冻结空间合同**：地点世界尺寸；墙、门、树干、道具占地；脚点与前景轮廓；主路净宽；入口与返回点；各时段人物凹口。完整灰盒走通所有门、路线与火灾替代出口。
3. **提供参考生图**：程序灰盒图＋当前分支`art_sources/qihe-v1/generated-village.png`环境参照＋同尺度角色标尺。固定相机与光向，不自由堆道具，不把人物直接烘焙到背景。主目录其他functional-v2仅作质量复核，不擅自更换当前分支整体画风。
4. **先完整可读预览，后分区生产**：每块绑定世界范围、实际输出尺寸与唯一对象归属；参考重叠区共享，完整房子/桥/树冠不由两块分别重画。保留清洁地面与必要透明前景。
5. **标定成图**：逐物件分开记录可见轮廓、地面脚印、前景遮挡、排序基线、交互接近点，编译掩码/寻路数据；布局漂移则修图或合同并复验，不能凭原草图就称成图通路正常。
6. **实际走行**：全部双向入口、NPC交互、绕屋、贴墙奔跑、两人跟随、火灾前后、存档恢复均留证据；技术与美术分别判定。

| 必守参数 | 门槛 |
| --- | --- |
| 成人/脚点 | 可见身体92世界单位；普通成人同类姿态0.97–1.03倍，有角色依据可0.93–1.08倍；脚底横向半宽14 |
| 碰撞 | mask每2世界单位；preciseNav；nav网格8，路径/移动扫描步长≤2；树冠/屋顶不是落地碰撞 |
| 门路 | 普通净宽≥56，主路≥84，多人区目标112–140；门洞可见净高≥100 |
| 密度 | 新正式图有效原生密度X/Y均≥1源像素/世界单位；各块相对统一目标±5%，材质纹理尺度比0.9–1.1 |
| 分区验收 | 核心≤640×480，重叠96；接缝两边各96；全图覆盖，不能只看主路 |
| 实机 | 1280×720和1920×1080，记录镜头/CSS/DPR；16ms与50ms步进均检查碰撞 |

当前A仍有0.64密度和小门例外，只能作风格/布局参考。新外区不能继承这些缺陷；若预算先做低清原型，明确标原型、待正式替换，不扩大当前图像冒充提升质量。每个B/C/D/E均超过小图面积上限125万，至少按中图验收；E含桥也至少中图。冻结家具量尺后才生成，设计阶段原拓扑只有用途；实施时补齐了灰盒对象矩形与尺度，保存为`art_sources/qihe-expansion-v1/layout.json`，再制作完整预览。当前仍为可玩原型，未进入正式分区美术放行。

## 人物必须走白模参考流程

1. 冻结便衣短发定妆、旧版共同身体比例及像素网格。独立角色ID如`qh_hero_initial`，不可覆盖全游戏`hero`。
2. 程序生成四方向白模：复用旧版已认可运动，删除旧白模马尾/背剑，按便衣体型调整衣摆。先导出白模走/跑GIF，正常速度判断承重、左右交替、对侧摆臂、跑步腾空与循环衔接。
3. 定妆＋每批最多4个白模姿势送生图，生成角色外观帧。姿势不合格回到白模，不能靠对静态全身切块平移、鞋/手贴片修出整套走跑。
4. 配准、共用色板、最近邻整数打包，真透明；保留源图、提示词、参考SHA、实际尺寸、动作与脚点元数据。初始目标沿旧包47逻辑单元高、×3打包；画布可为摆臂留边，不能裁鞋尖来凑141。不同画布仍保留同一身体尺度。
5. 步行12/跑步10/待机6帧为本轮旧动作候选，不以帧数判通过；四方向完整两步周期。白模QA沿cover≥0.62、spill≤0.16、腿脚IoU≥0.5，不为了差帧放宽门槛。
6. 先样板同框，再地图走/跑至少两循环、停步、转向、跟随、长路与转角；按实际位移推进帧，停步停脚。静态站姿或无报错不能证明动作合格。

地面接触先修承重脚与锚点，步行不连续腾空，跑步腾空由白模决定。脚点/阴影目标误差≤3屏幕像素。通过后可在泥路落脚时加少量尘点/短足迹，石地默认无尘；按落脚相位且实际移动触发，暂停/碰墙不刷。地面效果不是遮掩滑步的验收办法，铃铛脚步声不恢复。

## 分批交付与验收

| 批次 | 做什么 | 通过才进入下一步 |
| --- | --- | --- |
| 0 设计阶段 | 剧情、拓扑、人物时间表、素材证据 | 设计可审；不称已生成或可玩 |
| 1 样板 | 便衣萧白、叶蘅、帮众同框；A↔C与C↔D灰盒 | 造型阶段、头身颗粒一致，双向通路无空气墙 |
| 2 外区 | B/C/D/E参考预览与分区、门户与分时NPC | 既有序章小事搬迁后可完成；狼战正常两敌，无驱离 |
| 3 第一章 | 六半日、丙级功法、三方事件、火灾、F/G | 全休息/全准备/混合三线均到山居；学武实际可用且不重复发 |
| 4 第二章入口 | 暂住→拜师→首期培养、读取前章事实 | 10体力起期与5/3/2组合正确，取消不扣；叶蘅不自动拜师 |

专项场景检查：P02战败与重试；狼心声不变主角已知证据；没旁听仍获得主线必要消息；老人搬走后原地不留副本；三方只在事件需要时聚集；两个客栈门进入同一室内且回到来门；火前/火中/火后读档不困在障碍中；已学/未学棍法台词及培养菜单分别验证。

设计页保留制作门槛；本轮实施及本地验证见[实施记录](../../../../design/qihe-map/expansion/implementation.md)，**浏览器实机未验收**。实施时记录浏览器能否验收；若工具访问仍受限，清楚写未完成，不能用离线画布或文件数量替代。
