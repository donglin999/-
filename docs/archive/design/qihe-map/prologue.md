## 操作与状态

- 药铺后可自由探索。WASD / 方向键移动，Shift 切换走跑，单击寻路、双击奔跑，靠近按 E 或点击人物 / 门前点交互。
- 周婶发放受托物品，玩家不能自行拿走晾架上的布。交物与旁听分别记录，不需要旁听才算交物完成。
- 还药篮属于送药的一部分，送药后仍提示归还。入睡确认列出已接但未交还的事项；取消可继续办理。
- 没做完的小事在结束时标记 `closed`，不冒充完成，不给金钱、好感、武学奖励。
- `I` / 右上江湖按钮 / 右下行程按钮打开此序章的行程、存档与重开入口。重开有明确确认，不跳到襄阳菜单。
- 序章使用 localStorage `xjh.qihe-prologue.v2`；与旧地图试走会话档、旧襄阳存档分别保存，不套用旧坐标。
- 开场按 `encounter → dog → lodging → done` 存检查点；过夜以 `ending → rested` 恢复。刷新最多重播当前未完成片段，不重复发受托物品。
- 已结束时保存来历、旁听、旧物/字条归属与独立借宿地点；本分支第一章未开放。

苏芷、大黄、门派三选一与三年养成不在本序章出场。山犬不是宠物。萧白尚未习武，木杆仅在本次战斗使用，叶蘅的金针招式不授予萧白，战斗结束或中断恢复入场资源。遗物和字条由叶蘅保管。
