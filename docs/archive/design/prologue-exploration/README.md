## 本轮结论

- 按P-01～P-05与三件可选小事核对9位人物和1只山犬。萧白作为比例／衣装对照；陆衡、岑霜、乌魁、程铎等第一章出场者不混算为序章。
- 当前常驻5位人物、6处实例：陈伯在村中和门厅各有一处。另4位只在对白中说话，没有序章地图演员。
- 10套素材实际尺寸与切片规格匹配，未发现把人物名字直接绑到另一角色素材的证据；主要问题是旧新画风混用、陈伯年龄特征不清和剧情演员缺席。
- 序章现有容器表没有宝箱／补给箱。预览补充6位生活路人、2处模拟探索点，避免说出不存在的领取位置。
- 小地图使用当前 `assets/opening-maps-v4.json`；可走动、听提示、寻找并模拟领取、切换五间室内、收起／展开地图、手动标记目的地。

## 评审顺序

1. 人物核对页：确认哪些现有造型需要重画，以及陈伯、店家、老人应保留的年龄／职业特征。
2. 小地图预览：先找小满，听到区域线索，走近箱子后发现并打开；回来再听一句。
3. 路人对白：确认6人是否自然，线索与剧情的密度是否合适。
4. 确认后再实施正式人物整改、事件演员、路人模块和游戏HUD小地图。此次没有生成新人物图，也没有声称这些整改已在游戏里完成。

## 实际检查

- 运行映射：在本机独立浏览器会话读取 `npcsOf`，6处常驻人物脚点合法且有相邻可站交互位置；这不是所有路线的完整游玩证明。
- 素材：核对RGBA图实际宽高与4×4切片；山犬单独按1格核对。查看了当前四向切片并保留[同屏检查图](../../../review/prologue-exploration/npc-before.png)。
- 预览数据：[机器清单](../../../review/prologue-exploration/data.json)。实际代码依据为 `js/prologue-village.js`、`js/prologue-backhill.js`、`js/opening-character-art.js`、`js/opening-maps.js`、`js/containers.js`。

新预览是表现和交互验证；简化寻路与模拟箱子不替代真实游戏接入。原稿、现有角色与用户存档均保留。
