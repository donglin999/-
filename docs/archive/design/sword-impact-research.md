## 查到的实际方案

### 1. Cyanilux：Sword Slash Shader Breakdown

[作者原文](https://www.cyanilux.com/tutorials/sword-slash-shader-breakdown/)

用预制网格承载斩击遮罩，移动三角形纹理控制刀光形状与可见区，再叠加滚动噪声产生细节。作者说明也可由粒子系统发射单个网格粒子，小粒子作为辅助细节。

对本项目的启发：攻击主体需要可辨识的前缘和刀口；粒子渲染可以使用有形状的粒子，不能把粒子等同于均匀小方点。实现时可用程序生成的像素刃片或带噪声遮罩的粒子贴片，保留颗粒边缘，避免退回原来无纹理的几何光带。

### 2. Alexander Clark：Hail of Swords

[作者完整拆解](https://www.alexanderclarkportfolio.com/post/hail-of-swords-vfx-breakdown)

剑体粒子系统作为主驱动，按生命周期曲线控制速度；碰撞停止剑体并触发爆炸，再由子发射器组织星状碎屑和地面裂纹。出现、发射、碰撞和消失分别安排。作者也指出，过快下落可能削弱力度，因此不是速度越快越好。

对本项目的启发：先定义每一道剑气的头部、方向、行进进度和命中点，再从头部产生短拖尾；命中事件必须由主体到达目标驱动。爆点与次级碎屑独立计时。

### 3. Zoin / Sohan Dilusha：Cyberpunk Slashes

[作者迭代记录](https://zoinn.artstation.com/projects/Overd6)

页面列出先校准斩击位置与时间、再叠加元素的迭代过程；中期加入 impact frames，最终又移除。还分别展示主斩击层与高光层。

对本项目的启发：定格、闪屏并非必选项，应先修正轮廓和命中关系，再比较辅助反馈。不能靠强闪和镜头抖动掩盖攻击本身不成立。

以上依据为作者公开的实现文字与迭代说明，属于作者案例，不冒称全部商业游戏的统一规范。网页动画本次未成功获取，未声称完整观看演示视频。上述具体实现不依赖本项目引擎，需转换为当前像素画布方案。

## 当前代码为什么像水流

检查 `review/combat-av-v1/sword-choreography.js`、`sword-particles.js`、`sword.js` 后的项目诊断：

| 当前实现 | 感知问题 | 修正方向 |
| --- | --- | --- |
| 加速曲线控制发射位置；出生后粒子按各自阻尼漂移 | 没有统一向前切入的剑气头部，像沿路径不断倒出粒子 | 剑气实体维护 head/progress/tangent，拖尾从头部产生 |
| 外层宽、寿命约 400–650 ms，持续发射且边缘弥散 | 外轮廓圆软、拖尾连成流体 | 主刃更有方向，末端尖；攻击尾迹缩短，环境余烬另设寿命 |
| 命中粒子沿完整圆周均匀扩散 | 剑击读成水花或环状冲击 | 按入射方向生成窄爆点、穿透碎屑和侧向崩裂 |
| 施法者固定第 13 帧，目标主要是亮度和受击帧切换 | 看不见挥击完成和身体受力 | 统一出招、接触、后坐/回弹与回收时间；先核对精灵动作帧映射 |
| 壮阔主要来自多路持续叠加 | 相邻攻击黏连、缺乏重拍 | 每次斩击要有可分辨的释放、接触和快速退场 |

## 下一版单招验证脚本

以下是本项目试验参数，不是来源规定或行业标准；先做单道重剑气 A/B，再扩展甲绝。

以接触时刻为 0 ms：

| 相对时间 | 表现 |
| --- | --- |
| −450 至 −150 ms | 慢蓄势，粒子向剑身/手部聚集，主角动作配合；低亮 |
| −150 至 0 ms | 有锐利前缘的宽刃粒子加速切入；主体位置明确，短尾迹持续破碎 |
| 0 至 35 ms | 接触处窄而亮的切口/爆点；命中声、受击动作同步，绝不只播放背景散粒子 |
| 0 至 60 ms | 可选的局部命中停顿 A/B；只冻结该次动作时钟，不冻结 UI，也不复用剧情输入锁 |
| 35 至 160 ms | 沿剑势射出短而快的碎片，少量侧向崩裂；目标轻微后坐并开始回弹 |
| 160 至 400 ms | 主刃迅速侵蚀掉，露出目标；少量碎屑继续运动 |
| 400 至 700 ms | 仅余烬收尾，不再维持粗厚水流形态 |

主体刀口使用程序生成的像素刃片/遮罩粒子；噪声用于侵蚀边缘，不用于把整个轮廓揉圆。保留用户认可的规模和粒子质感，同时缩短攻击主体滞留时间。

## 对甲绝脚本的影响

- 乙的规模仍是等级基准；“像水流”的形态不是被永久锁定的质量标准。
- 甲：保留多道剑气和交叉收束，但每道必须形成一次清晰斩击；双斩分别有接触爆点，消除拖尾连成瀑布的情况。
- 绝：慢剑阵承担蓄势，快剑刃承担攻击；剑雨只保留能清楚辨认的主击节奏。主斩扩大切面及局部爆发，背景粒子退让；回吸只属于前摇，不能代替最后的斩击。
- 壮阔程度来自大轮廓、多方向与分层时序；每次命中是否清楚先于总粒子数。

## 驱动建议与验收

下一版独立模块：`SlashBody`（头部与形状）、`TrailEmitter`（短尾迹）、`ImpactBurst`（命中）、`HitReaction`（动作/可选停顿）、`Dissolve`（破碎消散）。由同一命中事件协调声音和反馈，避免分别估算延迟。

验证：关掉音效仍能认出命中瞬间；关闭碎屑仍能看出剑的行进方向；正常速度能辨认每次重斩；静帧有清楚头尾；命中后主体迅速退出；大招期间目标位置可辨。性能采用实际帧耗时评估，不用总粒子数冒充效果质量。
