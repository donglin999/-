## 八项实质调整

| 项目 | 第一版不足 | V2提案 |
| --- | --- | --- |
| BP | 大体沿旧公式，容易多段又增伤 | 每招唯一主模式：加段、加威力、延长、治疗、交予BP、改序或绝技。清单逐招有四档预览 |
| 拆防与输出 | 所有行动统一最多削4点，三段低阶被削掉发展空间 | 每招明确命中段数、弱点条件及0—3BP削盾预算；最高6只做本批硬边界，普通单击不能碰到它 |
| 绝级 | 至少1BP、每人每战仅一次，容易一直舍不得用 | 需3BP和24MP；输出／一般支援可重新蓄势再用，施放后的下一次自身行动禁止所有绝级。濒危保命仍有独立每人每战限制 |
| 辅助角色 | 多人都是一次卸力／全体卸力 | 徐供BP与协同，秦提前同伴，沈延后敌人，闻安排下一回合，阮留破势缺口，乔单人救援，柳全队物理保护 |
| 人物独特性 | 学会别人的技能后容易变成同一个人 | 可传授技能＋本人专长，18名人类参战者各有一个拟议身份被动；不新增独立能量条 |
| 内功（结构v2） | 旧辅修选择额外特性规则已废止 | 每门一主动一被动；三/五层强化同一被动；主辅只是运转槽 |
| 装备 | 大量只有减费，快慢差异不明确 | 同阶段轻衣先手、软甲承伤、医袍维持、承岳扣断后；比较行动排序与技能收益，不只比较品质 |
| 图标 | 构图有区别但未覆盖实际新作用 | BP供给画力点交接，抢先画前引线，断后画后承点，破势协同画被撑开的缺口；同步改完整提示词 |

上述3BP、24MP、削盾上限、心法槽和调息间隔都是本作测试方案，不能转述为八方原作规则。

## 支援差异的具体落点

- **同担一线／徐令仪**：将本次行动换成另一人的2／2／3／3BP，0BP也能支援，施者仍付MP与行动。
- **回袖引步／秦绯鸢**：把尚未行动同伴安排在自己之后；适合把破势者放到蓄势主攻手之前。
- **断渡擒锋／沈雁回**：只延后可延后的敌方未执行意图，给队友多一点准备机会；不取消一整轮。
- **三径相援／闻疏桐**：本轮有限防护，下一轮指定一人前移一位；更适合提前规划。
- **留缝接应／阮青雀**：自己低威力短刺，为随后队友留下额外1点削盾机会；不偷战利品。
- **回舟接客／乔行舟**：救回一名受迟滞或濒危同伴，承担其一次单体伤害；不再与柳含烟竞争全队减伤。
- **雨住留灯／柳含烟**：明确全队本轮一次物理卸力；没有“顺带什么都解”的万能支援。

## 制作仍需你的评审

先审这些取舍，再做襄阳低阶循环。秦、阮等游历同伴只能在独立评审沙盘演示高阶组合，不能提前进入襄阳正式队伍。新增玩法不会顺带开启新人物线、调换剧情时间或生成123张图。
