## 图标与动态的关系

- 用户已确认五档图标的画风和丰富度。动态图效继承同一技法身份、主形、门派配色，再以粒子程序组织速度、前后层与打击节拍。
- 原稿是武学界面的手绘图标，不直接拿来缩放旋转当战斗特效。后续优先用已有粒子驱动；独有轮廓确实需要新素材时再制作局部纹理／短序列。
- 山势、江纹、燕尾、叶脉是武侠意象，不自动引入召唤单位、地形碰撞、额外伤害或控制。
- 这次只生成静态图标和特效描述，不产生新的运行配方或特效动画。

这些是第一轮样片编排上限和参考时点，沿用品阶方案的普通模板预算，尚未测性能。高级效果通过宽而有结构的主形、汇聚与断裂、强弱主次体现；不能靠匀速长水流或每层更换颜色。确需更长的独有绝学另行提交脚本及资源预算，不暗中提高全部技能上限。

- 640×360特效空间，最近邻放大；速度单位像素／秒。建议主轨迹使用分段归一化路径：前65%路程慢收，末35%迅速提速；具体曲线依各分镜，绝非统一水流。
- 近战拳劲行程短、头重尾短；剑刀以直锋／斩面；针法以细长路径和精准落点；护卫强调承接与压缩；治疗强调接续。
- 单体高潮限制在目标附近，宽主形可延伸但必须保留人物、血条和敌我目标识别。群体共享主形，只按实际目标分配命中反馈，总预算不乘目标数。
- 程序预算按整行动统计：起手＋所有段＋所有目标＋尾迹。BP加段技读取实际段数并重新分配命中窗口；其他技能不因图上多几道锋芒多结算伤害。
- 闪避走擦过反馈，免疫不画成功控制，治疗满血与驱散失败不伪造数值；取消、倒地、战斗退出都停发并清理。

## 主动、被动与延迟触发

- 心法不是可主动施放的大招。通常只在对应状态获得／消费、真实减耗／增效结算时播放360ms以内的局部短反馈，累计12／活跃8粒子；不震屏、不全屏闪光、不常驻环绕。相同心法同次结果去重，战后反馈放在结算UI旁。
- 《抱山还岳》的援护授予、后续承伤、反击属于不同真实事件；授予不先播反击。后续反击沿用同技法身份，独立短反馈建议≤360ms／12粒子，不能触发反击链或额外BP。
- 《一息相续》授予保护与真正保命分开。授予只确认状态，后续致命保护发生时再接续一次；同一受益者次数限制从战斗结果读取。
- 《明约合锋》《留缝接应》后续宽锋只是后续队友攻击的辅助反馈，预算计入该次行动，不能提前播放第二名队友的伤害。
- 持续治疗、持续增益、援护状态不反复播放整套施法。后续触发短反馈≤360ms，共享全局预算；状态持续由UI负责。

## 声画绑定

各条目指定声音类别与生效时点，不代表已有可用音频文件。后续选用许可证明确的刀剑、拳击、衣料和短气流素材。命中声要与同段结果对齐，低阶干净短促，高阶增加前摇张力与主击低频；群体同帧合并主声，禁止每个粒子都播声。治疗和被动不用战斗爆炸声，不用频繁铃铛提示。

## 后续制作顺序与验证

1. 按条目分镜先做剑／拳／针／治疗／护卫／心法各一例，再扩展甲绝；图标已批准不等于动态样片已批准。
2. 渲染器负责表现，战斗系统负责真实结果。文档中的 `present_hit` 等为拟议适配事件名，尚未新增到现有引擎；禁止把该事件写成直接扣血的函数。
3. 以固定种子验证0BP／3BP、单体／群体、低／高重数、闪避、取消、免疫、护卫与延迟触发，逐段核对真实结果与表现次数。
4. 正常、简化、减少闪光／镜头运动三模式；简化保留主形和节拍，降低装饰50%，不减少真实命中反馈。
5. 真战斗录像和固定设备性能采样后再批准接入。此轮不宣称性能、打击感或图效实现已验收。
