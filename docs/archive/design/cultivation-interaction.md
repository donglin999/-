## 本期开始

按绝对年月与当前路线读取本期安排。先判断是否为独占剧情或整月地图：若是，展示已公告行程并进入对应内容；若不是，提供10点培养体力，更新在场人物、可用活动、近况和邀请。简短必要来信不占完整时段，也不因玩家没选通信而丢失。

第一期先通过周砚与萧白的开场说明提供培养教学，再进入可操作画面；教学说明本身不收费，首次正式基础练习按5点计算。新游戏不自动拥有招式、全部艺能或原型临时技能。

## 一次活动从选择到完成

| 步骤 | 玩家看到什么 | 规则 |
| --- | --- | --- |
| 1 选择类别 | 七类活动与固定成本 | 仅切页面，不扣体力，不推进时间 |
| 2 选择项目 | 具体课题、条件、材料、当前进度 | 未学、缺材料、人物不在或体力不足可读原因 |
| 3 查看详情 | 成本、可知收益、剩余体力变化、开始按钮 | 取消或返回无结算；普通活动不另弹一次重复确认 |
| 4 正式开始 | 按明确的开始／前往／托送按钮 | 再检查条件，锁定本次内容，扣除一次已展示的成本 |
| 5 经历活动 | 先播放约2秒Q版序列，再进入必要教学选择/人物事件 | 不在同一活动内另扣第二次菜单费用；关键分支由玩家选择 |
| 6 结果提交 | 实际成长、物品、关系、线索和后续机会 | 正式成果提交一次，演出快慢和素材加载不决定成败 |
| 7 返回本期 | 更新余力、原类别和列表位置 | 活动结束仍是同一时段；可再选活动，或主动休息 |

活动中禁止连续点击再启动另一份活动。菜单、演出、战斗与结算共用本次活动的占用记录。若开始前的条件已失效，说明原因并返回，不先扣体力再报错。

## 教学、练习和考校

首次正式教学指出用途、来源和能力边界，完成教学才登记对应学习经历。后续独练使用已学内容，导师指导使用新课题，不反复演同一句开场。未完成首次教学不得通过演出略读或直接打开行卷自动授予技能。

一般练功以稳定训练和短反馈为主；阶段课程才需要选择、解释和检验。学艺判断提供事实与提示，错答不让主线永久失败；学习记录按实际内容结算。特殊传承与考校要求在活动开始前可知，同一节课程的指导、判断与结果不拆成多笔费用。

招式、心法、生活技能有各自进度与资格。经验已够但需师友指导时，页面说明下一步；正式新阶段必须有教学或事件来源，不能由一个泛用「升级」按钮生成所有武学。

## 闲逛事件如何选入

先选可达地点，再选择普通闲逛或已知邀约。未按「前往6点」前不抽取并泄露普通隐藏事件；开始后锁定事件，继续／恢复仍是同一事件。普通闲逛的随机优先级与权重留作内容配置，不宣称照搬原作算法。

| 情况 | 本轮选入原则 |
| --- | --- |
| 有明确且仍有效的邀请 | 玩家可指定本次赴约；符合资格就进入对应内容，不被普通偶遇挤掉 |
| 有多个已知同地邀请 | 选择本次赴谁的约，其他保持自己的时间窗口；一份6点不自动完成全部邀请 |
| 无指定邀请，有合条件人物节点 | 依地点、窗口、前置、能力、关系、路线权限与在场状态筛选；新节点和即将过期的机会优先方案待清单校准 |
| 没有新人物节点 | 进入地点日常，如短途观察、普通生活协助或已学课题的应用，给可解释的常规反馈 |
| 主线必要消息 | 按日历／剧情明确出现，不放进必须反复抽中的闲逛池 |

一场正式闲逛默认承载一个主要节点，可以连带短生活反馈。完整医案、长谈或切磋都由同一6点支付；不能再收3点诊治或5点战斗费用。事件结尾开放下一次课程或正式委托时，先登记机会，玩家以后另选。

事件与关系显示读取实际经历：曾帮忙、只听说、已核实、曾承诺和已履行各不相同。同地点再次遇到同一人物时提供后续或结果回响，普通闲谈不重复记成新事件。公共事件的不同路线入口共享完成记录，不重复领奖。

## 战斗与失败

训练课、闲逛切磋、短篇护送和整月地图战斗分别保留原入口的成本；不因切入战斗界面自动再扣5点。是否恢复战后气血／内力、是否消耗背包药品和是否发战利品，必须按该场战斗的类型事先说明。

导师的友好过招使用对应训练／闲逛的一次费用，训练收益按实际表现，失败给可理解的点评与后续练法。剧情冲突按已有结果继续，不把一次败北当作培养存档结束。正式医案与调查必须有基础介绍、同伴帮助或其他做法，不以萧白高技能为唯一通路。

玩家在游戏规则内做出的错误选择、切磋失败和主动放弃已开始的事件按该事件结果处理，不能看到不好结果后免费重抽。临时资源不足时可选择合理替代；重要遗物不作为普通材料自动补缺。

## 休息与月度推进

休息展开预览，显示「剩余3点」「进入二月中旬」及余力对心情的说明。提交后结束本期，余力不结转；进入下期若是普通自由时段才恢复10点。体力0也保留查看与休息操作，结算卡关闭不自动替玩家结束时间。

月底休息先产生本月简短总结，再进入下一月。总结包括投入方向、主要变化和下月已知事情；不能额外赠送独立夜谈或一整场人物事件。需要独占时段的主线按已公告安排出现，不能先发10点、再要求没收玩家已用出的同一期成果。

限时事件在已知条件下提前提醒，明确暂缓、截止及后果。忽略提醒仍按剧情世界继续；错过可选事不删除已知真相，必要主线使用替代通路。

## 整月大地图

出发前显示月份、同行人、返程据点、该月暂停培养和受影响的邀请。月初进入后，五个时段统一属于此次历练，地图内主线与战斗不再按据点菜单扣体力。查看人物、任务与背包继续可用，培养活动页显示正在历练，不能又领取一套50点。

地图结算说明本月实际成果，进入下月月初指定据点；未完成任务按继续、后续改写或明确关闭分别处理。提早结束仍消耗这一整月。具体行程预算与可重复行为上限由[大地图方案](../../design/world-map-journeys.md)细化，本页不暗中增加现实倒计时。

如果以后设计正式分叉，当前地图仍只占一次完整月，返程据点按新的正式安排变化。初始去向、原本领、证据和关系保留，旧承诺有明确后果；新路线读取剩余日历，不重开三年或补满当前体力。叶蘅是否同行和改变所在地由她自己的安排承接。

## 保存、恢复与取消

设计上需保存：绝对年月时段与本期余力，当前路线／据点与人物所在地，已学来源与成长，实际资源，已发生事实与公共事件结果，未完成邀请，以及当前尚未结束的一次活动。具体字段与兼容迁移在实现时另定。

| 中断位置 | 恢复方式 |
| --- | --- |
| 只是查看菜单 | 保留选择位置即可，未执行不收费 |
| 已开始，尚未结算 | 返回同一课题／事件和已扣成本，按已保存的起始时间继续剩余2秒演出；不重新抽事件或再扣一次 |
| 已提交结果，结算画面未读完 | 显示已产生的结果，关闭后继续本期，不再发奖励 |
| 缺图、缺声或演出异常 | 以现有画面和文字完成同一内容，不由素材成功与否控制任务旗标 |
| 内容本身无法继续，尚无任何正式成果 | 显示明确失败原因，回退这一活动的体力与材料后返回；不得同时保留已发成果再退款 |
| 在玩法内失败或主动结束已开始内容 | 依据这份活动已定义的结果结算，不能当技术异常免费重试 |

现有 `#xiangyang` 等评审入口与未来正式培养存档分开；设计图不表示当前入口已支持续玩。正式测试需覆盖重复点击、读档、对话跳过、战斗返回和转场，重点验证一次扣费和一次成果。

## 四种完整操作样例

**首次基础教学**：月初10点 → 基本功／站位与发力 → 看学习来源 → 开始5点 → 周砚教站位、玩家选择如何试练 → 记录第一次指导与练习进展 → 返回本期5点。玩家可再练一次已开放基础，也可转做其他活动；没有自动发剑或家传心法。

**混合培养**：本期10点 → 已学步法5点，余5 → 在场叶蘅的医案记录学艺3点，余2 → 整理书案打杂2点，余0 → 查看成果 → 主动结束本期。三项各结算一次，不在学艺对白结束再追加6点长谈。

**一次人物闲逛**：本期10点 → 山居／赴陆衡已知会客邀请 → 前往6点，余4 → 对话选择与行路准备建议 → 记录经历，开放后续护送指导 → 返回本期4点。下一节行路学艺若另选3点才开始，邀请本身不同时免费完成整月护送。

**整月历练返回**：四月底休息 → 五月月初显示襄阳历练行程 → 进入地图，培养余力不发放 → 任务、走访和战斗各记实际结果 → 结束整月 → 六月月初回到当前指定据点，普通培养开始10点，侧栏显示地图成果带来的下一步。

更多首季机会与差异见[山居课程稿](../../design/mountain-cultivation-curriculum.md)。
