## 这次真正要讲的故事

柳含烟以为离楼后去清徽阁，就能重新拾起幼年中断的学艺。她循着老师留下的一支旧曲，却找到了一个被江湖除名、仍在教孩子唱曲的师姐。她第一次发现：学会一门手艺，也会继承前人没有做完的事；但替前人说话，可能毁掉自己刚挣来的安稳生活。

秦绯鸢以为从此不让同伴离开自己的眼皮，就不会再失去人。六年前，她曾擅自替外出演出的同伴签过一张名册。那张纸后来成了旧渡劫案的证据，领奏许照月被指作引路的内应。如今她才发现，自己这些年替柳挡帖、抢话，仍在重复“我替你答应”的动作。她要找回旧人，更要承认一件她一直没有告诉别人的事。

两人共用一段江湖旧事，但问题不同：**柳要不要为了一个活着的、并不愿被她拯救的故人得罪师门与资助者；秦能不能在失去名声和班中信任的情况下，仍把自己的名字签回证词。**离楼、谋生与组班保留，成为她们冒险时真正会失去的东西。

### 新增配角只设两人

**许照月**：初访年28岁，下山中段31岁；昔日领奏兼排场，柳的同门师姐、秦的旧同事，非招募。她会愤怒、讨生活，不是为给秦上课而等了六年的人。愿承认当年托付仓促，也会问秦为什么一直不说代签。她不要求秦永远赎罪，更不在重逢第一场拥抱原谅。

**汪成**：非招募，年龄不另锁。旧货栈经手、如今做护送代办。他靠熟悉两岸行路手续和各家顾忌赚钱。旧案真怕的不是掉几两银子，而是暴露自己的保人、丢掉以后发帖接生意的资格。他先撤席、施压，不一见主角便派刺客；到玩家接触仍可辨认他的船夫时才雇人劫走证人。既有体制中的采购人与保人按后期主线审定，不擅自指定谢承岳为幕后。

## 行动、势力与分支后果

- **保密核验／提早公示**（J03）：保密线先由沈验旧记录，证人不立即暴露，进度多一道正式约见；公示线仅贴无姓名的时间矛盾，招来旁证也让汪知道案子被翻，造成撤席。玩家确认后果再选，不能越权贴出许住址。
- **护住证人／追拿经手**（J07）：先护送保住船夫与原证词，汪暂逃，后续凭合法通缉和账目补查；追经手须已有另一队护送证人的承诺，不能“追人=默认送证人去死”。没有战力可先委托巡江司可用人员或岑的合法护卫，分别承担等候与货路人情，不强制刷武功、入派或支付未知大额。
- **证词具名／封存身份**（J08）：本人决定，主角只能建议。具名公开能更快纠正旧名声，也让许失去安静生活；封存真名仍须官署核身，公开案情删现住址，旧传言消散较慢，可后续补公示。沈只有协助核验和送呈权限，正式更正由有权受理者作出并实际送达。
- **揭旧渠道／先保当前运路**（J09）：徐需要查到冒盟名的保人；岑担心骤停整条货路牵连无辜脚夫。可以同步备案、限涉案商号，或先安排替代运路再公布；前者会短缺一批班用物资，后者需要跑实际交接且承担对方串供风险。不能永久藏证换无代价大团圆。
- **师门公示／个人署名**（J10）：柳可请求清徽阁公开师生关系，资助者退席、阁中接普通琴修补生计；也可由她自己署名证实所见，老师教过许的事实由登记佐证。二者均不把整个门派变成许全部行踪的担保人。
- **公开巡演／小班慢走**（J11）：秦允许班员选路。大场巡演需公开代签往事且拒绝代签条款，名声修复慢但机会大；小班沿熟悉渡镇收入较少、可保原有课堂与生活。不设置唯一正确答案，结果体现在邀约、人物来信与尾声，数值待经济表接入时另定。

这些是**设计结果**，不是已运行的机制。先保留可见事实与不同后续，不用“察言+3”代替叙事结算。

## 不绑死两人，也不堵主线

1. 原柳L07与秦QF06C招募链不增加任何J节点，玩家可以只交朋友、只招一个，或两人都不招。
2. J02从L02或QF03任一进入；旧案调查可由柳提出、秦提出、或收到她们授权的送呈委托。共同线不要求两人同时入队；默认两人同场版本必须有分别完成的邀请与旅程。
3. J06提供柳单独、秦单独、两人皆缺席的版本。别处人物仅以已送达的信／授权副本出现，页面不得沿用默认同场台词。尚无授权时任务停在“待回信”，不假定同意。
4. J08秦可本人到案，或先完成异地核身签录再送达证词；她不回应则仍可凭其他证据处理汪的劫货责任，代签争点与她自己的公开修复保留未完，不伪造悔悟。许不愿作证可延期，保底只结已有证据部分。
5. 不认识柳、秦也能完成汉皋药案、得到问题清单、推进叶家遗产。三条必达地区路线的最小事实仍由原主线提供。Qiyue支线增加证人保护经验、具体经手链、出庭与后期支持，绝不挪走主线唯一钥匙。
6. 15—17章节只定义人物篇适用窗口，不假称已锁未来城市地图／战争安排；18—20收束仅在主线允许回访时发生，不自动把全体伙伴搬到最终战。

## 场次长度、演出与空间

关键场通常8—12句主对白，一次只揭一层；不要把本文件作者真相念成台词。旧案采用现在的实物、相互纠正与会面，不插十分钟全知回忆。轻松D01—03保留，不能所有生活都暗示阴谋。

- 外堂：秦见保帖停拍、公开纠正、撤席后真正空出一桌；不是每次都来一个越界酒客。
- 试谱间：老师的童年谱、后来师门回信、柳决定带哪些东西；从私人物品逐渐牵出外界。
- 后廊／排练房：遗下衣料、实物留底、班中重新投票排路，群众不是装饰。
- 楼梯保留外形、梯脚触发如门切换；无需爬楼能力。二楼用于获邀的小范围交谈，不再用室内屋檐凑层次。
- 楼外旧渡、官署接待、清徽阁借既有场景职能；新增地图、战斗动作及立绘另列需求，**本轮不生图**。旧渡不需要动态水面，可在岸上对话／冲突，船行用淡出与到岸切换。

## 排期与制作边界

汉皋首月只加可选J01；J02/J03放年二合法历练，J04放年三合法到访，未到场转预约不是瞬移。J05—08下山12—14及后续补写，J09—11在15—17且前置落实后可选，J12在后期允许回访时发生。每场可延期，启动护送后先解决眼前危机再恢复自由探索。

新J节点未登记`calendar/mountain-events.json`，也没跑两线联合资源求解；成本页会显示“待登记”，不得据本稿上线。旧招募账例48/56/32仍是第一稿待审值，不因暗线重写偷偷涨价。

采用后依次完成：确认新旧人／旧案 → 正式日历和人物位置 → 分支证据状态与送达事务 → 场景入口和演出资产 → 实机完整路径。旧存档不凭空补见旧案；收到可选回访提示，已经入队的人仍保留原事实。
