1. 先读两章原稿，直到 `C1-12` 山居第一夜。

3. 月二：M-03旧识回信 → 阶段纠正 → L1承诺 → 莫松年来访。Z1、V1、Y2可选，未选不补为已经历。
4. 月三：M-04护送预告 → 可选L2 → M-05整期护送 → M-06回来交接 → Z2复盘；孟知微来访和Y3自主计划可选。
5. 月四：M-07邀请 → X1各自目标；照川来客和Z3可选 → 继续巩固课业 → M-08出发交接。
6. 月五月初：M-09城外转场，到城门以前结束。苏芷、唐照雪及其他襄阳初识另接城市章节。

日期、人物在场与费用以[机器日历](../../design/calendar/mountain-events.json)为准；本稿沿已确认的[12点自由期与现行费用](../../design/cultivation-energy-rebalance.md)和[培养优先方案](pre-xiangyang-training.md)；W05／W06／W07随剧情触发、0点，主动长谈通常4点。22项现有襄阳前日历事件均有对应全文；30项已开放活动都有对白入口或短反馈，听声辨位B05继续锁定。

## 制作合同

- 每句有稳定ID、正文、说话者、配音决定、情绪与来源。新稿的选择／状态条件放在block，不拼进可朗读正文；读者可在网页筛人物、阶段或拟配音句。
- 分支只命中一支，再到共用收束；选择不额外收费。处理分支与伤势、技能、关系表达属于不同条件组，不当成所有分支同时发生。
- `opening.chen_injury`、`facts.*`、`learned.*`等是叙事条件合同；接入时必须映射真实存档。未知旧值保守处理或暂停该段核实，不能默认已经受教、已完成回访或已走过险路。
- 免费必要消息确保全休息、不选长谈也能赴襄阳。跳过Y1、Z2或三场来访不补发其关系与见面事实，不阻断基础课、护送或邀请。
- 采用现有静态Q版、透明完整对白状态、场景切换与文字；动作说明不派生每句NPC动画，也不先增大量CG。人物表情与身体动作必须一起选，不能统一用推掌表现拒绝。
- 新精写尚未接入运行时、尚未生成音频；已有简版事件的可玩记录与新稿全文的交付分别看。本轮检查只证明文本、ID、日历费用与活动覆盖，不代表实机或听感验收。

## AI与后续维护

新增培养全文唯一来源是 `scripts/pre-xiangyang.json`；原开篇七页与三场来访保留各自来源，不复制改稿。开篇改正文或说话人时，同时更新 `scripts/opening-voice-revision.json` 的明确旧值、新值与拟配音决定；生成器要求修订与源稿逐条匹配，拒绝未登记改写，也不按相同句ID复用旧声音。执行 `python3 tools_story/build_pre_xiangyang_scripts.py` 生成短文档、配音决策表与审阅页；加 `--check` 只检查输出差异，不写文件、不合成、不触碰绑定。

[核对记录](../../../review/pre-xiangyang-scripts-20261005/audit.json)记录来源摘要、22项日历覆盖、30项活动覆盖、主角无配音及待定人物无派单。全文采用后，先接实际分支与正文，再向正式语音目录增量同步；不要直接把审阅页的全分支文本连播。
