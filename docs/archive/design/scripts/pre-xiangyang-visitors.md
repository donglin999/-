## 共用演出与状态合同

- 首页仅显示来客预告；点击“参与”后才打开 Q 版对白，不让陌生人一直占首页。免费看预告不设置“已认识”。
- 演出以双／三人静态对白为主，每屏一个说话者；人物名、气泡、选项、路图说明全部由程序显示。无新增战斗、长动画或强制走地图。
- 公共阶段 `intro → choice → branch → closing → committed`；开始锁唯一事务ID和成本、快照有效条件，分支及结果只提交一次。刷新保持当前阶段，缺图不影响继续。
- `visitor_*_seen` 在最终提交才写入；相应 `met_*` 同步记录第一次见面的 slot 和事件ID，不设置全门派好感。被跳过、看预告或读信不记见面。
- 剧本中的“拿图”“压页”“递帖”是对白中描述的动作，首版只用各自一张静态基准图；不按每句台词派生动作帧。
- 选项不设好坏答案：各分支固定同样＋2记录进度，仅事实不同；这不是战斗属性、招式熟练或新功法。没有道具奖励、原料扣除或自动收信。

## 谷中生活待定稿节点（不纳入三场来访排期）

这些是师门人员定稿后的剧情方向，不把待定身份当作已出场角色，不先填姓名或偷偷交给现有周砚代演。

### D01：两种教法，同一个落脚点

师叔正在检查练场边缘，指出周砚刚才说的“留退路”还有一个问题：主角看了地面，却没看同伴的位置。周砚承认自己的提示不够具体，请师叔用另一种解释讲清。萧白可以先复述理解，或指出仍没听懂的地方；两位前辈围绕同一个已授课题作温和争论，最终给出一次可实际尝试的任务。

- 用途：师叔有独立教学风格，师父也会调整讲法；两人不是争谁更厉害，不给主角突然开放第二条高级传承。
- 教学安排：优先嵌入一次已付费基础课，增加4～6句，不额外收3/6点。不改变已定老师权限，具体指导资格待师叔角色卡确认。
- 素材：师叔独立身份/Q基础图待定；人物动作必须与周砚不同。练场已有背景仅复用候选。未有身份卡、排期与图时不得插入代码。

### D02：练场边留下的位置

先入门同门正整理借过的练习器具，同时准备自己的一次外出。萧白以为“师兄/师姐总会带自己”，同门解释自己也有课题和差事；二人把公用器具摆回原位，约定下次如何请求陪练。称呼随性别与师承定稿，当前不使用某个已命名外派角色代替。

- 用途：同门有自己的生活，不只是教程按钮；主角学会合理求助，和陆衡的托运责任不是重复事件。
- 教学安排：可作为打杂结算里的短回应；不自动完成长人物篇、不提升亲密关系、不扣额外费。具体插入期与本人外出日程定稿后录入日历。
- 素材：同门独立身份/Q基础图待定，首版一张中性静态图即可；器具整理只用旁白，不新增劳动六帧。此项为后续角色定稿需求，不算当前三场来客资源已齐备。

实现字段约定：`met_<actor>` 存 `{source,period}`；`<事件>_seen` 存 `{period,choice}`；`<事件>_choice` 存稳定分支键。`period` 是槽位编号。观察记录对应培养项 `observation`，游戏显示名为“察势”，奖励固定＋2进度。
