# 人物动作做法

状态：现行　最后核对：2026-11-01

规则见 R-动作-01（[规则登记表](rules/规则登记表.md)）。本页写具体怎么做。先按[角色类型与必需素材](design/role-assets.md)和[剧情表现规范](design/story-presentation.md)确认这个人物要不要动作：普通 NPC 剧情不派专属动画，用对白或单张 CG。

程序白模加参考生图的旧管线已废止，记录在[归档](archive/anim-pipeline-rig.md)，只作追溯。

## 1. 按动作选做法

依据是 2026-10-23 同一角色、同一动作的对比（[记录](../../xiaojianghu-legacy-prologue/docs/updates/2026-10-23-motion-method-compare.md)）。

| 动作 | 做法 | 原因 |
| --- | --- | --- |
| 走、跑、待机呼吸、闲置小动作 | 图生视频加后期（第 2 节） | 首帧锁住造型和配色，色差约为生图的一半 |
| 普攻、快招 | 一张图画出整组姿势，再走同一套后期（第 3 节） | 视频试了两段都不能直接用：蓄力时转向镜头，命中瞬间只有拖影 |
| 复杂技能 | 不做 | 用户定的弃用；功法在原位简短施放，由目标处特效命中（[战斗表现边界](design/combat-presentation-boundary.md)） |

逐帧单张生图不用：没有共同尺度，细节逐帧漂。

## 2. 图生视频加后期

已用这条路线的批次，做新人物时复制其中的脚本：

- `xiaojianghu-legacy-prologue/art_sources/hero-motion-video-20261021/`（主角走跑）
- `xiaojianghu-legacy-prologue/art_sources/censhuang-motion-video-20261021/`（左右不对称的人物）
- `xiaojianghu-legacy-prologue/art_sources/ye-motion-video-20261028/`（待机、闲置小动作、跑步修正）

### 生成

- 模型：302 的 `wan3.0-video-prime`，720P，5 秒，`prompt_extend` 关闭。
- 首帧：同向站姿放大 6 倍，贴纯绿底。
- 提示词写清：朝向、原地循环、动作特点、背景保持纯绿、没有地面阴影和文字、固定镜头、人物不发生位移、严格保持首帧的画风和服装。
- 方向：下、上、右各一段，左向用右向镜像。只有左右站姿确实对称才能镜像，否则四向都生成。
- 每次调用都要记入生成账本。复制脚本时带上账本那几行。

### 后期

本地脚本，不需要 AE：

| 脚本 | 用途 |
| --- | --- |
| `tools/post.py` | 走：抠绿去溢色，缩回 1 倍，锁同向站姿调色板，上半身中线和脚底对齐，自动找一个完整循环，等距取帧 |
| `tools/post_run.py` | 跑：同上，只留最大连通块，周期上限压到 0.8 秒 |
| `tools/post_idle.py` | 待机和小动作：整段统一对齐，按和首帧的差异找出小动作段，取待机帧和小动作帧 |

### 现行规格

单元 96×116，原点 [48,108]，行序 dlru；走 12 帧，跑 10 帧，待机 4 帧，闲置小动作 18 帧。步距：走 .175、跑 .23。

### 常见问题

| 现象 | 处理 |
| --- | --- |
| 零星杂点把对齐带偏，帧上下乱跳 | 只留最大连通块 |
| 一段里取到几个步子的帧，节奏乱 | 压低循环周期上限，必要时限定范围重取 |
| 侧向待机时人物转过身来 | 提示词强调全程侧身，再生成一次 |
| 小动作段自动判断偏了 | 用 `--seg` 手动指定起止帧 |
| 动作不够理想 | 视频模型不能精确控制姿势，多抽几次再挑 |

## 3. 普攻和快招

- 一张图画出全部姿势，这样姿势之间有共同尺度。规格、锚点、调色板按[战斗精灵规格](battle-sprite-spec.md)。
- 画风参照要选**同一阶段**的正式动作表。2026-10-23 的画风偏离，主因是参照选错了阶段。
- 技能的身体动作不走这里（见第 1 节）。

## 4. 入库和接入

1. 批次目录记首帧、提示词、原始视频、任务返回、后期脚本、`manifest.json`。
2. 人工看过预览后，用批次的 `adopt.py` 三处登记：`production-assets.json`、`production-assets.md`、`js/production-assets.js`。旧文件不覆盖，新版另起文件名（R-素材-01）。
3. 接进运行：`ART.walk`、`ART.run`、`ART.idle`，闲置小动作用 `ART.fidget`（站满 `after` 毫秒播一遍，之后每隔 `gap` 再播，走动就重新计时）。

## 5. 验收

- 在 8792 实机看：四向走、跑、起停、转向，图片全部加载，控制台无错误；有小动作的要站够时间看完一遍。

## 6. 现在的情况

- 视频版已用在主角走跑（10-21）、待机和小动作（10-28），女主站、走、跑、待机和小动作（10-28），岑霜走跑（10-21）。其他人物用像素统一表（`xiaojianghu-legacy-prologue/art_sources/character-pixel-fix-20261007/`）。
- 还没用这条路线做过四足动物。需要时先出小样对比，再定做法。
