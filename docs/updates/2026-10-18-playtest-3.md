# 2026-10-18 第三轮试玩反馈（3.pdf）

## 1. 没有大立绘的人说话时，小头像压住文字、名牌对不齐（`js/dialogue-stage.css`）

- 原因：上一轮把立绘对话框改成透明渐变时，统一缩小了左内边距。周婶、采办随从等没有大立绘的人会显示小头像，原规则给头像留的左边空位被覆盖，头像压在台词上，名牌又按原位置偏右。
- 做法：有小头像时恢复左侧让位（7.2em），名牌与台词左缘对齐，头像缩到 4.6em，放进变矮的对话框。
- 验证：本地让周婶在主角和沈雁回同框时说话并给两个选项，头像、名牌、台词、选项各就各位。

## 2. 经常黑屏（`js/core.js`、`scripts/build-pages.cjs`）

截图里地图全黑，只剩人物和货架。这是地图背景还没下载到：

- **地图太大**：源图都是无损 webp，村中心一张 9.9MB，线上实测下载 22 秒。
- **后台下载顺序不对**：后台排队时先下 22 张这个试玩用不到的襄阳地图，栖河的地图排在最后。
- **失败不重试**：地图下载失败时，失败结果被缓存，之后进这个场景一直是黑的。

改动：

- 发布包里，把超过 1MB 的地图转为有损 webp（质量 92，透明层保真），源素材不动。30 张从 104MB 降到 32MB；局部放大 3 倍对比，肉眼几乎看不出差别。
- 栖河入口的后台只预下栖河地图，按剧情顺序排：后山、药棚、陈伯家、村中心、叶家、南村、东埠、西田埂、北边、客栈、接应点、山上。襄阳等地图不再预下。
- 下载失败最多重试 3 次（间隔 1、2、4 秒），全部失败后清掉记录，下次进场再试。
- 兜底：当前场景的地图还没到时，每 0.7 秒检查一次，立刻插队下载，并提示“载入地图中”，不让画面一直黑着。

验证：

- 本地新开一局，后台下载顺序是后山、药棚、陈伯家……，没有襄阳地图，控制台无报错。
- `verify_prologue` 7 项、`verify_chapter`、`verify_expansion` 75、`verify_startup` 10 都通过。
