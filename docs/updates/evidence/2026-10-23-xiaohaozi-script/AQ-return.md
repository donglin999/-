# AQ-return 伏笔点 1 拿了能还（fq_aqi_hint_return，可选）（演员法备选）

戏眼：小耗子想显摆手艺；萧白没察觉。散场时萧白知道他觉得什么都能“拿了再还”。

1. **小耗子**（把萧白的几文钱递回去，得意地说拿了还能还回去，这才叫手艺。）
   - 嘿，你腰上那几文——我拿了又还了，你竟没觉着！
   - 接着——拿得走还放得回，这才叫本事。
   - 嘿，拿去！摸走了还能送回来，这才叫手艺！
2. **萧白**（愣一下，接过来，问他什么时候拿的。）
   - ……什么时候的事？还我了？
   - ……什么时候的事？
   - ……啊？什么时候的事，我怎么一点没摸着？
