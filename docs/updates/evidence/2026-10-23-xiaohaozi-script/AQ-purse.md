# AQ-purse 东埠摸钱袋（fq_aqi_purse）（演员法备选）

戏眼：萧白想摸到随从的钱袋；随从嫌他挡路。散场时钱袋到手，随从没发觉，还在数篓子。

1. **采办随从**（边数篓子边嫌萧白挡道，搬出“公事”赶他让开。）
   - 十七、十八……让开，公事呢！
   - 二十三、二十四……你这少年，让让道，公事呢！
   - 十三、十四——让开，挡着公事了！
