# AQ-wage 工钱（fq_aqi_wage）（演员法备选）

戏眼：小耗子想拿那二两当“工钱”、也想交下这个朋友；萧白觉得这钱拿得不对劲。散场时二两在小耗子怀里，萧白学会了“窃”，知道了他叫阿七。

1. **小耗子**（迎上来问挂上了没有。）
   - 
   - 哎，回来啦？药摊那边挂上没有？
   - 回来了？挂上了没？
2. **萧白**（说挂上了，没敲门，老人在屋里问了一声，他没应。）
   - 药挂门上了，没敲。里头有人问了一声，我没应。
   - 药挂门上了，没敲。里头有人应了一声，我不敢答。
   - 挂上了，没敲门，里头有人应了一声，我没答话。
3. **小耗子**（满意，伸手要找回的那二两，说这是工钱。）
   - 行，那二两算我做好事的工钱。
   - 成了，二两归我，工钱。
   - 成，那二两归我，说好的工钱。
A-1. **小耗子**（理直气壮：他俩跑了一趟、老人得了药，拿二两天经地义。）
   - 药送到了吧？我可没光站着，这二两是我跑腿该拿的。
   - 那几文又不是偷穷人的，是跑腿脚钱——怎不该拿？
   - 药他吃上了，我腿也跑细了——这二两不叫偷，叫工钱。
B-1. **小耗子**（接过来揣好，夸萧白爽快。）
   - 得嘞，萧白你真够意思！
   - （七）
   - 萧白你今儿个倒爽快，兜里揣稳了啊。
后-1. **小耗子**（顿了一下，头一回跟人报本名：我叫阿七；别人叫我小耗子。）
   - ……阿七。我叫阿七，别人都管我叫小耗子。
   - ……我本名叫阿七。
   - ……阿七。我本名叫这个。
后-2. **萧白**（叫他一声阿七，回应他报的名字。）
   - 阿七，行，二两你收好。
   - 阿七，我记着你了。
   - 阿七，行，记住了。
