# AQ-buy 药摊买药（fq_aqi_buy）（演员法备选）

戏眼：萧白想买一包药又不想说给谁；药商以为他又是来追问传言的。散场时药买到了，钱袋花空，找回二两；药商只当做了一笔买卖。

1. **药商**（看见早上陪叶蘅来的少年，先急着撇清：该说的早上都说了。）
   - 该说的早上都说了，买药就买药，别的事我不知道！
   - 哎哟小兄弟！早上的话我可都说尽了，真没那档子事！
   - 早上那事儿咱可说清楚了，箱子的事跟我没半文钱关系！
2. **萧白**（说不是来问那个的，买一包治老寒腿的药。）
   - 我不是来问那事的，就想抓副治老寒腿的药，一包就够。
   - 掌柜，没别的事，就买一包治老寒腿的药。
   - 不是问那个的，就买一包治老寒腿的药。
3. **药商**（一听是买卖立刻换了脸，包好药，找回二两。）
   - 得嘞！治老寒腿的，一包二十两，您这银子我收好，找您二两。
   - 成成成！老寒腿的是吧，给你包好嘞——这是找你的二两！
   - 得嘞！专治老寒腿的，一包拿好，找你二两！
