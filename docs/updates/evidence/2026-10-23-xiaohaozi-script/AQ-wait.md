# AQ-wait 第一单没做完时搭话（fq_aqi_wait）（演员法备选）

戏眼：小耗子想催萧白把这一单做完。散场时萧白知道下一步去哪。

1. **小耗子**（（step=1）催他去东埠，钱袋在随从腰上。）
   - 走啊，趁那随从还没走远，腰上那钱袋沉得晃眼，去不去？
   - 走，东埠码头那个随从腰上挂着钱袋呢，先把他办了再说。
   - 东埠码头上那随从腰上挂着钱袋，我跟你赌——这回稳得很，走不走？
2. **小耗子**（（step=2）催他拿钱去药摊，别揣着钱袋到处晃。）
   - 走啊走啊！揣着钱袋杵在这儿等那随从回来找你算账？
   - 揣着钱袋子满街晃，找打呢？快去药摊！
   - 揣着它满街晃，你嫌那随从眼瞎啊？快走，药摊在南村口！
3. **小耗子**（（step=3）催他把药挂到村南门上，别敲门。）
   - 别愣着了，把药悄悄挂他门环上就成，敲门反倒把人惊着。
   - 跑啊！药往门环上一挂就完事儿，敲什么门！
   - 把药往门环上一挂就得了，敲什么门，撞上了你跟老人家解释去？
