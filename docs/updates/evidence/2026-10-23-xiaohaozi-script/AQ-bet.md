# AQ-bet 门口打赌（fq_aqi_bet）＋第一单交代（演员法备选）

戏眼：小耗子想跟这个外乡人抱团，教他一门手艺；挡着的是萧白不愿意偷东西。散场时萧白摸到了铜钱，听了两条规矩，答应去做第一单，知道要去东埠、药摊、村南三处。

1. **萧白**（走过来，问对方是在叫自己吗、有什么事。）
   - 是你在喊我？找我什么事？
   - 叫我？什么事？
   - 是你在叫我？找我什么事？
2. **小耗子**（打量他，问他是不是刚来的；说自己也是外乡人，外乡人在这儿得凑一块儿。）
   - 你也是外乡来的吧？在这儿，得凑一块儿才撑得下去。
   - 哎，我瞧你也是两手空空的外乡人吧？
   - 你是刚到这儿的吧？外乡人在这儿，得抱团。
3. **萧白**（报自己的名字，问对方怎么称呼。）
   - 我叫萧白，你呢？
   - 我叫萧白，你呢？
   - 我叫萧白，你呢？也报个名儿吧。
4. **小耗子**（说村里人都叫他小耗子；顺口说要教萧白一门在这儿吃得开的手艺。）
   - 村里人都喊我小耗子，本名你就甭问了；我教你一门手艺，保你在这儿吃得开。
   - 村里人都叫我小耗子，来来来，我教你一手，保你在这儿混得开。
   - 村里人都叫我小耗子，本名不说也罢——你想不想学门在这儿吃得开的手艺？
A-1. **小耗子**（不直说，先打个赌：萧白能从他身上摸走一枚铜钱，就教他。）
   - 你先别问，咱打个赌——我要是从你身上顺走一枚铜钱你都没察觉，这门手艺我就教你。
   - 打个赌，你摸得走我身上一枚铜钱，这门手艺就算你的。
   - 行，打个赌——你若顺得走我身上一枚铜钱，这手艺我白教你。顺不着，你欠我一顿饱饭。
B-1. **小耗子**（嬉皮笑脸地不否认，说先赌一把再说：萧白要能从他身上摸走一枚铜钱，就教他。）
   - 哈，偷？你只管来摸，摸着了我就认你本事，往后跟着我吃香喝辣；摸着，算我输。
   - 猜着了！赌一把——你从我身上摸走一文钱，我就教你。
   - 那叫本事！来，赌一把——你从我身上顺走一枚铜钱，我就教你。
后-1. **萧白**（有点无奈，又被激起来，答应试一试。）
   - 行，反正我身上一文钱没有，你摸着了算你本事。
   - 行吧，就一枚铜钱，你试试。
   - 行，赌就赌——我身上干净得很，就看你有没有这本事。
后-2. **（小游戏）**（fq_aqi_steal("aqi_lesson_coin")：JS 跑教学版袖里一按，失手播 fq_aqi_again，直到摸到。）
   - （小游戏：fq_aqi_steal("aqi_lesson_coin")）
后-3. **小耗子**（铜钱被摸走了，嘴上不服、心里服气，夸萧白手不笨。）
   - 嘁——说好的身无分文呢？算我手快走运，可你愣是一下没动，手上有点东西嘛。
   - 嚯，顺着了！你这手不笨，往后跟我学准没错。
   - 行，算你手不笨——可惜这铜钱，还是落我兜里了。
后-4. **小耗子**（收起贫嘴，说第一条规矩：不偷穷人。）
   - 记住了，往后只摸不义之财。
   - 不偷穷人，这条没得商量。
   - 第一条，不偷穷人。
后-5. **小耗子**（说第二条：不偷救命的东西。）
   - 还有一条——救命的东西，不碰。
   - 第二条，救命的东西不偷。
   - 还有一条——救命的东西，再穷再值也不动。
后-6. **小耗子**（又活泛起来，说光会摸不算，带萧白做第一单：村南腿脚不好的老人，怕药棚验过的药被拉走。）
   - 走走走，哥带你去开张。
   - 光会摸哪成！东埠征药那随从腰上钱袋晃呢——顺他钱买药，悄悄挂村南老头门上，不敲门不留名。
   - 走，带你去东埠开张——征药那随从腰上钱袋晃得欢，顺了买药挂村南老人家门口。
后-7. **小耗子**（说东埠那个点篓子的随从钱袋挂腰上，去摸他的钱，别碰他的药。）
   - 东埠有个点篓子的征药随从，嘴上嚷着"公事"，钱袋挂在腰上晃——咱们摸他的钱，那包药碰都别碰。
   - 东埠那点篓子的随从，腰上钱袋晃当响——咱只顺他钱，征来的药一根毛都不许碰。
   - 东埠有个点篓子的，腰上挂个钱袋晃，你跟我去顺他几文。
后-8. **萧白**（不明白：既然要药，为什么不直接拿随从的药。）
   - 他身上不就有药吗？干嘛不直接拿，非得绕一圈去摸钱？
   - 既然缺的是药，顺手拿了不更省事？
   - 随从身上不就有现成的药吗？干嘛不直接拿，非得绕一圈去摸钱？
后-9. **小耗子**（征来的药是救命的，犯第二条；拿到老人手里，人家一眼认得出是哪来的。）
   - 那药是公家征来救命的，碰了犯我的规矩；再说老人家眼毒，一眼就认得出是征来的，你这是帮他还是害他？
   - 那药是救命的，犯我第二条；拎去老人一瞧就认出来路。
   - 征来的药是救命的，碰了犯我规矩；再者原样送过去，人家一看就知道哪来的。
