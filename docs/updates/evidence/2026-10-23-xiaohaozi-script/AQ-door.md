# AQ-door 挂到门上（fq_aqi_door）（演员法备选）

戏眼：萧白想把药留下又不让人知道是谁；屋里的老人听见动静要来开门。散场时药挂在门上，萧白没留名就走了。

1. **萧白**（（心里话）药挂在门环上了。）
   - （药挂好了，走吧。）
   - （药包挂好了，走吧。）
   - （药包挂好了，不敲门，不留名。）
2. **村口老人**（在屋里慢慢应门，问外头是谁。）
   - 谁呀？等等，我这老腿走得慢，你别走啊——
   - （门环响得轻……是哪个呀？）
   - （这大早上的，敲门也不应一声……）
3. **萧白**（（心里话）不应声，走。）
   - （不能应，一应就走不掉了。）
   - （别回头，回头就又走不了了。）
   - （不应了，走。）
