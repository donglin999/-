- 2026-10-20 用户告知额度已重置，仍用当前源 302ai-sunburst 出齐 15 张（1024×1024，`--opaque-fix`，提示词请求 gpt-image-2.5，实际模型未确认）：方向 A 六个角色各两张（半身、紧头像），方向 B 萧白借衣、叶蘅、灰狼各一张。逐张记录见批次 `README.md` 与 `manifest.json`。

- 评审页 `art_sources/char-icons-20261019/review/index.html`（经 8792 打开），整页截图 `review/review-full.png`：状态栏、菜单出战编成、战斗轮次条（当前放大、敌我框色、破势、阵亡演示，1:1 与 ×1.5）、与对话立绘同脸对照、全部 18 个候选；顶部下拉框可切换三处使用哪一张。

- 2026-10-20 用户看首轮后的意见：“要清晰的，但我的意思不是让你一比一复刻，是一样的人和一样的风格，但是要有 icon 的特殊设计，例如表情，或者例如半身等等，而不是直接截图”。据此：设计文档新增 3.1“图标演出”（每人按人物登记的性格定表情、姿态、道具，两版），方向定为清晰的 A，B 不再继续。
- 第二轮（R2_*）仍用 302ai-sunburst：萧白现代装（回头摸后颈 / 抱臂）、萧白借衣（双手横握木棍 / 扛棍回头）、叶蘅（拈银针 / 缠布带微笑）、陆衡（握腰带挎行囊 / 肩挂绳索）、大黄（歪头吐舌 / 抬爪吠叫）、灰狼（扑击 / 低吼）。中途多次接口超时，降并发重跑。大黄首版画上了设定外的药包、领巾，已加约束重做（R2_dog_a2/b2）。陆衡含刀鞘、刀柄字样的提示词连续 4 次被接口返回 nginx 404，去掉兵器描述后成功（R2_luheng_a2/b2，未画刀鞘）。
