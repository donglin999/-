# 界面不写章节与固定环节，改为“江湖经历”（2026-10-19）

状态：现行　最后核对：2026-10-19

## 需求

用户：“不需要写着第几章，也不要显示固定名字或者环节，像类似大侠立志传那样记录某一个事件的概括名字即可（完成之后记录）”。

## 改了什么

- 新增 `js/qihe-milestones.js`：按存档状态列出已完成的事件，每件一个概括名字：后山遇狼、栖河第一夜、正道盟上门要谱、玉匣与药样、栖河起火、护送乡邻离村、对证三张附页、山居安身。事件完成之后才出现。
- 行卷标题、新版行记右上角、存档栏描述：显示最近完成的一件事；还没有完成任何事时，显示“江湖行卷”或“初到栖河”。
- 行卷任务：去掉“开始 · 山村来客”“开始 · 风起栖河”“培养 · 山居日常”三条固定阶段条目。正在做的主线统一叫“眼下”，完成的事件逐条记入“江湖经历”。
- 去掉标题页的“开始 · 山村来客”、网页标题里的阶段名、上山结尾的“风起栖河 · 完”（改为“江湖经历记下一笔：山居安身”）。
- 锁定提示不再写章节：心法残卷“（暂未开放）”，心法栏“暂未开放”，毒方说明去掉“（第二章实装）”。
- 主线提示里的“开始 · 自由探索”“开始部分已结束 · J 进入培养”“山居日常 · ……”改为不带阶段名的说法。
