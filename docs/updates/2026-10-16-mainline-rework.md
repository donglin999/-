# 2026-10-16 进城前主线 13 场返工

## 改了什么

返工此前由 codex 生成的培养第一部分进城前主线：M-02～M-09、Z-01、Y-02、L-02、Y-03、Z-03，共 13 场。

- **剧情重新设计**：每场先写戏眼（谁想要什么、什么挡着他、散场时什么变了），简报在 `docs/design/scripts/briefs/pre-xiangyang-mainline-brief.json`。
- **把几场串成一条因果线**：二月周砚旧识回信，说山那边镇上有户人家当年被温行舟治过 → 三月周砚托陆衡送药时捎叶蘅去那个镇子，萧白跟去背包认路 → 镇上收药的人正是那家的儿子，老人不在家，只能等回信 → 四月城里寿宴请帖，写回信的那位旧识就住在城里，叶蘅因此决定进城。原稿里叶蘅为什么跟去送药、为什么一定要进城，都没有交代。
- **删掉为凑指标写的台词**：如“亲见／听说分开记”“别替旁人签收”“我家的东西不当贺礼”“待收件方确认”等，相应的设计约束改成放在事情里自然满足。
- **台词**：MiniMax（MiniMax-M2）按简报起草，人工改定；之后交给一位没看过设计文档的独立审读者，按意见改了 21 处（称呼、前后矛盾、选项重复、替编剧交代下一场的句子等）。
- **称呼**：叶蘅没拜师（M-01“你照旧”），改称周砚“周先生”。完整称谓表仍待拍板。
- 段落 key、条件、效果、选项 key 都没改；分支选项文字改成了人物会说的话。

## 新增工具

- `tools_story/minimax_draft.py`：按简报调用 MiniMax 起草台词（密钥沿用配音配置，不打印）。
- `tools_story/apply_story_drafts.py`：把改定的草稿写回 `pre-xiangyang.json`，校验段落、说话人和每个人能用的表情。
- `tools_docs/story_lint.py`：修正 `--scene` 过滤（文档剧本原先把句子 id 当成了场景 id）。
- 规范 `docs/design/story-writing.md` 第六节补了 MiniMax 起草的步骤和常见毛病。
