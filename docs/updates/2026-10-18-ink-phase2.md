## 运行时与构建（向后兼容试点）

- `js/story-runtime.js`：`set_flag` 仍按剧本顺序排队，但排队期间 `flag()` 读得到刚写的值；选择框前那句的编号交给本场 `mark`（试点误用空 mark，原 JS 在 P-01-11 有 mark）；`flag()` 遇 null 返回 false；新增 `vars`（剧本参数）、`toast_for`；同一剧本文件里别的 knot 用到、本场没提供的游戏函数绑成“调用即报错”（inkjs 开演时检查整份剧本，否则寒暄会因邀请里的 `go_scene` 报错——比对时发现并修正）。
- `tools_story/build_ink.cjs`：
  - 支持 ink 函数、隧道 knot（只随调用方遍历）、参数变量（`VAR x = false // 参数`）、`bible/物品/` 里带“名牌”的页（路牌）；

  - `recordOnly` 标记不报断线；字幕行在总表里去掉【】。
- 路线文件 `docs/story-routes/` 每个非隧道 knot 一份，共 25 份：递水 3 条（A/B/C）、药箱 3 条、邀请 4 条、还碗/取布/送药各 4～5 条、周婶托付 153 条、过夜三段 148／128／144 条，其余 1～2 条。
