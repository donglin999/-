# 游戏参考候选评审站

状态：现行　最后核对：2026-11-09

## 需求与范围

用户希望收录《侠客风云传》的剧情、培养和人物塑造，《逸剑风云决》的功法、人物和剧情，《八方旅人》的战斗、演出及场景技能，《大侠立志传》的剧情、技能、地图和人物交互。

本轮后续明确：

- 八方一、二代都收录并注明差异。
- “先不要直接加入，做完之后给我一个网站去做评审”。
- “需要你结合现在的游戏板块去结合，而不是全量去找”。

因此产物仅为独立候选评审站，不建立正式知识库目录、不追加正式资料入口、不改游戏规则、设定和实现。初始“13 个原作主题”的组织方式已改为按当前游戏的 8 个板块筛选。

## 交付

- 本机网站：[游戏参考评审](http://127.0.0.1:8796/)。运行脚本：`xiaojianghu/review/game-reference-20261109/server.py`。
- 页面与候选正文：[评审站页面](../../review/game-reference-20261109/index.html)、[候选数据](../../review/game-reference-20261109/content.json)。候选正文是 JSON，不进入现有文档书阁的 Markdown 索引。
- 板块：开始剧情、归云谷培养、人物与队伍、武学师承、战斗、演出、八印交互、地图与生活内容。
- 31 个实际使用的外部来源，按官方、媒体攻略、社区 Wiki 标注版本与读取限制；28 份本地依据记录路径及内容指纹。
- 每页列本作现状、原作案例、结合分析、建议收录范围、暂不收录范围、待补证据；部分参考附原作截图和自制文字流程示意。没有复制全量剧情、武学表或地图集。
- 支持搜索、按参考游戏筛选、只看未评审、逐板块意见保存、历史及备份、导出。意见存在独立 `.review-state/feedback.json`，不执行自动入库。

## 核对依据与发现

只读核对现行 Godot 的培养、人物交互、武学菜单、战斗、对白及音频模块，以及 [汉皋前时间线](../design/pre-hangao-timeline.md)、[可选剧情规范](../design/optional-story-dependencies.md)、[师承功法](../design/cultivation-mentor-lines.md)、[功法结构](../design/martial-structure.md)、[人物交互](../design/npc-interaction-v2.md)、[地图规范](../design/map-development-standard.md) 和最近改动记录。

现行可玩范围止于汉皋南门，城内目标设计单列；当前培养已有 12 点预算，但 `cu_core.gd` 对一次性剧情及地点入口等不扣体力，与旧培养文档部分费用描述不同。此差异在候选页注明，未修改负责文档或规则。战斗已有破势与蓄势，交互已有八枚印，不将原作同类机制当成项目缺失项。近期人物立绘、菜单背景、命中特效和配乐评审继续由原会话负责。
