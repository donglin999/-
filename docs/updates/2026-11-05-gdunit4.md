# 2026-11-05 · 装上 GdUnit4 自动测试

状态：现行　最后核对：2026-11-05

## 需求（用户原话）

- 用户先说想看看 Godot 有什么好插件：“看下 godot 有什么比较好的插件可以优化现有的内容”。
- 看完推荐后，用户选了“装 GdUnit4”。

## 做了什么

- 插件：GdUnit4 6.2.3，2026-11-01 发布，是写这份记录时的最新版。
  - 来源：官方仓库 MikeSchulze/gdUnit4 的 v6.2.3 源码包，只取了 `addons/gdUnit4`。
  - 放在 `game/addons/gdUnit4/`，`project.godot` 里已启用，编辑器打开后底部会出现测试面板。
- 不进游戏包：`export_presets.cfg` 的每个导出预设都在排除列表里加了 `addons/gdUnit4/*` 和 `test/*`。
- 运行脚本 `tools/gd_test.sh`：
  - 无头运行，不弹窗；
  - 报告写到 `xiaojianghu-godot/.gdunit-reports/`，网页版和 XML 各一份，只留最近 3 次；
  - 退出码：0 表示全过，100 表示有失败；
  - 网上有报告说 4.7.2 无头模式下，有些失败的退出码仍是 0。为防这种情况，脚本会再读一遍输出里的总计行，有失败就强制返回非 0。
- 第一批测试，共 11 个，全过：
  - `game/test/story_runtime_test.gd`（5 个）：
    - 剧本调用游戏函数时，多出来的参数会被截掉，不收参数的函数照样执行（11-04 卡在后山就是这个原因）；
    - 参数刚好时原样传；
    - 多个函数按剧本里的先后执行；
    - 台词行能正确解析出说话人和标签。
  - `game/test/npc_interaction_test.gd`（6 个）：
    - 第一枚印是“互”；
    - 所有墨印数据里不再有“托”“回”；
    - 剧情钩子的标签都叫“互动”；
    - 全部 132 个场景人物都没有被关掉“谈”；
    - 站岗的人也都有“谈”；
    - 两段站岗谈话的剧本已经登记。

## 测试当场查出的问题

`data/runtime/globals.json` 里有一份旧副本 `QiheNpc.data`，是原版导出时附带的，游戏代码没有读它。它还留着“托／托付／回话”和站岗两人的“不能交谈”。

和现行数据 `QIHE_NPC_DATA` 逐项对过，除了这几处以外完全一样，所以整份同步成现行数据，免得以后有人读错。

## 验证

- 退出码：
  - 临时放进一个故意失败的测试，跑完退出码是 100；
  - 删掉后再跑，退出码是 0。
- 一个文件里某个测试失败后，同一文件里后面的测试不再跑，其他文件照常跑。所以一个文件里只放同一类的测试。
- 编译检查：118 个脚本、10 个着色器，失败 0。插件只在编辑器里起作用，`--checkall` 不扫描 addons。

## 留给接手的人

- 新测试放在 `game/test/`，文件名以 `_test.gd` 结尾，`extends GdUnitTestSuite`，测试函数名以 `test_` 开头，可以用中文。
- 适合写成测试的：
  - 交锋规则、墨印条件、存档读写这类纯逻辑；
  - 导出数据的约定，比如“谁都有谈”这一类。
- 要看画面的仍用 `tools/gd_bg.sh` 截图。无头模式下输入事件不生效，测试里不要模拟按键。
- 退出时会出现“7 ObjectDB instances were leaked”和“4 resources still in use”，这是 `--checkall` 本来就有的两行，跟测试无关。
