# 2026-10-19 第一夜改造（剧情三道关，批次“第一夜”）

范围：`story/01-开始/` 下 8 个剧本——周婶托付、还碗、取布、送药、收药箱、问候、过夜、村中查看。前一场以提案版 `docs/story-proposals/序章-进村第一夜.ink` 为准（萧白说过“明儿有什么活，您叫我”，叶蘅说她家在村西北）。

## 流程

1. **戏眼卡**：`xiaojianghu/docs/design/scripts/briefs/firstnight-actors-brief.json`，7 场（FN-aunt、FN-chen、FN-cloth、FN-elder、FN-relic、FN-night、FN-guest），每场写了谁想要什么、什么挡着、散场时什么变了，每人此刻知道／不知道什么，以及逐句意图（标了对应句号）。
2. **演员法**：`tools_story/minimax_actors.py`。MiniMax 同时被几个批次调用，多次报 2062（速率限制）；陈伯、取布、送药、收药箱、过夜五场拿到了完整备选（过夜收尾几句失败），周婶、客房两场第二次重跑只拿到一部分。失败的句子由主编按戏眼卡直接写，剪辑时整场通读。
3. **冷读审读**：独立子代理只读整理后的台词全文（含全部分支），提出“必须改”10 条和其余意见。处理见下文；新查出的问题已追加到反例库 `xiaojianghu/docs/design/story-ai-patterns.md` 末尾“2026-10-19 第一夜 冷读查出”。
4. **检查**：`node tools_story/build_ink.cjs` 通过；`story_lint --scene opening` 需处理 0（第一夜只剩两条系统字幕“无说话人”提示）。

## 每场改了什么

| 场景 | 改动 |
| --- | --- |
| 药棚 · 周婶托付 | 开口接上“有活叫我”，先把三件事报出来再让他挑（原选项里的碗、布、药周婶从没提过）；寒暄改为看他手上的擦伤，不再和托付连着说两遍“锅里还有粥”；再来时改说“回来啦？”；交代布为什么在客栈、竹篮为什么在老人家（老人帮着绑提手）。 |
| 陈伯家 · 寒暄与还碗 | 寒暄接上“客房腾好了”和村里对狼的反应；道谢方向改正；陈伯不再把阿蘅的去处告诉打听温家东西的生人，只让他明天当面问；萧白听到“阿蘅”心里对上叶蘅；“走了”改“出门好些年，再没回来过”。 |
| 客栈 · 取布 | 掌柜先说布搁在凳上，“布要掉了”才有来由；旁听改成“多等一会儿”（原选项“扶好篮子”里的篮子没人提过）；萧白听到“姓叶的”有反应；交布时掌柜托话（接回药棚时萧白的转达）。 |
| 村南 · 送药与还篮 | 老人不认得萧白，改为萧白先说来意、报名字；老人说起征药是担心自己的药；传话改为随从在他门口问路时说的（他腿脚不便）；删“翻名册”。 |
| 叶家门口 · 邀请 | 萧白先敲门报名；寒暄只播一次；邀请说明她在收药箱，进屋后不再重复“压布”的请求。 |
| 叶家 · 收药箱 | 若萧白旁听过周砚，不再问“他现在不在村里？”，改为告诉她有人在打听她父亲，她想当晚就去，被劝住；“又问错话”只在真问错时说；“她也住这里？”改“这些都是你母亲收的？” |
| 过夜 · 灯下的字条 | 在客房选了睡觉为什么又到叶家：陈伯喊他一起扛绳过去；萧白不再替叶蘅拿主意，改问“会不会是买罐子的药商塞的”；陈伯主动说周砚明天要来；叶蘅问他“碰见什么人”才引出追问；周婶补几句反应；没办完的小事改成他心里想得到的说法（“竹篮还没还”）；睡前加一句想家；手机电量接上进村时的“还剩一半”。 |
| 村中查看 | 客栈晒架按取布进度分三句；傍晚不再说“太阳底下”；手机那句加“怕是连电都没有”。路牌未改。 |

## 需用户拍板

1. **叶蘅为什么姓叶**：父亲温行舟，帮众说“姓叶的那家”，陈伯说“温家的东西”，冷读读者分不清。要不要在台词里交代（例如随母姓），由你定。
2. **周砚第一夜住哪儿**：客栈满了、陈伯家客房给了萧白，台词里没有交代。
3. **客栈方位**：路牌写西南、设计稿写东南、扩展后取布实际在“南村口 / 客栈外院”。第一夜台词已避免说方位，路牌未改。另：路牌和地图名牌叫“药铺”，台词都叫“药棚”。
4. **碰不到的三句**：`P-S2-bandit`、`P-S3-bailiff`、`P-S3-aide` 在现行游戏里碰不到（扩展把这几个人移走或换成了风起栖河的台词）。已顺手改写，但是否保留由你定。
5. **与别的批次冲突**：`三方-徐令仪上门.ink` 里周砚说“今早先找了陈伯”，而第一夜他是前一晚在陈伯家打听的（已写进 `xiaojianghu/bible/定稿事实-待合并-第一夜.md`）。
6. 过夜里三种“查证后”的说法（`P-05-Q1-letter-*`、`Q2-account-*`、`Q3-ledger-*`）属于风起栖河的状态，本批次没有改。
