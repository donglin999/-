# 2026-10-10 培养期切磋实战、入队分类与 if 线记录

用户要求：综合侠客风云传与逸剑风云决的入队做法；结缘必须有单独的个人剧情；培养期错过关键剧情后留 if 线；补足培养期的切磋与战斗。规则写在文档库 `xiaojianghu/docs/design/romance-rules.md` 第四、五节，实现说明在 `docs/design/qihe-map/expansion/relationships.md`。

## 改了什么
- 切磋与实战：新增同门切磋四项（卢小豆、方迟、钟拙、殷红缨，“招式”栏，可重复，每时段一场）、“竹径的狼”“出门前的考校”两段新剧情；“陪练”“年终考校”第二题改为真实战斗。胜负各接一段对白，按结果给所学兵器的熟练。
- 入队：殷红缨不再“除夕必入队”。同行即入队；没同行时除夕关系 ≥40 才留下，否则记 `if_yin`，第二年不在谷中。
- 结缘：新增殷红缨个人篇“十几年前的寿宴”，是“屋顶上的人”的前置。
- 存档新增 `qiheRoutes`（入队／if 事实／基础事实汇总）。
- 素材：四张对练小人入库（`s_npc_gy_{fangchi,luxiaodou,zhongzhuo,yinhongying}_20261010`），由 codex exec 内置生图产出，提示词请求 gpt-image-2.5，实际模型工具未披露。
- `js/bfx.js`：战斗静态帧支持图集子帧。

## 没做的
- 大地图上的 if 线剧情、乙类角色的任务链：只有规则和事实记录，内容未制作。
- “代师出行”路上的拦路人战斗：留到该段行程做成地图内容时再加。
- 对练小人只有静态四向，没有出招动作；萧白在战斗中仍是短发造型的动作表。
- 新增对白没有配音。
