# 游历、终局地区与玩法重构（设计）

日期：2026-10-16。来源：用户要求按`consistency-check`逐项调整全作设计，补充可入队人物与主线联系、自主调整人物，并明确第三第四部分的城市与游戏性。与同轮剧情/人物小组共同工作，本记录只覆盖地区子任务。

## 本地改动

- 新增[地区与玩法合同](../archive/design/story-rework-20261016/regions-gameplay.md)与[机器合同](../design/story-rework-20261016/regions.json)。四部分统一为开始、培养、游历、终局；第三部分在培养末叶家结案后开始。
- 地点落为汉皋枢纽、襄阳樊城北线、合川烬渡水路、鹿门照川山门与既有家园支点。不新增江夏大城。
- 设计三条地区链共12节点、汉皋公共节点与四种终局行动；新增武学试艺、修造、物资安排、公开演出/交涉、踏勘、生活回访六种循环，给每条主线缺席替代、失利回程与后果。
- 明确地图入口连接、返程、服务及状态；新制作上限15室外+9室内，共24张。汉皋和门派原有合同单列依赖，不算已完成资产。
- 更新[大地图](../design/world-map-layout.md)后期开放与ID；确定正道盟方向官道接汉皋南门。更新[整月历练](../design/world-map-journeys.md)首城为汉皋，修正旧50点/1410点引用为已确认每期12点下的60点/1692点，未调整日历或运行数值。
