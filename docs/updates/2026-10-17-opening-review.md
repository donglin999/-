# 2026-10-17 开场演出评审与整改

用户反馈：“刚开始的演出也得重新评审一下，那头狼的模型太好笑了。”本地开新档，从后山醒来跑到遇狼战斗、进村吃饭，逐段截图、记录台词。

## 狼

- 后山地图上的两只狼原来用 `c_wolf`，那是 Q 版小狼崽（大头、圆眼、坐姿），和写实人物放在一起像两只玩具，这是“好笑”的主因。
  - 改为取战斗灰狼 `b_wolf` 的待机第 0 帧，做成静态站姿（`js/prologue-backhill.js` 的 `registerStaticWolf`）。地图和战斗是同一种灰狼，比例到人的胸口。
- 战斗里的狼原来显示高 54，只到主角膝盖，像小狗。调到 76（`js/bstage.js` 的 `BATTLE_BEAST_H`），肩高约到人腰。
- 新手指引框原来在没有目标时贴左下，正好挡住第二只狼；统一放到左上“关闭指引”下方（`js/prologue-story-battle.js`）。

## 台词（`js/prologue-arrival.js`、`js/prologue-water.js`）

- **醒来与喝水接不上**：萧白一开场就在走动、被叶蘅喊“站住”，递水时她却说“醒了？别急着起来”，又问“怎么一个人倒在这坡上”。递水插画里萧白坐在石头上。
  - 改为“你脸色白得吓人。先坐下，喝口水。”
  - 问话改为“怎么一个人跑到这坡上来了？”
- **递的是水壶**：插画里是陶壶，“水囊还你”改为“水壶还你”。
- **说过的话重复**：叶蘅已经说“走吧”，萧白又问“我能跟你下山吗？”（上一轮审读改出来的）。还原为“那……麻烦你了。”
- **叶蘅的心里话**：遇狼时插了三句“叶蘅 · 心想”，跳出萧白的视角，也拖慢了“别动——有狼”的紧张感。改成她压低声音说的两句：“狼都在北坡……怎么跑到采药路上来了？”“地上全是生人的靴印，远处还有狗叫——有人在山里撵它们。”
- **进村的旁白**：去掉两句动作旁白（“周婶收晾晒簸箕……”“叶蘅示意萧白坐下……”）；后一句改成叶蘅的话：“手伸过来我看看。……擦破点皮，不碍事。”
- **住处说法不一**：山上说“药棚有张空榻”，周婶说“把那张榻腾出来”，最后叶蘅又说“你今晚住陈伯家那间空客房”。统一为陈伯家的空客房：
  - 叶蘅在山上说“先跟我回村，总有地方让你歇。”
  - 周婶问“陈伯，你家那间空客房还空着吧？”，陈伯答“空着。就堆了两捆绳，我回去搬开。”
  - 周婶后面那句改为“客店都住满了”。
