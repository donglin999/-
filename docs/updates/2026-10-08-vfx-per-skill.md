# 2026-10-08 技能特效逐招专属重做

用户：“我看到很多特效要么没选中单位，要么特效很垃圾，我需要你每个功法都专门去设计……只是说可以复用的情况下可以复用而已。”

- **评审**：
  - 新增确定性评审接口 `WuxiaBattle.preview`，按实战站位逐招截取起手、命中、收势三个时刻，不受浏览器后台节流影响。
  - 两轮逐招结论见 `docs/design/vfx/review-20261008.md`。
- **规范**：`docs/design/v4-vfx-per-skill.md`。要点：
  - 每招有独有母题，只在意象一致时复用素材。
  - 按战斗尺度设计。
  - 必须命中正确单位。
  - 画面上最显眼的不能是伤害数字。
- **引擎**：
  - 战斗尺度下限 0.75（原 0.5）。
  - 专属编排的起手阶段加施法者内息光（可用 `leadAura:false` 关闭）。
  - 逐招主体放大参数 `boost` / `noBoost`。
  - 选“防御”时播放防御强化招的特效。
  - 评审舞台的我方锚点校正到身体中线。
  - 浮字支持自定义描边色。
  - 门派特效文件接口：`WuxiaFX.define`、`WuxiaFX.lib`、`WuxiaFX.assetDirs`。
  - 通用出图流水线：`tools_fx/fx_pipeline.py`。
- **重做**：61 招加 20 门 v3 内功主动，加 12 门旧原型心法，全部逐招专属。
  - 编排在 `js/fx/fx-*.js`。
  - 素材在 `assets/fx/<门派>_v1/`。
  - 原图与规格在 `art_sources/fx_<门派>/`。
  - 设计表在 `docs/design/vfx/<门派>.md`。
- **原有专属特效**：11 招按实战评审加强。
- **规格导出修正**：`tools_fx/build_vfx_kit_specs.py` 先判伤害段数再判增益。听涛辨枝、明约合锋改为敌方单体，与战斗一致。
- **测试**：`tests/vfx-coverage.test.cjs` 新增门派文件素材校验（5 项）。功法、战斗、养成相关测试全部通过。
