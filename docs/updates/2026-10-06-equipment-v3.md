# 装备界面 V3 开发与验收

## 用户采用与文档核对

用户明确移除底部装备对比及穿戴按钮，双击直接穿戴；沿用此前数值图标、根骨山岳、音律、取消分组标题、全部装备分类搜索要求。先更新 ui-flow/inventory.md，再开发。核对正式素材登记、V6细线留白与预览 design.md；工作区为 legacy-prologue / 8792。

## 实际实现

- 左侧统一两列22项数值，每项有图标；气血/内力当前条也配图标，两种上限独立保留。
- 根骨为青玉山岳。音律进入 MN_ZY 和 WTYPES，旧存档归一化时补0；琴/箫/笛归为音律，复用现有造诣成长与伤害逻辑。未向玩家授予乐器或虚构招式，未来具体琴箫道具仍需单独设计。
- 默认全包裹装备，全部/兵器/护具/佩饰分类、名称搜索、兵器类型及名称/数量排序；左侧槽位不隐性筛选目录。
- 去掉常驻对比区。单击只选择，悬停显示说明、需求和差值；鼠标双击或键盘Enter直接提交模型装备事务，无额外确认。
- 换下的装备返包，库存扣减保存后才生效。装备同一物品防重复，条件不足短提示，保存失败完整回滚。点击已装备槽可明确卸下。
- 正式24枚图集由内置image_gen生成（具体模型未由工具返回），1536×1024，6列4行。第一次生成后检查透明效果，再通过同工具编辑输出真实RGBA；PNG原件保留，仅格式转换为无损WebP。文件/坐标/来源/哈希已登记 production-assets.json/md/js。正式场景、立绘及旧素材未替换。
