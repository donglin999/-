# 任务 A 汇报：战斗指令菜单缩小并按出手人定位

指令菜单已缩小，并改成贴着当前出手人、自动避让其他界面元素。六场战斗共 28 张截图的数值检查全部不压任何东西，只有四人队第二位（叶蘅）的菜单离人偏远。

## 原因

问题都在 `game/scripts/battle/panel.gd`（行号为改前）：

- **太大**：原 216-221 行的 `_cmd_dims` 把宽度写死成 140（教学 220），行高 21（教学 27），表头 23，蓄势栏 29。
- **位置不对**：原 224-247 行的 `_fit_cmd` 只有右、左、头顶三个候选位，用估算的身体矩形打分。它不考虑敌人弱点格、意图徽、说明条、指引框、顺序条和队伍状态卡，人多时就会压到别人或离出手人很远。

## 改法和设计取舍

- **尺寸**（`panel.gd:215-220`）：表头 20、行高 18、蓄势栏 20、图标 15；宽度按内容算，限制在 116～196。主菜单约 123 宽，四行 115 高，五行（带“逃跑”）133 高。名字和行字 13px、标题 10px，接了 `Paint.crisp`，放大图上笔画清楚。
- **障碍清单**（`_cmd_obstacles`，`panel.gd:267`）：
  - 所有存活单位的精灵（按当前帧不透明范围量，`_spr_rel`，`panel.gd:245`）
  - 敌人弱点格（含护盾数字）和意图徽
  - 顶部顺序条、右上队伍状态卡、说明条
  - 指引开关、指引框、自动战斗按钮
- **定位规则**（`_fit_cmd`，`panel.gd:305`）：先试三个贴身位（前上、头顶、后上），再在出手人周围 ±300 的网格里搜。取“不压任何东西且离出手人头部最近”的位置；实在没有空位时取压得最少的。
- **不跳动**：同一出手人、同一菜单尺寸时位置缓存，上下选行时菜单不动。
- **子菜单**：武学、道具用同一套定位，各自取最近位，所以和主菜单的位置会差几像素到几十像素。选目标时菜单收起，只留说明条。
- **两部分共用**：开始部分和培养部分走同一个 `panel.gd`，没有分支。
- **取舍一**：“不挡任何人”优先于“贴得更近”。
- **取舍二**：行高定 18 是被四人队逼出来的——五行菜单要放进状态卡底边（y≈230）和后排头顶（y≈369）之间，再高就放不下。
