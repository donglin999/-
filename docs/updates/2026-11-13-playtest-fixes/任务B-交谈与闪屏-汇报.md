# 任务 B 汇报：“谈”为空与交谈前闪屏

两处都已修好并验证：开始部分 11 份存档里每个在场的人重跑检查，“谈”为空、先弹选项、谈前黑场都是 0 条；`--checkall`、`gd_test.sh`、`ink_sweep` 全过。

## 原因

**“谈”为空（叶蘅、陆衡、药商）**
- `game/scripts/flow/chapter.gd` 的 `activity_body`（现 865 行起，改前 831 行起）：白天活动阶段点这三人的“谈”，直接弹“行程”选项框，没有任何人开口。活动已办过或过了时候时，只有萧白一句心里话。
- 改前命中：药棚叶蘅、西田埂陆衡、南村口药商（05／06／07 三个进度点和用户当前存档）。
- 用户截图那处不是叶家室内的另一条路径，是同一个问题：用户存档此刻 `ye_location()=="clinic"`，叶蘅按行踪就该在药棚。

**闪屏（村头老人）**
- `chapter.gd` 的 `_apply`（现 533 行起，改前 531–548 行）：播带站位的戏之前，只要主角离站位表里的主角位超过 70 像素，就 `UI.fade` 黑场 0.45 秒把主角挪过去（现 555 行）。玩家走到人跟前点“谈”，通常都不在那个精确位置上，所以先黑一下。
- 走同一路径的还有：
  - 村口老人（`elder_door`，主角被挪 107 像素）
  - 陈家的周砚和陈伯（`chen_hall`）
  - 客栈店家（`inn_cloth`，主角被挪 248 像素）

## 改法和取舍

**“谈”先有人开口**
- `activity_body` 加了 `talker` 参数：有说话人时先播一句 `fq_talk_<人>`（按“可办／办过／过了时候”三种状态各一句），再弹行程选项。办过或过了时候就只说这句，不再弹选项，也不再播萧白心里话。
- 叶蘅不在药棚时点“谈”，播一句 `away` 状态的闲话，不问活动。
- 新写台词 10 句，放在新文件 `story/风起-搭话先开口.ink`，id 为 `C1-T-ye-*`、`C1-T-lu-*`、`C1-T-merchant-*`。全是新 id，没有改动旧台词。
- 没有采用“置灰或隐藏”：这三人此刻都该能搭话。

**已在跟前就不黑场**
- `_apply` 新增判断（`_beside`，560 行）：这场戏开场要摆的人都已在站位上（偏差小于 24 像素），且至少一人离主角不到 180 像素，就不黑场、不挪主角，原地开演。
- 老人、陈家、客栈这三场戏不再把已经离开场景的人凭空摆回来（`TALK_STAGED`，585 行）。
- 有意保留的黑场转场：
  - 邻村周砚的对证和商量去处
  - 活动选“现在开始”之后的站位戏
  - 主线大事
  - 主角离得远、确实需要挪位的情况

**可重复跑的检查**
- `sweep_npc.gd` 新增 `--talk-audit [--pick=first|last]`：逐个存档、逐个场景、逐个在场的人点“谈”，结果分为好／谈为空／先弹选项／谈前黑场／对方没开口／卡住／墨印上没有谈／谈是灰的。
- 白名单只有一条：`qh_refuge/zhouyan`（邻村周砚，有意保留的黑场）。
