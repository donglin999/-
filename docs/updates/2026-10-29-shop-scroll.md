# 2026-10-29 · 商店改回挂轴式界面

状态：现行　最后核对：2026-10-29

用户在评审台对商店第二版点了“继续改”：“之前不是有一个卷轴商店的 ui 吗？为什么要用这个这么丑”，10-29 说“现在就改”。

## 找到的“卷轴商店”

10-09 用户确认的挂轴式商店：
- 规范：`xiaojianghu/docs/design/shop-ui-standard.md`，用户原话“可以了，按这个风格做成真页面，其他的商店也要类似的设计”。
- 预览图：`art_sources/hangao_shopkeeper_20261009/preview-shop-ui-v2.png`。
- 原型：`review/hangao-town`。

原型一直没接进现在的游戏；10-27 第二版商店是另起炉灶写的，没照这份规范。

## 改了什么

- `js/qihe-gift-ui.js` 的 `shop()` 照规范重写，调用方式不变，`qihe-town.js` 的货单、九折、牙牌优惠照旧传进来。版式：
  - 上方挂“买入／卖出”木牌页签；两根木轴之间是深褐纸面，一行一件货：图标、按品级着色的名字、品级·类别、铜钱价、持有数、按钮。
  - 按钮：买入（蓝）；兵器、护具、佩饰加“装上”（橙），可叠加的加“买五”；钱不够时灰掉写“不足”。卖出页只列身上有的山货，有“出售”和“全部”。
  - 花钱、卖东西都先过确认层，写清共需多少、剩多少，装上的写替下哪件。
  - 左边店主＋对话框；左下木牌写持有银两；下方横幅写关系、好感和优惠；右侧铜钱串、纸灯。
  - 选中一行，左侧浮出说明：用途、属性变化、售价与优惠原因。
  - 键盘：↑↓ 选行，Enter 买卖，Q／E 换页签，Esc 先退确认层再离开。
- `js/qihe-gift-ui.css` 加挂轴样式（`.qs2`，1920×1080 写、缩到 1600×900 层）；`index.html` 版本号换成 `20261029-scroll3`。
- 新增截图脚本 `tools_scene/qihe/shot_shop.cjs`。

## 留下的

- 店家、药商还没有立绘，先放大地图小人。规范要求每个店主单独出半身立绘，不能借别人的；没立绘的人怎么处理，等评审台“查看页”那题定了再一起改。
- 规范里的“修理”“熟客”页签、“讲价”在开始部分没有对应玩法，没做。
- 背景沿用当前场景压暗，没有按街区另出朴素背景。
