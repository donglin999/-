## 第一件：对白框里“一”字显示不全 —— 改了

- **判断：成立，而且不只这一种对白框。**
  - 字体本身没问题：`NotoSerifSC-Medium.ttf` 里“一”在 21 号下光栅完整，横笔正好只有 1 像素高（17～28 号都是 1 像素）。
  - 原因是字形贴图被缩小时按最近邻取样。界面根 `UI.root` 缩 0.75 倍（`ui.gd:70`），正文标签再缩 20.5/21（`dialog.gd` 的 `txt.scale`），工程默认贴图过滤又是最近邻（`project.godot` 的 `default_texture_filter=0`）。缩小时整行整行地跳像素，“一”的横笔落在被跳过的那行，就只剩收笔的小点。
  - 修前截图第 602～603 行只有收笔那几个像素，横笔那一行完全没有。
  - 字距 0.055、描边阴影、字体子集都不是原因。
  - 带立绘的框（18.5/19 号）同样有风险，这次“拿一下”的“一”只是位置凑巧没丢。
- **改动：** `game/scripts/ui/dialog.gd` 的 `_build()`，第 63～65 行，新增两行注释和一行代码：
  ```gdscript
  root.oversampling_with_scale = CanvasItem.OVERSAMPLING_WITH_SCALE_ENABLED
  ```
  对白框里的字（正文、名牌、选项，子节点跟着继承）改成按实际显示大小光栅，不再缩贴图。字号、字距、行距、位置都没动，字体文件和 `build_fonts.py` 没动。
- **验证：** 按给的清单重拍，两句都截到；另补拍一张带选项的。
  - 不带立绘那句的“一”完整了，带立绘那句“拿一下”完整，名牌和选项正常。
  - 修前修后整图比对，有差别的地方只在对白框一带，顶部头像栏和提示条没变。

### 需要主会话拿主意：对白框以外同样会丢笔画

- 这次只修了对白框。`UI.root` 下的其他字（提示条、交互提示、头像栏）还是老画法。
- 证据：`other-toast-zoom.png` 里提示条“新任务 · 邻村对证 · 已加入左侧追踪”，“任”“已”“左”都缺横笔；对照试验第三组（18 号、标签自己不缩放）现状那行“一”也丢了。
- 11-10 给宋体加粗（`ui.gd:61-68` “选 件送她”“键位 览”）很可能是同一个原因，但我没单独验证。
- 没一起改的理由：任务要求改动小、不改整体观感；头像栏和提示条我只看了两张截图里的状态；菜单、人物交互、培养、战斗各有自己的 0.75 根节点，在 `menu/`、`npc/`、`cultivation/`、`battle/` 下，不在我可改范围。
- 要全修的做法：在各根节点上加同一行。
  - `ui.gd:70` 的 `root`（加了之后对白框那行可删）
  - `ui/title.gd:13`
  - `menu/menu.gd:246` 的 `panel`
  - 人物交互、培养、战斗各层的根
- 全修前要注意两点：
  - 有缩放动画的节点（`cu_hub.gd:167`、`page_party.gd:281`）每个缩放值都会新光栅一套字，要看会不会卡。
  - `Paint.draw_text` 用绘制变换缩小数字号的自绘文字，这个开关大概管不到，没试。

## 第二件：管事、采办使、乌魁为什么没摆 —— 只读调查，没改任何文件

**结论：不是移植漏了。原版从 2026-10-10 起地图上就没有这三个人，Godot 版照搬了原版。三段剧本在两版正常游玩里都播不到。**

1. **Godot 版有没有摆：没有。**
   - `chapter.gd:320-329` 的 `_install_expansion()` 只摆了药商、护院、采办随从、差役、徐令仪、岑霜、沈雁回；帮众在 `side_town.gd:128`。
   - `sc.json` 各场景人物列表里没有 id 为 `steward`、`wukui`、`procurement` 的人。
   - 全工程没有任何地方用这三个 id 调 `interact()`。
   - 行踪表里乌魁十个时段全是“—”，只在《装卸路》和起火两场固定剧情里出场；管事、采办使不在表里。

2. **原版：也没摆。**
   - `js/qihe-expansion.js:43-45` 里 `steward`、`wukui`、`procurement` 只是站位锚点名，站在上面的是徐令仪、岑霜（第三天前）、沈雁回，点她们传的 id 是 `xulingyi`、`censhuang`、`shenyanhui`。
   - 原版唯一用这三个 id 的是评审入口 `?storyReview=steward|wukui|procurement`（`js/qihe-story-review.js`、`core.js:209`），进去后被 `QiheOutsiders.handles()` 接走，转给三位代表的跑腿。

3. **有意还是漏了：有意，是原版当时的决定。**
   - `docs/design/qihe-map/expansion/story.md:45` 和 `outsider-quests.md:7,40`：2026-10-10 用户确认三方委托改由徐令仪、岑霜、沈雁回直接对接，旧参数“现在分别交给徐／岑／沈”。
