# 第一章领队交锋：补做三招专属特效

用户本轮明确要求“把技能特效补上去”，解除此前“不自行生成特效”的限制。按 `xiaojianghu/docs/design/chapter1-clash-jia-20261014.md`「特效交接」逐招制作明约合锋 `am_s3`、缠腕短打 `cs_whip_s1`、回身掠影 `cs_whip_s2`。三招全部用程序编排（canvas 光带、曲线、渐变、粒子），沿用现有 `am_v1`／`kit_v1` 素材体系，**没有生图，没有新增贴图素材**，因此素材登记表不需改动。未发布线上。

## 每招做法

- **明约合锋（徐令仪，甲级群攻）** `js/faction-fx/fx-am.js`
  - 0–260ms：徐原位 cast，金白锋芒只在手中剑身上由柄向尖凝聚；全场轻微压暗（叠加层再减半），不熄黑、不出第二名剑客。
  - 260–520ms：同一起点的绛青扇形锋面（人物后层渐变面＋前沿弧线）横展到每个实际目标；前层绛青“开线”，后层较淡的金白“接锋”滞后跟进，只是装饰。
  - 520ms：只给实际命中者出交叉剑痕和金白作用点；闪避者的锋线从头侧擦过，只有擦过的白色碎线。
  - 520–1000ms：锋线向目标收束消退；1000–1250ms 收尽。
  - 接应缺口：交锋层按真实 `clashFollow` 状态在命中者身前常驻一个金白小缺口，被其他友方命中消费时短亮一次，状态消失即不画。
- **缠腕短打（岑霜，乙级单体）** `js/faction-fx/fx-cs.js`
  - 岑原位短 cast；150–300ms 一道墨紫短鞭形气劲自外侧甩入徐的持器腕侧（不从岑手里连出）；300ms 命中卷成一圈缠腕＋一个铜色作用点，闪避则鞭梢擦过、不缠腕；360–880ms 自柄端回收消隐。
  - “制势”腕环由交锋层按真实 `clashBlunted` 状态常驻，规则清掉状态时随之消失。
- **回身掠影（岑霜，甲级群攻）** `js/faction-fx/fx-cs.js`
  - 0–240ms：岑原位 cast，手边墨紫内息微聚；实体软鞭不离身。
  - 240–520ms：敌阵前一道**连续的**墨紫鞭形大弧自近侧穿过每个实际目标（闪避者处从头侧擦过），两道暗红残影滞后展开。
  - 520ms：命中者各出一道短鞭痕＋少量铜色碎点。
  - 520–920ms：大弧自梢端回卷到约三成，岑胸前出现一次暗红缺环“破绽”提示；920–1250ms 残余从梢向柄收尽。
- **合并反馈**（`js/qihe-faction-clash.js`）：同组多目标命中只合并一次轻震（甲级 2.5、乙级 1.5 画布像素）和一次顿帧（甲级 50ms、乙级 35ms）。明约合锋沿用原有刀击声一次；鞭类暂用现有 `whoosh` 提速作鞭梢主声（专属鞭声未制作）。
- **命中/闪避**：出手前在状态副本上跑同一套确定性规则，预判每个目标是否命中，只用于决定轨迹压在身上还是擦过；命中反馈在 hitAt 准时出，真实结算写入后以结算为准。真实状态、数值、出招顺序与结算均未改动。
- **低效果档**：系统开启“减少动态效果”时，装饰粒子和残影减半，保留主锋面／主鞭弧、逐目标命中与状态提示。

## 已知差异与未完成

- 没走“概念图 → 用户确认 → 拆素材”的标准生图流程；本轮按用户要求优先程序绘制，画面精细度低于有专属贴图的 `am_s1`。
- 鞭梢主声是 `whoosh` 提速的代用品，专属鞭声仍待制作。
- 本场脚本内回合数不推进，接应标记按规则一直有效，所以乌魁、堂众身前的接应缺口会保留到劝停。
- 制势腕环随规则状态在目标下一次出手**开始**时清除，比设计写的“下一行动结束”略早。
- `tools_story/build_qihe_faction_clash.py --check` 在本轮改动前就不通过：运行时数据里已有手工改过的台词和护院美术，而文档库场景源没有同步。本轮没有重跑构建，只在源与运行时两边同步改了特效字段。
- 原浏览器测试里写死的 playwright 浏览器（1228）和录像用 ffmpeg 本机不存在，需按实际环境调整后才能直接运行。
