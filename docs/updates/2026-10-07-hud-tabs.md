# 2026-10-07 · 探索HUD图标对齐、快捷键补齐与江湖页签合并

## 需求

用户截图反馈：探索HUD六枚圆章高低不齐；武学、任务（及设置）没有快捷键；江湖菜单里「属性」(1) 与「队伍」(5) 内容实质相同，要求去掉属性页签并把队伍挪到最前。

## 核对

工作区 xiaojianghu-legacy-prologue / 8792。读 AGENTS.md、[入口与页面](../design/qihe-map/expansion/ui-flow/navigation.md)。代码确认 `js/qihe-jianghu-ui.js` 中 `attr` 与 `party` 都调用 `partyPage(v)`，属于重复入口。

HUD图标错位原因：`assets/ui/jianghu-v5/icons-atlas.png` 为 1254px 4×4 图集，格宽 313.5px，各圆章在格内上下偏移不一（顶边 0/19/31px），地图章还越过格线；原 CSS 按整格 400% 取位，导致显示高度不同。
