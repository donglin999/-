# 战斗系统（js/battle.js）

横版回合制，歧路旅人（Octopath Traveler）式：**护盾 / 弱点 / 破防（BREAK）** + **蓄势（BP）**。敌人在左、我方在右，顶部行动顺序条同时预告本回合与下回合。

## 1. API

```js
const r = await battle({
  foes:[mk('bandit'), mk('wolf'), {name:'老僧',sp:'c_monk',lv:3,st:{…},skills:{palm_m:1},h:170}],
  bg:'bg_street',     // 背景资源键；缺省 'bg_'+S.scene，未加载则 loadOpt 动态加载，仍缺则用模糊的场景地图
  boss:true,          // 首个敌人为头目（居中大号、半血后每回合行动两次），不可逃跑
  noLose:true,        // 战败不回庙：气血至少回到 30%，由调用方处理 'lose'
  tutorial:true,      // 教学：三段说明、不带同伴、经验减半、不可逃跑
  noFlee:true,        // 禁止逃跑
  intro:'铁臂帮打手围了上来！'   // 开场旁白：字符串/字符串数组/async 函数
});
// r === 'win' | 'lose' | 'flee'
```

流程：`battleDom()` 建 `#bt` → 预载背景与同伴立绘 → `fade` 中 `mode='battle'`、隐藏 HUD/提示/触屏键，构造单位与站位 → intro/教学 → `battleLoop()` → 结算 → `fade` 回到原 mode（`map`/`battle` 回落为 `scene`）→ `hud()`。

结算：主角 `S.hp/S.mp` 从战斗单位写回（hp 至少 1）。同伴的气血内力**不持久化**，每战满状态开始。

> 注意：`battleLoop()` 抛异常时被 `catch` 记录并**按胜利处理**（`result='win'`）。

## 2. 单位构造

| 单位 | 来源 |
|---|---|
| 主角 `mkHero()` | `derived()` 全部属性；普攻类型 = 装备兵器 `kind`，空手为「拳」；武学 = `S.skills` 中除 `fist` 外的全部；`skLv` = 各武学**等效**重数（`menu.js mnEffLv`：重数倍率 04 §2.4 × 火候/心法加成，折算回 `1+0.15(skLv−1)`）；实际只带已装配武学（`S.load`） |
| 同伴 `mkAlly(key)` | `PARTY_DEF[key]`，等级 = 主角等级 |
| 敌人 `mkFoe(t)` | `statUnit(t)` 后：`mhp = round(mhp*(hpMul||.45)*1.8)`，`atk = round(atk*(atkMul||.62))`；盾/弱点/掉落取模板或 `FOE_DEF[精灵key]`（缺省盾 3、弱点 `['拳','刀']`）；`exp` 缺省 `lv*20` |

## 3. 回合流程（`battleLoop`）

每回合：
1. `round++`。我方存活单位：若 `round>1` 且上回合未投入蓄势，`bp+1`（上限 5）。
2. 破防到期（`round > brokenUntil`）的敌人恢复并回满护盾。
3. 行动顺序 `calcOrder()`：按 `spd + 抖动 rnd(0,3)` 降序，`prio`（上回合防御）+100 排最前；同时计算「下回合」预告顺序。
4. 所有敌人 `planIntent()` 预定本回合意图，显示在头顶。
5. 依序行动：敌人破防则跳过；我方单位 `defend` 清零，眩晕则跳过，否则 `allyTurn()`。每个单位行动后 `tickBuffs()`（定神倒计时、流血伤害）。任一时刻一方全灭即结束。

## 4. 护盾 / 弱点 / 破防

- 类型：兵刃 `刀 剑 拳 棍 暗器`，内劲 `阳 阴 毒 雷`（`WTYPES`，颜色 `WCOL`）。
- 每次 `strike()` 的兵刃类型 `t` 或内劲类型 `e` 命中弱点：伤害 ×1.25，显示 WEAK，并揭示该弱点（初始为「？」）；未破防且盾 >0 时**盾 -1**（每次命中每个目标至多 -1）。
- 盾归零 → `doBreak()`：`broken=true`，`brokenUntil=round+1`，取消蓄力与意图，屏幕震动、碎片、「破 防 BREAK」。破防期间：不能行动、受伤 ×2、弱点行灰显；**本回合剩余与下一整回合**后恢复满盾。
- 看破：`reveal(t,n)` 随机揭示 n 个未知弱点（`jinzhen`、`sniff`）。

## 5. 蓄势（BP）

- 初始 1，每回合 +1（投入过的那回合不加），上限 5；一次行动最多投入 3（`Q/E`、`←/→`、PageUp/PageDown 或面板 ＋/－）。
- 普攻：连击 `1+BP` 次，每击 pow 1。
- 伤害武学：有 `hits` 的多段武学段数 +BP（每段 pow 除以 √hits）；单段武学 pow ×(1+0.8·BP)。
- 治疗：×(1+0.5·BP)；定神持续 2+BP 回合；看破数 +1。
- 武学重数加成：`lvM = 1 + 0.15·(skLv-1)`，`skLv` 为 menu.js 折算的等效重数（1–4 重即重数本身；5 重起 +0.08/重，再乘火候与心法加成，见 04 §2.4 §3.3）。
- 武学熟练（工作流 X，menu.js 包一层 `doSkill/victory/layoutUnits/tickBuffs/foeAct`，不改本文件与 bfx/bui）：我方每次施展记 +1，削盾 +1，每次破势 +1；胜利后结算（败/逃 50%）并弹「精进」一屏；心法特性在开战（蓄势/定神/看破）、每名单位行动后（回复）、敌方出手后（免疫眩晕）生效。另包 `strike`（兵刃造诣：每 20 点该兵刃威力 +1%，≤10%，并记造诣）与 `hurt`（格挡：敌方出手时按 `u.block%` 伤害减半），目标设计见 design/growth-combat.md。

## 6. 伤害公式

我方 `strike()`：

```
dmg = atk*pow*(定神?1.3:1) - def*0.5
弱点 ×1.25；破防 ×2；暴击(概率 crit%) ×1.5；× rnd(.92,1.08)；取整，至少 1
```

敌方 `foeAct()`：

```
dmg = atk*pow*(多段?.65:1)*(全体?.85:1) - def*0.5
目标定神 ×0.8；防御中 ×0.5；× rnd(.9,1.1)；至少 1
单体攻击可被闪避：概率 dodge*0.6 %
```

状态：
- 眩晕：敌方 `coil`（缠绞）命中我方后按 `sk.stun||25`% 使其下一次行动跳过；我方 `shuaibei`（乞儿摔碑手）按 30% 取消目标本回合意图（`intent=null`）。
- 流血/毒：`lianhua`（莲花落）使目标 `bleedN=3`，该单位每次行动结束扣 6% 最大气血（显示「毒」）。

## 7. 我方指令（`allyTurn`）

| 指令 | 说明 |
|---|---|
| 攻击 | 选一个敌人，普攻（连击 1+BP） |
| 武学 | 列出单位武学；内力不足或 `needWeapon` 不匹配（如柳叶剑法需剑）置灰；按 `BSK.tgt` 选目标（`foes/allies` 为全体，`self` 直接施放） |
| 道具 | 列出行囊中有 `heal`/`mp` 的道具，对一名我方使用（消耗 `S.bag`），不消耗蓄势 |
| 防御 | 本回合受伤减半，下回合优先行动；不消耗蓄势 |
| 逃跑 | 非 boss/教学/noFlee 时出现；成功率 `clamp(55+(我方平均spd-敌方平均spd)*6,20,90)`% |

## 8. 敌人 AI（`planIntent` / `foeAct`）

- 意图在回合开始时公开：「招式 → 目标」「‼ 招式 · 全体」「蓄力中 · 下回合全体攻击」。
- 拥有 `ghost`（鬼头斩）的敌人：从第 2 回合起，未破防时以 30%（气血 <60% 时 50%）概率**蓄力**，下一次行动对全体施放鬼头斩；蓄力期间被破防会打断。
- 其他：从技能里随机一招（排除 ghost）。狼、以及会眩晕的招式优先打气血比例最低的目标（狼 40% 改随机）；其余随机目标。原目标已倒下则改打随机存活者。
- 头目（`opt.boss` 首敌，或精灵为 `chief`）：气血低于 50% 时每回合行动后**立即再规划并行动一次**。

## 9. 奖励、升级与战败

- 胜利 `victory()`：「胜」大字 → 累计所有敌人 `exp` 与 `silver`（教学战 exp ×0.5），`drops` 按百分比逐项掷骰；`while(S.exp>=S.lv*100)` 升级：`lv+1`、属性点 `pts+3`、气血内力回满。结算面板 `#bt-win`，点击或 Enter/空格/Z/Esc 继续。
- 失败：「败」。`noLose` 时 `S.hp` 至少 30% 并返回 `'lose'`；否则黑场旁白，回到羊太傅庙 `goScene('temple',[24,20.5])`，气血内力回满、**银两减半**，返回 `'lose'`。
- 逃跑成功：「脱身」，返回 `'flee'`。

## 11. UI 结构

- `battleCSS()` 注入 `<style id="battle-css">`（只注入一次）。
- `#bt`（960×540，按 `#game` 宽度 `transform: scale()` 适配），子节点：
  - `#bt-cards`：我方卡片（立绘/血条/内力条/BP 菱形 `.bt-pip`，当前行动者 `.cur`，被选 `.tgt`）
  - `#bt-hint`：说明/目标信息（含已知弱点）
  - `#bt-cmd`：指令菜单（`.hd` 标题、`.row` 行、`.ft` 蓄势控件）
  - `#bt-help`：操作提示
  - `#bt-win`：胜利结算（临时插入）
- 画布部分（`drawBattle`）：背景 + 地面线 → 单位（按 y 排序，冲刺/击退/受击闪白/破防倾斜变灰）→ 敌人盾行（盾值 + 弱点格 + 血条）与意图标签 → 目标箭头 → 粒子 → 破防闪光 → 浮字 → 暗角 → 顶部行动顺序条（`headChip` 头像，破防单位标「破」）→ 招式名横幅 → 大字（胜/败/脱身）。
- 精灵：敌人用 `c_{art}_r_0`（朝右），我方用 `c_{art}_l_0`（朝左），显示高度 `unitH(u)=150×ART.scale`（头目 ×1.12）。
- 音效：`bsfx(name,vol,rate)` → `window.__audio.sfx`（whoosh/select/blip/menu_close/advance/chime/coin）。


## 12. 交互优化（验证版）

- **特效与动作**：见 [vfx.md](vfx.md)。主角使用 `s_hero_battle` 动作表（待机呼吸/出招/连击/受击/运功），其余单位仍为静态帧。
- **残血条**：受击后白色残血段 0.4s 后缓慢回落（敌人盾行血条、我方卡片均有，`ghostTick()` / `syncCardGhost()`）。
- **伤害预估**：选择敌方目标时提示条显示「预计 N（×段数）」，命中已知弱点时显示闪烁的「弱点！」，同时该弱点格高亮并加 ▼（`B.pv` / `skillPv()` / `estDmg()`，与实际结算同公式，不含暴击与浮动）。
- **意图连线**：我方选指令时，每个敌人到其本回合目标画红色流动虚线（全体攻击更醒目）。
- **数字键**：菜单行前显示 1–9，按数字直接选中并确认。
- **伤害数字**：纯数字浮字改为弹跳出现（首 70ms 放大 1.4 倍）。
- **指令菜单位置**：固定在我方最左单位左侧，不再遮挡主角。
