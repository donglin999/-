# 战斗系统（js/battle.js）

状态：现行　最后核对：2026-10-19

> 当前表现规则（2026-10-14用户明确）：[普通攻击可以接触敌人，功法原位施放、由目标处特效命中](design/combat-presentation-boundary.md)。不以角色冲刺、复杂兵器接触或普攻轨迹完成技能命中。

横版回合制，歧路旅人（Octopath Traveler）式：**护盾 / 弱点 / 破防（BREAK）** + **蓄势（BP）**。敌人在左、我方在右，顶部行动顺序条同时预告本回合与下回合。

## 1. API

```js
const r = await battle({
  foes:[mk('bandit'), mk('wolf'), {name:'老僧',sp:'c_monk',lv:3,st:{…},skills:{palm_m:1},h:170}],
  bg:'bg_street',     // 背景资源键；缺省 'bg_'+S.scene，未加载则 loadOpt 动态加载，仍缺则用模糊的场景地图
  boss:true,          // 首个敌人为头目（居中大号、半血后预告并于下回合起进入二阶段：每回合行动两次），不可逃跑
  noLose:true,        // 战败不回庙：气血至少回到 30%，由调用方处理 'lose'
  tutorial:true,      // 教学：三段说明、不带同伴、经验减半、不可逃跑
  noFlee:true,        // 禁止逃跑
  intro:'铁臂帮打手围了上来！'   // 开场旁白：字符串/字符串数组/async 函数
});
// r === 'win' | 'lose' | 'flee'
```

流程：`battleDom()` 建 `#bt` → 预载背景与同伴立绘 → `fade` 中 `mode='battle'`、隐藏 HUD/提示/触屏键，构造单位与站位 → intro/教学 → `battleLoop()` → 结算 → `fade` 回到原 mode（`map`/`battle` 回落为 `scene`）→ `hud()`。

结算：主角 `S.hp/S.mp` 从战斗单位写回（hp 至少 1）。同伴的气血内力**不持久化**，每战满状态开始。

> `battleLoop()` 抛异常时中止结算，恢复入场气血、内力与背包，清理操作并抛出错误，不发奖励。

## 2. 单位构造

| 单位 | 来源 |

## 3. 回合流程（`battleLoop`）

每回合：
1. `round++`。所有存活单位的层数类异常（中毒、流血、内伤）各 −1 层。我方存活单位：若 `round>1`、上回合未投入蓄势且不在惊惧中，`bp+1`（上限 5）。
2. 破势到期（`round > brokenUntil`）的敌人恢复、回满护盾并记 `recoverRound`；头目恢复时清除控制类异常（封穴、眩晕、心乱、惊惧）。
3. 头目久战：第 10 回合起未破势的头目 `enrage+1`（伤害每层 +20%），第 9 回合飘字并在意图上预告。随后 `phaseTick()`：已预告二阶段且到期的头目进入二阶段（护盾上限与当前护盾 +2、换掉一项弱点，2026-10-08）。
4. 行动顺序 `calcOrder()`：按 `spd + 抖动 rnd(0,3)` 降序；本回合破势恢复的敌人 +1000 排最前，`prio`（上回合防御）+100，迟滞 −3；`calcOrder(true)` 预告下回合（本回合末将恢复的敌人排最前）。
5. 所有敌人 `planIntent()` 预定本回合意图（眩晕显示“无法行动”，封穴只出单体普攻 ×0.8，封穴/惊惧不蓄力）。
6. 依序行动（每个行动 `B.actSeq+1`，用于每次行动的削盾上限与多段合计）：敌人破势或眩晕则跳过；我方单位 `defend`、`guard` 清零，眩晕则跳过，否则 `allyTurn()`。每个单位行动后 `tickBuffs(u,acted)`：定神倒计时、下一击增伤消耗、v3 招式冷却与绝招调息 −1（`BattleRules.cdTick`）；实际行动过才结算中毒/流血与计次异常；随后 `phaseCheck()` 检查头目是否跌破半血（是则横幅预告“下回合起进入二阶段”）。我方行动前记 `wasDefend`（上次主动防御，供“一线开晴”等条件），并清除该单位给同伴的援护。任一时刻一方全灭即结束。

## 4. 护盾 / 弱点 / 破防

- 类型（2026-10-08 起，见 design/weakness-system.md §3.1）：6 兵器类 `剑 刀 长兵 音律 暗器 拳掌` + 6 属性 `炎 寒 雷 风 阳 阴`（`WTYPES` 即弱点格固定顺序，颜色 `WCOL`）。出手类型由 `hitTypes()` 决定：目录招式（`MOVE_RULES`，由 catalog.json / lineage-v3-moves.json 导出，`jinzhen` 按同名 `bh_s1`）读 `weak_class`/`element`；其余按旧 `kind`/`BSK.t` 换算（拳掌腿→拳掌，剑→剑，刀锤→刀，棍鞭伞→长兵，暗器扇→暗器，琴笛→音律），`BSK.e` 的阳阴雷沿用为属性，旧“毒”改为施加中毒 40%。`BSK.t` 本身保留旧兵刃名（兵刃造诣、特效仍按它）。
- 每段 `strike()` 命中弱点（兵器类或属性任一）：伤害 ×1.25，揭示命中的那一项；未破势且盾 >0 时**盾 −1**，每次行动对每个目标最多 −6（`BattleRules.shieldLeft`）；v3 招式另受本档 `shield_cap` 约束，`extra_shield_damage` 在命中弱点时每次行动对该目标附加一次（同受上限）；盾格上方弹“盾 −N”。
- 盾归零 → `doBreak()`：`broken=true`，`brokenUntil=round+1`，取消蓄力与意图。破势期间：不能行动、受伤 ×1.5（打碎最后一盾的那段按未破势结算）、异常必中且 +1；**本回合剩余与下一整回合**后恢复满盾，恢复的那一回合最先行动。
- 看破：`reveal(t,n)` 随机揭示 n 个未知弱点（`jinzhen`、`sniff`，以及 v3 带 `reveal` 的招式）。

## 5. 蓄势（BP）

- 初始 1，每回合 +1（投入过的那回合不加），上限 5；一次行动最多投入 3（`Q/E`、`←/→`、PageUp/PageDown 或面板 ＋/－）。
- 普攻：连击 `1+BP` 次，每击 pow 1。
- 伤害武学：有 `hits` 的多段武学段数 +BP（每段 pow 除以 √hits）；单段武学 pow ×(1+0.8·BP)。
- 治疗：×(1+0.5·BP)；定神持续 2+BP 回合；看破数 +1。
- **v3 招式（2026-10-08，`BSK.v3`，见 design/runtime-moves.md）**：不用上面两条旧公式，按合同 `BSK.bp[BP]=[总威力,段数,削盾上限,治疗倍率]`；总威力按段均分（`hit_weights` 不均时按权重），重数加成 `1+0.04·(重数−1)`；治疗 = 目标最大气血 × `heal` × 重数 × 治疗倍率，单次封顶 35%；绝级只有 3BP 档可用，施放后下一次自身行动不能再用任何绝级；`cd` 冷却按自身行动计。
- 武学重数加成：`lvM = 1 + 0.15·(skLv-1)`，`skLv` 为 menu.js 折算的等效重数（1–4 重即重数本身；5 重起 +0.08/重，再乘火候与心法加成，见 04 §2.4 §3.3）。
- 武学熟练（工作流 X，menu.js 包一层 `doSkill/victory/layoutUnits/tickBuffs/foeAct`，不改本文件与 bfx/bui）：我方每次施展记 +1，削盾 +1，每次破势 +1；胜利后结算（败/逃 50%）并弹「精进」一屏；心法特性在开战（蓄势/定神/看破）、每名单位行动后（回复）、敌方出手后（免疫眩晕）生效。另包 `strike`（兵刃造诣：每 20 点该兵刃威力 +1%，≤10%，并记造诣）与 `hurt`（格挡：敌方出手时按 `u.block%` 伤害减半），目标设计见 design/growth-combat.md。

## 6. 伤害公式

我方 `strike()`：

```
dmg = (atk*pow*(定神?1.3:1) - def*0.5) × share     （share：v3 招式本段份额，旧招式 1）
v3 条件倍率（已看破目标、上次防御、消耗守势、末段加成等，BattleRules.segMul）；弱点 ×1.25；破势 ×1.5；防御强化“下一击” ×(1+nextAtk)；暴击(概率 crit%) ×1.5；× rnd(.92,1.08)；取整，至少 1
我方目眩：每段 25% 落空（不削盾）；我方心乱：单体出手 40% 改打随机单位
```

敌方 `foeAct()`：

```
dmg = atk*pow*(多段?.65:1)*(全体?.85:1) - def*0.5
× 封穴 0.8 × 内伤 (1−0.08/层) × 惊惧 0.85 × 头目二阶段 0.6（每回合两次） × v3 削弱下一击 (1−atkDown，头目折半) × 头目久战 (1+0.2·enrage)
目标定神 ×0.8；防御中 ×0.5；v3 暴露 ×(1+expose)（一次）；援护者 ×0.7；防御强化／v3 卸力 ×(1−unload)（只卸下一次）；× rnd(.9,1.1)；至少 1
单体攻击若目标被援护（`u.cover`），改打援护者（`BattleRules.coverOf`）；濒危保护（一息相续）致命伤留 1 点（`BattleRules.guardDeath`）
敌方目眩：25% 整次落空；敌方心乱：40% 改打其他敌人；防御强化反击：下次行动前第一次被单体命中后反击
单体攻击可被闪避：概率 dodge*0.6 %
```

异常状态（2026-10-08 起，规则见 design/status-effects.md，实现 `BattleRules`）：
- 单位上的统一表 `u.ail = {异常: {n 层数 | left 剩余次数}}`，免疫计时 `u.ailImm`；旧字段 `u.stun`、`u.bleedN` 改为访问器（读写眩晕 / 流血），旧调用不报错。
- 成功率 = 基础率 + 每 BP 10% − 抗性（普通 0、精英 15%、头目 30%；我方 0），5%–100%；目标破势中必中且层数/时长 +1；头目免疫眩晕、封穴只在破势时可施加、惊惧时长减半；精英与头目被眩晕/封穴/心乱后 2 回合同类免疫；任何单位眩晕结束后 2 回合免疫眩晕。
- 来源：目录招式 `apply_status`（每段或首个落地段）；旧招式 `BSK.e==='毒'` → 中毒 40%、`BSK.stun` → 眩晕 `sk.stun`%；敌人模板 `inflict:[{on:'single'|'group'|'charge'|'any',status,chance,stacks}]`（山贼目眩、狼流血、巨蟒中毒、寨主全体惊惧），缠绞仍按 25% 眩晕。
- 解除：`BattleRules.cleanse(u,'low'|'mid'|'all')`；带 `cleanse_tier` 的目录治疗招式治疗后按层级解除；内功“清秽/忘虑”解除流血与眩晕。
- 防御强化（usage=defend_enhance，martial-structure.md）：装配后不进武学列表；选“防御”时自动附带效果最高一招的卸力、反击、守势、下一击增伤，不耗内力。

## 7. 我方指令（`allyTurn`）

| 指令 | 说明 |
|---|---|
| 攻击 | 选一个敌人，普攻（连击 1+BP） |
| 武学 | 列出单位武学；内力不足或 `needWeapon` 与所持兵器的兵器类不符（`weaponFits`，如柳叶剑法需剑类）置灰；按 `BSK.tgt` 选目标（`foes/allies` 为全体，`self` 直接施放） |
| 道具 | 列出行囊中有 `heal`/`mp` 的道具，对一名我方使用（消耗 `S.bag`），不消耗蓄势 |
| 防御 | 本回合受伤减半，下回合优先行动；不消耗蓄势 |
| 逃跑 | 非 boss/教学/noFlee 时出现；成功率 `clamp(55+(我方平均spd-敌方平均spd)*6,20,90)`% |

## 8. 敌人 AI（`planIntent` / `foeAct`）

- 意图在回合开始时公开：「招式 → 目标」「‼ 招式 · 全体」「蓄力中 · 下回合全体攻击」。
- 拥有 `ghost`（鬼头斩）的敌人：从第 2 回合起，未破防时以 30%（气血 <60% 时 50%）概率**蓄力**，下一次行动对全体施放鬼头斩；蓄力期间被破防会打断。
- 其他：从技能里随机一招（排除 ghost）。狼、以及会眩晕的招式优先打气血比例最低的目标（狼 40% 改随机）；其余随机目标。原目标已倒下则改打随机存活者。
- 头目（`opt.boss` 首敌，或精灵为 `chief`）：~~气血低于 50% 时每回合行动后立即再规划并行动一次~~ → **2026-10-08 起改为二阶段**：跌破 50% 时横幅预告“下回合起进入二阶段”并写进意图栏；下回合起每回合行动后再规划并行动一次（每次伤害 ×0.6），进入时护盾 +2、换一项弱点；与久战发狠并存（design/weakness-system.md 第 4 节第 4 项）。
- 精英：`FOE_DEF.snake`（青鳞巨蟒，`mk('snake')` 经精灵键 `snake` 取到）为 `rank:'elite'`：异常抗性 15%，眩晕／封穴／心乱后 2 回合同类免疫；目标说明行显示【精英】／【头目】。

## 9. 奖励、升级与战败

- 胜利 `victory()`：「胜」大字 → 累计所有敌人 `exp` 与 `silver`（教学战 exp ×0.5），`drops` 按百分比逐项掷骰；`while(S.exp>=S.lv*100)` 升级：`lv+1`、属性点 `pts+3`、气血内力回满。结算面板 `#bt-win`，点击或 Enter/空格/Z/Esc 继续。
- 失败：「败」。`noLose` 时 `S.hp` 至少 30% 并返回 `'lose'`；否则黑场旁白，回到羊太傅庙 `goScene('temple',[24,20.5])`，气血内力回满、**银两减半**，返回 `'lose'`。
- 逃跑成功：「脱身」，返回 `'flee'`。

## 11. UI 结构

- `battleCSS()` 注入 `<style id="battle-css">`（只注入一次）。
- `#bt`（960×540，按 `#game` 宽度 `transform: scale()` 适配），子节点：
  - `#bt-cards`：我方卡片（立绘/血条/内力条/BP 菱形 `.bt-pip`，当前行动者 `.cur`，被选 `.tgt`）
  - `#bt-hint`：说明/目标信息（含已知弱点）
  - `#bt-cmd`：指令菜单（`.hd` 标题、`.row` 行、`.ft` 蓄势控件）
  - `#bt-help`：操作提示
  - `#bt-win`：胜利结算（临时插入）
- 画布部分（`drawBattle`）：背景 + 地面线 → 单位（按 y 排序，冲刺/击退/受击闪白/破防倾斜变灰）→ 敌人盾行（盾值 + 弱点格 + 血条）与意图标签 → 目标箭头 → 粒子 → 破防闪光 → 浮字 → 暗角 → 顶部行动顺序条（`headChip` 头像，破防单位标「破」）→ 招式名横幅 → 大字（胜/败/脱身）。
- 精灵：敌人用 `c_{art}_r_0`（朝右），我方用 `c_{art}_l_0`（朝左），显示高度 `unitH(u)=150×ART.scale`（头目 ×1.12）。
- 音效：`bsfx(name,vol,rate)` → `window.__audio.sfx`（whoosh/select/blip/menu_close/advance/chime/coin）。


## 12. 交互优化（验证版）

- **特效与动作**：见 [vfx.md](archive/vfx.md)。主角使用 `s_hero_battle` 动作表（待机呼吸/出招/连击/受击/运功），其余单位仍为静态帧。
- **残血条**：受击后白色残血段 0.4s 后缓慢回落（敌人盾行血条、我方卡片均有，`ghostTick()` / `syncCardGhost()`）。
- **伤害预估**：选择敌方目标时提示条显示「预计 N（×段数）」，命中已知弱点时显示闪烁的「弱点！」，同时该弱点格高亮并加 ▼（`B.pv` / `skillPv()` / `estDmg()`，与实际结算同公式，不含暴击与浮动）。
- **意图连线**：我方选指令时，每个敌人到其本回合目标画红色流动虚线（全体攻击更醒目）。
