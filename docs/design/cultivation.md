# 三年休闲培养

状态：**设计方案**。体验参照《侠客风云传》[官方介绍的养成与大地图交替](https://wulin.fhyx.com/news/150703/45.html)：玩家在周砚山居选择每回合要做的事，见到人物关系和本领成长，再被阶段性事件带出据点。这里定义本作自己的规则，不照搬原作数值。剧情时间见[三年事件表](timeline.md)。

## 回合结构

三年共 **36 个“月”回合**，每月按“来信／季节事件 → 选择活动 → 结果与夜谈 → 月末结算”推进。每月有 **3 个活动格**，共 108 个可分配机会；夜谈一次为独立机会。可以提前结束本月，未用活动格不累积。季节主线和必须发生的角色决定不扣活动格。

| 环节 | 玩家实际要做什么 | 系统要反馈什么 |
| --- | --- | --- |
| 月初 | 查看季节、来信、可赴之约、人物所在地 | 期限、所需条件与替代路线清楚可见 |
| 活动 | 在山居或已开放地点选 3 次训练、劳作、交游、调查、外出、休息 | 立即显示能力、资源、关系或线索变化 |
| 夜谈 | 从在场或可通信的人物中选择一次谈话；也可不谈 | 新认知、关系回响或下月邀约，不是主线强制钥匙 |
| 月末 | 结算伤病、收入支出、队友动态和下月预告 | 告知下一锚点及将到期的事件 |

## 活动模块

| 活动 | 主要收益 | 代价与故事用途 |
| --- | --- | --- |
| 练武 | 基础身法、兵刃熟练、实战动作；导师或同伴教学 | 消耗体力；多练可专精，不能一月学成绝学 |
| 读书／研习 | 武学常识、医理、辨药、线索理解 | 需要书或请教对象；先认识术语再深入 |
| 医案／采药 | 医术、药材、患者关系；叶蘅和苏芷有不同观点 | 病人不会无限刷出；关键救治有兜底药材与协作方案 |
| 劳作／技艺 | 银两、食材、器具、烹饪、修补等 | 作为休闲节奏与角色交流，不强迫靠打工刷通主线 |
| 交游／闲逛 | 见人物、得传闻、开放约会或友谊事件 | 有所在地与时间窗，错过记录后果 |
| 外出／调查 | 小地图事件、战斗、物证、势力接触 | 大事件可暂停本月活动流程，归来接续 |
| 休息 | 恢复伤病与心情，触发安静的生活片段 | 永远可选，不因休息导致必败或不可逆卡关 |

## 成长与压力

- 主角有武艺、体力、医理、生活技艺和人际理解等发展方向；**事件解法允许能力、道具、同伴代行、花费或剧情保底中的至少两条路径**。具体成长来源见[成长与战斗](growth-combat.md)。
- 过量练习会疲惫，休息、膳食和医治可恢复；疲惫影响效率，不永久废掉角色。每季有推荐水平提示，低于推荐时开放补课、借器具或队友协助。
- 叶蘅选择白鹇谷后有驻谷学习与季节性回访，山居月份可收她的信、准备药材或响应医案；她留山居则在药圃和野外更常同场。两线都不能在数月内无理由断联。
- 角色关系按“相识—互信—重大选择”推进。医案、争论、共同劳作都可推动关系；结缘是可选方向，友情同样有完整互动和共同结局。

## 信息设计与防卡关

界面始终显示年月、3 格活动、夜谈机会、未完成邀约和关键任务的下一步。锁定选项说明缺什么、何时能补；错过限时事件写明后果。必达主线不以“某日闲逛某处”暗触发。可重复日常提供变化文本或摘要跳过，避免 36 回合内容变成重复点击。

旧十二日里“每天两格、晚上聊天”的结构仅是设计来源；新权威规则是 36 月 × 3 格，剧情和数值要按这一规则重新算，不能把旧日号直接乘成三年。
