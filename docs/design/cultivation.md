## 时间和体力

三年共 **36 个月**，每月依次为**月初、上旬、中旬、下旬、月底**，共 **180 个日历时段**，作为各路线当前的共用时间基准。普通据点月份按时段安排活动；大地图月份整体占用其中五个时段，改为独立探索阶段。月份仍承载季节与剧情窗口，五时段沿用原作的游戏日历称呼，不要求对应真实的等长日期。后期分叉沿用已走过的日历，不重新开始一套三年培养。

36 个月只描述当前养成阶段，不限制全作的后续时间；培养结束后的游历节奏另行设计。

每个普通自由时段开始时获得 **12 点养成体力**，不同活动扣不同点数。一次活动完成后留在当前时段，玩家可以继续安排，只要剩余体力足够。不设固定活动次数；在成本不变的情况下，一期可以练武两次，也可以做六次打杂。

**休息结束当前时段，进入下一时段后恢复到 12 点。** 剩余体力不累积；留有体力结束可改善心情，余力≥3点加3心情，余1—2点加1，用完不加。体力耗尽或不足以做想选的活动时，玩家可以休息推进。休息不能在同一时段补满体力并继续无限培养。

养成体力用于分配日常投入，与战斗气血、内力分开。先保持每期固定 12 点，不额外引入可无限回复的养成体力药或按武功等级膨胀的体力上限。

## 正式事件和普通对话

普通走动、查看近况与短闲谈免费。会改变人物事件进度、提供正式培养收益或展开重要关系情节的互动，归入体力活动；开始前显示成本。

**取消独立的每月夜谈配额。** 人物长谈归入当前据点的闲逛事件，消耗包含在本次人物活动费用中。山居线例如与周砚长谈、陪叶蘅整理心事；其他路线由各自人物事件池提供。月末可自动播放简短的生活收尾，不额外赠送一个完整人物事件。

一次活动所包含的对白、小游戏或战斗不再次扣同类活动体力。例如闲逛中同意切磋，已付本项费用就演出这段事件；不能又扣 5 点练功。活动开始前取消不扣体力，正式经历开始后按结果结算。

## 日历剧情和外出

| 类型 | 时间与结算 |
| --- | --- |
| 简短来信、来客通知、季节近况 | 回合开始或结束时呈现，通常不占整期，也不产生可重复培养收益 |
| 人物与地方支线 | 在日期窗口内选择地点闲逛，按具体活动费用进入事件；学艺、生产中的事件随对应活动结算 |
| 短篇主线、节会或指定路线的短外出 | 预告占用的具体时段；占整期时该期不再发放 12 点自由活动体力 |
| 大地图自由历练 | **每次占完整一个月、五个日历时段**，该月切换为可自由探索的地图；不发据点五期合计 50 点体力 |
| 已占期剧情或大地图内的战斗与事件 | 在对应阶段内结算，不按每场战斗再扣据点养成体力；整月历练于下月月初返回当前路线指定的据点 |

大地图月份拟在月初出发，下月月初返回当前路线指定的据点；出发前已完成的准备属于前一个月。提早结束探索仍结算完整一月，途中的驻留与休息不重新开启据点体力循环。地图内可以选择走访、任务、交易、采集和战斗，成长来源改为实际历练成果；地图内部的行程时间与重复活动收益另行细化。

大地图内完成的主线包含在这一月中，不再额外扣一次主线时段。必要通知照常到达；当前据点的人物事件依据离居状态改为通信、返程承接或提前提示截止日期，不因模式切换而无提示失效。若地图中发生正式转线，返程地点依据新分支安排，不强制回到周砚山居。

三年 180 个日历时段中，有些被整月大地图与独立短篇剧情占用。因此 2160 点只是全部时段都自由时的预算上限。**山居线示例**暂排六个月大地图、另留九个短篇剧情时段，余下 141 个自由时段、最多 1412 点体力；该数字不作为魔教、朝廷及后期分支的固定预算。详细示例见[主线占期预留](timeline.md#主线占期预留)，通用计算与分叉承接见[路线框架](cultivation-routes.md#各路线的时间预算)。

## 心情和成长

保留原作心情影响培养收益的思路：活动偏好、人物事件和留余力休息会影响心情。体力负责能做多少事，心情负责做事的状态；武学理解、相关能力与导师指导共同影响成长。本轮不照搬未经核实的经验公式，也不新增一套必须不断清除的疲劳条。

基本功、招式、技艺与人物关系各有明确来源。学艺、关系和事件可以开放新的武功，生产补充外出所需，打杂提供低成本的共同生活途径。导师与基础教学逐步出现，不能在一月内无理由学成家传绝学。

叶蘅按自己的医案与路线成长。共同活动可以同时留下二人的成长与关系记录，但不另外让玩家管理一套同样的体力循环。白鹇谷路线通过通信、季节回访与大地图期间的赴谷访问保持联系，远行不算一次山居闲逛；山居路线有更多同场事件。两线都由她明确决定（决定时点原写在汉皋事件后，汉皋剧情已作废，待重新设计），后续同行与否读取她的学习安排和意愿。

## 事件触发和信息

闲逛采用**当前培养路线、身份权限、日期窗口、地点、前置经历、能力、关系、分支选择与人物所在地**共同筛选的事件池。公共事件共享事实和结果，各路线提供不同入口与处理方法；专属事件读取本路线或分支。保留偶遇与探索感，主线来信、必要线索与重大决定按日历明确出现。支线可错过并产生回响；每条可玩路线的主线至少提供不依赖隐藏高技艺的推进方法。

据点界面重点显示当前据点与身份、年、月、当前时段、体力 0—12、心情、活动成本与本月传闻或邀约；大地图界面显示历练月份、返程日期与目的地、可达地点与当前任务。重复训练提供稳定收益和摘要，新事件完整演出；免费闲谈、已领取物品和同一成果不重复给培养奖励。
