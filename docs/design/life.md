# 生活、资源与外出

状态：现行　最后核对：2026-10-19（原记：**设计方案；生活技能暂缓上线，当前版本关闭**。生活技能的传授、重复练习与场景动作见[生活技能规范](life-skills.md)。配合[三年培养](cultivation.md)使用。地图中的宝箱、衣柜、木桶、固定奖励及淡蓝提示按[探索容器规范](exploration-containers.md)维护。）

山居的日常资源包括食物、药材、银两、书册、器具和人情。每月有基础生活保障，劳作、行医或委托能改善资源，不让不做打工的玩家在主线前饿死。休息可以恢复疲惫；受伤严重时有医治、付费求诊或同伴协助路线。

下表是当前山居及周边内容示例；[路线框架](cultivation-routes.md)同时为归烬堂、巡江司预留自己的驻地、保障来源与组织职责，具体内容以后另写。未来分叉保留实际持有资源，组织提供的权限与支持依据身份变化另行处理，不能把离开据点写成背包、证据和关系全部清空。

| 场所 | 可做的事 | 作用 |
| --- | --- | --- |
| 山居练武场、书案 | 练招、研习、与周砚或来客切磋 | 安全积累基础能力与人物关系 |
| 药圃、厨房、工位 | 采药、配普通药、做饭、修补 | 资源循环和生活事件，不提供无限神药 |
| 城市街市（[汉皋城](hangao-city.md)；旧襄阳街市已撤除） | 买卖、问讯、诊病、帮工 | 城中事件及后续人际网络 |
| 村址与安置点 | 回访、救治、核实旧证言 | 让村祸有长期后果，不只作为开篇背景 |
| 渡口、山路、白鹇谷 | 外出历练、通信、探访与门派医案 | 根据季节、同行者与线索开放 |

任务设计把“主线必需”“个人事件”“地方支线”分开。地方支线错过或失败有后果与回响；主线只要求玩家理解下一步，至少有一种无需特定隐藏技艺的推进方式。银两与药材紧缺可改变做法，但不能把续脉散当万能补给或现实处方。
