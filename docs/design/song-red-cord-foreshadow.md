## 一、红绳的特殊手艺：燎头死结（第十三轮第 1、2 条定）

| | 定稿方案「燎头死结」 |
| --- | --- |
| 是什么 | 结打成死结，**两个绳头用火燎成两颗黑疙瘩** |
| 一句话认出 | “两个绳头燎成了黑疙瘩。” |
| 作者层来历（不进剧本） | 裴嵩年轻时在正道盟本部掌过卷宗封存。封卷的绳要打死结、燎头——拆过就系不回去，一看便知有人动过。本部早就改用火漆封条，这手法没人再学；他一直改不掉，连系玉的绳也这样收尾。和他“手习惯压住文书”“以程序施压”是一类习惯 |
| 为什么只有他 | 一门已经没人用的旧封卷手法＋他个人的习惯，两条都对得上他的真身 |
| 会不会破 F-0004 | 不会：萧白只觉得“没见过这么收绳头的”，没人知道这是封卷的手法 |
| 好不好画 | CG 特写清楚（红绳＋两颗黑点）；对话立绘、像素精灵上看不清，靠台词与 CG |
| 和现有东西撞不撞 | 已查：全作装备与剧情里没有“燎头”的绳；厌胜钱的如意结、笛尾军中红绳都不燎头 |
| 揭开时怎么用 | 裴嵩真身出面，系玉的红绳绳头是燎黑的；他递来封存的文书，封绳同样燎头。萧白当场认出；在场的正道盟中人（如徐令仪）可以接一句“裴执事封卷，向来燎头”，把手艺落到他一个人身上 |

原方案二「红里绞黑」、方案三「八字锁缆结」不采用。

## 二、谁看得到：开启支线就看到（第十三轮第 3、4 条）

- **在哪一场**：只在竹匾那场（C1-00B，`风起-竹匾.ink`）给一次（第 3 条）。这是萧白唯一一次近看他的领口。
- **怎么看到**：**不加选项、不加交互点**。竹匾那场散场时，萧白心里话自动说出燎头的特征，再一句宋先生察觉、把绳塞回领子。三支（答应、问过再答应、不掺和）都播。
- **“开启支线”怎么算**：玩过竹匾那场（在倒木旁见过宋先生）就算开启。不掺和的那一支也见过他、也看到了这个结，后面揭开那场一样能回扣。**这是按第 4 条原话的理解**：若用户说的“开启”只指答应了托付，只要把拒绝那支的两句心里话去掉，其余不变（列第六节第 2 条）。
- **不另记标记**：看到燎头结的玩家正好就是玩过竹匾的玩家，已有的 `qiheChapter.records.stranger_deal`（不是“未见”就是见过）就能判断，不新增 `seen_cord_knot`。上一稿提的这个标记撤掉。
- **不给第二次机会**：C1-S1、C1-S2 里绳子一直在领子里，不再露出来；C1-S2 那句“他领口那根红绳底下，好像也坠着这么一块”说的是玉，不是结，照旧。
- **支线没开的玩家**：没见过宋先生，后面本来就没有红绳——C1-10 倒木那场只给答应过的播；揭开那场不出红绳回扣，按那场剧本的基线认人。

### 8.1 上两版的毛病

v1、v2 都只画了“树皮＋木缝＋一截绳”：画面里没有人来过的痕迹，绳子跟树皮的纹理、青苔混在一起，看着像藤、像长出来的东西。玩家看不出三件事：**这里有人天天坐**、**人今天没来**、**绳是他特意摆给来人看的**。

### 8.2 这截绳怎么会在那里（画面要讲的事）

只讲玩家看得见的，作者层的来历不画、不写进剧本。（第三版原写“封了”的记号，第四版已撤。）

1. **他天天坐的位置**：竹匾、回话一、回话二三场他都在同一段倒木上（坐着翻账、站着等）。这一段树皮被坐得**磨光、青苔蹭掉**，前面的**草被踩平、露出泥**——一眼就是“座位”。
2. **他今早来过又走了**：座位上**空着**，账簿、包袱都不在（对上 C1-10-01）；座位旁一小撮**熄灭的炭灰和半截烧黑的细枝**——燎绳头生过一点小火，灰还新。这是“绳头为什么是黑的”在画面里的交代，玩家不用读字。
3. **绳是解下来、再特意系上的**：只有一截细红绳，死结完整、两头燎黑，**没有玉**（玉被取走了）。它不是缠在树上，而是系在一件**人放上去的东西**上：
   - 方案甲、丙：座位旁木缝里**竖插一根新削的细竹签**（干净浅黄、一掌长、无字），绳在竹签上绕一圈打死结——竹签是人削的、人插的，绳因此不可能是“长出来的”。仍是“木缝里”，和 C1-10-01、F-0027 的说法一致。
   - 方案乙：座位上一块**扁平河石**（压账页用的镇纸石），压着一圈闭合的绳，只把带结的一段摆在石边；石旁苔藓上一个**长方形压痕**（册子放久了的印）。
4. **朝着来人**：结和两个黑头都朝萧白上山来的方向，放在晨光落到的地方——“留给谁看的”。
5. **清晨**：剧本是“明早还在这儿”的那个早上。薄雾、露水、低角度晨光，整体清冷，只有绳和座位带一点暖光。

### 8.3 不出现的东西（F-0004、F-0027）

不画人、手、账簿、纸张、文字、印章、钱币、玉、算珠（萧白手里那串是另一个疑点，不在这里重复）、包袱、兵器、鞋印细节。竹签、平石都是无字的寻常东西，指认不了身份；炭灰只交代“燎过”，不交代谁。

### 9.1 这截绳是怎么落下的（按逻辑想清楚）

1. 他平时把玉系在一根闭合的细红绳上，绳的两头打成死结、燎成两颗黑疙瘩（第一节）。死结就在玉的那一头。

3. 绳被座位边裂缝里翘起的一根干木刺勾住，他一起身就扯断了。**断在死结旁边**：燎过的地方最脆。闭合的绳圈断开成一根单股长条——**一头是完整的死结和两颗燎黑疙瘩，一头是硬扯断的毛茬**（丝线散开、起毛、不焦）。

5. 所以画面上：**一截散开的红绳中段搭在木刺上，一小段卡进木缝，带死结的那头短短地垂着，扯断的那头长长地顺着树皮垂下去**。
