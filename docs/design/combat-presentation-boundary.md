# 当前战斗表现边界：普攻接触，功法特效命中

状态：现行　最后核对：2026-10-19

2026-10-14用户再次明确的现阶段规则。适用于当前8792全部战斗与剧情旁观战，优先于此前角色动作合同中的复杂功法动作要求；并非永久取消后续动作规划。

## 普通攻击

近战普攻可以接近目标，以角色身体、持器手和实体兵器完成接触，随后回到原站位；已有普通棍连击、剑击、拳脚和动物扑咬继续按普通攻击合同执行。远程普攻可以使用已有投射出手与飞行表现。BP普攻接续仍按普通攻击规则。

## 功法与招式

当前功法由特效在敌方或友方目标处形成命中/生效反馈。施者留在自己的战斗站位，只允许已有的简短运功、抬手、持器蓄势或待机姿态；不冲到敌人面前，不使用复杂挥砍、突刺、横扫、连打或实体兵器接触目标的动画来完成技能命中。

- 功法命中时间由招式/特效合同控制，不能依赖普攻兵器接触帧或`playAttackPose`。
- 多段、群攻、伤害、削盾、消耗和状态仍逐项依真实规则结算；角色动作简化不改变技能数值。
- 技能和普攻必须明确分类，不能按0内力、兵器类型或单体/群体判定它是不是普攻。
- 未制作专属特效时，保留简短施放姿态、真实伤害/状态文字及已有普通受击反馈，明确记录缺失；不靠近身角色攻击补位，不新建通用光效冒充完成。
- 甲级与绝级的现阶段复杂度体现在特效的主形、轨迹、节奏与目标反馈；不要求施者同步制作高阶接触动作族。
- 本轮继续遵守用户“不要自行生成特效”的限制；只更新设计描述和已有播放器行为。

## 文档与实现验收

角色动作合同中的普攻部分仍有效，复杂招牌身体动作表标为后续候选，不作为当前开发或验收必需项。战斗精灵仍保留待机、普攻、受击、运功、破势、倒地、胜利等基础状态。

技能验收检查施者从起手到命中、收势始终保持原站位，动画只用简短`cast`/`idle`，没有`dashTo`、`hopBack`、`lunge`、`stepFwd`、武器接触或普攻投射释放调用；普通攻击仍检查真实移动/接触/投射。

开始部分双甲级群攻以此为准：徐令仪与岑霜在各自原位施放，两次群攻各对敌方全体结算一段；缺失特效的描述沿用原数值、颜色与时点，角色复杂收柄/蓄鞭/横掠/回带动作不再作为技能播放。
