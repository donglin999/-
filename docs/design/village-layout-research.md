# 栖河村重设计：市场案例与生活空间

状态：现行　最后核对：2026-10-19

日期：2026-10-03。状态：设计调研与新方案，旧村落整体设计已被用户退回。原有脚宽、碰撞与尺寸测试仅保留实际测试事实，不代表生活布置与村落体验合格。此页的具体尺寸是项目提案，不是案例原作参数。

## 1. 本次失败在哪里

现有襄阳规划已经要求先做活动与功能布局，本章实施又退回到四栋矩形房屋加围墙、再在空白地放道具。给物体写一句reason没有改变画面：院外衣篮不属于可读的洗晒区，屋前木箱没有搬运/储放关系，柴在另一岸缺少干燥与运输依据，树脚落在水岸与房基之间。家具也未纳入成人比例量尺：市场桌80px宽，源桌380px宽，桌面下约108px的腿缩成约23px，不能担当正常站立工作台。

## 2. 一手案例与核查范围

### 八方旅人II：固定镜头下看得见的目标

[Square Enix / Acquire开发者采访，Unreal官方](https://www.unrealengine.com/developer-interviews/octopath-traveler-ii-builds-a-bigger-bolder-world-in-its-stunning-hd-2d-style)：在地图探索问题中，团队说明固定镜头下希望玩家感兴趣的目的地能在一屏出现；地图分辨率与人物/背景协调也需共同考虑。

项目推论：桥头画面露出药棚识别物，下一处任务地点随道路转折揭示。家具和人物必须同倍率比较。文章没有给出本项目桌高或村路宽度。

### CDPR：先设计功能，再验证可玩空间

[CDPR AnsweRED Episode 30官方全文](https://www.cdprojektred.com/en/blog/188/answered-podcast-episode-30-paths-and-possibilities-the-art-of-level-design-transcript-included)：关卡制作从纸面提案、跨专业协调进入可玩片段；灰盒应表达场所用途。开发者用地形与排水举例说明空间因果的必要性。

项目推论：先画取水、诊治、晒药、修车、住家与客栈的关系，再决定建筑和道具位置。弯路有绕岸、避坡和接门的原因；不通过随机旋转房屋制造自然感。

### Firewatch：自然环境由地标与剧情需求组织

[Jane Ng，GDC 2016原始讲义](https://media.gdcvault.com/gdc2016/Presentations/Ng_Jane_MakingTheWorld.pdf)：实际核查纸图、代表性样段、地标和沿途发现的页段。地标承担导航及叙事作用，样段帮助评估距离。

项目推论：桥、药棚、旧屋、客栈各有剧情职责；先测桥到药棚的片段，再拓展全村。树丛用于岸边植被带、地标遮荫和视口边缘，不均匀撒树填空。该作品不是RPG村镇，不直接照搬其尺度和相机。

### 城市规划与完整区域协作

[CDPR Urban Planning in Games，GDC官方摘要](https://www.gdcvault.com/play/1034528/Level-Design-Summit-Urban-Planning)：摘要支持规划对可读空间和地区辨识的作用，未将未观看的完整演讲细节作为证据。

[Monica Roque《Assassin’s Creed Unity》工作记录](https://monicaroque.com/assassins-creed-unity/)列出街区、地标尺度、主路人流、建筑高度、隐私、院落与任务位置的整体工作及关卡/美术协作。

项目推论：以完整生活区域评审，而非逐件模型各自合理就放行。公路、公共作业区、私人宅前、后院有不同开放程度；物件群跟随这些关系。

### 负空间

[Jim Brown，GDC负空间讲座官方摘要](https://www.gdcvault.com/play/1020169/The-Importance-of-Nothing-Using)确认其主题；完整PDF超出读取限制，未据此引用详细方法或数值。

项目推论：门前、桥头、推车转身、交谈停留都需要空地。草坪允许作为开放空间，不要求填满家具；空地的作用必须先画出来。

## 3. 重设计原则

1. **地形→生活/剧情→路径→建筑群→物件群→植被→素材。** 两条生活路线不靠同一个方形院门硬塞，药棚有真正前后门和撤离后路。
2. **村路依地形生长。** 建筑保持已定镜头轴线；通过退让、不同进深、院外作业场与岸坡形成层次。不能把四个矩形院挪歪就称自然。
3. **道具需在画面上解释得通。** 柴堆属于干燥灶棚，衣篮属于洗晒区，车具属于陈伯工作区；搬运路线、取用净空与所有权共同落在草图。
4. **家具量人体实际使用部位。** 门看净洞，桌看桌面与脚之间的立面高度，凳看坐面，桶看桶身。像素图整体高度包含俯视进深，不能统一把所有物体图像高设为成人高。
5. **树有根部位置、植被带与遮挡职责。** 根基在干地、避房基和主要门；树冠可遮次要环境，不挡首次任务提示。源素材的朝向不能随意旋转。
6. **保留空地和疏密变化。** 街口收束、桥头停留、作业场展开、宅前安静；沿路有少量目的明确的发现，避免空旷棋盘和堆满杂物两种极端。

## 4. 本轮设计交付与放行

新稿独立存于 `art_sources/chapter1_scene_v2_plan/`，不覆盖旧画板和图。需交付：候选方案取舍、带真实单位的地形/功能图、物件群清单、全部家具同尺图、关键视口构图，以及剧情前后门和搬运路线。

**设计评审增加三项否决条件：** 不看文字说明时不能理解物件所属空间；主要家具无法按人体尺度使用；村落依然是重复矩形院或无因果的坐标错位。通行/alpha/哈希检查继续执行，但不能豁免这三项。

方案状态仅为候选。功能图评审之后还要同镜头构图与可玩灰盒；后续素材采用现有风格基线，新素材样板接受后才批量生成。不能把带参数SVG称成完成美术地图或实机验收。

## 5. 每次制作的执行顺序

|阶段|必须交付|否决条件|
|---|---|---|
|地形与功能|水岸、干地、出入口、公共/私人活动关系、剧情路线|只画房屋方框，没有地形与生活理由|
|带尺布局|建筑净门、家具语义尺寸、道路完整宽度、门前停留、维修/运输包络|中心线通了但通道边缘被占；物件没有可操作位置|
|同镜头灰盒|成人占位、遮挡与排序、四处关键镜头、代表性实际移动|看不懂空间用途、进门/过桥/修车不成立|
|风格样板|沿用当前批准画风的一个完整功能区；真实源尺寸、alpha与同尺截图|人物/屋/家具颗粒或角度不一致；为塞位置任意缩小|
|分区生产|按地图规模拆分完整区域与交界；旧版对比|分区成立但交界断墙、路径或活动链中断|
|独立验收|冻结版本证据，分别记录功能、比例、拼装、运行结论|把技术测试通过写成整图设计通过|

候选图中道路色带只表示预留净空，不是最终全部铺成同色泥地。地面制作另分路芯、磨损边、路肩、草地与排水/坡岸，并在真实镜头检查；不能把所有空地刷成宽黄色路面。

## 6. 用户四处截图的整改约束

|截图问题|新安排必须满足|对应证据|
|---|---|---|
|小桌像玩具|工作桌按成人92的桌面立面高度与手部取用位置制作；门口和屋顶边不能用于挤摆桌子|人体立面图→真实同尺素材→实机近景|
|柴在对岸、树挤在水和屋之间|柴归干燥灶棚/加工区并有搬运路线；树根落于明确干土，不占房基/岸坡；没有剧情生活用途则删除柴堆|水岸/土壤边界、物流与树根图→分区近景|
|箱子堵门|门前留进入/转身空间，储物改侧棚/库位；物资归属与权限独立定义|门口净空包络→入室/取物实际操作|
|篮、车和杆无关系|衣篮只在客栈洗晒链；车辆进入修车场并有拆轴/推车位置；训练杆归明确练习区|活动区、用具/使用者位置、运输及归还链→代表区实玩|

这些是未来生成与实现的要求，不能当作当前地图已整改的结论。

## 7. 前置流程的本轮实践

独立评审先拒收候选1，记录道路穿屋、微型储物房等12项问题。候选B3全路宽检查虽通过，独立复核仍发现门前工具桶、老人凳、晾架及练步区车轴架阻碍；扩展操作包络检查另发现行李侵入洗晒作业区。失败证据分别保留于 `review/chapter1/v2-plan-review-20261003/` 与 `review/chapter1/v2-plan-candidateB3-review-20261003/`。

`tools_scene/check_concept_layout.py` 已增加门前与工作包络的实体侵占检查；6项针对通道边缘、转角、无归属物件、门口与工作区的回归测试通过。通过只证明声明的矩形净空约束成立，不能证明用途可读、真实素材质量、车辆扫掠或实机体验已接受。修正候选必须重新冻结导图与参数，不沿用失败版本审批。

最终B3.1候选独立评审允许进入代表区灰盒，范围仅为功能与尺寸约束候选：五处操作区冲突已修，全部路宽与声明门/工作区无实体脚部侵占，四关键概念镜头和家具示意已同版本冻结。结论见独立限定评审（已移入 _attic，不作参考）。真实素材样板、无标签导航、逐件人体包络、车辆转弯、实机行走和遮挡未接受，旧生产地图仍拒收。带尺方案见[候选说明](../../art_sources/chapter1_scene_v2_plan/README.md)。
