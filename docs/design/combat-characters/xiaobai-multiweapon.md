## 五种发力，六套装备

| 装备外观 | 主出手：前摇 → 发力 → 接触/释放 → 收势 | 第二普通出手 / BP接续 | 握持与身体差异 |
|---|---|---|---|
| 钢剑 | 低锋蓄势 → 后脚送髋 → 斜上挑 → 收肘护中线 | 收肘对线 → 进步短刺 → 原线抽回 | 单手主握，另一手平衡；窄刃轨、半步试距 |
| 木剑 | 同剑路，略延长起手与回收停顿 | 短步直刺、收锋站稳 | 独立木剑外形，不能因已学剑自动装备 |
| 拳掌 | 沉胯护面 → 蹬地送肩 → 短拳 → 双臂回守 | 收掌 → 弓步推掌 → 护胸 | 无握柄孔与武器残留，拳掌分别有手型 |
| 单刀 | 提刀引肩 → 转腰落刃 → 低位斜劈 → 顺势收刀 | 后引刀身 → 横切 → 回腕落刀 | 站距较宽，重心跟随刀势，收势比剑长 |
| 棍 | 提杆引肩 → 转腰横杆 → 横扫 → 抽杆回护 | 双手收杆 → 弓步直送 → 抽杆站稳 | 前导后推，两只手始终约束同一杆 |
| 暗器 | 腰侧取针 → 抬腕蓄势 → 松指释放 → 收腕 | 压低重心取针 → 低位释放 → 起身回守 | 身体留在远距攻击位置，针独立飞行 |

木剑与钢剑使用相同基础剑路，但分别记录外形、接触点和节奏。刀、棍、拳、暗器使用各自完整全身姿势，不旋转同一站姿假装换招。重刀、长枪、软剑、双持、弓弩、鞭链不在本轮已开放五类内；不得用放大单刀、给棍加枪头或替换图标宣称对应动作已完成。

六套主角外观均为16个独立源帧。下表帧号从0开始；重复播放的待机/恢复帧不重复计入96帧。

| 待机 idle | 0、1、0 | 持器/空手分别呼吸，两脚保有支撑 |
| 移步 dash | 2、3 | 两腿真实换位，兵器随手；供进退与普攻接近使用 |
| 普通出手 atk | 4、5、6、7 | 起手、发力、接触/释放、收势 |
| 第二出手 atk2 | 8、9、10 | 不同方向的蓄势、接触/释放、回收 |
| 原位施放 cast / 防御 guard | 11 | 短守势；两个状态共享一个姿势，不虚报新增帧 |
| 受击 hurt | 12、0 | 失衡后恢复支撑 |
| 破势 brk | 13 | 屈膝停留，规则解除后恢复 |

每个主角/人物的所有动作均在预览中列出逐帧名称、源帧、持续时间、接触/释放点。113条动作映射由已采用的BART表派生，不另手写一套冲突时序；制表脚本为`tools_assets/build_character_action_review.py`，数据为预览目录`choreography.json`。

## 运行选择与动作切换

选择链：实际装备实例 → 形制/材质 → 动作族 → 当前行为。`HeroMultiweapon`读取`S.weapon`和物品的`weapon.kind`；无武器走空手，木剑与钢剑分开。借剑只在教学授权范围存在，结束或异常后恢复真实装备；不能用`learned.sword`推断装备。

- 普攻：待机 → 移步（近战）→ 主出手 → 按实际BP接续 → 回位 → 装备待机。暗器走释放与飞行，不冲脸。
- 功法：遵守[当前表现边界](../combat-presentation-boundary.md)，原位短施放，由目标处效果结算；复杂身体招牌动作仅作后续规划。携剑使用拳掌功法时，临时选择空手身体，结束或异常恢复装备外观。当前是状态切换，没有把它记作连续拔剑/入鞘动画。
- 防御/受击/破势/倒地/胜利：保留相应装备包，不能恢复成固定木剑；失败或死亡终止未执行的接触事件。
- 换装：按当前装备重新选择完整包；没有新增战中换武器规则、玩家武学、免费装备或奖励。镜像同时翻转整帧和握点坐标，展示右向不改变角色惯用手设定。

## 可编辑身体与武器源

[分层ZIP](../../../../xiaojianghu-legacy-prologue/art_sources/hero-multiweapon-production-20261014/hero-layered-source.zip)含六套×三层=18张PNG图集和96帧元数据。每帧480×324，脚底根点[240,300]；层序为身体 → 武器区域 → 握持遮挡。元数据包含主/副握点、杆/刃路径、是否持住武器及动作映射。

被兵器遮挡的身体由image_gen去武器补全，按整身相机对齐；不拉伸肢体。武器区域包含握口接缝，应连同对应握持遮挡层更换。空手无武器层；暗器的飞行针属于独立投射。此源是逐帧可编辑PNG，不是可任意拉伸的骨骼人偶，也未宣称头发/衣摆/每个肢体全部独立拆件。96帧按顺序合成的可见RGBA与正式整帧逐像素一致；运行继续使用整帧无损WebP。
