## 2a. 风起栖河：主线推进与任务时限（2026-10-21）

用户 2026-10-21：“不能直接开始演，需要玩家确认是否过渡到下一个时间段，但是不提示还有什么没做，然后任务也是有时限的，不然就永远挂在那里了。”

**主线推进**：玩家走进当前主线的地点，就弹“进入下一时段：<主线标题>”，选“开始”才推进；选“再等等”后，本时段走进这里不再自动弹，找对应的人说话时（她先说一句眼下的事）可以再确认。确认框不列还有哪些事没做；只有最后一步（离村）提醒“离村后就不能再回村里了”。

| 时段（halfDay） | 主线下一步 | 走进哪里弹确认 | 找谁也能确认 |
| --- | --- | --- | --- |
| 第一天白天（0） | 去药棚见来客（第一天傍晚徐令仪上门） | 药棚屋内 | 叶蘅（药棚） |
| 第二天白天（2） | 陪叶蘅去东埠送药（第二天傍晚装卸路） | 东埠 | 叶蘅（东埠） |
| 第三天上午（4） | 回叶家收拾药箱 | 叶家 | 叶蘅（叶家） |
| 第三天下午（5） | 傍晚随药车离村 | 西田埂 | 陆衡（西田埂） |

**任务时限**（设计方案，可再改）：每件可选的事都有时限，时限按剧情定；过了时限就关闭，任务里标“错过”，后面的固定剧情按没做过的基线走。时限写在任务说明里，确认框不提。

## 3. 三件遗物和私人行李

- 2026-10-08 起，三件遗产（《归元诀》、玄曜玉匣、续脉散记录与样品）**不在叶蘅手中**，她此前也不知道它们存在；见[修订依据](opening-pei-disguise.md)。三件遗产在培养阶段循线索取得。
- 叶蘅所有：父亲的几页笔记（一页边角写「归元」）、母亲手写的续脉散药签（签下无药）、母亲旧针囊、询价字条、许可抄本；未做抄录不产生抄本。药箱夹层底布的方形空压痕是玉匣线索，不是物品。
- `P-04`：只看到滑落的父亲笔记与箱扣，不看夹层。
- `C1-03`：叶蘅第一次拆开夹层，只找到药签与空压痕，明白自己交不出三方要的东西，决定离村。没有交出、服用、开匣练成神功的按钮。
- `C1-06`：接人路线由周婶临时看住箱子；护车路线由车上已安坐的伤者照看，周婶此时仍在另一队。战后叶蘅接回，临时看护不改变所有权。两种救援及战斗辅助都保留药箱与笔记。
- `C1-07`：叶蘅向三人说明夹层是空的，只展示压痕与药签用途，不递出笔记。
- `C1-10`：只有主动展示笔记的分支让周砚看一页；他只能判断像旧友笔迹、认出部分步架，不能用这一眼证明整卷或父亲结局。
- 章末：药箱在叶蘅独立客房的柜子里，萧白不自动获得这三件物品的装备、使用或赠送权限。
- 萧白保留现代衣包与手机；序章关机后不在每场自动亮屏，不增设太阳能充电、神秘短信或手机变武器。借来的乡村便衣继续穿，无剑。

## 4. 人物知道什么

萧白与叶蘅章末认识徐令仪、岑霜、沈雁回，知道三方诉求、药商越权传话、现场失火动作与周砚来村缘由。萧白若在后山见过「宋先生」（乔装裴嵩，可选剧情），知道他托自己打探；答应了的，还知道他问过装卸侧口、没有赴约；`told_about_stranger` 为真时叶蘅与三人也知道此事，沈记为待问经手人。没有人知道宋先生就是裴嵩。答应过宋先生的路线里，三人都承认因怀疑萧白是别家眼线而没有先强取。C1-07必达对证让三人也知道：不同附页把同一张旧药罐底单扩写成三种授权，并约同一时地，消息被有意拼接利用。全跳支线也能获知这一点；未问讯不补写为问过沈。众人仍不知道谁换件、谁授意、裴嵩的作用、父亲遇难细节、玉匣旧归属，以及三件遗产现在何处、何时被取走。

玩家从动作可见失火因果：乌魁抢箱 → 护院拔剑 → 采办随从推架堵路 → 乌魁闪避撞灯台 → 护院退步撞开油棚 → 火蔓延。不能简写成「魔教纵火」或「三方联手屠村」。周砚、徐令仪、岑霜、沈雁回分区救人；徐的看路签批、岑的控制路口、沈的整箱限制与执行者抢物／拔剑／堵门分别留名。识破算计和参与救援均不免除责任，赔偿、复核、回查仍须验证。程铎不在现场，作为委办发出者接受沈的回报。

叶蘅知道母亲已病故、父亲多年未归，不知道父亲已经遇难。她此时只做普通救治，白鹇谷与针攻路线都没决定。苏芷与宠物大黄本两章不登场，山犬不能复用成已收养的大黄。

## 6. 文本与完整体验分别验收

精修文本及已有对白入口的同步记录见[开篇精修说明](../archive/design/opening-polish.md)。风起栖河段已有运行状态测试，序章村中入口有浏览器验证；后山与借宿前段已有独立[流程验收](../archive/design/prologue-arrival-acceptance.md)，这些检查不能代替风起栖河段全场景美术、声音和真实移动验收。现代开场不再列当前验收项。以下仍是完整开篇应持续核验的项目：

1. 序章跳教学／全跳小事，风起栖河段全休息、不同活动顺序、六项各取一支，都能抵达同一山居终点。
2. 两种撤离、各陈伯伤势与守路胜／败／辅助路径；失败重置不复制物品、扣额外时间或留下持续锁定。
3. 先转移老人再送药，以及先送药再转移老人，NPC 所在地、对白和花费一致。
4. 未接、接而未交、已完成与旁听信息分别保存，不把药商袖中纸条变成玩家已获证物。
5. 任务提示不阻断移动；对话、CG、菜单、战斗及异常退出都释放输入状态。章节终点只存档，不串到旧襄阳开局。
6. 手机衣包、无佩剑、临时木杆归还或丢弃、遗物所有权、陆衡护送结束均一致。
7. 1280×720／1920×1080 实际演出，字幕可读、CG 不遮挡、声音不会循环刺耳；本轮序章村中段已跑两种视口，风起栖河段完整演出仍按独立验收清单核验。
8. 三条去向都可查看、仅第一项可确认；后两项清楚说明未开放，不伪装能力门槛。确认、取消、重复打开不重复写路线或代替叶蘅的同意。
