# 功法结构规范 v3

状态：现行　最后核对：2026-10-19

> **2026-10-07 修订（用户已确认规则）**：外功按品阶定招式数，门派按入门→镇派多门功法传承；人物技能不计入外功且暂缓细化。背景、调研与逐门清单见[门派功法传承 v3](martial-lineage.md)、[门派功法清单](martial-review/martial-systems.md)，新名称见[命名审定表](martial-review/lineage-v3-naming.md)（待审）。v2 的内功规则不变。

## 硬性结构

| 对象 | 必填字段 | 数量与约束 |
| --- | --- | --- |
| 外功 | id、名称、品阶、技理、招式ID列表（含开启重数）、学习前置、获取来源、十重精通 | **按品阶定招式数：丁、丙、乙 1 招；甲 2 招（第二招五重开启）；绝 3 招（五重、七重开启，第三招为 X 型绝招）**。招式品阶不高于功法，最后开启的一招等于功法品阶；每招只属于一门外功，兼容内功仅作引用 |
| 功法重数 | — | 取本功法已学各招重数的最高值；已开启招式共享功法重数，练任一招都算练这门功法；满十重得一项精通（并入十重火候：内力、威力或看破） |
| 招式 | id、所属外功、开启重数、效果、目标、内力、兵器、BP规则 | 学会功法即得第一招，后续招式只按本功法重数开启，不需额外剧情，残札也不能跳过开启节点；装配以招式为单位，功法本身不占格 |
| 人物技能 | id、所属人物、效果、BP规则 | 不算外功、不可传授；品阶随人物等级提升（暂缓细化） |
| 内功 | id、名称、主动技能、被动技能、层数、运转条件 | **恰好一个主动技能、一个被动技能**；两者不能用数组堆叠成多技能 |
| 内功主动 | id、名称、效果、目标、内力、冷却、行动消耗 | 耗一次行动；冷却按本人行动次数计（2026-10-08 统一，数据字段 `cooldown_self_actions`；每回合一次行动时与回合数相同）；BP不强化 |
| 内功被动 | id、名称、基础效果、成长节点 | 仅运转时生效；三层、五层是同一个被动的强化，不是额外被动 |

**防御强化招式（2026-10-08 用户确认）**：回岚步、松间错步、敛云守锋、逆流截江这类“只保护自己”的招式（回灰护影的效果是为同伴卸力，不属于此类，2026-10-08 核对后保持普通主动招），模拟显示单独占一次行动永远不如进攻（23520 场各只用 5–9 次）。改为**防御强化**：仍按招式装配、占招式格，但不能单独施放；角色选“防御”时，自动附带其中一招的效果（卸力、反击、守势、下一击增伤），不另付内力。装配多招时只取效果最高的一招。

功法仅分外功与内功；人物技能另列，不属于可传授功法。功法之间只有学习前置，学了低阶不自动解锁高阶；前置门槛最高为前一门七重（丙级三重、乙级五重、甲级与绝级七重），见[门派功法传承](martial-lineage.md) 3.4。个别功法可能因剧情提前到手，随剧情逐个设计，不是通用机制。装备效果、宠物技能、敌方技能与出身能力不作为第三类功法。

## 游戏规则与迁移

- 保留存档 skills/load/xinfa 的ID、层数和修炼进度。外功收纳层不自动赠送招式；不改原来外功装配槽容量。
- 保留一门主修与既有辅修槽开放条件。运转某内功，同时启用该门的一主动和一被动；停止运转后两者均不可用。
- 内功主动自动加入战斗武学菜单，不占外功招式槽；停止运转不可通过直接调用技能绕过。
- 冷却以战斗 round 为基准，施放于N回合，N+3回合可再次用；同场每个人独立记录，新战斗重置。
- 主动恢复内力：上限15%，至少1点；主动自疗：气血上限18%；清秽：解除流血和眩晕并恢复10%气血。定神：攻击+30%、受伤-20%，2回合；守势：防御至下次行动。辨机：揭示敌人一处弱点。各门内力成本见运行数据 js/martial-structure.js。
- 主动按固定效果计算，不受招式重数、BP或治疗被动再次放大，以防双重加成。战斗菜单必须显示内力不足及冷却原因。
- 毒经补齐养气被动：内力上限每层+2%，旧描述中的毒伤加成不宣称已实现。
- 原来标记todo的三/五层效果没有实现，不能作为已生效被动展示；已实现效果并入单一被动成长。
- 出身技能静心诀保留原存档与技能行为，属于出身能力，不能作为内功结构完成的样板。

## 提案与运行数据

catalog.json 的18门内功为后续门派设计提案，主动数值已列出、效果尚待实现，不等于运行中已经学会。现有运行内功 XINFA 逐门补齐一主动一被动；两份清单不能混用ID或宣称已全部接入。未来内功不得使用空泛效果上线，必须补齐具体数值、目标和测试。

外功清单以 martial-systems.json 为准；compatible_inner_ids 仅表达搭配关系。基础外功与进阶外功的传承关系保留各自学习前置，后者不因前者习得自动解锁。

## UI和素材

武学一级页签仅「外功」「内功」。外功按套路展示已学招式图标；内功详情必须同时展示一个主动与一个被动及成长节点。品质色框和高级光效沿用现有规范，不能因改分类重画成另一种风格。本轮没有生成新图，使用现有图标。

## 必须验收

1. 每门内功只有一个主动对象和一个被动对象，ID唯一。
2. 运转状态进入战斗才能出现主动；费用、行动、冷却和无效目标正确；每个主动效果均测试。
3. 旧存档层数、已学技能和进度保持；被动旧有已实现属性不丢失。
4. 实机武学两页与图录逐项核对；提案明确显示未接入，不冒充实装。
5. 修改后的浏览器控制台无新错误，停止运转和新战斗冷却重置测试通过。
