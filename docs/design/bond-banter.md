# 羁绊与闲话：同伴之间的日常对话

状态：现行　最后核对：2026-10-19（原记：**用户已拍板（2026-10-10）**：只做闲话，只在汉皋城与大地图自由模式里出现；交情独立于关系、只靠一起战斗增长。编写日期 2026-10-10。[关系、入队与结缘细则](romance-rules.md) · [名册](companions.md) · [逐人武力与入队](companion-power.md)）

用户（2026-10-10）：“新增一个羁绊系统，就每个可入队角色和互相都要有一定的日常对话情节（参考八方旅人），随着关系的不同有着不同的对话，可以显著丰富人物形象（先去调研，然后设计，然后让我拍板是否进行开发）”。

## 一、调研：八方旅人怎么做的

| 项 | 一代 | 二代 |
| --- | --- | --- |
| 名字 | 队伍对话（Travel Banter） | 同 |
| 形式 | 两个人的短对白小剧场，不影响剧情和数值 | 同 |
| 谁和谁 | 当前推进的那位主角 ＋ 出战队伍里的另一人 | 同 |
| 何时出现 | 培养部分起，某位主角的剧情段落之后；画面右上角出提示，按键播放 | 同；探索野外和城镇时也会出提示 |
| 酒馆 | 特定角色组合在队时，酒馆里可以触发小剧场 | — |
| 错过了 | 不能回看，过了时点就没了，只能查攻略 | 可以在日志里看已看过和错过的 |
| 其他互动 | 没有 | 新增“交错的故事”：固定四对各有双人章节；战斗里互相喊话（破防、濒危、倒下） |

玩家和评测反复提到的问题：

- 八位主角的主线互不相干，队伍对话是唯一的互动，量不够，“像八个人各走各的”。
- 一代要求两人都在出战的四人里才触发，可酒馆明明是八个人都在的地方。
- 一代错过不能补看。
- 二代补了回看和双人章节，评价明显好转，但仍有人觉得主线章节里同伴不存在。

来源见文末。

### 取什么、改什么

| 八方的做法 | 本作 |
| --- | --- |
| 两人短对白，不影响数值 | 取。对白本身不给奖励，只涨一点交情 |
| 事件之后出提示，玩家自己决定看不看 | 取。点了才有，不点不显示 |
| 只有主角和一名同伴 | 改。萧白与每人有，同伴与同伴之间也有 |
| 必须在出战位 | 改。在名册里并且人在场就行 |
| 错过不能回看 | 改。全部进“闲话册”，没看的有标记，随时补看 |
| 对白固定一版 | 改。按交情或关系的阶段解锁不同的闲话 |
| 二代的双人章节 | 不做（用户决定只做闲话） |
| 主线里同伴不存在 | 剧情闲话：事情发生过、交情到了、人在队里才有 |

## 二、设计（用户 2026-10-10 已定）

用户决定：
- 做，但**只做闲话**；对坐、同路篇不做。
- 同伴之间只有**背景相似或有联系的**才有对话，每人五六个人；师门里不入队的人不进这套系统。
- 闲话**只放在汉皋城和大地图自由模式里**，用 Q 版对白的形式，点了才有，不点不显示。**培养模式不用闲话**，有话直接在剧情里说。
- **交情独立于关系**，只能靠多一起战斗增长；交情到了就触发闲话。
- 偶尔的**剧情闲话**，不只要剧情发生过，还要交情（或关系）到了、对应的人在，才触发，不然不自然。

### 1. 闲话是什么、在哪里

- 两个人的短对白，5—8 句，Q 版对白界面，不影响剧情和数值。
- 只在两个地方出现：**汉皋城**里走动时、**大地图自由模式**里。画面角落出一枚提示，点了才播；不点就什么都不显示，过后在闲话册里还能看。
- 培养模式（归云谷）里没有闲话。谷里的人有话，写进闲逛和主线剧情里直接说。
- 两种组合：萧白＋一位同伴；两位同伴（见第三节的 55 对）。没列出的组合之间没有闲话。

### 2. 两个数，各管各的

| | 是谁和谁之间的 | 怎么涨 | 管什么 |
| --- | --- | --- | --- |
| 关系 | 萧白与每位同伴 | 现有的办法：剧情、通信、送礼、瓶颈剧情 | 入队、结缘、剧情里的说法；也是“萧白＋同伴”闲话的门槛 |
| 交情 | 同伴与同伴 | **只有一样：两人同在队里打完一场仗记一场**。赢或输都算；逃跑、单人战、教学战不算 | “同伴＋同伴”闲话的门槛 |

- 交情和关系互不影响：萧白与两个人关系再高，她们俩没一起打过仗，交情还是零。
- 交情三个阶段：生分（0 场）、相熟（6 场）、知己（18 场）。场数是提案。
- 交情不能送礼、不能靠对话涨，看闲话本身也不涨。

### 3. 一条闲话什么时候出现

要同时满足：

1. **地方对**：这条闲话写的是汉皋城还是大地图。
2. **人在**：两个人都在当前队伍里（萧白永远在）。
3. **到了**：同伴＋同伴看交情阶段；萧白＋同伴看关系值。到了就触发，不用另等时机。
4. **剧情闲话再加一条**：那件事已经发生过。只发生了事、交情没到，或者人不在队里，都不出现。
5. 涉及暧昧的，萧白满 18 岁之后。

每条只提示一次，之后收在闲话册里，可以重看。

## 四、要写多少

| 层 | 范围 | 每组 | 合计（估） |
| --- | --- | --- | --- |
| 萧白 × 每人 | 19 组 | 关系到信赖、托付各 2—3 条 | 约 100 条 |
| 同伴 × 同伴 | 55 对 | 相熟 2 条、知己 1—2 条 | 约 200 条 |
| 剧情闲话 | 挑有分量的事 | 偶尔才有 | 不设定量 |

## 五、当前实现与分期

- **已做**：规则与数据模块、交情随战斗增长、8 条示例闲话（萧白、叶蘅、殷红缨之间）。见当前游戏工作区 `docs/design/qihe-map/expansion/relationships.md`“闲话与交情”一节。
- **未做**：汉皋城和大地图自由模式本身还没进游戏，所以闲话目前没有地方显示；提示、播放、闲话册的界面等这两处做的时候接上。
- 之后随各同伴入队逐人补内容。
