## 时间与结算

提交 → 一次扣体力与自有材料并保存活动ID/开始时间 → 2000ms短过渡 → 首次关键受教保留必要选择，普通活动结算 → 成果约1000ms自动收起。画面加载或失败均不决定数值结算；刷新依据已保存的墙钟起始时间继续，不重复扣费。后台恢复检查经过时间，不承诺后台仍以可见帧率刷新。

## 画面标准

中央木框约占屏幕宽32.6%、高49.2%，框内纯米色。普通独练使用稳定Q人物；周砚阶段指导使用已确认的双人纯色底画稿，没有场景、台词或气泡。叶蘅首次课程使用现有透明Q素材在同一纯色纸面内组合。其他指导者/人物节点专属插图尚须补齐，不把错误人物作为替代。

人物主体不做来回缩放、摆头或大幅换姿态。当前按[六阶段动作修订](../archive/design/cultivation-action-loops.md)：吐纳使用新六帧透明原画，允许双手抬落和轻微胸口/发梢跟随，掌间光点逐帧锚定；指导与其他活动使用六个局部手势关键值平滑过渡，区域外人物固定。气息、水波、蒸汽、落叶、尘雾和刃光是独立环境图层，按活动使用；无怒符、汗滴或颜文字。右上头像继续只替换眼部区域。减少动态效果时人物和环境图层均静止，费用及2000ms不变。

吐纳已另绘六张关键姿态；其他现有12类动作图提供定姿取图。逐模块复查后，按具体项目选择合适的格：医案记录使用写字，辨药使用察看药叶，炊事使用揉面，缝补使用布料操作，磨墨使用磨墨，察势使用远望。基本功独练分别取站桩、步法和双掌协调定姿。补竹篓新增透明单人画稿，替换错误的扫帚画面。菜单与过渡共用项目映射，登记在素材清单的`action_static_poses`。

不宣称28个项目均有独立新绘动画。布包/缝补等仍共用相关姿态，基本功独练与确认的菜单小图也未全部统一为同一底稿；叶蘅、陆衡、乡邻的专属插图仍须补齐。周砚指导已通过原生imagegen清除原图烘焙的怒符/汗滴；后续干净素材应拆出人物/眼睛/真实手部细节层，不制作符号层。通信书房背景通过原生imagegen移除烧入HUD后接入。
