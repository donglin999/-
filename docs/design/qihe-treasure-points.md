## 1. 从八方旅人借什么

| 八方旅人 | 做法 | 本作 |
| --- | --- | --- |
| 普通棕箱（OT2 只分棕、红，谁都能开） | 走小路、绕屋后就能碰到，内容贴合当地 | **普通箱**：木箱、竹篓、漂来的木匣，看得见，靠近就开 |
| 红箱内容更值钱（OT2） | 贵重物放得更远 | **铁箍箱**：放在地图边角，走到就能开。不用钥匙，也不做开锁职业（紫箱的开锁门槛不借） |
| 隐藏物（OT1 有 152 处；OT0 用蓝色微光标记） | 不靠容器，走到尽头才有 | **隐藏点**：走近才闪淡蓝，地图尽头、屋后、窄巷 |
| 宝箱分布在支路和死角，极少错过（OT1 全游戏 734 箱，只有 1 个会错过） | 奖励的是多走一步 | 主路上不放；起火前村里一直开着，没有时段限制 |

不借：钥匙和开锁、箱子怪、随机内容、把神功放进箱子。

来源：[TrueAchievements 宝箱统计](https://www.trueachievements.com/a324282/treasure-hunter-achievement)、[Twinfinite 紫箱](https://twinfinite.net/guides/octopath-traveler-open-purple-chests-how/)、[Twinfinite OT2 箱色](https://twinfinite.net/guides/are-there-purple-chests-in-octopath-traveler-2-answered/)、[OT0 蓝箱](https://selphie1999gaming.com/game-guides/octopath-traveler-0/octopath-traveler-0-blue-chests-how-to-open-blue-chests/)、[OT0 进阶提示](https://intoindiegames.com/walkthroughs/tips-tricks/advanced-tips-for-octopath-traveler-0/)、[3DM 全宝箱地图](https://www.3dmgame.com/gl/3778169_32.html)。

## 2. 规则

1. **不偷村民**：每个点都是无主、遗落、早被丢弃，或主人允许取用（R-剧情-08）。偷东西走现有的“窃”。
2. **活动不耗时**（R-时间-01），开箱走对话框，一句心里话，不让玩家读细节。
3. **奖励固定、一次领取**，存 `S.qiheTown.chests`；箱子取后换打开的图，隐藏点取后消失。
4. **提示**：没开过的箱子闪淡蓝；隐藏点和旧木桶走近（190 像素内）才闪。
5. **开放时段**：第一天白天到起火前；起火后村子关闭。邻村竹篓只在逃到邻村时有。
6. **所有箱子都不用钥匙**（用户 2026-11-02）：看见就能开，铁箍箱只是内容更值钱。

## 4. 自审

| 问题 | 结论 |
| --- | --- |
| 数值会不会冲垮村里物价？ | 全部拿到约值 265 两（三件多精铁剑的标价）。货币单位是“两”（用户 2026-10-23 定，见 [门派关系与声誉](faction-reputation.md) 第十一轮拍板），但现钱只有 66 两，其余是药和零碎，且要跑遍五张图。不用钥匙后两只铁箍箱更好拿，靠放在边角控制。没给 q2 以上装备。 |
| 会不会抢主线奖励？ | 不碰平安符线（百家平安符是另一件）、老更夫心法、石洞秘籍。 |
| 拿了火折子会不会提前解开石洞？ | 石洞现在关着（`CAVE_ON=false`）；货郎也卖火折子，没有新影响。 |
| 叶家屋后、陈伯后院算不算偷？ | 屋后是草根散钱；后院由陈伯许可，台词里交代。 |
| 旧存档里捡过钥匙怎么办？ | 没发布过，只可能在本机测试档里；背包只列已登记的物品，旧钥匙不显示也不报错。 |
| 不做的 | 石洞、山上营地、室内暂不放；室内已有客栈箱笼，山上是收尾段。 |
