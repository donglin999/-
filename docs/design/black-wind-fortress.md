# 黑风寨：空间、阻挡物与战后状态

状态：2026-09-30 返工基准。适用 `bgate` 寨门与 `cave` 聚义洞；世界观和案件位置仍以[襄阳章节](xiangyang-chapter.md)为准，素材尺度遵循[襄阳美术规范](xiangyang-art.md)。

## 现状问题与设计结论

寨门前画了整幅草地，却用独立的 `walk_poly` 只开放中央区域。实测前场 y=180–390 的裸草地，扣除所有物件占地后仍有 **61,169 / 102,816（59.5%）** 不可走；`(550,340)`、`(100,220)` 是无遮拦草地却被挡，邻近同色草地反而能走。洞内裸岩地有 **10,361 / 145,983（7.1%）** 同类误差。旧审计的单连通区、`issues=0` 未检查视觉地面与碰撞的一致性，因此旧“通过”结论撤回。

寨门当前具备寨墙、门楼、火盆和拒马，但**前场边界未先规划用途与实物**：大片草地只是颜色，玩家无法从画面判断通行权限。这一步没有完整遵循“先区域功能和阻挡语义，再摆单体，再从占地生成碰撞，最后同屏验收”的开发原则。不能靠画深草、暗色土或一条色带作为不可走理由。

## 区域用途与通行合同

| 区域 | 画面用途与可见实体 | 行走规则 |
| --- | --- | --- |
| 寨门与木墙 | 望楼、木栅、关卡门扇形成北部实体；门洞是上山转场 | 墙、楼和拒马足迹挡人；门洞出口可达 |
| 门前夯土场 | 盘查、守夜、酒棚和兽皮架；南部接山道 | 裸露夯土及物件间净空可走，火盆、棚架和拒马按脚点挡人 |
| 西、东草坡 | 供玩家绕行、探酒和观察地形；低草只是材质 | 看得见的裸草坡全部可走，树干、石块、陡坡/栅栏实体单独挡人 |
| 外缘林石与南坡 | 左右以成组松林、岩石和陡坎收边；南部只留山道出口 | 不可走边必须贴连续可辨的实体外缘，不能在草地中画隐形多边形；下山路保持通畅 |
| 洞内聚义厅 | 中央战场、虎皮交椅、聚饮桌、赃物和蛇箱分区 | 可见岩地除家具、柱脚、石笋外可走；阴暗深处以真实洞壁、坍石或断崖轮廓封边 |

每段不可走的边都需能指认具体挡路物：木墙、拒马、树干、密林石堆、洞壁、石笋或断崖。视觉上连续的草坪或岩地不能在中间突然失去行走权限。世界边缘可以用有高度与投影的林石/岩壁收口，山道和洞口出口处留清晰缺口。不要用大量随机石头把通路做成迷宫；物件服务于关卡、营地与山势。

## Boss 败后状态

独眼阎罗被击败并设置 `chief_dead` 后，洞内四名普通喽啰应在战斗遮罩结束后的当前场景立刻退场；返回洞内、读档后也不再出现。寨门仍可进出，但守寨盘查者与巡哨撤离，营地的墙、棚、账册、箱笼等物件保留，表现“据点已败、现场可搜查”。若战斗失败或未击败 Boss，喽啰维持原状态。剧情以 `chief_dead` 为唯一持久依据，不另建容易不同步的临时变量。

## 生产与验收

1. 先按上表画出可走草坡/岩地及收边实体，再修改地图生成器；`walk` 应覆盖看起来能站的地面，实体足迹从可走区扣除。地图、素材图集、碰撞 mask 同一次构建生成。
2. 对寨门和洞内生成无 UI 全景、正常 1280×720 游戏镜头与碰撞叠图。逐段检查每条禁行边在同屏画面有可见物；记录草地/岩地未被实体占据却不可走的面积，目标为 **0**，地图外缘保护带和可见断崖后方另列。
3. 实走西草坡挖酒点、东草坡、门前绕行、山道、洞内两侧岩地及洞口；不穿墙、不堵主线。Boss 胜利当场、结算返回、重进和读档四种状态实测喽啰；失败仍在场。
4. 新增素材先对照现有黑风寨人物、门楼、洞壁和地面截图审稿，记录来源、用途、尺寸、占地与退稿原因；不能用统一调色掩盖画风或尺度不符。

## 本轮实现记录

`bgate` 以整片草坡为可走底层，南侧沿山道两边使用挡土石墙、左右用连续陡石坡收边；木寨墙、拒马、树石等仍以物件占地挡人。没有另画一条只靠深浅色区分的禁行线。南墙留山道缺口，左右岩坡占住地图侧沿。石坡调用现有 `sheet_bandit_6`，四段分别改变宽度、嵌入位置和朝向；南墙复用 `sheet_mount_9`，交替镜像。洞内可走多边形与裸岩地轮廓一致，外侧仍由岩壁隔开。

新建 `tools_scene/ground_contract.py`，逐源像素比较裸草/裸岩地、实体占地和最终可走 mask：寨门裸草 76,646 像素、洞内裸岩 145,097 像素，**无实物却不可走均为 0**。`tools_scene/audit.cjs` 对寨门/山洞均为单连通、`issues=0`。实走左草坡 `(130,250)→(80,250)`、右草坡 `(570,280)→(620,280)` 和下山路 `(200,350)→(212,380)`，到点误差约 5 像素；岩坡 `(20,280)` 与 `(700,280)` 则不能站，角色停在可见岩石边。以上坐标是 720×400 场景源图坐标。

`wanderers` 保留各自来源配置，在场景每帧依据 `show()` 撤下失效的喽啰，不重新随机摆放其他人。寨主死亡旗标同时令洞内四名喽啰、寨门盘查者和巡哨退场，寨门出口继续开放。独立验收在真实战斗 UI 使 Boss 败北：胜利当场 `chief_dead=true`、洞内喽啰 0；章节结算后选择“继续游历”、返回寨门、重进洞内，以及载入已胜利存档，喽啰均为 0，守卫不再出现、洞口仍可进。战败分支 `chief_dead=false`，四名喽啰和 Boss 仍在。浏览器无页面错误。

正常 1280×720 游戏视口复看左右岩坡、南墙的高度、投影和草地接边；独立验收判定本轮阻挡语义和重复拼贴已达标。南墙仍能辨出模块接缝，列为后续美术细节精修，不将其误报为本轮空气墙。验收截图在本地 `/tmp/accept-blackwind-final-view-{west,east,south}.png`，地图审计叠图在 `/tmp/blackwind-audit-final2/audit_bgate.png`。
