## 装配

在项目目录运行 `python3 tools_audio/equip_voices.py`。脚本通过本地后台读取已确认绑定与有效成品，只导出真实 MiniMax 音频；若已确认角色还有缺失、过期或失败的台词，拒绝更新清单，不装配半成品。未确认角色继续字幕演出。

音频导出至 `assets/audio/voices/`，按内容哈希命名，最后原子更新 `manifest.js`。此目录是游戏正式静态素材，可纳入 Git 和静态发布；忽略的后台状态、全部候选试听和 API 密钥不发布。游戏加载清单后可离线使用，不依赖选音后台。日后换音色或改稿，先补全成品再重新装配。

2026-10-05装配更新：13个角色、90条正式语音；叶蘅以原绑定补齐12句序章和风起栖河段关键对白，108条状态选音示例明确排除。旧襄阳包78句沿用。此前批次：叶蘅、苏芷共 67 条，已选配角 11 条。铁匠、盐商、汲水妇人、教头尚未确认，因此没有替用户挑选声音。主要角色的 9 条情绪短句包含在素材中，只有相应台词实际出现才播放，不随机插入未发生的剧情或战斗。

## 播放规则

`js/voice.js` 用角色身份与完整文本匹配台词，允许立绘表情差分；主角和旁白不播角色语音。普通对白由 audio.js 的 say 包裹触发，选项提示由 choose 包裹触发；救治 CG 每个台词节拍单独触发，继续或关闭 CG 时停止上一句，全屏 CG 不显示立绘。

语音单通道，不叠播。首次操作后才播放，遵循现有静音按钮和 M 键。快速展示整句文字不打断语音，真正推进对话或选择选项时停止；场景淡出和交互结束也停止。声音加载失败或播放被浏览器拒绝时仍可正常读字幕并推进。人物语音使用原始语速与音高，音量 .85；配音时音乐和环境声压至原增益的 .35。有配音的台词关闭打字 blip。

配角每次交互最多播放一次，同一识别句至少冷却 20 秒，未配音的其他台词只显示文字。附近走路、靠近人物不自动播放。

## 验证

播放测试覆盖单句冷却、交互限次、拒绝主角配音、单通道、不让旧句回调停止新句、静音、对话快速展示与推进、选项提示、全屏 CG 换句。襄阳章节剧情回归通过。装配脚本验证仅使用真实有效成品，正式清单与素材文件一起保存。
