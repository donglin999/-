仓库目录运行 `python3 -m http.server 8149 --bind 127.0.0.1`，打开 `http://127.0.0.1:8149/?layout=simple-v5#cultivation`。旧 `?layout=approved-v3#cultivation` 同样加载最新实现，不并存两套页面。

没有培养存档时从第一年一月月初、12点体力开始，自动出现入门剧情，继续后正式拜入归云谷；不赠送武学、装备或队伍。开始部分结束、选择进入养成时继承章节事实、财物与角色状态。养成预览使用 `sessionStorage['xjh.cultivation.save']`，不覆盖正式 `xjh.save` 或开始部分检查点。存档可恢复当前时间、所学、材料、已扣费用、待选择与结果；地图恢复行程与地点，坐标回到该场景入口。

## 当前交互

首页只有景物、日期/体力、固定头像与八类底栏。基本功、生产、学艺、打杂、闲逛以图标子菜单直接执行；每个标签用2—4字短名，完整名称、费用与失败理由在聚焦/悬停提示和辅助标签中提供。类别切换、返回、查看免费。招式只显示实际已学的剑式/拳脚。

日期统一为纸面内两列竖排（右年份、左月份时段）；日期、葫芦数字、姓名与心情按各自装饰图的实际留白定位，字号随游戏宽度缩放。体力数字置于圆腹中心，体力标签复用木牌，心情文字置于挂签纸面。长日期、零/十体力与窄窗口证据见[HUD样式修复](../../review/cultivation_hud_style_20261004/README.md)。

同日比例修订：卷轴透明边距由上下69%补偿改为33%，容器17%高，对应实际可见约17%，不再显示成约29%的大栏。类别与子菜单图标统一6.2cqw方格，竖签1.05/1cqw；日期19→14cqw，葫芦9→6.5cqw，数字2.25→1.5cqw，头像13→10cqw，姓名与心情文字按同一比例缩小。中央训练木框和八入口交互不变。详见[比例修正及截图](../../review/cultivation_scale_20261004/README.md)。

初次站桩由周砚指导；完成基础课且体力足够时自动出现传艺事件，明确选择《试锋剑法》或《守拙拳法》，只按5点提交选中课程，无默认主修。可改日受教，不收费；同一期不反复催促。主修受教后不自动教另一门，练习栏只列实际已学功法；交叉修习须专门的后续传艺剧情，目前未开放。只有完成本课才登记来源。

提交后立刻扣费、保存并锁定操作。图像可见后开始约2秒的木框过渡，播放六张完整原画；普通练习不带指导者，首次受教/人物节点才呈现对应指导插图。框内指导无场景背景、气泡、台词或情绪符号。动画后普通成果显示约1秒，自动返回同一菜单；首次指导选择完成后也只发一次成果。

右上头像改用已确认的07-avatar专用审图原稿，等比取完整发束与肩部，不再从首页紧贴脸裁切；只在两只眼睛的椭圆区域切换眨眼。按实际显示尺寸与屏幕像素比采样并平滑缩图，静止时不重复重画；保持人物姿态，不追加心情符号。中央共29套完整六帧原画（28套新稿及保留吐纳），与整套审图使用同版素材、固定方格和节奏，不再使用旧图局部扭曲。周砚/叶蘅首次课程使用G01/G02整幅双人图，W01/W02节点使用各自图集，所学独练使用活动专属图。仅保留吐纳掌间光叠层，水滴/蒸汽/尘叶来自新原画。减少动态效果使用静止首帧，仍按2000ms正常结算。未结束演出读档时重播两秒但不重复扣费；待选和结果按原状态恢复。详见[整套重画](cultivation-redraw.md)。

按同日最新要求，原通信图标改为“邮箱”，点击或数字6直接打开既有江湖行卷的行囊页，展示当前人物立绘和真实背包物品；其余既有页签可照常切换。培养逻辑仍停留在当前期，查看不收体力或历练时间。返回按钮/Esc关闭行卷、保存实际物品/装备更改、恢复谷中画面并将焦点交还邮箱。菜单期间停止培养绘图，避免隐藏层键盘与演出干扰。演出、剧情和未关闭子菜单期间仍锁定邮箱。此前送信/送物的规则、素材与未完成投递档保留兼容，但首页不再进入独立通信子菜单。

R打开休息预览，确认才推进；数字1—7定位类别（6打开江湖行囊），方向键移动子菜单焦点，Enter使用按钮，Tab遍历，Esc返回。行卷打开时数字键由行卷处理。设置含声音与四个独立小游戏候选；游戏过程、重试与退出不改培养状态或发奖励。
