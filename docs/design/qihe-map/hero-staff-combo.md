# 萧白开始部分棍法连击

状态：现行　最后核对：2026-10-19

2026-10-10；当前栖河游戏 / 8792。用户要求增加出手次数，进一步确认重点是第一段出手的打击感；延续已采用的[末端握棍](../../archive/design/qihe-map/hero-staff-grip-adoption.md)。本机已采用并完成守路战实录，见[更新记录](../../updates/2026-10-10-hero-staff-combo.md)与[批次说明](../../../art_sources/hero-staff-combo-20261010/README.md)。未提交、未线上发布。

## 动作与节奏

- 普通攻击：收棍转肩 → 腰身横扫 → 顺势回提 → 斜打 → 短促直戳 → 回收。三个接触点，连贯向前压制，中途不回到待机。
- BP 后续攻击：斜打 → 直戳，两次接触，较短前摇，避免每次完整重新蓄力。
- 横杆护身使用三接触连招，再保留原本护身效果。只对 `hero_village` 启用此完整动作表，其他角色继续使用自己的动作。
- 初学者的扎实棍法：脚下重心、髋肩与双臂同时变化；不加空翻、转圈或发光棍。两手握在同一端，后手邻近棍尾、前手与其保持距离，长击打段在前。

## 接触与规则

用户进一步确认：重点是开头第一次出手的打击感。首击横扫必须有明确蓄力、快速切入命中姿势、接触停留、敌人后退与短促木棍撞击声；不能继续以翻页提示音充当命中声音。首击使用普通攻击预算内的 30ms 顿帧、较明显受击闪色及 14px 后退，镜头短促推近；第二次斜打较轻，最后直戳结束动作。

每套动作的前两次接触用于连击演出，最后一击执行该次攻击原有伤害、弱点削盾与技能附加效果。普通攻击仍按 `1 + BP` 次规则结算，技能次数、总伤害算法和护身持续时间不因演出扩展而改变。BP 额外攻击切换较短的接续动作。木棍音效使用本地确定性合成，保留源脚本、无削波 PCM 原件与正式登记；试听影片的音轨按实机成功播放事件与实际音频文件同步混合，注明音效轨不包含背景音乐或角色语音。

接触事件必须绑定动作帧，不能按任意定时器提前结算，也不能让普通三击被误算成三次削盾。受击反馈使用实际位移后的目标位置。视觉接触不能把敌人提前击杀；最后一击仍保留规则结算反馈。

## 素材与验收

新增全身横扫与斜打姿势；正式末端握棍表提供身份、服装、像素颜色和直戳姿势。取正式登记文件，不以未采用候选为画风参考。每组保留源图、提示词、灰色姿势、源图哈希、身体独立标志点、握持与棍长测量。

统一固定身体摄像比例与地面基线，按稳定身体锚点配准；不能逐帧包围盒等高缩放，不能只旋转人物或武器假装新全身动作。扩充单元格容纳斜举棍头，保留旧非攻击像素。

验收需同时满足：三种击打姿态可辨；两腿与双手完整；棍轴穿过握持手；末端握持与棍长稳定；头部和躯干比例分别符合预算；横扫/斜打/直戳各自接触时有反馈；BP 和技能规则无额外结算；实际开始部分守路战自动完成，并交付实机视频。
