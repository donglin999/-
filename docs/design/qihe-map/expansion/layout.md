## 空間生产和阻挡约束

- A–B/C/D/E边缘需重绘可见出口并更新掩码，禁止只在岩壁或河水上挂传送触发器。
- 开场B为固定演出；P03换衣完成后正常重访B，不需要现代装四向步行。深山支路用连续坡崖/溪沟结束，不画一条看似能走却被空气墙封住的路。
- E至F开始部分开放，C1送老人活动直接使用；序章入口由正在修理的可见便桥及工人说明，风起栖河段修复是必达事件，不能要求玩家先选修车支线。修车支线修的是车，不是过桥许可。
- G开放与“已选择山居”绑定，是同行目的地而非可提前搜刮的野外；此前山道入口用实际谷门和说明承接，不在路中间静默阻止移动。
- 徐、岑、沈与乌魁采用明确分时固定站位；程铎保留在巡江司，不因有素材而部署到栖河。部署与可达性按8阶段检查和实际浏览器核对，不以角色参考图代替。
- 火灾状态只改变有画面依据的局部脚印；每个救援阶段保留至少一条能走的出口。存档加载在合法安全点，不能恢复到烧毁或封闭的地面。
- NPC按`阶段+活动+去向`配置唯一位置；切区只显示当前阶段，不能留一份旧NPC在原处。只在事件切换站位的普通NPC不强制生成行走。
