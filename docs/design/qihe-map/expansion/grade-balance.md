# 品阶、命名、特效与初期数值核对

状态：现行　最后核对：2026-10-19

2026-10-06 本地实施规范。适用于本工作区；不自动采用兄弟工作区的品阶表。品阶是功法体系/器物制作水平，重数是掌握程度；内力费用、品阶、重数不互相替代。

## 品阶与命名

统一丁、丙、乙、甲、绝五阶，对应原装备 q=0…4，保留存档数字，只改显示。开始部分即显示。丁为普通器物/粗浅技法；丙为可靠制作/完整入门体系；乙为专长传承；甲为名家体系；绝为罕见顶级传承。普通物品不加“神、圣、天罚”等夸大前缀。材料、剧情证物不强行排名。

现有装备：练习棍、枣木短棍、桃木剑、厚背柴刀、铜针囊、粗布短打、平安符、铜铃项圈为丁；麻布夹袄、牛皮软甲、精铁剑、井底锈剑、青玉佩为丙。锈剑的丙代表原制作及剩余战斗能力，并非外观新旧。

护路棍法为丙，横杆护身是一式，不拆成两个功法。伏虎拳、柳叶剑法、乞儿摔碑手、牧羊鞭法、莲花落为丙；刮风脚为乙；静心诀、吐纳法为丁。医术中的金针刺穴、回春散、百草露、定神为丙。头目鬼头斩/翻江刺为丙级敌人招式；兽类行动和普通攻击标丁，不作为可授予功法。

门派主修玉泉心经、百衲功、浩然诀、太和玄功、本草经、毒经为乙；军中吐纳及其余基础辅修为丙。目前无甲、绝级实装功法或装备，不能为了凑齐五阶把已有普通内容抬级。心法未生效特性仍明确标注，不纳入强度计算。

## 特效预算

保留 T0…T3 预算：丁最多T1、丙最多T2、乙/甲/绝最多T3，同时受内力档位上限限制；头目明确允许高一档，但不得超过T3。高品阶初层低耗招式允许克制演出，品阶不保证每一式全屏爆发。BP只增强本档预算，不越级。

护路棍法从误用T0改为T1：施术者短暂土金色护身双弧、命中棍环与尘土，无全屏压暗、巨型法阵。翻江刺补T2登记，避免因不在BSK中漏检而回退普攻。音律补独立青玉色波纹，不回退拳击。后续甲/绝需要新增独有形态和图标验收，本轮不宣称已有完整五阶素材。

## 数值核对标准

采用实际引擎公式，不以价格或面板增长百分比单独判断强弱。统计无装备、单件、三槽组合、需求、购买价、MP/BP/重数和敌方攻防。命中伤害为攻击×倍率−防御×0.5，弱点×1.25，破势×2，暴击×1.5，随机±8%；概率和行动顺序单独处理。

开始部分基础五维3、境界1：气血114，内力62，攻击19，防御9。短打+4防御实际每次少2伤害；枣木棍+5攻击有明确但有限提升。平安符定力+1额外带来防御+2、内力+7，加词条10共+17，需如实显示。高价青玉佩走悟性/暴击路线，不用价格强制做全属性上位。

练习棍仅教学；运输赠正式短棍。柴刀需臂力4，不能开局越过要求；铜针囊切暗器后不能使用需棍的护路棍法。保留当前装备值和价格，数值脚本输出敌方样本和组合收益。开始部分敌人本来有剧情支援和低攻击系数，不为了抵消赠装而自动抬怪。

定神描述按实际改为2回合、伤害+30%、所受伤害−20%，BP每点多1回合；恢复类预览按气血上限比例说明。开始部分功法最多4重并不表示立刻可升满：属性、兵刃造诣及熟练仍有门槛。

本页仅核对已接入旧战斗引擎及开始部分内容，三年培养到后期数值曲线、甲绝图像差异仍需各阶段实际课程和敌人数据验证。
