# 关系、送物与回信

状态：现行　最后核对：2026-10-19

2026-10-06 用户确认方向：关系分阶段、有关键剧情瓶颈；送物、回信和回物须反馈，每个角色独立编写。本轮实施归云谷现有四个往来对象，不将旧苏芷好感−10…20换算为本版关系。

## 当前问题

旧培养送物只扣资源并记录通信成果，回信内容多为通用“已收到”。普通回信没有可见收件箱；旧菜单好感只有数值阈值，无阶段门槛。通信成果是阅读书写经验，不能当人物好感。

## 四阶段与瓶颈

关系值0…100；初识0…19，熟络20…49，信赖50…79，托付80…100。每个对象从0开始（不是抹除旧剧情，只是不凭空赠送关系值），已发生的关键事实用于开放阶段上限。达到19/49/79后停在当前阶段，显示具体要求，送物不能越级，也不存隐藏溢出值。突破开放上限，不凭空把0升为20；仍需真实互动积累。

| 对象 | 初识→熟络 | 熟络→信赖 | 信赖→托付 |
| --- | --- | --- | --- |
| 周砚 | 正式拜师joined | 已受吐纳指导且完成首次同行送药 | 后续师徒重大选择，尚未开放 |
| 叶蘅 | 药签上的空白herb_labels | 首次送药且参加白鹇谷药材记录交接 | 后续学医/同行重大选择，尚未开放 |
| 陆衡 | 话别说得太满promise_scope | 首次同行送药 | 后续履行护运承诺的关键剧情，尚未开放 |
| 乡邻 | 实际回访visit_neighbors | 回访且首次同行送药 | 后续安置与回访关键剧情，尚未开放 |

乡邻是目前安置点通信对象，不是第五位虚构队友：陈伯与周婶分别作为回信署名人，不能共用一句“感谢你的礼物”。既有错过窗口可能限制关系，但不阻挡主线、学基本功或一般回信；不补记未经历的事件。第三道门目前保留瓶颈，不伪造后期事件已实装。

## 日常积累与防刷

送信+1；普通送物+1；契合当前用途的礼物+3。周砚重视日用布包（练场小物）、叶蘅药材（明确只是普通药材）、陆衡干粮（护运行路）、乡邻布包（安置收纳）。连续近期送同一物品：最近5期已有1次降至+1，已有2次降至0。每人每月礼物贡献最多4、信件最多2；同一期每人各1次信/礼，沿用现有限制。重复或瓶颈反馈明确“本次关系+0”及原因；仍可选择表达关心，不强制礼物变成付费解锁。

具体剧情达成通过上述事实开放上限。回信、回物领取不增加关系，不以反复点收件箱刷值。关系独立S.cultivation.relations，不使用S.aff解锁旧苏芷教学或恋爱。

## 人物反馈与回物

- 周砚：克制、问实际用途；干粮让留给练后，药材交药圃，布包用于装木楔。不承诺传秘技。首次布包回信带一份普通布料，供补磨坏的绑带。
- 叶蘅：先确认药材来源和标签，不将普通馈赠视作取用家传物或恋爱资格；收到干粮提醒自己也吃，布包用于空白药签。首次药材往来附一份已分拣普通药材，说明与来礼分开，不说凭空炼成药。
- 陆衡：谈路上怎么用；干粮留给下一段路，药材说明会单独捎至药摊，布包装路单。首次干粮往来附一份普通食材，由途经集市购得，非自动无限补给。
- 乡邻：干粮由陈伯署名报休养近况；药材由陈伯说明先请医者辨认；布包由周婶写安置点整理行李。首次布包往来附普通布料一份，作为修补用余料。

每种礼物有独立即时反应、下一期回复；近期重复礼物有该角色专属简短反馈。寄送结果显示扣除数量、实际关系增量、当前值/上限、瓶颈、回复预计到达。远程送物只先显示投递结果和待回信，不能假装当面听见对方讲话。

## 收件箱与存档

邮箱增“回信”页，显示未到达/未读/已读，正文、署名、源礼物及回物数量。到期方可阅读领取；回物阅读时一次写入资源，读信与回物标记同一结算；重复阅读只查看正文。未到期禁领，取消无变化，重载不重发。旧信保留原文，不给旧往来反向补关系、补礼物或虚构关键事件。旧档关系字段按无记录补齐，已发生事实仍有效。

本地持久化写入失败时动作回滚并提示，不把失败领取展示为成功。当前归云谷通信仅三类可赠资源；背包装备与要物仍不可赠送。本轮不新增图像、立绘或语音，保留正式登记原件。

收束边界：三年第36月末没有下一期投递窗口，该期停止新的送信/送物，避免产生永远不可领取的在途回信。送物卡片提前显示实际关系增量；瓶颈和本月贡献上限时明确+0。邮箱主页显示到期未读数。

## 关系线（2026-10-09）

规则以文档库 `xiaojianghu/docs/design/romance-rules.md`（关系与结缘细则）为准，本节只记实现。

- **按关系换台词**：`qh-mode-cultivation-household.js` 的 `REL_ALT`，按“剧情 id → 原句全文 → 版本列表”覆盖；版本写 `who`（往来档案 id）、`min`（关系值）、`adult`（只在第二年起），取最后一个满足的版本。剧情上下文 `extra(s)` 带 `rel`（各人关系值）与 `adult`（`s.month>=13`）。生成剧本与闲逛支线不改原文件，全部走覆盖表。
- **关系够了才出现的选项**：`CHOICE_NEED`。代师出行“我跟小师叔去”要小师叔 ≥30；中秋“去屋顶找小师叔”要 ≥55。不够时该选项不出现；窗口一过即错过。
- **瓶颈剧情**：定义里写 `relNeed:{id,min}`，可用性检查（`CultivationCore.availability`）不足时提示“与某某的关系还不够”。叶蘅第三道瓶颈“灯下的方子”（`gy_ye_lamp`，第一年十一–十二月下旬，书房夜，叶蘅 ≥70）。
- **错过**：往来档案的 `missed[阶段]={until:时段号,text}`，过了时段号还没过瓶颈，关系页提示改为“已错过……，关系停在某阶段”（`inspect().missed=true`）。殷红缨：代师出行（七月月底）、中秋（八月中旬）；叶蘅：灯下的方子（十二月下旬）。
- **结缘（心意）**：独立剧情，不挂任何日历节点。殷红缨“屋顶上的人”（`gy_yin_bond`，庭院夜，第二年起到第三年底随时可遇，`relNeed` 80、`adultOnly`）；“结缘”记 `gy_bond_yin`，“还没想好”可以下回再来。谷中日程显示“心意 · 殷红缨 · 屋顶上的人 / 闲逛庭院（夜）· 随时可去，不会过期”。叶蘅的心意剧情等第二年去向编排后再定地点。
- **年龄**：萧白第二年正月初一满十八；第一年所有版本只写友情。为此改了两句闲逛支线的原文：屋顶上的酒“今晚这一口，给你”→“酒你还不能喝——这口茶，给你”；雪夜屋顶“往后只跟你一起”→“往后你想上来，就上来”。

## 入队、if 线与切磋（2026-10-10）

规则以文档库 `xiaojianghu/docs/design/romance-rules.md` 第四、五节为准。本节只记当前实现。

### 入队与 if 线
- 殷红缨（培养期直入）：“代师出行”与她同行，当场入队；没同行的，第一年除夕时关系 ≥40 也留下入队。两样都没做到，除夕她的台词改为“开春我还得出趟远门”，存档写入 `facts.if_yin`，第二年起她不在谷中（不能再找她指点）。大地图的 if 线尚未制作，只有事实记录。
- 结缘前置：`gy_yin_bond`（屋顶上的人）要求先看完个人篇 `gy_yin_past`（十几年前的寿宴：第二年起、关系到托付后，夜里去竹径）。
- 汇总：每次同步时把 `{yin, ye, lu}` 的入队情况、if 事实、基础事实列表、个人篇与结缘写入存档 `qiheRoutes`（`CultivationHousehold.routes`）。陆衡的基础事实取自“话别说得太满”“多出来的半天”“首季护送”三件事。

### 切磋与实战
- 剧情定义带 `fight:{bg,foes}` 的，对白走到选择处时显示“开始切磋／迎战”，进入真实战斗（单人、不会战败出局、不能逃跑）；剧本的两个分支固定为 `win`、`lose`，按结果接对白。
- 收益：已学剑则给入门剑式熟练，否则给拳脚熟练，胜 6／负 3；都没学时给该剧情原定的收益。结果栏照常显示“某项 ＋N”。
- 同门切磋（`repeat`，列在“招式”栏）：卢小豆、方迟、钟拙在练武场，殷红缨在竹径。要求先学会一门招式；每个时段只能切磋一场；胜负都加一点关系（胜 2／负 1）；每位对手首胜送一份干粮。对手不在谷时不可选：方迟回谷前、下山历练与养伤期间（到第 56 时段为止）；殷红缨回谷前，以及走了 if 线之后。
- 剧情实战：`gy_fang_spar` 陪练（方迟只守不攻）、`gy_bamboo_wolves` 竹径的狼（第 6–11 时段去竹径闲逛遇到，两只狼）、`gy_zhou_test` 出门前的考校（第 18 时段自动，周砚只用三成）、`gy_year_exam` 年终考校第二题（对殷红缨）。年终考校里钟拙的评语在切磋胜场 ≥5 时换一句。
- 素材：方迟、卢小豆、钟拙、殷红缨各一张 96×116 静态四向小人（`art_sources/guiyun-spar-sprites-20261010`）；殷红缨的场景与战斗小人同步换成这一版，旧图保留未删。战斗里对手没有专门的出招动作，用程序化的前冲与受击；萧白用已有的战斗动作表（短发造型）。
- 战斗静态帧现在能画图集里的子帧（`js/bfx.js`），此前只有带战斗动作表的角色能在战斗中显示。

## 闲话与交情（2026-10-10）

规则以文档库 `xiaojianghu/docs/design/bond-banter.md` 为准。本节只记当前实现。

- 模块 `js/qihe-banter.js`（全局 `QiheBanter`），不属于培养模式。**培养界面里没有闲话**：谷里的人有话在剧情里直接说。
- **交情**：存档 `S.kinship={'甲|乙':场数}`。战斗结束时给当前队伍里的同伴两两各记一场（包了一层 `battle`，不改它的行为）；赢或输都算，逃跑、单人战、教学战不算。6 场相熟，18 场知己。与萧白和各人的关系值互不影响。
- **闲话**：每条写明能出现的地方（`hangao` 汉皋城、`worldmap` 大地图自由模式）、两个人、门槛（同伴之间看交情阶段，萧白与同伴看关系值）、可选的前置事件和是否要萧白满十八岁。`QiheBanter.due(S,地方)` 返回现在该提示的一条，没有就是空；`blocked` 说明为什么不出现。每条只提示一次，`S.banter` 记提示过和看过的，`book` 列出闲话册。
- **内容**：8 条示例（叶蘅×殷红缨 4 条，其中 1 条是剧情闲话；萧白×叶蘅 2 条；萧白×殷红缨 2 条）。
- **还没有地方显示**：汉皋城和大地图自由模式不在当前游戏里。提示、播放（Q 版对白）、闲话册的界面等这两处做的时候接入。
- 验证：`node tools_scene/qihe/verify_banter.cjs`（7 项）。
