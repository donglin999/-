## 信息的三个层级

| 层级 | 显示什么 | 触发 |
| --- | --- | --- |
| 常态 | 人物/物品/技能美术、必要短名、血蓝、数量、选中/禁用/出战状态、重要消耗与操作对象 | 始终可见 |
| 快速详情 | 名称、类别、核心效果、当前/替换差值、不可操作的原因 | 悬停或键盘聚焦 |
| 深入详情 | 完整属性、词条来源、BP分档、突破条件、长背景文字 | 点击详情入口或固定浮层后展开 |

不能把所有文本删掉后让用户猜图标：导航保留短标签，根基保留名称及值；悬停解释含义。决定一次操作所必需的对象、数量、花费/不可逆代价，在确认层必须出现，不能只藏在悬停里。

## 各页的图像组织

### 人物

- 中央以当前人物单独立绘为主，约占屏幕高度70%—85%；环境淡雅，构图预留左侧状态与右侧三槽位置，不盖脸和手。
- 场景随阶段读取：现代醒来、借衣入村、后续入门分别匹配；本图为短发借衣萧白，不能误用长发门派装或虚构村名。
- 五维用五个有辨识度的图案和小数字：臂力、根骨、身法、定力、悟性。悬停显示当前值、来源及作用。
- 兵器、护具、佩饰三格用实物图；空位是淡轮廓加号。身穿便衣不自动等于护具已装备。
- 下方四个小出战头像、独立宠物标识与“编成”入口。点击已有头像切查看对象，点击空位进编成；人物页不隐式上阵。
- 攻击、防御、暴击等完整计算移入“属性详情”抽屉，不常驻六行表格。

### 行囊

- 保持独立大页。左侧紧凑操作对象＋可折叠人物展示，主体为物品网格；取消右侧永久文字详情栏。
- 物品格默认只显示高辨识图标、叠加数量及状态角标。名称在悬停出现；同轮廓物品需靠不同实物设计/非颜色角标区分，不能只靠稀有度颜色。
- 分类用物件图标＋短名，搜索/排序入口收紧；保留数百条目的列表滚动机制。小库存不铺满空格，大库存不牺牲可见图标尺寸。
- 1672×941预览显示8列4行；实际布局按宽度分档，1920目标8列5行。1280可收起大立绘，以6列或更多可读物品为优先，不能把整页缩成小字。
- 悬停只预览，单击选中出现细选框和操作条；明确点“装备给萧白/对叶蘅使用”才修改数据。双击不默认消费。
- 换装浮层对比当前对象，绿色加值必须同时有符号；无法装备直接写短原因。长词条可固定浮层再展开，不强迫追逐鼠标。
- 出战/候补/在场检查继续按V3；视线落在另一人头像上不切换操作对象、不消耗物品。

### 武学

- 功法用卷轴/封面，招式用有动作含义的图案。常态保留短名、重数、小内力标记、熟练环与可施展状态；不铺满效果段落和BP表。
- 悬停说明对象、消耗、段数/削盾、主要效果；点击打开详情浮层，里面才可切BP0—3和看修炼来源。
- 招式、内功心法、被动效果仍分开；取消六主动槽的机制提案保持。图像化不把被动摘要误做成新装配槽。

### 编成与其他页

- 编成保留四个人类大头像/半身卡和候补肖像带，姓名与出战状态常驻；定位、主要招式、限制原因悬停显示。选人、选位置、应用仍是明确点击步骤。
- 候补多时滚动，不用人物履历占满右栏；放大选中人物与短定位即可。宠物与人类区域明确分开。
- 任务以地点小画/事件插图加标题和当前目标为主；详情点开。设置保留明确控件标签与当前值，可读性高于强行图像化。

## 浮层与输入合同（待实现）

1. 鼠标停留约180毫秒展开，移出目标和浮层后约120毫秒收起，便于移入浮层。一次只开一个快速浮层。
2. 浮层锚定目标，在视口边缘自动翻转；避开当前目标、人物面部和确认按钮。正文超过约六行时转为“查看详情”，不让大浮层盖住半屏。
3. 悬停边框是细高亮，已选中使用明确角标/实线；焦点、悬停、已装备、已出战不能只用同一个发光效果表达。
4. 键盘聚焦获得与悬停同样的信息；Enter选中，详情键/按钮固定浮层，Esc先关详情再关菜单；搜索输入期间不触发游戏移动。
5. 触摸单击选择并显示详情，不悬停也能完成全部操作；第二次明确点击操作按钮才执行。点击空处关闭快速详情。
6. 普通浮层不抢焦点，固定详情有可达关闭按钮、正确焦点恢复。所有纯图按钮提供可访问名称。
7. 切人物、筛选、条目消耗为0时清理旧浮层与动作目标；不能显示甲的预览却扣乙的物品。
8. 快速详情和完整详情读取同一套派生/资格接口；图片不包含生产数值、人物名、按钮文案等动态文字。

## 美术资源与实现要求

| 美术层 | 要求 |
| --- | --- |
| 角色与阶段背景 | 分层保存透明角色和背景；可单独切人物/服饰/场景，不把图中的状态文字烘焙进去 |
| 导航与五维图标 | 同套笔触、光照、边框；常态/悬停/选中/禁用通过界面叠层实现；图意可辨 |
| 物品图 | 独立裁切、统一占格比例与透明边缘；相似物品有真实形状差异；缺图用一致占位和短名兜底 |
| 功法和招式 | 功法封面与动作图标区分；未学/不可施展用明确角标，不能全靠灰色 |
| 槽位与浮层 | 边框九宫格或可缩放组件；数值和文本由代码渲染，保持中文清晰 |

生成图只确定视觉方向，不是这些正式资源已完成。后续复现需拆分生产资源、沿用既有角色身份标准，并在实际分辨率检查，不以放大整张截图冒充UI。
