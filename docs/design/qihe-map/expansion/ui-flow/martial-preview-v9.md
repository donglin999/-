## 构图和操作

- 左侧约30%：大立绘、场景、姓名及角色切换；保持原人物身份。
- 中部约43%：已学目录、全部/外功/内功筛选、名称搜索，双列紧凑图标条目；常驻名称、重数/层数、类型和当前可用/运转状态。长列表独立滚动。
- 中部下方：选中对象熟练进度、提升条件入口；精确条件点击后查看，不常驻长说明。
- 右侧约27%：选中招式名称、最少必要效果、BP预览；下半部固定内功运转概览（主修/辅修），点击内功再展示配置动作。
- 悬停给短说明；点击固定右侧详情。选择外功不会学习、遗忘或装配；选内功后才出现对应主/辅修动作与确认。
- 开始部分示例只列教学后已学横杆护身，内功锁定。另设明确标注的“容量示例”展示现有数据中的8条目录，仅检验布局，不声明当前萧白全部学会。
