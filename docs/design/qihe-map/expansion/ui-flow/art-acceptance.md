## 动态界面标准

- 数值、姓名、按钮、数量、锁定原因都由代码渲染，不烘焙进图片。
- 四人同屏按统一脚底基线；缩窄时横向滚动或收起详情，不把四人压成细条。
- 1920×1080、1280×720均需真实运行截图验收；文件检查及合成接触表不能代替运行验收。
- 悬停说明不得遮住当前目标脸；键盘聚焦、触摸点按可获得同等说明。
- 透明缺图可用同角色原立绘卡片明确兜底，不随机换人、不制造未加入角色。
