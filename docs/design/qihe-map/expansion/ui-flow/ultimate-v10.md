## 定位

特殊招式名为“绝式”，所需资源叫“战意”。外功保持已学即按条件施展，BP 保持现行蓄势；绝式独立占用一个出战位，内功仍是一主修与有限辅修。学习多门绝式可以选择战前携带哪一门，不占普通招式位。

## 规则提案

| 项目 | 初版规则（待平衡） |
| --- | --- |
| 战意归属 | 每名人类角色独立0—100；入战为0，战后清零，不跨战存储；宠物本版不加入。 |
| 正常行动 | 完成一次有效普攻、普通武学、治疗、增益或防御，+10；多段/群攻只计一次；治疗需确有恢复，增益需确有应用；物品/逃跑不涨。 |
| 受击 | 每次敌方行动确实损失气血，+8；多段/群攻对同一人只记一次，免疫/闪避/零伤不记。 |
| 破势 | 亲自造成至少一次破势额外+15；同一次行动只计一次，仍受回合总上限约束。 |
| 总限 | 每名角色每个战斗回合最多获得30战意，统一结算并截断至100，回合初重置获得计数。 |
| 释放 | 已领悟且已设为出战、战意100、当前轮到本人且能行动、兵器等专属条件满足、目标合法。 |
| 消耗 | 占用本人的一次正常行动，成功提交时消耗100战意；不另耗内力，不叠加BP；不改变原有BP自然恢复判定。 |
| 提交边界 | 选目标/返回不扣战意。最终确认时复核全部条件，再原子扣除及执行；失败不扣。重复确认只结算一次。 |
| 防循环 | 绝式本身不产生行动/破势战意；敌人后续有效攻击可继续积攒。未满不能先透支，满后不自动释放。 |
| 死亡与复活 | 倒地清零，倒地不积攒；复活从0开始。不可行动时即使满值也不显示“可释放”。 |
| 装配 | 每人1个绝式位；战外可设置/替换/卸下；进入战斗后锁定配置。不把“点中查看”等同于出战。 |

以上是本项目方案，不声称与参考游戏公式一致。伤害/增益数值须以后续教学战、普通战与首领战回归调平；满值频率初步目标约3—6回合，未验证不能宣称已达标。

## 习得与样例

绝式属于功法衍生的独立能力条目；普通招式的重数仍是原数据。绝式不再新增一套重复十重；首版效果固定，后续强化如有需要另定义。

- **回风守关**：护路棍法衍生；拟在护路棍法第三重且完成陆衡后续点拨后领悟。需要棍类兵器。对单个敌人连续两击，每击基础威力1.15；每次有效命中棍弱点削1盾。己方存活人类获得20%护身减伤，分别持续到各自下次行动开始；与横杆护身取较高值、不相加，死亡不保留。这不是现有剧情已发放的技能。
- **伏虎震岳**：伏虎拳衍生；五重且完成对应领悟事件，当前仅作为“条件不足”的目录示例。效果暂不定数，未通过设计前不开放出战/释放。
- 来源未发现时只显示未知提示，不能借目录泄露未来人物或剧情。

开始部分现行教学只授予横杆护身；V10“第一章”预览不默认解锁绝式。新教学与领悟剧情若要落地，另同步章节脚本。

## 界面

沿用 V9 左侧人物画卷与正式图标；无江湖题字、无粗边框。

中栏上部保持已学功法目录，下部新增“绝式”独立双列区：图标、名称、所属功法、已出战/可配置/未领悟。普通功法筛选不隐藏绝式区，搜索会同时过滤两区。未领悟条目在本轮已知来源的演示中灰显，点击可查看条件。

右栏上部显示选中对象；选中绝式后显示效果短句、战意门槛与设置/卸下按钮。下部先“出战绝式”再“内功运转”。设置绝式不占内功或普通技能位。

独立的“战斗条件预演”只存在评审页：可切战意0/72/100与兵器，展示未满、满值但兵器不符、满值可释放、确认消耗后的状态。不把战外菜单中的演示数值当作真实积攒值。普通游戏武学页只写“战意满时释放”；战斗页在实际人物资源区展示战意和绝式指令。
