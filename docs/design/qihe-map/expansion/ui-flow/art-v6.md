# V6：细线与留白分区

状态：现行　最后核对：2026-10-19

2026-10-05 · [流程目录](README.md) · 替代 V5（已删除） 的纸框方案。

## 用户确认的方向

- 江湖页保留淡雅场景和人物美术；取消宣纸底板、金属角饰、整圈画框及黑色题签。
- 分区使用 1 CSS px 的近黑色细线（约50%透明度），配合留白。顶部导航下的线水平居中，两端各留4%空间。
- 气血、内力、修为为一组；与下方五维用一条短横线分开。属性操作与五维再用细线区分。
- 队伍、属性页取消右侧重复装备栏；装备页仍保留换装入口。左侧属性之外的区域用于人物展示，1—4人整体居中，按立绘宽高和人数调整组宽，显示高度保持一致。编成操作位于底部横线下，人物姓名留在对应人物脚下。
- 行囊取消人物栏；武学保留带背景人物画卷。各页内容排布与分隔按 [V7](interaction-v7.md)，边界线跟随布局，不固定穿过操作区。
- 物品格保留轻薄轮廓和选中反馈以明确点击范围，不使用装饰画框。抽屉用浅色底保障阅读，边缘只用单线；浮层不要角饰。
- 图标继续使用V5绘制徽章及既有真实器物/技能图；细线直接用CSS实现，不生成为位图。
- 探索地图HUD维持轻量悬浮，不能套用江湖分区装饰。

## 验收

- 打开队伍、属性、行囊、武学、任务、设置和详情时，区域面板的 `border-image-source` 必须为 `none`。
- 1280×720及1920×1080检查四人完整、姓名不出界，顶部线不穿头、五维线不穿图标。
- 详细说明仍悬停或点击查看，不能因去框增加主面板文字量。
- 旧V5框图作为历史资产保留，运行界面不再使用。当前截图见 `art_sources/jianghu-ui-v6/runtime/`。
