状态：现行　最后核对：2026-10-19

## 素材交付

| 资源 | 用途 | 验收重点 |
| --- | --- | --- |
| 四人独立透明立绘 | 总览同屏、选中放大 | 同一量尺、完整脚部、身份/阶段正确、alpha无边；不能裁截图提人代替正式原图 |
| 淡雅背景 | 人物/队伍/行囊 | 左右信息区低对比，四人不互挡，场景不误写地点 |
| 同源头像 | 名单、候补、操作对象 | 脸一致、裁切稳定，不把岑霜头像换成叶蘅 |
| 七导航/五根基/三槽/分类图 | 可交互入口 | 同一图案语法，正常/聚焦/选中/禁用可辨 |
| 物品和招式图 | 网格/功法/浮层 | 缩至实际尺寸可认，长名与缺图有兜底 |
| 可缩放边框/角标 | 浮层、空位、锁、数量 | 文本由代码渲染；不烘焙动态值 |

复用已验收原资产，新图只补真正缺项；先资源清单再批量生产。背景人物图与UI层分离，不能一张静态大图上贴透明按钮当正式界面。

## 实施顺序与完成定义

| 阶段 | 工作 | 通过后才能 |
| --- | --- | --- |
| P0 | 冻结页面职责/ID、资产清单，确认V3机制开关 | 开始接规则 |
| P1 | 统一成员/物品/技能读模型、结果可检测的存储、迁移 | 开启写操作 |
| P2 | 菜单壳、七页路由、输入与返回栈、悬停/固定详情组件 | 接各页交互 |
| P3 | 四人总览、选人、编成草稿、剧情锁、跟随/战斗快照 | 开放四人编成 |
| P4 | 物品网格、筛选、换装/恢复/秘籍事务、素材映射 | 开放行囊完整流程 |
| P5 | 属性草稿、武学详情、逐招BP、心法、培养同步 | 发布新武学规则 |
| P6 | 宠物、任务、行程、设置；素材与窄屏校验 | 端到端试玩验收 |

完成每阶段必须提供实际截图/测试输出，并标明哪条用例通过；设计截图不能作为运行证据。提交/部署/资源上云不属于本次流程包的交付。

## 验收矩阵

| ID | 操作 | 预期 |
| --- | --- | --- |
| A01 | I开关20次，B/J分别进入 | 一入口一动作；不叠监听、不移动角色、不扣时间 |
| A02 | 四人逐个点击身体与头像；悬停另一人 | 点击切人，悬停不切；左右对象一致，四人无遮挡 |
| A03 | 2→4人、满员替换、取消、保存重载 | 1—4有效人类；候补与装备完整保留 |
| A04 | 强制同伴/驻地/暂离；编辑时状态变更 | 不可绕过，应用复查，原因可读 |
| A05 | 换装/卸下/库存为0/条件不足 | 单次转移、差值正确、不偷卸他人 |
| A06 | 满血/部分伤/数量越界/取消/双击 | 实际恢复准确，无无收益扣除，无重复扣除 |
| A07 | 秘籍取消/无目标/未开内功；野草药 | 无误耗、无提前解锁、无草药服用 |
| A08 | 0/12/500库存，中文检索、换分类/人 | 图标可读、焦点稳定、仅可视行渲染，禁用信息可达 |
| A09 | 加点确认/重置/切人/读档 | 未确认不变，确认只写目标人一次 |
| A10 | 已学>6、BP0—3、低MP、不同兵器角色 | 新规则启用时列表完整；详情/AI/结算一致 |
| A11 | 换主修取消/确认/失败 | 仅成功有代价，主辅约束真实生效 |
| A12 | 四人＋宠物、主角缺席允许场景 | 宠物独立自主，无目标能回退；不出现第五个人类 |
| A13 | 打开任务与行程、取消活动、确认活动 | 查看不耗时，确认按本章正确计量 |
| A14 | 模拟存储失败/重复请求/自动存档竞争 | 不部分写入，不伪报成功，恢复不丢资产 |
| A15 | 键盘全流程、触摸、视口四角浮层 | 无鼠标也能操作；浮层不越界，Esc焦点正确 |
| A16 | 1920×1080 / 1280×720 / 窄屏 | 字图清晰，四人缩放有下限，窄屏可横滑而非挤成线 |

性能记录目标设备、数据量、打开/筛选耗时和滚动帧耗时；未建立基线前不虚报60FPS。可先以交互后100ms内出现状态反馈、无>200ms连续主线程阻塞为调查门槛，最终标准按实机基线调整。
