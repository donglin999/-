## 六个页签各管什么

| 页签 | 常态画面 | 主要操作 |
| --- | --- | --- |
| 队伍（1） | **四人同屏总览**，选中人一套状态/装备 | 点击人物查看，调整编成，宠物入口；根基详情、加点 |
| 武学 | 功法封面、招式图案、重数/熟练环 | 悬停效果，点击详情和来源；内功/被动子页 |
| 行囊 | 人物预览＋宽图标网格 | 查找、选择、确认使用/装备 |
| 装备 | 当前人物放大＋三槽，装备状态角标 | 看当前装备，筛选更换或明确卸下 |
| 任务 | 已知地点/事件小画、任务短名和当前目标 | 展开任务内容与记录 |
| 设置 | 图标分组＋明确标签控件 | 当前支持的声音、战斗主题、存档、操作说明 |

“队伍”对应已认可四人同屏图，“装备”是单人深入页。人物页和装备页的槽位使用同一组件与操作，不能各自计算装备。

2026-10-07：原「属性」页与「队伍」页实际渲染同一页面（partyPage），按用户要求删去「属性」页签，「队伍」移到首位，页签由七个减为六个；代码中旧入口传 `attr` 时统一按 `party` 处理。

探索HUD六个入口及快捷键：江湖 I（打开队伍页）、行囊 B、武学 K、任务 L、地图 M、设置 Esc（地图展开时 Esc 先收起地图）。菜单内 B/K/L 同样直达对应页。

任务追踪（2026-10-07）：探索左侧为追踪列表——「当前行程」（主线向导，J）在上，其下列出已追踪的进行中任务（最多 4 条，其余显示「另有 N 项 · L 管理」）。新出现的进行中任务默认加入追踪并弹提示；任务页每条进行中任务可「加入左侧追踪 / 取消追踪」，列表中以「◆ 追踪中」标记。取消追踪主线（序章/第N章）则隐藏「当前行程」行。追踪状态以任务名为键存于存档 `S.questTrack`。点击追踪条：村中活动/人物任务在小地图标出目标，其他打开任务页并选中该条。

## 入口和初次体验

- 第一次按I或点击江湖：打开队伍总览，默认选主角（在场时）。以后保留上次页签和有效人物。
- M 或右上地图圆章切换区域舆图，默认收起，Esc 收起；地图为探索浮层，移动仍可继续，菜单与对话优先。具体显示规范见 [开始部分表现](../chapter-presentation.md)。
- B直达行囊，J仍直达行程。现有B资源面板需整合为行囊材料筛选入口，不能同时触发两个面板。
- 打开前检查对话、转场、战斗、结算是否占用输入；被占用则保持当前流程，最多显示一次短提示。
- 打开菜单释放已按住的移动键并暂停探索输入；关闭不让按住的键导致角色突然跑动。查看菜单不消耗半日/培养体力。
- 没有存档或角色状态未初始化时不打开空壳菜单；加载失败显示重试/返回，不弹JavaScript报错。

## 交互层级

| 行为 | 反馈 | 数据影响 |
| --- | --- | --- |
| 悬停角色/图标约180ms | 细高亮＋短浮层；角色悬停不切选中 | 仅界面 |
| 移出目标及浮层约120ms | 收起浮层 | 无 |
| 单击人物/物品 | 稳定选中角标，更新对象/操作条 | 仅界面 |
| 点击详情 | 固定详情抽屉，可滚动 | 仅界面 |
| 明确操作按钮 | 校验后执行；必要时显示数量或代价确认 | 仅此步可提交 |
| 取消/返回 | 恢复上层焦点与滚动位置 | 未提交草稿不写存档 |

所有详细数据都能通过聚焦/点击访问，不能把必要信息做成鼠标独占。浮层≤约六行，更多走详情。禁用按钮仍可聚焦查看原因；不让浮层盖住目标、脸和确认按钮。

## 输入优先级与返回栈

- 输入优先级：确认弹层 > 固定详情/抽屉 > 当前菜单 > 探索。只有最上层消费事件。
- Esc：取消确认 → 关闭详情/抽屉 → 若有脏草稿则询问应用/放弃/继续编辑 → 关闭菜单 → 回地图。
- I再次按下遵循同样的关闭守卫，不能跳过未提交编成或加点。
- Q/E切页，1—6直达页，Z/C切人物；方向键移动本区域焦点，Tab跨区域，Enter激活，F1打开当前焦点详情。中文输入/文本编辑时禁止菜单与探索快捷键，Esc仅退出搜索编辑状态。
- 编成草稿中Q/E、I、Z/C等若会离开草稿编辑，同样经过脏状态守卫；不能快捷键绕过。
- 触摸：点目标选中/看简要，再点明确按钮执行；点击空处收起快速详情，不能点两次物品就直接吃掉。
- 装备槽跳转行囊携带 returnContext={page,actorId,slot,focusId,scroll}；返回先还原该上下文，再继续关闭菜单。

## 任务页阅读背景（2026-10-05现行调整）

任务页以浅暖纸色为主，原正式山水背景只在边缘淡露，禁止高对比建筑和树枝穿过正文。左侧索引与右侧正文有稳定纸色底，选中项用低饱和金色与细竖线。右侧「江湖行记」只保留紧凑文字题签，不重复铺第二张山水图；正式背景原件保留，不生成或替换素材。此项为现行任务页可读性调整，不表示V10预览全部功能已采用。

## 其它面板背景统一（2026-10-06）

属性、武学、行囊、装备、队伍和设置沿用任务页的暖纸底与弱山水背景。信息栏、详情正文、物品网格和设置卡片增加稳定纸色底；人物立绘和图标保持原色清晰。武学人物区的局部山水也压淡。现有背景图片及引用保留，先以CSS遮罩调节，不删除原件、不生成替代素材。

## 武学人物立绘（2026-10-06）

武学左栏使用当前选中人物的正式完整立绘，与队伍/装备采用相同来源，切换人物同步立绘、招式和详情。扩大人物展示区，姓名与身份放在下方紧凑题签；完整显示头部与脚部，不拉伸、不将地图行走精灵作立绘。立绘不受背景淡化遮罩影响。原山水背景及素材保留。
