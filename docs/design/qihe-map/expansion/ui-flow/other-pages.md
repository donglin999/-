# 宠物、任务、行程与设置

状态：现行　最后核对：2026-10-19

[流程包](README.md) · F11—F14

## 宠物

从队伍底部独立爪印进入。未结伴显示简短空态，不能生成可控人类位；已有大黄则用宠物形象、血蓝、项圈图标和自动行动提示。

喂食：选择已支持的食物 → 展示收益/数量 → 确认 → 单次保存并刷新。项圈同物品事务，不把人类全部兵器列表塞给宠物。悬停护主图案说明条件，无手动施法按钮。

四人以外宠物位仍为机制方案。大黄无主角目标时必须有自动行为回退实现，不能在界面展示“参战”而引擎空过。

## 任务与行程

任务页默认已接/当前，图为已知地点或事件，短标题和一行当前目标。点击展开细节、已完成阶段与已知地点；不显示未触发剧透、不虚构导航路径。没有自动完成/领取未知奖励按钮。

J现打开正式任务页，显示活动、地点与追踪；不显示半日预算或培养体力。开始部分活动不耗时、不自动推进主线，继续主线单独确认，详见[剧情规范](../story.md)。

任务追踪只改目标、不传送或执行；开始活动仍需实际NPC交互。前置不足则留在详情显示原因。两张静态任务插图就能满足列表展示，不为菜单额外要求大量CG。

## 设置与存档

当前确认支持：静音开关、战斗界面主题、快速保存、操作说明、存档管理与返回初始首页。2026-10-06用户新增的存档操作及失败/返回规则以[设置与存档管理](settings.md)为准。

音效/主题切换立即反馈并遵循现有配置持久化方式。立即存档必须返回可检测结果：成功显示简短“已保存”，失败显示原因/重试，不能调用吞异常函数后无条件报成功。

存档管理提供独立手动副本、载入、重命名及可恢复回收站。返回首页先保存，再回到当前版本的开始/继续选择页。云存档仍未接入。

## 通用返回

各详情返回原对象和原焦点；行程活动已开始后遵守该活动退出规则，不用菜单Esc跳过结算。关闭江湖回到打开时地图/坐标/镜头，清理菜单事件监听；无草稿和交易时无需额外确认。

当前页面布局与详情展示位置以 [V7](interaction-v7.md) 为准。
