## 信息结构

左侧：紧凑目录、主线／支线短分类与任务名，只展示正在进行／已完成两种状态；中止和未承办事项不混入。人物另有图鉴页签，具体布局与解锁规则以整改合同为准。

右侧：标题及章节 → 当前指引（下一步做什么、去哪里、找谁） → 事情起因 → 已发生的经过（按顺序记录） → 已识相关人物、已见文书与实际领取报酬 → 完成后的结果。中止事项不放入已完成目录。

正文是主内容，采用易读文字段落与小标题、细线分隔；不再放占据大面积的地图、人物或奖励插画。不为日志新增CG。

## 操作

- 点击任务读记录，长正文独立滚动；切任务回到该任务当前指引。
- 可以展开已发生的完整记录；未来步骤、真相和未见人物不得提前展示。
- 已接入“追踪任务”：切换该事项是否显示在HUD，不接取、不传送、不推进剧情、不领取奖励；完成事项不提供追踪，当前追踪显示明确状态。标记地点复用现有导航，继续主线复用原剧情确认流程。
- 去除跟任务无关的角色选择。日志阅读、搜索、筛选不消耗时间。
- 任务示例“护路棍法”的来源与报酬依据 qihe-chapter.js；只展示练习棍、笔记与横杆护身，不把新绝式当作该任务已发放奖励。
