# 设置、存档管理与返回首页

状态：现行　最后核对：2026-10-19

2026-10-06 用户要求在右上角设置中加入存档管理和返回初始首页。

## 入口与操作

探索右上角「设置」进入同一设置页，保留声音、战斗主题、快速保存及操作说明，增加「存档管理」「返回首页」。沿用现有淡雅界面和已采用图标，不新增图片资源。

存档管理显示当前旅程、原有旅程、所有新旅程及手动存档，注明章节、地点、保存时间和当前标记。旧记录没有时间则如实显示「旧存档，时间未记录」。只读取本版本正式栖河记录；专项评审档、襄阳试验档不纳入列表，损坏记录保留并注明不可载入。

- 快速保存：更新当前自动进度，保存成功后显示「已保存」。
- 新建存档：输入名称，复制当前完整进度到独立手动存档，不覆盖旅程或已有手动存档。
- 载入旅程：确认后先保存当前进度，再切换；载入手动存档时创建新旅程继续自动保存，手动原件保留，可重复回到该节点。
- 重命名：名称非空，最多24字；当前旅程的名称同步到运行状态，后续自动保存不会撤销名称。
- 移入回收站：确认后标记隐藏，记录仍保留，可在回收站恢复；当前正在玩的旅程不能移入回收站。不提供永久清空。
- 返回首页：明确提示「保存当前进度并返回首页」，成功写入后回到当前版本启动页；保留原有档与当前档，通过「继续进度」恢复，或「从序章开始」另开旅程。

## 写入与失败边界

章节状态、人物、背包、任务、培养与场景坐标整体保存；菜单打开后暂停移动，保存使用当前人物坐标。战斗、对白执行中不能调用管理写操作或返回首页。未应用编成/加点草稿仍沿用原有离开检查。

所有操作先校验，再写浏览器本地存储，成功才更新内存/跳转/提示。空间不足或浏览器限制时保留界面和原档，显示失败原因并允许重试；载入切换失败不会覆盖目标档。最近旅程指针仅在正式旅程写入成功后更新。回收站和手动原件不会被自动保存覆盖。

本功能为本机浏览器存档，没有云同步、导入导出或跨设备迁移。存档元信息附在记录内的`qiheSave`字段；原有无该字段的版本继续可读。

## 验证

实际存储逻辑检查全部旅程枚举、独立手动副本、载入副本保留原件、重命名后自动保存、回收站恢复、当前档保护、评审隔离、损坏档保护、保存失败不跳转、成功返回正确首页。浏览器走设置→存档管理→新建/重命名→载入→返回首页→继续，核对位置和正常移动；验收截图与执行结果写入更新记录。
