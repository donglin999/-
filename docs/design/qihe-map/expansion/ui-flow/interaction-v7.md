## 人物总览

属性与队伍均展示已应用编成中的全部角色（1—4人），点击人物/头像只切换左侧资料，不隐藏其他出战者。仅在调整编成并应用后改变人数；装备、武学是单人配置页。分隔线属于实际布局边界，不用绝对坐标横穿内容。左侧资料过高时独立滚动，操作与底部编成区不相交。

## 装备

左栏常驻当前气血、内力、等级、根基五维及全部已实现派生值，造诣/技艺/品德可滚动浏览。中栏人物、三个槽位、头像切人；右栏按槽位列出库存候选，选中后直接显示需求、说明和八项派生值的当前→替换预览（含未变化值）。装备/卸下明确确认，成功留在装备页；无候选、未满足需求显示原因。其他人穿戴物不混进可用库存。切人清除旧候选与确认。

## 行囊

取消立绘占位，以全宽图标网格呈现库存，常驻搜索、分类、装备部位筛选、名称/数量/类别排序及目标人物下拉。选中后底部操作条说明对象和实际收益，悬停/详情显示长说明。目标改变保留器物并重新计算可用性；筛选和搜索不修改库存。大库存继续虚拟行渲染。

## 武学

左侧使用正式人物立绘叠加已采用水墨场景，组成带背景人物画卷，底部头像切人。中栏招式/内功/被动目录，图标、名称、重数和可用性；右栏固定详情，招式显示内力、兵器条件、熟练进度、BP 0—3预览、效果及修炼来源。点击列表不会施放或升级；已学招式按现行战斗条件可用，不虚构装备技能格。心法切换沿用实际主辅修限制及确认成本。开始部分内功保持进入培养才开启的提示。

## 任务

当前目标置顶，左侧目录按进行中/已了结/已中止/全部筛选，并标明主线/支线。右侧显示所选任务标题、状态、已有描述及来源数据提供的地点/委托人/奖励；缺少的信息不编造。当前行程入口保持明确按钮，不自动消耗半日。不增加未接任务与剧透。

## 素材与验收

沿用正式 V5 图标、V4 背景及当前采用人物图，布局和细线由 CSS 实现，无新位图需求；不得复用已弃用纸框。浏览器核对两人同屏及点击不改变人数、编成换下后单人居中、两个角色资料不穿线、装备替换预览与确认、行囊搜索分类空态、武学 BP 只读预览、任务筛选和详情。另运行模型/界面回归与正式素材检查，失败如实记载。
