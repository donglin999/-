# 装备、行囊与物品使用

状态：现行　最后核对：2026-10-19

[流程包](README.md) · F04—F07 · [物品数据依据](../inventory-ui-v3.md)

## 换装：从角色到角色

1. 装备页选人、点兵器槽 → 同页筛选兵器候选；左侧常驻当前数值，右侧显示替换预览。
2. 悬停候选图标 → 显示短名、需求、当前/替换差值；不更改装备。
3. 点击物品 → 选中角标和操作条出现，明确“装备给萧白”；切对象立即重算差值、清除旧确认状态。
4. 点装备 → 再查数量、角色在场、部位、要求 → 把旧装归包、新装移出包、限制血蓝上限，作为一个事务。
5. 保存成功 → 槽位图和数量更新，短提示完成；留在装备页继续浏览。
6. 卸下从已装备槽的固定详情进入，明确点卸下。无装备时没有卸下按钮。另一人在穿的唯一一件不直接抢走，先去对应人物处理。

## 用药与永久道具

悬停看名称与效果 → 点击选择 → 选择在场目标 → 操作条显示当前血蓝、实际恢复与用量 → 点“对叶蘅使用1份” → 校验保存 → 刷新同一目标。

默认1份。普通恢复品可进入数量层，上限按逐件实际收益与库存计算；满值不扣，收益为0禁用。永久提升物、秘籍只单件明确确认，不提供全吃。选中不使用、双击不使用；连续点击提交时按钮锁定，防止同一动作重复执行。

## 秘籍与材料

- 武学残页：选对象 → 点参悟 → 选择符合门槛的功法/招式 → 查看提升和消耗 → 确认一次；取消任一层均不扣。无目标显示原因和修炼来源。
- 心法残卷按章节门槛判断；护路棍法笔记是要物，不因名字像书就出现消耗按钮。
- 枯枝/野草药/芦苇：短浮层显示类别与已知用途；详细页可看交付NPC地点。没有服用/远程交付按钮。
- 未知物品ID保留存档，界面用“暂无法识别”占位且不提供消费；缺图仍显示可辨短名。

## 大库存规则

一级全部/装备/秘籍/药食/材料/要物/其他，装备二级按部位；搜索按已有名称与描述，稳定排序。排序和筛选不改变实际库存。

8列网格按视口降至6列；数百条目按可视行虚拟渲染，键盘自动滚入焦点。网格格内只显示图、数量和必要状态，不常驻长名。0项有清空筛选入口；少量项自然留白，不填满假格。

悬停、选中、当前操作对象分开记录。翻分类清理失效选中；排序仍保留相同itemId；用尽选邻项并收起原浮层。焦点、筛选、滚动属于界面状态，不污染存档。

## 统一失败反馈

数量已变/角色不可用/条件不满足/保存失败：就地短提示并维持真实状态，不弹剧情对话、不关闭整页。失败不得部分卸装、扣道具或回血。保存结果可判断前，不允许显示“已保存”。

页面布局与常驻信息以 [V7](interaction-v7.md) 为准；行囊无立绘，使用紧凑目标下拉框。

## 当前装备页修订（2026-10-06，用户明确采用）

装备页右侧默认展示包裹中全部装备，支持全部/兵器/护具/佩饰分类、名称搜索、兵器类型（含音律）筛选。点击槽位仅选择当前槽位，不隐性限制目录；穿戴动作按所选物品实际部位执行。

取消底部常驻对比区和穿戴按钮。单击选择，悬停显示说明、需求和替换差值；双击直接经 QiheUIModel 装备事务校验保存，无二次确认。键盘 Enter 在装备条目上同样执行穿戴；双击提交防重、库存守恒、旧装备返包、失败完整回滚。已装备槽点击打开详情，提供明确卸下操作。

左侧气血/内力当前条保留，气血上限/内力上限独立列出；取消数值组标题，统一两列小图标+名称+数字。根骨改山岳意象。造诣新增音律，琴/箫作为同一兵器类型归一为音律；复用已有造诣成长与伤害规则，不能因为界面显示就发放新乐器或虚构对应技能。正式图标另登记来源，不从预览整图裁角色。

以上取代本文早期装备页操作条及常驻对比描述；行囊药食/秘籍的确认规则不变。
