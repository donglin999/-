# 属性、武学、内功与被动

状态：现行　最后核对：2026-10-19

[流程包](README.md) · F08—F10 · [机制核查](../martial-ui-v3.md)

## 加点

五维图标悬停说明当前值与加成来源；点击“分配”才进入草稿。待分配为0时保留可查看属性，隐藏或禁用加点入口。

加减点在内存预览，派生值以正式计算器模拟；重置仅重置本次草稿。确认后复核可用点/单项上限/目标，统一保存。切人、切页、关闭有草稿时走应用/放弃/继续编辑；未确认不得增加实际属性。

造诣、技艺、品德从属性详情抽屉查看，按现有系统显示；未实现作用标状态。人物总览不铺密集表格，深入抽屉可使用必要数值表。

## 招式查看与修炼

点击武学 → 保留人物 → 正式武学图标目录 → 悬停消耗/主要效果 → 点击固定详情。

详情才显示重数、熟练、作用范围、兵器、段数、削盾、BP0—3效果和突破来源。BP切换是纯预览，不增减角色BP或内力；未知弱点不提前泄露。不会因点击技能图就学会/升级/装备。

主动无六格的方案：已学按施展条件进入战斗列表；角色学习范围、当前兵器、有效内力、状态共同判断可用。尚未完成该机制迁移时不发布与实际规则相矛盾的UI。原型必须显式标提案状态。

修炼来源点击后展开已知剧情/秘籍/请教地点；未发现来源只给未知提示，不泄露后续人物地点，不传送、不自动交付。不在菜单免费提升熟练或突破。

## 内功与被动

开始部分点内功显示锁与“第二章开启”，返回仍选同一人。开放后用心法图和主辅修角标呈现。

换主修：点心法 → 查看适配 → 点设为主修 → 代价层明确内力清空、不稳等实际代价 → 确认 → 保存后生效。取消不清内力。辅修数量/境界、阴阳冲突依正式规则，不额外创建四被动格。

被动页只汇总心法、装备、人物等已有来源，悬停说明来源和生效条件；不可点图标就卸掉不可卸的人物特质。

## 战斗交接

菜单配置提交后，入战生成快照；战斗中不允许通过菜单换装、编成、主修来刷新战斗状态。战斗列表与详情、AI读取同一“能否施展/有效消耗/BP成长”接口。

横杆护身样例：第一重基础威力1.10，内力3，单段命中棍弱点最多削1盾；BP提高伤害，护身15%至下次本人行动前。该样例不能套用为所有招式BP规则。

当前武学页面布局以已接入的 [V9](martial-preview-v9.md) 为准：双列目录、搜索筛选、中部熟练进度、右侧固定内功运转概览。其他页面仍按 V7。
