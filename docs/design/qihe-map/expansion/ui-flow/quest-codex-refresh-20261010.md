## 版式

共享顶栏沿用现有六项绘制徽章。行记内横向两页签“任务”“人物图鉴”；当前位置只用紧凑章节标签，不再以100px主线横幅占满全页。

- **目录**：约220px（1600下约15%，1280下约19%），条目约64–80px高；头像／委托图标加短名、短分类，去掉重复地点、状态长句。提供收起目录，缩成约72px图标列。条目不为了填满高度而均分。
- **任务**：目录顶部“正在进行／已完成”两项；主体为任务标题、下一步、起因和已发生进展。辅助栏用头像显示相关人物，用文书图标展示已见材料，地点／交还方式是任务信息，不塞回人物图鉴。
- **图鉴**：选人目录很窄，主体为原有完整人物画像与档案。档案含姓名、势力、已知身份、初识地点、短小传、事件经历、相关人物、关联任务。没有“可交谈”“尚未询问”或标记人物按钮。初识地点是历史信息，不承诺实时人在那里。
- **图标**：复用正式V5绘制徽章（任务卷、人物、书册）、正式人物立绘／头像、可辨认物件；文字仍作为说明，不能靠同一卷轴冒充所有不同概念。勾选节点用原生状态符号，不作为新美术资源登记。
- **字体**：正文18–20px，标题32–40px；辅助分类14–16px。正常字距，宋体用于题头，系统中文字体用于正文；保留淡雅暖底与细线。

人物图鉴是用户本次要求的新增展示职责，允许人物美术作为主内容；这不把任务日志重新改成大幅地点插画，也不改队伍页和出战机制。
