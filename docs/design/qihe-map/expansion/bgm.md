## 本次修正

日常明确温馨、放松、有归属感；战斗明确激烈、热血、有持续推进，参考《八方旅人》的JRPG战斗音乐方向。撤销V1“战斗小编制且克制”的限制，也取消强制共用四音动机，先把两种场景的情绪区分清楚。

查阅了[任天堂公开的制作人及作曲者介绍](https://www.nintendo.com/en-gb/News/2017/December/Behind-the-music-of-project-OCTOPATH-TRAVELER-1321210.html)（经典RPG情感与现代动态表现），以及[Square Enix《Break & Boost》介绍](https://www.jp.square-enix.com/music/en/lineup/item/SQEX-10703.html)（轻钢琴与更有分量的乐队编曲）。以下配器是本项目据此制定的原创方案，未提取或上传原声音频，不声称已逐音听析原曲。

## 日常《溪桥日暖》V2

- 温暖柔软的钢琴主旋律，木吉他轻柔分解和弦，小弦乐与大提琴低音铺出舒适和声；圆润木管回答，古筝只作少量点缀。
- G大调，柔和六和弦/附加九度和声，完整而亲切的旋律句；取消异乡不安、悬疑、悲伤与故意空旷的情绪。
- 目标72 BPM、4/4。舒缓但有连续伴奏，避免薄弱独奏、尖锐笛音、金属拨弦与明显鼓点。
- 本次60秒样段：0–18秒主旋律 → 18–36秒木管回答 → 36–48秒温柔变奏 → 48–60秒主题回归。

## 战斗《护路初锋》V2

- 快速弦乐十六分音符持续推进；圆号/小号唱出鲜明主题；活动贝斯、鼓组、定音鼓形成节奏支撑；少量琵琶加强武侠音色。
- 目标156 BPM、4/4、E小调起点，有上行模进、旋律对答和强拍合奏。激烈度来自编曲与节奏，不靠单纯放大音量。
- 开场数秒即进入战斗，不做漫长铺垫。保留可记住的主旋律与清晰层次，避免纯音墙、预告片式音效轰鸣、长时间停鼓。
- 本次60秒样段：0–4秒强起 → 4–22秒主主题 → 22–38秒上行与对位 → 38–48秒保持节奏的对比句 → 48–60秒全编制回归。
- 狼战与守路战共用主曲；陆衡对练后续可出轻编制混音。当前先验收主曲方向。

以上BPM、配器和段落均为生成目标，尚需听审确认；60秒样段不是最终无缝循环。保留44.1kHz双声道MP3、日常-20±1 LUFS/战斗-18±1 LUFS、真峰值不高于-1dBTP的技术门槛。

## 场景与交互切换合同

| 情境 | 目标行为 |
| --- | --- |
| 村中 → 南/东/西外区 → 同主题室内 | 同曲保持播放位置，不因换地图、进屋、走跑而重播 |
| 对话 / 三路支线 / 江湖菜单 | 保留背景；普通文字对话降低约3 dB，有角色语音时降低约6 dB，结束平滑恢复；嵌套对话不能提前恢复 |
| 狼群出现至战斗初始化 | 日常曲约0.6秒淡出，战斗准备好后约0.2秒淡入；不等待音乐播完才允许操作 |
| 选择指令 / 目标 / BP / 自动战斗切换 | 战斗曲连续；不按每次动作、每回合或选项切换重新触发 |
| 破势、受击、技能语音 | 音效独立；必要时短暂压低BGM，不重启音乐 |
| 胜利结算 | 战斗曲约0.8秒淡出，现有短反馈一次；按返回剧情决定恢复日常或保持安静 |
| 失败 / 重试 | 失败淡出，无欢快恢复；重试从战斗开场重进，旧实例先停；不能双重播放 |
| 起火、撤离、伤者安置 | 剧情覆盖优先，日常曲淡出；有火声、人声时用独立环境音，未有合格环境音可留白；守路战仍用战斗曲 |
| 火后接应、山居第一夜 | 暂不自动播热闹村曲；关键对白留白，平静安顿段落可恢复疏淡版本 |
| 静音 / 页面不可见 / 返回标题 | 静音为最高优先；暂停后台播放；返回页面平滑恢复，不能积压音效或重叠多个循环 |

音景优先级：**静音/后台暂停 > 战斗及结算 > 剧情覆盖 > 地图日常**。进入普通战斗需保存探索曲播放位置，退出后重新判断剧情；只有允许恢复原日常时才使用保存位置。切换中再次进入战斗或换场景，旧切换任务必须失效。

## 实施边界

已接入V2两首配乐，实际实现与限制见[音频技术页](../../../audio.md)。正式文件与来源登记已同步；语音压低是预留接口，完整音乐小节循环仍待专门听审。

本轮交付为两首主曲的设计与制作合同；疏淡日常、轻对练是同工程可选混音，不要求先生成一套大规模配乐。环境声、脚步、交互反馈独立管理。既有带铃音脚步保持停用，不借BGM恢复。

## V2装配决定

用户要求直接装配现有V2。采用约59秒已交付音频，不再生成新曲。日常覆盖栖河中央/外区/后山/室内，战斗覆盖狼战、陆衡对练、药车守路战。单播放实例循环，接缝60毫秒音量收放以抑制点击声，避免旧2.5秒双轨叠鼓；这属于当前样段循环方案，不宣称已经完成按小节重编的无缝母带。

切换保存日常播放位置，战斗每场从头；对话/江湖面板压低约3dB，语音压低预留接口。静音和后台暂停保留位置。起火/撤离/接应及山居第一夜先留白。用户可通过M静音。正式采用与技术验收分开记录，主观长期听审仍留待实玩。
