## 采集与消耗

- 靠近按 **E / 空格**，也可点素材自动寻路。资源本身不增加碰撞；陆地可站立、可直线接近才给奖励，不能隔墙或下水领取。
- 靠近220世界单位才有轻微提示，最近目标显示名字、数量。采完移除该点的素材与交互，露出原地表，不保留空闪光。
- **B / 右下“野外行囊”**查看持有量、用途、附近交付。面板滚动，Esc或B关闭，不借用剧情立绘对话框。
- 店家（南村口）、周婶（接应院）、厨房（山居）：枯枝2换干粮1，作为添柴后的普通回礼。总落枝量最多换5份。
- 药商（南村口）：野草药2换4文；芦苇2换2文作为包药垫料。两类全收最多18文，不能直接服用野草药。离开收取者或材料不足，按钮禁用。
- 采集及交付不推进开始部分半日、不扣培养体力、不发功法熟练度。主线没有采集硬门槛。
- 火灾和撤离阶段暂不采集、交付；主线救援优先。后续到接应院、山居后按当地固定点开放。

## 存档与复用

节点状态在 `S.qiheResources.nodes[稳定ID]`，材料在 `S.bag`。首次加载旧存档按“未采集”处理，无需重开。切图、休息、读档、跨章均不刷新；三年培养的季节再生尚未接入，不能提前使用“每日重置”。

领取和交付先把下一份完整状态写入栖河独立键 `xjh.qihe-prologue.v2`，成功才改内存。存储失败不扣材料、不发奖励、不消失；重复输入只领取一次。原襄阳 `xjh.save` 不受影响。

增加新点必须填写：稳定ID、场景、类型、世界坐标、数量、环境理由。至少距其他交互85单位；点位、玩家接近点均须可达。新物种需先增加产地和实际用途，不用现有树枝改名成矿石。
