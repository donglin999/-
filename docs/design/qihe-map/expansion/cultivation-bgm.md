- 108 BPM、2/4轻弹性节奏，F大调与五声色彩。琵琶主奏先起，笛子作回答；低音拨弦和轻手鼓。取消二胡领奏、大弦乐铺底和齐奏，主奏一次只留一个声部，旋律和伴奏分音区。
- 新主题A：短促同音起拍、六度跳进再级进回答；B：四度起句和较长拱形旋律；C：不等长短句及留白；D：新的下降对题。都是新作目标，不宣称已落实为准确音符。
- 段落0–12秒琵琶引句；12–36秒A；36–60秒B；60–84秒C；84–108秒D；108–120秒新结句。仅末尾短暂节奏呼应，不整体循环前段。
- 清晰度要求：近距离录音感、短且少的房间反射、明确拨弦起音、稳定声像，禁止厚混响、合唱/相位效果、磁带抖动、模糊瞬态和低中频堆叠。不得以大幅提亮EQ掩盖生成缺陷。
- 输出请求原生MP3 48kHz/320kbps；试听由原件解码后仅固定增益校准至-20±1 LUFS，真峰≤-1dBTP，导出48kHz/24bit双声道WAV。WAV避免再次有损编码，但不能恢复源MP3丢失的信息，不称其为原生无损生成。

## 验收与后续装配合同

1. 技术：解码、时长、采样率、声道、响度、真峰、静音、来源哈希；技术通过不等于听感通过。
2. 听感：主题是否明显更欢快、与Q版人物动作协调；B/C是否有真正的新旋律、而非相同旋律换乐器；短句是否俏皮且不幼稚滑稽；笛声是否刺耳；是否有实际人声/奇怪拟音；连续三遍是否疲劳。配器/BPM/分段目前都是目标，不作已实现承诺。
3. 循环：试听样曲不标无缝成品。确定风格后选择完整小节边界，听查接缝，不能只用淡入淡出掩盖节奏断裂。
4. 运行：仅正式进入培养部分后启用；开始部分山居首夜继续保留剧情留白。培养菜单/活动/月份变化不断曲；切战斗用现有战斗曲，回培养恢复位置；对话压低3dB、语音6dB、静音和后台暂停遵循现有音频合同。
