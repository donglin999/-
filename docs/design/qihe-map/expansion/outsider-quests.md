## 三件小事，逐步识别来意

| 支线 | 接取与人物分布 | 流程与信息揭示 |
| --- | --- | --- |
| 一封未落款的拜帖 | 南村口徐令仪 → 村内东北陈伯家门厅 → 徐令仪 | 徐亲自核办联络院递出的拜帖；陈伯辨出正道盟名头与“旧谱登记”，提醒物有其主；回话后徐明确登记与保管需另行交涉。 |
| 旧罐与玉匣 | 南村口岑霜 → 同区药商 → 岑霜 | 岑核实乌魁带回的旧货账；药商说明只卖六只药罐，“温”是罐底款，叶家未许玉匣；旧罐账不能证明叶蘅同意。第二日傍晚后岑移至东埠。 |
| 药单上的两道数 | 东埠沈雁回 → 村内药铺周婶 → 回沈处由差役当场联合核对 | 沈核查采办队转来的三篓与两篓之差；病人药包被混入货单，“已验”无签名；分栏记药或当面记录争议。这里只核普通药货，不能提前解决主线药签与伪造附页。 |

每条都有接取、暂不接、途中提醒、核实、交还、两种回应和完成后复谈。两种回应保留在存档，不替叶蘅答应交物，也不以跑腿任务直接解决主线冲突。分别给一次性路费6、8、6文；不新增战斗、CG或动作素材需求。

## 时间、存档与后文

- 入村借衣完成后可接，开始部分自由活动期仍可继续；普通交谈与跑腿不消耗半日。三条均不影响主线门槛。
- 在对应证人核实后写入已知线索。征药回采办点时由就在现场的差役一起核对，直接完成回话，不再走几步单独问差役后又提交。旧档“已见证”仍可直接交还。
- 夜谈根据已知线索换词；开始部分徐令仪索谱、岑霜索匣、沈雁回查验承接查账结果。主事人剧情见[当前接入合同](../three-representatives.md)。拒绝代为承诺不等于对方放弃索取。
- 起火撤离后，未完任务在江湖任务页标注中止，保留已知线索；不跨到山居继续找失散委托人交任务。旧任务ID、进度、选择与奖励标记保留，由新对接人续接，不重领路费。
- 状态位于 `S.prologue.outsiders.quests`，旧档按需补齐；关键步骤保存，重复交谈不能重复发钱。原有还碗、取布、送药仍可从“原本的事”进入。

## 立绘必须按在场者配置

- 双人：萧白左，对话对象右。队伍成员不等于对话在场者，禁止从出战阵容或固定女主名单填充立绘。
- 三人：左、右、中三个稳定站位；四人及以上保留左右，中央显示第三人或当前额外发言者，其他在头像栏。换发言人不随意换左右。
- 每场明确 `DialogueStage.withCast`；结束恢复上一层。不得因“两句话间隔很短”继承上一位NPC。
- 章节单句、选择菜单、成组演出分别配置实际说话人。旁白隐藏立绘；没有对应立绘的普通NPC不拿叶蘅或其他角色补位。
- 角色动作、CG和既有画风不在本次整改范围内。

## 2026-10-05 收尾规则

入村首次问候也必须限定实际交谈双方，再恢复上一层立绘；不得绕过支线分支入口。VM 专项工具须隔离页面启动流程，不能在测试中后台自动开始序章并污染出场名单。普通入口与独立支线入口均纳入浏览器核对，工具验证与浏览器交互结果分别记录。

普通 NPC 的对话小像须通过统一 `drawImageAsset` 绘制精灵表帧；不能将帧描述对象直接传给原生 `drawImage`。三条支线的完整浏览器交互与正常入口已核对，结果与范围见 [2026-10-05 收尾验收](../../../updates/2026-10-05-outsider-acceptance.md)。
