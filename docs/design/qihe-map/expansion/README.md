## 用户确定与本轮建议

| 用户确定 | 采用的实施方向 |
| --- | --- |
| 开放村外，沿用现有地图生成逻辑 | 栖河生活核心 + 北后山、南村口、西田埂、东河埠；另接邻村与归云谷入口 |
| 主角使用初始阶段，NPC画风统一 | 短发借来便衣重新走白模生产，统一旧版动作的像素语言；取消长发白衣替身例外 |
| 基础步法改成学习丙级功法 | 陆衡教民间《护路棍法》（暂名），开始部分可用，培养部分保留 |
| 群狼由外人惊动，以叶蘅内心埋伏笔 | 叶蘅先怀疑异常脚印与犬吠，第二天从车夫证言确认有人惊山；幕后身份仍未知 |
| 顺畅进入培养部分 | 火后暂住 → 萧白主动求学 → 培养第一年一月正式拜入归云谷；叶蘅独立决定暂住 |

## 版本优先级

本方案通过后，替代本分支“长发旧hero可长期使用”“单只山犬”“村内集中摆三方人员”的生产目标。旧页面仍记录实际运行状态，不能将本页方案写成已接入。

主目录更新设定优先于旧分支：周砚为归云谷掌门，开始部分不拜师、培养第一年一月正式入门；培养采用36个月、每月五时段、普通时段10体力。风起栖河段保留三日故事背景，取消六半日计时；活动自由探索，主线按玩家确认推进，详见story.md。旧分支“36月×3格”、旧台词“我那里不是门派”不再作为新内容输入。

地图与章节已按[制作顺序](../../../archive/design/qihe-map/expansion/production.md)接入可玩原型，野外资源另见[采集规范](resources.md)。完成范围及尚未实机验收的项目以[实施记录](implementation.md)为准。
