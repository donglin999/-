| 页面 | 新方案 | 操作主线 |

| 人物 | 保留五维、状态、三装备槽、身份与淡雅背景立绘；移出完整背包 | 选人物 → 查属性 → 点装备槽进入行囊 → 返回原人物 |

## 三张评审图

### 编成

### 独立行囊

1672×941概念图为8列4行，显示1—32；240是明确标注的后期样例条目数，不是容量上限、当前玩家物品或已完成的压力测试。1920×1080布局目标为8列5行，条目数继续向下滚动。名字与效果采用现有目录；额外小图标和持有数量仅示意排版，不因此创建药材、制作或经济内容。

### 武学

!武学（已移入 _attic，不作参考）

展示已学“护路棍法 → 横杆护身”，按条件显示可施展；BP预览只查看效果，不消费资源。不再将六个主动装配槽当成八方机制。

八方本传1/2以职业组织战斗能力，辅助能力另行组合；弱点破防与BP强化共同构成战斗节奏。参考[Square Enix 二代系统](https://www.jp.square-enix.com/octopathtraveler2/system/)和[一代辅助能力说明](https://www.jp.square-enix.com/octopathtraveler/sp/traveler/ophilia.html)。本项目保留师承、秘籍、熟练和突破，不照搬职业许可证/JP货币，也不声称所有历史所学技能在八方中均可跨职业使用。

**推荐改造**：本项目已学且满足角色、兵器、内力、状态条件的主动招式可在战斗列表选择，取消旧准备槽数、最多两项群攻、MP×5的准备限制；学习/突破门槛保留。内功仍依原一主修和逐步开放的辅修结构。被动效果页只是现有来源摘要，不新增四个可装被动槽。该改动会影响平衡，评审后必须复测本章战斗；详见[机制核查与实施边界](martial-ui-v3.md)。

图中BP0横杆护身威力1.10，一击命中棍弱点削1盾、减伤15%；BP提高伤害而不加段数或护身强度。正式界面须写明“至下次本人行动前”的持续期，并基于实际重数/状态计算，不能把评审数值硬编码。

## 代码核查发现，实施时必须一起解决

1. S.party 当前兼任加入、跟随、战斗名单，未限制四人；需要统一名册/阵容/可用性，连同剧情临时名单和旧存档迁移处理。
2. 当前始终把主角注入战斗；若设计允许非剧情时换下主角，需要同步战斗结算、镜头/剧情视点和宠物失去护主目标后的行为。
3. 候补不能通过临时塞入 S.party 获得物品操作权限。装备/物品事务需要数量、目标和存储失败校验。
4. 当前兵器需求检查对主角与队友不一致；横杆护身缺少兵器声明；部分技能有效内力消耗与战斗准入检查不一致。
5. 培养进度、章节点、叶蘅正式加入/成长分支仍需接到统一状态。

这些问题已经形成文档中的实施清单，本轮不声称修复。现有角色动作、地图和游戏状态未在本轮更改。
