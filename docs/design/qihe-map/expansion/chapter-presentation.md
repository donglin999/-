## 火灾演出

1. 装车争执：短对白，药车与西侧出口先交代清楚。
2. 地图旁白先交代乌魁侧身避剑、后肘碰架、油灯被带出架边。CG一「灯倒」重新生成零人道具插入镜：浅陶油灯落在晾布折边，燃着的棉灯芯接触湿布，初火仅在接触处。只有一条起火旁白后收图，不画人物、残缺手臂或剑。精细纸本武侠插画，与递水CG一致。
3. 回地图：萧白叫叶蘅退后；油罐破裂扩火、陈伯绊倒、药车卡住分别交代。周砚接应伤者，程铎指挥差役开西侧车道，岑霜扣住乌魁手腕让他退到墙边，不安排岑霜搬家具。火光暖、河侧环境冷；不全屏爆炸，不新增纵火者。
4. 选择：救陈伯／护药车仍由玩家决定，CG不能预判选择。两条分支都救回人、保住叶家三件旧物，普通物资和照护状态按原规则记账。
5. 地图先按分支交代陈伯照护与物资结果。CG二「离开」仅萧白、叶蘅两人：叶蘅先向西走并压住自己的药箱肩带，萧白落后半步回望，背景只有局部烟光。配两句「药箱在我这里。人齐了吗？」「齐了。走，我看着后面。」其他人物、药车、物资均不入镜。与灯倒同为傍晚，不能突然变深夜。
