## 身份与动作

初版清秀成年脸、轻巧偏瘦体态、束发、米灰棉麻便衣、深灰裤、布鞋和固定腰侧针囊。当前是乡村医者自保阶段，不提前穿白鹇谷制服或使用未来进阶技能。与现行萧白约六头身、64逻辑身体、3倍硬透明像素规格同屏；脸、衣层、道具独立辨识。

| 状态 | 具体全身动作 |
| --- | --- |
| 待机 | 侧身稳站，持针手低收，另一手轻护针囊；无推掌架势 |
| 移动 | 小步前探、后脚跟进，身体前倾，手护针囊；针法普通攻击保持远距，不冲到贴脸 |
| 普通攻击 | 腰侧取针 → 双指蓄针 → 髋肩转向、甩腕出针 → 手臂随势 → 收腕归位 |
| 连续攻击 | 后手续取 → 腰间低位快甩 → 迅速收回；与第一攻击有明确高度和重心差异 |
| 金针刺穴 | 胸前拈针凝神 → 目光定穴 → 出针后收势；仍只有既有技能的数值效果 |
| 受伤 | 护住躯干侧撤，针手收紧，肩头后仰 |
| 破势 | 单膝撑地，另一手护针囊，抬头观察而非礼仪下跪 |
| 倒地 | 完整侧倒，两腿与双臂自然屈曲，针囊仍有真实连接 |
| 胜利 | 松开紧绷肩背，垂腕把针收回囊中，轻呼气 |

少量待机/破势呼吸允许从同一生成母帧派生；不同动作关键帧必须完整生成人体，不将一套推掌/持武器动作机械套用。

## 发射与命中

BART明确记录放针帧、实际手部坐标、飞行时间与收势。普通攻击和金针均在放针后显示短银白针光；针光到达目标才触发伤害、受击、短顿帧和轻锐的针击声。针法普通攻击保持远距，身体只有短踏步；命中不套用木棍的夸张后退和声音。每次普通攻击仍按1+BP逻辑次数，技能原MP/伤害/削盾/效果不变。

修改只对初始叶蘅的专用发射合同生效，其他角色与苏芷使用原有合同。序章教学仍手动；新增显式隔离验收入口可自动运行同一序章战斗、原敌人和数值，并提供完整九状态的实际渲染检查。不能为了展示把叶蘅加入原本仅萧白与陆衡的药车守路战。

## 制作与验收

按用户提供的pose-pixel-animation：完整人体灰色姿势 → 正式身份和现行画风参考 → 内置imagegen逐动作组生成 → 原图哈希与手部/头身独立标志点 → 共同相机、固定身体锚点与脚底 → 32色、硬alpha、3倍无损表 → Aseprite工程与原速预览。

各组独立头颅与躯干尺寸分别验收，预算18%，不以平均值抵消比例错误；同一组禁止逐帧包围盒等高。遮挡不可测段如实记录，低伏/倒地不能按可见高度放大身体。双手完整、取针位置可追溯、两腿解剖自然、无漂浮针囊。最后核查实际8792全状态、与萧白的同屏体量、普通/BP/金针命中时序，并交付真实战斗视频。

旧原件保留；新增正式文件、JSON/MD/JS清单、BART、预加载校验和更新记录一起更新。文件、动作、代码、浏览器验收分开记录。生图请求gpt-image-2.5，实际版本若工具未披露则记unknown，不自动使用付费API。

## 当前采用结果

采用 `b_ye_initial_needle_20261012`：18张完整生成关键帧+3张呼吸派生，21列360×288，逻辑120×96、身体64基准、32色、3倍硬alpha。9个基础状态加独立金针动作；普通攻击放针290ms/命中430ms，连续攻击放针100ms/命中220ms，金针放针310ms/命中450ms。实际手部坐标和锚点记录于BART，轻短针击声已登记。胜利时叶蘅收针入囊。

4次内置生图，其中快甩因第一版肩高出针单独重画为腰高；其他5格继续使用原来源。头颅/躯干组间分别通过18%预算，配准不对低伏或倒地包围盒放大。Aseprite的10标签31个时间帧通过像素往返、透明、颜色、边距与时长结构检查。

1280实际十状态、1920待机与出针已逐项查看；后山实际自动战斗有金针、普通/BP飞针、叶蘅受击与胜利。此战仍是萧白刚到异乡的现代衣装阶段，不为了视频提前换风起栖河段便衣。实际发射/命中声音间隔约141/140/122ms，浏览器无warn/error。函数验证与素材检查通过；完整出处、提示词、图集、工程和[17.51秒实录](../../../art_sources/ye-needle-battle-20261012/video-final/ye-needle-battle.mp4)见[制作包](../../../art_sources/ye-needle-battle-20261012/README.md)。视频按成功音效事件同步原样本，未采集系统音频/BGM/人物短句。
