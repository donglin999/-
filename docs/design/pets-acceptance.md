## 1. 首期探索必测

| 编号 | 前置与操作 | 通过条件 |
| --- | --- | --- |
| E01 | 偏巷未收养；无馒头尝试、取得馒头再收养 | 无物不扣资源；有物只扣一次；原犬 NPC 消失，仅一个跟随实例；读档不重复扣物 |
| E02 | 主角、叶蘅、苏芷与大黄同行，改变人类次序 | 大黄始终队尾，不占人类位；无人类同伴时正常跟随 |
| E03 | 走、跑、急转弯、停下；穿偏巷门口和寨门 | 不穿墙、不切角入物体、不堵主角；停下不持续滑步，脚点与阴影一致 |
| E04 | 宽草地停留 30 秒 | 从待机进入符合条件的闲动作；活动在规定半径、可达地面和镜头内；草地不变成障碍 |
| E05 | 窄桥/门洞停留同样时间 | 只跟随或原地待机，不选阻挡通道的落点 |
| E06 | 闲逛、嗅闻、坐卧和喝水各过程中移动及召回 | 旧目标取消，及时起身/归队；不等长动画播完，不瞬移、不重复回调 |
| E07 | 水钵可达、不可达、无水、条件中途失效 | 只在条件有效时饮水；不可达放弃；鼻端朝钵口，身体不进井/钵；无无限资源奖励 |
| E08 | 依次对话、开菜单、战斗、切图 | 自主计时暂停/重置，旧路径不继续；无人为锁主角；恢复仅一个实例 |
| E09 | 渡船脚本接管和回陆地 | 船上只保留剧情犬，禁止自由跑；上岸解除接管，恢复队尾 |
| E10 | 等候后跨图、读档、进入战斗；休养进入战斗 | 等候不造成遗失；读档安全归队；休养不参战，数据保留 |
| E11 | 故意让兴趣点路径失败或地图无合法落点 | 重算次数有界，放弃目标；无碰撞绕过和镜头内闪现；缺合法位置明确报错 |
| E12 | 连续切图和召回 20 次 | 无重复犬、残留回调、重复音效或增长的计时器；未加入时不扫描兴趣点 |

使用真实碰撞和移动，不以设置角色坐标直达代替 E03–E07。调试仅用于构造难出现的异常前置，并在记录里注明。

## 2. 战斗与资源

| 编号 | 前置与操作 | 通过条件 |
| --- | --- | --- |
| B01 | 主角血量 30%、31%、50%、51%；宠物有/无资源 | 各边界严格按目标决策表；30%先治疗，不被护主遮住；资源不足继续评估合法动作 |
| B02 | 大黄血量 25%、26%；主角低血 | 自身危急防御，不连续以护主致死；无玩家指令框卡回合 |
| B03 | 敌方攻击主角，带护主；奇偶伤害、倒下、过期、持续伤害 | 转移取整与总伤害守恒；护主倒下/失效立即停止；无递归或持续伤害误转移 |
| B04 | 多敌人残血相同、弱点全知/未知；中途敌人死亡 | 选择稳定合法目标；不攻击尸体、不读取隐藏弱点；空目标安全结束 |
| B05 | 教学、单挑、休养、普通出战各一场 | 只有普通且同行未休养才生成宠物；战斗重开无遗留护主引用 |
| B06 | 胜利、失败、逃跑、注入异常，再存读档 | 合法资源正确写回；异常不写临时残血；普通战败无永久宠物死亡 |
| B07 | 连续点击喂食/装备/卸下，满血和资源不足 | 无负数量、重复返还或满血浪费；物品效果与界面相符 |
| B08 | 不收养/休养完成案件和关键战斗 | 保留非宠物线索与通关路线，不因为宠物状态卡主线 |

现有 `tests/battle-error-regression.cjs`、`tests/xiangyang-slice.test.cjs` 可作为资源回滚和队伍分离回归基础，不声称覆盖自主活动。新增自动测试优先覆盖决策边界、状态中断和迁移幂等；视觉和活动路线仍需真实浏览器验收。

## 3. 界面、素材、存档

- 两视口分别看宠物面板全屏、每类图标悬停、键盘焦点、禁用原因；文字可读、不溢出、不遮目标。当前活动和休养状态与游戏一致。
- 四方向 walk/run 与新增动作至少各播放一完整周期；同深度与主角比较，脚底不悬空、坐卧不漂、起身不跳体型；昼夜不换毛色或立绘画风。
- 验证旧 `S.party=['dog']`、旧 `S.mates.dog`、已有 `S.pets.dog`、缺字段和未知 id 的存档；每档加载两次，数据不重复成长，不吞装备。
- 训练与信任若未开发，界面不展示虚假的完成状态；阶段 C 上线后另测一次性关系奖励、每日上限和三年时间结算。
- 记录网络失败与资源缺失：动作资源失败回退到可用待机，不停止游戏循环；不得用空白图或文字宣称动作完整。
