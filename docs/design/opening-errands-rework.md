## 零、选定方案（2026-10-23）

### 0.1 周婶三件：选乙-1「替周婶跑一圈」

**为什么选乙-1，不选乙-2、乙-3**：
1. 用户嫌的是“无聊”，乙-2 只加回扣，“走过去交差”的感觉不变；乙-3 取消后第一夜只剩“收药箱 → 睡觉”，新玩家没机会认路、认人，也和整改第 5 项“交互太少”方向相反。
2. 三件事真正的内容是三处旁听（F-0011 的三条传话），现在藏在“多等一会儿”后面，大多数人会错过。乙-1 把旁听摆到台前，玩家**自己决定听不听**，听全三处的当晚由叶蘅说出“三拨人都冲我家来”——有判断、有人记得，正是第四节三款作品的共同点。
3. 合成一条任务，任务面板从三条变一条，第一夜的信息量变小；用户也说过剧情要简单。
4. 改动只在第一夜几份剧本里，固定剧情的触发不变（R-剧情-07）；和小耗子的一课、观察者支线都不冲突（0.3）。

**定下的做法**（第七节乙-1 的细化）：
- 周婶一次报三处，萧白接一次，任务面板一条「替周婶跑一圈」，步骤列三处，顺路：陈伯家（还碗）→ 客栈（取布）→ 村南老人家（送药、还篮）。三处做完回药棚交差，周婶一句收尾。
- 每处到了地方，人就在那儿说话：选“听下去”或“走开”。不再要求“多等一会儿／坐会儿”。
  - 陈伯家：周砚在打听温家功法（F-0011 第一条）。
  - 客栈：帮众在说叶家缺钱、肯卖旧玉匣（第二条；客栈方案 A 后帮众本就坐在客栈饮酒桌，见地图稿 5.4）。
  - 老人家门口：老人转述采办随从“叶家的药早验过了”（第三条）。
- 听下去的，回药棚时周婶顺口问一句“听着什么了？”（一句，不追问）。
- 三处都听到的，当晚《过夜》多一个小分支：叶蘅自己说出“三拨人都冲我家来”，萧白心里对上。只听到一两处的，《过夜》照现有按标记走。
- 奖励：周婶给一贴药棚的膏药（复用现有最低档回复药，道具 ID 开发时按物品表取），不发钱。
- 存档：`prologue.errands` 三个键保留，新增汇总状态 `round`（`none`／`taken`／`done`）与 `heardAll`；旧档按三个键推导，已做完的不重发奖励。

## 三、为什么无聊，以及顺带查出的逻辑问题

### 甲组（三方跑腿）

1. **只是传话**：托付人把要问谁、问什么都说清了，被问的人把答案原样说出来（“六只旧药罐的钱，早结清了”），萧白回去复述一遍。玩家不需要找、不需要比、不需要判断。
2. **选择没有后果**：回话时的二选一写进 `quests.<k>.choice`，全工程没有地方读它；两支都给同样的钱。
3. **奖励无意义**：6～8 文，开始部分几乎没有花钱的地方。
4. **得到的信息别处都会给**：三件查出的事实（拜帖冲着旧谱、玉匣是传错的、“已验”没人签）在固定剧情《装卸路》《对证》里全都会揭开；周婶三件的旁听也已经各给过一遍同一条线索（`heard.skill／box／inspection`，跑腿用的标记就是这三个）。
5. **三件同构**：同一套“托付→问一人→回话→二选一”连做三遍。
6. **时间不对**：第一夜就能接，托付人还没在剧情里登场。

逻辑问题（属于 R-剧情-07 的“没看过／看过的玩家穿帮”，开始部分的可选内容至今没有盘点过，见 [optional-story-dependencies.md](optional-story-dependencies.md) 第七节末）：

| 级别 | 问题 | 位置 |
| --- | --- | --- |
| 乙：认错人 | 第一夜或第一天白天替徐令仪送过拜帖，傍晚《徐令仪上门》她仍问“这位是叶家请来的见证，还是自己出的头？”；拜帖回话里她说“我亲自去向叶姑娘赔个不是”，上门却是来封存的 | `三方-徐令仪上门.ink` R1-B2，`三方-跑腿-拜帖.ink` E1-A1 |

### 乙组（周婶三件）

1. 主体是搬东西：送碗、取布、送药，到地方就完成，还碗连回药棚交差都没有。
2. 真正的内容是三处旁听（周砚打听功法、帮众打听玉匣、随从说药“早验过了”），但旁听藏在“多等一会儿／坐会儿”后面，大多数玩家会选“直接拿走”。
3. 结果只在当晚《过夜》里被叶蘅问一句，之后不再提；不给东西，也不改变谁对萧白的态度。
4. 时间与动机是合理的：萧白进村时自己说过“明儿有什么活，您叫我”，都在村里、不碰外人。

## 四、参考：三款作品的委托怎么做

以下按公开玩法的一般印象整理，未逐条核对原作，只取做法、不搬内容。

| 作品 | 做法 | 可借的地方 |
| --- | --- | --- |
| 《大侠立志传》 | 城镇里的委托常是几步的小链：先打听人在哪，再到现场看、问、比对，最后有“照实办／私下处理／揭穿”几种收法；结果改变人物好感与门派声望，有的在后面回来找你 | 每件委托至少一个“玩家自己得出结论”的步骤；选择分出不同收法，并且有人记得 |
| 《侠客风云传》 | 养成期的事件按时间开放，错过就没了；小事件的选择会在之后的大剧情里被提起，影响结局走向 | 时限按剧情定（本作已有）；选择要在后面固定剧情里回扣一句（中、小分支） |
