## 1. 现状：系统骨架已有，内容没有设计

运行中的 `js/battle.js` 已经是八方旅人式的骨架：

- 敌人有护盾和弱点，弱点初始显示“？”，打中才揭示；
- 打中弱点伤害 ×1.25，每次出手对每个目标至多削 1 盾；
- 盾归零就破势：本回合剩余时间和下一整回合不能行动，受伤 ×2，之后回满护盾；
- 有 BP 蓄势，金针刺穴、嗅探可以看破弱点。

缺的是内容和规则细节：

| 缺口 | 现状 | 影响 |
| --- | --- | --- |
| 敌人弱点表 | 只有山贼、狼、蛇、寨主 4 个模板，其余敌人缺省“3 盾、弱拳刀” | 打法单一，弱点不能引导配队 |
| 削盾规则 | 每次出手每个目标至多 -1 盾，与招式合同里“按 BP 分档削盾”不一致 | 多段招和 BP 的拆防用途发挥不出来 |
| 弱点类型 | 兵器种类加阴、阳、雷、毒四种内劲，但目标内功没有定义哪招带哪种内劲 | 内劲弱点几乎打不中 |
| 破势恢复 | 恢复后按速度正常排序 | 少了八方“恢复后先手反扑”的压力，破势后没有收尾的取舍 |
| 头目阶段 | 半血时立即在本轮多行动一次（**2026-10-08 已改为提前一回合预告的二阶段，见第 4 节第 4 项**） | 压力突增且没有预告（数值审计已列为风险） |
| 护盾成长 | 没有按阶段、敌人等级的护盾表 | 后期拆防行动数不可控 |

## 2. 八方旅人的做法（核实结果）

来源：GamerGuides 战斗系统攻略、Destructoid Break & Boost 指南，以及本库已有的[八方官方调研](martial-review/octopath-research.md)。

1. 每个敌人有护盾点数和若干弱点（兵器类与属性类）。未知弱点显示“？”，打中或用看破类技能后才揭示。
2. 每打中一次弱点削 1 点护盾；多段攻击每段都算，所以 BP 加段数就是拆盾手段。
3. 护盾归零即破防：本回合剩余时间和下一整回合不能行动，期间所有攻击都按命中弱点计，受到的伤害约为两倍。
4. 破防恢复的那一回合，该敌人一定最先行动。
5. BP：每回合加 1，最多存 5 点，一次最多花 3 点；花了 BP 的那一回合不加。BP 按招式决定加段数、威力或持续时间。

本作取舍：保留 1、2、4、5；破势倍率不照抄两倍，由模拟决定（候选 1.5，现行 2.0）；破势期间不把所有攻击都算弱点（避免弱点表失去意义），只按倍率增伤。

## 3. 本作规则 v1

### 3.1 弱点类型 v2：6 兵器类 + 6 属性（2026-10-08 用户要求对齐八方旅人的类型数量）

八方旅人共 12 类弱点：6 种兵器（剑、枪、短剑、斧、弓、杖）＋ 6 种属性（火、冰、雷、风、光、暗），弱点格按固定顺序排列（兵器在前、属性在后），玩家可以据此推断未揭示的弱点。本作名字武侠化，类型数量与结构一致：

| 八方 | 本作 | 包含的本作兵器 |
| --- | --- | --- |
| 剑 | 剑 | 剑 |
| 枪 | 长兵 | 棍、篙、伞 |
| 短剑 | 音律 | 琴、笛、琵琶、箫（2026-10-08 用户定：本作没有“短刃”一类，八方的短剑位换成音律武器） |
| 斧 | 刀 | 刀、短刀、锤（原“短刃”并入此类） |
| 弓 | 暗器 | 暗器、飞刃、针、扇（铁骨扇可掷可截） |
| 杖 | 拳掌 | 拳、掌（空手普攻也算拳掌） |
| 火 | 炎劲 | |
| 冰 | 寒劲 | |
| 雷 | 雷劲 | |
| 风 | 风劲 | |
| 光 | 阳劲 | |
| 暗 | 阴劲 | |

- **属性由招式决定**（同八方）：每个招式有 `weak_class`（兵器类）与 `element`（属性）两个字段，由 `tools_docs/build_elements.py` 写入。乙级以上的进攻招（B、X 型）带本门属性；丁、丙级基础招只算兵器类（燃隙刀等少数按意象例外）。
- **每个门派两种属性**（2026-10-08 用户要求，便于配队协调）；六种属性各被两个门派使用：

  | 门派 | 属性 | 分布 |
  | --- | --- | --- |
  | 归云谷 | 风、阳 | 剑路：开晴剑法、归云剑诀风，云开见山剑阳；拳掌路：叠岚掌法、归云拳掌法阳，万壑掌风。两条路各自都能打出两种属性 |
  | 白鹇谷 | 寒、阴 | 金针刺穴寒（丙级例外），镇魄针阴 |
  | 照川剑派 | 寒、阳 | 问隙挑灯、江心定影、一剑澄江寒；照川落日、千帆照水阳 |
  | 合川拳门 | 雷、炎 | 崩石短打、坠桩镇步、百步震关雷；开闩重拳炎 |
  | 松风观 | 风、雷 | 松涛合阵、听涛辨枝风；松影千重雷（松涛如雷） |
  | 归烬堂 | 炎、阴 | 燃隙刀、焚契破阵、残火截锋、余烬留生炎；断烬回身、烬里藏锋阴 |
  | 巡江司 | 寒、雷 | 断渡擒锋寒，锁江擒拿雷 |
  | 正道盟 | 风、阳 | 短锋相照风（丙级例外），明约合锋阳 |

  人物技能（暂缓）按人物一种属性：叶蘅针线阴、晏小楼风、乔行舟寒、柳含烟阴、秦绯鸢风、阮青雀阴、霍逐尘雷。
- 一段命中只要兵器类或属性任一项是弱点，就算打中弱点，同时揭示命中的那一项；每段仍只削 1 盾。
- 内功的阴、阳、中性只用于运转相冲的规则，不再给招式附加属性（取代 v1 的做法）。
- 当前覆盖（招式数）：炎 5、寒 5、雷 6、风 8、阳 8、阴 6；兵器类剑 25、拳掌 15、短兵 12、长兵 9、暗器 7、刀 5。刀与暗器两类兵器偏少，后续新增功法优先补。

### 3.2 敌人弱点卡

| 敌人等级 | 弱点数 | 护盾（年一 → 游历 → 后期） | 规则 |
| --- | --- | --- | --- |
| 普通 | 3–4 | 2–3 → 3–4 → 4–5 | 至少一项属于公开基础课能打出的兵器类（剑、拳掌、长兵、暗器之一），避免没带专精就拆不动 |
| 精英 | 4 | 4–5 → 5–6 → 6–7 | 带一项预告重击，破势可打断 |
| 头目 | 4–5 | 6–8 → 8–10 → 10–12 | 阶段转换提前一回合预告：护盾 +2，并换掉一项弱点（新弱点为“？”）；第 10 回合起“久战发狠”，伤害每回合 +20%（提前预告） |

- 运行中的精英：青鳞巨蟒 `FOE_DEF.snake`（`rank:'elite'`，盾 5，`mk('snake')` 经精灵键取到）。**已实装并核对（2026-10-08）**：异常抗性 15%、硬控后 2 回合同类免疫，目标说明行显示【精英】；“预告重击”尚无精英专属招式，未做。
- 同一区域的敌人弱点要成组设计，让“这一带该带谁”成为配队问题，而不是固定答案。
- 护盾每加 1，拆防可能多花一次行动；改护盾要跑模拟，不能当成小改动。

### 3.3 削盾

- 每一段命中对应弱点削 1 盾；打中未知弱点同时揭示它。
- 每招每档 BP 的削盾上限按招式合同 `shield_cap`；`extra_shield_damage` 类效果另算，但每次行动对每个目标最多削 6 盾。**已实装（2026-10-08）**：v3 招式按 `BSK.bp[档][2]` 传入 `strike` 的 `cap`，附加削盾每次行动对每个目标一次、同样受该上限约束；旧原型招式仍只受 6 盾总上限。
- 群攻每个目标单独计算，不能把多个目标的预算集中到一个人身上。
- 未命中、打中非弱点、打已破势目标都不削盾。

### 3.4 破势

- 破势的那一段仍按未破势结算，之后的段才享受破势倍率。
- 持续：本回合剩余时间加下一整回合，期间不能行动，预告的重击、蓄力一并取消。
- 恢复：再下一回合开始时回满护盾，并且**本回合最先行动**（新规则，运行代码需补）。
- 破势倍率：**1.5（2026-10-08 用户确认）**。模拟中 2.0 只让头目战快约 8%，破势的价值更多放在跳过行动、恢复先手和异常必中上。

### 3.5 看破

- 来源：看破类招式（金针刺穴、江心定影、听涛辨枝、镇魄针等）、内功主动（观岚、澄心、听风）、地籁诀开场看破、打中未知弱点。
- 看破只揭示已有弱点，不创造弱点；目标弱点全部已知时，看破型伤害招照常造成伤害。

### 3.6 BP

沿用八方规则与招式合同：开战 1 BP，每回合开始 +1（上一回合花过 BP 的人不加），上限 5，一次最多花 3；绝级招式必须花满 3 BP。

## 4. 运行代码要改的地方（本轮未改）

1. `strike()`：削盾从“每次出手至多 1”改为“每段 1，受招式 `shield_cap` 约束”。
2. 破势恢复回合把该敌人排到行动顺序最前。
3. 敌人模板补齐弱点卡，撤下雷、毒；按 3.2 的表配置护盾。
4. 头目半血加行动改为“提前一回合预告的阶段转换”。**已实装（2026-10-08）**：任一行动后头目气血低于 50% → 横幅“下回合起进入二阶段”、意图栏预告；下回合开始进入二阶段：护盾上限与当前护盾 +2，换掉一项弱点（优先换已看破的，新弱点为“？”），之后每回合多行动一次，每次伤害 ×0.6（整轮 +20%，见 formula.md“保持本轮预算再分摊”）；与第 10 回合久战发狠相乘并存。参数在 `BattleRules.R`（`PHASE_AT`、`PHASE_MUL`、`PHASE_SHIELD`）。
5. 招式出手的弱点类型改为读 `weak_class` 与 `element`；运行中旧的“毒”内劲改为异常状态（见异常状态 v1），“雷”并入六属性。
6. 弱点格按固定顺序显示：剑、刀、长兵、音律、暗器、拳掌、炎、寒、雷、风、阳、阴。

这些改动要等模拟结果确定倍率与护盾表后一起做，并补浏览器验收。
