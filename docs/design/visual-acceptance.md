# 桌面版视觉与交互验收合同

状态：**本轮设计基准；逐项验收前不得宣称已完成**。本页整理 2026-09-30 的十二页问题反馈，作为生成、排布、实现和验收的同一把尺。附件中的截图是问题证据和界面参考；截图上的描述不替代实际游戏复测。画风与素材生产见[襄阳素材规范](xiangyang-art.md)，界面见[表现规范](presentation.md)，具体场景见[偏巷方案](xiangyang-alley.md)。

## 工作顺序

1. 先确定用途、比例、可走范围、界面层级和资源语义，写进相应设计页；核对现有资产清单与场景状态。
2. 先做可评审的界面线框和游戏内预览，再决定哪些图需要新生成。候选图必须与同屏人物、物件或图标并排审稿；不能只看单张原图。
3. 修改代码、场景与素材，逐页在 1280×720 和 1920×1080 桌面视口截图。每个碰撞修改都需叠图加实走；每个素材替换都需同机位前后对照。
4. 独立验收者从运行版本复现，不凭实现者口述、单元测试或生成图判定通过。未通过项记录原因、截图和负责文件，修复后重测。

## 跨场景量尺与视觉规则

- 以成年主角站姿游戏内**脚底接地点**为统一锚点；同一地面深度的成年 NPC、同伴、敌人不因资源画布留白改变身高。儿童、犬、巨兽另列物种尺寸，仍以脚底或爪底接地点对齐。
- 每个场景资产卡记录对象实物尺寸、对应像素尺寸、与成年角色的比例、遮挡底边、碰撞轮廓和交互距离。门、桥、告示牌、树、篝火、炉灶、桌凳必须用同机位角色截图比较；不能各图独立“看着差不多”。精确数值在[素材规范](xiangyang-art.md)统一维护。
- 脚底应落在可见地面，影子压在同一接地点，行走与倒地帧不浮空；透明边缘不能出现白圈/亮边。场景与战斗的比例分别核对，战斗仅可用一致的镜头缩放改变整组尺寸。
- 肉眼可走的连续铺地原则上可走；不可走处应有水、树干/树丛、院墙、栅栏、房屋、货堆等可见原因。可见桥头必须接上岸边道路，画面中的门口/桥面/院门应与实际出口和寻路一致。装饰性亮暗不充当碰撞暗号。
- 人群遵守“主通道能行走、任务焦点能发现、同屏轮廓能分清”。重要 NPC 与一次性路人的视觉权重按剧情级别区分，后者不使用与主角同等级的精细大立绘。
