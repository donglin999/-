## 场景落地：用现有后山，不新建地图

宋先生的三次出场都放在 8792 当前游戏已有的北区「后山采药路」（`qh_north`，底图 `m_qh_north`，1536×1024）。这张图是序章初遇叶蘅的取景地，换衣后可自由重访，但现有内容只有树、倒木、石堆和四处枯枝／草药采集点，缺少停靠理由。本次新增内容同时给后山补上剧情停靠点：

| 位置（世界坐标约值） | 用途 |
| --- | --- |
| 倒木（约 875,245，南侧落脚） | 宋先生坐着翻账簿的固定站位；`C1-00B`、`C1-S1`、`C1-S2` 都在这里对话 |
| 倒木旁 | 他放下的包袱与账簿，只在他在场时出现；`C1-10` 改为倒木上卡着的一截红绳 |
| 南入口（`entry`） | 萧白从村里上来的落点，不改 |

时段与站位：

- `C1-00B`：第一天上午，强制。`C1-00` 结束后提示「周婶托你去后山收回晒药的竹匾」，玩家走到后山即触发；竹匾作为一次性可拾物放在倒木附近。
- `C1-S1`：第二天上午开头、`C1-S2`：第三天上午开头，宋先生在倒木处等候，任务栏提示「后山有人等你回话」。两场不耗半日；玩家不去，进入下一次半日行动前自动以短过场补播，不能借此跳过。
- 周砚原排第二、三天在后山入口察看路径。两人不能同场：这两个上午周砚改在西田埂接应，下午再回后山入口。宋先生避开周砚本身也是线索。
- 第三夜起后山不再有宋先生；章末若重访，只剩倒木和红绳。

需要的新素材只有宋先生一人：探索用静态站／坐姿精灵与对话头像（账房便装、衣领下露出红绳），按[角色素材规范](role-assets.md)另立需求。地图底图不改。

## 二、作者层真相（不向角色揭示）

裴嵩以正道盟执事身份难以公开进村：徐令仪认得他，周砚也可能认得。他化名「宋先生」，扮作替人跑账的过路账房。

他的完整算盘：

1. 借药商散出叶家有秘物的消息，把正道盟、归烬堂、巡江司都引到栖河村。
2. 经手拼接三份转附内容，把三方约到「第三日戌时、药棚装卸侧口」，让三方当面相争。
3. 等三方把叶家逼到走投无路，次日以正道盟执事真身出面「收拾残局」，用庇护和「代为保管危险功法」的名义拿走遗产。
4. 他需要知道三方何时动手，于是托一个刚到村里的外乡人萧白当眼睛。诱饵是替叶蘅沿路打听她父亲温行舟的下落：萧白受叶家收留、想报答，这个许诺最能打动他。裴嵩是否真知道温行舟的结局，本次不定。

计划落空的原因：

- 萧白照他的嘱咐在路口数人、记站位，三方都看见了这个外乡人，各自怀疑他是另外两家的眼线。谁也不敢先下死手，徐没有让护院进院硬取，岑只让乌魁「看住」。三天里没有一方提前强取，叶蘅得以和陆衡把撤离准备做完。
- 火灾后叶蘅当即随周砚离开，村民由邻村接手，没有出现他预想中「只能求正道盟庇护」的局面。
- `C1-07` 三人当场对证附页，识破消息拼接。此时再以正道盟执事身份出面就太可疑，他只能撤走，不再赴后山之约。
- 他还以为遗产在叶家；实际上叶家箱子里只有线索。即便计划成功，他也拿不到想要的东西。

三份附页由裴嵩一方经手拼接，这是作者层设定。角色要认定他的责任，仍须在培养阶段取得经手人证言、传讯时间与物证互证，培养阶段的具体剧情待重新设计（原写在[汉皋城剧情](../archive/design/hangao-story.md)与[汉皋主线逐句稿](../archive/design/scripts/hangao-main.md)，2026-10-19 已作废归档；旧[襄阳会面评审](../archive/design/xiangyang-gathering-review.md)已归档）。

## 四、叶家箱子里实际有什么

叶蘅在 `C1-03` 第一次打开母亲叮嘱别拆的夹层，只找到药签与空压痕；再加上她从小就有的父亲笔记，共三样线索，各对应一件遗产：

| 线索 | 对应遗产 | 线索内容 |
| --- | --- | --- |
| 父亲的几页笔记（医案与步架草图） | 《归元诀》 | 一页边角写着「归元」二字，后文不在这里 |
| 母亲手写的药签 | 续脉散记录与样品 | 写着续脉散与治伤用途，签下没有药 |
| 夹层底布上的方形压痕 | 玄曜玉匣 | 这里放过一只匣子，现在空着 |

叶蘅明白：三方要的东西她交不出来，说没有又没人信；留在村里，下一回被砸的就是周婶家的门。这成为她离村的直接理由。

谁取走了这些东西、放在哪里，本次不定。由培养段遗产线索剧情另行设计，须在年二秋冬裴嵩亲自索谱之前让《归元诀》有着落，见[三年事件表](timeline.md)。
