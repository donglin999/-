# 人物立绘风格：淡彩水墨与情境背景

状态：现行　最后核对：2026-10-19（原记：**用户于 2026-09-30 确认，作为后续江湖菜单人物立绘的固定制作标准**。基准为已采用的[萧白](../../assets/p_menu_hero_v1.webp)、[叶蘅](../../assets/p_menu_ye_v1.webp)、[苏芷](../../assets/p_menu_suzhi_v1.webp)。三人的阶段说明见[菜单立绘](jianghu-portraits.md)，原始提示词见[制作记录](jianghu-portrait-prompts.md)。）

## 固定的画风

- 中国武侠题材的精细白描、淡彩水墨与水彩晕染，带自然宣纸纹理。人物线条清楚，面部、手部与棉麻衣料细节精细；背景笔触更松、更淡。
- 成人骨相与自然身体比例，保留角色自己的脸、发型、职业骨架和气质。可加入成年女性按[当前逐人选择与身材基准](female-visual-v5.md)制作；叶蘅恢复初版，唐照雪沿用户最新指定原图，其余默认沿双图基准。不得把所有人物画成同一张脸，或以夸张大眼、幼态比例表达年轻。
- 暖米白纸色统一画面；灰蓝、灰褐、草木绿承担环境，赭红等角色服饰色只作局部重点。光线柔和，色彩低饱和，人物辨识度高于背景。
- 使用绘画质感，不采用照片、写实 3D、厚重油画、赛璐璐动漫或像素立绘。材质细节服务于人物生活状态，不增加华丽盔甲、珠宝或装饰来代替表现。

## 背景由当前剧情决定

女性服饰与体态的当前调整范围见[第五版](female-visual-v5.md)。用户于2026-10-03确认岑霜稿，并提供双图身材基准；随后指定叶蘅恢复初版、唐照雪沿用户最新指定原图，沈雁回和乔行舟以好看为第一要素整图重置，姿态、衣装和情境背景重新生成。最新逐人选择优先；其他角色脸、发型与职业服饰沿本人原稿，少量领口和裙衩依据气质。普通职业人物保留职业衣装和年龄。此规则与本页固定画风共同验收。

每次出图先明确：**人物当前所在地点、季节、已经发生的经历、当下心境**。从这些信息选择少量环境线索，例如城门、河岸、茶棚、药铺、竹影或山路；背景要能说明此人为什么在这里。

背景是完整画面的一部分，不能退回单色空白或透明抠图。远景低对比、轮廓疏朗，保留淡雅和空气感；不以密集人群、招牌、建筑细节或强光抢走人物注意力。心境主要由神态、姿态、光与空间表达，不画情绪符号、魔法光环或说明文字。

不得提前画出尚未获得的门派身份、服装、装备或已知剧情之外的象征。路线与阶段改变时依据[人物](cast.md)和对应分支文档换装、调整背景，同一角色仍保持外貌连续。

## 构图与交付

- 统一竖幅 **2:3**，基准分辨率 **1024×1536**；更高分辨率仍保持该比例。完整包含头顶、手、衣摆和鞋，不能用下沿截断来省略腿脚。
- 单个人物居中，脸位于画面上部，轮廓与背景清楚分离；人物在狭窄菜单里仍应看得清。背景不遮挡面部或关键医具、兵器。
- 原画不烘焙姓名、边框、装备槽、按钮、等级或任何 UI 文字，也不添加水印。菜单自行叠加信息，底部背景须能承接界面的渐暗信息层。
- 原始 PNG、运行 WEBP、完整提示词和参考图来源一起保存。新图使用版本文件名，并在游戏菜单中检查显示效果。

本标准用于带背景的菜单人物主视觉。对话使用同一画风与人物身份的透明表情立绘；探索与战斗的像素素材继续遵循各自媒介规范，剧情 CG 依据事件构图。

2026-10-03新增的培养Q版对白与人物反应按[独立Q版规范](cultivation-q-portraits.md)制作，允许用户采用的漫画比例与表情语言；本页自然成人比例与淡彩水墨要求继续适用于江湖菜单及同画风对白，不用于否决该Q版媒介。

## 可复用的提示词主体

```text
精细中国武侠人物情境立绘，淡彩水墨、清楚的白描线条、水彩晕染和暖米白宣纸纹理。按最新逐人选择保持成年面容、发型、职业骨架与当前阶段服饰；用户要求整图重置时重新设计面容、姿态、衣装、背景与构图，以好看和吸引力为第一要素。若为可加入成年女性，默认按双图身材基准呈现自然丰满胸部、收腰与腰胯、修长腿部；叶蘅沿初版，唐照雪沿用户最新指定原图，不自动改体态。衣装裁剪自然承托，身材参考只负责身体比例。自然成人比例，面部、手部、衣料和道具细节精细。竖幅2:3，单人从头到鞋完整入画，脸在画面上部，人物为视觉中心。背景依据[当前地点、季节、已发生经历、当下心境]，使用[少量符合剧情的环境线索]，低饱和、低对比、淡雅疏朗，远景笔触轻于人物。柔和自然光，背景完整不透明。没有文字、UI、边框、水印，没有额外人物主角、夸张动漫比例、3D质感、魔法光效或未发生的身份与装备。
```

人物、背景和心境字段必须逐次填写；不得把上一角色的背景或道具直接复制给下一角色。出图后与三张基准并排检查画风、身份、背景浓淡、全身完整性，再检查实际菜单里的脸部与信息可读性。

## 独立衣装与面部结构

出图前分别填写[衣装身份](faction-attire.md)与[本人面部卡](character-face-identity.md)。至少两项非颜色衣装特征，含一项领袖或衣摆形制；具名角色至少三个面部结构维度，含骨相和眉眼。只用“美丽鹅蛋脸、杏眼、小鼻、小嘴”不够。同派不共用脸，服饰换色不算区别。局部整改时以最新授权为准：衣装编辑锁脸；面部编辑允许改骨相五官、锁当前衣装及全图情境；不写互相冲突的锁定要求。确认新定妆后再沿同一身份制作后续表情与CG。
