# 新故事中的人物与旧角色调整

状态：现行　最后核对：2026-10-22

2026-10-16。当前全流程设计的人物负责页，未生成新素材、未接入新剧情。新角色均为非招募剧情人物，19位可入队名册保持。已有同伴形象与年龄沿原负责页，新联系见[人物与支线](companions-and-side-stories.md)。

年龄均以开篇同年为基线；三年之后按实际日历增长。以下年龄是本轮新设计值，不冒称用户逐人指定。首次出场与首次被提及分开，已故人物不需要制作能活动的尸体单位。

## 阿七

- ID `a-qi`，男，开篇18岁，无门派。**开始部分是栖河客栈门口的乞丐少年，村里人叫他“小耗子”**（2026-10-22 用户第八轮「12，合并」把教窃的小耗子并入阿七；名字关系“阿七是本名、小耗子是外号”待用户确认，见[偷窃稿](../npc-steal.md)第 3 节、`bible/人物/阿七.md`）；替人跑腿换口饭，喜欢听说书和给孩子演大侠。与萧白在风起第一天的固定剧情“小耗子的一课”认识（次日药摊之后萧白一出门就被他叫住，教会“窃”，主线必经）；旧档没有这段时另做现场补初识。
- **两条规矩**：不偷穷人，不偷救命的东西。他管自己的小偷小摸叫“做好事的工钱”——后来借名做好事，拿的“工钱”从一个饼变成掌声和被人记住。
- **形象**：稍长的脸、左眉短缺口、笑起来一边嘴角先抬。开始部分乱发用草绳扎、脸上带灰、补丁短褂挽一边袖、赤脚，手边细竹杖、脚边豁口碗；离村后头发扎得随便，旧短褂常挽一边袖子。扬名后换挺括青蓝行衣，但脸与动作保持，怕被看穿时先拢衣领。冒名借的是姓名和师门声望，不是神奇易容；熟悉萧白的人不会认错脸。
- **欲望与缺点**：想被当作有用的人记住，确实敢救人，却害怕回到无人认识的生活。受夸奖会把事实说大，心虚时抢着替别人说结论。
- **过程**：客栈门口教萧白“窃”、立两条规矩、第一单把偷来的酒放回柜台（固定剧情；P1-02草台演侠建议不另做）→火里救孩子（取舍待定）→到谷试练却选择继续谋生→萧白在培养部分出名（原写二年正月汉皋试艺与解围；汉皋城内剧情作废，出名照样成立，具体事件待汉皋重设计补，用户第八轮 10）→在只闻名未见脸的邻镇借名真救人→接受被安排的胜利→真萧白出现→公开承认或继续争功→第一次用自己的名字承担结果。
- **与玩家的关系**：他不是新增同门，也不靠满好感加入。提前揭穿、私下劝阻、一起救人和真正交手留下不同关系，不能统一回到“从来不知道是假冒”。
- **战斗与资产**：普通刀攻击、守势和有限既有招式映射；不是完整归云剑法继承人。需要乞丐（小耗子）/粗衣/扬名衣三阶段的同一身份包、真实切磋包；目标准备值与敌人标定由[百级方案](../character-levels-100.md)维护，不根据主角等级生成数值。

## 姚安

- ID `yao-an`，男，开篇18岁，玄烛会弟子。P2-04实际初见，P3起携养父阎望山的棺木还乡；是重要同行NPC，不加入永久名册或额外第五战斗位。
- **形象**：方中带圆的脸、眼尾略向下，头发贴服束起；褐灰窄袖衣，袖口认真补过。护送时加素色丧带，谈到父亲会抚平衣角；愤怒时先把手里的东西放稳。与阿七的扬眉、抢话和借来的华服相反。
- **欲望与过失**：想把养父葬回故乡，也想证明自己记得的疼爱是真的。他曾奉命押送一名被称为叛离者的人，事后知道对方被杀，却选择不继续问。这是他的行为，不能用“我不知道全部经过”抹掉。
- **过程**：与萧白共同照顾受伤者→还款通信→养父病故→拒绝被示众→听见恩惠和血债→被受害者认出自己的过失→知道生父也死于阎→拒绝替师兄再报仇→安葬、留下交代自己的旧事。
- **主动性**：自己安排船家带棺离场；自己拒绝旧刀与复仇召集；自己面对受害者。主角可护葬，也可只追借名，他不能强迫主角为全部血债担保。
- **战斗与资产**：日常/丧服两阶段；有抵挡和脱离的剧情交锋需求，首版可用专用短旁观序列。没有新秘术、血统觉醒或继承会主全部功力。棺木由场景物和分段转场表现。

## 阎望山

- ID `yan-wangshan`，男，开篇63岁，玄烛会前会主；培养末到游历开始之间病故，具体消息由P2-10送达。正文不安排活着的他与萧白会面。
- **形象与遗物**：遗像是厚眉、面颊削瘦、嘴角下压的老人，旧刀磨损明显。只需身份资料、遗像与可辨棺上纹样；没有尸体行走、复活或活人战斗包需求。
- **既有事实**：救过洪水中的孩子，养育姚安，也在清算叛离旧部时杀过人，包括姚安生父。好坏行为都能找到具体当事人，不能用一个背后黑手替他开脱。
- **作用**：他的死亡引出活人怎样面对师恩与仇恨。不是叶家旧案主使、温行舟化身或萧白穿越答案；这几条故事互相独立。

## 陶照海

- ID `tao-zhaohai`，男，开篇53岁，合川独立武馆拳师；P3-04实到约56岁。他不是合川拳门的掌门。
- 也不是LIFE故事里的梁守拙；两位拳师身份和素材分别登记。
- **形象**：宽鼻、短胡、右耳有练拳旧伤，常穿洗得发白的深褂，教人时不高喊，只拍一下对方肩背纠正。愿拿自己的面子换馆里周转，却低估被人宣传成骗子的后果。
- **故事**：受邀输一场“让少年出头”的切磋，谢的经营者却借此夺走他的名声和生计。玩家赛前制止则武馆仍在；赛后才揭穿，仍须有实际补救。用于假赛旁观的结果是已写明的演出，不能假装玩家参与的战斗被固定判负。
- **资源**：一阶段重要NPC、拳系旁观与对练所需战斗包。其弟子复用合适的普通模板，不能为了省资源把梁与何的故事并到他身上。

## 常秀

- ID `chang-xiu`，女，开篇39岁，山桥附近居民，P3-08实到约42岁。此前不认识萧白，认识的是当年押送父亲的姚安。
- **形象**：眉浓而平，脸颊晒红，头发紧挽，灰绿短袄与旧腰布；父亲留下的刀包在粗布里，开口之前先将刀横在桥前。她说具体的年月和人名，不替作者总结正邪。
- **欲望与行动**：阻止仇人被风光安葬，要求姚安说明自己做过什么。她不接受谢擅自借自己的仇逼别人当众杀人；可以一生不原谅，也可以允许棺走一条不经过自己家门的路。
- **资源与玩法**：重要NPC对白/探索与可选交锋包；不强迫玩家与她战斗，独立追查者可旁听后走岸路。非致死战胜只改变当前通路，不把她的态度改成感激。

## 梁守拙与何素娘

- `liang-shouzhuo`，男，开篇61岁，退下长途镖路的老拳师；扶帽子、叫阵声大、挨打后先看她有没有笑。灰褐短打、旧护腕与不合时宜的鲜亮帽带构成辨识。
- `he-suniang`，女，开篇59岁，卖豆腐的寡妇与拳术熟手；衣袖挽得齐，收钱前先擦手，训人不耽误手里的活。深蓝围布、素簪、扎实站姿，后期才出现视物困难。
- 工作名《输了二十年的老人》不作为每年固定届数。培养初识可说二十来年；游历重逢按实际经过年份承接，晚初识不伪造与主角多年交情。
- 旧约发生于她守寡之后；她自己的家事和生计也曾让出行推迟。现在徒弟能接摊，她才有条件考虑去看海。结局由她和梁自己决定，不由萧白治好眼疾换取。
- 五场完整故事及在场、迟到、收益见[LIFE故事](companions-and-side-stories.md)。两人不入队，各需自己的重要NPC身份/对白/探索和拳系旁观包；不能用一个老年头像替两位人物演拳。

## 普通人物与素材限额

旧船夫、被扣船工、患病者、村中孩子、执捕队长及随从使用有清楚职责的普通或战斗精英模板。重要证言可以有姓名/称呼，不因此人人扩成可招募或六状态主角包。执捕队长可以有独立敌人配置，但不需要再写一条身世长篇。

本轮登记新增7名具名非招募人物，19名可入队不变。资源估算的9位重要在场人物包括3位旧稿主事者与6位新活人，另计阎的遗像资料；这些是待制作需求，非已经完成的素材数量。
