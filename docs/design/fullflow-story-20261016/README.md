## 先读故事

萧白在栖河认识爱演大侠的阿七，两人在火里做过真正救人的事。萧白入谷学艺，第一年五月短访汉皋，第二年正月在汉皋试艺、结识众人并替人解围，渐有地方声名；之后仍多次外出、返谷。三年末独立游历时，萧白发现自己的名字已经被阿七借去行侠，也被别人拿来购买胜仗、招揽年轻人。追到这段借来的名声时，他又遇见当年帮过的姚安，正要把已故养父的棺木送回白石。

葬礼已经被谢承岳宣传成少年英雄断旧怨的盛会。姚安拒绝成为被示众的“孽子”，带棺离开。沿途有人记得亡者救过自己的孩子，也有人要他为血案偿命；姚安既是养父杀过的仇家后代，也曾参与过把另一个受害者押向死亡，无法一句话说自己全无责任。

白石镇的三方已经动手：谢要让年轻人以亲手杀人证明立场，庄要他们继承师父的仇，严为抓旧案犯把无辜者也扣住。萧白终于不能再借别人的名字摆平事情。他要亲自选择破擂、断复仇，或带一批人离开，并承担其他地方没能同时处理的结果。阿七与姚安也会自己作决定。

## 可实现的制作范围

首个完整切片从**当前正式汉皋南门→药案→返谷→阿七来访与真实陪练**。它需要先接通正式城市与读档路由，再做最小城街、医馆和后仓，不把隔离演示当作正式主线。

后续复用现有对话、探索与回合战，集中补四个共用适配：事件状态和奖励去重、任务同行与出席、特殊战斗目标、分段行程。护送、潜入和船上交锋采用实走节点、选择及固定场景战；楼层通过入口跳转，不要求先造实时海战或攀爬引擎。

全流程空间和人物资源是分批制作估算，详见实施矩阵。当前只有部分栖河与培养内容实际接入；旧候选地图和图鉴头像不能直接算正式可用素材。新增战斗目标仍需接口、敌人和数值验证，剧情里写“能输也能继续”不等于代码已经支持。

## 本轮的有效选择

提前揭穿阿七，后面改讲争功与名声；先阻止假赛，武馆不会仍被写成倒闭。拒绝护葬只追假名，也不会被后面台词追认为一路护棺。叶蘅学医或针攻均能完成家事，19人未收齐仍能理解并走完主线；普通关系不能让缺席人物突然上场。

老人比武、戏班改本和修船等支线留下独立地方变化，不全变成终局援军或隐藏钥匙。三年月份和人物年龄照实际阶段增长，普通城内走路不推动时间；进入最终行动前才明确展示受影响内容。
