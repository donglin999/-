# 100级上限与人物首次出场等级方案

状态：现行　最后核对：2026-10-19

2026-10-13。**用户确认：角色满级100级。** 下列逐人等级由本轮设计提出，尚未批量迁移到战斗、培养或招募配置；不能把规划表当作已生效数据。

负责范围：角色等级上限、首次出场固定等级、首次正式入队固定等级及其迁移边界。功法仍外功十重、内功五层，职业/医术/好感独立；100级不代表自动学完绝学。当前四部分为开始、三年培养、下山游历、终局，旧二十章时间表仅追溯，不复用其章节号。

2026-10-13追加确认：世界顶尖NPC/敌方完整形态不超过90级，主角与已入队同伴成长上限仍100级。周砚改88级；叶蘅初见及入队改3级。常规主线终局敌方建议72—80级，85—90级强敌只作可选挑战，不用隐藏攻击/气血倍增变相恢复百级门槛。逐场轻度玩家验收另做，不能仅凭等级下降宣称已降低完整游戏难度。

2026-10-16核对：现行`gy_go_in_stead`窗口为培养第34期（第一年七月末），选择同行即授予正式资格；未入队者除夕关系≥40可补入。原表“八月”已校正为现行入口时间；此项纠正不表示54级数值已批量迁移。

### 殷红缨：真实等级保留，限制实际出力

初见/入队54级保留，以持久状态“旧伤未愈→伤势缓解→经脉渐复→痊愈”表达出力下降，具体数值与解除规则统一见[人物状态与同队成长](character-condition-growth.md)。不改真实等级、不反复乘原始属性、不用主角等级决定伤势。

### 三位领队的阶段一致性

徐22→36、沈24→38、岑38→58，为首次出场到正式入队的固定成长节点。岑的38体现先成名与独门软鞭，不能让三人都8级仅靠文案称强弱。当前3v3演出仍为徐8、岑8，沈无单位；迁移时应重算整场伤害/HP、护卫等级和四招后停战，绝不可只把lv字段改大。

岑旧“主角≥34级”入队门槛与新游历中段曲线不匹配：本方案建议改为主角≥50级，赔偿、交接与两场考验仍必需；这是随曲线提出的待测修订，不是用户已确认的新门槛。殷的旧34级恢复任务门槛同样列入待校准，不静默提前/延期任务。

## 实施顺序与验收

1. 本轮实施角色升级上限100；满级后修为槽显示已满级，不再发升级点或因经验奖励回满血；金钱、道具、关系、功法熟练仍正常结算。
2. 本轮不把表中等级灌入所有NPC，不调整开始部分交锋，不新增武器，不开放待做的招募。
3. 2026-10-13追加实施：普通人类同伴改用个人lv/exp，不再由mkAlly或菜单统一读取S.lv；叶蘅3级起步。其余旧档保留已记载的lvSeen与已有属性点，首次迁移一次后独立增长。全员新出场/入队等级表尚未批量采用，宠物跟级是后续独立任务，不冒充已完成。
4. 100级旧档溢出经验清零；超过100级的调试/旧档读入时钳到100，记录迁移前等级和经验，已加属性/装备不擅自扣除，不自动重算历史点数。
5. 验证99→100恰好一次升级，巨额经验不越级、满级奖励无重复属性/治疗，普通升级与经验余数保留；浏览器检查满级菜单和存档独立测试。

## 全流程新增人物的配置边界

阿七、姚安、陶照海、常秀及二老为非招募剧情人物，具体战斗固定数值须在相应P3、P4或LIFE切片内标定后填写；本轮没有用主角实时等级计算一个伪“固定值”。阿七的真实切磋可败也可拒，前期旁观假赛与真战的结果分开；二老正式比武为固定叙事的NPC旁观序列，陪练另按真实操作目标结算。阎望山已故，不建立当前可战版本。数字未标定不影响故事可写，但会阻止对应战斗宣布正式可玩。
