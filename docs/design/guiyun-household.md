## 氛围目标

归云谷不是“掌门＋弟子＋教程”的功能表，而是**一个吵吵闹闹、互相护短的家**：

- 饭桌上永远有人拌嘴，但谁受伤了全谷一起熬夜。
- 长辈各有毛病：师父话少、二师叔唠叨、小师叔不着调、师母管得严；可萧白和叶蘅出事时，四个人会同时出现。
- 规矩少而硬。师母定的三条家规（见下）比任何门规都管用。
- 江湖名望藏在细节里：来客对周砚执晚辈礼，小师叔提一句“归云谷”就能让地痞收手，但谷里的人从不拿来炫耀。

### 人物细节

**江采薇（师母）**
- 出身荆襄“远山镖局”大小姐，年轻时走镖，一手绣花飞针名动一时；嫁给周砚后封针不出，只在谷里缝衣、补网、偶尔钉一只乱跑的鹅。
- 治家三条家规：**饭桌上不谈打杀；受了伤先报给我，不许硬扛；来客无论正邪，先奉一杯茶。**
- 心结：周砚当年护送受过的旧伤一直没好全，她最怕他再为别人的事拼命。叶家之事一开始她持反对，后来因为叶蘅而改变。
- 与叶蘅：她认得叶青——二十年前走镖受伤，是叶青替她接骨。这让她把叶蘅当半个女儿，也是叶蘅第一次从旁人口中听到母亲年轻时的样子（**只提供叶青的为人与医术，不揭晓遗产真相**）。
- 说话样例：“吃饭。打架的事，吃完再说。”／“你师父说没事，那就是有事。”

**殷红缨（小师叔）**
- 周砚的小师妹，师祖晚年收的关门弟子，剑法与“回岚步”身法最好。十几年前在一次寿宴上当众掀了正道盟某执事的桌子，从此“不受盟里欢迎”——为后续裴嵩线埋一个旧怨的钩子（具体是谁待定，不必是裴嵩本人）。
- 表面：睡到日上三竿，酒葫芦不离身，叫萧白“小白脸”“小呆子”（她不知道穿越真相，不使用泄露作者信息的称呼），喜欢逗他脸红。
- 里子：谁欺负归云谷的人，她第一个拔剑；她其实是全谷最怕“家散了”的人，所以才常年在外，不敢多待。
- 与周砚：互相嫌弃又彼此信任；与钟拙：见面必吵“剑与拳哪个先学”；与师母：只有师母能让她把酒葫芦交出来。
- 说话样例：“剑是用来护人的，不是用来摆姿势的——不过姿势也得好看。”／“谁动我师侄，我就动谁。”
- 写作边界：可以性感、调侃、暧昧逗弄，但不写成对弟子越界、不写成用色相解决问题；她的魅力来自强与真。

**钟拙（二师叔）**：拳掌传人，信“笨功夫”，让萧白挑一个月水再出拳；谷里的木人桩、水车、鹅圈都是他做的。爱讲门派往事，十句里有三句是吹的。与殷红缨的教学之争给玩家第一次主修倾向的选择。

**方迟（大师兄）**：被周砚当继承人带大，什么都做得对，却不知道自己想要什么。萧白入门后他第一次有了“要带的人”。年一中段下山历练受伤归来，是师门凝聚的转折。

**卢小豆（小师兄）**：拜师面初见时十四岁，十一岁入门，比十七岁的萧白小三岁、却早入门三年。爱撑师兄架子，照顾师弟时又会露出少年心性，是日常喜剧担当。轻功天分高到让殷红缨都认真；他偷偷想跟小师叔下山闯江湖。

2026-10-12 用户确认小豆应为约十四岁的少年，与当前立绘对应；取代此前十七岁、与萧白同岁的设定。保留现有少年立绘与 Q 版，不改成主角的成年形态。十四岁指入谷初见阶段，后续随故事时间成长；不借此改动萧白年龄或其他角色年龄。

同日确认小豆默认持剑。固定对练配置、现有归云剑法映射和待制32帧剑招精灵见[小豆战斗合同](combat-characters/lu-xiaodou.md)。脚下快、剑路浅，不再默认拳脚；仍为非招募师门角色。所有师门成员出手须遵守[逐角色动作规范](combat-action-contracts.md)，不能共用一套攻击动作。

**周小满**：13 岁、未拜师，不参与战斗与情感线，只作为家的气息：起外号、告状、在叶蘅身边学认药，偶尔误打误撞带出线索。

## 殷红缨 · 全作联系与可玩后续

状态：本轮设计修订，依用户要求自主补齐人物与全作联系；后续事件未实装，未登记正式日历。基础年龄、身份和已采用外形沿登记与明确决定，新增举止是演出需求，不代表已有素材。时间只按开始（栖河）、培养（三年）、游历、终局；本节承接既有招募、职业和关系，不增加统一好感门票。跨角色调度与替代解法见[十九人整体合同](story-rework-20261016/companions.md).

### 人物辨识与缺点

沿用户选定B版、现有白灰归云衣装与红发带/酒葫芦；靠柱懒站，遇事先把葫芦塞稳再出剑，右手旧伤收指动作只在已设阶段使用。外形不因新篇重做，真实等级/旧伤效果沿现有状态合同。

**自身追求**：学会留在家人身边承担长期责任，而非每次护完人就走；让晚辈真正能接过自己守的路。

**真实缺点**：极度护短、不愿暴露怕家散的心事；把离谷和喝酒当作不必回答旧怨的办法。

**说话与例句**：嘴利、闲懒，危险时短而直接。示例：“这回你守前头。我在这儿，不走。”

### 可玩个人任务

**事件与前置**：CP-YH《这回你守前头》：游历后段至END-CHOICE前，归云谷口与近山旧路；本人旧怨/伤势阶段已满足对应行动，不能用本任务自动治愈。

**玩家实际做什么**：先在探索中确定前后口分工和撤离集合点，完成家人交接；两次普通小队战分别对付前口拦路者与后口追击者，玩家自行决定当前合法编队，殷留守则不同时出现在另一场。每战都以击败本场敌方小队为成功、win/lose/flee返回探索，再查看接应情况；不设独立守满回合的胜利条件。战败或逃离回谷口整备/换路，师门不为煽情被强制全灭。

**与主线的双向影响**：主线令她不再能一走了之；做成建立一次明确谷口接应/师门避难能力，同时主角获得独立行动回响。没招募仍可由周砚/方迟的留守安排完成基础防守，不扣她的全部人生进度。

**招募与成长边界**：她已是采用的可入队人物，保留代师出行/除夕与游历if补救入口、现行武学和固定等级；旧八月概述不得覆盖现行关系合同的具体触发。新任务只续写，不剥夺旧存档资格。

**在队、不在队与未结识**：在队可随行，留谷则本地守一处；不在场不能在另一地图同时教招。未招募由师门原有安排护谷，不能额外把小豆变可控同伴补她。

**终局立场与代价**：支持护住师门与普通人，可与三方合作；拒绝拿归云收留者抵债，亦不会纵容萧白仗师门欺人。她承担拒绝盟内推荐/推迟游历的代价，旧伤不靠亲密值消除。

**其他人物的独立关系**：方迟继续独立历练与接班压力；卢小豆保持初见14岁、默认剑、非招募，培养末随时间成长，不为了这条线立刻成年或送上政治前台。
