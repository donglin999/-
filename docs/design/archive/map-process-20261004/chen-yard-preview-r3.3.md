## 从图到运行时

完整屋身地面占位包含纵深，不能只标正立面的一条窄矩形。左右附棚分别有占位和完整顶棚前景。石墙、木栏、门扇逐段标注；打开的院门中间保留通道，不将两段墙整体封死。树根占位，树冠遮挡；草坪与普通土路仍能走。

全村此次从22项主要障碍补成69项，包括屋身纵深、附棚、侧墙、院栏、南菜园石墙、配套餐凳和落地支撑。由 `tools_scene/repair_preview_v3_exterior.py` 根据原图坐标生成，参数单一来源为authoring-board.json。历史参数在 `review/chapter1-preview-v3/exterior-r3.3/history/authoring-before.json`。

## 本轮验收门槛

1. 图中陈家门洞、院门和主路一眼可读，工作物只在有用途的区域。
2. 独立于参数生成脚本的固定坐标检测：用户所示左棚、南菜园墙和其他墙/屋身必须不可站，门口、院门和普通路必须可走。
3. 障碍边界密集采样检查碰撞缺口；此项只能查参数栅格化，不能替代对照原图查漏标。
4. 实际移动到陈家门内外、两条屋侧路、三个院门、南菜园外、桥两岸；键盘向问题石墙持续行走应被实体阻挡。
5. 实际进陈家并返回，完整序章委托/歇息/刷新回归。
6. 每次实机截图实际打开，失败图与失败参数保留；只为这轮覆盖位置作结论，桥高差、像素密度和正式第一章依旧未验收。
