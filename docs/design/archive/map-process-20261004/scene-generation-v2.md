# 场景生产规范：序章第二版基准与襄阳迁移

状态：2026-10-01。用户要求以当前序章第二版实际制作方式重构襄阳，保留旧版对比。本页记录真实参数与执行门槛，不把本地自查写成用户批准或线上发布。剧情由各场景设计页负责；空间规则见[画板与空间合同](../../scene-spatial-contract.md)。

2026-10-03补充：村落生活布置与家具比例已退回，执行[市场调研与生活空间](../../village-layout-research.md)。道路与围墙检测不能替代功能构图评审；无标签的空间用途、家具人体尺度和非重复院落形态均为设计否决项。先验收功能草图、同尺家具及可玩灰盒，再批量制作素材。

## 基准与范围

生成前执行[独立设计基线与前置验收](../../map-preflight.md)：冻结建筑尺度、院落边界和功能入口，再生成与拼装；不得只让可变画板自证。第一章旧视觉接受已撤回，新门槛目前先在村落实行，其它图待逐图迁移。

采用稿是 `art_sources/prologue_village_v2/` 的修正批；直接参考为 `art_sources/prologue_village_v1/terrain-source.png`。可核查[生成记录](../../../../art_sources/prologue_village_v2/generation-record.json)、[世界画板](../../../../art_sources/prologue_village_v2/authoring-board.json)与 `tools_scene/build_prologue_village_v2.py`。本轮使用内置 `image_gen`；记录没有给出的模型版本、seed、steps、guidance 等不能补写为事实。

采用干净地面与独立透明物件，延续高三分之四俯视、宽屋顶和短朝南立面、中等绘制色块、灰蓝瓦／灰米墙／土褐地／低饱和灰绿草、左上柔光。独立分层不能自行更改画风。襄阳增加城防与市井用途，镜头、颗粒、材质与采样保持此基准。

人物继续复用既有资源，不生成新人物。角色颗粒与场景还不能据此宣称全套正式统一完成。立绘、图标、战斗背景各按原有专门规范，不套用地图参数。

## 制作顺序与每一步门槛

### 0. 城市设计方案、草图与建筑玩法

布局方案先按[城镇设计调研](../../../archive/design/game-town-layout-research.md)组织街坊、院落、主次路径与关键镜头，至少比较两个同尺布局。每段转折、扩宽与建筑错位都要有活动或构图依据；禁止把物件统一排成两行后仅以通行检查视为设计完成。

扩建襄阳先按城市扩建方案（已删除）完成体验定位、功能关系草图、带成人尺的构图稿、逐栋功能表与室内外剧情状态。拓扑图不代替造型草图，坐标表不代替城市设计。沿街商业、公共支巷与私人院落有明确关系；建筑标明常开、剧情开放或外景。

城门、道路、城墙先核对统一透视轴线、门洞中心和承重柱；偏斜源稿在样板阶段退回。首个开放建筑完成入口、室内、交互与状态闭环后再扩其他建筑。缺少功能表或构图稿不启动整批生成。独立验收另判布局与用途，不用通行测试代替设计审看。

### 1. 归档与功能卡

替换前保存旧底图、图集、空间数据与脚本来源，记录文件摘要。每图保存无 UI、正常游戏、占地叠图；新旧对比采用同角色点、同视口和同光照。旧版需能独立复看，不能只保留缩略图。使用版本化源目录与输出名称，完成验收后切换运行引用。

从剧情列出口、NPC、交互物、必经／可选路线、案发／结案状态，物件逐项写用途。不让生成图移动任务与出口；低草、土色与阴影不制造禁行。

### 2. 世界画板与灰盒

每件物体有唯一 id、asset、世界 rect、独立 footprint、baseline、depthMode。画板另列入口、出口接近点、NPC 脚点、交互接近点、水域、桥甲板、成人尺、美术合同与地图版本。碰撞、图层、锚点与调试图都从此生成，运行代码不另写近似边界。

普通通道建议净宽≥56，主路／主要门≥84 世界像素。序章主路 140、横路 100、下侧门 140 是该图设计值，不要求所有襄阳路线照搬。偏巷原五格主路名义宽 200（每格 40），不能擅自缩为 140；街心救治与人群处额外留绕行和同伴空间。

先用同尺寸人物走灰盒：所有出口、目标及返回，门口正反向／斜向、墙角与队友跟随。连通区、脚底探测、通路净宽均检查；“单一连通区”只证明拓扑，不能替代有人物时的真实路径与视觉核对。

### 3. 同画板样板与生成

先放房屋、树、横纵墙、桌桶及成人尺，在同显示尺寸对比当前序章修正批：屋顶／立面比例、叶簇大小、砖木纹密度、颜色光向、边缘颗粒。通过自查再扩展全套；文字“高清像素风”不能代替直接参考。

首批独立素材因正面立面偏大、瓦木纹过密、细碎写实树叶被用户退稿。修正批以旧序章物件分离／补全为主，只补被裁切或遮挡部分；树保持宽矮轮廓和中等叶簇，小物件共享简化材质。新城市建筑按城市用途设计，不复制村落布局，也不把提高清晰度当更换风格授权。

地面只含道路、低草、石板、地表阴影、水域与已确定的平面甲板，不含立体建筑／树／墙／家具／角色。桥栏杆与立柱另做。透明物件不得带整块地面或相邻物件；允许廊下通行时素材需有对应透明开口，不能只在 mask 上掏洞。

保存原稿与退稿；套图按分区裁切后定位实体框，记录源图、源尺寸与裁切矩形。保留内部半透明边，不能整图二值化或按背景颜色删除来冒充原生 alpha。

### 4. 同源构建与空间视觉核准

素材等比例拟合画板；比例不合则返修或有理由地改画板再走灰盒，不压扁素材救场。碰撞只取 footprint：树干阻挡、树冠不挡；墙脚有厚度、门处显式断开；封闭屋身阻挡、开放廊下独立留白；阴影不阻挡。

地面不烘焙前景副本，图集只绘实际 alpha。排序按当地实体脚底；不能以裁切框顶点或整面纵墙最南端排序。合法树冠遮挡可用现有 revealOccluded 局部人物提示，但不能借此遮掩脚点落入实物。前景淡化需有干净地面，不能露出烘焙副本。

### 5. 独立验收与接入

2026-10-02起增加[地图大中小分级门槛](../../map-size-review.md)：中、大地图全覆盖局部区与接缝逐条验收，结构完整性单独检查。围墙的声明开口、覆盖连续性、侧墙／房体连接与端柱必须有证据；整体可走不证明围墙正确。分区未审或旧证据过期均禁止productionReady。

验收 agent 读实际文件、日志和截图，列通过／失败／未覆盖项，不仅复述生产 agent 的结论。失败修复后重核，至少覆盖：

1. 所有目标及出口往返；门、墙角、树干、桌边双向／斜向；带 NPC、同伴与宠物分别检查。
2. 障碍边缘及高速移动扫掠；空地不阻挡、脚点不落入实体。先证明符合 mask，再对图判断 mask 是否正确。
3. 主角／NPC 前后遮挡、门口脚部 alpha；固定复查用户反馈的树下、纵墙、院门、桌边。轮廓外不许矩形截断。
4. 1280×720、1920×1080 实机图，成人同屏量尺；100% 素材边缘与实际游戏缩放颗粒；深浅底 alpha 边缘。
5. 任务奖励一次性、案发／救治／结案人物状态、容器领取、队友跟随、旧档位置迁移及存档隔离。

统计来自本轮输出，不沿用序章数字。“位置设置视觉检查”截图不写成完整实玩。artStatus=ready-for-review 只说明可进入审看；productionReady=true 必须建立在声明范围内所有必需门槛通过、当前资源摘要与独立证据一致的基础上，不能仅因输入齐备设为true，也不代表用户批准或线上发布。最终给出旧新同机位对比、实际通过项、剩余限制与是否上线。

## 襄阳迁移范围与连续性

城市范围按 gate 南门、street 街市、alley 偏巷组织，保持城设定（已删除）、[偏巷功能](../../../archive/design/xiangyang-alley.md)、[章节](../../../archive/design/xiangyang-chapter.md)的剧情与跨图关系。各图列完整任务／容器／出口锚点，不能只迁移显眼建筑。

- 南门：盘查、城防、进城与外部出口。
- 街市：南口、偏巷入口、茶棚／柳三娘、说书、铁匠、包打听、救治空地与既有互动。案发／救治／案后共用同一地标，不用素材重绘改变案件因果。
- 偏巷：公井／大黄、吴长老、柴角书匣、可选鸡场、土地龛与回城口。不得重新加废宅官史或巨型土地庙。

渡口、东岸、黑风寨、寺庙与室内不等于这三张城市地图。相邻出口和共用资源需回归，但未实际重做的地图应明确列出，不能声称全十图已达标。旧人物、CG、战斗背景和音频不会因换探索图自动更新。

### 襄阳素材适配退稿与构建硬门槛

- 原城市墙和纵篱长轴斜向，无法按水平/纵向画板连续铺设。分别重新生成 `citywall_h.png`（1774×887）与 `fence_v.png`（819×1920）；保留 `*-diagonal-rejected.png`，改稿请求见 `citywall-correction.json`、`fence-correction.json`。切片工具禁止把退稿覆盖回生产源。
