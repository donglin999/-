## 参数与真实限制

| 项目 | 村落室外 | 叶家室内 |
| --- | --- | --- |
| 生成原图 | 1536×1024 | 1536×1024 |
| worldScale | 2 | 0.6 |
| 世界尺寸 | 3072×2048 | 921.6×614.4 |
| 占位成人世界高度 | 92 | 92 |
| 脚点左右半宽 | 14 | 14 |
| 碰撞采样 | 约 2 世界像素 | 约 2 世界像素 |
| 寻路 | 现有 preciseNav | 现有 preciseNav |

世界尺寸不等于原生图像细节。当前图用于验证布局与流程；大地图正式素材须按最终观看比例分区生成，并复查像素密度和近景清晰度。室内镜头在小于视口时居中，不改变人物世界高度。

新增药棚、陈伯门厅、客房均为1536×1024原图、worldScale=0.6；客栈为相同原图尺寸、worldScale=0.7。成人仍统一世界高度92。原图黑边属于预览画布，客房的有效房间更小，不能按整张图宽度判断家具比例。上述比例是本轮试验参数，室内外原生像素密度尚未验收统一。

## 图到代码的约束

1. 先看整体图，判断建筑是否看得出用途、道路是否顺着活动连接、家具是否有尺寸依据。
2. 修正图中的可通行状态。本轮先将叶家、老人院门改为打开，门扇靠墙，通路中心留空；禁止画闭门却直接让人物穿门。
3. 标定落地障碍与遮挡两个集合。屋身、床、桌、门扇、树根参与碰撞；屋檐、树冠、屏风和前墙按脚点深度重画。
4. 当前用同一张预览原图按多边形裁剪重画遮挡区域，避免再次生成前景导致造型漂移；被遮住的角色在遮挡区域内显示半透明，保证位置可读。这是样板渲染方式，正式制作仍需完整对象轮廓与分区资产。
5. 入口与工作点从图中标定，不能从旧地图坐标平移。本轮首测陈家点落到推车附近，已改到实际主门前；失败截图保留在 review 的 history 中。
6. 用真实移动依次走桥、院门、各建筑前与室内分区，进屋和出屋通过真实 E 交互触发；逐张截实机图并实际打开。
7. 自动脚点合法和截图成功只算技术证据。正式视觉验收仍需查墙体、比例、物品逻辑、画质和遮挡全覆盖。
8. 本轮实测发现床侧小凳漏碰撞，尽管流程测试通过仍必须拒收该截图。小家具也纳入物件清单，逐图核对「可见落地物→碰撞轮廓→遮挡→可达侧边」；不能只检查房屋与大桌。失败轮次保留，修改后截图不能复用旧轮次的视觉结论。

## 序章交互与存档

沿用 `PrologueVillage.previewActions` 中既有对话和任务状态：药棚接还碗/取布/送药小事，分别在陈伯门厅、客栈、老人屋前处理，再回药棚交还。叶家须经过邀请，收药箱由叶蘅交互触发。萧白住陈伯家的独立客房；歇息剧情中的叶家往返使用新版入口，结束回到客房。歇息后停在序章交接点，第一章未迁入时禁止自动跳旧图。

试验使用 `xjh.map-preview.v3.save` 隔离存档，刷新可恢复房间、位置、委托与夜色。新版入口为 `#map-preview-v3`，正式 `#prologue` 地图保持原流程。

## 后续完整场景的开发顺序

五室内与序章主要交互已实现。后续为室外后路门面标识 → 村落分区/接缝及家具各侧覆盖 → 分区高清素材与像素密度统一 → 桥高差 → 第一章迁移。每个新场景先有完整预览，再标定用途、空间尺寸、入口返回点及碰撞/遮挡。村落为大地图，本轮路线不能替代全图验收。
