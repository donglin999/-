# 人物与地方事件如何影响全作

版本 STORY-2026-10-16.1。当前设计方案。负责[四部分主线](story-framework-review.md)的铺垫和回收；逐人具体设计见[19人全作联系](story-rework-20261016/companions.md)。

## 各部分交付什么

开始让玩家认识村里的人，并带着实际救援结果离开。培养通过共同生活、学艺和历练建立可信的关系，完整解决叶家家事。游历让这些关系进入人物自己的师门、职业与地方处境。终局让玩家和伙伴兑现或拒绝一项具体承诺，结算已经作出的选择。

每条重要人物线先有独立人生问题，再与主线发生交叉；不能把所有人都变成谢承岳罪证提供者。支线可以帮助主线、改变某个地方，也可以只完成一个人的故事。

## 主要回收关系

| 前期经历 | 游历中实际发生的变化 | 终局可兑现的帮助与代价 |
| --- | --- | --- |
| 栖河救援与村民重建 | 村民选择新住处、职业与来往，不只等主角施舍 | 可提供接应与住处；不能因好感高就要求他们再次失家 |
| 汉皋假药案与苏芷引荐 | 叶蘅、苏芷建立可信诊疗与复诊关系 | 能辨伤、分诊、安排照护；病人与供药能力限制救援范围 |
| 徐令仪赈济和裁断 | 她获得参与联防事务的机会，也面对强制借兵 | 能争取代表与保护小派，不能自动控制正道盟全部人手 |
| 岑霜赔偿与堂务交接 | 会中统合威胁她已经答应保护的人 | 可提供渡路、会中交涉或反统合帮助，也必须面对真实抢掠责任 |
| 沈雁回委办核验 | 真实命令与伤害并存，证据本身未必马上带来放行 | 找有权限者、护送和留存事实；没有凭空出现的官阶与军队 |
| 唐照雪、段明棠、石长庚的门内事务 | 授徒、公平比试、拳馆收入与借兵发生关联 | 有人守住一段通路或接替职责；不能用一个人的同意代表整个门派 |
| 闻疏桐、乔行舟、霍逐尘的职业能力 | 道路、船只、器具在地区事件中经受实用检验 | 增加勘路、修造与突破的方法；缺席时主线仍有不同成本的公开办法 |
| 陆衡与戚铮的工作和责任 | 护送承诺、撤退与会众处境需要实际判断 | 可协同护路或断后，职责交接和有限兵力必须有来源 |
| 晏小楼、柳含烟、秦绯鸢的生活与事业 | 戏班、师承、演出与个人选择受到局势影响 | 留下独特的人物结果、帮助与拒绝；不能统一改成密探或宣传工具 |
| 阮青雀与裴知古的成长 | 修锁查验和亲历见闻成为可靠本领 | 能提供独特解法与可信记录；不是偷一纸密令或送一本书即可解决一切 |
| 殷红缨与归云谷家人 | 师门旧交和自己的选择进入游历 | 大人有自己承担的事，主角完成另一处任务；不以师父必死强制成长 |

## 主线可达与支线差别

所有必需真相都在公共推进中给出。没有某位同伴时，主线使用公开信息、有限NPC协助或另一种战斗/职业方式；该方法只替代任务功能，不替本人发言、签约或完成个人成长。

支线优势应写成具体结果，如救下某人、保留一条通路、减少一场交战、取得一种愿意承担的援助。不得只用“好感+5”代替叙事回收，也不声称未完成支线就必然让无提示的灾难发生。

人物在队、异地、未结识、暂拒任务和已完成交接分别有承接。公共确认前给出受影响任务清单；可继续、换地点或延期的内容不清空。只有发生明确不可逆事件且预告后果，才改变相关人物线。

## 内容落地前的核对

逐场核对参与者、知识来源、相遇地点、阶段、本人意愿与权限；核对同一物件的归属和数量；核对选择是否改变任务或地方结果；培养内容另外检查日历、旅行与体力。地区合同检查不代替逐句对白和游戏演出验收。
