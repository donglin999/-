# 游历与终局推进合同

版本 STORY-2026-10-16.1。当前设计方案，未接入正式游戏。[四部分总纲](story-framework-review.md) · [城市与玩法](story-rework-20261016/regions-gameplay.md) · [事件合同](story-rework-20261016/regions.json)

## 培养结束后的改变

第二部分三年培养完成叶家真相、阶段考验和出行交接。第三部分自行选择目的地、同行者和事务，保留修习、采买、切磋、职业委托及回访。培养体力不直接套到城市；大地图跑动和普通活动不计剧情时间，主线时间点推进，特殊夜景有明确事件来源。

功法不必满级、同伴不必招齐，出师考验有指导和替代实务，不再花一年重刷日历。高阶师承与队伍配合仍在游历发展，具体成长继续引用既有武学和数值合同。

## 推进节点

| 节点 | 必需条件 | 玩家得知什么 | 世界状态 |
| --- | --- | --- | --- |
| TRV-START | 三年结束、叶家真相收束、据点交接完成 | 可选地区、当前身份及同行安排 | 开放三个地区链，允许自由探访 |
| TRV-NORTH-DONE | 北线地区链完成一种结案方式 | 守备需要、征发后果与实际命令边界 | 北线记录结局、救援和军需状态 |
| TRV-RIVER-DONE | 水路地区链完成一种结案方式 | 玄烛统合与归烬自主的真实代价 | 渡口控制、会众交接与通行改变 |
| TRV-SECT-DONE | 山门地区链完成一种结案方式 | 联防的利益、强制与小派选择 | 支院和联防关系发生变化 |
| TRV-COMMON | 任意两条地区结案；完成缺失第三方的公开会面与可核实见闻 | 三方目标、边界和至少一次真实后果 | 不代替未完成地区结案，不发其独占奖励 |
| TRV-CLOSE | 任意两条地区结案及公共节点完成 | 局势升级原因、可用行动与未完成事项 | 读取各地成果，提前显示可能影响的地点 |
| END-CHOICE | 地区阶段结案，查看各条道路后选择筹备方向 | 自己保护什么、付出什么、不能同时承诺什么 | 进入终局筹备，尚可按明示条件改选 |
| END-COURT-SUPPLY／ALTROUTE／REVIEW | 官府筹备时实际交军需、验证替代路，再由严奉钧当面复核 | 改令仅限其授权；拒绝后可接受原额或在最终承诺前转独立护人 | 保留此前任务成果与责任，不等待神秘上级自动解决 |
| END-COMMIT | 两项公开筹备完成；官府另完成复核；主动确认最终后果 | 当前路线、被影响任务与同伴安排 | 正式开始行动，不再用菜单无代价改写身份 |
| END-ACT-ALLIANCE／GUIJIN／COURT／FREE | 对应准备与实际行动完成 | 已完成目标、失败后果和剩余责任 | 由所选道路结算，不重演全部其他路线 |
| END-RESOLVE | 所选道路关键结果写入 | 城镇、师门、同伴和普通人的去向 | 后日谈按事实组合，未解决的问题保留说明 |

事件ID的逐项前置、地图与结果以地区合同为准。本页表达阶段资格，不把人物任务、恋爱或单项技能满级设为公共推进门槛。

## 支线和紧急任务

一个地区先给到访理由和下一步，再开放人物、武学与职业内容；启动具体救人或战斗后，先解决当前危机，再回到自由探索。不要一边声称立刻处刑，一边允许无限跨城游玩。

公共邀请不会自动关闭世界。局部通路、NPC驻点、待交付任务的变化在确认行动前列出；逐项区分可继续、换地点、由本人通信承接、暂缓或确实关闭。普通阵营差异不强行清空已入队名册；同伴拒绝某项行动时安排其所在地与返队条件。

第四部分的在场要求先检查角色状态。主线NPC可提供公开信息或有限帮助，但不能冒充缺席同伴发言、替本人完成职业决定或代签感情承诺。所有必需真相至少有公开查验或主线见证的通路；各个人物提供独特方法和结果，而非唯一钥匙。

## 原有路线如何承接

归云谷培养不等于终生只走正道盟行动。四条后期道路区分当前组织身份、权限、临时承诺与私人关系；正式换籍、任官或长期外派须写具体交接。当前游戏另外两种三年培养入口仍未开放，本合同不补发其日历和课程。

叶蘅学医或针攻的选择决定自己的安排；她可以完成家事后继续事业，不随萧白的站队自动转籍、停学或移交遗产。

## 接入验收

必须验证三组任意两地区组合分别可达后期、四条终局各有未招齐同伴的可达路径、关键选择确实改变地图结果、未做第三地区保留可玩或明示改写、重入不重复结算。当前离线合同检查只证明结构，不代替存档迁移、战斗难度或实机验收。
