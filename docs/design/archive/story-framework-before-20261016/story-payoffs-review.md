## 群像回收优先级

先完成各派自己的故事，再安排它与终局的关系。剑派的传承争议可让弟子反对统一收谱，拳门的生计困难可让同门支持共同保障，行者可以救人但不站队，差役可能为了秩序与好友争执。这些经历改变立场，不必都发现谢承岳罪证。

公共初识保证多数代表见过面；三年闲逛决定了解、信任与具体承诺；最终再会展现独立选择。支持主角不是所有人物成长的唯一正确答案。归烬堂与朝廷路线须有自己的事业和结局，不能只作为正派线信息补丁。

## 三类回收

1. **事实线索**：医案、证言、药物流向等，帮助认清责任与证明当下伤害。
2. **行动条件**：可信的人、运输路线、诊所和安身处，帮助最后真的救出人。
3. **情感与价值**：先经历受助、争执和互相承担，再让玩家理解最终选择的代价。

不是所有支线都发现反派徽记。有的只让一个普通人得到完整故事，有的让玩家学会一种判断；小事也有独立价值。

## 信息释放的阶梯

- 第二至四章 / 第一年：安身、襄阳初识、确认三方被挑拨；各派人物先有自己的日常。
- 第五至六章 / 第二年：父母旧事与各派处境逐渐清楚，部分村祸责任落定；不提前结束身世。
- 第七至八章 / 第三年：查清父母经历、结局与直接加害责任，叶蘅选择传承方向，完成下山交接。
- 第九至十四章 / 游历：拜访师门、完成区域主线、延续人物篇。通路争端产生新矛盾，不把叶家真相重新设成谜。
- 第十五至十七章 / 中后期：公共治理方案出现争议，具体越权坐实，玩家明确立场和行动目标。
- 第十八至二十章 / 后期：回收各方经历及行动承诺，处理公共危机与各路线结果；最终地点可重返襄阳。

养成得到的是初步信任，游历让承诺经受考验，中后期才决定愿为谁承担多少责任。最终对手与共济盟约依然是候选，非既定真相。

## 支线自由与不卡关

- 核心真相与主线通路放在必达章节；支线补佐证、扩大可救援范围、改善条件和个人结局。
- 一条路径至少有主线保底及两类可选强化，如水路商队、地方差役、中立护送；不要求全部完成。
- 未完成商路线，救援可走更费时的陆路；未结交谷中医者，可用苏芷和地方诊所，但需要更小规模分批安置。具体损失须预告，不事后把玩家不知情的遗漏判成恶行。
- 偷盗、劝说、打探提供不同解法，关键真相不能只靠某个高等级能力；有付出时间、公开问询、保护证人等替代途径。
- 恋爱、友情和叶蘅职业分支不改变知晓父母真相的资格。
- 每章关键后果记录“谁受助、谁作证、谁愿承担什么”，不用一个全局善恶值替代具体关系。

## 制作约束

现阶段只评审整体骨架，不据此开发二十章或扩展新地图。方案通过后优先做“章节问题 → 必达证据 → 支线回收 → 月份占期”的逐章表，再写对白。襄阳仍是当前体验章节的开发范围。
