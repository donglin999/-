## 全作结构：序章 + 四篇二十章 + 尾声

| 篇章 | 章节 | 游戏阶段与预计内容比重 | 主要体验 |
| --- | --- | --- | --- |
| 入世养成篇 | 第一至八章，含培养前开场及三年培养 | 前期至前中期，约 30% | 初识江湖、培养能力、结交人物、查清叶家旧事 |
| 江湖游历篇 | 第九至十四章，下山以后 | 前中期至中期，约 35% | 自主行程、拜访师门、地区事件、伙伴故事、独立解决问题 |
| 风云合流篇 | 第十五至十七章 | 中后期，约 20% | 区域冲突相互影响，选立场、组建关系、明确主要对手 |
| 江湖抉择篇 | 第十八至二十章 | 后期，约 15% | 分线应对公共危机、完成行动、决定人物及势力未来 |

比重指预期可游玩内容，章数不等于时长；培养与游历章可承载大量自由事件。具体小时数、地图规模和制作预算以后单独估算。全作时间不再被三年框住，下山后采用事件进度推进，是否跨年及最终历史年份待排期；不自动引入襄阳围城。

## 第一篇：入世养成（第一至八章）

序章《山村来客》保留萧白被叶蘅救助、村中借宿。

| 章 | 时间与主题 | 主要推进 |
| --- | --- | --- |
| 一《风起栖河》 | 培养前，村祸与去向 | 保留三方争物、失控火灾、撤离与去向选择；灾后对传讯起疑 |
| 二《初栖江湖》 | 年一春，安身学艺 | 熟悉据点与日常，帮助乡邻，开始基础训练；收到襄阳邀请 |
| 三《襄阳初会》 | 年一夏，公共初识 | 聚会认识多数核心人物；嵌入青蚨散救治；三方核验被挑拨，责任仍各自承担 |
| 四《少年各有志》 | 年一秋冬，朋友与方向 | 各派人物闲逛与叶蘅倾向事件展开；第一年结束时明确选择次年学医或留谷针攻，父母旧事出现不同说法 |
| 五《故人有旧事》 | 年二上半年，接近过去 | 短途差事与旧识互证，知道父母参与过什么、留下何种争议；不在此提前解完身世 |
| 六《山门内外》 | 年二下半年，成长遇到现实 | 各派传承、生计与职责显露；身世调查取得实质进展，落实部分村祸责任 |
| 七《旧路渐明》 | 年三春至秋，具备独立能力 | 几次有明确来回的历练补齐关键证人与物证；朋友承担初次责任，人物线仍未全数收束 |
| 八《一纸家书》 | 年三末，身世篇高潮与下山 | 交代父母身份、经历、结局、遗产用途及直接加害责任；叶蘅决定如何面对遗产，萧白完成独立行事的阶段考验 |

第八章要真正回答“叶蘅是谁、父母为什么遭难”，交代直接责任人的处置或明确去向，不能靠宣布还有更大身世秘密拖延。谢承岳与旧医武计划的关联仍为候选，不将其伪装成已确认旧稿。

下山是生活方式改变：山居线告别固定培养安排，归烬堂线未来获得独立外派资格，巡江司线未来获得巡历办差身份；不是所有路线叛门或辞官。叶蘅学医线以完成阶段学习、获准出谷行医衔接，同行线继续同行，均保留回访导师和据点的机会。

## 第二篇：江湖游历（第九至十四章）

新的阶段矛盾建议为“荆襄通路之争”：护送、商路、地方规费与救助物资受阻，各方提出互不相容的解决办法。这是与朋友、地方百姓有关的现实事件，不继续把找叶家遗物当唯一动力。具体组织及地点待确认。

| 章 | 主线牵引 | 给自由游玩的空间 |
| --- | --- | --- |
| 九《初行万里》 | 接下一件可以自行决定行程的护送、交涉或公差，建立通路问题 | 低压力旅程，拜访旧友、收队友、找武学与生活机会；下山不立即倒计时救天下 |
| 十《山门来客》 | 调查一段被封阻的路线，进入朋友所在师门 | 剑派传承、拳门生计等独立篇章；第一次看见朋友在家中的另一面 |
| 十一《渡口风波》 | 商队损失、地方征收与帮会争夺交织，完成一个地区事件 | 镖行、江湖与官府提供不同解法；其他地区仍可回访 |
| 十二《旧友新途》 | 处理另一处路线节点，发现所谓合作也有真实受益者 | 队友个人篇、医者游历、门派继任或内部争权；玩家可先处理更关心的人 |
| 十三《一方公道》 | 在区域争端中独立作出有代价的判断 | 经营人脉、技艺与名声；已经完成的支线影响可选方法，没做仍能推进 |
| 十四《路通人未同》 | 地区问题获得阶段解决，几处问题显出制度与利益上的关联 | 收束本轮旅程并留休整期；旧友有自己的意见，未进入终局动员 |

第十至十三章是地区模块的编辑编号，不要求依编号串行游玩。第九章开放第一批地区，完成任一地区主线后开放下一批；完成指定公共锚点与任意两条地区主线可进入第十四章。具体必达锚点与可替代路线见游历页。未选地区保留后续游玩，不能变成完成全部支线的隐形要求。

## 第三篇：风云合流（第十五至十七章）

| 章 | 主线变化 | 节奏边界 |
| --- | --- | --- |
| 十五《共济之议》 | 各方提出共同治理方案；玩家已亲历地方问题，理解支持者与反对者 | 只有完成游历阶段锚点并主动参加议事才触发；仍是讨论，不自动全地图敌对 |
| 十六《同席异心》 | 在一项联合行动中，征调、退出权与问责问题产生具体伤害；主要对手行为坐实 | 人物关系遇到立场冲突；留救援、调查和谈判的不同处理方式 |
| 十七《各有所守》 | 确定本路线目标，协商同盟、代价与行动方案 | 明确主要冲突并开放准备阶段；主线有保底资源，不强制凑齐所有好友 |

谢承岳、共济盟约继续作为候选；可承接叶家旧案，但不能成为所有门派内部矛盾的唯一来源。新矛盾依靠游历中的真实利益冲突成长，不在下山当天由前辈直接宣布最终黑手。

## 第四篇：江湖抉择（第十八至二十章）

| 章 | 主线内容 | 人物回收 |
| --- | --- | --- |
| 十八《风起诸途》 | 多方开始行动，玩家通过所选立场处理通路、证人、组织内部或官面压力 | 不同路线拥有不同权限、责任和任务，不只更换对话称谓 |
| 十九《再会襄阳》 | 回到初识之城，交涉、举证、会盟与分头行动，形成最终决断 | 当年弟子可能已代表师门；旧友可支持、中立或敌对，不能以好感强制一致 |
| 二十《此后江湖》 | 完成与目标一致的关键行动和对决，交代新的利益安排与责任 | 战斗解决具体阻碍，安置、传承、组织变化也需交代；不是打倒一人自动解决所有问题 |

尾声《各自归处》交代个人生活、叶蘅道路、师友与村民、各派未来。只有第十九章最终行动前设置明确的不可逆提示；第十八章局部变化也须预告受影响任务。后期未完人物线有可继续、改写或关闭三种处理，不默认全部删除。

## 全作持续的设计约束

- 襄阳初识 → 三年闲逛建立关系 → 下山拜访深入师门 → 中后期承担立场 → 终局与后日谈回收。主要人物线不得在第三年全部结清。
- 个人友情、阵营声誉和具体承诺分别记录；三方早期识破挑拨，不抹除个人责任与组织分歧。
- 叶蘅身世篇有完整结论，下山后继续有针攻/医师事业、关系与主动选择，不降格成提供加成的队友。
- 支线可铺垫事实、帮助行动、影响立场，也可只讲一个完整的小故事；不要求所有地方坏事都由同一人策划。
- 三年培养使用月份与体力；游历阶段以地点与事件进度为主。后期触发不用人物等级、总好感或无提示计时器。

## 文档与实现边界

本版替代“全作三年结束、序章加十章”的范围。正式主线与事件表同步全作边界；逐月事件和章号占期以后细化。现行山居预留为六个地图月、九个短篇时段、141个自由时段，仅是培养期预算；新增群像与招募占用须重算，不覆盖下山游历。当前依旧只开发襄阳体验片段，不据此扩地图或开放另两路线。
