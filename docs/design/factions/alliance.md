# 正道盟

状态：现行　最后核对：2026-10-19

当前组织设计；全流程故事见[从栖河到白石](../fullflow-story-20261016/story.md)，主要后期人物见[本轮人物](../fullflow-story-20261016/characters.md)。尚未接入的旧联防借兵主干由新稿取代。

正道盟是跨门派联盟，调停、互助与公共名望来自各成员，不是同一师门，也没有一个能支配所有人的全权盟主。事务总管蒋闻礼、办事人赵闻达保持原职责；赵不可招募。徐令仪是可招募的调停执事，她在栖河的签批与救援责任、汉皋后续核查均保留，正式同行仍要完成本人篇。

培养期谢承岳真实资助过困难门派，并在公开比试见过年轻人。游历期他把阿七的冒名与几场买来的胜仗包装成少年侠名。白石时他借姚安真实押送过失逼阿七立即行刑，一部分弟子拒绝；不是所有正道成员都支持他。

玩家可以提前制止假赛，陶照海的武馆便不会被强写成倒闭；N-01针对具体私刑与强留行动，不是打败谢便获得全盟。裴嵩的旧案和村祸责任在培养末结清，不把谢无证添成旧案共谋。
