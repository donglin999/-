# 照川剑派

状态：现行　最后核对：2026-10-19（原记：首版设计方案；新增姓名、职务和武学定位待细化，未实装。[门派目录](../factions.md) · [同伴名册](../companions.md)）

- **性质与生活**：剑派（新增）。讲求剑式清楚、胜负有据，靠授艺与护送维系声望；年轻弟子常把名次等同价值。
- **活动范围**：荆襄周边山门，距离与旅行时间另定。
- **武学定位**：单体破势、反击、剑势连段。
- **内部矛盾**：传承名额有限，循规培养与因材施教争执不断。

## 核心人员

- 掌门顾行简：重考校但不偏私；教习梁照庭：偏爱稳妥剑路，忽略另类长处。
- **可招募女性：唐照雪**。个人篇及同行理由见[女性人物目录](../companion-women.md)。
- **常驻／剧情人物：裴砚秋（不可招募）**。承担同门竞争、约斗与传承考校中的对手，可有任务协作，不进入可控体验队伍。本组织只提供女性招募角色。
- 普通人员按教习／办事、后勤、年轻成员与地方联系人配置；先用职能占位，不为每名背景 NPC 创建完整同伴素材。

## 初识与后续行动

**初见**（地点与剧情待重新设计；下句为汉皋旧稿，只作记录）：裴砚秋输了嘴硬；唐照雪替双方指出计分疏漏，也承认对手出剑漂亮。

**发展**：培养期约斗、各有长短的考校与外出授艺。2026-10-16 补充设计：游历 `TRV-SECT` 以鹿门—照川支院的联防轮值为具体冲突；顾行简同意有限支援，却必须回应未到期学生被延长留用；梁照庭发现被他推荐的弟子不愿再次出战。唐照雪需要保护不同意出战者并履行自己答应的护送，裴砚秋可自愿留下，但没有权替别的同门同意。校场比试决定交接方式，后续护送、守点与人员交接才能落实结果。终局回收弟子留下/撤出、授艺能否继续及联防实际援手，不把全派传承简化为交一本秘笈。

**边界**：裴砚秋与裴嵩无亲属关系，不凭同姓暗示支线；不是每个弟子都争掌门。

招募同伴不等于加入其组织；弟子获准游历、独立承接差事或协商离开，均须在个人篇落实。各组保留女性招募位；男同伴仅按总名册配置，核心前辈不默认可招募。

## 与主角师门的关系

2026-10-03 调整：照川保留外部剑派定位，不再作为萧白本门；周砚不属照川，唐照雪与裴砚秋也不是萧白同门。主角本门采用[归云谷方案](../protagonist-sect.md)，双方可通过前辈旧交、汉皋试艺与后续游历往来。

## 当前衣装辨识

修身长剑衣与利落分摆，线条纵向、衣摆可随剑步展开；利落交领、收臂袖与护腕；规整长靴和固定剑带。剑鞘、整齐剑穗、细剑带；不借医具识别。练习服收摆；外出剑衣长分摆；正式服加规整衣缘，不增加盔甲。完整要求见[衣装规范](../faction-attire.md)。
