# 地方官署与守备

状态：现行　最后核对：2026-10-19

2026-10-16全流程设计。当前故事见[主线](../fullflow-story-20261016/story.md)，个人设定见[本轮人物](../fullflow-story-20261016/characters.md)。原军需与征船主干退出本次执行范围，保留为前轮设计记录。

严奉钧改为追查旧劫饷案的地方承办官员，在P3-09白石舟棚出现。案子确有真凶，玩家实际看到被抓者和相关见闻；严为了不漏任何线索而扩大扣押，连普通船工与家属都不愿先放。P4-02与N-03处理的是这些具体行动，严本人不是武功Boss，交锋对象是已出场的执捕小队。

各个群体分别登记：已经获救并交接的人、庄扣住的报复对象、严扣住的证人船工。不能一个角色同时在两处押人院，也不能打退一队就取消全国通缉。主角动武的地方后果在行动前明确，结局按本人选择和实际救出的人结算。

梁定川保留为襄樊守备的未启用地区候选（襄阳为以后开放的新城市，剧情未设计），不参与白石主干，也不替严忽然出兵解围。巡江司的程铎与沈雁回仍各按地方巡检、民间委办身份行动；沈请求掌案者放人可以被拒绝，不能用玩家友情直接命令严或调兵。

严以文职衣装、案匣和随行公差出现；梁若以后启用再按守备战具核验。真实宋代官衔与服制另依场景考据，不临时创造秘密全权机构。新人物与相关地图都尚未正式接入。
