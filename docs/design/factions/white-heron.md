# 白鹇谷

状态：现行　最后核对：2026-10-19（原记：首版设计方案；新增姓名、职务和武学定位待细化，未实装。[门派目录](../factions.md) · [同伴名册](../companions.md)）

- **性质与生活**：医门。诊治、辨药与针术；重病例、复诊和授业责任，不能只以疗效邀功。
- **活动范围**：谷中诊所与外出行医网络，准确方位另定。
- **武学定位**：针药、恢复、解毒、持续增益。
- **内部矛盾**：闭门保秘能保质量，却可能让外地患者无医可求；推广又有误用风险。

## 核心人员

- 谷主何素问：谨慎开放教学；医案执事孟知微：负责考核与复诊，不以献方换入门。
- **可招募女性：苏芷**。个人篇及同行理由见[女性人物目录](../companion-women.md)。
- **常驻／剧情人物：许知衡（不可招募）**。承担药材核验、药房轮值与共同会诊联系人，可有任务协作，不进入可控体验队伍。本组织只提供女性招募角色。
- 普通人员按教习／办事、后勤、年轻成员与地方联系人配置；先用职能占位，不为每名背景 NPC 创建完整同伴素材。

## 初识与后续行动

**初见**（地点与剧情待重新设计；下句为汉皋旧稿，只作记录）：苏芷在街边救治，许知衡一边分药一边认真核对欠账。

**发展**：培养期共诊与求学；游历期追踪长期病人及教学。2026-10-16 补充设计：何素问必须决定在征运冲突中开放几处外诊而不把谷内病人扔下，孟知微为轮值和复诊负责，许知衡实际承接药房而不只提供证言。苏芷与叶蘅可同行救人，也可对使用范围持不同意见；两人不是同一个全队治疗职能的互斥皮肤。终局根据此前供给与轮值保住具体一处救治点，不能医术检定成功就治好所有战争损伤，不能把自愿诊疗变成三方强索秘方的正当理由。

**边界**：苏芷引荐不等于入门；叶蘅入谷不顶替苏芷的招募位置，也不是名额互斥。

招募同伴不等于加入其组织；弟子获准游历、独立承接差事或协商离开，均须在个人篇落实。各组保留女性招募位；男同伴仅按总名册配置，核心前辈不默认可招募。

## 当前衣装辨识

月白为主的轻短外医袍，内层药青；分层针药袋形成医者轮廓；药青双细缘、窄袖可束腕；外袍开摆方便蹲身诊疗。分格针囊、布带、小药包；发簪朴素。学徒单缘和基础药袋；医师双缘与分格针囊；已明确教习可加第三细缘。依职务，不依年龄自动升级。完整要求见[衣装规范](../faction-attire.md)。
