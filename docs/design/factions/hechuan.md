# 合川拳门

状态：现行　最后核对：2026-10-19（原记：首版设计方案；新增姓名、职务和武学定位待细化，未实装。[门派目录](../factions.md) · [同伴名册](../companions.md)）

- **性质与生活**：拳门（新增）。讲究站得住、护得住，开馆教拳，也承接护运和工坊护卫。
- **活动范围**：河运城镇的拳馆与练场，不占据全部码头。
- **武学定位**：近身破防、护卫、架势与硬直控制。
- **内部矛盾**：师门收入依赖地方大户，护住自家人可能纵容对外欺压。

## 核心人员

- 门主杜敬山：善教拳却怕断生计；账房兼师叔罗绣娘：知道账目，也有难舍的人情。
- **可招募女性：段明棠**。个人篇及同行理由见[女性人物目录](../companion-women.md)。
- **可招募男性：石长庚**。短篇条件见[男性招募表](../companion-men.md)。
- 普通人员按教习／办事、后勤、年轻成员与地方联系人配置；先用职能占位，不为每名背景 NPC 创建完整同伴素材。

## 初识与后续行动

**初见**（地点与剧情待重新设计；下句为汉皋旧稿，只作记录）：段明棠替受伤弟子结工钱，石长庚先扛货后与收规费者争执。

**发展**：培养期帮工与切磋。2026-10-16 补充设计：第三部分 `TRV-RIVER` 从合川被扣护运者进入芦花渡—烬渡线，杜敬山希望保住承运收入，罗绣娘坚持工钱和伤者抚恤先落实；两人的争论让段明棠、石长庚有自己的同门关系戏。玩家要实际护人回馆、修复一次护运交接或协助守撤离口，不以查一份账结束。拳门支持任一方都须写轮值、工钱及救伤安排，不提供无限免费弟子；终局已有护运承诺决定能支援哪处通道。

**边界**：保留粗粝生活与同门温情；不把穷困当作欺压他人的免责理由。

招募同伴不等于加入其组织；弟子获准游历、独立承接差事或协商离开，均须在个人篇落实。各组保留女性招募位；男同伴仅按总名册配置，核心前辈不默认可招募。

## 当前衣装辨识

赭红短褂、分裤或宽松练功长裤，露出清楚发力肩线；短袖或可卷袖、层叠布绑手、结实窄腰带。绑手、绳套、补缝护具；不使用飘逸长袖。教习可长外衫但保留绑手；训练减层；接护运加工作护具。完整要求见[衣装规范](../faction-attire.md)。
