# 巡江司

> 当前全流程出场按[新故事](../fullflow-story-20261016/story.md)与[人物](../fullflow-story-20261016/characters.md)；下文旧TRV/END任务只保留为独立地区备选，不再作为必达主干。组织身份与既有人物责任继续有效。

状态：现行　最后核对：2026-10-19（原记：2026-10-16 按用户授权完成本轮主线整改设计，未实装。[门派目录](../factions.md) · [同伴名册](../companions.md) · [军需与守备](court.md) · [三方行动](../../archive/design/story-rework-20261016/faction-cast.md)）

- **性质与生活**：地方官府组织。维护水陆秩序、救灾与查案；权限、手续和上级命令都产生现实约束。
- **活动范围**：汉皋地方巡检衙署与沿线巡查站，不代表整个朝廷；跨地办案和襄樊军需行动须另有明确交接与授权。
- **武学定位**：长兵、控场、护送与擒拿。
- **内部矛盾**：依法履职、地方实际与个人仕途冲突，执法者也应留下可追责的记录。

## 核心人员

- 巡检程铎：现有角色，负责指派与监督；典吏周敬实：熟悉文书，倾向保全衙门。
- **可招募女性：沈雁回**。个人篇及同行理由见[女性人物目录](../companion-women.md)。
- **常驻／剧情人物：高守诚（不可招募）**。承担巡查协作、案件交接与地方差役，可有任务协作，不进入可控体验队伍。本组织只提供女性招募角色。
- 普通人员按教习／办事、后勤、年轻成员与地方联系人配置；先用职能占位，不为每名背景 NPC 创建完整同伴素材。

## 四部分中的行动

**栖河初见**：程铎委沈雁回主办药物查验，程本人留署监督。沈过信转附记录而限箱，救灾时停验，灾后对证、署名核错回报。[三方修订](../opening-three-representatives.md)。

**培养·再会／其他初识**（地点与剧情待重新设计；原写汉皋再会）：沈接续转件回查，药车缺手续时说明放行条件；高守诚帮车夫抬轮。程复核沈与本署的责任，周敬实保存原件，不能把栖河错误简单归为不知名下属抄错。延寿误传已纠正；后来的军需需求另有来源。

**游历·真实命令下救人**：沈受委办核验征船对象与扣人条件，在 `TRV-NORTH-*` 见到军需确实短缺、征令也确实存在。她需让实际补给与替代运路可验证，找严奉钧当面复核授权内征额，并争取梁定川安排本营有限接应；不能揭出一张假信就让各方全部散去。高护送被影响船户，周保住原件并签清自己的经手，程提出本署可承担的替代安排并留存转呈，不在本轮召来神秘上级撤全令。

**游历末与终局**：封渡限行后程可以暂停自己辖下的争议核验，但无法撤销全部整饬；沈可履行有限委办、争取延缓、或选择违规救人并承担撤销委办的后果。严复核拒绝减额时，玩家可按原额度护运，或在 `END-COMMIT` 前公开拒命转独立护人；既有事实保留，过线后不得重选抹去代价。若接收后期官府委任，主角与沈的身份分别交代，同行不自动给沈授官。

**边界**：沈雁回暂设受委办的民间查验人，非正式女官；长期同行需明确差事许可，不能凭空调兵。

## 状态与交接

记录 `本次委办是否有效／核验对象与期限／被扣人员去向／改令是否到达／违令行为与责任`，不把“朝廷好感”当任意通行证。军需督办与守备营属于独立组织登记，不把严、梁挂到巡江司中。战后放行、退还船只和撤销资格在地图与人物对话上可见；未见过沈的玩家仍可由程/高取得基本核验与救人路径。

招募同伴不等于加入其组织；弟子获准游历、独立承接差事或协商离开，均须在个人篇落实。各组保留女性招募位；男同伴仅按总名册配置，核心前辈不默认可招募。
