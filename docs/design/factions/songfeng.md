# 松风观

状态：现行　最后核对：2026-10-19（原记：首版设计方案；新增姓名、职务和武学定位待细化，未实装。[门派目录](../factions.md) · [同伴名册](../companions.md)）

- **性质与生活**：道门武学支系（新增）。修习剑与步法，重观察和自律，门人可以游方；生活靠田产、抄书与香客供养。
- **活动范围**：山观与沿途客舍，具体地理另定。
- **武学定位**：步法、卸力、阵位牵制与剑术。
- **内部矛盾**：不卷入争端的门规与亲眼见到的伤害发生矛盾。

## 核心人员

- 观主静笃：担心弟子被势力利用；监院明谦：负责日常与出行，愿听年轻人陈述。
- **可招募女性：闻疏桐**。个人篇及同行理由见[女性人物目录](../companion-women.md)。
- **常驻／剧情人物：莫松年（不可招募）**。承担行脚见闻、送物委托与山观生活联系人，可有任务协作，不进入可控体验队伍。本组织只提供女性招募角色。
- 普通人员按教习／办事、后勤、年轻成员与地方联系人配置；先用职能占位，不为每名背景 NPC 创建完整同伴素材。

## 初识与后续行动

**初见**（地点与剧情待重新设计；下句为汉皋旧稿，只作记录）：闻疏桐记路时绕开被封的小桥，又回头问渡船能否载老人；莫松年摆棋却老惦记饭点。2026-10-05新增可选前置：他可于二月来归云谷交路况记录；参加则此处为重逢，未参加仍初识，见[来访设计](../../archive/design/pre-xiangyang-visitors.md)。

**发展**：培养期行脚与观星记候；游历期修订旧地图、处理被遗漏的村路。2026-10-16 补充设计：鹿门外围封路后，静笃反对把本观变成驻兵处，明谦却得为路过的民户腾住处；闻疏桐与莫松年实际走通一段旧路并安排接应，地图不是瞬间开出无限新通道。终局本观可以提供一处有限庇护而不加入某方讨伐，但须承担供给、伤者与可能的追索；中立是行动和代价，不是没有剧情。

**边界**：闻疏桐为观中习艺的俗家弟子，不用出家戒律制造强制还俗或恋爱门槛。

招募同伴不等于加入其组织；弟子获准游历、独立承接差事或协商离开，均须在个人篇落实。各组保留女性招募位；男同伴仅按总名册配置，核心前辈不默认可招募。

## 当前衣装辨识
