# 玄烛会·归烬堂

> 当前全流程出场按[新故事](../fullflow-story-20261016/story.md)与[人物](../fullflow-story-20261016/characters.md)；下文旧TRV/END任务只保留为独立地区备选，不再作为必达主干。组织身份与既有人物责任继续有效。

状态：现行　最后核对：2026-10-19（原记：2026-10-16 按用户授权完成本轮主线整改设计，未实装。[门派目录](../factions.md) · [同伴名册](../companions.md) · [上层玄烛会](xuanzhuhui.md) · [三方行动](../../archive/design/story-rework-20261016/faction-cast.md)）

- **性质与生活**：会中分堂。收拢无处立足的江湖人，以货路、护卫与灰色交易谋生；重兑现承诺，也存在强者压弱者。
- **活动范围**：烬渡为本堂主要驻点，通过芦花渡、合川护运谋生；汉皋设交涉与善后接洽。玄烛会为上层组织，不能将本堂等同全会。
- **武学定位**：刀、短兵、烬砂与压制，强攻有资源代价；岑霜按已定独门软鞭，不因堂众主用刀而改兵器。
- **内部矛盾**：忠诚、分配与问责冲突；“护自己人”是否包括包庇抢夺。

## 核心人员

- 堂主韩烬川：重生存与控制；刑务管事邢守夜：维护规矩，却倾向按权势执行。
- 上层统合使庄照尘由[玄烛会总堂](xuanzhuhui.md)负责；本堂可受其有限统合命令，但他不占本堂堂主之位，也不归本堂登记。
- **可招募女性：岑霜**。个人篇及同行理由见[女性人物目录](../companion-women.md)。
- **可招募男性：戚铮**。短篇条件见[男性招募表](../companion-men.md)。
- 普通人员按教习／办事、后勤、年轻成员与地方联系人配置；先用职能占位，不为每名背景 NPC 创建完整同伴素材。

## 四部分中的行动

**栖河初见**：岑霜以本次索匣负责人到场，被暗送正道盟的消息诱导，放任乌魁看路；救灾后对证，撤人并签赔偿。[三方修订](../opening-three-representatives.md)。

**培养·再会／其他初识**（地点与剧情待重新设计；原写汉皋再会）：岑交补偿清单、核传讯路径，戚铮盯着实际钱粮和伤亡补偿。韩要从真实收入履行赔付，邢先照顾有后台的人，岑须承认并纠正自己的纵容，不能只换一份漂亮名单。

**游历·归烬夺渡**：总堂先提供护航与抚恤，韩接受利益；随后庄要求抽人交渡。`TRV-RIVER-01` 合川护运者遭扣，`-02` 烬渡点名露出强征，`-03` 救出被扣者、保护撤离船或支持有期限统合。邢直接看守扣人仓；韩必须就交人命令表态。岑拒绝扣普通船户作退路，戚要求分账和抚恤兑现，不能把正常护运临时改为送人抵债。

**游历末与终局**：根据渡口控制、失地和人员去向决定守堂、参与反击或接受有限招安；韩可接受限制、失去堂众支持或强行集中控制。支持本堂也要处理旧债与赔偿，选择扩张有具体受害者；不将所有本堂成员写成无辜受害人。

**边界**：岑霜保留开篇中层身份和管束责任；乌魁不是本轮可招募人，不能靠送礼抹掉村祸责任。

## 本堂状态与玩法结果

按 `赔偿履约／抽调是否自愿／本堂人手／渡头控制／招安期限／外部受害者` 记录具体结果。渡头守卫、可停泊船只、扣人仓、可用补给和堂众住处会变化。游历战斗不以击杀高阶庄照尘为必需目标，救人撤出同样能推进；晚来地区按明示主线节点的当前状态处理，不能因为练功多做两次就自动处决新人。

招募同伴不等于加入其组织；弟子获准游历、独立承接差事或协商离开，均须在个人篇落实。各组保留女性招募位；男同伴仅按总名册配置，核心前辈不默认可招募。

## 当前衣装辨识

墨紫暗红叠衣、非对称披袖或短兵行装，精致而有张力；斜向衣缘、铜扣分段束腰，袖长依交涉／实务变化。细铜链、账签或短兵鞘，依角色身份。岑霜确认稿为交涉衣基准；堂众简化铜件和纹样，不能人人穿堂主同级华服。完整要求见[衣装规范](../faction-attire.md)。
