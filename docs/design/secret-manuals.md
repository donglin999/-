# 秘籍：拿到书与学会分开

状态：现行　最后核对：2026-10-19（原记：**已确认并接入运行时，2026-10-08**。）

用户原话：“‘拿到书’和‘学会’分开，中间隔着属性门槛，就这样就行。拿到书，然后如果满足学习要求的话点击就学会（书并不会消失），但是只有一重这样。”

本页与[门派功法传承](martial-lineage.md) §3.2～3.5 衔接，不改其中已确认的规则：
- 功法不与章节绑定。
- 学习要同时满足前置重数和属性门槛。
- 七重可以学下一门。
- 剧情提前获得只是一种情况说明，不是通用机制。
- 绝学不设互斥。

## 1. 规则

1. **秘籍是道具**：每门功法一本。外功为 `mj_<功法 id>`，内功为 `mj_xf_<心法 id>`。秘籍放在行囊的“秘籍”分类。
2. **拿到不等于学会**：在行囊里选中秘籍，选择研习的角色，点击研习。
   - 满足学习要求，就立即学会该功法的**第一重**（内功为第一层）。
   - 不满足，界面写明还差什么。例如：

     | 不满足的项 | 界面提示 |
     | --- | --- |
     | 前置重数 | 需先将《试锋剑法》3重 |
     | 属性门槛 | 属性不足：身法 4/6 |

3. **书不消失**：研习后秘籍留在行囊里，可以给同伴再学。同一角色已学会时，提示“已学会”。
4. **学会之后照旧**：升重靠熟练，需求为 min(6n², 20n)，主属性 ≥ 3+⌊1.5(n−1)⌋，四重升五重、七重升八重仍是突破关。秘籍不加速升重。
5. **个人技能不出秘籍**（2026-10-08 用户确认）：同伴的个人技能和个人篇功法，只能向本人请教获得，不能通过书籍取得。涉及唐照雪的《照川剑法》《澄江剑》、岑霜的《留生短兵诀》、徐令仪的《明约协锋法》，以及暂缓设计的同伴个人技能。
6. **不做**：研读进度、手抄本、残篇等版本区分、互斥代价、随机鉴定、逆练。

## 2. 学习要求

**外功**：
- 前置：同路前一门功法到规定重数（丙要丁级三重，乙要丙级五重，甲、绝要前一门七重）。
- 属性门槛按品阶和路线取值（martial-lineage.md §3.2 的表）。
- 本门本路的入门功法没有前置。例如正道盟的《短锋相照》从丙级起步。
- 江湖散学候选（旧原型 6 门）目前没有门槛。2026-10-11 新增的 28 门江湖散学没有前置功法，但有属性门槛（按品阶和路线，同门派功法），见[攻击招式扩充 v1](martial-review/attack-expansion-v1.md) 第 7 节。

**内功**：沿用运行时心法数据里的属性要求（`XINFA[id].req`），并受心法须进入培养（`S.chapter≥2`）才开放的限制。

数据来源：`tools_docs/build_martial_lineage_v3.py` 把 `learn_req` 和 `prerequisite` 写进运行时数据 `js/martial-external-data.js`，字段为每门功法的 `learnReq` 和 `prereq`。

## 4. 参考调研（2026-10-08）

几款同类游戏几乎都把“拿到书”和“学会”分开，中间隔着属性门槛：

| 游戏 | 学习门槛 | 秘籍是否消耗 |
| --- | --- | --- |
| 大侠立志传 | 悟性分档 | 不消耗，全队共用 |
| 侠客风云传 | 属性或武学等级 | 不消耗 |
| 逸剑风云决 | 好感、实力评估 | 同伴只能学书 |
| 太吾绘卷 | 资质、造诣、悟性 | 另有真传、手抄、残页等版本 |

本作取最简单的共性，不做版本和研读进度。

## 5. 投放与图标（2026-10-08 完成）

- **投放**：每本秘籍在哪里、通过什么途径拿到，见[秘籍投放表](manual-placement.md)。
  - 投放表由 `tools_docs/build_manual_placement.py` 生成。
  - 每本门派秘籍都列出两条途径：本门途径（导师传授时赐书），以及按品阶的外派途径（丁、丙走公开渠道，乙要合作许可，甲要人物篇或深交，绝不外传）。
  - 行囊里的道具说明会显示“来源”。

  | --- | --- |

  | 丙 | 蓝布面线装书 |
