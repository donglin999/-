- 当前按**开始、培养、游历、终局四部分**：栖河为开始、三年为培养，之后地区游历与明确终局行动；2026-10-02四篇二十章作为历史追溯。2026-10-16授权调整已写入[总纲](story-framework-review.md)，见[决定记录](story-decisions.md)。
- 主要门派保留女性可招募角色，男性不再逐派配对，并有非门派男女同伴；当前为18位、14女4男候选（含阮青雀、秦绯鸢与裴知古）。每位当前阶段规划6张完整对白状态，共108个素材位；表情与动作同图，按人设逐张设计，不再拆分动作和表情拼配。前期可体验同行；后续男性短剧情加条件判断，女性完整独立人物篇。名册与素材生产进度不等于招募剧情实装。

- 序章为栖河村初遇、借宿与第一夜；风起栖河段为旧物风波、村火撤离、[三选一去向](opening-routes.md)与安身。三选一当前仅首项周砚山居可确认，另两项只可看介绍；[两章脚本](../archive/design/story-scripts.md)止于山居第一夜，后续培养、汉皋和叶蘅成长路线另写。

- 栖灯馆从新剧情移除；旧十二日安排由**三年、三十六月的休闲培养**取代。
