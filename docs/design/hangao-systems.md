## 2. 剧情时间点与住宿

### 剧情时间点（方案 A，2026-10-10 用户确认）

决定过程：2026-10-09 用户定“活动没有时间概念，只靠剧情推进时间”；2026-10-10 考虑到后面要做大地图，对照《逸剑风云决》（主线不做时间不走、休息不过夜、“几日后”约定可快进、支线以主线节点为截止）后，用户选 **A：逸剑式**，并要求“为特殊剧情、特殊场景设计夜晚场景便可”。

- **时间只由主线推进**。本月是一串剧情时间点（表见[主线逐场稿（已作废归档）](../archive/design/scripts/hangao-main.md#时间怎么走剧情时间点)）；界面显示日期（如“五月初三·上午”）、当前目标和最近的约定。
- **活动不耗时间**：走路、买卖、鉴定、典当、委托、擂台、零工、听书、听曲、出城往返、支线步骤，都不让时间走。玩家不去找目标人物，时间就停着。
- **推进**：到目标场所找目标人物（多为周砚）→ 一段小剧场 → 下一个时间点。
- **没有昼夜交替**。夜晚只有两种：
  1. **特殊剧情夜**（本月是“城中第一夜”“寿宴之夜”）：**不模拟全城入夜、不做关店**。只给这一晚**限定可活动范围**（几个场所），范围内的场景做夜景处理；范围外的地方当晚不去，城图上标“今晚不去”。用户 2026-10-10：“特殊剧情夜不需要，只要限定可活动范围，以及活动范围内的场景处理即可。”
  2. **夜景场所**：栖月楼、长明坊、虹桥夜市、香水行、临水酒肆是按夜景设计的场所，什么时候进去都是入夜后的样子，不受全城昼夜限制。需要夜色的支线步骤（货栈蹲守、作坊夜潜、栖月楼篇）各自做成夜景场面，由该步骤直接进入。
- **约定与快进**：剧情给出“几日后”的约定（如“两日后·祁老寿宴”）时，顶栏显示；玩家可以在目标人物处选择直接快进到那一天，中间的自由时间放弃。
- **截止与提醒**：支线以主线节点为截止，不设倒计时。每次推进前列出“之后会错过”的事，确认了才走。
- **防反复刷**：次数限制按时间点计——每店讲价一次、每种零工三次、赌坊十局且输赢 ±20、点菜一次；擂台靠有限的对手名单（三名守擂人加按剧情开放的擂主），输了可以再来。
- **自由期**：核验之后是不限时的自由期；想走时到南门找周砚回谷（M08）。
- **大地图**：赶路不耗游戏时间；跨区域远行需要“过了几日”时由剧情过场交代。
- 培养模式（36 个月、每月五时段、体力）是另一套已确认规则，不受本节影响。

### 住宿

| 住处 | 报价（旧按晚口径，计费细化见下） | 功能 |
| --- | --- | --- |
| 迎客店通铺 | 2文 | 歇息、存档；行李寄存（6格） |

- **歇息**：在住处歇息只恢复气血内力，**不推进时间**（推进时间要找目标人物）。露宿只恢复一半。战斗受伤未治的同伴歇息只恢复一半，需去义诊棚或药铺。
- **计费口径待评审**：报价不触发过夜；本次细化建议按当前剧情时间点购入房间使用权，同点重复歇息不重复收费，周砚预付上房记录覆盖范围。详见[住宿合同](system-completion-20261016/city-time-economy.md#2-刷新到期与重复规则)。
- **存档**：住处与鼓楼告示墙旁的“驿递”可存档；其余地方只自动存档。

## 3. 江湖委托榜

鼓楼告示墙的“江湖委托”一栏。和支线不同：委托是**可重复、短小、数据驱动**的。

- **数量**：同时挂 4—6 张，在配置的剧情时间点更新一部分；不得通过休息或切图刷新。具体批次为[补充合同](system-completion-20261016/city-time-economy.md#2-刷新到期与重复规则)中的提案；剧情会插入固定委托（如“寻找钱二麻子的下落”）。
- **类型**：

| 类型 | 例子 | 何时可接 | 报酬 |
| --- | --- | --- | --- |
| 跑腿 | 送药到坊巷、取货到码头 | 任意时间点 | 5—10文 |
| 寻物 / 寻人 | 走失的孩子、丢了的狗 | 任意时间点 | 8—15文 |
| 护送 | 护商户出城到芦花渡 | 白天时间点（走大地图） | 20—30文 |
| 讨伐 | 城外官道的路匪（接[野外遇敌](wilderness-encounters.md)） | 白天时间点 | 25—40文 |
| 采集 | 端阳艾草、菖蒲 | 白天时间点（城外草市） | 6—12文 |
| 文书 | 抄写、对账（悟性判定） | 白天时间点 | 8—12文 |

- **委托评价**：完成后按完成质量给“城市声望”（第15节）。声望高了出现更高报酬的委托和指名委托（某派人物点名找萧白）。
- **失败**：到配置的截止主线节点或任务失败时不给完成报酬及声望；已接委托不因普通榜单更新消失。同一张委托实例只能结算一次。具体重试、归还委托物与推进提醒见补充合同。

## 4. 鉴定

博古斋提供，以后其他城镇的古玩店、书肆可接同一系统。

- **未鉴定物品**：野外拾得、赌坊赢得、典当流出、支线获得的“旧剑一柄”“残卷一页”“玉佩一块”等，显示为“未辨”，属性、品阶、真伪未知。
- **鉴定方式**：
  1. 付费鉴定：钱守拙鉴定，丁级 2文、丙级 6文、乙级 15文，必定准确。
  2. 自己看：萧白用“察看辨识”（[NPC 交互](npc-interaction.md)），按**鉴定熟练度**判定；熟练度不足时只能看出一部分（例如知道是丙级，不知道真伪）。
- **鉴定熟练度**：0—100，每次亲自鉴定成功 +3、失败 +1；HG-S02 一次 +10。达到 30 能分辨真伪，60 能看出隐藏属性（例如“饮过血”的旧刀有额外暴击）。
- **真伪**：假货鉴定后变为“仿品”，可卖但价低；真品可能有附加词条。真伪由存档种子固定，**不可读档重刷**。
- **证物**：主线证物（招贴、授权附页、行程残账）不经鉴定系统，由剧情固定。

## 5. 典当

信和解库提供。

- 典当价＝估价的 60%；当期 **3 个时间点**，期内以典当价＋10% 赎回；过期物品流入博古斋货架，按估价 120% 出售。
- 剧情物品、证物、叶家遗物、人物信物**不能当**（按钮置灰并说明原因）。
- 用途：缺钱时短期周转；与 HG-S01 赎当支线联动。

## 6. 打造、强化与修理

洪炉铁铺（兵器、护具）、霍记修械（器具、机关件）提供。

- **购买**：见[店铺功能·洪炉铁铺](hangao-shops.md#洪炉铁铺)。
- **强化**：每件装备强化 +1 至 +3。
  - 费用：丁级 6／10／16文，丙级 15／25／40文；需材料（铁料、皮革等，可在码头买或野外采集）。
  - 效果：主属性每级 +8%；+3 时解锁一个小词条（锋利、轻便、坚韧之一，按类型）。
  - 不会失败、不会损坏装备（不做赌博式强化）。
- **修理旧提案（未确认，暂不作为接入要求）**：曾提出装备耐久与重伤后修理 1—5文，耐久为 0 属性减半。本轮候选改为只修作者配置的旧器／任务损坏物，不新增通用耐久、逐战磨损或随机洗练；两种取舍由[制作链合同](system-completion-20261016/city-time-economy.md#4-药食与修旧器两条制作链)比较，未改当前装备规则。
- **打造（定制）**：本月只开放丁、丙级定制，需提供材料＋图样；乙级以上定制要庞铁山信任达到一定值并完成后续支线（年二）。
- **器具修复**（霍记）：修复损坏的机关件、旧兵器（“锈锋”类），恢复其原品阶；霍逐尘信任高时修复费用减半。

## 7. 赌坊

长明坊为固定夜景场所，普通自由期可进入；特殊剧情夜是否可去由该节点活动范围决定。

- **玩法**：
  - 骰子“比大小”：押大小／押点数，赔率 1:1 与 1:5。
  - 叶子戏（简化牌戏）：与庄家比点，有策略。
- **限制**：每个时间点最多 10 局、输赢上限 ±20文，达到上限庄家请你“改天再来”。期望收益为负（庄家抽一成）。
- **出千**：萧白可以用“察看辨识”看出庄家换骰（定力判定），揭穿后：
  - 当场揭穿：长明坊翻脸，战斗或赔钱了事，归烬堂声望 −；
  - 私下告诉戚铮：戚铮整顿，归烬堂声望 +，长明坊此后不出千。
- **欠债**：萧白不能在赌坊借钱。NPC 欠债走支线（HG-S06）。
- **边界**：赌坊不是刷钱途径，不设“赢取装备”的高额奖池；玩法主要服务剧情与人情。

## 8. 擂台

④西市擂台（特殊剧情夜不在活动范围内）。

| 模式 | 内容 | 规则 | 奖励 |
| --- | --- | --- | --- |
| 新手试艺 | 初五寿宴专场 | 三人组；只能用丁级招式；三场两胜 | 《端阳彩缕》或《端阳香囊》 |
| 守擂挑战 | 不限次数，输了可再来 | 先连胜三名守擂人，再挑擂主；单挑或带一名同伴（2 对 2） | 本轮候选：每名配置对手首胜 5文；胜擂主得对应阶段彩头（重复奖励细化见补充合同） |
| 擂台十番 | 擂主随剧情开放：自由期之前只有第一位，自由期开放第二、三位（打败前一位才见下一位） | 见 HG-S08 | 丁、丙级装备 |
| 照川指点 | HG-C01 后 | 唐照雪对萧白一对一指点，输了也有经验 | 招式熟练度（按作者配置的教学实例结算，不随自然日或旬刷新） |

- **切磋规则**：点到为止；气血降到 30% 判负，不会死亡；战后自动恢复到 50%。
- **擂台与声望**：每击败一名擂主，城市声望 +；输给擂主不扣声望。
- **限制**：不能在擂台挑战主线人物（徐、岑、沈、苏芷等）；他们不上擂台。

## 9. 传闻与说书

- **传闻**：城市里获取的“消息条目”，记入江湖手册的“传闻”栏。来源：说书茶坊、望江楼酒客、玉容坊韦三姑、香水行、脚夫行。
- **作用**：
  1. 指向支线（如“码头有人偷运鲥鱼”→ HG-S17）；
  2. 解锁对话选项（知道某传闻后，可以对某 NPC 说出来）；
  3. 有的传闻是假的（说书人添油加醋），去验证后标为“属实／谣言”。
- **说书**：听一段书 1文；会听到江湖大事（铺垫远处地点、门派动向）和萧白自己的事迹（HG-S09）。

## 12. 存档字段

主线剧情标记归 `S.hg`（汉皋城剧情域）；城镇服务状态放 `S.town[<townId>]`，汉皋的 townId 为 `hangao`。铜钱、背包、装备和关系仍使用各自正式系统，不在城镇域复制，接入细节见[数据归属](system-completion-20261016/city-integration.md#3-状态归属与提交约定)。下列字段为设计结构，不代表当前正式存档已有这些字段。

```text
S.town.hangao = {
  visited: true,
  beat: 'T1'..,                          // 当前剧情时间点（昼夜由时间点决定）
  rep: 0..100,                            // 城市声望
  shopFav: { hg_smith: 0..100, ... },     // 店铺好感
  rumors: { id: 'heard'|'true'|'false' },
  boardTaken: [...], boardDone: [...],    // 委托榜
  arena: { wins, bossBeaten: [..] },
  pawn: [{ itemUid, price, openedBeatOrdinal, dueBeatOrdinal, status }],
  appraiseSkill: 0..100,
  casino: { byBeat: { /* beatId: {net, rounds} */ } },
  state: { workshopClosed, niuErSober, huojiOpen, ... }  // 第14节
}
S.hg = { m01..m08, m06a/b/c, m06.all, choices..., c01..c14, s01..s24 }  // 剧情标记
S.flags.factionRep = { alliance, guijintang, patrol, whiteHeron, zhaochuan, hechuan, songfeng }  // 势力声望
```

- 剧情标记只用 `hg.` 前缀；不复用旧 `S.flags.xq`（旧襄阳 demo）。
- 旧档迁移：旧襄阳 demo 的存档不迁入汉皋；从归云谷第4月正常进入。

## 14. 城市状态与扩展

- **状态**：城市按“街区＋阶段”记录变化，例：作坊被封（⑨后院贴封条）、牛二戒赌（⑤码头常驻）、霍记开张（③招牌换新）、拳门失去雇主（⑤护运棚冷清）。年一10月等再访时读取，不重置。
- **招租铺面**（[汉皋城第6节](hangao-city.md#6-预留与扩展)）：每个铺面有 `slotId`、`街区`、`门面朝向`、`室内模板`。开张条件写在数据里（如“阮青雀下山篇完成后开修锁铺”）。
- **预留驻点院**：每院 `courtId`，绑定一个势力 ID；新门派开设时只需写入驻点数据与常驻 NPC。
- **新城镇复用**：新城镇只提供：店铺表、委托池、擂主表、传闻表、零工表、剧情时间点与人物位置表。系统逻辑不改。

## 15. 声望与店铺好感

- **城市声望**（汉皋）0—100：委托、擂台、支线、帮助居民提升；欺压、偷窃、在城里斗殴下降。
  - 20：委托榜出现指名委托；
  - 40：望江楼东家请吃一次饭（传闻 ×2）；
  - 60：府衙推官请萧白作证人（年二支线入口）。
- **势力声望**：沿[培养路线·触发与不卡关约定](cultivation-routes.md#触发与不卡关约定)要求，个人信任与组织声望分开记。本月主要变化来源已在支线中写明。
- **店铺好感**0—100：常客、支线、讲价成功提升；讲价失败不降。
  - 30：九折；60：八五折并出现“熟客专柜”（每店 1—2 件）；90：店主私人小剧情。
- **讲价**：江湖手段·讨价，每家店每个时间点一次，成功九折（与好感折扣叠乘，最低七折）。

## 16. 快速往返

- **车马行**（②）：到过的大地图地点快速往返，按路程收车钱，**不耗时间**；首次必须亲自走到。
- **渡口**（⑤）：水路去芦花渡、合川镇（合川本月未开放，只显示“汛期停航”）。
- **城内**：九个街区之间不做快速移动；但城市小地图点击街区可自动寻路。
