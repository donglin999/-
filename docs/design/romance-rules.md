## 二、本作规则

### 1. 两条线分开
- **主线**（叶家遗产、三方责任、汉皋等）永远可达，不因关系高低改变走向。
- **关系线**（每个可结缘角色一条）独立推进：关系值 0–100，四阶段 初识 0–19 / 熟络 20–49 / 信赖 50–79 / 托付 80–100；每升一阶段要先通过该角色的**瓶颈剧情**，否则关系停在当前阶段的上限（19 / 49 / 79），送礼送信也不能越级。

### 2. 年龄
萧白穿越后 17 岁，第二年正月初一满 18。**萧白满 18 岁之前，任何关系阶段都只写友情、关心、玩笑与信任，不写暧昧和恋爱。** 所有可结缘角色是成年人。第一年里关系高的回应是“更亲近、更放心、更会照顾人”，第二年起托付阶段才可以出现暧昧的对白。

### 3. 关系高低改变对白（随处可见的小演出）
- 任何剧情里，可结缘角色的台词可以按关系阶段准备 2–3 个版本：基础版、信赖版（更亲近、更直接）、托付版（第二年起可暧昧）。播放时按当时的关系值和年龄选一版。
- 不是每句都要分版本：每段剧情挑 1–2 句最能体现关系的台词就够了（打招呼、道别、玩笑、关心的那一句）。
- 送礼回话、回信、节日小场（如除夕、生辰）同样按阶段换写法（对应原作“按好感发红包”）。

### 4. 瓶颈剧情（原窗口错过与后续补救）
- 每位可结缘角色有 3 个瓶颈：初识→熟络、熟络→信赖、信赖→托付。瓶颈可以是一整段剧情，也可以是某段剧情里**只有关系够了才出现的选项**（对应原作“好感高于50才出现‘喜欢齐丽’”）。
- 每个瓶颈都有**开放窗口**和**关系门槛**（门槛定在当前阶段上限附近，例如信赖→托付要求 ≥ 55～75）。窗口关闭时没过，就算**原窗口错过**：关系暂留当前阶段，界面写明“已错过：……”与已知补救线索；依据下方2026-10-10用户要求，游历if线保留补入队与信赖的机会。托付是否可补由个人篇明确，不能统一承诺补满；叶蘅已有第二年补方子的特别方案。原缺席事实保留，主线、友情和其他角色不受影响。
- 选错也会断线，但必须在剧情里有明显的态度差别，不出“看不出对错的陷阱选项”；断线只影响这一个角色。
- 可以附加技能门槛（例如医术、步法），但不能要求刷满某项能力。

### 5. 结缘是自由选择
- 达到**托付**、萧白**满 18 岁**、未与该角色结缘时，她所在的地点会出现一段“心意”剧情（独立事件，不排在主线日程里）。玩家什么时候去、去不去，自己决定；没有截止时间，也可以一直保持托付不结缘。
- “谷中日程”会提示“心意 · 某某 · 闲逛某地”，但不会自动开场。
- 结缘后：对白同时读取结缘事实、当前关系和具体争议；关系暂降时不退回初识、不自动分手。后续专属剧情另写，不改变主线。
- 多人结缘允许，人数不改变托付80门槛，不要求伴侣批准。吃醋已要求设计，具体任务/扣分/频率仍待评审；不自行加入互斥。

### 6. 写作要求
- 先写清每位角色的“关系线表”：瓶颈三项（时间窗口、门槛、在哪段剧情、错过的后果）＋心意剧情的地点。
- 暧昧要克制：靠称呼变化、停顿、玩笑里的认真、动作上的照顾来表现，不写露骨内容。
- 关系变化在剧情里有原因（一起经历了什么），不能只靠数值跳变。

## 四、入队：两种做法综合（2026-10-10 用户）

用户原话：“在侠客风云传里面在培养阶段把好感度拉满后，进大地图模式后就可以直接进队了，而在逸剑风云决里面是通过大地图实际的一系列支线才可以把人物进队，我希望可以综合一下，把一些角色可以在培养阶段就可以直接进队，而有些角色在培养阶段之前做好了基础，后续还是需要一系列的任务情节才可以进队，结缘则是必须有单独的个人剧情才可以结缘；我希望培养阶段在一些关键剧情错过后，会有在大地图模式后进入该角色的 if 线，希望是可以在 if 线里面有一些补救的机会进队的。”

### 1. 三类入队方式

| 类型 | 做法 | 归入的角色 |
| --- | --- | --- |
| **甲 · 开始/培养期可正式加入** | 角色专属入口成立；不能把同样的好感门槛套给所有人 | 叶蘅（开始即同行）；裴知古（培养五月）；殷红缨（现行代师出行/除夕入口）。男性四人的年二入口按[短篇表](companion-men.md)与[固定等级方案](character-levels-100.md)分别安排 |
| **乙 · 培养打基础＋游历任务链** | 初识、通信、共事记成实际基础事实，游历完成本人篇和职责交接；基础能改变解法/开场，不能跳过核心本人选择 | 苏芷、唐照雪、徐令仪、岑霜、沈雁回；陆衡有年二及游历两种约定入口，不强制等毕业 |
| **丙 · 以游历人物篇完成招募** | 核心任务在游历阶段完成；可按本人篇提前初识，不再把此类解释为培养期绝不能认识 | 段明棠、闻疏桐、晏小楼、乔行舟、柳含烟、秦绯鸢、阮青雀 |

- 入队只看“这段共同经历够不够让她／他愿意同行”，不要求关系到托付，也不等于结缘。
- 乙、丙类的任务链每步都发生在地图上的具体地点，有战斗或调查，不能只靠对话跳过。

### 2. 结缘必须有个人剧情
- 结缘的前提改为：**已取得正式同伴资格 ＋ 关系托付（≥80） ＋ 萧白与对象均成年 ＋ 看完该角色的个人篇和规定感情事件 ＋ 双方明确心意**。个人篇是 2–4 段只属于她的剧情（过去、心结、她自己的选择），在自由时间里去对应地点触发，不排进主线。
- 个人篇看完后，“心意”剧情才出现；仍然由玩家自己决定去不去、何时去。
- 殷红缨：个人篇第一段“十几年前的寿宴”（第二年起，托付后夜里去竹径），之后才有“屋顶上的人”。

已入队指已获正式资格，不要求当前占战斗位；人物在场与日程照常检查。已结缘者后续短期降值不撤销资格，未通过的原瓶颈则不能用礼物或修复返分绕过。

### 3. if 线：错过之后的补救
- 培养期错过关键剧情（瓶颈没过、关键选项没出现、窗口关闭）时，记一条 **if 事实**，角色按剧情离开或保持距离，不在谷中入队。
- 下山进入大地图后，该角色出现一条 **if 线**：换一个地点、换一种处境重新遇到她。if 线比原路线多 1–2 步、要求更高（例如要先在别处帮她解决一件事、要赢一场切磋），但**一定留有入队的机会**；完成后入队，关系上限同时解锁到“信赖”。
- if 线一般只补入队和信赖；托付与个人篇照常另算。普通战败、暂缓或缺材料保留该任务允许的复试/补做；永久拒绝必须由个人篇明确列出重大选择并事先提示，不能把“暂时没重试”视为永久失败。
- 每条 if 线都要写明：触发它的 if 事实、出现的时间与地点、步骤、与原路线不同的对白（她记得你当时没来）。

| 角色 | 培养期关键点 | 错过记为 | if 线（大地图，设计方案） |
| --- | --- | --- | --- |
| 殷红缨 | “代师出行”与她同行（当场入队）；没同行的，第一年除夕时关系 ≥40 也留下入队 | `if_yin`：开春她又出门游历，不入队 | 下山后在江陵酒肆听到“掀桌子的女人”→ 码头找到被正道盟旧怨缠住的她 → 帮她挡下一场（战斗）→ 她说“这回是你来找我”，入队并解锁信赖 |
| 叶蘅 | 第一年十一–十二月“灯下的方子” | 关系停在信赖（已在队，不影响同行） | 第二年按她的去向（留谷／白鹇谷）各有一次“把方子补完”的机会，可补到托付 |
| 陆衡（乙类） | 话别说得太满、多出来的半天、首季护送 | `groundwork_lu` 的条数 | 基础 0 条：任务链从“雇他护运”开始，共 5 步；基础 ≥2 条：他主动来信托事，3 步 |

### 4. 记录方式
- if 事实：`if_<角色>`（记错过的是哪一步、在哪个时段），由培养期写入存档。
- 基础事实不另存一份：由已有剧情事实汇总得出。`qiheRoutes`是接入读取的投影，不是全名册已经完成的证明；当前实现覆盖范围以运行模块为准。新增角色按[保存合同](system-completion-20261016/endings-relationship-integration.md#3-事件与存档接入)扩展，避免与资格、成长、关系原字段各存一套互相矛盾的值。

## 五、培养期的切磋与实战（2026-10-10 用户）

用户原话：“现在培养阶段似乎是没有切磋的或者一些关于战斗的剧情，还是要有的，不然拿到的功法只能硬练，没有正反馈不好。”

- **同门切磋（可重复）**：学会任一招式后，“招式”栏出现“切磋”。对手按在谷情况开放：卢小豆（入门）、方迟（稳）、钟拙（拳）、殷红缨（指点，收着打）。每个时段一场，真实战斗，不会战败出局；胜负都给所用兵器的熟练，胜了多给，并加一点关系。首胜另有一次性回报。
- **剧情实战**：第一年安排若干段必有战斗的剧情——大师兄陪练（实打）、竹径的狼（二月到三月上旬去竹径闲逛遇到）、出门前师父考校（四月下旬，去汉皋前）、年终考校第二题（对小师叔）。“代师出行”路上的拦路人留到该段行程做成地图内容时再加。战斗结果改变之后的对白与回报，但输了也能继续。
- **反馈**：战后在结果里写明“这一场用上了什么”，例如“入门剑式 熟练 +N”；年终考校和长辈的评语会提到切磋的胜场。
- 战斗素材：2026-10-16已完成本地主角六套武器96帧、五位人物112帧，动作与现行接入以[动作完成记录](../../../xiaojianghu-legacy-prologue/docs/updates/2026-10-16-character-actions-completion.md)为准；早期96×116静态四向小人不能继续当作完整战斗动作规格。

每位同伴的武力档、入队时间与考验、功法兵器配置另见[同伴武力、入队代价与配置（逐人）](companion-power.md)：武力越高，入队考验越重、时间越晚。

实现说明见当前游戏工作区 `docs/design/qihe-map/expansion/relationships.md`“关系线”与“入队、if 线与切磋”两节。
