## 2. 时代依据

蓝本是南宋荆襄一带的州府城市。下面是我按通行的建筑史与城市史常识整理的，取自《清明上河图》的画面、《东京梦华录》《梦粱录》对街市的记述、《营造法式》的做法等级；**没有逐条回查原文**，要用作对外说法前需再核对。只借面貌，不复原某座真实城市。

1. **坊墙已拆，沿街开店。** 宋代城市没有封闭的坊墙和定时的市，店铺直接朝街开门，屋檐、凉棚、货摊伸到街面上。所以街道两侧是连排门面，不是一栋一栋隔着空地。
2. **等级写在屋顶和颜色上。** 官署、寺观、城楼可用筒瓦、歇山顶、朱漆柱和彩画；庶民房屋不许用重栱藻井和五色彩画，只能是悬山顶、板瓦、原木色。所以民间店铺本身颜色素，热闹靠招幌、布帘、灯笼、彩楼这些可拆的东西。
3. **前店后宅。** 临街一到三间做铺面，白天卸下整排门板，后面是作坊和住处，再后是小院。
4. **酒楼分正店、脚店。** 正店是两三层楼，门前扎“彩楼欢门”（木架扎彩帛的门楼），挂栀子灯，设红绿杈子（栅栏）；脚店小得多，只在门口立一个简单的木架和酒旗。
5. **瓦子勾栏是大棚。** 演出场所是带顶的大棚，里面围栏分出戏台和看席，门口挂招子（演出牌）。
6. **城墙多是夯土。** 州城城墙以夯土为主，城门一段包砖，上建木构门楼，重要城门加瓮城。
7. **南方做法。** 荆襄多雨夏热：出檐深，木构架加竹编泥墙抹白灰，或者整面木板壁；临水用木桩架起的吊脚房；穷人用茅草顶、芦席棚。
8. **主街铺砖石，小巷是土。** 主街铺石板或条砖，两侧有明沟；巷子是夯土和碎砖。街树是柳、槐，不是成片草地。
9. **货栈叫塌房。** 码头边有成排出租的仓房，墙厚窗小，防火防盗。

## 3. 建筑分五类

| 类别 | 用在 | 屋顶 | 墙与木作 | 颜色 |
| --- | --- | --- | --- | --- |
| 官式 | 城门楼、鼓楼、府衙、巡江司分署、城隍庙 | 歇山顶、筒瓦，屋脊有吻兽；城隍庙用绿琉璃剪边 | 青砖墙或红墙，朱漆柱与大门，石台基 | 朱红、青灰砖、绿琉璃，最鲜明 |
| 大商号 | 望江楼、栖月楼、远山镖局、汇通钱庄、信和解库、长明坊 | 两到三层，悬山或歇山，青灰板瓦 | 朱栏、格子窗、深色木柱；钱庄当铺是高砖墙小窗 | 深褐木、朱栏、白粉墙，靠彩楼和灯笼提色 |
| 连排铺面 | 东市各店、茶坊、酒肆、书肆、杂货铺 | 悬山连檐，青灰板瓦，屋面高低错落 | 整排可卸门板，檐下凉棚，前店后宅 | 原木色、白灰墙，各家招幌颜色不同 |
| 民居 | 坊巷、各街区填空 | 悬山板瓦；穷处是茅草顶 | 竹编泥墙抹白灰（斑驳露黄泥）、木板壁 | 白灰、黄泥、旧木，最素 |
| 棚与栈 | 草市、勾栏、义诊棚、货栈、脚夫行、窝棚 | 布棚、茅棚、芦席；货栈是大跨悬山 | 木柱敞开；货栈厚墙小窗；临水吊脚木桩 | 麻黄、旧布色；勾栏棚顶用彩布 |

同一类建筑尺度一致；不同类之间高低分明：官式和大商号明显高出连排铺面一头，这是城里的天际线。

## 4. 地面、水、树、街市物件

- 主街与广场：青灰石板或条砖，有车辙和修补痕迹，两侧明沟。
- 巷子与后院：夯土、碎砖、煤渣，墙根才有草。
- 码头：条石驳岸、石阶、木栈桥、系船桩。
- 城内运河：石砌河岸，垂柳。
- 汉水：浑黄偏灰绿的大江，不是清蓝色。
- 树：街边柳、槐，院内花木，庙里古柏。不铺草地。
- 街市物件：招幌、灯箱、遮阳大伞、货摊、水缸（防火用）、拴马桩、独轮车、挑担、井台、公告牌。端阳时门上挂艾草菖蒲，街口有卖粽子、香囊、五色线的摊。

## 6. 室内

- 脚店（迎客店）：城里的客店，地面是旧木地板，门口一段铺方砖；原木方桌长凳、木板壁，朴素但干净。夯土地面只用在铁铺作坊、货栈、窝棚。
- 正店（望江楼）：木地板或方砖，朱漆柱、雕花栏杆、屏风、宫灯，讲究。
- 庙：方砖地、朱柱、神龛彩绘、幡幢，光线暗。
- 铺面：前面是柜台和货架，后墙有门通作坊或里间。
- 赌坊：深色木构、油灯、烟气，只做夜景。
- 艺楼（栖月楼）：见第7节。

## 7. 街区里不许有“填空”

2026-10-10 用户指出⑨坊巷西南角一堆棚子挤成一团、看不出是什么。原因是上一版提示词让模型“把空隙用房屋填满”。改为：

1. 每一栋房、每一组棚子都要说得出用途和主人，门朝哪条路开；说不出的不画。
2. 房屋之间必须留出看得见的巷道或院子，巷道至少两人并行宽；不许屋顶叠屋顶。
3. 屋脊只有东西向和南北向两种，全图同一视角；不画斜放或侧倒的屋顶。
4. 街区边缘用完整的院落或一道院墙收边，不用半截屋顶堆出“密集感”。
5. 窝棚区（⑨西南）重新定：沿一条 L 形土巷排 6 间茅顶或芦席棚，巷口有水缸和晾衣绳；巷尾是阮青雀常待的货棚（一间敞棚，堆木箱麻包）；中间留一块晒场。

## 8. 栖月楼：风月场的表达

用户指出上一版栖月楼像酒店，没有风花雪月的勾栏气。按宋人笔记里酒楼妓馆的通行描述（门首红纱栀子灯、彩楼欢门、绣额珠帘、主廊上歌伎待客；同样未逐条回查原文）重定。玩法边界不变（只卖曲不卖人，见[总设计](hangao-city.md#青楼艺楼的写法边界)），变的是气氛。

外观：
- 2026-10-14建筑V3方案：两层正楼与后中部单层排练屋，曲堂挑空，楼上U形环廊；西北试谱间、东北雅间落在一层实房上方。原三层外观不再作为生成依据，详见[同位楼层方案](../archive/design/hangao-qiyue-building-v3.md)。朱栏绿窗、灯笼彩帛按层高与门位安排。
- 每层挑出回廊，栏杆上搭绯色、藕色纱帘和彩绸；二层廊下挂一排写着艺人名字的花牌。
- 临河一面只保留有柱脚的小廊角，岸墙、柳影与帘布遮去大幅水面。河景为静态窄带加现有短横粼光，不依赖实时倒影或画舫尾流。门前石阶两侧摆牡丹、海棠盆花。

外堂（室内）：
- 中空的大堂：正中是铺红毡的歌舞台，三面围矮栏；台后是绣屏和层层纱幔，台侧有琵琶、筝、箫、拍板、小鼓和乐师的坐席。
- 四周是酒席而不是茶桌：矮几、锦垫、酒注子与酒盏、果碟；席间立着屏风隔出半私密的座。
- 抬头能看到二层环廊：朱栏后是一间间垂着珠帘的雅间门，廊柱间挂纱灯和彩绸。
- 陈设：熏香炉冒细烟、大瓶牡丹、墙上仕女与花鸟画、门边的花牌架、掌事的小柜台和曲单匣。
- 颜色：朱红、绯红、藕粉、金，配深色木构和暖黄灯光；浓而不俗。
- 2026-10-14表现补充：东侧楼梯保留外形与扶手，脚点按门口淡出跳转；不做逐级爬升。恢复下表的艳丽多色、彩帛珠帘，避免把艺楼画成素木客栈。
- 当前视觉制作采用用户重新指定的室内画风，见[V4分场景](hangao-qiyue-scenes-v4.md)；V3只保留建筑关系参考，其生成剖视风格已被用户否定。V2/r3上下层不对应，旧可走动整图只留历史测试；不要在其上继续生产正式物件。

### 栖月楼配色（2026-10-10 补）

用户看第五版后指出：浓度够了，但不能只有红色，要多种颜色一起构成。定为“朱柱为骨，青绿为底，粉黄紫点染，金线勾边”：

| 部位 | 颜色 |
| --- | --- |
| 柱、栏杆、楼梯扶手 | 朱红（只有这些是红的） |
| 梁枋彩画、窗棂、雅间门 | 石青、石绿叠晕（宋式青绿彩画），描金线 |
| 歌舞台地毡 | 宝蓝底织金团花，红只作窄边 |
| 堂内地面 | 深褐木地板露出大半，席下各铺小块绿、蓝、驼色地衣 |
| 纱幔与帘 | 藕粉、鹅黄、水绿、湖蓝交替，不成片用同一色 |
| 屏风 | 石青或墨绿底，粉白牡丹、孔雀、山水 |
| 锦垫、桌围 | 翠绿、绛紫、鹅黄、宝蓝混搭 |
| 灯 | 白纱灯、淡黄宫灯、彩绘走马灯为主，红灯笼只在门口 |
| 花 | 粉白牡丹、紫藤、黄蔷薇、青瓷瓶 |

外观同理：朱栏、青绿彩画与绿窗、各色纱帘、白纱灯与红纱灯相间。

## 9. 屋瓦分级

第三至五版除城隍庙外屋瓦都是同一种深灰，看不出等级。定为四档：

| 档 | 用在 | 画法 |
| --- | --- | --- |
| 琉璃 | 城隍庙 | 绿琉璃筒瓦，黄色脊饰 |
| 官式筒瓦 | 城门楼、鼓楼、府衙、分署 | 青黑色筒瓦（一垄垄圆筒形，垄间深沟），檐口有圆瓦当，正脊两端有鸱吻，垂脊有走兽 |
| 商号板瓦 | 望江楼、栖月楼、镖局、钱庄当铺、长明坊 | 青灰板瓦，屋脊抹白灰线，朱红博风板和檐口 |
| 民间旧瓦 | 铺面、民居 | 灰褐色旧板瓦，深浅斑驳，有补瓦和青苔；穷处茅草、芦席 |

另：院落里的厢房一律画成屋脊东西向的小屋，不画屋脊南北向、像侧倒的屋顶。
