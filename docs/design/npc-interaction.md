# NPC 交互与江湖手段

状态：**设计方案**。生活技能的师承、重复练习、考校、动作与音效以[生活技能规范](life-skills.md)为准；本页规定 NPC 模块与取得途径；剧情对象来自[故事主线](story.md)和[青蚨散事件](xiangyang-case.md)。

## 每个 NPC 的交互构成

菜单由 `基础身份模块 + 当前服务模块 + 事件模块 + 已掌握江湖手段` 组合。只有对话是所有可交流 NPC 的基础项；服务和手段由人、地点、时间、关系与剧情状态决定，行动后即时刷新菜单。

| NPC 类型 | 常驻选项 | 条件选项示例 |
| --- | --- | --- |
| 普通居民 | 对话、询问近况 | 打探、劝说、赠物、求助、切磋（合适者） |
| 店主／摊贩 | 对话、买卖 | 讨价、赊账、打听货源、帮工 |
| 医者／患者 | 对话、诊治或求医 | 请教、共同会诊、劝服用药、交换医案 |
| 导师／同伴 | 对话、请教 | 传授、练习、夜谈、委托同行 |
| 势力人员 | 对话、说明来意 | 出示凭证、交涉、探问、挑战、偷取物件 |

特别能力的选择只在剧情与人物行为允许时出现。偷取不是对所有 NPC 随时可按的万能按钮；有可见风险、失手反应与回头处理。劝说也需要论据或关系，不让高数值直接跳过人物立场。

## 手段如何获得和提升

| 手段 | 首次学习途径 | 提升途径 | 必须提供的替代解法 |
| --- | --- | --- | --- |
| 打探 | 山居来客教学、街市消息铺初见 | 多次问询、核对传闻、同伴请教 | 付钱买消息、找物证或等待主线证人 |
| 劝说 | 周砚指导一次冲突调停，或事件中有可信论据 | 协助谈判、处理关系、读书 | 提供实物证据、交换条件或由合适同伴交涉 |
| 偷取 | 江湖人物的支线教会基本手法，不能默认开局拥有 | 低风险练习、潜行和观察 | 交易、借用、公开挑战或其他可得线索 |
| 察看／辨识 | 萧白基本观察、叶蘅医药知识或导师指点 | 现场调查、医案、研习 | 请教专业人物或使用工具 |
| 切磋／威慑 | 基础武艺训练与明确对手同意／冲突 | 战斗和实战训练 | 不以战胜为唯一通路；可谈、可绕、可求援 |

所有手段属于生活技能，按“未学—入门—熟练—专精”四档展示；正式技能必须由人传授（襄阳临时直接授予入门，详见规范），再通过多次有效练习及真实应用提高，达到 6/18 点并满足真实成果要求后由导师考校突破。基础练习可以重复，但需要不同具体判断与操作，重复点同一句话不计熟练。任务显示当前可行解法和失败后果；主线证据至少有两条获取路线，避免因未学偷盗或劝说卡关。

## 行动后的变化

互动结果写入该 NPC 的关系、所知信息、服务开放状态和事件回响。成功劝说后可出现“托付／请教”；偷取暴露后可出现“解释／赔偿／避开”；共同会诊后可出现“复诊／交流医案”。刷新的是选项组合，不创建另一个重复 NPC。队友常驻闲谈由队伍界面或山居场景进入，和地图 NPC 的一次性事件分开记录。
