## 3. 人物如何改变主线，又如何被主线改变

个人任务产出具体事物：一班护卫、一条经验证的路、一艘有船工和载重的小船、一处能接几名伤者的诊棚、一场有自愿参加者的演出。这些写入地区状态和当事人约定，不能压成“全体支持+10”。主线反过来改变订单、通路、课程与伙伴去处，玩家回访能看到人员、摆设、服务或对话变了。

| 主干节点 | 同伴影响 | 无相关同伴时仍成立的基础路线 |
| --- | --- | --- |
| TRV-START | 旧识给具体会面邀请，玩家选择带谁、先去哪里；叶蘅能提出自己的路线 | 从公开护运/来客委托开始，不默认全名册都熟识 |
| TRV-NORTH-01…03／DONE | 沈争取有限改令；苏/叶决定救治；陆护路、霍修机关、阮修锁 | 官署公开窗口、普通医者与本地护运匠人；多一项费用/绕行，不凭空复制伙伴绝招 |
| TRV-RIVER-01…03／DONE | 岑面对交人，戚面对新货单；乔试航，段/石处理工钱与护运能力 | 原有渡工、堂内公共交涉和自办守渡；不会因为没招岑就不交代玄烛会目标 |
| TRV-SECT-01…03／DONE | 徐面对强制借兵；唐带学生实测，闻核路；柳与清徽决定教学/庇护 | 小派代表、普通向导、公开练场；少一个捷径仍可维护小派或支持联防 |
| TRV-COMMON／CLOSE | 选过两地后以获准公开的结果补第三方；人物只谈亲见或收到的消息 | 公共使者、受影响群体和三方行动补齐动机，裴的书和秦的旧案均不是必需证据 |
| END-CHOICE | 列出本人实际承诺、可协作/拒绝事项、成本和所在地点；一次政治分歧不删掉友情 | 玩家能走公开的阵营/地方基础任务，不需四人全是特定角色 |
| END-ACT-* | 按已完成个人任务请求一项有限帮助；可把候补安排在已约定的一处协作点 | 各路线自己的小队、付费职业协作或较长正面路径，未做个人篇不赠同等成果 |
| END-RESOLVE | 逐人结算事业、责任、私人关系；不在队仍有自己的生活 | 未结识只呈现玩家能知道的地区结果，不弹出陌生角色的全知回忆 |

**在队/候补不能同时占两个场景。** 场景有必要说话者但未上阵时，可在已安排同行的前提下作场景协作者；第四个可控位已经占满，不默默增第五人。未在当地的人只用真正已送达的信息；不能在立绘没出现时仍用她的第一人称替另一人讲话。

## 4. 关系分歧与群像，不把人全写成帮手

1. 徐与岑争的是涉害会众怎样交人和问责，沈问的是权限、伤者和退路；三人都可以先救同一批人再继续分歧，不用假信让大家同夜失智。
2. 唐愿自愿联防，段先核谁留下养馆；石可以不同意段的安排，戚可以不同意岑的退路。来源同一组织不代表自动同一选择。
3. 叶蘅自己决定家传；苏芷把复诊做好，不能因为叶蘅是女主就撤销苏的专业生活。
4. 柳的解约与秦的舞约独立；许照月拒绝回楼仍是有效结果。秦的班组、晏的戏班与柳的独奏不为省篇幅合成一个文艺队。
5. 裴知古可以留下不利主角的记录，闻疏桐可以拒交藏身图；这是具体边界，不是因为关系低随便背叛。
6. 殷红缨与周砚、方迟能分担后方；无需必死师父或突然变弱的师叔替主角让位。卢小豆仍按岁数成长，短期陪练不升级为政治领队。

拒绝一项任务的状态是“此事不同行”，不是立刻抹去正式资格、已学技能、恋爱或全人生。真正严重伤害须由事件先展示对象与后果，再按负责篇执行；不能临时改成全员强制原谅或全员永久敌对。

## 5. 制作范围与节奏

- **第一批**：三位主事人、叶蘅、殷红缨的主线回响；每条地区主线先有不依赖特定队员的基础解，再加关键人物版本。裴早期资格与五招沿现有成果，不重做招募。
- **第二批**：地方玩法联系紧密的唐、段、闻、苏、乔，以及陆/石/戚/霍短篇后续，复用已有地区空间。每人一项核心可玩任务即可，不给所有人写同样的查账六连。
- **第三批**：栖月楼共同旧案、柳秦独立事业、晏公开演出、阮合法手艺与裴核访；复用汉皋、清徽与既有旧渡地点。旧案J链按新阶段承接，不作为三方通关锁。
- 同伴完整个人篇可拆进可选游历，不把19条全部压在固定培养月份。早期铺垫沿已有窗口；新增培养活动先录统一日历、合算体力、地点与旅行，再写运行。
- 普通交谈每场只解决一个眼前问题，行动前后分场；新关键场正文建议8—14次发言，每次1—2短句，超出拆成进入/行动/善后。不同意见用具体人和处境说话，避免“秩序、代价、边界”的抽象宣讲。
- 玩家已做的赔偿、勘误、解约不重复收取；新个人任务可承认已有成果作为前置。普通失败可补料、返工、重约、重试；不因真实时间流逝让已离开的玩家暗自错过救命时限。

## 战斗与地图表现的实施边界

本轮个人任务统一用“探索准备/交接/操作 → 当前敌方小队的普通战斗 → 探索验收”。战斗只依现有win/lose/flee返回结果：击败本场敌方小队推进；失利或撤离回安全点重组/换路。剧情中的守渡、护工、断后和撤离表示事情的目的，不等于引擎已经支持坚持N回合、护送对象存活、战中拉闸或实时追逐胜利条件。普通人先在探索中交接离开战区，不能偷偷加保护对象血条。

唐的通道安排、徐的排班、殷的前后口分工均在探索完成，随后各打一场普通小队战再验收；霍先修、遇敌暂停、胜后回探索拉闸；乔在岸边做载额菜单，过场跳到对岸检查，不写真实驾船、水流或水面战斗。已存在武学/旧伤状态按其当前合同执行，未实现状态不因人物任务擅自生效。

樊城仓街/工坊只落在rg_fc_wharf既有货棚/作业棚交互区，烬渡旧栈是rg_jd_yard侧栈；清徽教学小院沿其门派内容依赖，不由同伴线再扩一张独立城市图。
