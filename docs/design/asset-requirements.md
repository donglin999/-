剧本动作说明不能直接变为生图任务。先确定表现方式，找出同阶段可复用资产，再把真正缺少的图列到章节清单；已锁住、未开放路线只保留文字与界面状态，不提前铺其场景和角色包。

## 2. 当前制作限制

- 普通 NPC：基础站立或小头像即可，**专属剧情动作帧数为 0**；普通任务对话结算，确有必要最多一张任务 CG。
- 主角与重要角色：按分类最低包准备基础立绘、表情和静态姿态，再按场景补充。角色有成长设计不代表所有未来换装立即进入当前清单。
- 重要事件：优先复用立绘与姿态，复杂多人关系用 CG；每张 CG 都要说明不同信息，不为每句台词生成一张。
- 探索移动、真实战斗、已要求的主角生活技能反馈、宠物系统动作继续各自专题规范；不得以它们为依据给普通剧情 NPC 增加动作任务。
- 本轮只补设计与需求，未开始新图生成、角色动画制作或开篇接入。已有资源按实际状态盘点，不覆盖来源或删除素材。

## 3. 每条需求的必填项

| 字段 | 要填的具体内容 |
| --- | --- |
| `asset_id`／版本 | 稳定 ID；修改用新版本，不以角色姓名作唯一识别 |
| `scene_ids`／台词范围 | 哪个场景使用，从哪句进入到哪句收起；分支条件 |
| `narrative_purpose` | 玩家从图里必须读到什么；与已有素材相比新增哪条信息 |
| `presentation`／角色级别 | dialogue、static_pose、cg、scene_state 等；普通 NPC 不能填专属 animation |
| `characters`／阶段 | 出场者、年龄、当前服装、已获得装备、伤病与知道的信息 |
| `identity_refs`／风格参照 | 同一人的采用基准、该媒介画风；不能用另一角色图当脸部基准 |
| `pose_and_props` | 身体朝向、视线、手、重心、道具接触与所有权；多人站位关系 |
| `canvas`／显示方式 | 源图目标与实际尺寸、透明与否、运行尺寸、脚点或立绘锚点、安全区 |
| `reuse`／`fallback` | 现有候选与不足，缺图时如何用对白／基础图完成事件 |
| `prompt_record`／文件 | 完整提示词、参考输入、真实使用的生成工具与模型（可获取时）、处理步骤、原稿与运行图路径 |
| `status`／证据 | 缺少、可复用候选、已生成候选、已采用、已接入、已实机验收；每阶段的实际证据 |

「高画质」不能替代身份、构图、手部和阶段要求。模型、实际分辨率和生成结果按实记录；不把放大后的尺寸写成模型原生输出，不把未生成的提示词写成已完成素材。

## 4. 交付类型与命名

以下是新需求命名建议，现有运行键可沿用，不因此批量改名。

| 类型 | 新文件示例 | 画布与交付要点 |
| --- | --- | --- |
| 菜单人物情境立绘 | `p_menu_ye_rural_v2.webp` | 2:3 全身，基准 1024×1536，背景不透明、淡雅，按固定画风 |
| 对话基准／表情 | `p_ye_rural_neutral_v1.webp`、`p_ye_rural_worry_v1.webp` | 透明，同阶段统一画布锚点；原稿优先采用高分辨率，运行图等比处理，保留现有兼容键映射 |
| 重要人物静态姿态 | `p_ye_rural_hold_box_v1.webp` | 透明，人物／道具整体完整；与基准头顶、眼线一致，变姿不变脸 |
| 单张剧情 CG | `cg_c1_relics_v1.webp` | 16:9，目标 1920×1080 或以上；实际尺寸记录，等比安全裁切，禁止直接拉伸；字幕与选项由程序叠加 |
| 普通 NPC 基础站立图 | `s_chen_stand_v1.webp` | 统一探索像素密度和脚点；只制作所需视角，不派生任务动作表 |
| 场景状态／道具 | `prop_opening_relics_v1.webp`等 | 可复用时先用现有单体；地图仍按布局与碰撞规范组合，CG 不是可走地图 |

图内不烘焙玩家需读取的字条、账簿文字、姓名、UI、按钮和任务提示。物件文字在界面显示；角色与背景的关键区域为字幕留出安全空间。

## 5. 条件需求卡例：叶蘅护住药箱

以下说明独立姿态确需制作时如何填写，不是本章自动派单。当前护箱动作可画入章节 CG，叶蘅基础角色包无需因此补图。

| 项 | 内容 |
| --- | --- |
| ID／场景 | `opening_ye_hold_box`；`C1-03`、索物谈话、避险等待 |
| 表现与身份 | static_pose；重要角色叶蘅，18 岁乡村医者、初始便衣；非白鹇谷或针攻换装 |
| 叙事目的 | 看出箱子是她要保护的家人物件、她未同意交出 |
| 动作 | 两手与提带／箱侧接触，肩背稍收，目光朝索物者；成人偏瘦身形、同脸同发 |
| 画布 | 透明，高分辨率原稿；与初始对话基准锚点匹配，道具不挡脸；实际尺寸入记录 |
| 复用／回退 | 复用初始脸、服装与药箱定稿；缺图暂用初始立绘、文字说明她背好箱子 |
| 当前状态 | 未请求独立姿态；优先采用已有角色图与章节 CG。只有具体场景仍无法表达护箱行为才启用本卡 |
| 验收 | 同脸、手部正确、所有权明确、无提前门派标记；1280／1920 对话视口检查 |

普通 NPC「收下药包」不建立等价动作卡，直接写 dialogue；整项任务若用 CG，就在 CG 卡中写该 NPC 的静态收物姿态。

## 6. 制作顺序与完成判断

1. 先定角色类型、阶段、地图出场与战斗侧，按分类展开必需项；定场景表现方式并填需求卡。
2. 盘点已有图，能表达同一阶段和行为就复用；不合阶段只可取脸部身份参照。
3. 列缺图、优先级和复用点，保存完整提示词，再生成范围内候选。
4. 检查身份、手部、媒介、画布、透明边和视线，记录采用／退回理由。
5. 接入后检查实际视口与输入恢复、CG 起止、分支状态一致，记录证据。

有文件≠已采用，有采用稿≠已接入，程序通过≠画面已验收。普通 NPC 没有专属动作属于按规范完成，不列为美术缺口；重要剧情图暂缺则明确回退与后续缺口，不能永久以无图长旁白当成正式完成。
