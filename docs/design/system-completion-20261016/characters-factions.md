## 2. 组织身份：权限必须有范围和责任（B02）

### 2.1 身份记录和优先级

补充方案：一个角色可同时有师承、受托身份、私人交情，但同一项权限只认一份有效授权。建议记录`organizationId / identityKind / issuer / scope / issuedByEvent / expiresAt / duties / status / returnedItems`。`scope`至少包含可办之事、可进入区域、可使用资源；没有填写不等于全部许可。

判定顺序：**已确认人物边界 → 当前场所与安全状态 → 具体事件授权 → 身份有效期/暂停状态 → 尚未履行职责 → 资源余额**。私人好感和组织声望只能帮助获得申请/复核机会，不覆盖前面的硬边界。正式招募一名组织成员只让她愿意同行，不改变萧白籍属，不把组织仓库变成队伍背包。

| 身份类型（方案枚举） | 触发与权利 | 必须承担的事 | 退出/失败与物品处理 |
|---|---|---|---|
| 访客/公开交流者 | 获准进入公共区；听公开课、购买公开物资 | 遵守场所规则；指定事务另外接取 | 可自由离开；拒绝服务须指出具体原因；不发成员物资 |
| 正式师承 | 只由负责篇明确拜师事件授予；本门基础课及逐级考校 | 已接受的师门差事、借物交还和师承承诺 | 不因一次练习失败取消；离派需专门剧情，不用换装按钮完成 |
| 客修/交流许可 | 一门课程或一项技艺的有限授课许可 | 完成该课程的练习、保密或实务要求 | 课程结束关闭未约课程，保留已学与记录；借用器具交回 |
| 协作/受托 | 接受具体委托并确认责任范围 | 交付、回报事实、归还借用/公用物 | 任务取消或结束后失效；失败按任务恢复合同结算，不抹除此前交情 |
| 委办 | 有明确发令/委托人、事项与地点 | 留存过程、交接证物、报告越权争议 | 不含调兵、任官和任意搜查；凭牌/公物回收，证物移交可访问的任务保管处 |
| 客卿/常任职务 | **尚无通用已确认授予节点**，只预留结构 | 必须先写持续职责与拒令后果 | 当前不提供“声望够就升职”；若三方方案采用，再逐路线审定 |

明确的有效期限使用培养日程编号或剧情推进点；仅限一次任务的授权以任务结束关闭。切图、读档、休息不能刷新。紧急主线导致的客观冲突，先给改期/交接方案，不自动判为背约；玩家明知责任仍主动违约，才进入该事件的问责分支。

## 3. 全同伴生命周期（B09）

### 3.1 分开保存的状态

资格`unknown / known / formal`；体验是独立的临时许可`trial`，保存之前资格。同行状态`active / reserve / duty / away / repair`；`repair`只指已发生、可说明的严重分歧。关系、结缘、职业、成长和位置是独立记录。离队不删除角色，不以“已入队”一个布尔值代替六类状态。

| 触发 | 同时检查 | 提交的变化 | 失败/取消与读档 |
|---|---|---|---|
| 初识 | NPC在场或已署名通信；没有重复初识事实 | 已结识、玩家知道的地点、后续线索 | 不补未经交流的私事；重复对话不再发奖励 |
| 体验同行 | 任务许可、当前身体/日程可用、空位或已确认换人 | 体验开始/结束条件、在队、已有成长和借装清单 | 满队取消保持原样；先登记任务协作者也不生成第五战斗位 |
| 正式资格 | 各人事件节点、本人同意、尚未解决的具体分歧 | 正式资格只授一次；可选择立即入队或留驻 | 满队不使已授资格丢失；角色没有空档时记会面约定 |
| 替换队员 | 安全点、双方能真实会合、被换下者去向 | 新编队、留驻地点、借装交接、日程 | 两人不能有一人凭空消失；未完成交接前存档失败整体回滚 |
| 普通暂别/回职责 | 当前任务有无必须在场者；确认归还选项 | 保留资格、成长、关系；更新位置与可邀约窗口 | 未在队不惩罚私人关系；未接的邀请无背约 |
| 强制分离 | 只来自已排期事件；事先列明物品与接续方式 | 保留本人装备/成长；玩家借物送已存在安全保管处；任务证物维持可访问 | 技术异常不写离队事实；未能写档则恢复原编队/物品状态 |
| 重邀/修复 | 本人在可会合地点、具体争议已处理、未触发负责篇明确永久结果 | 恢复可用状态，承认旧经历的对白 | 不重新初始化、不再发入队装备、不把关系重置为新朋友 |

补充方案规定上阵默认4人含萧白；数量方向与现行基础一致，但全员接入仍需逐人验收。主要任务不以某一可失去角色为唯一钥匙；替代由原任务负责篇定义为公开资料、非同伴职能帮助或另一路行动，不能凭空复制同伴能力。

### 3.3 首次配置、追赶与物品账

补充方案：首次初始化凭`initializationVersion+characterId`执行一次。先检查存档已有临时参战记录；有记录者保留个人经验、点数、功法和装备，再按明确差额迁移，不能用入队模板覆盖。暂离期间只有已完成、可追溯的职业/训练节点才给个人经验；共享历练按[现行规则](../shared-insight-pool.md)使用，裴知古排除普通战斗经验与未在场补记。固定入队配置未定的人保持“待接入”，不要运行时向主角看齐。

每件可交接物必须带实例ID、`owner`（玩家/角色/组织/任务）、`custodian`（当前持有）、`loanEvent`、消耗许可、返还地点。普通共用消耗品只返剩余量；消耗日志不变回原数量。玩家借出装备可普通暂别时收回，强制离开时进入当前已存在保管处；没有可访问保管处的剧情不得通过接入验收。角色自有装备随人保留，不能用卸装把其固定形象变成不合剧情状态。纪念物领取与正式资格分别去重；没有正式确认的纪念物不预发。

## 4. 传承发现：所有来源都能解释为何可学（B10）

### 4.1 一个来源，一张学习信息卡

补充方案：为每门正式可学功法引用唯一`placementId`，不另抄门槛数值。卡片需要：功法/技能ID、来源种类、导师/授予方、地点、已知程度、公开线索来源、先修与属性、本人传授许可、在场窗口、费用/材料、是否一次奖励、失败出口、候补来源、不可传授原因、保存事件ID。

显示分三级：未听闻时不列导师姓名和隐藏地点；听闻后列“某处有人教这一路”及信息来源；亲见或取得可信授课线索后才显示姓名/地点、当前欠缺和预约。已知来源失效必须显示原因与能确认的下一线索，不谎称“老师还在”。没有替代老师的秘传明确写“本人传授”，不能为了兜底让普通店主代教。

许可判断顺序：**本人是否允许学 → 技能是否可传 → 取得来源 → 前置重数 → 属性 → 教师在场/可预约 → 材料费用 → 确认研习**。界面同时列出全部公开缺项，不逐次收费试错。送礼不能跨先修，持书不等于已学；成功学会第一重且书保留。基础课因师长临时离场，应在离场事件中提供延期或已经授权的代课，不临时指定无资质角色。

## 5. 关系轴、知情来源与责任（B13）

**2026-10-16用户确认单关系轴**：个人关系沿现行0—100四阶段；招募“信任”只是对同一关系及合作事实的称呼，不新建数值条；恋爱意向/结缘是事件资格，不再有独立情意值。吃醋与修复作用同一关系值，已结缘资格不因短期降值撤销。同伴之间交情沿`kinship`，组织/地方声望仍按对应公共事件分别记录，不能混入个人关系。旧`S.aff`不能直接等同归云`relations`，通信技能经验也不换关系值。

统一事件账`eventId / outcome / participants / witnesses / disclosedTo / deltas / permissions / promises / rewardKey`。同一结果可以影响多人，但每项影响必须有原因和知情来源。亲历者立即更新；远方人只有收到信、见到公开结果或完成传播事件后更新。传闻只改变“听说/待核”的态度，不提前写实锤处分。本人收到可信勘误后回退错误判断，保留原传播及纠正记录。

| 行为 | 可变化的轴 | 不随之自动变化 | 重复/补救 |
|---|---|---|---|
| 给苏芷合用的普通药材 | 本人关系，按现有礼物上限；若是任务交付另结任务 | 白鹇成员资格、行医权限、全谷声望 | 同一物品不能同时当礼物与任务数量；重复用现有减益规则 |
| 徐参与的裁断被实际纠正 | 已知情当事人的信任，公开受理后联盟记录 | 全盟认可、恋爱意向、入盟职务 | 后续可复核；重复读结果不再加值 |
| 完成岑的赔偿交接 | 受偿者对应事件态度、岑的履约事实 | 原侵害记录被抹除、全会免责 | 少赔部分仍未完成；私人礼物不能抵作赔款 |
| 协助沈交接证物 | 她对具体合作的信任、该差务许可状态 | 永久官职、巡江全部权限 | 隐瞒或损坏按证物任务补证，不靠泛用好感恢复证物 |
| 拒绝一次尚未承诺的任务 | 必要的对白差别 | 自动背约、自动扣所有人好感 | 之后在任务窗口内可再接；窗口后记录未参与 |
| 已承诺后爽约 | 仅知情相关人的具体失约记录 | 整队统一扣分、组织自动敌对 | 解释原因→重新安排/补做→本人回应；不能用刷新/重邀清除 |
| 承担本人职业责任并暂离 | 地点、可用日程 | 正式资格、已学、恋爱数值无原因下跌 | 按已有约定复邀；关系修复与职业交接各判各的 |

事件负责页填写实际增减值；没有明确数值时只写事实和对白，不能实现成隐藏默认扣分。相互抵触的事件按发生顺序处理且保留记录，不允许总分正好抵消就解除未完成赔偿。严重后果须有明确事件ID、前置提醒和本人回应；派系标签本身不直接触发永久离队。

## 6. 保存与验收清单

所有资格/身份/借物/事件结果先在状态副本校验，再一次持久化。成功后才切地图、发奖励和显示完成；写档失败保留可重试界面。旧档只迁移有依据的正式资格、既有物品和完成事实，未知关系保持未知，不补满关系、不伪造初识。旧档已获得资格不得因为新人物篇尚未播放而撤销；新增篇按“既有同伴回访”适配，保留兼容来源。

| 验收编号 | 输入/操作 | 必须得到的结果 |
|---|---|---|
| CF-01 | 满队接受体验、选择取消，再读档 | 资格、编队、借物数完全不变 |
| CF-02 | 正式授予但暂不同行，后续两次重邀 | 一份正式资格、一份初始配置；成长与装备实例不重置 |
| CF-03 | 借玩家武器给同伴，剧情强制分离，主线继续 | 武器进入可访问保管处；任务证物可用；不复制角色自有装备 |
| CF-04 | 知古不在队完成事件，随后重邀与回放 | 不补见闻、不重复升级书本；绑定册子仍归本人 |
| CF-05 | 给组织成员送礼至高关系 | 可增加个人交情；没有未授权的官职、仓库或秘传权限 |
| CF-06 | 教师外出且玩家满足全部学习门槛 | 已知信息提供实际预约/已授权代课；无教师或来源的秘传不假装可学 |
| CF-07 | 有书但属性不足，选另一位符合要求的角色研习 | 前者显示完整缺项；后者学第一重，书保留；个人独享禁学仍有效 |
| CF-08 | 公开事件、私人事件、假传闻、后续勘误依次发生 | 仅有知情来源者更新，事实/传闻分开，纠正不删除历史 |
| CF-09 | 退出某项受托身份再加入，重复交接凭牌 | 首次补给不重发；过期权限仍关闭；私人已学与责任保留 |
| CF-10 | 已招募旧档缺个人篇字段；迁移后读档两次 | 保留资格/成长，新增篇为回访适配，迁移不重发物品或关系值 |

这些是接入验收用例，本轮只完成设计和本地链接/登记核对，没有声称以上功能均已制作或运行通过。
