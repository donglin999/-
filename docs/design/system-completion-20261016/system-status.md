## 生活技能发布范围

沿2026-09-30决定，正式旅程的通用生活技能默认不开放；历史襄阳测试的临时授予不能影响正式新档。当前源码仍加载旧模块，属于已核实的接入偏差；本轮只更正文档并补正式整改合同，没有自行删除玩家记录。

建议实施时设一个有来源的发布配置，至少分：正式旅程、历史显式评审、培养独立活动。关闭应同时阻止旧全局入口、自动授予与NPC动作注入；不能只用CSS藏按钮、让底层仍改存档。

以下保持各自已采用行为：归云师承授课、剧情考校、同门切磋、培养生产、普通商店/对话、固定任务调查。它们不是“开通所有NPC江湖手段”的证明，也不因旧模块关闭而被移除。

验收：正常新档五技能未被临时赠送；旧档字段保留但暂停入口不重新开放；历史评审仍独立；地图、培养、战斗、读档后的按钮状态一致；关闭后普通服务/任务/既有切磋仍可走完。

## 已识别文档差异的处理

- 数值参考旧页的共享等级表述：按现行独立等级纠正，并保留全员初始配置未全迁移的边界。
- 招募旧17人：按登记与负责页分清18条现有图谱记录和殷红缨追加位；R1获准后已同步为19条同伴记录，殷的未细化五官仍单列。
- 知古旧游历后六节点入队：旧路线不再作为现行谷内入口前置；其后期个人篇仍可保留来源。
- 城市昼夜、耗时、按日/按旬限制：已明确的剧情时间点决定优先；具体新刷新表须标本轮提案。
- 141期与149期：属于不同预留范围，保留适用说明，不全局替换。
- 旧美术年龄/造型和四部分以前的编号：遵守豁免与历史追溯，不为检查清零批量改写。
