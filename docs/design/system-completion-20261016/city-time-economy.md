## 1. 已确认边界与时间键

**已确认**：2026-10-10 方案 A，活动、走路、休息不耗游戏时间，只由剧情时间点推进。特殊剧情夜只限制活动范围并处理对应夜景；固定夜景场所不需要等全城入夜。培养月份仍用自己的五期与体力规则，整月历练占一个月，不另发同月五期体力。

以下是使上述决定可执行的**细化提案**，不新增全局时钟：

| 键 | 含义与归属 | 可以控制什么 | 不能控制什么 |
| --- | --- | --- | --- |
| `cultivationPeriodId` | 培养系统维护的月／期 | 据点生产体力、药圃当期份额 | 城里休息不得推进它 |
| `visitId` | 一次正式城市历练，如年一五月汉皋 | 本次收入池、限定货架、离城结算 | 读档、切图不得换 ID |
| `beatId` | 剧情系统的 T1、T2 等稳定标识 | 可达范围、人物位置、服务次数 | 不按字符串大小推断先后 |
| `beatOrdinal` | 主线表中显式顺序 | 当票到期、跨点通知 | 不由现实日期或游戏帧数增长 |
| `instanceId` | 一张委托、一个教学或一次奖励实例 | 一次性取得与结算 | 同一事件换入口不能换 ID |
| `txId` | 单次已提交交易 | 防重复扣钱、发物、发奖励 | 不把按钮点击次数当交易完成 |

本月顺序引用主线表：`T1(0) → T2(1) → T3(2) → T3b(3) → T5(4) → T7(5) → T9(6) → T10(7) → F(8)`。数字是本合同计算示例，正式以剧情表版本为准。T5 允许跳到 T9；F 不再自行推进。M08 是离城结算，不擅自补出十日或月底自由节点。

一次推进应先计算预览，再让玩家选择继续或留下：

1. 校验当前节点、目标人物、必达前置；列出会截止的任务、会到期的当票、跳过的机会及目的地活动范围。
2. 预览期间不扣钱、不撤任务、不改时间；取消后原状态完整保留。
3. 确认后按固定顺序完成旧节点退出、区间内截止与到期、目的节点进入；一次提交保存。
4. 跳过的节点只处理其截止条件，不发其零工次数、委托奖励、库存补货或教学收益。目的节点只激活一次。
5. 载入已完成的推进事务只恢复镜头与当前目标，不再次调用奖励。中断在提交前回到旧节点；提交后回到新节点。

本节全部频次是**本轮建议的可实施口径**；原设计中的次数有注明出处，新增上限另标。

| 守擂 | 原案每胜 5文，三名守擂人、三位阶段擂主 | 建议按三组各四名对手的首胜实例记账，最多 12×5＝60文；同一对手重赛只保留练习，不再次发铜钱／物件；失败可重试 | 对手组需有独立 ID，不能用“赢的次数”充当领奖次数；重赛熟练等成长记入统一奖励预算，未配置则为 0 |
| 教学、雅集 | 作者配置 `instanceId + availableBeatIds` | 同一实例一次；按自然旬重复的旧说法撤回；跳过只失去明确提示过的实例 | 实例本身负责师承、关系与技能上限；不自行把每次听曲变成永久成长 |

| 住宿 | 建议通铺 2、上房 8、望江上房 20 按当前节点的房间使用权收费；周砚预付上房另记覆盖 `visitId` | 同点重复歇息免费；新的节点未覆盖则再次明示收费。歇息不刷新任务、次数或存货；特殊剧情“回房歇下”是独立推进按钮 | 保存房间权益；免收费不等于无限收益：歇息只恢复，不发成长或道具；露宿风险也固定为同点首次，不能连点重抽 |
| 典当 | 原案估价六成、三节点、赎回加一成；所有金额取整规则见第3节 | 到期不删物；转为对应流当记录；最后三个可达节点不足时的候选限制见下 | 当票只指向被托管的一件物，已装备／已托管／被任务预留的物不能直接典当；确认前要求卸下或说明不可用 |
| 赌坊 | 原案每点十局且净额 ±20；推荐首个正式片段不启用，保留原型 | 不能把每点可能赚 20 当稳定收入；开放前须确定概率、抽水位置和停止条件，随机事件结果与局号先固化后展示 | 如果后续按原上限开放，最多九点会额外出现 +180 U极端收益，应单独重算经济；本页 400 U候选池不含赌坊 |
| 出行、租马 | 按路线收服务费，不推进时间；租马建议 5文覆盖一趟约定行程 | 返程落点校验失败不扣费；先购未走可退，已完成不退；不能按现实日期续费 | 只保存路线通达／已访与已交费事务；路线距离的 `days` 旧字段不能兼做耗时 |

**典当边界实例**：T1（序号0）典当，`dueBeatOrdinal=3`。在 T1、T2、T3 可以赎回；确认进入 T3b 前明确提示“这张当票将到期”，进入 T3b 后流当。若 T3b（3）典当，到期为 T9（6）；T5 跳到 T9 同样会流当，不能因少点击一次推进延长。到期不依赖是否进入当铺。

**本月晚期典当的具体候选**：只在存在三个后续可达城内时间点时开三点当票，因此最晚 T7 可开，到 F 到期；T9、T10、F 不开新的三点票。界面解释“本月将近返程，此处不再开三期新当；仍可卖出普通物件”。这避免凭空设计跨月利息与外地赎回，但减少晚期周转自由。若要放开晚期典当，需要另选“跨访问保存并明确下次截止”方案；不能默认为离城没收，也不能阻止主线返程。此项列为待用户选择，不自动改代码。

**截止不等于刷新**：一张 T1 接取、F 前截止的委托在 T5 刷榜后仍可完成；未接且 T5 关闭的委托变为错过，不算玩家接单失败。任务道具由任务账登记所有权，过期时归还或保留由逐任务数据声明，不静默卖掉或吞掉。

旧方案风险可复算：五类零工按 8、5、4、5、5文，每类三次，单点上界 `3×(8+5+4+5+5)=81`，九点理论上界 729；加委托160、擂台60、支线100为1049。该算例尚未追加小游戏额外表现奖金，亦未扣特殊夜范围，不能当作实际全月可领，但足以证明仅靠“每点三次”不能保证300—450目标。独立原型目前仅两种工作，不能拿原型金额替代五类完整方案。

建议将原来的“可攒300—450”改作**普通完成度的毛收入观察区间**，候选最高现金投放400；净余额必须减实际采购。是否采用该解释仍待评审。真正必达任务不要求玩家达到300或把收入池刷满。

每条奖励配置需同时填：`silver, insight, proficiencyByArt, materialQty, relationDelta, cityRepDelta, firstOnly, poolId`。城市合同不另造等级经验；沿统一成长来源记账。未填写的列为0，不能按“完成委托”再隐式给全队一份重复成长。历练池及培养体力由各自负责文档维护，不在本页重新分配6720或1788的预算。

### 3.3 买卖、折扣与典当闭环

原案写“卖物六成”，独立原型 `RULES.sellRate=0.5`、典当0.6，属于未确认的两种口径。**建议候选**：卖普通物取估价五成，典当六成；不暗改原文为用户已确认。正式价格依据物品目录，折扣不会改变物品估价。

- 候选取整：购买、鉴定、强化、赎回费用向上取整；卖出／典当收入向下取整。店铺好感与讲价叠乘、最低七折沿原案；优惠不能乘到玩家卖出所得。
- 特征折扣合并的本轮候选：特征提供的额外折扣最多15%，在关系与讲价后的报价上再作用；最终仍受七折底价及可售回价+1约束。该提案取代特征旧稿“所有商店折扣总和最多15%”的歧义，未自动改运行公式。例如100×0.85×0.9×0.85=65.025，按总底价支付70；没有特征时77（费用向上取整）。
- 同物估价100：最低购价70，卖回50，单轮亏20；典当60、赎回`ceil(60×1.1)=66`，借款成本6；流当回购`ceil(100×1.2)=120`，无额外折扣。回购物始终对应原件，不能同时仍在旧背包。
- 店铺首次加价、以旧换新、半价修复分别有服务范围；不得把“修复半价”作用在买入价上。以旧换新按原案五成抵扣，旧物随成交移出，取消无副作用。
- 鉴定可能增加一次性物件价值，不等于所有未知货可无限重购。未辨库存必须有限、结果在物件首次进入世界时固定；不能用刷新种子重抽丙级货。
- 采购赠礼后关系提升，原物已消费；因关系折扣下降而赚差价仍须通过最低买价高于回收价校验。
- 强化费与材料价值计入成本，卖价不补偿全部强化投入；+1—+3与8%是旧未确认方案，只在平衡评审通过后开放。对未定稿装备不先兑现永久战斗数值。

### 4.3 鉴定归属与明确取舍

- 付费鉴定由钱守拙服务提供，原费用丁2、丙6、乙15；未知品阶如何报价尚不确定。候选统一先报原型的4U并一次完成，不在揭示丙／乙后补收。若要按品阶收费，应先免费给出可解释的外部等级判断再报价。
- 自己看沿生活技能“察看辨识”的师承与阶段，不再叠一根城市0—100的独立熟练度。原城市+3/+1与30/60阈值暂作旧原型规则，推荐正式接入时撤下；如果保留独立古玩鉴定，必须先说明它与生活技能的分工。此为待评审取舍，不擅自恢复暂停技能。
