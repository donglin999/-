# 探索接入与通关后的产品边界

状态：草稿　最后核对：2026-10-19

2026-10-16。覆盖C04、A03，设计补充。既有野外合同继续负责警戒、追击和清场机制；本页只补当前地区迁入及通关后的交付边界。新产品取舍是本轮提案。

## 当前区域明雷接入

不得把旧黑风寨试点的地图坐标、休息价格、等级比较或两群配置直接搬到栖河和汉皋。每个新区域需填写一张遭遇卡：

| 字段 | 内容 |
|---|---|
| region / encounterId | 正式区域与唯一敌群ID，引用地图登记 |
| storyAvailability | 哪个已发生事件之后存在、何时清除；普通刷新不能复活已结束的剧情敌对 |
| role | 可绕普通群、资源守卫、精英或剧情战；不混用首胜与普通掉落 |
| route | 入口安全区、可绕净宽、追击与返回路线、战后分离点 |
| partyBudget | 按当前阶段固定配置、2/4人队、宠物、最低技能与补给预算验证 |
| reward / repeat | 正式奖励表、首次标记、可重复收益和刷新事件 |
| pause / return | 对话/菜单/加载暂停；逃跑、败北、异常恢复职责 |
| assets | 地图代表、战斗敌群、音景与掉落语义一致；素材按正式清单采用 |

先选一张现有正式城外图验证，只有该图与任务责任明确时才配置敌群；当前合同不擅自新增一条正式道路或在安全城内刷敌人。

必须检查：入口不被堵、低练度可绕、NPC交谈不被偷袭、同帧只开一场、战后不立刻再次碰撞、切图/菜单/读档不重刷、正常休整不改变剧情旗标。新增危险提示依据实际队伍与地区预算，不继续沿旧“共享等级”假设。

## 通关后游历

建议首版只交付结局前独立手动节点与结局回看，明确通关后是否仍可自由行动；尚未制作后日谈城市状态时，不把旧城图开放为“完整通关后世界”。

结局一旦结算保存结局输入摘要与输出版本。回看只播放文本/图像，不重新打战斗、不改变人物关系、不再次发奖励。若未来开放结局后游历，读取独立postgame状态，不覆盖原结局证据。

## 新周目

本轮建议默认无数值继承：新旅程仍按正常开局。可在后续提供已看剧情快进、已解锁图鉴的独立收藏视图；收藏视图必须明确不等于新旅程人物已认识或线索已获得。

神装、历练、武学、关系与金钱均不自动跨旅程复制。若以后加入继承模式，作为独立配置明确可带项、上限、剧情解释和成就边界，并保留普通新档。

验收：回看/快进不会跳过未做选择；新档没有旧关系与证据；手动节点永不被结局后的自动保存覆盖；已失效版本的结局仍可按原摘要回看，不能重判为另一条结局。
