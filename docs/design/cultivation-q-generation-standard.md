## 硬性参数

| 项目 | 标准 |
| --- | --- |
| 新生成试图 | 请求 1024×1536 PNG；实际原生尺寸必须另记，尺寸不符不得靠拉伸伪装 |
| 背景 | RGBA 真透明；四角 alpha=0；主体外不得有可见底板、阴影盘或光晕 |
| 构图 | 完整发顶至大腿中段；脚仅用于全身白模检查重心，不进入本对白裁切 |
| 安全边距 | 发顶和必要的手／道具距边至少 3% 对应边长；衣摆在底部裁切允许，手／道具被切断不允许 |
| 白模基准 | 可见画布 1024×1536，全身重心草模 1024×2304；头顶 y70，头高约590px，肩 y740–770；逐角色骨点与接触点见 frozen-poses.json |
| 比例容差 | 对冻结白模头顶至下颏高度误差≤10%；发型宽度可以因角色差异调整，但必须人工记录，不能改白模迁就失败图 |
| 显示 | 等比缩放；按头部锚点校准同组，不能用不同裁切的素材直接按图片框高度当人物身高 |
| 同屏校准 | 相同年龄体型等级的头高差≤10%；明显年龄／体型差异须有角色卡说明；身体高度不能靠非等比拉伸 |
| 桌面验收 | 1280×720、1440×900、1920×1080；双人和三人对白均检查；当前不把手机作为交付门槛 |
| 清晰度 | 保留既有大头紧凑上身、短颈、手绘色块、深色变化轮廓；禁止像素马赛克、糊化、过量布料微纹理盖过大色块 |

旧的 1145×1374 透明图和已存 1024×1536 图属于历史资源，保留原稿和尺寸；不能声称已经重新生成。接入时先量头部锚点，再与同组比较。不得给每个人独立加无限放大／向下裁切来掩盖构图差异。

## 身份与动作

1. 角色卡锁年龄、脸型、发型、胡须、衣服层次、颜色、道具归属。陆衡30岁；叶蘅22岁医者便衣；萧白24岁初学者，无凭空佩剑。服装随剧情阶段变化另建基准。
2. 同一对白组先分配动作家族。周砚背手观察，陆衡低位提既有包，叶蘅双手整理药布，萧白倾听，不统一使用胸前摊掌。
3. 两个角色至少有两项可见结构差异，其中一项是手臂动作或物体接触；镜像、换脸、换衣服不算动作差异。
4. 姿态卡写解剖学左右手、肩肘腕位置、视线、重心、遮挡与道具接触。手在腰后不可绘成腰前；提包必须实际抓住布结。

## 固定流程与交付门槛

剧情出场名单 → 身份基准 → 每人姿态卡 → 同尺度可见／全身白模及剪影 → 单人与整组人工检查 → 冻结参数、文件哈希 → 每人单独生成 → 原生文件检查 → 单图、同屏与实际对白截图 → 采用或退回。

每次生成必须实传本人身份图和本人冻结白模；提示词逐张保存，不用另一角色的姿势作本人基准。试图需要修正时保存新版本、提示词与参考路径；不得剪贴手脚、拉伸人物或把白模改成失败图的姿势后宣称通过。

机器检查 PNG 解码、尺寸、alpha、四角、参考和哈希一致、资源能加载、UI边界和浏览器异常。人工检查年龄／身份／画风、头部锚点、肢体结构、手与包接触、同组动作差异、对白框是否遮住关键动作。alpha 通道存在不等于没有光晕；图像工具的黑色预览也不等于真实不透明背景：必须叠到白、灰、场景底图复核。

清单状态使用 existing / generated / rejected / review-candidate / adopted。只有单人与同屏、实际UI检查全部通过，才能标 adopted 并修改运行时映射。截图、人工判定和自动检查结果同时留存；自动检查不能替代美术验收。
