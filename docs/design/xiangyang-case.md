## 在三年故事中的位置

年一夏，萧白与叶蘅为村民药材、路上生计或旧讯来到襄阳。挑夫老周当街中毒，苏芷施针，叶蘅参与救治。二人从铁臂帮收例钱和疤脸刘接触过茶碗入手，取得解药，追出药源与帮会的联系。此案让叶蘅亲眼见到白鹇谷医术，也让苏芷看见她的能力。

| 原剧情节点 | 新用途 | 必须调整的地方 |
| --- | --- | --- |
| 老周中毒、街市问线索、茶摊对质 | 本事件的必经调查与救治 | 萧白和叶蘅原本已相识、已在培养阶段；叶蘅不能从场上消失 |
| 苏芷施针、青蚨散瓶、解药 | 苏芷登场及白鹇谷分支的可信开端 | 苏芷可引荐，但不直接许诺收徒；叶蘅医案由本人决定是否递交 |
| 渡船、东岸暗桩、黑风寨 | 案件进一步追查和独立外出历练 | 可决定追查深度；没打穿山寨也能救老周、完成叶蘅分支前置 |
| 大黄 | 地方事件中可结识的宠物 | 收养后按[队伍与宠物](party-pets.md)自动行动，队尾跟随 |
| 羊皮图、老僧身世、落草结局 | 仅按新主线需要挑选重写 | 不再揭示萧白“苍龙之子”；投匪只能影响地方案后果，不能直接结束全作 |

## 案件结案与主线接回

保底结案是救下老周、确认青蚨散外流和疤脸刘的责任；可选追查将铁臂帮、黑风寨、青蚨柜供毒链串得更完整。完成后，苏芷可联系白鹇谷医师，叶蘅据亲历事件选择下一阶段。案卷可在后来作为“门派禁方流出”的支线重访，但不强行证明叶家药方与青蚨散同源。
