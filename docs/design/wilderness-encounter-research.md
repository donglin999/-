# 野外遇敌调研：八方旅人、逸剑风云决、大侠立志传

状态：现行　最后核对：2026-10-19

日期：2026-10-01。状态：**调研与小江湖建议，未开发、未定稿**。八方以《八方旅人 II》为主要样本；昼夜机制不能套用到一代。逸剑、大侠的部分详细资料来自2023年首发/EA阶段；机制与版本范围分别标注，不把历史参数称作现行精确规则。

## 1. 先分清五个设计问题

1. **世界地图旅行**：地点选择、旅行成本与途中事件。
2. **场景内发现敌人**：敌人可见、不可见，是否巡逻和追击。
3. **进入战斗**：随机触发、接触、警戒识别、主动交互或剧情。
4. **战斗后的世界**：敌人消失、逃跑返回点、场景刷新、故事后果。
5. **反复探索的成本**：绕路、药品、时间、重复战斗与收益。

“明雷”表示敌人在探索地图可见；“暗雷”表示探索时未显示对应敌人而触发随机战斗。明雷不等于一定有视锥、追击或背袭；回合制/即时制是战斗内规则，也不决定遇敌方式。

## 2. 三款游戏对照

| 维度 | 八方旅人 II | 逸剑风云决 | 大侠立志传 |
| --- | --- | --- | --- |
| 常见野外遇敌 | 路途/迷宫随机战斗，暗雷为主 | 地图可见敌人，接触后进入战斗；另有剧情战 | 地图可见敌人，侦察/潜行与事件参与触发 |
| 玩家预判信息 | 地区风险、队伍资源；触发前通常看不到本次敌群 | 可见敌人位置；开发资料展示过难度颜色提示 | 可见敌人位置，潜行资料展示侦测区域和发现进度 |
| 探索中的避战 | 减少随机遭遇、快速移动到已知地点；不是地图上绕开一个敌人 | 明雷提供绕行机会；是否绕得开取决于地图净宽 | 绕行、潜行等待敌人走位；基础移动较慢时付出时间成本 |
| 战斗空间 | 切换至队伍回合战斗表现 | 进入格子战场，可选择回合/即时模式 | 场景内网格战斗；需要核对参与范围和对象 |
| 反复战斗来源 | 再次经过危险区域仍可能随机遇敌 | 官方发行方明确敌人会随时间刷新 | EA补丁曾修复野怪突袭击杀后不刷新的问题，说明普通野怪与特殊人物须区分 |
| 核心设计作用（分析） | 用随机战分配路途资源压力 | 用可见敌群给路线和刷取目标 | 将敌人纳入可交互的江湖场景 |

上述机制的证据见下一节。末行是本次设计分析，不是制作人原话。

## 3. 逐款拆解与证据

### 3.1 八方旅人：路线风险与资源消耗

- 野外以随机遭遇为主，探索阶段通常不能按敌人的具体位置绕行。[实玩评测](https://www.gamerevolution.com/review/935199-octopath-traveler-2-review)
- II的昼夜可主动切换；其作用还包括人物状态和场景指令变化。[官方系统介绍](https://www.jp.square-enix.com/octopathtraveler2/system/)
- 攻略资料记录II中夜间遭遇更频繁、冲刺增加遇敌风险、学者辅助能力能减少遭遇。这里仅采纳方向，不采用社区给出的具体倍率或步数公式。[遇敌攻略](https://game8.co/games/Octopath-Traveler-2/archives/404769)、[玩家交叉记录](https://gamefaqs.gamespot.com/boards/380184-octopath-traveler-ii/80348155)
- 战斗利用弱点破防与Boost提供解题空间，所以敌群构成应承担战术变化。[官方系统介绍](https://www.jp.square-enix.com/octopathtraveler2/system/)

**分析**：危险路段可以不摆大量敌人精灵，遇敌后组合也有变化；但玩家找路、找宝箱和往返时会被不可见战斗打断。减少遭遇手段本身也成为养成选择。

**可借鉴**：区域风险提示、地区敌群池、组合变化与资源节奏。**需要谨慎**：把冲刺和更多战斗绑定，会让快速跑图的便利受到惩罚。

### 3.2 逸剑风云决：可见敌群与重复历练

- 首发实玩评测明确记录探索地图接触明雷敌人后进入格子战斗。[IGN中国评测](https://www.taptap.cn/moment/452033800017283731)
- 发行方在2023年开发进度中展示绿色较易、红色较难的敌人提示。这是已有设计实例，不据此推断当前完整颜色公式。[官方开发进度 #2，Wandering Sword部分](https://store.steampowered.com/news/posts/?enddate=1685631684&feed=steam_community_announcements)
- 官方发行方在缺陷反馈中说明敌人随时间刷新，并未确认“打开菜单就刷新”。[发行方回复](https://steamcommunity.com/app/1876890/discussions/0/3759978601806335773/?ctp=7)
- 回合和即时战斗可选择，是进入战斗后的执行方式。[发行方介绍](https://www.reddit.com/r/JRPG/comments/10v8q03/were_the_publisher_of_wandering_sword_a_martial/)

**分析**：位置可见让玩家知道哪里会打、哪里值得去；固定敌人分布适合材料和战斗成长的重复历练。狭窄道路、同质敌群、快速刷新仍会把往返变成重复劳动。即时模式可缩短战斗，但不能替代遇敌节奏设计。

**可借鉴**：敌人可见、危险可预判、敌群与地理分区关联、普通历练和剧情战分开。**待核实**：当前精确刷新周期、追击半径、是否有固定先手规则；不把玩家所说的“五分钟”直接写入本作规范。

### 3.3 大侠立志传：敌人是场景中的对象

- EA探索攻略展示可见野猪、潜行按钮、红色侦测区域、敌人问号充满后被发现，以及等待走位绕过的办法。[地图探索攻略，2023-03](https://www.gamersky.com/handbook/202303/1577357_5.shtml)
- 同一资料记录大地图地点旅行和时间/体力成本；应区分地点间旅行与局部场景中的敌人发现。[同一探索攻略](https://www.gamersky.com/handbook/202303/1577357_5.shtml)
- 2023-03-22补丁记录“突袭击杀野怪后不再刷新”的修复，能支持普通野怪存在刷新机制，不能据此推出所有NPC复活或统一刷新周期。[历史更新记录](https://news.17173.com/z/dxlzz/content/03262023/095808950.shtml)

**分析**：避战是场景行动的一部分，位置、敌人走位、侦测反馈共同提供选择。采集点、宝物、支线人物与敌群可以共享地图，让敌人承担守护、阻拦、威胁等职责。不过潜行、关系、特殊手段、战斗参与对象共同增加实现复杂度。

**可借鉴**：敌人有活动范围和地理职责、发现过程有反馈、危险区域存在绕行路线。**暂不引入**：完整潜行/突袭/点穴/窃取成长系统；用户已要求生活技能暂缓上线。

## 4. 证据边界与未确认项

本次为网页资料调研，没有对三款现行安装版本进行逐帧实测。官方/发行方资料优先，无法覆盖的具体遇敌行为采用有日期的实玩评测与攻略；玩家帖子仅用于交叉观察。大侠官方Wiki此次无法读取，不把不可读页面当证据。

- 八方：未确认精确距离阈值、步数公式、跑步/昼夜倍率，以及各区域例外；一代、II、0不可混写。
- 逸剑：未确认当前精确刷新周期、开菜单是否暂停计时、不同敌人追击和接触边界、当前自动战斗便利功能的版本细节。
- 大侠：未确认现行刷新时间、侦测累计/衰减公式、不同NPC的敌对传播、全部脱战条件及普通野怪与特殊头目的例外。
- 未核实三款的统一掉落概率、经验系数、首杀奖励、逃跑成功率或失败损失。建议方案不得伪称这些数值来自原作。

## 5. 小江湖建议：可见敌群为基础，少量剧情伏击

以下方案已获用户确认；2026-10-01 第一版实现与参数见 [实施合同](wilderness-encounters.md)。本节保留调研时的方案依据。保留现有独立战斗舞台，不要求为了明雷改成场景战棋。

### 区域与职责

| 区域 | 建议遇敌内容 | 探索职责 |
| --- | --- | --- |
| 城内（如汉皋）、正常渡口服务区 | 日常不刷主动敌群；由已存在案件/剧情触发战斗 | 对话、交易和调查流畅，保留城市烟火气 |
| 官道、城外普通路线 | 少量可见路匪/野兽群，主通路保留可绕净宽 | 展示路途风险，控制第一次出城压力 |
| 林地、偏路、资源点 | 可见动物与少量危险群，资源附近配置守护敌群 | 玩家主动选择战斗换取探索收益；不是所有宝箱必须打 |
| 山寨、洞窟、敌方据点 | 可见岗哨/巡逻/头目及明确剧情战 | 突出势力控制和推进目标 |

这些是区域类型举例，不自动新增尚无剧情责任的地图或动物。

### 最小规则

1. **可见且可判断**：地图上的一个敌群代表一场明确遭遇，显示名称、敌意和大致危险；战斗敌群类型须与地图所见一致，不能一个狼精灵突然变一群山贼。
2. **发现有过程**：正常警戒→注意玩家→短距离追击→进入接触范围开战；用小符号/声音提示。敌人不会隔墙发现或无界追到城里。主动挑衅可以直接开战。
3. **基础绕行即可避战**：第一版不要求生活技能，也不加潜行等级、视锥成长或背袭奖励；地图留真实可走的绕路。
4. **减少连续打断**：进图入口、剧情对话、菜单和加载阶段不触发；战后/逃跑后的短保护窗口与分离点避免立刻再撞同群，保护期间主动开战仍可用。
5. **刷新可追溯**：普通群、精英和剧情人物分开。首版优先“本次探索击败后保持清除，返城休整后再刷新普通群”；切图、开菜单、读档不单独重置。精英周期后续调，剧情人物跟旗标走。
6. **奖励有分工**：普通群提供基础成长/常见材料；精英提供明确的稀有目标；任务证物和剧情进度不能靠普通野怪随机掉落。避免全城巡逻兵被当成刷材料资源。
7. **弱敌与回程减负**：已清理道路保持通畅，普通弱敌可降低主动性；保留手动和现有测试自动战斗。自动战斗不作为高密度刷新的补救措施。
8. **伏击必须可解释**：只给少量已写入剧情的伏击，先有脚印、喊声、路障等铺垫；地图没有敌人时不在城中突然随机开战。

暂不定硬数值：警戒距离、追击范围、保护时长、每图密度、战斗时间与刷新时机要在一张真实城外测试图上验证，再写入正式契约。

### 第一版验收重点

- 敌人不在入口脚下刷新，不堵唯一出口，注意符号不遮挡地面动线。
- 看见危险后有时间绕开；暂停、对话、菜单不会被偷触发战斗。
- 连续碰到同群只启动一次；逃跑、战败返回可行动的位置。
- 战后清除、普通群重刷、剧情人物状态均能存读档，不重复发首次奖励。
- 返程找人/交任务不被刚清理的路线反复打断。
- 地图敌人种类、战斗编组、背景、音景、战利品一致；敌人素材按角色规范复用和制作。

## 6. 本次结论

先借鉴逸剑的**可见敌群与危险提示**，加上大侠的**活动范围和避战反馈**，利用八方的**地区敌群组合和资源节奏**。第一版以简单绕行和少量剧情伏击完成野外风险，不恢复已暂缓的生活技能。用户确认后，已完成黑风寨偏路试点的代码、动线检查、清场与休整状态，并整理待统一制作的素材清单；正式范围及验收见 [实施合同](wilderness-encounters.md)。本轮没有生成素材。
