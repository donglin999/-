## 2. 实体与意象的边界

| 用途 | 应画内容 | 禁止的混用 |
| --- | --- | --- |
| 包裹中的装备、药食、工具、证物 | 对应真实物件：剑、护甲、酒壶、茶碗、货签等；材质与磨损符合用途 | 把证物统一画为金色宝物；把全部药品画为同一种宝瓶 |
| 包裹中的可学习秘籍、残卷 | 实体书册、残页、手札或竹简，须符合该物件定义 | 用秘籍物件图代替学会后的武学图 |
| 已学功法／招式 | 技法意象：剑气、掌势、虎势、流风、针路、冲击、恢复回流 | 写实手臂、实体教材、摆放的兵器、通用修习者 |
| 已学心法 | 内息组织和精神意象：吐纳、阴阳、沉静气旋、山岳、流云、水火、叶脉般生机 | 书卷、经页、香炉、玉盘、坐垫、整尊佛像或器物堆叠 |

掌势是由气劲与墨彩形成的技法形态，可以体现掌力轮廓，不能出现肤色、肌肉、手臂、衣袖等实体肢体。虎、龙、叶、山、水等可以作为气劲意象，不据此新增真实召唤兽、仙术或世界设定。针法表现精密线束与落点意象，区别包裹中展开的针囊。

每门武学先写“这门技法如何形成这个轮廓”；不能批量生成一个换色旋涡。图标语义取自现有名称、说明与实际作用，不由生成模型推测玩法。

## 3. 五档的设计增量

| 品阶 | 装备造型 | 功法／心法意象 |
| --- | --- | --- |
| 丁 | 简单、可靠的形制；清楚木纹、铁面、粗布等自然材质；一个主要辨识点 | 一个清楚主形，简洁气流／冲击，灰白为等级辅助色 |
| 丙 | 精制刃脊、护手、柄缠或缝制；两个明显辨识点 | 有组织的主副轨迹，青蓝为等级辅助色 |
| 乙 | 独有刃形／护手、镶嵌、剑穗等形成新轮廓；细节主次清楚 | 独有技法形态与第二层气劲，淡紫为等级辅助色 |
| 甲 | 复杂护手、鎏金嵌银、名匠刃纹、精致剑穗与集中局部锋芒 | 完整多层意象、主副高潮与清楚收束，赭金为等级辅助色 |
| 绝 | 标志性结构、组合材质、丰富装饰和受控气劲辉光；轮廓仍可读 | 传承／个人身份鲜明的完整意象，朱砂辅暗金为等级辅助色 |

同类跨阶至少改变轮廓／结构和材质／关键细节两项。高级不能只是换色、加框、加散点或让整个主体发白。丁级也要精细，甲／绝不能依靠更多模糊辉光掩盖主体。

等级色为辅助，技法语义色可以保留：医术生机用绿与纸白，毒术可用幽绿，剑气按技法设计。不能让所有同阶图标都是相同形状、相同色的光球。

品阶定阶表仍按 [统一方案 §7](grades-and-skill-vfx.md#7-现有内容的初次定阶草案) 作为建议映射；画风通过不代表品阶字段、平衡、战斗演出已接入。

## 4. 当前内容范围与章节标记

现有菜单图标键为 **30 个物品／装备、22 个招式、13 个心法，共 65 个**。数量来自现有映射，是资产目录规模，不是襄阳演示可获取内容数量。

每件必须标记：

- `current_chapter`：襄阳现有剧情、商店、初始队伍或实际敌人使用的内容。
- `reserved`：现有数据或映射保留、当前章节尚未开放或剧情责任待核定的内容。
- `sample_only`：跨阶造型验证样张，没有实际物品／技能 ID，不进入运行映射。

`js/menu.js` 的 `mnXfOn()` 在 `S.chapter≥2`（进入培养）或显式心法调试入口开启；13 个心法原稿属于预备素材。不能因素材生成而给襄阳演示解锁心法、默认习得全部门派武学，或声称培养部分的 `todo` 特性已完成。`xf_can` 是内息残札物件，也须保留培养部分用途说明。

已有襄阳要物如茶棚旧盏、东津渡货签，按粗陶／木签的真实质感生成；关键剧情用途不提高物件品阶。旧门派、残图、书匣等条目须核定当前剧情用途，不能将旧原型素材自动升级为绝级传承。

## 6. 单件生产与记录

逐件完整提示词与范围清单：[`xiangyang_icons_v3_manifest.json`](../../tools_scene/xiangyang_icons_v3_manifest.json)。清单版本、生成进度和实际图像必须一致；不能仅有提示词就标记生成完成。

- 原稿建议至少 512×512 RGBA、透明底；运行单格 192×192，平滑缩放。
- `raw/` 原稿保留完整原始像素；打包工具另导出 `production/` 的 512×512 生产帧，以纯布局缩放和透明画布居中提供四边至少 48px 安全边。只做必要的缩放采样，不重绘图案、不抠背景、不调色；源图已裁切不能通过补透明边修复。
- 运行图集元数据的 `revision` 为实际 WebP 文件 SHA-256 前 12 位，用于图集缓存版本；类别、键位和 192px 格尺寸保持不变。
- 主体占画面约 70–80%，安全边至少 8%，尾迹和剑穗不能被切断；同类保持相近视觉占比。
- 固定参考来源与风格版本，逐件保存 ID、名称、类别、建议品阶、章节状态、主体语义、禁用元素、完整提示词、原稿路径、模型返回记录与审核结果。
- 生成清单负责区分待生成、已生成待审、通过、退稿、已接入。原图成功返回仅代表“已生成待审”。
- 先制作对应真实内容的原稿，再做实际尺寸对照。后续增量复用本页与批准图，不从已作废的实体武学提示词继续扩写。
- 生成、切图／缩放打包和运行引用分别留证；不覆盖无法追溯的旧原稿。复用／重做／退役逐 ID 记录。

## 7. 验收与退稿

每件在 48/56/72px、宣纸与深墨背景、灰阶下审阅：语义一眼对应、轮廓有区分、画风一致、透明边缘干净、无文字和生成残片。武学还须核对意象是否有技法依据，装备核对等级结构是否实际可见。

下列情况必须退稿：学会的武学画成实体手臂／书卷／器物；多个技能只有换色差异；透明区夹带底板；高阶只有模糊光球；名字、主体和真实用途不符；细节仅在大图可见、缩小后轮廓消失。

图集覆盖测试、代码测试与视觉审核分别提供证据。运行接入前校验所有键位和槽位，检查行囊、装备、武学、悬停与深浅背景。章节门控保持原逻辑。上线状态须以实际发布和线上画面核实，不能由文档或本地原稿推断。

## 8. 本批实测补充的防复发规则

- 原稿生成成功仅记为待审。运行48/56/72px以production透明规范帧为准，不拿带大量空白的raw整幅缩图代替实际图标；同时检查raw是否裁断主体。
- 成组比较相近技法：拳脚用短促冲击星形，劈砍用厚斩弧；鬼头斩用棱角裂势，刮风脚用流风；翻江刺用紧凑交叉双刺与纵向破浪，区别柳叶三股上扬剑气。舔舐表现温息触碰和伤痕消退，不用泛用金色漩涡。
- 薄线/长条不能只靠加透明边过审；明亮主形在48px要能分出关键结构。零星尾迹不计入有效主体占比。
- 剧情标识逐件核对：解药瓶底青虫、乌木令牌背面浪纹、账簿油渍及末页青虫印。浪纹密札是窄油纸折条，不能画成绑绳包裹；箭镞不是整箭，竹片不是多片竹简。
- 单件不得生成正反双件图；原稿每次重做后更新SHA-256并重新审批，旧审批不适用于新图。`--install`须同时满足完整映射、透明几何、逐件approved及approval_sha256匹配实际原稿。
