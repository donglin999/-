## 培养从哪里开始

开始部分仍结束于山居第一夜。进入培养需要后续开场：周砚正式收萧白为归云谷弟子，与二人商量日常和基础教学，说明生活与学艺如何安排；叶蘅继续行医与保管遗物。萧白没有自动得到武功、剑、专业医术或所有生活技能。

开场先解释体力、年月和「结束本期」，普通说明免费。第一笔正式投入是B03站位与发力的5点基础课，教学与练习包含在这一次中。完成后才记录具体已学内容，并把下一步可以练什么显示出来。

## 首季开放范围

| 内容 | 起始／开放条件 | 首季可以做到什么 |
| --- | --- | --- |
| 基础站位B03 | 萧白已正式拜师，玩家选择首次5点练习 | 从紧张乱站到理解保护自身，后续练协调发力 |
| 步法B02、舒展B04 | 第一课完成并听过对应基础说明 | 独练与阶段纠正；护送中可使用学过的做法 |
| 吐纳B01、察势B06 | 后续明确指导时开放 | 基础练习，不是直接获得完整内功秘籍 |
| 听声B05 | 未来阶段课程占位 | 首季可知有此训练方向，不要求首季掌握 |
| 守拙拳法／试锋剑法 | 首月B03后周砚即可在K02／K01提供首次5点正式教学 | 招式页出现已学项目，可投入5点练招；暂未教学时保持未学 |
| 医理A02、辨药A03 | 叶蘅在场且愿意指导，玩家选择3点学艺 | 整理医案与普通药材；不独立行医 |
| 药圃P01 | 辨药基础与允许使用的工具已说明 | 照料或在限定范围采集普通材料 |
| 厨房P02、布包P03 | 完成周砚的家常炊事A05／叶蘅的普通布料课A06，工具实际具备 | 准备普通食物与日用物，产量待资源平衡 |
| 打杂D01—D05 | 事项有实际需求、材料和使用许可 | 用2点兼顾生活；不是直接刷满所有人信任 |
| 乡邻通信 | 已认识的人和陆衡等投递途径可用 | 捎信、收必要近况；没有传送人物功能 |
| 本地闲逛 | 地点已知且本期能往返，人物节点满足窗口 | 山居、药圃、安置点和近山事件；集镇按实际地理开放 |

首季暂不编排高级剑法、针攻、神兵锻造、毒药配制或全部艺术课程。新课只打开对应项目；首次教学与之后熟练的区别保持可见。

## 十五个时段的机会表

下表是信息与机会，不是强制行动队列。普通时段各有10点，玩家可以重复培养、参加事件或提前休息；三月中旬由短篇护送占用，余下十四期最多140点。全休息也能得到必要主线信息，培养与可选经历则不同。

| 时段 | 本期已知近况／机会 | 玩家可选择的方向 |
| --- | --- | --- |
| 一月月初 | 培养开场、基础教学说明 | 首次站位5；完成后再练开放基础，或打杂与休息 |
| 一月上旬 | 叶蘅整理普通药材，愿意说明记录与标签 | 医理／辨药学艺3，药圃人物闲逛6，普通打杂2 |
| 一月中旬 | 陆衡捎来必要乡邻近况，安置点回访开放 | 回访6、通信4、基础训练5；消息本身免费 |
| 一月下旬 | 已学课题可独练，周砚提供一次基础纠正机会 | 练功、学艺、生产或混合；不要求必须已经获得招式 |
| 一月月底 | 当月已知邀请仍按各自窗口有效 | 自行收尾，休息后显示本月简短总结 |
| 二月月初 | 周砚旧识回信由叶蘅先看，出现可核实方向 | 必要回信免费；有前情的长谈6，普通培养继续 |
| 二月上旬 | 已可受教的拳架继续练习，普通医案准备出现 | 基础指导5、医理3；学会后另期可练招式5 |
| 二月中旬 | 普通医案的人物节点开放 | 选择药圃／安置点闲逛6；有无此前帮忙影响做法 |
| 二月下旬 | 陆衡来客会面，护送前的行路话题开放 | 赴约6，或在他在场时选行路学艺3；两项为不同经历 |
| 二月月底 | 医案、回访和教学按实际完成情况回应 | 补已知机会、生产或休息；不强迫清空全部事件 |
| 三月月初 | 普通药包护送计划与同行人明确 | 训练、生产、通信；显示中旬短篇占期 |
| 三月上旬 | 最后一轮护送准备与陆衡会面窗口 | 选择自己的准备方向；没有材料也有求助方案 |
| 三月中旬 | 陆衡带队，叶蘅负责熟悉的医疗事务 | 整期短篇，零自由体力；按经历选择应对，不再扣一次菜单费用 |
| 三月下旬 | 返回山居，人物记得护送过程 | 周砚复盘或叶蘅谈话6，也可普通训练；必要结案说明免费 |
| 三月月底 | 首季生活总结，年一夏的已知出游安排逐渐明确 | 自由安排与休息；下一次整月地图另行预告 |

## 首季正式节点

| 节点 | 入口与成本 | 条件／可参与窗口 | 操作与差异 | 成果 |
| --- | --- | --- | --- | --- |
| S01 防身第一课 | B03，5点 | 一月起，尚未受过该课 | 慢练、说明紧张处或先在指导下尝试；不是善恶选择 | 具体基础已学与练习记录，开放后续基础 |
| S02 药圃的标签 | 药圃闲逛，6点 | 一月起，叶蘅在场 | 可帮记录、听她说明生活安排或只了解近况；是否学过辨药影响措辞 | 生活经历与后续医案前情，不自动成为医师 |
| S03 回访乡邻 | 安置点闲逛，6点 | 一月中旬至三月上旬的合理窗口 | 读取陈伯伤势；选择合意帮忙或记录需求，资源不够可请求协助 | 乡邻实际回响与后续委托，不转移遗物 |
| S04 问一段练习 | 山居闲逛，6点 | 第一课后、周砚在场 | 结合已练内容谈危险、耐心或困难；没有多练也能交流 | 师友经历，具体下一课题线索 |
| S05 普通医案 | 药圃／安置点闲逛，6点 | 二月起，叶蘅有此医案 | 学过记录者可以接续整理；未学者由基础介绍开始 | 一份共同经历与后续学习机会，救治由叶蘅负责 |
| S06 陆衡来客 | 山居赴约，6点 | 二月下旬至三月上旬，来访已知 | 讨论路线、乡邻或物资准备；不默认接下整套长期护送责任 | 会面与行路课机会，具体承诺另记 |
| S07 基础拳架 | K02正式教学，5点 | 首月起，周砚在场、第一课已完成 | 分解动作与收势，实际完成教学；不额外再收招式费用 | 正式守拙拳法学习来源，招式页开放 |
| S08 首次同行送药 | 三月中旬独占一期 | 必达短篇，陆衡和叶蘅同行 | 学过步法者尝试判断落脚，未学者由陆衡指点；资源不足有协助 | 实际护送结果，不要求战胜强敌 |
| S09 护送之后 | 山居／药圃闲逛，6点 | 三月下旬起，S08完成 | 选择与周砚复盘或与叶蘅交流；一次闲逛只展开一个主要谈话 | 对应人物经历与下一阶段话题 |

S01、S07是一次性教学，完成后对应训练可重复，不反复发新武功。S02—S06及S09是人物节点，读取实际前情。两场长谈不是一个免费月度夜谈包。旧识回信、护送邀请和必要结果不依赖抽中这些可选节点。

节点正式对白、数值与所有选择分支以后扩写；本轮已确定入口、费用、操作和应保留的前情，未声称完整脚本已经完成。

## 一项课程怎样写到可评审

**S01示例**：详情显示「第一次基础指导」「周砚」「体力10→5」「学会站位的基本要求」。按开始后，周砚先指出萧白遇到危险时习惯后仰，玩家可选择先慢练、问为什么或在指导下试做。周砚针对选择说明问题，再让萧白尝试；结果卡显示已受基础指导、当前练习进展和可练步法。没有发剑、教归元诀或给固定阵营阶位。重复B03改为今天实际要练的目标。

**S05示例**：闲逛开始6点后，叶蘅介绍一份普通医案。曾帮过标签／学过记录者能接续整理，其他玩家先了解她需要哪些信息；玩家选择帮记录、找普通物资或听她如何判断。关键医疗决定由叶蘅作出，收获是这份医案经历与相应学习反馈。下一次3点医理课可回顾这次记录，不能本次对白中又扣3点；不提供现实诊断教程。

**S08示例**：进入三月中旬先显示本期随队送药，菜单不能领取10点。沿途路况困难先给已学课题对应做法，再给陆衡指点／求助的基础通路，叶蘅处理医疗事务。完成后进入下旬，基础事实自动承接；是否另外选S09决定深入交流的内容，不能因没选长谈就丢失护送结果。

## 三种首季投入的差别

| 玩家倾向 | 可采用的组合 | 希望看到的成果 |
| --- | --- | --- |
| 武艺专注 | 同期5＋5，优先基础与已学招式 | 学过的做法在护送里可用，周砚评价具体；生活人物节点较少 |
| 生活与交游 | 6＋3余1，或3＋3＋2＋2 | 熟悉乡邻与叶蘅的工作，准备普通物资，人物回响较多；武艺成长较缓 |
| 混合培养 | 基础5＋学艺3＋打杂2 | 本领、生活与师友互相承接，显示三个不同来源的结果 |
| 全休养／忽略可选事 | 每期主动休息，必达短篇按期经历 | 主线仍可推进，护送有协助路径；不伪造技能或所有人物已深交 |

这些是可行方向而非固定最优攻略。首季只用140点上限检验选择空间，不规定必须花满或完成九个节点；年一夏整月地图进一步检验所学。
