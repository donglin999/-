# 势力与世界

状态：承接旧稿的三方动机；地理与年代采用当前项目可复用部分，属于**设计方案**。主线因果见[故事主线](story.md)。

## 时空与活动范围

萧白从现代来到南宋江湖。三年培养暂以约 1260—1263 年为时间框架，主要往返栖河村旧址、襄阳周边、周砚山居、白鹇谷及沿途城镇。历史大事作为背景压力，不要求三年主线延伸到 1268 年后的围城。栖河村和山居的精确地图位置待制作地图时核定，不能在对白里随意改动方位。

**周砚山居**是三年休闲培养的固定据点：有练武场、小药圃、厨房、书案和来客空间。它是私人住处及友人网络，**不是新门派**，不给萧白凭空授予组织阶位。玩家从这里训练、会客、外出，按月返回结算。

| 势力 | 合理目标与内部差异 | 剧情边界 |
| --- | --- | --- |
| 正道盟 | 有守护百姓的正直人士；裴嵩利用执事身份索《归元诀》 | 不把整个正道写成幕后黑手；裴嵩散讯需要证据链 |
| 玄烛会／归烬堂 | 底层有人抢夺玉匣，中高层有人讲承诺并愿意救人 | 救人不免除下属作恶的管束与赔偿责任 |
| 朝廷采办体系、地方巡江司 | 上层误信“延寿药”而催贡；地方人员先救灾、查案 | 续脉散不具长生功效；基层不统一反派化 |
| 白鹇谷 | 以诊治、辨药与针术为核心，有自己的入门规矩 | 苏芷只负责引荐，接纳叶蘅由谷中医师评估；叶家药方不作入门押金 |
| 铁臂帮、黑风寨、青蚨柜 | 襄阳地方事件中的帮会、山匪和供毒链 | 其案件能牵出更广江湖，但不替代叶家三方主线 |

白鹇谷与青蚨散外流的关联是苏芷个人调查，不意味着全谷配毒害人。旧稿中与栖灯馆绑定的弟子、管事及课程不直接迁移；人物可按独立动机重新安置，旧职务失效。
