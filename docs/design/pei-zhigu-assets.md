## 六张完整对白状态

| 状态／语义 | 表情与全身动作 | 双手、资料承托与用途 |
| --- | --- | --- |
| `neutral` 走神后倾听 | 单脚自然承重、肩颈松，翻页停半途后抬头看说话人，眼睛自然睁开、视线重新聚焦，嘴轻合或刚欲应答 | 左手托半合抄校册在腰侧，右指夹书签停页；纸册不能贴在空中。例：“嗯，我听着。这页先不翻。” |
| `happy` 查实欣喜 | 肩身舒展，向来人点头、真实笑意，不挥手招呼 | 左手将合册收至肋侧，右手轻举沾墨拇指展示核验成功；书的底边仍有掌与前臂承托。例：“找着了！这回是能对上的，不是我猜的。” |
| `sad` 为人惜字 | 头偏低看页、右肩落下，眼神柔沉、嘴角收住；身体保持对资料的注意 | 左手托开册，右指慢慢抚过被划去的姓名，不用全员收腰缩肩。例：“这页若只剩一个大姓，他们就又没了。” |
| `angry` 据理护证 | 身体侧转保护资料，抬下巴直视、眼微窄不笑；不是推出示停掌 | 左前臂将证据夹稳贴肋，右食指点册页证据处；拒绝他人取走／改写。例：“旧本还在，你不能替他们改名字。” |
| `surprise` 停页确认 | 颈向前核看，眉眼骤抬，嘴轻分；不同于后退手贴胸 | 左手把册抬到胸上稳托，右指停在翻到一半的纸边，双手接触清楚。例：“等一下，这一行……之前的本子里没有。” |
| `engrossed` 入迷考据 | 半侧前倾、前脚小幅探出，视线沉入细纹，忘记看谈话者；专注而非嬉笑 | 双手将折叠拓本展开到胸下，左手托底、右手捏纸角，纸张有厚度与自然折线；不画可识别UI文字。例：“先让我把这处缺口对上……啊，你还在等我。” |

无分离的表情图，也无额外欢迎基础；每种动作都有正在处理的事情。当前图像未生成时不可把这张表或六个ID算作六张成品。

## 单图生成约束

完整提示词须包含本人年龄、骨相、已锁定服装、上表该情绪的双手与资料受力、肩身、目光、重心及口眉反应；禁止用统一“愤怒推掌／惊讶贴胸／担忧双手收腰”覆盖本人的动作brief。原生调用提示词、输入参考、工具输出与hash独立保存，模型名未暴露如实记录`not_exposed`。

对白原生目标1024×1536、2:3、RGBA真透明；运行图512×768带alpha无损WebP，同一画布等比导出，不裁每张轮廓重心。菜单背景图与对白原生分开保存，不能自动抠整张菜单代替六种身体动作。

## 验收清单

- 六种身体与表情都能读出上表意图；与常态至少两类身体特征改变。`surprise`是在发现证据时停页前探，`engrossed`是继续读纹路忘记人，不能两张只是不同眉毛。
- 道具只有本人正常数量：两手两臂两腿两脚；纸册／拓本有抓握与底部支承，书签不变第三手或短刀，纸角不穿手，素发笔确在发中固定。
- 五官、透明镜片与细框链、栗黑低松双辫、丰满成年体态、燕麦白与茶金衣层、栗褐斜裹裙内衬和布囊位置一致。表情不默认半眯媚笑，镜片不遮掉眼神；不为了不同动作改服饰、拆掉眼镜或改变年龄。
- 浅深底完整检查细发、纸边、露肩服装边缘和alpha；双鞋、头顶、双手、资料安全边完整，无第三腿、浮物或假背景。
- 1280×720和1920×1080实际对白大小逐状态切换，再放大原生。与当前全员同情绪的愤怒、惊讶、担忧横排复审；不能只因为六张彼此不同就忽略跨角色同模。
- 内部美术接受、用户选定、预览显示、游戏台词映射分开记；当前章节不实装她，四向行走、战斗、语音都保持明确缺口。
