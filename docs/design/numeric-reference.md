## 1. 三款游戏分别参考了什么

| 游戏 | 现有设计中的参考 | 数值参考到哪一步 |
| --- | --- | --- |
| 八方旅人 I／II | 弱点破防、BP强化、支援与输出分工、完整的准备—破势—输出—恢复循环 | [八方调研](martial-review/octopath-research.md)与[招式合同](martial-review/move-contracts.md)已有逐项采用说明；本作的伤害公式、BP预算、治疗比例和回合目标自行设计，未核实或照搬原作隐藏公式 |
| 侠客风云传 | 有限时间的培养取舍、基本功与招式分开成长、师承和人物事件；练功效率与经验需求曲线 | [培养数值方案](cultivation-balance-20261012/README.md)与[培养验证](cultivation-balance-20261012/balance-report.md)已有课程、曲线和策略验证；这不覆盖游历、百级与全队敌人的完整平衡 |
| 逸剑风云决 | 武学修炼节点、练满后的价值、向NPC请教与门派分层传承、内外功和装备的组合 | [功法传承](martial-lineage.md)已有采用说明；尚无原作攻防、装备收益和各阶段敌人强度的完整对照表，也没有完成本作全体同伴的数值标定 |

官方材料能确认的范围：八方的[系统介绍](https://www.jp.square-enix.com/octopathtraveler2/system/)说明破防、强化与职业组合；侠客的[官网养成系统](https://wulin.fhyx.com/)说明固定回合内分配修炼、基本功、生产、闲逛与交友；逸剑的[发行方游戏介绍](https://store.steampowered.com/app/1876890/_/?l=schinese)说明武学、经脉与送礼／切磋／请教／结交同伴。2026-10-12已核对这些页面，未据此推定未公开的原作公式。

侠客经验曲线的具体数字来自现有培养方案标注的玩家实测，逸剑的具体修炼节点来自功法传承页标注的社区资料；它们的证据等级与官方机制说明不同。本作采用的是经调整的方案，不能称为三款原作的官方数值。

## 2. 已有具体数字不等于已经统一校准

- **培养**：新方案给出每自由期12体力、练功5体力、学习效率与A/B/C熟练曲线。例如固定效率E=6时，一次招式练习30经验，普通外功十重共需40次（含首次授课）；实际效率会变化，具体规则只在[培养数值负责页](cultivation-balance-20261012/README.md)维护。
- **战斗**：已有公式候选、行动与BP预算，以及离线模拟。普通3—5回合、精英5—7回合、头目7—10回合属于本作的待验证目标，并非这三款游戏的通用标准，详见[数值评审](martial-review/balance/README.md)。
- **同伴**：首次出场、正式入队固定配置统一由[百级与逐人等级](character-levels-100.md)负责；叶蘅已按追加确认改为3级。19位同伴的规划数值不等于全部招募事件已采用；定位、兵器和授业仍查[逐人配置](companion-power.md)。
- **现行8792**：普通人类同伴已保存自己的`lv/exp/pts`，菜单和战斗读取个人等级；旧档只在首次缺失等级时按已保存`lvSeen`迁移，随后独立成长。证据为[成长模块](../../../xiaojianghu-legacy-prologue/js/character-growth-state.js)、[菜单模型](../../../xiaojianghu-legacy-prologue/js/qihe-ui-model.js)与[状态/成长实测](character-condition-growth.md)。叶蘅3级初始化；知古见闻、宠物规则分别处理，不能由此写成所有角色都采用同一种经验。
- **江湖历练**：[共享培养池](shared-insight-pool.md)已接入当前8792，角色经验与已学功法可以按规则分配；不替代教学资格，不自动治疗，不是未分配加点草稿。当前完整来源上限6720只是已配置投放，不是全游戏经济预算。

## 3. 固定入队等级怎样设计与使用

**先估计萧白在人物预计入队时点的表现，再设计该人的固定配置。** 比较时同时看属性、已会功法与重数、兵器、输出／承伤／治疗／支援、入队代价和后续成长空间。

配置中分别维护：固定入队等级、初始属性、功法与熟练、装备、招募资格、后续成长方式。主角等级门槛只用于判断招募资格，不能生成同伴等级。

举例仅说明规则：某人设为固定20级，则萧白17级或25级时招募，她都以20级初始化。晚招募不自动升级；某分支确实让她成长，需单独列固定分支配置。离队重邀读取该人的存档，不恢复到初始20级，也不跟主角重新计算。

## 4. 下一步数值定稿需要补的证据

1. 按偏练武、均衡、偏生活三种培养路径生成萧白实际成长曲线，替换未经验证的参考等级。
2. 按已有19位同伴固定配置，逐人核对实际招募、装备、技能与当时队伍；低输出医者、工匠和见证者不能仅按伤害排档，不再另填一份冲突等级表。
3. 把等级、属性、功法重数、装备收益和敌方配置接到同一份战斗计算中；同时评估行动次数、破势窗口与续航。
4. 验证早招／晚招、两人／多人队、叶蘅两线、单医／双医、不同装备及宠物自动行动；离线算表和模拟结果不能代替实际游戏流程与体验核对。

这四项完成后，才可以声称三款参考已转化成统一且验证过的本作数值体系。当前结论是：**三者都有参考，参考深度不同，完整校准尚未完成。**
