# 江湖历练：全队共享培养池

状态：现行　最后核对：2026-10-19

2026-10-13。用户要求同时增加可分配给自己和伙伴的历练经验池，并核对《大侠立志传》的设计及数值。实施对象为8792当前游戏。

未核实：当前各平台/版本完整兑换倍率、所有功法逐重历练消耗、减耗特性如何影响池子。下文1:1、5:1和任务额度全部是本作设计，不声称复刻原作数值。

## 本作规则

正式名称统一“江湖历练”。与战斗修为、功法熟练、培养根基、银两各自独立。界面显示共享余额和来源；玩家选择已正式加入且当前可培养的人物，再选等级、已学外功或内功。后备但仍在场可培养；离队/驻外/剧情不在场、临时客串、宠物不能消费。裴知古的等级仍走见闻，不用历练替代见闻；其已学武学若规则允许可修习。

- 1点历练=1点角色经验，不叠主角20%领悟或落后伙伴加成。满100级不收款；升级依然每级3点。投入不会自动补血蓝、疗伤、授课或入队。
- 5点历练=1点功法熟练。已学功法才能投入，现有十重/五层、授课阶段、属性/兵刃门槛继续生效，不购买未学招式。一次最多补至下一重，超出需求的部分不扣。正式培养功法使用原thresholds/addXp；同门多招共用功法熟练。旧内功以1进度=100练习经验换算后接原0.8×当前层进度规则；旧外功沿6n²熟练，不另改旧曲线。
- 角色等级可一次投入任意正整数，实际花费=min(请求值,余额,升到100所缺经验)。武学通常按5的倍数投入、最多下一重；最后不足1熟练时按所需历练向上取最小整数结清，其余不足5点不收款。
- 操作前同时展示名字、用途、实际消耗、余额变化、等级/重数及主要面板变化，玩家确认后一次保存。重复提交同一命令不再扣，保存失败不改变内存余额或人物。
- 旧“仅补到主角减3级”的限制撤下：共享资源由玩家决定给谁，不把强同伴锁死；招募/绝学传承等资格仍不能花钱跳过。
