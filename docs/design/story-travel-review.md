# 游历与终局推进 当前全流程版本

状态：现行　最后核对：2026-10-19

2026-10-16。当前设计，未接入新主线。[完整流程](fullflow-story-20261016/README.md) · [逐事件剧情](fullflow-story-20261016/story.md)

旧“三地区任选二进入四势力路线”的草案不再是本作唯一主干。本轮先把《两个萧白》与《教主的葬礼》接成有因果的旅程，地区人物篇在主线间自由展开。旧TRV/END技术草案未实装，不据此改写正式存档。

1. 培养结束、叶家真相结清、出师交接完成，进入P3-01。无满级、全招募或恋爱要求。
2. P3-01至05从误认、相认、真救人、假赛发展到送棺请帖；不同选择保存，不能揭穿后又强演认错。
3. P3-06明确护葬或独立追查，P3-07至10各有承诺范围与到场来由，最终都亲历白石局势，未接受的职责不自动追加。
4. P4-01至04让玩家亲眼见到各方动手、姚本人的责任、阿七的真实选择。P4-05先完成最低安置，再预告三种行动的目标和代价。
5. P4-06只选择N-01／02／03之一，实际完成或明确接受有代价的结果后进入P4-07。普通失败先可重试/撤回，技术异常不算失败，取消选择不锁路线。
6. P4-07安葬或暂置、交代本人过失；P4-08回访当事人。没选的地方根据已完成援助与NPC自己的行动结算，不全胜也不默认屠杀。

城市跑动、普通活动不推动时间，没有全局昼夜交替。紧急段在明确确认后开始，用分段任务和固定场景推进，不能嘴上立即处刑却允许无限绕世界。培养另按36月日历，未完成个人篇按真实状态保留。

至少区分三类人：已交接到安全点的人、庄扣押的报复对象、严扣押的船工/证人；不能同一NPC同时被两方扣在两个场景，也不能完成最低安置就默认所有人脱险。每条末段援助与NPC去向都须记录。

关键对话只由本场实到者发言；未招募代表可在公开约见点作为NPC出场，不赠正式资格。具体同伴方法只有本人在场可用，普通公开路线不复制她的特殊能力。分支、收益去重和恢复验收见[实施矩阵](fullflow-story-20261016/implementation-plan.md)。
