# 队伍与宠物

状态：队友、宠物分离及宠物队尾跟随来自**已确认方向**；下列编队细节为**设计方案**。叶蘅具体参战分支见[叶蘅分支](ye-routes.md)。

## 人类同伴

萧白是固定主角。叶蘅从开篇同行，分支后按行程有在队、驻谷、回访三种状态；**驻谷不等于消失，也不清除培养与关系记录**。苏芷在襄阳事件后可作为同伴或同行医者加入。人类同伴拥有独立属性、装备、所学、关系、地点和日程；同伴交互按[NPC 交互](npc-interaction.md)开放。

人类编队上限与战斗替补位在实现前统一定数；当前代码里的“主角＋苏芷＋大黄”是旧配置，不能当新故事的起始队伍。选人界面清楚区分“可上阵”“暂不在场”“剧情离队”，不要让白鹇谷学习中的叶蘅被误判为未招募。

## 宠物独立模块

大黄是**宠物参战角色**，与人类同伴共享战斗站位、受伤和成长的必要数据，但不用人类装备、武学教学或手动指令。探索时默认跟在整支队伍**最后面**；人类队员前后换位后，大黄仍在末尾。

宠物自主行动由“主人气血、敌人威胁、宠物可用技能、关系／训练倾向”决定，不读取玩家对人类队员的控制命令。示例：萧白气血健康时大黄倾向追击或牵制；萧白气血偏低时提高护主和防护技能权重。玩家可在培养中训练“大致倾向”，不能逐回合选具体技能。战斗界面显示它为什么护主或进攻，避免随机感。

宠物可休息、疗伤、建立信任；永久失去宠物不作为普通战败惩罚。宠物未加入时，所有主线与支线仍有非宠物解法。具体数值与出战上限待[成长与战斗](growth-combat.md)落定。
