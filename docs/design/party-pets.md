# 队伍与宠物

状态：现行　最后核对：2026-10-19（原记：队友、宠物分离及宠物队尾跟随来自**已确认方向**；下列编队细节为**设计方案**。叶蘅具体参战分支见[叶蘅分支](ye-routes.md)。）

## 人类同伴

萧白是固定主角。叶蘅从开篇同行，分支后按行程有在队、驻谷、回访三种状态；**驻谷不等于消失，也不清除培养与关系记录**。苏芷初见时（初见地点与剧情待重新设计）可体验同行，长期加入需完成个人篇与诊务交接。人类同伴拥有独立属性、装备、所学、关系、地点和日程；同伴交互按[NPC 交互](npc-interaction.md)开放。

首版提案采用人类出行及战斗最多4人（含萧白）、暂不设战斗中任意替补，正式实现前验证；当前代码里的“主角＋苏芷＋大黄”是旧配置，不能当新故事的起始队伍。选人界面清楚区分“可上阵”“暂不在场”“剧情离队”，不要让白鹇谷学习中的叶蘅被误判为未招募。

资格、体验到期、满队替换、日程、离队与存档规则统一见[招募系统](companion-recruitment.md)，角色见[17人候选名册](companions.md)。招募资格不等于当前在队，满队不丢失正式资格。

## 宠物独立模块

宠物独立于人类编队、培养和手动指令；探索默认位于人类队尾，具体自主活动、召回、场景接管、战斗决策、成长、照顾、界面、素材和数据规则统一由[宠物系统设计规范](pets.md)维护。

- [现行实现与缺口](../archive/pets.md)：基于代码盘点，不把设计写成已上线。
- [宠物验收清单](pets-acceptance.md)：移动、状态中断、战斗边界、存档和素材的交付门槛。

大黄未加入时，主线与支线保留非宠物解法；普通战败不造成永久失去宠物。宠物不占人类队位，剧情单独展示大黄时不得再生成队尾跟随实例。
