# 襄阳片段测试范围与缺口

状态：**当前测试阶段范围**。只以襄阳街市、青蚨散案、渡口、黑风寨及其回城结果验证基础系统；三年培养、村庄序章、白鹇谷正式入门和叶家终局暂不开发。目标剧情与当前原型差异见[青蚨散事件](xiangyang-case.md)，技术验证方法见[测试文档](../testing.md)。

## 本阶段的最小闭环

`index.html#xiangyang` 是新设定的片段测试入口：固定萧白、叶蘅初始同行，使用会话测试档；`#street` 留给旧流程回归。测试入口能稳定重置并进入襄阳 → 对话与场景移动 → 老周中毒调查和多种解法 → 战斗或非战斗后果 → 苏芷互动、可选大黄 → 渡口与黑风寨 → 地方案件结算。结算只称“襄阳片段”，不把地方事件当全作终局。

## 先补的基础项

| 优先级 | 缺口 | 襄阳范围内的验收结果 |
| --- | --- | --- |
| P0 | 提示与交互占用的回归 | `toast()` 立即返回、提示排队显示；浏览器中连续获得道具／任务完成提示时交互已释放，提示仍可见 |
| P0 | 战斗异常被当作胜利 | 抛错时停止结算并报错，不发经验、奖励或推进任务；普通胜败与重试各验证一次 |
| P0 | 核心分支与状态复原覆盖不足 | 青蚨散婉拒再邀请、代付、不同处置、战败再试、渡口不同解法、宠物有无、存读档都可完成，不出现卡关或重复奖励 |
| P0 | 评审存档隔离的回归 | `#xiangyang`／`#street` 写 `sessionStorage['xjh.review.save']`；浏览器验证普通存档保持原值、结算后重测回到固定初始阵容和任务状态 |
| P1 | 新故事的最小角色配置未接入 | 测试片段固定萧白身份，叶蘅作为初始同行测试位在场；苏芷按案件登场。无需制作完整开篇或三年路线 |
| P1 | NPC 交互仍按个别剧情脚本拼接 | 先让普通对话、店铺服务、案件选项和一种江湖手段共享菜单与行动后刷新；完整能力成长可后置 |
| P1 | 地方案件结算仍带旧主线身世与“第二章”提示 | 结案界面说明此案结果、留下的线索与继续游历入口，不宣称全作结束或新主线已可玩 |
| P1 | 正常等级、装备和宠物组合的战斗平衡缺少完整验证 | 不只用评审直达角色；至少用起始、常见、低资源三类状态走通所有必经战 |

## 可以留到三年阶段

36 月山居培养、季节剧情、叶蘅白鹇谷正式入门与两条立绘、叶家三件遗产的完整终局、远期围城和其他地区地图。本阶段可以在襄阳使用测试用角色或简短前情说明，**不要为了单片段测试提前铺开整条主线**。

## 证据边界

2026-09-29 回归：提示解锁与顺序、战斗异常后停止结算、会话测试档隔离、角色与队形、本地结算、NPC 组合菜单的自动测试通过。青蚨散及渡口的分支状态、败北重试、奖励幂等与存读档通过受控结果回归；`#street` 和 `#xiangyang` 的真实寻路、对话、战斗触发、苏芷入队和街市出口往返通过浏览器实走。

正常数值战斗内核抽样：起始 Lv1＋叶蘅（两馒头）、常见 Lv3＋叶蘅／苏芷（桃木剑布衣）、同级低资源（主角 55% 血／25% 内力，无药）各以五种固定种子打七类遭遇。起始档除直接越级挑战 Lv9 独眼阎罗为 0/5 外，其他六类均 5/5；常见和低资源档七类均 5/5。头目不属于青蚨散案保底结案的必经战，失败后可准备再试。此抽样调用原战斗内核与敌模板，只跳过动画、画面绘制并用固定策略选招；它尚未证明手动操作、连续战斗资源消耗或所有战术的平衡。普通标题开局仍使用旧原型设置；`#xiangyang` 中叶蘅暂借通用女性素材测试阵容，不是定稿立绘。
