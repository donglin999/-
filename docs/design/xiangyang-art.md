# 襄阳城素材制作规范

状态：**目标美术基准 + 当前素材盘点**。地点、时间、人物关系以[襄阳城设定](xiangyang-city.md)为准；具体文件格式、脚本参数和运行时读取方式以[美术管线](../art-pipeline.md)为准。本页回答“这张图要画什么、画成什么样、怎样判断能否放入襄阳”，不表示下列缺口已经出图。

## 画面合同：三种媒介，一套江湖

| 层 | 统一做法 | 参照与边界 |
| --- | --- | --- |
| 探索地图与单体 | 南宋市井题材的**三分之四俯视像素画**；近似正交，无强透视消失点；房屋露屋顶和朝南的正面；轮廓清楚、色块成簇、用有限色阶 | `raw_scene/style_ref.png` 是当前生成脚本的风格参考；`review/final_v5/street_idle.png` 用于检查角色与城景同框。参考图只传递像素密度、配色和光向，不复制其布局 |
| 对话立绘 | 国画白描、淡彩与明确骨相，人物为成年人；站姿和表情可变但脸、发色、身材连续 | `assets/p_*.webp` 当前 v2 候选；叶蘅新立绘先以[人物](cast.md)定脸与阶段，不从现有苏芷变形生成 |
| 界面与提示 | 宣纸、淡墨、朱印、深墨底和少量赭金；阅读清晰，物品／武学以图标格和悬停说明承载 | [表现规范](presentation.md)与现行菜单；不要把场景像素图放大成模糊的 UI 背景，也不要把立绘的淡彩笔触硬塞进地面图 |

城市主色以**灰蓝瓦、灰砖、米白灰泥、暖褐木**为主体；朱红用于旗、茶棚布与小范围引导，草绿和河岸土黄作环境层。白天主光从画面左上，建筑朝向与投影一致；偏巷略收光，案发时用人物动作与人群密度制造紧张，不直接把整城调成灾难夜景。色值不作为生图模型的唯一控制，最终以现有参考图并排审稿。

### 一眼能识别襄阳的五个信号

1. 北面的汉水方向与可辨的城墙／门楼，南面的陆路入口；不把两个城门画成同一面。
2. 石板街、茶棚、书场、铁匠铺、药铺与货担构成**人能工作的街**，不是一排空店面。
3. 军士、拒马、榜文和军需材料只占局部，和商贩共处，表达戒备中的生活。
4. 行人的衣物、肩挑背负、竹筐、瓦罐、药柜和船货表现水陆运输；不要用现代商标、塑料袋、霓虹牌或统一武侠门派制服。
5. 老周倒地、两名医者施救、茶碗／药瓶等线索在**可玩镜头距离**仍可辨认，不靠画面上生成的字解释。

## 场景资产矩阵

“现有”只代表文件与原型场景存在；目标剧情中的角色配置、状态变化及部分音景仍未迁移。地图是探索用 `m_*_v2.webp` 加单体图集 `m_*_v2_props.webp`；战斗用 `bg_*.webp`，两者不能互换。

| 区域／场景键 | 现有核心文件 | 画面必备轮廓与可达关系 | 目标需要补的状态或素材 |
| --- | --- | --- | --- |
| 南门外 `gate` | `m_gate_v2.webp`、`m_gate_v2_props.webp`、`bg_gate.webp` | 南侧官道→盘查→门洞入城；城墙、门楼、吊桥、车货分层 | 年一夏的同行者入城同框、盘查后的人群变化；不复用旧单人开局对白 |

| 偏巷 `alley` | `m_alley_v2.webp`、`m_alley_v2_props.webp`、`bg_alley.webp`（已重排，待镜头终验） | 西口回街市；主巷串公井、大黄和吴长老；柴角、鸡场、小土地龛承接可选任务 | 按[偏巷实施方案](xiangyang-alley.md)复用单体；若镜头检验发现缺项，再按用途补素材，旧废宅不是新素材基准 |
| 东津渡 `ferry`／`crossing`／`ferry_e` | 各自 `m_*_v2.webp` 与对应图集；`bg_ferry.webp` | 泥岸、芦苇、栈桥、船体和货物使过江行动可信 | 船只前后状态、供毒线索、渡运与冲突后的差分；其细化地理暂待定 |
| 黑风寨 `bgate`／`cave` | 各自 `m_*_v2.webp` 与图集，现有战斗背景 | 木栅、山路、寨门、洞内据点，城外势力与市井材质有区分 | 可选深追的证据与后果，不制作取代主线的“终局圣地” |

## 生产流程与来源记录

1. **先填资产卡**：场景键、剧情状态、玩家要识别的物件、视角、尺寸、遮挡底边、相邻素材、目标文件名与是否可复用。没有资产卡，不以一句“宋代襄阳繁华街市”直接批量生图。
2. **锁参照**：单体与角色分别给同层参照；单体生成优先沿用 `raw_scene/style_ref.png`。`assets/review/` 中的候选稿和 `m_street_gen1/2` 只作对比，不能因文件在仓库里就当作最新权威。
3. **分层生成**：建筑、摊位、证物和人物分开出图；地图由地面、单体、遮挡、碰撞数据组合。生成图上的招牌、榜文、账簿一律留白，文字由游戏字体或剧情 UI 后贴。
4. **后处理与装配**：现有 `tools_scene/gen_props.py` 记录提示词及参数到 `raw_scene/props/params.json`，`cut_props.py` 抠图，`build_scene.py` 排布并生成地图、图集与 mask。角色与立绘管线见[美术管线](../art-pipeline.md)。这些脚本会写本地素材；本页是规范，编写文档时不自动重跑。
5. **场内验收**：先看无 UI 的场景，再看 1280×720 游戏镜头。确认入口、NPC、鼠标命中／交互标记、遮挡、碰撞和剧情镜头；通过后才替换当前文件并记录前后截图。

### 资产卡样例：街心老周救治组

| 字段 | 本组应填写的内容 |
| --- | --- |
| 使用场景与状态 | `street`；平日可见挑夫货担，案发时老周倒地并留救治空地，结案后人群散开。三态共用同一街心地标 |
| 叙事目的 | 一眼看出“有人病倒，需要医治”，再通过近景和交互确认茶碗、药瓶、疤脸刘接触等线索；不能让生成图直接写出毒名 |
| 人物与比例 | 老周是长期负重的成年挑夫；叶蘅为乡村医者、苏芷为游方针医。三人的脸、衣物和医具分别锁定，不为案发状态换人 |
| 拆分文件 | 角色立绘／精灵动作、货担、茶碗、药瓶、人群站位和遮挡分别制作；具体资源键由实现时登记，不把整场事件烘焙成一张不可交互插画 |
| 镜头与碰撞 | 1280×720 游戏视口里病者和两名医者同时可辨；玩家可绕到救治区与茶棚；物件遮挡底边、交互位置、mask 同步检查 |
| 审稿证据 | 并排展示平日、案发、结案三张同机位截图，加近景证物图与碰撞审计图；写下采用素材的提示词记录和退稿原因 |

实际生产时每个 P0 组都按此卡填写。若缺少人物同脸参考或案件状态尚未敲定，先补设定和站位，不用临时生图结果倒推剧情。

### 单体生成提示词骨架

下方是**构图约束模板**，具体对象从资产卡填写；不是要求现在生成。文字描述使用英文与当前 `gen_props.py` 保持一致。

```text
One isolated [exact object and material], for a 13th-century Southern Song
Xiangyang street in a top-down Chinese wuxia pixel RPG. Orthographic-looking
3/4 view from the south, roof and south-facing facade visible; upright,
not rotated. Match the supplied style reference's pixel density, blue-grey
roof tiles, warm timber, cream plaster, limited palette and upper-left warm
daylight. Clear silhouette at game scale. Center the full object with empty
margin on every side, pure flat #FF00FF background. No ground tile, people,
cast shadow on background, legible writing, modern objects, watermark or frame.
```

证物的提示词另写**材质和使用痕迹**（例如被人端过的粗陶茶碗、小而可握的封口药瓶），不能把毒物画成发光宝物；角色提示词先引用人物身份卡与同脸参考，再写动作，不允许每个表情重生一张陌生脸。生成模型输出是候选，最终尺寸、像素边界、透明区与可交互轮廓必须由后处理及场内验收决定。

## 评审时逐项勾验

| 项 | 合格标准 | 常见退回原因 |
| --- | --- | --- |
| 设定 | 对应[襄阳城设定](xiangyang-city.md)的年一夏、市井加城防、目标角色在场；不暗示长期围城或主线终结 | 全城战火、叶蘅缺席、苏芷独自决定收徒 |
| 视角与尺度 | 地图用统一三分之四俯视，角色脚底接地，建筑不向不同消失点倾斜；与当前 3×像素网格同屏协调 | 斜转建筑、人物比门还高、写实照片混入像素图 |
| 材质与光 | 灰蓝瓦／灰砖／米白墙／暖木，左上暖光；偏巷可更旧但仍属于同城 | 每件物品独立调色、光从四面来、整图模糊或渐变带噪 |
| 可玩性 | 入口、救治点、茶棚、店铺可找；主要通路和交互点无遮挡；mask 与图形吻合 | 漂亮但堵路、门看似可进却没有出口、病者被摊伞挡住 |
| 叙事可读性 | 证物与职业道具在实际镜头可辨；案前案后差分可以观察到 | 靠生成文字或旁白解释全部变化、毒瓶像法器 |
| 资源可追溯 | 资产卡记录用途、参考图、提示词、输出文件、采用／弃用理由和审图截图 | 只保留一张成图，不知来自哪个状态或哪版提示词 |

### 待确认而不得由素材自行决定

东津渡与东岸的精确地理位置、青蚨柜可进入的实体场所、年一夏是否需要雨天与夜景、案后街市的长期人口变化。制作这些内容前先在[襄阳城设定](xiangyang-city.md)和[青蚨散事件](xiangyang-case.md)落实用途，再新增场景键或资产，不为了“看起来丰富”向城里塞没有剧情和交互依据的楼阁、门派大殿或巨型雕像。
