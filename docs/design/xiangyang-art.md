# 襄阳城素材制作规范

状态：**目标美术基准 + 当前素材盘点；场景比例与碰撞待重新验收**。地点、时间、人物关系以[襄阳城设定](xiangyang-city.md)为准；本轮已采用的人物与证物图、完整提示词见[襄阳生图记录](xiangyang-art-prompts.md)，文件格式与读取方式见[美术管线](../art-pipeline.md)。2026-09-30 的游戏截图反馈指出角色悬空、桥断开、告示牌偏小、场景尺度及空气墙等问题；旧截图或资产已入库不代表本页以下标准已通过。

## 画面合同：三种媒介，一套江湖

| 层 | 统一做法 | 参照与边界 |
| --- | --- | --- |
| 探索地图与单体 | 南宋市井题材的**三分之四俯视像素画**；近似正交，无强透视消失点；房屋露屋顶和朝南的正面；轮廓清楚、色块成簇、用有限色阶 | `raw_scene/style_ref.png` 是当前生成脚本的风格参考；`review/final_v5/street_idle.png` 用于检查角色与城景同框。参考图只传递像素密度、配色和光向，不复制其布局 |
| 对话立绘 | 国画白描、淡彩与明确骨相，人物为成年人；站姿和表情可变但脸、发色、身材连续 | `assets/p_*.webp` 当前 v2 候选；叶蘅新立绘先以[人物](cast.md)定脸与阶段，不从现有苏芷变形生成 |
| 界面与提示 | 宣纸、淡墨、朱印、深墨底和少量赭金；阅读清晰，物品／武学以图标格和悬停说明承载 | [表现规范](presentation.md)与现行菜单；不要把场景像素图放大成模糊的 UI 背景，也不要把立绘的淡彩笔触硬塞进地面图 |

城市主色以**灰蓝瓦、灰砖、米白灰泥、暖褐木**为主体；朱红用于旗、茶棚布与小范围引导，草绿和河岸土黄作环境层。白天主光从画面左上，建筑朝向与投影一致；偏巷略收光，案发时用人物动作与人群密度制造紧张，不直接把整城调成灾难夜景。色值不作为生图模型的唯一控制，最终以现有参考图并排审稿。

## 全场景尺度、接地与可走性合同

本节适用于探索地图、剧情镜头及战斗站位；素材生成、裁切和装配均以**游戏内实际显示尺寸**验收。现行探索坐标每格 40 世界像素，主角目标身高 `CHAR_H=92` 世界像素，960×540 画布上的可见身高约 77 像素；这是基准，不是要求将所有人画成同一高度。尺寸差异只能来自人物设定、年龄、姿势、前后纵深，不能来自原图留白或逐张任意缩放。

| 类别 | 尺度与落点基准 | 退稿界限与检查方式 |
| --- | --- | --- |
| 成年探索人物 | 同一地面、同一镜头的普通成人**身体**可见身高以主角为 1，目标 0.97–1.03；有明确高矮设定的具名人物可放宽至 0.93–1.08 并记录原因。武器、挑担、帽上长饰和画布留白不计入身体高度。孩童、犬、鸡等按物种另列 | 并排站在同一水平地面，逐帧量身体头顶到最低承重脚点；同一角色四向、移动与待机的高度变化不超过基准的 5%，非动作跳跃帧不能双脚离地。仅凭整图 alpha 外框或 `ART.scale` 数字不得判通过 |
| 老周倒地事件精灵 | 保留老周灰褐布衣、头巾和长期劳作的体态；画法必须与 `s_hero_bright.webp` 等街市探索人物共用清晰像素网格、深色阶梯外轮廓和有限色阶。倒地姿势可以不同，不能混入平滑写实插画；静态事件不用伪造走路四向帧 | 以正常游戏镜头同屏看老周、萧白、叶蘅和苏芷，检查像素颗粒、边缘、明暗笔触和身份；倒地长轴仍按成人站姿量尺，保持接地 |
| 同伴移动接地 | 待机、步行、跑步都以相同世界脚点落在地面；动作允许交替抬一只脚，但每帧至少有承重脚/鞋尖触地或与阴影仅隔 1–2 个画面像素。帧内透明留白不得使整个人上浮 | 四方向连续跑动逐帧量最低承重脚点、阴影中心和相邻帧位移；尤其核对苏芷长裙、跑步表与普通探索表的切换 |

2026-09-30 返工记录：叶蘅没有专用跑步表，快速追随复用四帧行走图，原画下摆遮鞋，导致可见裙摆与阴影拉开约 15 屏幕像素。仅把鞋尖贴在地面会形成断开的贴片；把一条细腿直通地面又像高跷。当前保留原图，在角色绘制时把前后交替、折膝的承重腿绘在裙摆背后，并用原图盖住腿的上半段；苏芷专用跑表仍保留。整张 4×10 跑步表的生成候选因格线漂移、杂色背景和人物身份变化退稿，不进正式资源。最终仍须以两名女医者四方向连续实际跑步镜头判定，不能用 alpha 最低点恰好对齐脚点代替视觉验收。
| 倒地成年人 | 按身体长轴比较：从头到脚的可见长度目标为同镜头主角站姿身高的 0.9–1.15，短轴厚度由姿势决定；交互标记和阴影不计入长度 | 将倒地者与一名站立成人放在同一地面截图，量可见身体长轴、接地边和阴影；不能因站姿画布是 141 像素就按画布高度缩小躺姿 |
| 接地与阴影 | 精灵的脚底锚点、世界坐标、椭圆阴影中心使用同一地面点；步行动画允许抬脚，至少一只承重脚应接触该地面点。倒地者按身体与地面接触边界重算阴影 | 同机位截图放大检查：站立帧最低脚点与阴影中心的纵向偏差不超过屏幕 3 像素；不出现双脚同时离地或阴影明显游离 |
| 像素轮廓与透明边 | 探索精灵使用同一像素密度、清楚的深色外轮廓与有限色阶；裁切透明留白不改变渲染身高。对话立绘可用淡彩，但透明边缘须贴合人体和衣物 | 在深、浅两种背景各检查一次；不得有连续可见白底边、浅色抠图晕圈或异质画风；不能仅在白底预览通过 |
| 战斗人物 | 同一站位深度的普通成人身体可见身高目标为主角的 0.93–1.08；图集来源、透明留白、敌我阵营和 `tier` 不得自动改变身体比例。纵深缩放如启用，须对所有来源一致；头目体型差异须有角色设定 | 玩家、队友、普通敌兵同屏比较可见身体高度与脚底线；分别覆盖专用战斗表和探索精灵回退路径，不能只比较 `unitH` 或整张图的透明外框 |
| 固定物件 | 每张场景先放一名基准成人、门洞和 40 像素格线，建立资产卡中的目标宽高；凳面约成人膝部高度、桌面约腰部高度，水井井沿约腰部高度，火堆不得高过站立成人 | 篝火、灶台、货车、井、树、龛、告示牌逐一在 960×540 游戏镜头同屏核对；不以独立素材预览决定尺寸。超出基准须说明实际用途与尺度参照 |
| 可行走边界 | 地面颜色只表示材质、光照或使用痕迹；可走区域由明确道路、入口、建筑／围栏／水域等可见物界定。遮挡图、碰撞 mask、互动锚点随布局一起更新 | 在目标视距遍历浅色、深色地面与全部出口：看似连通的路必须能走；不可走边应有可见实体。角色脚底至实体边缘允许小幅贴边，不得隔着大片空地被阻挡 |

每张地图保留一张**无 UI 比例审计图**和一张**碰撞叠图**，至少标出玩家身高、场景门洞、最大与最小物件、出口、互动点和不可走边。核对范围是 `gate`、`street`、`alley`、东津渡及其衔接场景、黑风寨、寺庙与室内场景；仅修一张截图不能关闭“全场景尺度”问题。比例标准是设计目标，现有素材仍须逐项实测。

### 逐场景量尺卡（场景构建前填写）

下表把当前脚本 `tools_scene/build_scene.py` 中的关键物件与统一成人 92 **世界像素**的基准放在一起。表中的宽度是 `S.place(..., w=...)` 使用的**源像素**目标范围；当前 `K=3`，地图实际宽度约为表值的 **3 倍世界像素**，高度还要乘素材本身的宽高比。不能把 `w=30` 误读成 30 世界像素。最终值由用途和入口净宽决定，并在 `S.place()` 及审计截图中同时记录源像素宽、实际世界像素宽高；现有值超出范围时应先查物件原图留白与脚底锚点，再决定缩放。每个场景同时保留至少一名成人、一个门/通路、最小交互物和最大地标的同机位对照。

| 场景 | 量尺对象和目标显示宽度 | 必查关系与可达点 |
| --- | --- | --- |
| `temple` 庙内 | 神龛 135–165；取暖火堆约 10–13（以显示高 ≤46 世界像素为准）；木箱 28–42；灯桌 32–45 | 火堆实际显示高度低于成人腰部，神龛不比门洞窄；草铺、火堆、神龛、出口能互通 |

| `gate` 南门外 | 吊桥 54–72；榜文牌 34–48；拒马 38–50；官道门洞宽至少一名成人加两侧余量 | 桥两端接岸路、榜文和守卫同镜头可辨，南北走通且不穿河 |

### 2026-09-30 二次量尺记录

本轮在文档目标修正后遍历 `tools_scene/build_scene.py` 的 10 张场景，读取每个 `S.place()` 实际裁去透明底后的包围盒，而不是只读传入的宽度。合计 **553 个放置实例、227 个语义组**；逐株树木、芦苇与同款围栏在同一场景按源素材和用途合并，表内给最小—最大值及件数。宽高均为**世界像素**，`高/成人` 以 `CHAR_H=92` 为分母。屋顶、旗杆、长枪、晾架等包含竖向结构，因此整体高度大于成人并不自动构成比例错误；桌面、井沿、门洞净高另需实图量。

对照证据为同版构建后十张正常游戏镜头（`/tmp/size-all10-fixed/game_all_<scene>.png`，汇总 `game_contact.png`）和十张碰撞叠图（`/tmp/size-all10-fixed/audit_<scene>.png`）；临时路径只记录本机本轮验收结果，长期复核应执行 `node tools_scene/audit.cjs <输出目录> temple temple_out gate street alley ferry crossing ferry_e bgate cave` 并重新拍游戏镜头。十场景连通审计均为一个可走区、`issues=0`；这只证明导航条件，不能代替视觉判断。

本轮修正：庙外药炉由 **72×75** 缩为 **42×42**（高/成人 0.46）；东岸火塘由 **78×84** 缩为 **42×45**（0.49）；偏巷瘦高柴垛 **84×102** 改为两束横置柴包，总宽 **129**、高 **54**（0.59）。三处均已在游戏内与成人同机位复看。西岸栈桥净宽 78、另一栈桥及东岸栈桥净宽 72；江心船甲板可走纵深 75，均为地面笔画及 `walk_rect`，不在 `S.place()` 表内。江心静态地图黑底为运行时江面未绘制，游戏正常镜头有完整江面。

**仍须逐件覆盖的类别：**这张台账量的是探索地图的 `S.place()` 物件整体，尚未逐帧量完角色身体、手持精灵、NPC 与同伴站位、战斗背景与战斗角色、CG、UI 图标、动态特效；未逐一分割桌面/井沿/船舷/门洞的功能高度，也未把每个 553 实例分别放在成人旁截图。每场至少有一张带成人的实际游戏镜头；以后替换单体源图、改变裁切或 `K/ZOOM`，须更新相应行并重拍邻近成人对照，不得凭此旧记录沿用通过状态。

### 一眼能识别襄阳的五个信号

1. 北面的汉水方向与可辨的城墙／门楼，南面的陆路入口；不把两个城门画成同一面。
2. 石板街、茶棚、书场、铁匠铺、药铺与货担构成**人能工作的街**，不是一排空店面。
3. 军士、拒马、榜文和军需材料只占局部，和商贩共处，表达戒备中的生活。
4. 行人的衣物、肩挑背负、竹筐、瓦罐、药柜和船货表现水陆运输；不要用现代商标、塑料袋、霓虹牌或统一武侠门派制服。
5. 老周倒地、两名医者施救、茶碗／药瓶等线索在**可玩镜头距离**仍可辨认，不靠画面上生成的字解释。

## 生产流程与来源记录

1. **先填资产卡**：场景键、剧情状态、玩家要识别的物件、视角、尺寸、遮挡底边、相邻素材、目标文件名与是否可复用。没有资产卡，不以一句“宋代襄阳繁华街市”直接批量生图。
2. **锁参照**：单体与角色分别给同层参照；单体生成优先沿用 `raw_scene/style_ref.png`。`assets/review/` 中的候选稿和 `m_street_gen1/2` 只作对比，不能因文件在仓库里就当作最新权威。
3. **分层生成**：建筑、摊位、证物和人物分开出图；地图由地面、单体、遮挡、碰撞数据组合。生成图上的招牌、榜文、账簿一律留白，文字由游戏字体或剧情 UI 后贴。
4. **后处理与装配**：现有 `tools_scene/gen_props.py` 记录提示词及参数到 `raw_scene/props/params.json`，`cut_props.py` 抠图，`build_scene.py` 排布并生成地图、图集与 mask。角色与立绘管线见[美术管线](../art-pipeline.md)。这些脚本会写本地素材；本页是规范，编写文档时不自动重跑。
5. **场内验收**：先看无 UI 的场景，再看 1280×720 游戏镜头。确认入口、NPC、鼠标命中／交互标记、遮挡、碰撞和剧情镜头；通过后才替换当前文件并记录前后截图。

### 单体生成提示词骨架

下方是**构图约束模板**，具体对象从资产卡填写；不是要求现在生成。文字描述使用英文与当前 `gen_props.py` 保持一致。

```text
One isolated [exact object and material], for a 13th-century Southern Song
Xiangyang street in a top-down Chinese wuxia pixel RPG. Orthographic-looking
3/4 view from the south, roof and south-facing facade visible; upright,
not rotated. Match the supplied style reference's pixel density, blue-grey
roof tiles, warm timber, cream plaster, limited palette and upper-left warm
daylight. Clear silhouette at game scale. Center the full object with empty
margin on every side, pure flat #FF00FF background. No ground tile, people,
cast shadow on background, legible writing, modern objects, watermark or frame.
```

证物的提示词另写**材质和使用痕迹**（例如被人端过的粗陶茶碗、小而可握的封口药瓶），不能把毒物画成发光宝物；角色提示词先引用人物身份卡与同脸参考，再写动作，不允许每个表情重生一张陌生脸。生成模型输出是候选，最终尺寸、像素边界、透明区与可交互轮廓必须由后处理及场内验收决定。

## 评审时逐项勾验

| 项 | 合格标准 | 常见退回原因 |
| --- | --- | --- |
| 设定 | 对应[襄阳城设定](xiangyang-city.md)的年一夏、市井加城防、目标角色在场；不暗示长期围城或主线终结 | 全城战火、叶蘅缺席、苏芷独自决定收徒 |
| 视角与尺度 | 地图用统一三分之四俯视，角色脚底接地，建筑不向不同消失点倾斜；与当前 3×像素网格同屏协调 | 斜转建筑、人物比门还高、写实照片混入像素图 |
| 材质与光 | 灰蓝瓦／灰砖／米白墙／暖木，左上暖光；偏巷可更旧但仍属于同城 | 每件物品独立调色、光从四面来、整图模糊或渐变带噪 |
| 可玩性 | 入口、救治点、茶棚、店铺可找；主要通路和交互点无遮挡；mask 与图形吻合 | 漂亮但堵路、门看似可进却没有出口、病者被摊伞挡住 |
| 叙事可读性 | 证物与职业道具在实际镜头可辨；案前案后差分可以观察到 | 靠生成文字或旁白解释全部变化、毒瓶像法器 |
| 资源可追溯 | 资产卡记录用途、参考图、提示词、输出文件、采用／弃用理由和审图截图 | 只保留一张成图，不知来自哪个状态或哪版提示词 |

### 待确认而不得由素材自行决定

东津渡与东岸的精确地理位置、青蚨柜可进入的实体场所、年一夏是否需要雨天与夜景、案后街市的长期人口变化。制作这些内容前先在[襄阳城设定](xiangyang-city.md)和[青蚨散事件](xiangyang-case.md)落实用途，再新增场景键或资产，不为了“看起来丰富”向城里塞没有剧情和交互依据的楼阁、门派大殿或巨型雕像。
