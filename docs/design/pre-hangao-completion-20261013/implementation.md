## 3. 课程短句合同

每次练习不弹一大段新剧情。首次短教、复习一句、首次达到里程碑一句，三者按真实状态选一个；同一结算不叠三套对白。完整台词收在`lessons.json`与逐句预览。

站桩/协调等读取当前培养规则，不另定义经验增量；功法使用既有《试锋剑法》《守拙拳法》《吐故纳新篇》。心法/武学名字、属性收益与战斗数值都从现行库显示在结算栏，老师不念“基础经验+48”。

授课人同步项：本方案拟将B03站桩、K02拳课统一给钟拙，使日常授课与过渡剧情一致；当前数据仍为周砚，未改运行。B01调息、B02基础步法、K01剑课仍由周砚负责，A03辨药由叶蘅负责。殷红缨的回岚身法是后续课程，不能在尚未回谷时隔空承担B02。

前四月共有20期，扣三月中旬占期后为19个自由期、最多228体力；本轮6段剧情不再加收费。可选知古链的联合安排示例：slot4初见、7认字、8罚抄、9田头账、13残稿、14水碓房，每期只安排一次串门；来客可放8/13/15，按当前3点费用，与一次5点训练合计不超过12。这里只证明剧情有排期空间，不等于全作培养平衡已测。

必达队列要求：同一期可以顺序播放多场0点短剧情，关闭对话不推进日期。slot16先完成邀请后的装备交付，slot17/18再做装备核对，slot18考校；slot19固定知古→约定→送行。若玩家中断，待完成的必达队列阻止直接推进而不是偷偷跳过过期；已有可选活动锁先恢复，不抢占其事务。

## 4. 演出与战斗接受标准

- 每个说话人必须在场，远方信件使用信卡而非凭空立绘。超过三名在场者用轮换前景＋旁席头像；不能把暂时没讲话的人删出事件事实。
- 周砚考校是“按口令收招、辨脚下、知道求助”。技术成功/需要重练都放行，生活题也能结束。复用HP战斗时必须另有教学终止条件，不能出现打倒宗师字幕。
- 小豆用剑，双人退狼真的建立小豆临时单位，不能继续单人战却播两人共同出手。失败是撤退，不死亡；不凭这场强制永久招募。
- 预览中的“查看胜/负分支”只供审稿；正式结果由实际事件决定，不把调试选择暴露给玩家。
- 角色专属出手和高低强度沿[角色动作合同](../combat-action-contracts.md)。本稿不把静态四向回退当成动作完成。

## 5. 必测用例

| 用例 | 必须满足 |
|---|---|
| 全休息、不学外功 | 可看生活题并正常出门；没有未学招式对白 |
| 剑/拳各主修一次 | 邀请、装备、考校三处一致；不突然切别的武器 |
| 主修已选但还没受教 | 仍走未学版，不赠技能 |
| 缺剑/已有剑/反复读档 | 只有缺剑完成借用才得一个借用实例；其他路径0新增 |
| 未认识/已认识/问过‘后来呢’ | 出发版本分别对应，不混播 |
| 送药三种方法 | 归来评语各有对应，未走坡不说走过 |
| 陈伯轻伤/腿伤/未知 | 回信不替他治愈，也不假造玩家知道的伤势 |
| 知古未加入/在队/只在名册/中途离开 | 仅实际在队且参与整件事才记见闻 |
| 同一事件改选/战斗重打/回看 | 一条见闻、一笔奖励，绝不按句计数 |
| 队满与旧入队标记 | 不挤旧队员、不重置已成长人物、不补未经历事件 |
| 四月底连续三段中断 | 从正确句位恢复，只结算一次，不漏送行也不重播加入 |
| 新城未上线/旧五月档 | 不把人送到空场景；旧档继续旧片段，待明确迁移 |
| 汉皋已上线 | 只播一次城外告别，进入HG-M01-2，正确移除送行小师叔 |

本轮预览检查只证明候选分支可读、角色名单和引用一致、长度符合约束；不证明以上正式游戏事务都已实现。接入时还要跑真实存档、完整出行与战斗回归。
