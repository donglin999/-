## 二、剧情顺序与行动预算

`slot=(月−1)×5+期序号`，沿现行每月五期、自由期12体力、三月中旬占整期、五月整月历练。下表成本是剧情成本，不覆盖原课程数值；既有可选活动的费用沿当前规则。

| 月份/slot | 必经骨架 | 可选人物线 | 本轮改变 |
|---|---|---|---|
| 入谷过渡/0 | 拜师面→认路→站桩→初识心法→束发 | — | 保留已确认外观阶段；“两个月”是过渡段，进入自由培养后才从年一正月计期 |
| 正月/0—4 | 乡邻信、夜归人 | 账本、站位纠正、知古初见窗口开启 | 拜师面与心法采用短稿方案；不再说镇派心法开局就会 |
| 二月/5—9 | 寻父来信、拳剑倾向、小满认药、大师兄回谷 | 知古初见/认字、小豆罚抄、田头账、莫松年来访 | 新增`hg_aftercare`（8—9，读信0体力，一次）；不是三位领队一起进谷 |
| 三月/10—14 | 送药预告→中旬整期送药→回谷交代 | 陆衡改期、师父复盘、白鹇谷来访、水碓房、残稿 | 新增`hg_trace_reply`（14—16，0体力），只在送药后出现；回信不能早于实际寄问 |
| 四月前半/15—17 | 汉皋邀请、师兄离谷、装备准备 | 来客礼数、师门介绍、叶蘅清单 | `hg_pack_review`（17—18，0体力），紧接已有出门装备剧情，不再多送一套装备 |
| 四月下旬/18 | 出门考校 | 未完成可选支线按原窗口 | 取消“打败宗师才算合格”；所有培养路线均可完成出行交接 |
| 四月底/19 | 知古出发→各人约定→家人送行 | 玩家可先处理未结束事项再出发 | `gn_depart`→`gy_m08`→`hg_farewell`合为连续三小段，可中断续读；不重复播放原出发段 |
| 五月初/20 | `hg_road`→`hg_gate` | 路上处理只选一种方式 | 进入五月后无谷中12点体力；两场是整月历练开场，不另推进五期 |

六场新增：`hg_aftercare`、`hg_trace_reply`、`hg_pack_review`、`hg_farewell`、`hg_road`、`hg_gate`。全部0额外体力；既有剧情里已收过的费用不重收。新增内容不额外送培养经验、好感或武学，只有明确列出的剧情事实与真实在队见闻；原场景收益沿原事务结算。

新增必达短场不随机抽取，不要求刷好感。读信可从来信页补读，但补读不虚构人物在场。月底出发前提示尚未处理的可选事件；这些事件不是进城门槛。

## 三、人物与信息边界

- 萧白17岁、知古20岁、小豆14岁/11岁入门。萧白的现代记忆不能被其他人未卜先知；不同头发阶段沿过渡剧情。
- 叶蘅叫周先生，萧白叫师父，钟拙/殷红缨是二师叔/小师叔。知古与正道盟裴嵩没有亲属关系。
- 书信不等于寄信人站在谷中。三方善后用有署名的信卡呈现，台上只有读信的人，不生成领队分身。
- 读者见过的剧情，角色未必在场。主角问话必须由眼前事物或刚听到的话引出；不为下一条教程预埋精准问题。
- 村火后各家承担善后，不能宣称损失全部赔清或幕后已查明。新交锋里岑的兵器方向按2026-10-13软鞭决定，不沿旧短刀提案扩写。
- 寻父线从“有传闻”推进到“有可请教的联系人”，仍无父亲下落、死亡或遗物真相。入城后核验随城内剧情待重新设计，不抢先给答案。
- 旧襄阳青蚨散案不作为本次入城前文案的后续。名称替换仅发生在本候选文本，旧`xiangyang_*`存档键的迁移另列合同，不能全仓库字符串替换。

## 四、对白长度与分支

主干单场通常120—360字，复杂送药沿原长场分段；新增短场原则上不超过420字。书信正文也计入玩家阅读量。最多两条短舞台说明，动作信息另进分镜表，不让人物念出来。四月底三场合计目标不超过850字，不增加长篇训话。

不同条件是替换句，互斥选项只播一条路径。预览提供主修、送药方式、陈伯伤势、知古熟悉程度、考校结果切换。图鉴、等级、奖励和未满足条件显示在说明区，不混进人物台词。

## 五、改稿与保留的边界

重点修订邀请/出发/考校/知古同行及相关成长回响；其余既有事件全文保留在同一预览里，标“既有收录”，不伪称全被重新写过。旧城名在入城前候选中统一为汉皋，原ID仅作追溯。当前拜师面、莫松年和初识心法的编辑短稿作为本次候选基础，保留编辑署名，不标作MiniMax原始输出。

本轮不改`js/`、`index.html`、正式对白机器源、现行日历或玩家存档；新设计放在独立目录。后续接入必须先完成本稿的分支/时间/资源/素材检查，再更新权威运行源。
