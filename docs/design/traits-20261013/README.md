## 设计内容

当前20项候选：6项固有能力、9项后天结业结果、5项伤病/临时状态。9个后天结果归入7条完整路线，修行与步法各二选一。四项原小任务标签（脚下有路、识药不混、备粮有方、根基渐稳）撤回为普通学习记录，不再额外加永久数值。

- [完整获取路线](routes.md)与[routes.json](routes.json)：每条至少包含学习、独立实践、问题处理、成果验证及收官；新事件明确标记未实装。
- [特性数据](catalog.json)：数值、路线门槛、互斥、时效和兼容记录。
- [触发与收官对白](triggers.md)：单个旧事件只记阶段，全部前置成立后才发结业奖励。
- [数值合同](numbers.md)、[UI](ui.md)、[接入合同](implementation.md)、[核对记录](../../archive/design/traits-20261013/review-notes.md)。
- [旧剧情来源快照](source-events.json)与check.py检查源码引用。新增路线的联合日程仍待实装前检验。

## 获取节奏

开始部分只积累经历；第一年主要能完成一条修行路线并择一结业，其余放到第二年或游历。三五个零碎任务不能自动凑出特性；同一任务反复刷也不计为多阶段。普通玩家终局常用3—5项后天特性是目标，不是强制装备上限或通关门槛。

固有能力体现角色此前经历，不是见面奖励；短期休整、饮酒等身体状态继续自然发生，弱且短效，与永久结业标签分区。主角既有20%成长加成仍只展示一次，不重新获奖。

错过早期事件可补同等实质经历，失败只补未完成验证，不永久锁路线。涉及取向的特性在收官时公开效果并选择，早期对话不能暗锁角色培养。

## 实施边界

现有正常游戏没有载入这批后天特性，因此本轮不删除玩家已有战力。新收官事件的演员、旅行、日程、成本和非战斗替代路线须验证后才可采用；静态数据和预览通过不等于新任务已实装。旧V1单事件奖励稿在archive仅供追溯，不再是授予依据。
