## 2. 素材

- **概念图**：13 张，存放在 `art_sources/v4_vfx_concepts_v1/`，生成脚本是 `tools_fx/gen_v4_vfx_concepts.py`。
- **单体素材原图**：26 个，存放在 `art_sources/v4_vfx_elements_v1/`，生成脚本是 `tools_fx/gen_v4_vfx_elements.py`。
  - 每个素材都以对应概念图作参考图，单独生成。
  - 发光元素画在纯黑底上，运行时加色叠加。实体元素（金针、碎石、纸卷、水墙）是透明底。
  - 通道是 `codex exec` 内置生图，由服务端选模型，提示词里带了 gpt-image-2.5 的要求，但未经核实。
- **运行时素材**：存放在 `assets/fx/v4_v1/`（manifest.json、contact.png），由 `tools_fx/build_v4_vfx_assets.py` 整理。
  - 整理方式与剑法套相同：按 640×360 特效像素空间缩到目标宽度，压到 96 色，存为无损 webp。
- **复用剑法套素材**：`cloud_mist`（叠岚掌的山岚）、涟漪程序环。

## 3. 编排

所有编排都写在 `js/wuxia-fx.js` 的 `addV4(...)` 段（`set:'v4'`），沿用剑法套的舞台锚点和工具函数（`fly`、`strike`、`shed`、`ripple`、`motes`）。新增内容如下：

- **属性色带**：`RAMP` 中新增 fire、frost、thunder、wind、sun、yin、heal、plain，颜色对应伤害数字规范第 1 节。
- **伤害数字**：`fx.num(text,x,y,{scale,ramp})`，色带按属性选择。
  - 字号倍数：2 为普通，4 为绝招。
  - 治疗数字带“+”号（新增 `PLUS` 字形）。
- **异常浮字**：`fx.label(text,x,y,col)`，颜色取异常色表（`STC`）。
- **命中**：统一走 `hurt(...)`，依次出现属性色斩击火花、伤害数字、异常浮字。

镜头强度随档位递增：

| 档位 | 镜头 |
| --- | --- |
| 丙 | 不压暗 |
| 乙 | 轻压暗（夜阑、叠岚掌） |
| 甲 | 压暗 + 暗角，焚契破阵加推镜 |
| 绝 | 重压暗、暗角、推镜、闪白、震屏 8 |

## 5. 群体、BP 加强与接入战斗（2026-10-08 第二轮）

### 5.1 群体多目标

- 编排统一从 `fx.targets()` 取目标，从 `fx.allies()` 取我方成员。每项包含胸口坐标 `x,y` 和脚下坐标 `gx,gy`。
- **焚契破阵：**
  - 火线圈住全部目标，火痕弧按目标群中心放大。
  - 纸卷悬在目标群上方。
  - 每个目标各出一个数字和一个“惊惧”。
- **松涛合阵：** 十道松针轮流分给各目标，最后每个目标各命中一次。
- **一曲安澜：** 每名我方成员脚下各有一圈音波和莲叶，各出一个治疗数字和一个“解除”。
- 评审页可勾选“群体招式演示 3 个目标”，舞台上会画出三名敌人。

### 5.2 BP 起手加强

BP 只在本档内加强，不升档（见伤害数字规范第 6 节）。加强只作用在每招的起手窗口 `lead` 内。

| BP | 起手表现 |
| --- | --- |
| 1 | 手部出现主色聚气粒子和光晕 |
| 2 | 粒子更密、范围更大，脚下加一圈主色涟漪 |
| 3 | 在 BP 2 基础上，起手时轻微震屏 |

各档共通的加成：
- 命中火花与震屏 ×(1+0.15·BP)。
- 粒子预算 ×(1+0.2·BP)。
- 评审页的演示数字 ×(1+0.25·BP)，只用于演示。战斗中的数字由结算决定。

评审页可以切换 BP 0～3。

### 5.3 接入战斗（`js/wuxia-battle.js`）

`index.html` 在 `bfx.js` 之后加载 `wuxia-fx.js` 和 `wuxia-battle.js`。

**接管条件**：招式 id，或经 `MOVE_ALIAS` 转换后的 id（如 `jinzhen→bh_s1`），在 `WuxiaSkills` 里有 `set:'v4'` 编排。满足时，由 WuxiaFX 的叠加模式接管 `VFX.cast` 和 `VFX.hit`。

**时序与表现**：
- `VFX.cast` 播放编排，等到 `hitAt` 再返回，战斗在这一刻结算伤害。
- 伤害数字和异常浮字仍由 `bui.js` 显示，特效这边不再重复出数字。
- 近身招式改为原地出手，不冲刺。

**图层**：
- `back` 层画在战斗背景之后、角色之前。
- `front` 层、辉光和浮字层画在角色之后。
- 压暗减半；推镜和暗角交给战斗镜头处理；震屏并入 `B.shake`。

**尺度换算**：
- 评审舞台的角色约 125 特效像素高，战斗角色约 60～65。
- 以施放者和目标的中点为枢轴，把锚点放大到舞台尺度来演，绘制时再整体缩回 k（k 约 0.5，限制在 0.4～1）。
- 叠加图层四周各留白 200/120 特效像素，放大演出时不会切边。

**沿用旧特效的情况**：素材没加载完、敌方施放、施放者不在目标右侧。

**实测**（`index.html?runtimePrototype=1#street`，萧白、苏芷对黑风喽啰 ×2 和野狼）：
- 金针（正式招式 `jinzhen`）已由新特效接管。
- 焚契破阵、松涛合阵、一剑澄江、一曲安澜是在控制台临时注册成技能后试放的，表现正常，控制台无报错。
- 测试通过：`battle-weakness-status`、`battle-auto`、`combat-sim`、`martial-lineage-v3`，以及 `battle-error-regression`。

## 6. 待定与已知限制

- **全部招式的特效**：2026-10-08 已覆盖全部招式与内功主动。其余 7 门绝招为专属编排，其余为组件库模板，见 [v4-vfx-kit.md](../archive/design/v4-vfx-kit.md)。新招式注册进战斗另有更新记录（`docs/updates/2026-10-08-runtime-moves.md`）。
- **朝向**：编排默认我方在右、面朝左。我方在左的站位暂时沿用旧特效。
- **字号**：评审页里伤害数字和浮字的大小是按特效像素空间近似的，战斗中的实际字号以 `js/bui.js` 的浮字为准。
