### 2026-10-19 序章冷读审读查出（已在剧本里改掉）

| 场景 | 原句／现象 | 问题 | 处理 |
| --- | --- | --- | --- |

| 递水·路线 B | 对“说来话长”完全不接话 | 选了和没选一样 | “说来话长，就路上说。” |

| 遇狼 | “别动，有狼。”紧接“站我身后” | 两句指令打架 | “嘘……有狼。” |
| 遇狼 | 战后“别追了！” | 一个手在抖的人不会去追狼 | “退了……先别动，等等看。” |

| 进村 | 刚打完狼，进村只字不提 | 村里头等大事，不可能不说 | 进门先报狼下到采药路 |
| 进村 | “灶上给你留的饭还热着” | 没人知道他会来 | “给蘅丫头留的饭，先分你一半。” |
| 进村 | 叶蘅说“我回家”又说“有事喊一声” | 人走了上哪儿喊 | “村西北那家就是，有事来找我。” |
| 进村 | 伤看了两遍、住处说了两遍、“客店住满”放在安排住处之后 | 重复与顺序颠倒 | 删重复，先说客店满再问空客房 |

**共同教训**：演员法能让每句话更像人说的，但“这一场漏了什么反应”（现代人的震惊、村里对狼的反应）只有冷读才看得出来。戏眼卡里要写清“这个人此刻最在意的事”，不能只写他要说什么。

## 2. 字面套路（`story_lint` 的 AI_* 规则）

| 规则 | 套路 | 例 |
| --- | --- | --- |
| AI_STOCK | 套话 | “刚才要不是你，我就交代在这儿了。” |
| AI_NOTBUT | “不是……而是……”纠正句 | “不是为了护着这些东西，是不能让他们……”（2026-10-17 审读已改） |
| AI_SUMMARY | 总结腔开头 | “说到底……”“其实……”“毕竟……” |
| AI_MOTIVE | 自报动机 | “我之所以……”“为的是……” |
| AI_THEME | 把主题说出口 | 承担、责任、成长、守护、信任 |
| AI_TRIAD／AI_ANTITHESIS | 排比、对仗 | “X 是 X，Y 是 Y” |
| AI_MONOLOGUE | 一个人连说三句以上 | 往往是在替编剧讲解 |
