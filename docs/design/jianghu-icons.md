# 江湖行卷图标规范 v2（待视觉评审）

## 改版原因

上一版 `i_jianghu.webp` 由 32×32 像素剪影放大，物品细节少，武学与心法大量使用相近的圆形底和通用形体；在桌面端 44–56 像素的卡片里，名称比图形更容易识别。该版保留为对照，不作为新素材的画风目标。

## 新目标

采用与游戏宣纸、深墨、朱砂界面相容的**精细手绘道具图**：原稿至少 256×256，透明底，斜上方暖光、冷色暗部、可见的木纹／磨损／布纹／金属反光。边缘清楚但不做粗黑描边、整数像素块或最近邻放大；最终在 48、56 和 72 像素三个尺寸审图。画面仍是南宋市井武侠，不用现代奇幻装备、发光宝石、霓虹法阵或过度华丽的仙侠特效。

图标的**外轮廓先于颜色**：缩到 48 像素并转灰阶后，相邻物品、招式、心法仍应能凭形状区分。兵器不能只换颜色；招式应显示不同兵刃、手势、脚步或作用方向；心法应显示修习意象，不把所有条目放进同一个圆环。每张图只描绘一个主体，主体占画面约 70–80%，留透明边；不含文字、数字、边框、卡片底板或 UI。

| 类别 | 区分方式 | 示例 |
| --- | --- | --- |
| 兵器 | 长短、刃形、护手、柄缠、磨损、主轴方向 | 桃木剑是横向、宽钝的木制练剑；精铁剑是竖向修长直刃；井底锈剑是斜向、折断的锈刃 |
| 护具／佩饰 | 穿戴位置、缝制方式、材质 | 粗布短打有交领和腰带；牛皮软甲有分片；青玉佩以绳结与玉雕识别 |
| 药食／杂物／要物 | 容器或物件真实形制 | 馒头、瓷药瓶、竹叶青酒壶、货签、账簿、书匣各有不同轮廓 |
| 招式 | 招式动作或结果的瞬间，不复用一枚通用拳／剑印 | 伏虎拳有虎爪发力；柳叶剑法有细剑与柳叶弧线；金针刺穴有数枚散开的银针 |
| 心法 | 呼吸节律、修习姿态和所属门派的具象意象 | 吐纳法是胸腹气息；玉泉心经有石泉水纹；本草经有草药和摊开的经页 |

七个系统页签沿用相应类别的代表图；队伍使用肖像，任务状态保留朱印。空装备槽仍用低对比度示意，但示意图与新图标同源。保留名称、数值、悬停介绍，让图像帮助扫视，不承担全部说明。

## 生成与审核顺序

1. 先按物品、招式、心法分别制作高分辨率透明原稿。提示词逐件写明历史形制、主轮廓、可辨别的关键细节和禁用元素；不能仅用类别名批量出图。
2. 先出少量跨类别样张：桃木剑／精铁剑／井底锈剑、牛皮软甲、伏虎拳／柳叶剑法、吐纳法／玉泉心经。这组专门检查同类区分度和三类风格是否一致；样张通过后再扩展到全部内容键。
3. 将原稿缩至实际界面尺寸，在宣纸和深墨两种底色上并排审图。每图记录 48 像素可读性、灰阶轮廓、材质感、时代感、透明边缘；不合格的单件重出。
4. 通过视觉评审后才打包新图集、替换 `js/menu.js` 的引用并跑 `tests/menu-icons.test.cjs`。当前运行中的 32 像素图集与脚本不在样张阶段覆盖。

当前样张阶段只改本规范并在 `review/jianghu-icons-v2/` 留预览，不改游戏运行素材。前版可重建管线见 `tools_scene/build_menu_icons.py`，用于新旧对照。

## 第一批样张记录（2026-09-30）

原稿使用透明底逐件生成，保存于本地 `review/jianghu-icons-v2/`；`preview.html` 将八件样张和旧图集并排展示，在 48、72 像素与灰阶下审阅。三把剑初稿虽然材质细致，缩到 48 像素后仍是相近的斜线，因此重出为横向桃木短剑、竖向精铁直剑、斜向断刃锈剑。第二稿在灰阶下也能凭轮廓区分。

本批还包括牛皮软甲、伏虎拳、柳叶剑法、吐纳法、玉泉心经。武学采用手势／挥剑轨迹，心法采用修习者／石泉意象。精铁剑在深色底的 48 像素状态下线条偏细；后续批量制作时要控制最细主体宽度。样张等待视觉确认后，再决定是否用于运行素材和扩展全量图标。
