## 当前规范

采用南宋武侠语境下的精细手绘墨彩图标，透明底、清楚轮廓、自然材质与集中高光。原稿建议至少 512×512，图集单格 192×192，平滑缩放至桌面 48/56/72px；不做粗像素块、最近邻放大或泛用人物剪影。

- **真实物品画实体**：兵器、护具、佩饰、药食、工具、证物以及包裹中的可学习秘籍，依据真实用途和形制绘制。
- **学会的功法画技法意象**：剑气、掌势、虎势、流风、针路、冲击或回流，以轮廓表达招式身份；不能画成写实手臂、实体教材或摆放的兵器。
- **学会的心法画修习意象**：吐纳、阴阳、气旋、山岳、内息回流、凝聚与舒展；不能画成书卷、竹简、香炉、坐垫、玉盘或器物组合。
- **高阶兵器要有明显设计增量**：护手、刃形、柄缠、镶嵌、鎏金嵌银、剑穗及受控局部辉光共同形成跨阶差异。不能只换颜色、加框或只增加放大后才可见的纹理。
- 丁级与绝级保持同等绘画完成度；品阶表达丰富度，不表达图片质量。画面主体占约 70–80%，安全边至少 8%；文字、品阶框、数量和状态由 UI 绘制。

| 类别 | 当前区分方式 | 示例 |
| --- | --- | --- |
| 兵器 | 长短、刃形、护手、柄缠、磨损、装饰与局部高光 | 桃纹木剑宽钝木质；青锋剑修长钢刃；井底锈锋保留锈蚀与旧用痕迹，破损程度以实际内容说明为准 |
| 护具／佩饰 | 穿戴位置、缝制方式、材质和独有绳结 | 归谷短衣交领腰带、牛皮护心甲护心皮分片、檀木手串木珠与绳结 |
| 药食／杂物／要物 | 容器或物件真实形制 | 馒头、瓷药瓶、酒壶、货签、账簿、书匣各有不同轮廓 |
| 功法／招式 | 技法意象与出手结果，各有独有形态 | 伏虎拳以虎势气劲，柳叶剑法以柳叶般剑气，金针刺穴以精密针路与落点意象 |
| 心法 | 内息组织、精神意象与修习方向 | 吐纳法内息回流；玉泉心经清泉与沉静气旋；本草经叶脉般生机回流，均不使用实体书卷 |

系统页签与空槽可以使用低对比度示意；保持名称、数值和悬停介绍。武学统一页面包含招式和心法分区。图标存在不等于对应机制已开放。

## 生成与验收顺序

1. 逐件确认真实内容 ID、类别、用途、建议品阶和章节状态；保留物品与已学武学的不同语义。
2. 按用户批准的 v3 参考制作高分辨率透明原稿，每件写明主体轮廓、独有辨识点及禁用元素。
3. 在宣纸、深墨底色及 48/56/72px 下并排审图，记录语义、轮廓、灰阶区分、画风和透明边缘。通用换色旋涡、写实手臂、心法实体器物均退稿。
4. 通过视觉审核后打包、映射并执行 `tests/menu-icons.test.cjs`；覆盖测试只能证明键位与技术契约，不能代替视觉验收。
5. 分别记录原稿、通过件、退稿件、接入件、上线件；有退稿或未生成项时不得写“全量完成”。
