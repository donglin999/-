## 规则

每人固定1个身份被动，不占六招式或心法栏。达到对应正式教学／参战节点后才生效；叶蘅序章没有针攻、内功或长期增益。所有触发遵守同类取高、回蓝和防护总上限，不能因被动再触发自己。先审下表，不在当前代码添加字段。

| 人物 | 专长候选与用途 | 激活阶段／限制 |
| --- | --- | --- |
| 萧白 | **学而后应**：本战首次主动观察／防御后，下一个已学基础招式少耗1MP | 归云谷正式基础课后；不得免费施放最低1MP招式 |
| 叶蘅 | **循脉记要**：分支前首次正式照护后，下一次照护少耗1MP；针攻线首次命中已看破目标，下次针攻少耗1MP；医线首次持续恢复生效，下次维持少耗1MP | 本战共享一次机会；后两项仅第13月后对应路线生效 |
| 苏芷 | **临证取舍**：本战首次治疗濒危同伴时可额外净化1项可驱散异常 | 正式参战；未使用时卡面标明可用，不无限触发 |
| 唐照雪 | **识招记锋**：本人第一次用剑命中实际弱点后，再揭示该敌人另一未知弱点 | 每战一次；已全揭示时无额外伤害奖励 |
| 段明棠 | **开架**：本战首次对完整护盾敌人命中拳弱点时额外削盾1点 | 计入该招最终预算与全体硬边界6，不叠成无条件削盾 |
| 石长庚 | **替人站稳**：本战首次实际代人承伤后，自身免受下一次可驱散迟滞 | 护卫训练后生效，不增加代伤次数 |
| 闻疏桐 | **认路**：首次安排下回合前移时，受益者同时免受一次可驱散迟滞 | 必须已学对应阵位课 |
| 岑霜 | **留退手**：首次带暴露完成进攻后，下次主动防御解除本人的暴露 | 要再花一次行动，不免费抹掉强攻代价 |
| 戚铮 | **按约出刀**：本战首次带暴露实际受伤且存活后，自身获得1BP | 遵守BP上限5；不恢复HP、不抵销暴露增伤，不因反击再触发 |
| 徐令仪 | **照约行事**：本战首次交予BP发生溢出时，将其中1点溢出转为受益者2MP | 仅转一次，遵守每轮回蓝2MP上限；接收者MP已满则无转换 |
| 沈雁回 | **辨动**：本战首次延后成功时，解除该敌人一个可驱散攻击增益 | 无合格增益时不另增伤害；不可驱散首领阶段强化 |
| 晏小楼 | **识场**：本战第一次两段投掷可在两个目标间逐段指定 | 总段数与威力不变；只能用已学投掷技 |
| 乔行舟 | **熟水识险**：首次救援并成功净化迟滞后，受益者下回合额外前移一位 | 要求已经学会回舟接客；与其他前移取最高 |
| 柳含烟 | **留一处静**：本战首次队伍防护实际替濒危同伴减伤后，该同伴恢复5%最大HP | 全队共享一次；先存活再恢复，不能复活 |
| 秦绯鸢 | **掌节拍**：本战首次引步可选择自己下轮末位，令受益者本次招式少耗2MP | 玩家可不承担这个代价；消耗最低1MP，不影响实际BP支出 |
| 阮青雀 | **知缝**：首次接应标记若因目标先倒下而未被消费，本轮可自动转给另一个已看破且未破势敌人 | 仅转一次；无合格目标则到期，不增加总削盾 |
| 陆衡 | **押后验人**：本战第一次在我方末位主动防御时，给当前最低血量同伴一次10%卸力 | 按本轮结束到期；若没有后续敌方攻击便无收益 |
| 霍逐尘 | **辨器**：第一次锤击命中实际棍弱点时揭示同目标另一未知弱点 | 每战一次，不推断未命中目标 |

行动队列、合法目标、能否延后、消耗与削盾预览对所有角色开放，不锁在天赋后。专长都应产生规则中可验证的额外结果，正式数值须在沙盘比较价值。

## 传授边界

基本剑拳、常用针技、护卫与职业基础动作可经本人许可传授；具体教学须有来源，不默认所有同伴能学所有武学。人物长线形成的个人招式（如《照川落日》《邀锋护席》《留缝接应》）按清单 `access:personal` 保留本人使用。归云谷高阶作为师门传承仍有许可学习路径。

“主角能学很多”与“主角复制全部人物天赋”分别处理。暂不增加每人一条底力槽；未来若做临机爆发，须逐人设计、单列素材和UI预算，再评审。
