## 3. 行动与成本模板

保留现有弱点、护盾、破势、BP骨架。下列MP预算按原型调整，不直接写入现有技能。

| 标记 | 作用 | 拟议基础内力 | 基础结算约束 |
| --- | --- | --- | --- |
| A | 入门／效率型进攻 | 丁2、丙4 | 多段拆分总伤害，不每段复制整招倍率 |
| B | 战术进攻 | 乙8、甲14 | 条件增伤有上限；群攻单目标预算低于同阶单体 |
| G | 卸力／援护 | 丁3、丙5、乙8、甲14 | 占本人一次行动，防护次数写在卡面 |
| H | 医疗／维持 | 丁4、丙6、乙10、甲16 | 急救、持续恢复、增益分别显示；医药演出不额外暗扣背包物品 |
| X | 绝级招式 | 24，必须投入3BP | 施放后的下一次自身行动禁用所有绝级；之后可重新积攒资源使用，保命有额外限制 |

标准招式占一次行动。BP储存上限5、一次投入0—3；战斗初始1BP，第二回合起若上回合未花BP则自然增加1。继续沿这个基础节奏验证，支援所得另计。绝技必须3BP；威力已经包含满蓄势预算，不再额外乘一次普通BP倍率。

每招按[清单](catalog.json)的 `boost_mode / bp_effects / shield_budget_by_bp` 结算：

- 普攻：1＋BP段，每段一次命中；普通技能不自动继承这个规则。
- 加段型：本批拨云回锋、折光三叠、循隙针、飞燕点枝，增加命中段数，总威力保持0BP基准并分摊，适合花BP拆防。
- 威力型：总威力暂按1／1.35／1.7／2.1，段数固定；千岚归一满BP仍3段。
- 治疗型：恢复量暂按1／1.25／1.5／1.8，净化不跟着变多；维持型按2／3／4／5次受益者行动，不同时提高每跳恢复。
- 防护型：默认一次卸力为25／30／35／40%，人数与次数不增加；雨住留灯只对物理伤害，本轮结束即退场。
- 改序型：改变顺序的次数固定，BP只加强明确附带收益。回袖引步仅BP≥1时附10／15／20%卸力，0BP也可改序。
- 资源型：同担一线付8MP和一次行动，按投入给予另一人2／2／3／3BP，不能对自己使用；每个受益者每回合从所有同伴合计最多收到3BP，收到的当回合不得再转赠。上限溢出在确认前可见，默认不返还施者；无任何有效收益时不能施放。

这些BP曲线是本作方案，不把旧代码按段数加BP的算法直接带入新表。技法表现轨迹可比结算段数多，但实际伤害、削盾时点必须对齐。

主动招式装配最多6格，普攻、防御、物品不占格；每项招式（含医疗和身法）占1格。沿当前代码3→4→5→6的容量梯度，建议将扩格从旧境界等级改成首季基础考校、年一末、年二主修成果，分别开4／5／6格。只要补做公开考核即可扩格，不要求指定恋爱或支线；旧等级门槛与新教学节点的替换仍待评审。已知招式可在战外免费替换，入战后固定。

新招式未写冷却则下一次行动可再用。《百草回生》暂设施放后两次自身行动不可再次施放。绝级施放后的下一次自身行动需调息，不能使用任何绝级，但可普攻、普通技、防御、物品；受控跳过行动不缩短调息。取消全部绝技统一每战一次的限制；《一息相续》仍规定同一受益者每战只能获得一次该保护，保护持续至其第二次行动结束或被消耗，不能靠多个医者轮流延命。

## 4. 状态词典与防止循环

> 2026-10-08：异常状态（中毒、流血、内伤、封穴、眩晕、目眩、心乱、惊惧、迟滞）以[异常状态 v1](../status-effects.md)为准；本表保留卸力、援护、守势、削弱、暴露、看破、濒危的定义。迟滞在两处定义一致。

| 术语 | 本提案精确定义 |
| --- | --- |
| 卸力 | 对下一次伤害减伤；默认25%，甲级群体仍每人一次。持续至受益者下次行动开始，或先被消耗；选择即将行动的队友前要显示有效窗口 |
| 援护 | 绑定一名同伴，替其承受下一次单体攻击，自带25%减伤；至施者下次行动开始。群攻、处决、不可转移机制不转移。护卫者倒地则解除 |
| 守势 | 自己主动防御／有效援护后获得的个人准备状态，最多1枚，保留到下一次主动攻击结算后；有明确赋予来源才产生 |
| 削弱 | 默认目标下一次攻击伤害降低15%，首领7.5%；至目标下次行动结束到期。同类只取最高 |
| 暴露 | 默认下一次受击伤害增加10%，至下次自身行动结束；无受击也到期。强攻代价不可用本条心法自动完全抹去 |
| 迟滞 | 下一回合行动排序降低；不是跳过回合。解除仅针对可驱散迟滞 |
| 看破 | 揭示未知弱点，不凭空制造弱点；已全看破时看破型伤害技仍正常攻击 |
| 濒危 | 当前HP≤30%；临时濒危保护不清除伤病、不自动复活、不替代剧情医疗 |

“回合”指全员各行动一遍；“自身行动”指该角色一次可用行动。持续治疗按受益者行动结束触发，施加当下不额外触发；两回合增益计受益者两次行动，覆盖同名时取剩余较长值，不相加。《归息续照》对同一份增益只允许刷新一次，重新施放是新实例且须重新付费。

以下均为新内容原型护栏，不回溯宣称现有代码已实现：

- 削盾按每招四档预算；普通单击最多1点，崩石短打等明确条件可额外1点，折光三叠可3／4／5／6点。个人天赋或接应标记额外削盾需在预览单列，最终硬边界为每行动每目标6点；常规招式不能因为硬边界是6便削6点。群攻不能把多人预算集中给一个目标。反击类护卫由后续反击实际命中结算，反击最多削1点，不当作施放防护当下命中。
- 首领默认不能被普通招式直接取消行动；对标明可打断的蓄力，先通过削盾破势实现。各首领具体抗性须在意图说明中可见。
- 同类增益取最大；不同来源总减伤上限60%，总减耗上限30%，有消耗技能最终MP至少1。条件伤害加成采用同一加法池；数值补充提案将V2的50%测试上限收窄到30%，不包括BP与破势倍率，需用完整循环验证。
- 援护一次只转移一次；反击不再触发反击、援护收益、BP奖励或装备连锁。装备触发与心法同名收益共享“每轮一次”计数。
- 所有“少量返内力”首版按1—2MP验证，单角色每轮来自装备与心法合计最多2MP，战后恢复另计；不得无限自疗回蓝。
- “主动护卫”不要求空间移动。秦绯鸢、阮青雀、闻疏桐的换位先用援护关系与短步表现，真正站位系统另立项。

## 5. 心法装配、学习与改修

建议延续1主修：首年0辅修，年二一次基础考校后开1辅修，出师开2，游历后段明确突破事件开3。不使用旧原型13/25/39级直接替代三年剧情节点；这是待评审的迁移提案。

内功主修、辅修是运转位置，均固定一主动和一被动。三层、五层只强化该门被动，取消旧的「选择第三／第五层特性」规则。保持已有运转槽、门派和阴阳兼容限制；未运转内功保留层数，但主动与被动都不可用。主动费用、冷却和行动规则见功法结构规范v2。

首次教学获得第1层，正常训练、实务复盘积累熟练，第三与第五层强化同一个被动；不允许战斗中防御刷到满层。每日／每期重复低风险练习的有效收益递减，正式体力价格沿培养活动责任文档。不同心法的训练阈值在原型按完整年度预算校准，当前不编造已经平衡的经验曲线。

建议在安全休整点免费切主修、保留层数；一次休整后生效，取消旧原型“清空内力并惩罚三场”的刷战恢复方式。作战中不能换主修；出城前展示当前内息、兼容与可用招式。该改动单独列为评审项，未改代码。

## 6. 获得资格与防卡关

公开丁／丙基础课可经付费、劳动报酬、借用器械或师友担保取得；门派乙／甲需要实际合作与授业许可，不要求转籍。绝学只从长线成果取得，不靠偷窃随机掉落。

数值条件用“已知基础→练习记录→明示考核”表达；达不到时给出课程和复试。基础课错过可回谷预约，外派关键教习不在时可约下一窗口；不能用离场NPC堵死唯一主线。武艺低的主线采用同伴支援、准备或剧情替代方案，导师不得凭空赠送整套高级武学。

每条取得记录后续需补 `event_id、teacher_id、location、窗口、前置AND/OR、体力、失败出口、替代机会`。本轮目录是内容提案，尚未伪造排期注册。

## 7. 行动顺序与角色模块

每回合开始展示本轮确定队列和下轮预估。前移／后移不重置“已行动”标记，不能把已行动者插入队列再来一次。多个同轮改序按实际施放先后处理，已锁定剧情动作不动。

回袖引步只选本轮未行动的另一同伴并移到自己之后；断渡擒锋只移到本轮末尾，首领须有可延后标记，且同目标不能连续回合延后。下轮“前移一位”按正常排序完成后交换一个合法相邻位置；无可交换位则不动。迟滞先算，前移后算，同类前移不叠层；具体优先级须写在预览。

师门传承、已学技能、主辅心法、[人物专长](identity.md)、场景技艺分别记录。专长不随传功复制；个人招式按清单许可，不因换武器获得。先不添加底力槽，也不让绝级品阶兼任角色身份条。
