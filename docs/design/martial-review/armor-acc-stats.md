## 1. 护具

**防御**：中装基础值按品阶为丁 4、丙 7、乙 10、甲 14、绝 16，约占阶段参考防御（budget.json anchors.defense）的 35–40%。各类型乘以倍率：

| 类型 | 防御倍率 | 副属性（品阶序号 gi） | 主属性要求 | 定位 |
| --- | --- | --- | --- | --- |
| 轻 | 0.70 | 闪避 +(2+gi)% | 身法 | 剑、身法、暗器路线 |
| 中 | 1.00 | 气血 +8×gi | 根骨 | 通用 |
| 重 | 1.40 | 身速 −1，格挡 +2×gi | 根骨 | 护卫、拳路 |
| 医 | 0.75 | 内力 +6×gi，治疗 +5% | 悟性 | 医者、音律 |

品阶序号 gi：丁 1、丙 2、乙 3、甲 4、绝 5。装备要求按主属性：丙 5、乙 7、甲 9、绝 11。

**数量**：原 8 件补到 12 件，新增四件：
- 丙级重装：牛皮护心甲。
- 甲级轻装：岚纹轻衫。
- 甲级重装：铁鳞软甲。
- 甲级医袍：百草织袍。

**机制**：原有护具的“略减”“小恢复”都写成了具体数字。例如护运软甲“援护承伤再 −10%”，守诺旧氅“首次援护濒危同伴后自身回复 10% 气血”。

## 2. 佩饰：战斗类与功能类

**数量**：原 9 件扩到 37 件，其中战斗类 22 件、功能类 15 件。按品阶分布：

| 品阶 | 件数 | 说明 |
| --- | --- | --- |
| 丁 | 2 | 低阶没有必要多做 |
| 丙 | 7 | — |
| 乙 | 11 | 中高阶为主 |
| 甲 | 10 | 中高阶为主 |
| 绝 | 7 | — |

**词条数**：丙 1–2 条，乙 2 条，甲 2–3 条，绝 3 条。原有佩饰的技能影响（属性亲和、抗性、持续缩短）保留，模糊描述全部改成具体数字。

**战斗类词条**：

| 方向 | 词条 |
| --- | --- |
| 属性与数值 | 五维、气血、内力、防御、暴击、闪避、身速 |
| 条件增伤 | 弱点、破势中、对精英与首领 |
| 治疗 | 治疗量、受到治疗 |
| 回合回复 | 每回合回气、回内 |
| 开战与先手 | 开战蓄势 +1、首回合身速、首回合必定先手 |
| 抗性 | 全部异常抗性 |
| 濒危保护 | 致命伤以 1 点气血撑住，或濒危自动卸力（两者互斥，取较强者） |
| 援护与卸力 | 援护减伤、卸力加成、护卫后回内、守势后减费 |

**功能类词条**（挂在战斗之外的系统上）：

| 词条 | 作用 | 代表佩饰 |
| --- | --- | --- |
| 银两获得 | 战斗胜利结算 | 厌胜钱、算盘坠、行商牙牌 |
| 修为获得 | 战斗胜利结算 | 玉蝉、长命金锁 |
| 福源（掉落率） | 战斗掉落 | 吉祥结、福寿钱、桃木剑坠 |
| 拾遗 | 战后有几率另拾得一件药食 | 福寿钱、桃木剑坠 |
| 逢凶化吉 | 战败不损失银两（原规则是扣一半） | 桃木剑坠 |
| 商店折扣 | 购买价 | 算盘坠、行商牙牌 |
| 熟练成长 | 功法升重 | 玉蝉、长命金锁、书院闲章 |
| 心法修炼 | 心法进层 | 笔管坠、书院闲章 |
| 战后回复 | 气血与内力 | 指南鱼坠 |
| 食药恢复 | 道具 | 药香荷包 |
| 酒量 | 酒类回内 +50% | 小酒葫芦 |
| 犬缘 | 同行的大黄攻击 +15% | 犬牙坠 |
| 好感获得 | 人物关系 | 犬牙坠、长命金锁 |

标“（独有）”的词条只出现在那一件佩饰上。

**上限**：
- 条件增伤：与武器、心法共用 30% 加法池。
- 异常抗性：同一异常合计不超过 60%。
- 暴击率：不超过 35%。

**价格**：

| 品阶 | 佩饰价格 | 护具价格 |
| --- | --- | --- |
| 丁 | 30 | 30 |
| 丙 | 100 | 90 |
| 乙 | 260 | 240 |
| 甲 | 650 | 600 |
| 绝 | 不出售 | 不出售 |

绝级不出售，来自人物篇、大支线、奇遇，取得途径随事件排期登记。

## 3. 模拟验证（每组 40 个种子，23520 场）

**接入方式**：
- 护具防御按“实际防御 − 当阶段应有防御”修正。应有防御取中装梯度：第一年丁 4 → 丙 7，第二年至出师乙 10，游历起甲 14。
- 护具的气血、内力、治疗直接计入。
- 佩饰的战斗词条计入，包括属性、暴击、条件增伤、开战蓄势、每回合回复、全抗。
- 功能词条不进战斗模拟。
- 名册按角色定位换装（`balance/sim/roster.json`）：

  | 定位 | 护具 | 佩饰方向 |
  | --- | --- | --- |
  | 输出 | 轻装 | 暴击、破势 |
  | 破势 | 中装、重装 | 气血、破势 |
  | 护卫 | 重装 | 援护、回血 |
  | 医者 | 医袍 | 内力、治疗 |
  | 辅助 | 轻装、中装 | 先手、蓄势 |

**结果**（全套装备数值对照不计装备数值）：

| 队伍 | 平均回合 | 剩余气血 |
| --- | --- | --- |
| 稳定入门 | 5.78 → 5.75 | 86.6% → 87.9% |
| 破势爆发 | 4.12 → 4.07 | 83.2% → 83.6% |
| 稳守游历 | 7.30 → 7.37 | 83.7% → 86.2%（阵亡减半） |
| 松风接应 | 6.09 → 5.90 | 86.1% → 87.3% |
| 归烬强攻 | 4.39 → 4.22 | 85.5% → 87.1% |
| 清徽和鸣 | 5.12 → 5.07 | 85.7% → 86.6% |
| 清徽笛阵 | 6.52 → 6.48 | 82.9% → 85.6% |

- 胜率不变：普通、精英 100%，头目 99.9%。
- 各阶段回合变化在 ±7.5% 以内。后期快约 2%，来自佩饰的对精英、首领与破势增伤，属于装备该带来的成长。
- 模拟数据：`balance/sim/weapons-v1/results-full-gear-*.json`。

## 4. 命名评审（2026-10-09）

按 [物品与装备命名规范](../item-naming-standard.md) 逐件核对：与现有 79 件装备、30 件正式物品不重名；名称与图标器形一致；不暗示未实现的功能。每件都补了来源、命名含义、器形锚点和玩家释义（catalog.json 的 `naming`，脚本里的 `NAMING` 表），`node tools_scene/check_item_naming.cjs` 通过。

改名两件（ID、数值、图标不变）：

| 原名 | 新名 | 原因 |
| --- | --- | --- |
| 定风珠 | 惊鸿青珠 | “定风珠”是《封神演义》里的法宝，名字暗示能定风的神异，违反“不暗示未实现功能”。新名取曹植《洛神赋》“翩若惊鸿”的迅疾，对应首回合先手与身速。 |
| 燕尾银簪 | 飞燕银簪 | 与同为乙级、同走身法路线的武器“燕尾飞刃”用了同一个“燕尾”，放在一起容易混淆。 |

其余 30 件保留原名。几件说明：
- 指南鱼是宋代实物，见《武经总要》，合乎时代。
- 牙牌取宋时牙人凭牌入市。
- 桃木剑坠、厌胜钱只取民间吉物之意，不具法术。

**来源**：甲、绝两档的来源都标“提案”，状态为 `design_proposal_pending_story_review`，等对应人物篇、支线排期后再核。
