## 1. 金庸、古龙内功是怎么起名的

来源：维基百科《金庸笔下武功列表》《古龙笔下武功列表》（二手整理，检索日期 2026-10-07）。下表只用来归纳规律，不作为本作素材。

| 规律 | 原作例子（仅作参照） | 名字靠什么成立 |
| --- | --- | --- |
| 典籍出处 | 北冥神功（《庄子·逍遥游》）、太玄经（扬雄《太玄》、李白《侠客行》）、无妄神功（《周易》无妄卦）、庖丁解牛功（《庄子》） | 一个有来历的词，读者一看就有画面，懂的人还能读出深意 |
| 阴阳数理 | 九阳神功、九阴真经、纯阳无极功、先天功、混元功、太极功 | 道家术语直接指出内息性质 |
| 自然意象 | 紫霞神功、寒冰真气、明玉功、天水神功 | 一个颜色或物象，同时暗示真气的样子 |
| 佛门修持 | 易筋经、小无相功、龙象般若功、神照经 | 佛经用语，表现修身与心性 |
| 名字自带代价或悖论 | 嫁衣神功（练成要先毁去功力）、天长地久不老长春功 | 名字本身就是故事，带出练功的代价 |
| 后缀分档 | 功、神功、经、真经、心经、真气、大法 | 后缀暗示分量：“神功”“真经”多用于顶级，“心经”“功”较常见，“大法”常带邪气 |

**本作的取用规则：**
1. 学的是方法，即“典籍出处＋本门意象＋合适的后缀”，不拿原作名字改一两个字。
2. 不使用原作中辨识度最高的核心词组合，例如九阳、九阴、北冥、易筋、紫霞、明玉、嫁衣、无相、太玄、神照、吸星，也不用“先天功”“混元功”这类原名。“先天”“混元”这种通用道家词可以单独使用，但不能与原作的后缀凑成同名。
3. 典籍出处尽量选南宋襄阳一带人物读得到的经史诗文，例如《庄子》《周易》、陶渊明、谢朓、陶弘景，并且要和门派气质对得上。
4. 后缀随品阶加重：丁、丙用“法、篇、功、心法”，乙用“诀、真气、真劲、息”，甲用“经”，绝级可用“神功”，也可用“诀”（归云谷《万壑归元诀》由用户定为“诀”）。
5. 一门内功只有一个名字。主动技能沿用现名（敛云、观岚、归元等），等本稿审定后再看是否跟着改。
