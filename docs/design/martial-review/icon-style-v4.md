# 技能图标风格 v4（试样）

状态：草稿　最后核对：2026-10-19（原记：**2026-10-08 用户认可 C 版“精绘”方向（“可以吧，暂时就这样”）；尚未批量重画**。2026-10-08。用户反馈现有技能图标“AI 味道有点重”，要求参考《大侠立志传》《逸剑风云决》等游戏的技能图标重新设计。选定后取代 [五档生成标准](icon-tiers.md) 中的构图与画法部分，品阶分档原则保留。试样文件：`art_sources/martial_icons_v4_trial/`。）

## 1. 现有图标为什么有“AI 味”

对现有 64 张招式图标（`assets/ui/martial-moves-v3/`）的诊断：

1. **没有图标容器**：透明底上漂浮一团气劲，像特效贴纸，放进技能栏不像一个“技能”。
2. **构图雷同**：多张是左右对称的蝴蝶形或 X 形气浪，换个颜色就是另一招。
3. **细节堆砌、没有主次**：碎石、飞溅、漩涡、水花层层叠加，缩到 48px 只剩一团色块。
4. **假水墨质感**：边缘随机的墨点和飞白是生成模型常见的质感，不是有意识的勾线。

## 2. 参考游戏的做法

| 游戏 | 做法 | 借鉴 |
| --- | --- | --- |
| 《大侠立志传》（官方 wiki 功法图鉴，84px） | 圆形实心徽章、深色底；一个主体（刀、拳、手、扇、锤）加几道运动线；一图一个主色调；斜向构图、强对比；像素画 | 固定容器、单一主体、主色调、强对比 |
| 《逸剑风云决》（逸剑 wiki 武学，64px） | 白色剪影／阴刻版画式图形（兵器、人物姿态、龙虎蛇、拳），外圈一层品质色光晕（绿、蓝、金、暗金、红） | 剪影清楚、线条统一；品阶靠外圈表达，不靠堆细节 |

《侠客风云传》在攻略站只有游戏截图，没找到清晰图标，本轮未作参考。参考图只用于分析，不作为生成时的参考图输入，不照抄任何一款。

## 3. v4 规范（草案）

- **容器**：每个图标都是完整的圆形徽章，深墨色底，外圈一道边框。品阶只体现在边框与纹饰上：丁素灰细边、丙青蓝双边加刻痕、乙淡紫回纹、甲赭金云纹压角、绝朱砂边配暗金线与小朱印。
- **主体**：只有一个主体（兵器形态、掌印拳印、松鹤虎云等意象），加 1–3 道运动线；不画实体手臂（沿用已批准的“功法为意象”原则）。
- **颜色**：主色按属性：炎朱红、寒霜蓝、雷金紫、风青绿、阳金色、阴黛紫；只有兵器类、无属性的招式用墨色。每张 3–4 种颜色。
- **画法（待选）**：
  - **A 木刻剪影**：中国木刻版画、剪纸式平涂剪影，边缘干净，主体用属性主色。
  - **B 白描剪影＋光晕**：主体为米白剪影或阴刻线描，外侧一层属性色光晕（接近逸剑的做法，但用属性色而不是品质色）。
- **禁止**：对称蝴蝶形构图（题材本身需要上下对称时除外）、碎石飞溅、烟雾云团、随机墨点飞白、渐变天空、文字、西式奇幻元素。
- **验收**：缩到 48px、转灰阶后一眼认出主体；同一门派的图标并排时轮廓互不相同。

## 4. 试样

6 个招式覆盖丁到绝五档：试锋探路（丁·剑）、金针刺穴（丙·暗器·寒）、叠岚掌（乙·拳掌·阳）、千岚归一（甲·剑·风）、焚契破阵（甲·刀·炎）、一剑澄江（绝·剑·寒），A、B 两种画法各一张，共 12 张。提示词在 `prompts/`，生成通道为 `codex exec` 内置 image_gen（服务端选模型，提示词中写明 gpt-image-2.5，不能据此认定实际模型）。

## 5. 试样结果与决定

- **A 木刻剪影、B 白描光晕**：用户评价“太简陋”，不采用。对照图 `comparison.png`。
- **C 精绘**（采用方向）：沿用已批准的[品阶评审样张](../../../art_sources/xiangyang_icons_v3/style-approved.png)的精细手绘墨彩与光影，作为参考图输入；方形深底图块加品阶边框（丁旧铁细框 → 丙青铜 → 乙暗紫铜回纹 → 甲鎏金卷云 → 绝朱漆描金加小朱印）；单一视觉焦点、主体约占七成；背景随品阶从纯墨底到完整小场景。对照图 `comparison-C.png`，提示词 `prompts/*_C.txt`。

### 批量重画前要修的问题

1. 千岚归一、焚契破阵仍是交叉构图：改为三股气流螺旋收成一道剑锋；刀从一侧劈入、纸卷向另一侧裂开。
2. 丁、丙级在 48px 偏暗：低品阶主体提亮、加粗。
3. 叠岚掌掌形不明显：给掌风加一点掌形轮廓，仍不画手臂。
