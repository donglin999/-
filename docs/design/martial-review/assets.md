## 画风与文件

复用批准参考[style-approved.png](../../../art_sources/xiangyang_icons_v3/style-approved.png)的笔触与意象语言，招式／心法的装饰密度以[五档标准](icon-tiers.md)为准。参考中的文字与格子不进入单件；低阶不得借用高阶格子的金线、光核与气场。

- 精细手绘二维武侠墨彩、自然细墨边、清楚轮廓、集中高光；静态UI图标不做粗像素。
- 原生PNG RGBA至少512×512；生产512帧四边至少48px安全边；运行图集192×192。制作从原生透明稿开始，棋盘纹不算透明。
- 主体占70—80%，长剑／长篙用斜构图，旋转和缩放需保持刃柄与铁脚均完整；不能为了填方格缩短真实形制。
- 已学技能画技法，心法画内息，装备画实体；秘籍与配方只有真实可拾取物品才画书册。
- 品阶以轮廓、结构、细节至少两项递进。辅助色沿丁灰白、丙青蓝、乙淡紫、甲赭金、绝朱砂暗金；语义色优先，不强制医术改紫色。

## 逐件提示词使用

[catalog.json](catalog.json)每项已保存可单独提交的 `prompt` 和 `negative_prompt`，不是只有通用风格一句话。提示词由共同规格、品阶设计增量、该件独有主形组成；修改后仍逐件保存完整文本。

关键字段：`id、icon_id、kind、grade、phase、effect、obtain、visual、prompt、negative_prompt、planned_path、runtime_id、status、asset_status`。心法另有性属／槽位／层数特性，招式另有兵器／预算模板，装备另有槽位／推荐使用者。

`runtime_id:null`说明尚未审定迁移；`planned_path`只是未来目标，不是已存在图像。机制设计仍为 `draft_pending_review`；10张五档图标为 `sample_user_approved`，本轮新增图标为 `generated_pending_review`；41件装备保留原状态。实际完成数量以[生成进度](../../../art_sources/martial_icons_full_v1/progress.json)为准。样张文件使用 `sample_path`，不替换正式路径。

## 图标与战斗声画如何对应

静态技能图标给出“识别形状”，战斗通过**代码粒子、方向、节奏、命中与音效**表达同一技法。禁止把整张图标贴到战场当特效。按既有[品阶与技能演出](../grades-and-skill-vfx.md)和当前粒子驱动继续深化，以下只是本批分镜提案，未修改引擎。

| 家族 | 蓄势→出手→命中→收势 | 声音语义 |
| --- | --- | --- |
| 归云剑 | 收拢云隙→直锋快速穿出→单个结实亮核→两侧气息回落 | 短吸气感风声、清亮剑啸、硬接触瞬态 |
| 照川剑 | 极短稳锋→折线试探→末击锐利爆点→断然停光 | 几次有间隔的利刃切风，末击更厚 |
| 合川拳 | 下沉聚力→粗短气楔→钝冲与地面反馈→碎尘快速落地 | 布料／挥拳、低频身体冲击，少长尾 |
| 松风协作 | 分向流线先标受益者→错开卸力→偏转短亮→静白退场 | 轻风、刃擦，控制技能避免爆炸声 |
| 归烬强攻 | 不闭合余烬→折角突刺／厚斩→短促碎锋→清楚撤路 | 短刀尖锐瞬态、刀击厚响，火色不配火球爆炸 |
| 叶蘅针攻 | 可数落点先隐现→前慢后快针束→三处准确命中→收针 | 细锐破空、三次不同轻重击点，避免铃声 |
| 医术 | 目标定位→针脉连续接续→温白恢复节点→短息消退 | 细布／药具动作和短柔气声，不整段持续蜂鸣 |
| 长兵、扇伞 | 杆线／扇骨弧明确→格挡／拨开→接触点闪击→回护 | 木／铁接触、扇骨开合；不靠长尾掩盖命中 |

**三档剑法评审脚本候选**：乙《一线开晴》先慢蓄一道主线，再快出一记重锋；甲《千岚归一》三路先后进场，左右试锋停顿半拍，中锋突然加速，末击压出宽碎锋；绝《云开见山》两翼大片云势缓慢展开、数路粗剑气分别停蓄，主剑瞬间贯穿，宽阔山形锋面收束。视觉轨迹可多于结算段数，命中亮核跟真实伤害时刻一致。

高阶的壮阔来自覆盖宽度、前后景、粗细、速度差与高潮顺序；不是把同一弧形复制几十次。震屏、闪白、顿帧和总粒子预算沿现有驱动上限，低特效设置保留主轮廓与打击节奏。甲／绝正式逐帧数值在确认静态身份后另审，不在本轮声称已经达成“炫酷”。

音效优先复用项目已审的开源／CC0刀剑拳声；新增下载逐文件核对许可与来源，不能把语音MiniMax工作流当作攻击音效来源。混音分挥动、接触、破势三层；同一行动多段采用变化采样，限制同时发声数，防止刺耳叠音。

## 后续生成顺序与验收

用户已批准五档10张样稿，按[固化流程](icon-production.md)扩展全部64招式与18心法。装备另行安排：练习剑、流云剑、归山与折扇优先检查形制；装备样稿不阻塞已授权的功法图标生成。

每件在48/56/72px、宣纸／深墨、灰阶下审核，记录：内容准确、主形辨识、同类不重复、材质／品阶差异、透明边缘、无裁切。需实际成图后保存原稿SHA-256、生成工具及实际返回模型、提示词版本、审核人和结果；不要预写某模型已经生成。

状态流转：待设计审核→可制作→已生成待审→通过／退稿→已打包→已接入→已发布。任何返修重置原稿审核；素材覆盖检查不能代替视觉审图。首批5图保留返修记录，其中3项已有新一批版本；新生成图标仍待用户评审，五档10张样稿已获确认；均未正式打包或接入。

## V2：机制差异进入图标和技能卡

新BP／改序作用已同步回[123项清单](catalog.json)的逐件完整提示词，数量不变。角色18项身份被动暂用人物头像旁文字说明，不自动增加18张技能插画或一套底力条。

- 同担一线：力点在两条气流之间交接，避免继续画成护盾。
- 回袖引步：一束白线被前引；雀步换位则是后侧承接，两者不能只换颜色。
- 留缝接应：细锋撬开防线、后续锋势沿缝进入，区别单次高伤斩击。
- 回舟接客：孤立一点被接回；雨住留灯是宽弧覆盖多点，范围一眼可辨。

运行UI另画职责小标和0／1／2／3BP预览：实际段数、预计削盾、目标、MP、持续、行动顺序变化、限制。未知弱点不泄露精确必削盾结论，应显示“命中对应弱点时至多N点”。绝技写明3BP和调息；不把规则文字烘焙进原图。

预览模板、职责小标可以程序绘制；本轮只规定语义，未创建新UI资产。甲绝演出保持原先慢蓄、快击、宽主形的方向，但必须跟新的实际段数和资源结算对齐。
