## 建议采用的设计顺序

**先定一场战斗应该怎样打完 → 定各阶段普通队伍能做什么 → 反算敌人与资源 → 检查跨阶段变化 → 用完整运行与真人测试校准。**

| 层面 | 要控制的内容 | 暂定评审起点 |
| --- | --- | --- |
| 普通遭遇 | 战斗时长、受击压力、耗药 | 3—5回合；首次见新机制先给低压力示范 |
| 精英 | 合作与准备 | 5—7回合；允许有明确可识别的针对方法 |
| 主线头目 | 爆发窗口与阶段变化 | 7—10回合；新阶段先预告，不突然免费多打一轮 |
| 成长 | 同期不同培养路线差距 | 主线只按必达收益与普通装备设计；专精奖励效率与玩法 |
| 装备与技能 | 一次替换的真实收益 | 看四回合输出、行动数、续航；不只看面板攻击 |
| 地区切换 | 同配置面对相邻普通战的变化 | 实际输出压力变化超过15%、战斗长度变化超过25%就复审 |
| 随机波动 | 同一队伍的坏运气 | 记录高分位伤害与首动前倒地率；不只看平均胜率 |

这些比例是本作的**报警线和目标区间**，不是其他游戏公认标准，也不是达到这些数值就必然好玩的证明。正常头目与普通战不直接做“相邻普通战”比较。

## 本次发现的主要风险

- 旧减法防御接近临界点时，一件装备可能让有效伤害翻倍。
- 头目半血立即追加行动，可能出现同回合压力突然翻倍。
- 固定百分比治疗随目标血量、技能成长与BP同时放大；双医队续航可能过强。
- 队伍从2人变3人，增加的是行动数；不能当作普通几级升级。
- 盾值6→7可能令拆防从2次行动变3次，不能把“只加1盾”当成小改动。
- 三年出师、首次辅修、新同伴、换甲级武器若同时发放，会形成多个成长奖励叠加。
