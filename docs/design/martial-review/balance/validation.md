# 防止难度跳变的验证门槛

状态：草稿　最后核对：2026-10-19

[数值目录](README.md) · [现行测试限制](../../../archive/design/martial-review/balance/current.md)

本页是开发与验收合同。本次只运行了原有105次简化测试和离线算表，**以下完整矩阵尚未运行**。没有正式运行证据前不能把提案状态改成“数值完成”。

## 1. 四条测量轴

| 轴 | 至少记录 |
| --- | --- |
| 时间 | 总回合、第一次破势的行动数、破势覆盖率、准备／输出／恢复行动占比 |
| 生存 | 首个行动前倒地、各人最低HP、同轮被集火最大伤害、被控损失行动数 |
| 资源 | 进出场HP／MP、BP获得与花费、药品、连续战中补给消耗；不能每次都满血重置 |
| 决策 | 不同策略胜负、失误一次的后果、是否只有特定同伴／绝技可解、是否出现无限循环 |

胜率同时统计队伍构成、人物在场、技能和装备、玩家熟悉程度、策略版本、种子、敌组、地区访问顺序。单看全体平均会掩盖某路线卡关。

## 2. 必测配置与行为

人物／资源至少覆盖：低投入、标准、专精；2／3／4人；有无大黄；叶蘅针攻／医线及求学不在场；无苏芷；普通装／错配装／刚换高阶装；100%和约60%HP＋30%MP；缺少可选秘籍；游历地区模块的不同访问顺序。

不得暴力假定所有组合都合法。先按人物和教学日历筛出可达存档；主线最差合法可达配置是测试责任，未学绝技硬塞入队的“万能配置”没有代表性。

行为策略至少三种：

- **首次游玩**：不读隐藏弱点，第一次观察，能看懂预告但不保证每次最优BP；允许一次合理误选。
- **熟悉玩法**：已知公开信息，安排破势与恢复，不能读取随机种子未来。
- **专精组合**：明确测试转赠BP、延后、连续护卫、甲绝输出与恢复联动，搜集可能破坏平衡的循环。

自动策略只能作为代理。额外安排实际新玩家走关键流程，记录不明白、来不及应对与无法预知的失败。不能把“脚本通了”当成“体验顺畅”。

## 3. 暂定报警线

以下全部是本作待测目标，报警后需要判断，不是一刀切删掉挑战。

| 情况 | 暂定门槛与处理 |
| --- | --- |
| 相邻同档普通战 | 同配置预期有效压力变化超过15%，或中位时长超过25%，标记原因；精英和明确挑战另列 |
| 同配置胜率变化 | 相邻同职责主线战差超过10个百分点，且置信区间显示可信差异，进入回放复审 |
| 标准配置首次游玩代理 | 普通主线拟目标胜率90%以上，头目75%—90%；真人是否感觉公平单独确认 |
| 熟悉玩法代理 | 普通主线拟目标95%以上；强制头目一般85%以上；低投入替代路线也需验证 |
| 专精配置 | 允许更快通关；若多数头目一轮内击杀、未见任何意图，检查爆发与机制预告时点，不全图追平玩家 |
| 无预告倒地 | 主线首动前满HP直接倒地是阻塞问题；随机敌方连续集火超过最脆合法角色65%HP需复核 |
| 破势锁死 | 头目长期超过60%应有行动被取消，先检查盾、BP和额外削盾循环；不能简单加免疫破坏全部流派 |
| 资源永动 | 在无外部补给下，30回合全员HP不降且MP／BP净增，记录并审查循环；允许有成本的恢复 |
| 支援同质化 | 一种支援在全部常见敌组都严格优于其他角色，调整适用场景和代价 |

正式随机验证先每关键配置200种子筛查，临近门槛或异常扩到1000种子；使用配对种子比较版本，记录95% Wilson区间。1000次在50%附近的误差仍约±3.1个百分点，不能把微小差异当定论。极低概率致命局面还要定向构造，不靠随机等它出现。

## 4. 阈值扫描

以下参数逐一±1或±5%重算，其他条件固定：敌盾、敌人数、速度、攻击、防御、HP、MP、装备替换、技能重数、辅修槽、队员加入／离队、头目阶段切换。

必须包含：

1. 护盾6／7的拆防行动变化。
2. 头目HP51%／49%时整个回合的行动数和总伤害。
3. 只够23／24MP、2／3BP时的选择空间，不允许“差1点无法继续且无替代”。
4. 临界升级前后是否因回满导致长路线压力消失。
5. 破勢前最后一击与破势后多段，确认倍率只从正确段起生效。
6. 同一组招式是否多次折算心法、火候和BP；治疗是否溢出又回蓝造成永动。
7. 缺苏芷、叶蘅学医离队和队伍从3→2人时是否出现不可预知的失败。

## 5. 通过条件与报告格式

每关报告必须含 `game_revision、content_revision、profile_id、route_snapshot、party、gear、skills、policy、seed、result、rounds、first_break_action、action_log、resource_before_after、warnings`。汇总结果链接至少一个失败和一个正常回放，不能只贴“1000次通过”。

发布门槛：主要合法路线无未解释的红色跳变，替代处理与补课可达，最差集火有合理应对，主要组合无无限循环，真人测试完成。任何未完成项保留待验证标签。

本轮离线检查命令：`python3 docs/design/martial-review/balance/check_curve.py`。它只检查算术例子与生成参考表；不导入或执行真实伤害函数，不生成胜率，不会替代上述测试。
