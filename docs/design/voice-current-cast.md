## 同步操作

1. 改人物或台词后运行 `python3 tools_audio/sync_voice_catalog.py`。`--check`只检查差异，不合成、不绑定、不写运行状态。人物图鉴、六状态示例和开篇脚本是来源。
2. 点击页面“同步台词与试听”，重新读取已保存资料，串行补齐缺失试听；正在制作的角色先沿用当前定义，结束后应用更新，其余角色立即同步。保留绑定和有效音频，按钮不改写剧情。
3. 新角色先提供3个真实系统候选，每候选默认连播3句；单句NPC只试听指定的一句。“选择此音色”打开确认框，取消不绑定。主要角色同一基础voice_id排他，NPC可复用并显示全部使用者。
4. 确认后只补正式采用的语句。后期角色尚无正式台词时可确认音色储备，任务为0句；状态示例继续标“试听稿·未接入剧情”，不会自动装配。
5. 改句保留ID、递增版本；新增、过期、失败可增量补全，退役句不制作。导出只收真实有效的正式成品，未确认角色继续字幕。

服装和身材变化不要求声音更性感；性格、职业、说话习惯和事件决定表演。演出说明用于听验，不是MiniMax自由表演指令；每句实际发送emotion_api。调校音高或语速不能声称创造了新的基础声音。
