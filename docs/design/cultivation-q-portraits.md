## 已采用的画风与基准

画风依据用户提供的2015年《侠客风云传》养成Q版人物：大头、紧凑上身、灵活的小手、短颈、粗细变化的深色轮廓，眉眼嘴型与身体姿态共同表达反应。保留手绘色块与适度体积，服饰和发束简化为明确形状。人物性格、年龄和当前服装继续依据本作设定。

## 交付的是带动作的情绪立绘

用户进一步明确：只改眉眼嘴型、所有图沿用相同站姿会显得生硬。本组主要素材因此是**情绪＋手势＋头肩姿态＋重心＋持物方式**的独立静态立绘。惊讶要看到后仰抬手，疑惑要看到挠头，疲惫要看到弯腰撑膝；动作轮廓本身就应有区别。

每次从该角色同一Q版基准重新生成，锁住身份、发型、服饰设计、配色、年龄和物件归属；允许改变手臂、肩背、头部角度、重心、衣褶与发束动势。不能把“同一角色”误写成“所有肢体位置必须固定”。手与药包、布带、针囊的实际接触要成立。

一个调用只出一人一动作，保存独立PNG。多人救治与复杂事件另用CG；本组是静态姿态，不表示已经制作起手、执行、收势的连续动画。普通NPC仍不因此增加专属劳动动作。

## 主角优先的八种动作

| 动作键／情绪 | 肢体和表情 | 可用场景 |
| --- | --- | --- |
| listen／neutral | 平静·认真听讲：双臂自然放下，头略侧向讲述者，闭口留意 | 课程说明、普通接话 |
| salute／smile | 喜悦·抱拳回应：左掌抱右拳置于胸前，轻点头，欣然回应 | 接受指导、道谢、完成课题 |
| scratch_head／puzzled | 疑惑·挠头思考：一手挠后脑，另一手扶腰，身体略偏，眉口迟疑 | 不懂课题、权衡办法 |
| startled／surprise | 惊讶·后仰抬手：身体后仰、双手抬起，肩部缩紧，睁眼张口 | 突然消息、意外发现 |
| stop／firm | 坚定·抬手制止：一掌向外制止，另一手近身，身体略前倾，目光坚定 | 拒绝、保护同行者 |
| concern／worry | 担忧·前倾询问：前倾询问，一手贴胸、一手低位向前，皱眉关切 | 询问伤势、关注同伴 |
| hold_arm／hurt | 难受·扶臂收身：一手扶另一上臂，收肩转身，小幅忍痛 | 受伤压力或身体不适 |
| catch_breath／tired | 疲惫·撑膝喘息：弯腰、双手撑膝，肩部放下，抬眼缓息 | 普通训练后休息 |

原有萧白开掌谈话基准可额外保留为talk，用于自然讲述。八张动作图优先覆盖课堂、交游、意外与练习后的反应，不把现代身份表现成全知。难受与疲惫不新增血迹、永久伤疤或已经发生的剧情。

## 构图、提示词和使用

本组以1145×1374竖幅为目标，使用浅米白预览底，通常完整头部至大腿；弯腰动作可放宽到膝部，双手、头发和关键医具必须留在画内。面部保持与基准接近的可读尺度，不能为了容纳动作把人物缩成小精灵。

同组保证画布与显示容器稳定，但头肩和腰线可以随动作自然移动。允许挠头时抬臂、惊讶时后仰、疲惫时弯腰，不能用每张固定眼线的要求把动作重新锁死。后续接入以显示锚点和安全区检查切换，不逐张裁脸或非等比拉伸。

生成输入顺序为“本人的Q版基准＋用户提供的动作画风参考”。提示词写清左右手、接触点、身体方向、重心、表情和道具；正向明确要求重新摆动作，再锁定身份与服装设计。完整实际提示词各自保存为单独文本，不只给一个抽象的“开心／生气”。

未来按角色＋阶段＋动作键调用，每个动作另有情绪标签；同一句对白根据语义选图，而不是仅按心情数值换脸。一次对白无需逐句换图，反应或行为变化时再切姿态。涉及姿态自然回落时用listen／tidy等普通动作承接；不能把所有图都回退同一张并声称动作包齐全。

## 目录、已有差分和验收

源目录为`art_sources/cultivation_q_20261003/`。主交付为`poses/`中的20张动作立绘（萧白8、叶蘅6、苏芷6），其中两张复用已有女主基准，18张已新生成。基准存于`base/`，准确输入存于`references/`，完整提示词存于`prompts/`，实际来源与状态记录在`manifest.json`。

先前已生成的纯表情图保存在`expressions/`和[辅助表情清单](../../art_sources/cultivation_q_20261003/expression-manifest.json)，用于同一动作内的小幅表情变化，不代替主要动作包；尚未生成的女主纯表情计划已停止。本组不用情绪×动作×服装全组合扩张。

逐张检查：与本人基准同脸同装、动作确实不同、情绪可读、肢体与手指成立、持物接触正确、人物与关键部位不出框、无文字水印或新剧情物件。动作相同只换脸的图不算合格动作交付。生成成功记为候选，实际接入仍需1280×720／1920×1080对白版面与切换检查。

V1整组20张静态姿态原稿保留，尺寸与来源不变。当前实际使用的萧白4个、叶蘅3个姿态已通过图像生成编辑去除背景，透明V2直接叠在场景；其他13个原稿备用。V2另有12条修习动作和3档心情序列，见[动作合同](cultivation-animation.md)及[素材台账](cultivation-assets.md)。本页“一人一动作”规定针对V1静态对白姿态，连续序列另按V2规范制作，不混称20张原稿已经是动画。
