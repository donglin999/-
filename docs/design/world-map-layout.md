## 2. 地理骨架

蓝本是南宋荆襄一带，地名虚实混用（与 [world.md](world.md) 一致：栖河村、归云谷为虚构，汉水、大江、岘山、襄阳为真实地理锚点）。约1260—1263年是培养期背景；游历、终局的具体公历年份尚未排定，不据此把史实围城搬入游戏。

- **大江**在南，自西向东横贯；**汉水**从北面襄阳、樊城之间流下，经汉皋城东北侧，往东南在合川镇旁汇入大江。
- **城镇临岸，不跨河**：城池、衙署、镇子都建在一侧河岸上，只有码头、栈桥伸进水里。襄阳与樊城隔汉水相望；汉皋城在汉水西南岸，码头朝东北；巡江司在大江北岸；合川镇在汉水口西侧的大江北岸；白鹇谷在江北山谷里，不临江。渡口（芦花渡）是唯一画在水上的节点。
- **云梦泽**：汉水东岸的芦苇沼泽，归烬堂的灰色货路藏在水网里。
- **山地**：归云谷所在的低山群在腹地正中；西北荆山（照川剑派）、西面松风岭（松风观）、西南药岭（白鹇谷）、北面岘山（清徽阁）。
- **襄阳·樊城**移到大地图北端，属前线大城（以后开放的新城市，剧情未设计；旧可进城内容已撤除）；年一5月的首座大城改为腹地的**汉皋城**。

坐标单位是“大地图单位”，整张 4800×3200，北在上。它不是场景世界像素，也不是成图坐标合同；做灰盒时再冻结实际坐标。

## 3. 核心约束：归云谷居三方正中

三方据点以归云谷为中心，**直线距离相同（约820），互成120°**；三条“走廊”道路实际路长控制在1000±60。文中“日”只表达叙事脚程，不是活动扣时；大地图行走和快行均不耗游戏时间。

| 方向 | 据点 | 坐标 | 走廊中途节点（公共支线位） |
| --- | --- | --- | --- |
| 中心 | 归云谷 | (2400,1500) | — |
| 西北 | 正道盟·鹿门公议院 | (1820,920) | 鹿门驿：驿站、茶棚、告示 |
| 东北偏东 | 玄烛会·归烬堂（烬渡） | (3192,1288) | 芦花渡：要渡汉水，渡船、船户 |
| 南 | 巡江司·江口巡检署 | (2188,2292) | 三岔山神庙：歇脚、避雨、夜宿 |

为什么这样摆：

1. **三方来客同样方便**。培养期徐令仪、岑霜、沈雁回（及未来三条路线的据点）到归云谷的叙事脚程相当，来访月份不必因远近区别排期；同一个月可以安排三方先后来访。
2. **公共支线放在走廊与中心**。走廊中点三个节点、归云谷谷口、汉皋城是三方共用的相遇地，事件写一次，按路线换入场缘由（见[培养路线·三条路线如何遇见同一批人](cultivation-routes.md#三条路线如何遇见同一批人)）。
3. **三方之间互相隔着归云谷**。三方据点两两距离约1420，比到归云谷远得多；归云谷作中立见证的设定（[主角门派](protagonist-sect.md)“信用有分量”）有了地理依据。
4. **汉皋城不在任何一条走廊上**。城在归云谷东南约470、半日路程，夹在两条走廊之间；去城里办事不会顺路经过某一方据点，避免某派“近水楼台”。

验收：灰盒阶段量三条走廊实际路长，差值超过 ±6% 就改道路，不改跑速。

2. **腹地空节点 R7、R8**：区域一内两个空着的路口（栖河西北、汉皋东南），用作小型新地点（村庄、驿站、隐士居、新门派分舵）。

4. **地点 ID 规则**：`wm_<拼音缩写>`，例如 `wm_guiyun`、`wm_hangao`、`wm_r4`；预留地块先用 `wm_rN` 占位，启用时改名并保留旧 ID 映射。

## 7. 大地图跑动规则（方案）

细节以[整月历练](world-map-journeys.md)为准，本页只补与方位有关的部分：

- 主角在大地图上以小型 Q 版人物跑动，沿道路速度正常，离开道路的草地、浅滩减速，山、深水、沼泽深处不可走。到达地点图标按 E 进入对应场景。
- **不扣时间**（方案 A，2026-10-10 用户确认；对照《逸剑风云决》）：大地图跑动与城内活动不计时间，时间只由主线推进；需要“过了几日”时由剧情过场交代；夜晚只为特殊剧情与特殊场景设计（[城市系统第2节](hangao-systems.md#2-剧情时间点与住宿)）。路程长短只影响跑动距离和遇敌机会。
- **快速往返**：到过的城镇可在车马行、渡口付费快速往返，按路程收钱、不耗时间；第一次必须亲自走到（借鉴《大侠立志传》车夫）。
- **野外事件**：道路上按区域刷出“！”事件点，内容来自[野外遇敌](wilderness-encounters.md)与各支线；走廊三个节点固定有公共支线，不随机消失。
- **地图购买与迷雾**：未到过的区域显示为淡色舆图，到过的地点点亮；在汉皋城书肆可买区域舆图提前看到地名（不能直接解锁地点）。

设计路线为合川出发，沿汉水驿院至汉皋上游落岸，再从栖河外山路进入白石；岸路追查者与护棺者在已定义的驿院/桥路节点会合，不要求自动跟随NPC跨图。船行通过固定登船点和转场，不能把水面直接设为角色可走路面。

白石内部拆镇外舟棚、镇口街巷、停棺旧会馆、押人院、比武台后台、旧堂、侧路、墓地等独立可进入空间，数量与归并以[新资源估算](fullflow-story-20261016/implementation-plan.md)为准。前版24图是旧范围估算，不再当成新全作上限或现有资产库存。
