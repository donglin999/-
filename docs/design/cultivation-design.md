## 一轮培养的体验

玩家进入本期据点，看见当前年月、剩余体力、人物近况和下一次外出。选择一类活动，查看可做的项目、来源与消耗，再按「开始」；一段练习、生活互动或完整事件结束后，立即看到实际变化，回到同一期继续安排。选「结束本期」才推进时间。

培养主画面承担生活感：人物在不在、药圃与书案的状态、季节和来客发生变化。菜单承担明确选择：学哪项、做什么、耗多少、为什么暂时不能做。重复培养保持短而稳定，第一次教学与新的关系事件完整展开。

培养投入影响之后的经历：步法练习让护送中多一种应对，帮叶蘅记录医案让后来对话有前情，出游认识的新师友开放学艺。数值、人物反馈与新机会一起解释成长。

## 当前可以评审的设计选择

| 项目 | 本轮方案 |
| --- | --- |
| 主画面 | 据点场景为主体，底部七类活动，右下独立「结束本期」；常驻日期、体力与心情 |
| 展开选择 | 一级活动 → 项目列表 → 固定详情；普通活动直接在详情中开始，不连续弹确认框 |
| 基本功 | 保留原作内、轻、硬、软、耳、眼六方向的培养思路，映射本作成长，避免照抄另一套战斗属性 |
| 招式 | 只练已正式学会的招式；内功心法放在基本功的内功页，装备仍通过江湖行卷处理 |
| 学习方式 | 首次有来源与教学，日常练习简明反馈，阶段指导提出新的课题；生活技能熟练须结合实际成果 |
| 小游戏 | 先定识别、排序与判断类交互；日常练功不每次强制小游戏，限时反应挑战留作可选进阶 |
| 事件 | 选地点闲逛或明确赴约；已知邀约有保障，普通偶遇保留探索感，无新事件有地方日常承接 |
| 多路线 | 界面和成本共用，场景、项目、导师与事件来自当前路线；后两线本轮不写课程 |
| 整月出游 | 出发前展示月份和返程据点，地图月暂停据点体力，返回后接续日期和成果 |

## 数值与制作边界

活动的体力成本沿用[通用机制](cultivation.md)。本轮确定课程来源、操作、资源转移和收益类型，界面线框中的经验和材料数量是明确标注的排版／平衡示例。永久属性每次涨多少、招式经验曲线、心情倍率和各配方售价，需要与战斗成长一起校准，不把原作数值或当前原型等级表直接当成定稿。

首季优先周砚、叶蘅、陆衡与已有乡邻。后续师友使用[人物名册](companions.md)和[组织目录](factions.md)中的设定，课程必须符合其能力和处境，不因列在名册就自动成为常驻老师。三年结束仍是培养阶段结束，后续游历按[全作阶段评审](story-framework-review.md)另行衔接。

现有生活技能暂缓上线的决定继续有效。本组内容是其未来培养入口的方案；正式学习采用体力成本，现行原型的免费教学与临时技能不能直接迁入。普通聊天、购买、必要调查与叶蘅按身份救治不因此收费或变成萧白的技能。[生活技能边界](life-skills.md)

本轮输出 Markdown 与两张界面线框示意，不制作正式UI美术、活动CG、角色动作或语音，不接入游戏代码。

## 评审应走完的体验

1. 初学者看懂体力与年月，完成第一次基础教学，再主动结束本期。
2. 完成 5＋3＋2 的组合，每次看到剩余体力与不同收获，不重复收费。
3. 体力不足时知道差多少，材料不足时知道怎样取得，未学时知道合适的来源。
4. 参加一次明确邀约，普通闲逛一次，再看两者的事件选择与反馈区别。
5. 留有体力结束本期，明确显示放弃的余力、下一时段和心情回响。
6. 进入一个整月大地图并返回，日期、人物所在地、物品和已完成事件持续有效。
7. 用另一个据点的占位信息替换山居，通用界面与流程仍成立；如未来有正式分叉，已有成长和未完事项可承接。

这些是后续原型验收场景，本轮只核对文档、链接和线框，不宣称已实机通过。
