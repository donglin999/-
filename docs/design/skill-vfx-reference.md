## 参考中的可见表现

| 约略时段 | 可见内容 | 要吸收的表现方法 |
| --- | --- | --- |
| 0–3.5 秒 | 多层金色空中阵列逐步亮起，落弹带尾迹，命中亮核、受击闪白、尘烟与地面反馈 | 多阶段构形；空中主体、飞行路径、地面落点之间有连续因果 |
| 4–7 秒 | 场景出现电光，落雷分叉，施法者与目标之间有电弧，地面电纹和目标轮廓随命中变化 | 主干、分支与细碎电弧分层；环境、人物、落点一起响应 |
| 7.5–13 秒 | 紫色粒子聚集，光点拉成长缝，张开为带亮边和暗部的裂隙，目标被卷入并持续受击，随后收束 | 明确的形态演变；前后遮挡、内部暗部、外部光晕共同形成空间感 |
| 13–18 秒 | 金色亮核、环带和地面图形逐步展开，多层上下呼应的结构形成光柱，底部持续有响应 | 持续技有形成、维持、脉冲与退出；不能把一张图简单缩放当完整演出 |
| 18–23.3 秒 | 多种效果同屏，光柱、落弹、裂隙、电弧、数字与受击响应叠加 | 检查同屏层次、遮挡与明暗关系；不能仅凭单个静帧验收 |

这是录屏中观察到的画面，不据此断言原作者的引擎、算法、帧率或性能。参考音效未作听觉分析。

## 对当前方案的纠正

- 像素风必须有足够细节。不能把粗块轮廓、统一色填充和简单摆动视为成品；龙形需要体积、透视、沿运动方向的形变与前后层次。
- 允许发光核心、半透明衰减、受控局部辉光、色阶过渡与场景染色；保留主体的清晰像素边界。“全图只能不透明硬像素”“全面禁止辉光”不再作为质量标准。
- 程序绘制是制作方式，画面质量才是验收目标；不能因使用代码而省略造型与分镜。现有 v2 的 320×180 像素层、24fps 更新是旧实现记录，不是新方案的强制规格。
- 普通攻击保持利落；代表性绝学独立设计完整演出。原 1700ms 上限只保留为旧短招模板参考，不能压缩所有绝学。具体时长与资源预算经新样例验证后确定。
- 参考中的魔法阵、符号和空间裂隙不自动照搬进全部武学；武侠招式用自己的龙形、剑气、气浪、针路和地面响应承载相同表现层次。

## 降龙掌方案归档（暂缓）

以下方案已有降龙掌 v3 单招样例（已删除），等待用户评审；实现存在不等于质量已获确认。

1. 聚劲：掌前气流汇聚，衣袖与站姿配合，局部亮核逐渐形成龙首。
2. 成形与扑出：龙首领动，龙身沿有纵深的弯曲路径展开；鳞面明暗、鬃须、爪和尾部各有运动关系，部分身段穿插前后。
3. 命中：龙首与目标实际接触，亮核短暂爆发；目标闪白／轮廓强调、受击位移、气浪、地面尘烟与接触声同时响应。
4. 收束：主体从头到尾逐步解体成气流与像素碎光，余劲、尘烟和尾音分层结束。

当前先验证可复用的聚集、持续发射、旋流、爆发与消散粒子配方，再按技能组合。音效继续采用来源明确的开放录音，按重做后的事件时间线重新编排。

## 2026-10-06 按视频重做的四段样例

[重做预览](../../review/combat-av-v1/skillfx.html)（`js/skill-fx.js`）。通用粒子配方无法表现法阵、裂隙、光柱等成形结构，改为专用像素渲染：480×270 像素层逐点绘制（Bayer 抖动渐隐、符文环、像素数字），四分之一分辨率辉光层模糊后加色合成；人物夹在前后层之间，命中用白／黑剪影。

| 样例 | 对应视频段落 | 结构 |
| --- | --- | --- |
| 星阵陨落 | 0–3.5 秒 | 三个倾斜符文法阵依次展开，施法引线，陨星拖尾坠落，火球＋暗边、尘烟、地面冲击环 |
| 九霄雷殛 | 4–7 秒 | 雨夜压暗，手中蓄电，主雷中点位移分叉并闪烁重算，天光闪白，持续电弧，地面电纹环与符文 |
| 虚空裂隙 | 7.5–13 秒 | 光点旋聚、竖缝、张开为多层亮边＋暗心旋纹，前后分层的轨道环，目标被吸入并脉冲受击，收束星爆 |
| 天罡光柱 | 13–18 秒 | 地面法阵、空中三层环阵与顶盘，细光引线，光柱贯通（白芯渐变、斜纹上行、环带下行），黑色剪影，底部飞溅 |
