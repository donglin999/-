# 挂轴式商店与城镇场所界面规范

状态：现行　最后核对：2026-10-19

版本 SHOP-UI-2026-10-09.1。状态：**用户 2026-10-09 确认的界面方向**（“可以了，按这个风格做成真页面，其他的商店也要类似的设计”）。适用于所有城镇店铺与城镇系统场所（鉴定、典当、住店、告示墙、赌坊、擂台、车马行、酒楼、零工、艺楼等），汉皋城是第一份实现。

- 确认依据：[商店界面预览 v2](../../art_sources/hangao_shopkeeper_20261009/preview-shop-ui-v2.png)（生图概念预览，非正式素材）及[评审记录](../../art_sources/hangao_shopkeeper_20261009/README.md)。
- 版式参考：用户提供的另一款游戏挂轴商店截图（只借版式与质感）。
- 已否定的方向：浅宣纸仿江湖页（v5，用户评价“更像文本交互类游戏”）；深色三栏描金面板（v6）被本方向替代；预览 v1 背景“过于艳丽”。
- 实现：[汉皋城交互原型](../../review/hangao-town/README.md)。店铺数据与系统规则仍由[店铺功能](hangao-shops.md)、[城市系统](hangao-systems.md)负责，本页只管界面。

## 1. 画面构成（1920×1080 基准）

```text
           [买入][卖出][修理][熟客🔒]   ← 悬挂木牌页签（挂在上轴上方）
  ┌对话框┐ ═══════════上木轴═══════════  ○
  │店主话│ ┃ 名称 │ 价格 │ 数量 │ 全部▾ ✕┃  ○ 铜钱串
  └──────┘ ┃ [图] 物品名(品级色) ◎价 数 [橙][蓝]┃  ○
  店主       ┃ [图] …                       ┃  ┆ 旧绳穗
  半身立绘   ┃ [图] …                       ┃
  （压在挂轴 ┃ （空行：暂时没有……）         ┃      纸灯
   左缘前）  ═══════════下木轴═══════════
 [萧白持有铜钱：220]   [与某店关系：熟识（好感42·九折）| 讲价·今日可试]
```

| 元素 | 规定 |
| --- | --- |
| 背景 | 当前场所所在街区的场景图，**朴素**：低饱和、压暗，灰褐暗墨为主；不得有大片火光、亮黄灯光、大红装饰。可以保留一点场所特征（铁铺角落一点暗余烬、码头远处桅杆） |
| 挂轴 | 上下两根木轴（两端铜帽），细绳吊起；轴间深褐纸面，可有极淡的圆形暗纹 |
| 页签 | 竖排小木牌挂在上轴上方，当前页签点亮（金边、略长）；未开放的页签变暗带锁，悬停说明开放条件 |
| 表头 | “名称／价格／数量”＋右侧筛选“全部▾”；右上红叉关闭（Esc） |
| 条目行 | 深色木纹长条；左侧方形描边物品图标框；名称按品级着色并在下方小字写“品级·类别”；价格前一枚铜钱；数量列；右侧按钮区 |
| 空行 | 不满屏时补一到两条空木条，写一句情境文字（“暂时没有可以出售的物品”“熟客专柜的货，好感到 60 才摆出来”） |
| 店主 | 本作固定立绘画风（[立绘风格](character-portrait-style.md)：白描淡彩、宣纸底），半身，面朝挂轴，压在挂轴左缘前，边缘以水墨晕散进背景；头旁一个米白对话框 |
| 持有金 | 左下米色木牌“萧白持有铜钱：N” |
| 关系横幅 | 挂轴下方一条细横幅：与该店／该人的关系阶段、好感、当前折扣；店铺有讲价时放“讲价 · 今日可试／今日已试” |
| 装饰 | 挂轴右侧铜钱串＋暗褐旧绳穗；右下柔光旧纸灯（不写红字）。装饰不得遮挡条目 |
| 悬停浮层 | 深色底、金色细边；写名称·品级、属性变化（当前→之后 ▲▼）、现装备、售价（原价与折扣原因） |
| 确认层 | 深色木框匾额标题；列出物品、价格、剩余、装备给谁／替下什么；按钮“再想想”“只买入”“买并装上” |

## 2. 颜色与按钮

| 用途 | 规定 |
| --- | --- |
| 品级名称色 | 丁：米金；丙：青绿；乙：淡紫；材料、杂物：米白；剧情物品：暗金并标“剧情” |
| 价格 | 米金；买不起或不足时**红色**，按钮变灰“不足” |
| 主操作按钮 | 蓝漆木按钮：买入、出售、接下、上台、前往、歇息、递曲单 |
| 次操作按钮 | 橙漆木按钮：装上（买并装备）、买五、全部（全部卖出）、完成 |
| 禁用 | 灰木按钮，文字写原因短语（不足、已满、未开、已试）；悬停浮层写完整原因 |
| 危险操作 | 提前回谷、典当等不可逆操作一律弹确认层，确认层写清代价 |

## 3. 各类场所怎么套用

同一套骨架，只换页签、行内容和按钮。

| 场所类型 | 页签木牌 | 每行 | 按钮 |
| --- | --- | --- | --- |
| 买卖店铺（铁铺、饰品、胭脂、成衣、药铺、杂货、书肆） | 买入／卖出／熟客（锁）／修理或强化（铁铺、修械铺才有） | 物品 | 买入（蓝），装备类加“装上”（橙），可叠加物品加“买五”；卖出页：出售（蓝）、全部（橙） |
| 鉴定（博古斋） | 鉴定／古玩／卖出 | 未鉴定物品 | 自己看（橙）、请鉴定（蓝，写费用）；表头上方一条鉴定熟练度 |
| 典当（解库） | 典当／当票 | 可当物品；当票 | 典当（蓝）；赎回（蓝，写到期日） |
| 住店（迎客店） | 歇息／存档 | 住处 | 歇息（蓝，写价格） |
| 告示墙 | 江湖委托／官府告示／商号招贴 | 委托 | 接下（蓝）、完成（橙）、放弃（灰）；数量列写耗时 |
| 赌坊 | 骰子 | 挂轴内换成骰桌：两骰、今晚净值条、押注步进 | 押大（蓝）、押小（橙） |
| 擂台 | 守擂 | 守擂人与本旬擂主，一人一行 | 上台（蓝，只在当前一人） |
| 车马行／渡口 | 车马或水路 | 目的地 | 前往（蓝）；提前回谷（橙，确认层） |
| 酒楼 | 点菜／宴请／打听 | 菜、人、传闻 | 点这道、请吃饭、打听 |
| 零工 | 零工 | 活计；挂轴内含时机小游戏 | 开始、出力、跳过 |
| 艺楼（栖月楼） | 听曲／雅集（锁） | 曲单 | 递曲单（蓝）；表头上方写楼规“只卖曲，不卖人” |

价格列在非买卖场所改写为对应量：委托写报酬、擂台写胜得、车马写车钱、住处写房钱；数量列改写为耗时或剩余次数。表头文字随之改。

## 4. 店主立绘

- 每个有固定店主的场所都要一张半身立绘，按[立绘风格](character-portrait-style.md)单独生成并定妆，面朝右侧（挂轴方向）；不得借用旧襄阳人物立绘。
- 立绘画背景只留极淡情境（铁铺淡炉影、药铺淡药柜），界面会再用遮罩晕散。
- 没有固定店主的公共场所（告示墙、车马行、渡口、擂台）放该处的职能人物（看榜更夫、车把式、船户、主簿），同样单独生成。
- 未生成前，原型显示墨色剪影占位，并在店铺数据里标“立绘待生成”；不能拿别人的立绘顶替。

已定妆：庞铁山（洪炉铁铺），`art_sources/hangao_shopkeeper_20261009/pang-tieshan-v1.png`。

## 5. 物品图标

条目图标沿用已批准的[墨彩物品图标画风](xiangyang-icons-v3.md)。新物品没有专属图标前，原型按类别借用已有图标并在悬停浮层标“图标待制作”；正式上线前逐件补齐。已知问题：现有“枣木短棍”图标在小尺寸下易被看成笛子，补图时重画。

## 6. 交互底线

- 买、卖、典当、赎回、出行、宴请等花钱或耗时的操作都要经过确认层，写明价格、剩余、耗时、装备替换。
- 每个禁用按钮都要能看到原因（按钮短语＋悬停全文）。
- 键盘：1—5 切页签，Q／E 左右切页签，↑↓ 选行，Enter 执行该行主操作，Esc 关闭当前层（浮层→确认层→场所）。
- 1280×720 与 1920×1080 都要完整显示，不出现横向溢出；1280 下店主立绘可缩小，但不能遮挡条目。
