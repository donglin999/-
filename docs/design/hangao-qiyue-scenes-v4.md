# 栖月楼V4：用户指定风格的分场景制作

状态：现行　最后核对：2026-10-19

2026-10-14。用户明确指定本轮上传的黑底、去顶近正交室内图为风格基准，否定V3整楼剖视展示及其画风。用户指定优先于旧候选不得用作风格参考的通用规则；仅本次所附图被授权，不扩展到其他旧稿。

## 交付与用途

交付外堂、二层环廊及两后房、后廊工作空间三张分场景图和当前引擎中的连接预览。每张用于实际室内镜头、角色比例、碰撞、遮挡和入口检查，不再以整栋外部透视图代替地图。V3只保留两层同位、挑空、后部空间用途与剧情分期；视觉不引用V3两张被否定概念图。

一层左右错位共七席，东侧楼梯口上楼、西北/台侧门通后廊；二层是U形环廊，中间真实不可走挑空，后部有两处大小不同实房，不能变成另一个大平地大厅。按用户最新澄清，保留东侧可见楼梯与扶手外形；角色到楼梯脚点即像进门一样用goScene淡出切换，不做逐级爬升。两端有独立返回落点。后廊为紧凑的茶炉、修弦、排练与收信空间，家具靠工作用途摆放，不铺巨型桌凳。

人物按现用蓝灰萧白实际尺寸显示，成人量尺92世界像素，不放大人物补救家具失衡。目标：短凳30×28，单席组合约140×80（其中矮几72×46，烛/瓶单独高出），修弦案112×58，柜76×110，小柜台144×68。可见投影含道具，不能把烛高算作桌腿高度。椅凳与桌面同尺对照后才能用于场景。

## 素材方式

一层和后廊先生产无活动家具的结构底图；二层优先生成RGBA结构层，中央挑空和建筑外部alpha=0。家具用真正的透明背景，工具transparent_background=true；桌腿/横档/把手的空隙也alpha=0，不用白阈值抠图。家具按预定目标尺寸统一机械缩放与图集打包，底图不烘焙活动桌椅，视角和描边取用户指定图。每次含模型请求行，实际模型未披露时不冒称验证过。

二层若原生透明开口有效，可由当前Canvas在其下绘制同源一层底图与家具，再压暗作为楼下背景；上层只使用上层mask和家具，不宣称实现同时多层导航。挑空必须有栏杆边界，不能走入。若透明开口不合格，保留失败图并修正，不把实心地板假称挑空。

## 二层中央瓦面纠正（2026-10-14）

用户指出两间室内房之间的灰瓦屋面难以理解。该屋面源于V3单层排练屋的设定，不适合当前连续室内视角，本轮撤销这项视觉结构：中央改为与两侧梁柱连成一体的室内后墙，设一幅固定绣屏/彩绘墙面，不能再画瓦片、屋脊或外檐。前方U形环廊与挑空保留，不新增可走房间或假门。原blocked lower-roof区域改为rear-wall；碰撞区域保持相同，已存在门口和楼梯不移动。旧原稿保留，采用新RGBA图并复查挑空透明与相邻环廊。
