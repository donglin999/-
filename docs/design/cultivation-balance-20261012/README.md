# 培养部分数值：侠客参考与现行战斗适配

状态：现行　最后核对：2026-10-19

日期：2026-10-12。用户授权：参考《侠客风云传》的数值，结合现有功法和战斗系统重设计并实装。本页取代 20261012 首轮整改中临时换算；对白与人物关系仍由原负责文档维护。实现工作区为 xiaojianghu-legacy-prologue / 8792。以下是本作的适配方案，不称为《侠客》原版数据。

## 参考依据与取舍

- [2017 玩家练功实测](https://www.3dmgame.com/gl/3698985.html)：经验依悟性、武学与心情计算，内功/招式系数100、软硬功160、眼耳轻功200；杂务40、挑水20。取课程间效率比例，以及前两项促进学习的关系。
- [2015 玩家经验曲线实测](https://gl.ali213.net/html/2015-8/78913.html)：功法分四类需求曲线；普通类十级累计23000、高阶类37000/55000，特殊类后段增长很陡。本作采用前三类累计曲线的1/20；不用指数型末级去挤占三年活动预算。
- [内功成长实测](https://www.gamersky.com/handbook/201508/631868.shtml)：修炼内功同时增加气血、内力等实战属性。本作把永久根基成长与功法熟练分开：满级后基础调息仍有效，高悟性不会因为练满太快反而少得永久属性。

上述来源是有版本背景的玩家实测，并非官方当前版本的数值规格。原作五维、武学量级、行动预算与本作不同，不能直接复制几千血和几百攻击。我们保留现行命中伤害：攻击×招式倍率－防御×0.5；弱点×1.25、破势×2、暴击×1.5及随机±8%。重数倍率保留1～4重每重+15%、5～10重每重+8%；造诣每20点同兵刃伤害+1%，最高10%。

## 行动预算、收益与学习效率

每月五期、每自由期12体力。三年180期，6个整月历练和一次整期送药后149个自由期、1788体力，正式练功最多298次。剧情免费且只结算一次；寄信1、送物2，生产/学艺3、打杂2、基本功/招式5。护路笔记保留免费，每期只结算一份，不能无限重复。

心情五档：0～19烦躁=1；20～39低落=2；40～59平静=3；60～79舒畅=4；80～100高兴=5。取行动开始时心情，显示当次使用值；练功仍降心情，写信和生活活动恢复。效率 E = min(10,基础悟性) + min(10, floor(培养所得武学常识/20)) + 心情指数。基础悟性含培养永久悟性、已有成长，不读临时装备。心情变化为基本功−5、招式−4、打杂−7、生产+4、学艺+2、通信+4、闲逛及剧情+4；结束一期按剩余体力恢复心情。初期五维3、无武学积累、心情50时 E=6；心情60时 E=7。高悟性只提效率，不免除授课、先修与日期。

基本功经验=round(5×E×课程系数)：站桩/协调1.6；步法/听声/察势2；吐纳1。招式/心法5×E，首次传授学会一重/一层，不另发修炼熟练；课程对应根基成果照常获得。学艺为E点、生产round(0.7×E)点、杂务round(0.4×E)点，挑水round(0.2×E)点。一次性剧情按原额固定给成果，避免闲逛比正式练功更高效。

## 功法、层数与教学

已有归云功法ID和技理保持。第一期不能送门派上乘或终极心法。初阶首次传授5体力，先站桩再明确选择剑/拳；非主修未教学不出现在练习栏。丙级同路基础三重后、六月起；乙级同路丙级五重后、第二年起且季度考校；甲级同路乙级七重后、二年末起并正式请教师父。绝级第三年第31月起有先修与高属性门槛。授课本身明确显示功法，不自动跨阶赠送。

普通A累计经验（第1～10重）：0、25、75、150、250、375、525、700、900、1150。B：0、25、75、175、325、525、775、1075、1425、1850。C：0、50、125、275、500、800、1175、1625、2150、2750。丁/丙采用A，乙采用B，甲/绝采用C；不是以原作A/B/C直接等同本作品阶。入门前五个月上限三重，之后六月起基础可继续练至十重。内功保留现有五层结构，A累计0、75、250、525、1150（映射原作1/3/5/7/10），B/C同索引抽样。前五个月吐故上限二层、六月起五层。

练满定义：外功十重、内功五层；三/五/七重为各自先修节点。次数必须标注前提：首次授课算1次；固定效率E=6即每次30经验时，普通外功学会1次、三重4次、五重10次、七重19次、十重40次；普通内功二层4次、三层10次、四层19次、五层40次。实际效率会上升，游戏按当前效率计算余下次数，不能把固定效率次数当硬承诺。

外功与战斗共用一份熟练；施展/弱点/破势给现行实战熟练，课程按上述公式增加相同熟练。心法战后所得修为折算同一层数进度：主修经验=战斗修为／本次境界升级需求×30，辅修为一半，例如境界1战斗得100修为，主修+30、辅修+15；败退不加心法修为；秘籍也在同一账本提升，不能被下次培养结算抹回。旧档保留已学身份、真实成长、重数与材料；只进行一次单位转换，并保留旧实际加成下限，刷新不再迁移。正在进行的旧活动沿原结算快照完成。

## 现有功法的正式适配

本轮本机采用现有10门归云外功、4门内功和开始部分护路棍法，不另造“入门剑法”“粗拳”。原门槛按现行五维量级×2/3向上取整，在功法表保留原值供对照；日期与先修由本轮培养规则负责。初学《吐故纳新篇》，每层内力上限+3%，三层战后回10%内力、五层战后另回15%气血。六月起《出岫心经》，第13月起《观岚诀》，第31月且满足高根基及出岫五层才可学《万壑归元诀》。当前不会一进培养就送终极心法。

招式BP取既有合同的总倍率及段数，逐段分摊；重数倍率和造诣增伤保持现行公式。两种防御强化随实际防御触发；绝招需要3BP且有一行动调息。群壑承声的双目标改为自动取最多两位在场角色；万壑的防御二选一UI、惊惧与内伤的未来状态系统尚未接入，本机描述与文档均明确实际范围。独立目标动画未在此轮生成。

旧档不能凭新增训练把原有属性扣回；迁移保留原实际成长下限。新档从新曲线起步。正在进行的旧课完成一次旧单位结算后换成新累计，之后不再重复发放；正常玩家存档未被测试写入。
