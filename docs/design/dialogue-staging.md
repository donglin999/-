# 对话立绘站位与多人演出

状态：现行　最后核对：2026-10-19（原记：OC-2026-10-04.4，2026-10-04用户纠正后采用。共同字体、框和人物等级见[画面规范](presentation.md)；[剧情表现](story-presentation.md)负责选择对白、静态动作与CG。）

## 人数与站位

| 参与人物 | 固定安排 |
|---|---|
| 主角独白 | 主角左位，禁止默认放右 |
| 一般NPC与主角 | 主角左侧立绘，普通NPC只用正文旁小像，不因此新增大立绘 |
| 两位有立绘人物 | 主角／视角人物左位，主要对话对象右位；双方同时在场，换说话人只换高亮与表情 |
| 三位有立绘人物 | 左、右主位保持，第三人中位；中位人物不得遮正文和名字牌 |
| 四位及以上 | 最多三幅大立绘；左、右主位固定，其他参与者在上方头像列。头像列中的人物发言时进入中位，上一位退回头像列；主位不随话轮跳边 |
| 无主角的剧情 | 脚本明确指定左／右主位，未指定按出场顺序分配；不能全堆到右侧 |
| 旁白／全屏CG | 旁白隐藏人物层但保留本段分配；CG中抑制全部大立绘与头像列，结束恢复原位 |

人物左右由会话角色分配，不由当前说话人或反派／同伴类型临时决定。主角换衣仍占原位，人物表情沿用同裁框；不能通过翻转角色修站位，持物左右和服装须保持一致。

## 构图与可读性

- 双人各占左右约28%，三人各约29%；人物层在正文框后，底部身体可被框自然遮挡，脸部不能被框遮住。正常立绘统一约72%画面高度，不使用叶蘅专用的负底边偏移。
- 发言者保持完整明度；其他人物用亮度轻度压暗，保持原有不透明度，避免背景透过身体；不能完全黑成剪影。以名字牌和表情同时标识发言人，不依赖颜色独自传意。
- 正文框跨底部，文字与选择共用起始线；正文≥18px、选项≥17px、行距≥1.5。多人层不能挤成窄文本栏。
- 头像列复用对应阶段头像或现有立绘裁脸，不把整幅全身立绘缩成难辨的小人。头像列是当前对话参与者的显示，不做可点击切人控件；普通围观者不会因存在于地图上自动加入立绘阵容。
- 脚本使用`DialogueStage.begin({id,cast:[{who,sp,slot}]})`／`end(token)`声明完整参与者。未迁入脚本仍由真实发言者自动补充，普通NPC保持小像。会话结束或切场景清理；不将上一段无关人物带入下一段。

## 验收

主角独白、双人往返、三人接话、四人及以上换中位、普通NPC小像、主角换衣、表情差分、CG全部抑制／恢复和会话清理均需检查。1280×720、1920×1080保存全画面；立绘不得越界、遮脸、遮选项。代码夹具只能证明分配与状态；实际构图仍需目视核对。

## 完整对白状态节拍（2026-10-04）

可加入人类使用[六个完整状态](companion-performance.md)，节拍记录`character / stage / dialogue_state / intent`。每张同时改变表情、手势、肩身与重心，不组合独立动作和表情。不随机轮播；情绪或意图转折时切换整图，同情绪连续数句沿用。换说话人时只高亮，除非听者有真实反应。

身体语言不匹配情绪的整图不能显示为该状态；缺图默认常态并记录缺口，不能称为完成。新版资源生成、预览显示与实际剧情映射分别验收，站位左右不会因为切状态而改变。
