# 野外可见遇敌系统 · 第一版实施合同

状态：现行　最后核对：2026-10-19

更新：2026-10-01。依据：[三款游戏调研与获批方案](wilderness-encounter-research.md)。本文记录本作规则，数值为本作第一版参数，不代表参考游戏原始公式。

## 1. 已落地范围

保留独立回合制战斗舞台，以地图上可见的敌群代表一场战斗。首张验证地图使用现有黑风寨寨门 `bgate`，不另建缺少剧情责任的新地图。城镇和正常渡口没有新增随机遇敌；现有剧情战照常触发。

| 敌群 ID | 地图站位（格） | 编组 | 职责 | 背景 |
| --- | --- | --- | --- | --- |
| bgate-west-bandits | 10.8,20.5 | 3级黑风喽啰 ×2 | 西侧偏路风险，靠近埋酒探索区；仍可绕过 | bg_bandit_gate_day_v1 |
| bgate-east-bandits | 38,22 | 3级黑风喽啰 ×1 | 东坡偏路练习、可选择遭遇 | bg_bandit_gate_day_v1 |

入口为 `(15.9,28.05)`；中路到守寨人保留安全路线。两群均不压入口和出口，不移动守寨人的站位、交涉、令牌/暗号、头目和巨蟒任务。获得 `gate_pass` 后停止新增巡逻敌意；`chief_dead` 后巡逻消失。休整不改变这些剧情旗标，不能重新刷出已经结束的势力冲突。

第一版只实际配置以上两群普通敌人。精英具备独立清场持久化能力但尚未放置；没有新增剧情伏击、地图、生活技能、潜行成长或背袭奖励。后续每张地图必须先交付动线、敌群责任和独立验收，再增加配置。

## 2. 状态与输入

`警戒 idle → 注意 alert → 追击 chase → 交战 engaged`；失去视线、超出活动范围或追击超时转为 `归位 return → 警戒`。

- 注意时显示黄色提示与进度条，首次注意使用专用短提示音；追击显示红色状态。随时显示人数和相对危险；靠近才额外显示名称，避免大量长文字挡住地图。
- 危险依队伍共享境界与敌群标注等级比较：主角低于敌群等级为危险；高于敌群等级超过2层为低危；其余相当。此提示不是胜率预测，不读取隐藏战斗结果。
- 敌群代表为同类路匪；地图显示的人数与战斗编组一致。不能使用狼代表山贼。
- 视线和移动路径均检查地图脚部碰撞，不能隔墙发现或穿墙追逐。归位沿追击轨迹逆向返回，不无界追击，不瞬移穿墙。
- 接触开战只在注意阶段完成后触发。靠近按 E / 鼠标挑战走已有 NPC 交互流程，可主动开战。
- 忙碌、对话、菜单、加载、入场动画期间不运行敌群更新，保护时间也不流逝。退出区域优先于遇敌判定。
- 交战同步占用一个 pending 槽，再启动异步战斗；同帧/连续接触和重复交互不能重复开启。
- 开战清除主角寻路、速度与按键残留。结束恢复输入，避免提示结束后仍走旧路径。

## 3. 首版参数（世界像素 / 毫秒）

地图一格为40世界像素；屏幕缩放不参与距离计算。

| 参数 | 初值 | 用途 |
| --- | --- | --- |
| notice | 180 px | 径向注意范围，另需无墙视线 |
| alertMs | 900 ms | 留给玩家撤离/绕行的预警时间 |
| contact | 34 px | 追击状态的接触开战范围 |
| leash | 240 px | 玩家离敌群初始站位超过此距离则停止追击 |
| chaseMs | 4500 ms | 单次最长追击时间 |
| speed | 0.075 px/ms | 慢于主角步行，可逃离 |
| entryMs | 2200 ms | 进图/读档保护，仅可行动时倒计时 |
| recoveryMs | 5000 ms | 战后/逃跑/战败保护 |
| restCost | 10两 | 安全城镇休整成本 |

战后重置敌群到合法初始点，并沿可通行短线搜索主角分离点；候选距离100/140/180px，不落出口、不穿墙、距活跃敌群至少90px。如果狭窄地形找不到分离点，不强塞到障碍里，保护时间延长为10秒。保护期间可主动挑战。

## 4. 结算与刷新

- 胜利：沿用既有战斗结算，仅发一次修为、银两和常见掉落；遇敌模块只记录清场，不二次发奖。单名路匪模板25修为/12两、馒头25%几率，双人群按原战斗模板累加。不会新增任务证物掉落。
- 逃跑：保留既有逃跑成功率和战斗资源消耗；敌群未清除，归位并给保护。
- 战败：本版普通野外战使用 `noLose:true`，气血至少恢复至上限三成，留在原区域并给保护，不重置剧情、不扣一半银两；同伴沿用既有战斗结算。
- 异常：不标记清场，不发遇敌额外奖励；释放 pending 和输入锁。战斗模块负责原战斗状态回滚，遇敌模块兜底清理仍停在战斗模式的舞台。
- 普通群本次探索击败后消失；切图、菜单、浏览器存档恢复不重刷。
- 江湖行卷 → 设置 → **返城休整**：目前在街市、城门、巷内、羊太傅庙及其安全外院可用。确认并支付10两后恢复主角和人物同伴气血/内力，增加探索批次并刷新普通群。取消/银两不足不扣费、不重刷。这是暂用服务入口，不虚构尚未存在的客栈建筑；宠物不新增独立持久资源字段。
- 精英首版清除后永久保存，休整不重刷。剧情人物继续使用自身旗标/原脚本，不进入普通刷新表。

## 5. 代码与存档合同

- `js/encounter-core.js`：纯状态机，可独立 Node 单测。
- `js/encounter-art.js`：图集载入、四向切片、状态图标与缺图回退。
- `js/encounters.js`：敌群配置、NPC代表、碰撞/视线、战斗适配、休整服务。
- `scene.js`：NPC列表、接触更新、深度排序和绘制接入；敌群不使用 NPC 硬碰撞圈阻止接触，而由地图碰撞与接触判定控制。
- `menu.js`：设置页休整入口；`index.html` 在场景定义之后、main之前载入系统。

旧存档首次访问惰性补齐：

```json
{"encounters":{"version":1,"trip":0,"cleared":{"bgate-west-bandits":0},"permanent":{}}}
```

`cleared[id]===trip` 表示普通群已清除；`permanent[id]` 保存精英。休整只增加 `trip` 并清空普通 `cleared`。运行时追击位置、计时器、输入锁不进存档，读档回合法站位并重新给入口保护。

扩展配置字段：唯一 `id`、`scene`、`kind`（normal/elite）、`faction`、`name`、`sp`、世界像素 `x/y`、`foes`（mk模板键数组）、`bg`、提示用 `lv`，以及核心参数覆盖。新增阵营需显式定义对应敌意政策；剧情对象继续使用原NPC脚本。无合法初始站位的配置打印错误并跳过，不能让角色刷在障碍里。

## 6. 素材与验收

素材需求见 [清单](../archive/design/wilderness-encounter-assets.md) 和 [机器清单](wilderness-encounter-assets.json)。2026-10-02 本批已生成并接入新版地图路匪、日景战斗背景、状态图集与三段提示音。战斗动作表、头像和地图底图经复核后复用；制作/验收证据见素材清单。

验证：`node tests/encounters.test.cjs`；启动本地静态服务后 `node tests/encounters-browser.test.cjs http://127.0.0.1:8137`。浏览器测试使用独立上下文，不覆盖个人游戏存档。覆盖暂停、预警、视线、归位、单次开战、入口/中路、逃跑分离、胜负与异常解锁、存读档、休整成本/取消/刷新、剧情旗标保护，并完成真实战斗奖励与战后键盘移动检查。

自动测试不能代替长时间游玩的密度/耗时评审；下一张地图扩展前再验收新配置。当前两群是试点，不宣称所有尚未设计的野外区域均已制作。
