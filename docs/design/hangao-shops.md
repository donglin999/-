# 汉皋城·店铺功能设计

状态：现行　最后核对：2026-10-19

> 2026-10-19：汉皋城现有剧情设计已作废，待重新设计（用户：“汉皋的剧情也还没定，只是指定了有哪些商铺之类的系统而已，所以取消现有剧情的设计，后面另起炉灶”）。本页的城市布局、店铺、系统、空间仍现行；页中夹带的剧情内容（主线节点 HG-M 与 T1—T10 时间点、端阳药案、寿宴、人物初识 HG-C、支线 HG-S、各人物来城缘由等）只作旧稿记录，不再作设计依据。见[汉皋剧情作废记录](../updates/2026-10-19-hangao-story-void.md)。

版本 HG-SHOP-2026-10-16.1。状态：**设计方案，待用户审定**。22 个场所的货架与服务已进入[交互原型](../../review/hangao-town/README.md)（未接入 8792 当前游戏）；店主小故事、强化面板、换妆改衣尚未做。店铺位置与清单总表见[汉皋城第4节](hangao-city.md#4-店铺与功能)；价格基准、鉴定、强化、赌坊、擂台等通用规则见[城市系统](hangao-systems.md)。本页逐家写：场景表现与可达条件、店主、货架、服务、熟客专柜、店主小故事、剧情带来的变化。

**界面**：所有店铺与场所统一用[挂轴式界面规范](shop-ui-standard.md)（用户 2026-10-09 确认）；本页只管货架与服务内容。

**说明**：

- 物品名为草案，按[命名规范](item-naming-standard.md)写（2—6 字、材质或工艺＋器形）；进正式清单前过命名审。已有正式物品（笼饼、金疮药、竹叶青、青锋剑、归谷短衣、牛皮护心甲、行旅夹衣、厌胜钱、檀木手串等）直接沿用，不另起名。
- 效果只写定位，具体数值等[平衡审计](martial-review/balance/README.md)。品阶：丁、丙、乙；甲、绝不在城中出售。
- “熟客专柜”在店铺好感 60 时出现（[城市系统第15节](hangao-systems.md#15-声望与店铺好感)）。
- 下文“营业：昼／夜／全”是历史表格沿用的**场景表现标签**：昼＝日景场所，夜＝固定夜景场所，全＝场景不以日夜区分。三者均不代表自动开关店；实际可达性仅由剧情时间点、活动范围、任务状态和店主位置决定（2026-10-10 已确认，见[时间规则](hangao-systems.md#2-剧情时间点与住宿)）。
- 2026-10-16 已同步活动不耗时的口径；消费计费、刷新与库存实例见[时间与经济细化](system-completion-20261016/city-time-economy.md)，新数字与新限制均为待评审提案。此页价格是城市草案价格；正式武器须按物品 ID 对齐[武器数值](martial-review/weapon-stats.md)，不得用城市原型覆盖已定稿目录。

## ② 鼓楼十字街

### 望江楼（正店酒楼）

- **营业**：全。**东家**：贾望之，左右逢源。
- **服务**：
  - **饭食**：点菜回复，按菜色给短时增益（城内与下一场战斗有效）：红烧鳊鱼（气血）、藕汤（内力）、酱鸭（臂力小幅）。每个剧情时间点一次。
  - **宴请**：花 15—40文请一位已认识的人物吃饭，信任 +2—+4，并触发一段饭桌对话（每人每月一次）。
  - **上房**：20文报价，计费实例见[住宿](hangao-systems.md#2-剧情时间点与住宿)，歇息不推进时间。
  - **打听**：给跑堂 2文，得一条酒客传闻。
- **剧情**（已作废，待重新设计）：寿宴外席（M04）；HG-S16 抢包间；HG-S24 玉麒麟藏在雅间屏风后。

### 远山镖局

- **营业**：昼。**人物**：寿主祁远山（退隐）、陆衡借住、镖头若干。
- **服务**：**护送委托**（与委托榜分开，报酬更高、按指定路线完成；路程叙事可以写 1—2 日，活动本身不推进时间）；本月最多接 2 趟。
- **剧情**（已作废，待重新设计）：寿宴主院；M05 核验地点；HG-S24。

### 汇通钱庄

- **营业**：昼。**服务**：存取铜钱（存在钱庄的铜钱，野外被劫不丢）；兑换票据（后续城镇通兑）。

### 鼓楼告示墙与驿递

- **服务**：江湖委托榜（[第3节](hangao-systems.md#3-江湖委托榜)）、官府告示（剧情信息）、商号招贴（主线入口）；驿递：寄信回归云谷（信件在6月月初送达，内容影响来信事件）、存档点。

### 通衢车马行

- **营业**：昼。**车把式**：老郝。
- **服务**：快速往返（[第16节](hangao-systems.md#16-快速往返)）；租马（下次走大地图速度提升，5文／次委托行程（计费口径提案，结束后解除，不按现实天数））。
- **剧情**（已作废，待重新设计）：HG-S22 老马病了。

### 白鹇医寓义诊棚

- **营业**：昼（端阳前后十日）。**人物**：苏芷、许知衡。
- **服务**：免费治伤（拟每个剧情时间点一次）、解毒；收购草药（比药铺高一成，但只收药材，不收杂物）。

### 端阳药市（临时）

- **营业**：初三—初七，昼。十余个临时药摊，可买端阳限定药材（菖蒲、艾草、雄黄），也有几个摊位卖可疑的“仙丹”（察看辨识可识破，识破后报给查验队，城市声望 +）。
