## 1. 所有角色共同满足

| 检查 | 必须成立 |
| --- | --- |
| 身份 | 同阶段各图同脸、发型、发色、体型、年龄；身份参考有实际文件，不只写「清秀／冷静」 |
| 阶段 | 衣物、徽记、武器、医具、伤病符合当前剧情；不借未来素材暗示已经入门或学成 |
| 结构 | 手指、关节、握持与肩带受力正确；人物和道具完整，没有多手、悬浮器具或错误承托 |
| 媒介 | 白描淡彩立绘、探索像素、战斗像素各自使用对应标准，不靠滤镜互相替代 |
| 来源 | 保存基准、完整提示词、原稿、实际生成工具与可获模型信息、原生尺寸、处理与运行路径 |
| 显示 | 1280×720 与 1920×1080 的真实显示尺寸可辨；一张放大原图不能证明小图可读 |

## 3. 探索与战斗最低覆盖

四向朝向、步态、承重接地、首尾循环、左右道具与逐向实机检查详见[四向行走质量](character-walk-quality.md)。文件尺寸通过只是第一步。

**可加入人类**：进入地图探索的阶段需四向站立与完整步行循环；新表建议每方向至少 4 帧，既有四列站立／行走合表可继续采用。专用跑步是独立提升项：角色卡明确 needs_dedicated_run=true 时才派四向跑步，每方向至少 4 帧，须表现真实跑步。叶蘅现行以行走表调整步频跟随加速，不因缺独立跑步文件就判基础包不齐。已有更丰富的 12／10 帧表可复用，不能按最低值重做缩水。

**可参战人类**：必须映射 `idle、dash、atk、atk2、hurt、cast、brk、dead`，我方再含 `win`。当前我方 20 帧方案为默认参考，动作内帧数以[战斗规格](../battle-sprite-spec.md)为准；新武器／招式调整需保留完整起手、执行与收势。角色无第二种普攻时 `atk2` 可显式映射第一种，不能把缺失攻击全部退到 idle。特殊技能新增具体姿态，不必一技能一整套独立表。

普通 NPC 剧情动作始终为 0。一个普通 NPC 确实参与战斗，就按 combat=true 提供对应战斗包；这只补战斗需要，不给其任务场景增加动作演出。动物动作按物种规则展开，不强行补人类合掌、跪地或胜利姿态。

## 4. 采用前与接入后的记录

每个资产卡维护五个检查：身份、阶段、结构、媒介、显示。尚未做的检查写 pending，失败写失败事实和截图，不写空泛「质量良好」。

角色基础素材齐备、章节适配完成、新增资产验收分开记录。现有已接入基础包不因章节尚未开发而整体退回 pending。新角色／新资产交付须满足：实际必需项有合法文件与映射；源图检查通过；两种视口显示通过；动态包有关键帧运行证据。表情或专用战斗表缺失才列对应基础缺口；可加入人类的六张完整对白状态（动作与情绪合一）自2026-10-04起计入新包必需项；额外事件姿态和未另行要求的专用跑步不计入该新静态包。新章节仍须核对服装、技能、背景与状态，当前襄阳验收不冒充开始部分验收。

制作时先生成该角色一张定妆和少量代表图，验证画风与手部，再扩展必要表情／姿态／帧。每张差分直接引用同阶段基准；不让一串编辑把脸逐步变成另一个人。
