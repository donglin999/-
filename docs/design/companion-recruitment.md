## 一、四种资格与独立日程

| 招募资格 | 含义 | 如何变化 |
| --- | --- | --- |
| 未建立关系 | 尚未认识或刚见面，不能随意邀请 | 公共初识或补初识事件 |
| 已结识 | 能交谈与发展剧情，未获长期同行资格 | 完成各自招募事件 |
| 体验同行 | 因当前任务暂时可控，可体验技能 | 结束条件显示在任务和队伍页；结束回到原资格 |
| 正式同伴 | 已有长期同行约定 | 可邀请、留驻、暂离；不会因不在队自动丢失 |

资格、是否在队、地点与日程分开存储。正式同伴可处于在队、空闲候补、驻谷学习、处理公务、个人任务、关系待修复等状态。体验结束不撤销已有正式资格，学医和公务不等于未招募。

叶蘅是初始正式同行的特殊入口；其长期主线承担关系塑造，不补收好感门票。苏芷初见阶段（初见地点与剧情待重新设计）允许直接体验，但不因此跳过后来的个人篇。男性也不能因体验过就免除短剧情与正式条件。

裴知古以[2026-10-10已确认改设定](companions/pei-zhigu-valley.md)为准：进城前在谷内相识，培养第一年五月同行；早期相识可漏，保留城中补初识。后续勘误与写书是她已入队后的个人篇，不再以旧PG六节点作为首次招募门票。殷红缨按[关系细则](romance-rules.md)中的培养入口及游历if补救处理，不套用“只能游历后招募”。

## 二、前期体验怎样安排

1. 场景给出共同任务，角色主动提出同行，玩家可接受或暂缓；任务必需出场者即使不上阵也能承担其剧情职责。
2. 显示“本次同行至：送药结束／离开本次历练”等明确范围，不按未提示的现实分钟到期。
3. 入队后可控、可查看技能与职业说明；低练度阶段提供适配招式，不能把后期绝学提前永久送给主角。
4. 任务结束有告别、回访地点与下次线索；正式个人篇未完成时显示“已相识，长期同行尚待约定”。
5. 测试片段可提供明确标注的体验队伍，仅作用于测试存档，不写成正式招募成功。

默认不在村祸开头强行塞进所有职业。首次进城（汉皋城内剧情待重新设计）原拟以叶蘅、苏芷体验为主，可选陆衡护送；其他角色随试艺、运货、短期公差逐步开放。体验不占满全部自由时段。

## 三、正式招募条件

### 男角色

共同小事完成 AND 信任达到角色门槛 AND（指定技艺档位 OR 事件成果替代）AND 本人同意及日程允许。无技艺条件的角色按其表格条件判断，不凭空追加。

2026-10-16用户确认单关系轴后，招募文案中的“信任”指该人的个人关系及合作事实，不新增第二条信任数值；首版关系门槛20—25仍为设计起点，具体见男性表，并须满足本人瓶颈。礼物不能替代必要成果。短剧情写清共同目的和原职业交接即可，不要求每人长篇身世。

### 女角色

个人篇达到招募节点 AND 关键责任已处理 AND 双方同行目标成立 AND 本人明确同意及日程允许。好感或交涉数值可提供不同解法，不允许直接跳过个人篇。每人至少六个节点，分布于初识、培养、下山，不一定一次连续演完。

不是统一“救她一次—送礼—表白—入队”。必须有本人选择与善后；长期同行可建立在事业、朋友、共同立场或互助上。结缘系统独立，当前15位可招募女性全部可结缘，并允许多人结缘；友情能完整招募。2026-10-16用户确认沿用单关系轴与阶段瓶颈；结缘使用托付80、成年、个人篇和本人心意等条件，取消独立情意与人数加价，见[关系接入合同](system-completion-20261016/endings-relationship-integration.md)。

### 条件失败与补做

普通不足可回来补做，显示缺项与下次去处。错过培养期初识不永久锁人，下山通过重逢与共同事件补齐关系；不能用一句旁白跳过完整人物篇。永久拒绝只用于明确的重大伤害或不可逆立场，行为前提示；主线关键通路不得依赖某个可失去的同伴。

## 四、人数与编队（首版提案）

- **出行人类队伍最多4人，含萧白**；每场战斗默认由这4人参战，暂不设计战斗中任意换人。
- 正式同伴名册不因4人限制丢失。候补有实际所在地和可见空闲窗口，不瞬移到当前地图。
- 安全地点可调整队伍；相约会面或在共同据点集合后替换。路线与时间规则明确后再定旅费，不在危险战斗中叫来远方人。
- 剧情必要但未入编队的人可作为场景协作者，提供对白或预定支援，不默默增加第五个可控战斗位。
- 宠物独立自动参战，不占人类名额，默认队尾；数值验证另做。

4人是本轮方案，正式实现前按战斗节奏确认。叶蘅在主线必须出场不等于永远占固定战斗位；驻谷状态用通信、约定会面或分工承接，不能同时出现在山谷与远方。

## 五、界面操作

NPC交互增加“邀约同行”模块；队伍页按在队、可邀约、暂不可用显示，角色详情包含资格、战斗定位、当前位置、可用窗口、关系、未完成约定与个人篇进度。

| 情况 | 按钮与反馈 |
| --- | --- |
| 初次体验 | “本次同行”，先展示期限与结束去向 |
| 条件不足 | “商议同行”，列出缺少的事件／信任／日程，不把隐藏身世直接剧透 |
| 条件完成 | “邀请加入”，角色确认同行目的后取得正式资格 |
| 已满队 | 弹出4个在队位，选择换下者并显示留驻地点；可选“登记为同伴，暂不同行”或取消 |
| 角色有公务／学业 | 显示原因与下一窗口，可“约定会面”，不能用高好感强行拉走 |
| 正式同伴离队 | 使用“暂别／返回职责”，明确去向和再次邀请办法 |
| 严重分歧 | 显示争议与修复方式，需剧情处理；不允许重复点击邀请洗掉后果 |

招募成功只处理一次，不重复送初始装备或任务奖励。满队取消不得推进已入队标记或扣物品；剧情已授予正式资格与实际编队步骤分开，先获得资格者仍留在名册。

## 六、成长、装备和离队

人物经验、所学、关系与装备跟随角色保存。暂离或转候补不清空成长，不允许离队再招募复制资源。剧情固定的体验装备标记为角色自有，不可出售；玩家借出的装备在结束体验时可选择收回，角色外观不因此出现不合剧情的裸体状态。

正式同伴普通暂离时装备仍由其持有，离队确认提供收回玩家借出物品的机会；剧情强制离开则将这类物品安全转入公共保管处并告知。任务证物归任务系统，不被带走锁主线。

候补与不在队角色只按明确完成的训练、职业经历节点获得个人成长，具体数值待平衡，不自动追平萧白，也不复制其练满的技能。首次入队按[逐人固定配置](character-levels-100.md)，晚认识不改成随主角等级生成；已临时参战获得的成长保留。裴知古遵守必须在队的见闻规则，离队不补记；普通同伴的共享历练适用范围见[历练池](shared-insight-pool.md)。

## 七、实现所需最小数据（仅设计）

角色ID、来源组织、招募规格（初始／短篇／完整人物篇）、正式资格、体验前资格、当前同行状态、地点和时间窗口、信任、事件节点、招募条件组、承诺与背约、可重试／永久拒绝原因、角色成长、装备归属、已领奖标记。

性别用于内容配置，不作为引擎中不可改的招募算法。当前男角采用短篇、女角采用完整篇，以每人招募规格选择；这样未来增加有长篇故事的男角色不用改底层。女性各自节点不可统一压成同一条模板剧情。

状态变更必须一次提交资格、编队、日程和物品，存档保留版本迁移方案。旧存档已有苏芷时保留既得资格并标注兼容来源，不直接剥夺；旧体验片段与新正式流程区分，具体迁移在接入前核对现行代码。

## 八、以后实现的验收场景

1. 苏芷初见时直接体验（初见地点与剧情待重新设计），结束后有去向；重新邀请不能复制装备或越过个人篇。
2. 叶蘅入谷后仍是正式同伴，驻谷期间显示日程，回访和毕业后恢复可邀约。
3. 男角色完成任务但数值不足，补足后能加入；两种替代条件均可达。
4. 女角色高好感但未完个人篇不能正式加入；完成友情路线可加入。
5. 满队替换、暂不同行、取消、读档均不丢资格、角色或物品。
6. 跨阵营角色可通过具体约定共同行动；严重分歧有提示与修复，不用单个阵营标签封死。
7. 强制离队不带走主线证物，晚招募不重复领奖；宠物名额不混进人类编队。

本轮仅文档，不修改运行逻辑，不宣称上述场景已经通过代码测试。
