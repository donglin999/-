## 章节位置与人物动机

第一年夏，萧白与叶蘅同行到襄阳采买药材。叶蘅已有乡村医者经验，苏芷是更成熟的游方医师。老周在街心中毒倒下，二人一起稳住他的脉，萧白调查毒与解药。苏芷看见叶蘅的判断力，提出可代递医案给白鹇谷医师；是否递交、何时入谷，由叶蘅自己决定。本片段不会提前选择叶蘅三年后的路线，也不会认定叶家医术与青蚨散同源。

## 必经节拍

| 顺序 | 玩家所见／要做 | 剧情信息与状态 |
| --- | --- | --- |
| 1 街心 | 老周倒地；宽幅事件画呈现叶蘅与苏芷合力施救，随后萧白选护空地、取清水或问人。 | 青蚨散可暂缓，须取解药；任务进入查访。清水不能直接灌给吞咽不稳的病人。 |
| 2 三处问话 | 包打听讲例钱纠纷，柳三娘证实刘碰茶碗并交出茶碗，说书老伯见刘左袖小瓶。任取两条可推进。 | 动机、人证和物证分开呈现；没有十两收费或对对子、听书等强制门槛。 |
| 3 茶棚对质 | 可摆证、代付三娘二十两，或先动手。疤脸刘与打手一场战斗。败北可重新准备。 | 代付只解决眼前勒索，不能代替拿解药；胜后得青瓷解药瓶与铁臂帮账簿。 |
| 4 处置刘 | 交军士、逼其放弃收例钱、或拿钱袋充药费。 | 影响道德与银两；他承认经手茶碗，不等于他配制了毒。 |
| 5 救老周 | 把解药交给苏芷。苏芷施针、叶蘅扶肩喂药，老周醒来。 | 药瓶消耗；可拒收谢钱或代管药费；白鹇谷医案引荐仅作为后续伏笔。 |
| 6 地方结案 | 街心案卷选择“记录地方结案”；或继续向东津渡追查。 | 保底闭环是救人、固定证据与责任。苏芷可同行或留城照看老周，不锁住渡口。 |

救人前不存在结案按钮。取得两条证言后可直接对质，第三条线索仍可查。老周获救后，玩家能够继续游历，地方结案可以在同一档中升级为深追结案。

## 对白语气与关键台词

| 人物 | 说话方式 | 本章关键表达 |
| --- | --- | --- |
| 萧白 | 直接问证据，遇到急症先协助医者 | “老周拒交例钱，你碰过他的茶碗；有人看见你把小瓶塞进左袖。” |
| 叶蘅 | 观察细致，短句判断，遇到病人先做事；不把未证实推断当结论 | “这是动机，不是下毒的证据。”、“交不交、何时交，我想自己再想一想。” |
| 苏芷 | 话少、动作准确，尊重叶蘅的自主决定 | “是对药。叶蘅，留意他的呼吸。”、“若愿意，我能替你递给白鹇谷的一位医师。” |
| 老周 | 惦记货担与生计，感谢不夸张 | “我还活着？货……货担呢？” |
| 柳三娘 | 怕帮会，又愿为街坊作证 | “碗我留着。若要对质，我作证。” |
| 包打听 | 看重消息来源，提供动机而非定罪 | “欠的早晚得还。” |
| 说书老伯 | 以见闻作证，有自己的职业自尊 | “说书看的是眼，认错了砸自己饭碗。” |
| 疤脸刘 | 街坊面前勒索，对抗中把责任推给“上头” | “我收钱、递碗，没配过毒！” |
| 汤老舵 | 熟悉渡口货路，谨慎务实 | “钱袋用麻绳双扣，送上东岸从不让船户碰。” |

## 交互与奖励规则

- 包打听、柳三娘、说书老伯取得线索后仍有符合当前案情的短对白；不回落到旧开局的价格、谜题或“单人萧白”称呼。
- 叶蘅开局在队并跟随，场景对白和队伍页都能确认她的在场；苏芷仅在玩家同意后成为正式队友，茶棚战允许临时协战。
- 茶碗、解药、账簿和货签都进背包并有独立图标。解药救人后消耗；账簿和货签为证据，不给出未查到的配毒者姓名。
- 结算只记录襄阳地方案卷，允许继续游历或重测。三年培养、白鹇谷入门以及人物最终分支尚不在这个入口展开。
- 战斗失败不发胜利奖励，不推进证据或任务；苏芷未入队时，深追结案由叶蘅归纳证据，不能隔空出现苏芷台词。

## 状态验收

基础路径：开场 → 任两条线索 → 对质与刘战胜 → 取药 → 救老周 → 地方结案 → 继续游历。分支应至少检查：线索顺序、代付银两不足、刘战败重试、苏芷拒绝同行仍可渡江、地方结案后深追升级、渡口多解法、寨门通行与硬闯、苏芷有无、重测隔离存档。自动测试和未覆盖边界记在[测试范围](xiangyang-test.md)。
