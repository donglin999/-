# 黑风寨地面表现改造方案

状态：2026-09-30 地表第一轮实装。场景空间、遮挡物和可走边界以[黑风寨设计](black-wind-fortress.md)为准；本方案只处理可走地面的表现，不以颜色暗示空气墙。

方向稿：`review/blackwind_ground_concept_v1.png`（只供草土层次与细节密度参考，**不允许直接替换地图**；生成图重绘了门楼、树石和比例，且日间鲜亮色调不符合现行夜景，需回到原场景资产逐层制作并按夜景光源调色）。本地纯程序地面样张 `/tmp/blackwind-ground-v2-prototype-2.png` 仅修了直边与细点，视觉改善不足，未纳入正式版本。

实装图集 `raw_scene/cut/bgate_ground_atlas.png` 为生成的 4×3 透明候选；第一版缩小时成为深褐斑块，已退稿，现用第二版明显的低分辨率草叶和碎石形体。`bgate_ground_edges()` 只打散草土交界；`bgate_ground_decals()` 按西坡、东坡、营地边缘和山道四组确定性坐标摆放，`fp='none'`、`sort='flat'`，不参与碰撞与人物遮挡。正常 1280×720 本地游戏镜头见 `review/blackwind_ground_v2_gameplay.png`，上线后从正式域名重跑游戏流程所截的同视口画面见 `review/blackwind_ground_v2_production.png`；线上实走 `fails=0`、`errors=[]`。这一轮改善地面形状与静态细节；高草交互动态仍属后续制作，不将其冒称完成。

## 问题

现行寨门以一整片草地、整块夯土场和一条土路构成三种大色块。它们的多边形边界过于直，草点均匀撒满场景，没有区域的使用痕迹；一眼能读出「绿色区域」与「黄色区域」，却看不出营地、山坡和常走小径的自然关系。只在整个场景叠统一滤镜或再随机放石头，无法修正这个结构。

## 分层制作

1. **底材与形状**：保留草坡、夯土场、下山小径三种语义。仅让草土交界以低频起伏破边，宽窄由人审，不让窄路断开。泥路和营地仍能从构图辨认，边缘不再像用直线工具裁出。
2. **过渡层**：草根侵入泥地，土屑散进草边；控制在约 3–8 源像素的边缘带内。色值差距收小但不涂成模糊渐变，保持与现有地图一致的硬边像素簇。
3. **地表生活痕迹**：营地入口与草棚前为踩踏、灰土、碎木；枯树与山石旁有成簇野草、落叶和阴湿苔点；山道有冲刷沟、浅脚印和零星碎石。每处细节解释场地使用或地形变化，避免全图均匀随机噪点。
4. **上层物件与纵深**：草束、矮灌木、石砾大小分级。可跨过的低草仅画在地面，不改变可走 mask；树干、岩坡和挡土墙才承担碰撞。火盆光、树影与近处草叶提供局部层次，不能靠全局滤镜制造深度。
5. **克制的动态层**：只在坡边高草做小幅摆动，玩家经过时压弯并回弹；火盆附近维持烟、火星和暖色局部照明。夜景可有极少量虫光，但不要让全场草坪同时起伏或满屏飘粒子。动态层仍依附上述位置设计。

## 可复用生产原则

正式图集应备齐草／土／石边缘的直边、内角、外角与中心变化，并给同一材质准备多张轻微差异的底纹；摆放时以邻接关系选过渡形态，以限定区域的权重散布装饰。当前项目不是 TileMap 引擎，先在 `build_scene.py` 中按相同逻辑确定性烘焙地形；不因美术变化新增碰撞多边形。若后续切换 TileMap，维持相同的区域语义与资产清单。

行业依据：[Godot terrain sets](https://docs.godotengine.org/en/4.1/tutorials/2d/using_tilesets.html)用邻接关系选择边、角及材质过渡；[Godot scattering](https://docs.godotengine.org/en/latest/tutorials/2d/using_tilemaps.html)可把多个细节图块按概率散布到地形；[Unity 2D Tilemap Extras](https://docs.unity3d.com/cn/current/Manual/com.unity.2d.tilemap.extras.html)包含 Rule Tile、Random Brush 与 Animated Tile。这些是生产方法参考，不表示本项目需要切换引擎，也不表示随机撒点能替代区域设计。

## 验收

- 对比改造前后无 UI 全景与 1280×720 正常游戏视口，草地仍看得出可走且寨门／山道的引导明确；不用颜色猜测禁行边。
- 检查不同密度的近景与远景草簇、泥土侵入草边、营地踩踏和山道磨损；放大看不存在连续平滑糊边或明显重复图案。
- `ground_contract.py`、地图出口审计、左右草坡和山道实走结果与上一版相同；美术更新不得让低草挡路。
