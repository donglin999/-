# 培养部分：培养、人物往来与逐句剧本整改

状态：现行　最后核对：2026-10-19

日期：2026-10-12。责任文档库：xiaojianghu；正式游戏实施位置：xiaojianghu-legacy-prologue / 8792。用户要求：每次培养必须有可解释的实际作用，人物关系可见，师门教学采用已有功法，心法按传承解锁，逐句重审现有台词。

## 已查明的问题与修订边界

1. 正式版 `growth()` 只统计 period 0–19 的六种课程次数，许多实际进度完全没有消费方。第五个月以后继续练习也没有属性增量。
2. 战斗读 `derived()`、江湖页读另一个 `calc()`；旧培养只扩展了前者，所以两个页面的数字不一致。
3. 关系实际存在 `cultivation.relations`，但人物图鉴只显示栖河旧人，归云谷家人与裴知古没有档案；剧情关系变化也没有结果展示。
4. 正式版教学仍使用占位名称，拳课更把普通攻击 `fist` 当成门派所授拳法，没有独立功法身份。
5. 过渡对白说“归云心法”，结算登记 `tuna`，造成传承误解。机器清单中的通用丁级内功为《吐故纳新篇》；丙级《出岫心经》、乙级《观岚诀》、绝级《万壑归元诀》另有身份，不能凭进入培养自动全学。

本轮覆盖当前所有可运行培养活动和全部现有剧情分支。没有完成的高阶传授须明确列为后续剧情，不用换名字伪装成已实装。原有演出登场、发型、成年门槛、送药方式、胜负和关系瓶颈保留。

## 好感度怎样落在人物上

人物图鉴和同伴属性摘要显示同一条真实关系：分数0–100、阶段、当前上限、最近三次变化的事件与时间。阶段为初识0–19、熟络20–49、信赖50–79、托付80–100；重要事件开放上限，送礼不能越过剧情。关系不是额外攻击加成，不为了好感改写角色本人去向。已经存在的剧情门槛（小师叔同行／留谷、个人篇、夜谈与成年结缘）继续直接读取此分数。可说明下一段关系需要哪件经历，不能把人物图鉴写成走路指示牌。

未认识的人不显示；归云谷家人和裴知古在真正出场后入录。原开始部分旧档人物仍保留。送礼、寄信和一次性剧情都显示实得变化；被瓶颈压住时说明当前阶段已满，而不是声称获得了未入账的数值。

## 对白参考、取舍和逐句交付

参考《侠客风云传》的机制和情境安排：[官方系统介绍](https://wulin.fhyx.com/)；入谷时以疗伤、搬东西误会、师兄反应引出人物，而不是大家轮流宣讲制度，见[逍遥谷入门图文流程](https://www.gamersky.com/handbook/201507/626604_3.shtml)和[第二章情境记录](https://www.gamersky.com/handbook/201507/627164_26.shtml)。这里提取的是“具体事情先发生、性格在接话中显露、授艺落到一门实际功法”的写作办法，属于对这些材料的设计判断；没有照抄其对白。

萧白：先反应、再问，不动辄总结道理。周砚：话短、盯动作，温厚中有规矩；不把“边界、实际、范围、授权”当日常口头禅。江采薇：食物、衣服、家务承载关心，能怼人也能疼人。钟拙：动手比解释快，和师兄抬杠不论证制度。殷红缨：利落、调笑，涉及旧事时收住；不句句插科打诨。方迟：稳重，负伤时嘴硬但会疲惫。小豆：爱撑师兄架子，话被现实打断。小满：孩子的直话，不借她说成人道理。叶蘅：确实懂药，谈自家旧事有个人情绪，拒绝或询问用具体对象。知古：爱书、敏锐、会困窘，与主角能互相取笑，避免每场都像公开答疑。

每句记录包含稳定ID、场景／时段、说话者、前置与分支、修订前文本、采用文本、发言目的与接话关系、表情、实际上场名单。标题卡与内心独白分列，人物不用系统结算句替代正常台词。选项写萧白要做什么，数值独立写在结算里。逐句表见本目录 `dialogue.md`，机器源见 `../scripts/chapter-two-dialogue.json`；正式文本由生成器编译，编辑源后核对覆盖率和缺失句，不能手改生成文件。
