## 视觉层级

山居界面承担三年休闲培养的常驻画面：季节、年月、三格活动、人物来访、邀约期限和角色状态应在一屏读懂。进入城镇或野外时切回可探索地图和战斗。剧情事件结束返回山居时，用简短结算说明时间、能力、关系和未完成事项的变化。

| 对象 | 必需阶段 | 一致性要求 |
| --- | --- | --- |
| 萧白 | 现代装、入世便衣、山居练功／出游装 | 同一成年脸和发长；学剑后才持剑 |
| 叶蘅 | 村中医者、白鹇谷医师、山居同行 | 同一成年脸、体型、发色；两线以服装、医具与动作区分 |
| 苏芷 | 游方医者、后续白鹇谷关联状态 | 与叶蘅在颜色、发型、针囊轮廓上可辨 |
| 大黄 | 跟随、进攻、护主、受伤 | 一只宠物的连续外观，不把宠物当人类队员换装 |
| 场景 | 村址、山居四季、襄阳案场、谷中医舍 | 时间与季节能从光、植被和人流看出，不仅靠界面文字 |

立绘状态由角色、路线、季节事件和伤病决定。先确定角色阶段与事件需要，再制作图；本轮只写规格，不生成素材。旧第一章素材可作复用候选，但“苍龙身世”图像与古代少年萧白设定不能直接作为新主线的权威外观。

对话、交互、任务和队伍菜单都应清楚显示“可做什么、会消耗什么、行动后发生什么”。任务接受或完成提示不能阻断移动；当前 `toast()` 已改为立即返回，后续仍按[襄阳片段测试](xiangyang-test.md)回归验收。
