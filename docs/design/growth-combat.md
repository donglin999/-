# 成长与战斗

状态：保留现行游戏已做的战斗体验作为基础；培养与新角色接入属**设计方案**。具体运行状态以[战斗技术文档](../battle.md)和代码为准。

## 角色成长

成长来自三年[月度活动](cultivation.md)、事件选择、战斗和导师请教，不只来自刷战斗。萧白开始不会武功，先学防身、兵刃和运气；可偏武艺、医理、交涉或综合路线，但主线任何单项不要求满级。叶蘅在白鹇谷偏诊断、解毒、针术与持续治疗；留山居偏急救、护人和医武协同，详见[分支](ye-routes.md)。

武学是主动招式，心法是修习方式或被动效果；医术、打探、劝说等技艺另有用途。经验提升要给明确来源、当前档位和下一步，不把剧情资格藏在未说明的数值里。精通或“归息”可以奖励专精玩法，不能成为了解父母真相的条件。

## 战斗规则边界

现行八方式的护盾、弱点、破势、蓄势可保留为战斗骨架；战斗目标来自剧情与敌人行为。多数地方冲突允许非战斗或较低难度的替代处理；主线强制战提供受伤后的复试、准备或支援，不因一次败北锁档。数值重算要以三年成长节奏、叶蘅两线和宠物自动行动为准，不能沿用原六章节的敌人等级表。
