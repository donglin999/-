# 成长与战斗

状态：现行　最后核对：2026-10-19（原记：保留现行游戏已做的战斗体验作为基础；培养与新角色接入属**设计方案**。具体运行状态以[战斗技术文档](../battle.md)和代码为准。）

## 角色成长

2026-10-13用户确认角色满级100级。逐人首次出场、入队固定等级与迁移边界统一见[百级人物方案](character-levels-100.md)；该页逐人数字为本轮规划，不等于现有NPC已改。

成长来自三年[月度活动](cultivation.md)、事件选择、战斗和导师请教，不只来自刷战斗。萧白开始不会武功，先学防身、兵刃和运气；可偏武艺、医理、交涉或综合路线，但主线任何单项不要求满级。叶蘅在白鹇谷偏诊断、解毒和针药增益支援；留山居偏针法攻击、穴位牵制与医武协同，两线都保留基础救治能力，详见[分支](ye-routes.md)。

[培养路线框架](cultivation-routes.md)为正派、魔教、朝廷预留各自教学与事件，当前只细化山居。成长数值须按实际路径的培养时间、地图收益和组织资源比较；六个地图月、1410 点体力只作为山居示例。未来若正式转线，已学能力保留，新教学另按资格开放，不重新领取另一线整套成长；主角路线与叶蘅能力方向分别记录。

武学中的功法分外功和内功：外功收纳招式，内功固定一个主动技能和一个被动技能；医术、打探、劝说等技艺另有用途。经验提升要给明确来源、当前档位和下一步，不把剧情资格藏在未说明的数值里。精通或“归息”可以奖励专精玩法，不能成为了解父母真相的条件。

## 战斗规则边界

现行八方式的护盾、弱点、破势、蓄势可保留为战斗骨架；战斗目标来自剧情与敌人行为。多数地方冲突允许非战斗或较低难度的替代处理；主线强制战提供受伤后的复试、准备或支援，不因一次败北锁档。数值重算要以三年成长节奏、叶蘅两线和宠物自动行动为准，不能沿用原六章节的敌人等级表。
