## 一张图表达一个完整状态

对白状态立绘是对话框旁的**透明人物层**。表情、双手动作、肩身、头角度、视线和重心共同表达情绪，切换时直接换整张图；不单独贴脸，不把负面表情套在欢迎或开心身体上。背景菜单图与CG是另两类素材，不进入这个包。

| 状态 | 表情与身体必须协调 | 用途 |
| --- | --- | --- |
| 常态倾听 `neutral` | 自然闭唇、平静视线、肩颈松弛、手势收稳；不是固定欢迎动作 | 倾听、说明、日常对话 |
| 开心认可 `happy` | 眉眼舒展、真实笑意，肩身打开，手势有认可或接话意图 | 好消息、欢迎、放心 |
| 伤心担忧 `sad` | 内眉收、目光低、嘴角落，肩稍沉、手收低、重心后移 | 牵挂、失落、不安 |
| 愤怒拒绝 `angry` | 不笑、眉压低、目光直接、唇收紧，稳定设界、护物或示停 | 拒绝、维护边界、制止 |
| 惊讶发现 `surprise` | 眉眼抬、唇轻分，躯干小幅后移，手靠胸或稳住随身物 | 意外发现、确认消息 |
| 角色专属情绪 | 按本人性格和职业设计整个人的反应 | 如叶蘅含蓄亲近、苏芷疲倦、闻疏桐思考、阮青雀认账 |

六张包含常态，总数就是6；没有额外的中性基础、纯脸图或“5动作×6表情”组合。每个状态必须画出可读的身体变化。不是要求全员同一个示停手模：医者护医具、曲师收琴拒席、船工护工具、护运者挡护，逐人手势见短文档。

## 身份与阶段

18人使用当前图鉴各自已选定的身份阶段，萧白为固定主角、宠物和普通NPC按各自规范。未来可招募角色制作本包不代表当前章节已开放招募。叶蘅采用初版偏瘦清秀的朴素行装；唐照雪采用用户指定蓝白竹纹原图；秦绯鸢保留舞者规则覆胸纱、前后半透明红裙与不透明内衬。不得因为换情绪擅自換脸、换门派、换衣或添加后续装备。

每张独立引用本人当前身份基准与经过验收的透明图，不从上一张情绪连续派生。脸型、眉眼、鼻唇、发型、服装连接、道具归属和身高体型稳定，身体姿态允许随情绪明确改变。现有整图只有通过“身体与情绪协调”的新验收才可复用；旧的悲伤／愤怒脸配欢迎身体不再展示。

## 生成提示词

每张完整提示词链接在[逐人设计](companion-performance/index.md)，实际调用提示词与输入路径另存。明确写出左右手、肩身、承重与视线，同时写出眉眼嘴；不能一边要求悲伤、一边要求锁死欢迎身体。高质量精细武侠白描、淡彩水墨与克制水彩沿[固定画风](character-portrait-style.md)，每位五官差异沿本人原稿。

生成设置真实透明背景，只有人物和随身道具，不画菜单场景、米色纸底、地面阴影、文字或假棋盘格。原生输出和失败尝试保留以追溯；运行导出只等比缩放，不做贴脸、手工拼肢体或放大冒充原生达标。记录实际工具来源，模型名未暴露时如实填`not_exposed`。

## 验收标准

- **情绪和动作一致是硬门槛**：担忧／伤心的低垂收拢、愤怒的设界稳直、惊讶的肩身反应必须在真实对白大小看得出；负面情绪仍挥手欢迎、开放邀约、开心微笑直接退回。
- 与常态相比，其他状态至少改变手臂轮廓、肩身／头方向、重心三类中的两类；不用翻转、裁切、移动物件或只改脸充数。同一种专属情绪也须与开心或常态的身体有区别。
- 原生目标1024×1536、2:3、RGBA PNG；运行512×768带alpha无损WebP。整张共同画布等比导出，不按各图轮廓裁切。头顶约8%、脚线约93%为构图目标，实际数值测量后记录，不能把目标写成已测。
- 头顶、双手、双鞋、衣摆和道具完整；恰有两臂两腿，髋膝踝鞋连接合理，握持承托正确。多腿、断接、悬浮器具、裁道具或关键部位即退回。
- 深浅底检查真实alpha、细发与纱料，没有纸色背景、黑白边。秦绯鸢的纱有布料结构和透度，不透明胸衣与腰胯短衬保留。
- 1280×720与1920×1080核对整图切换、脸和手的可读性、脚线／身高稳定以及名字、正文、选项无覆盖。双人／三人和CG抑制按[站位](dialogue-staging.md)检查；预览检查和实机演出分别记录。

六个独立门槛为`identity / stage / structure / medium / emotion_pose / display`。`display`须记录具体检查范围，本轮为单人对白预览；实机接入单独记录。文件检查只能证明分辨率和透明通道；内部美术验收、用户定妆、采用、实际游戏接入分别记录，不自动互相代替。

## 剧本选图

节拍填 `character / stage / dialogue_state / intent`，只选一张已经存在的完整图，不再填独立`pose + expression`组合。主要情绪、选择或说话意图转折时换图；同一情绪连说数句沿用，听者有真实反应才变化。默认常态，缺图明确记缺口，不能回退欢迎动作冒充悲伤完成。

例：叶蘅听病情→`neutral`，担心恶化→`sad`，拒绝强索药袋→`angry`，听到转安消息→`happy`。前后两句的表情和全身姿态一起变，不随机轮播六张。
