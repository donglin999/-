# 02 序章（上）：开局、段落调度、后山固定场景

源：`qihe-map-trial.js` `start/fresh`；`prologue-arrival.js` `play/encounter/dog/lodging`；`prologue-backhill.js`；`prologue-water.js`；`prologue-dog.js`；`prologue-story-battle.js`；`prologue-modern-art.js`；剧本 `story/01-开始/序章-*.ink`。

## 1. 新档初始化（`qihe-map-trial.js` `start(force)`）

- 无有效旧档：`S=newState()`；`S.name='萧白'`；`S.prologue=fresh()`；`S.scene='prologue_backhill'`；`S.party=[]`；`S.pet=null`；`S.unlocked={}`；`S.hp/mp=derived().mhp/mmp`。
- `fresh()`：`{version:2, errands:{bowls:'none',cloth:'none',medicine:'none'}, carry:{}, heard:{}, relicSeen:false, rested:false, ending:false, yeHousePermission:false, arrival:{version:1,stage:'encounter',borrowed:false,originExpression:null,dogResult:null,greeted:{}}}`。
- 通用：`mode='scene'`，玩家 `dir:'d'`、`alpha:1`；`cur.dark = prologue.rested ? 'rgba(13,22,32,.32)' : null`；`placeName(cur.name)`（地名条显示 2200ms）。
- 右下固定按钮 `#qihe-journal` “行程 · J”：`position:fixed;right:16px;bottom:12px;z-index:6;padding:8px 14px;background:#24271dee;color:#f3dfb4;border:1px solid #8f8056;border-radius:4px`。
- `PrologueArrival.bindGreetings()`（见 04 §5）→ `QiheChapter.restoreScene()` → `checkpoint()` → `arrival.stage!=='done'` 时 `PrologueArrival.play()`。

## 2. `PrologueArrival.play()` 段落调度

守卫：`running||dlgBusy||mode!=='scene'||stage==='done'` 时直接返回 false。进入时：`busy=true`、清键与寻路；`OpeningCharacters.modernEvent=!arrival.borrowed`（未换装时用现代装立绘）；`#dlg.style.zIndex='60'`。
`DialogueStage.begin` 初始站位：萧白 `c_hero` 左；`stage!=='encounter'` 时叶蘅 `c_ye` 右（相遇开头萧白独自一人）。

依次：`encounter` → `dog` → `lodging`（每段剧本末尾 `set_flag` 推进 stage 并存档，读档后从当前 stage 的段首重播）。
异常：toast“序章片段未能完成，可以点击“继续序章”重试。”（4000ms），显示按钮 `#prologue-retry`“继续序章”（`position:fixed;left:50%;bottom:12%;transform:translateX(-50%);z-index:65;padding:12px 22px;background:#24271d;color:#f3dfb4;border:1px solid #bfa16b`），点击移除并重跑 `play()`。
finally：清诊所站位、`PrologueBackhill.release()`、`player.alpha=1`、`modernEvent=false`、恢复 dlg zIndex、`busy=false`。

## 3. 后山固定场景 `SC.prologue_backhill`（`prologue-backhill.js`）

- 底图 `m_prologue_backhill_v1`；道具层 `m_prologue_backhill_props`，`propK=0.78125`，`props` 每项 `[atlasX,atlasY,w,h,worldX,worldY,底边y]`，世界尺寸 = 源×propK，按底边 y 与角色一起深度排序（`scene.js` `drawProp`，`imageSmoothingEnabled=false`）。
- 屏幕 `W=960,H=540`，`ZOOM=5/6`，`k=1/ZOOM=1.2`；`TS=40`；`gw=W*k/TS`、`gh=H*k/TS`（即 1152×648 世界像素，整屏一张）。`mapv:1`、`startDir:'r'`、`playerSp:'opening_hero_modern'`、`walk` 全图、无出口。底图未载入时 `under()` 画 `#66755a` 底和 `#b2a080` 梯形路（顶点 (180,H)(410,140)(700,140)(830,H)×k）。
- **固定镜头**：`cam=(0,0)`，`camC=(W*k/2,H*k/2)`；`fixedScene()` 为真时 `setPath` 返回 null、`updateScene` 中冻结玩家（vx/vy=0、walk=0）、画布 pointerdown 被吞；方向键仍用于选项。提示栏 `.hint` 改为“点击对白 / 空格推进 · 点击选项或按数字选择”。
- 站位（屏幕像素，×k 为世界坐标）：`encounter: hero[490,330], ye[620,315]`；`dog: hero[300,262], ye[405,275], dog[610,235], dog2[640,365]`。
- 演员：叶蘅 `c_ye`（相遇朝 l，遇狼朝 r）；狼 `c_backhill_wolf`（`h:52`、朝 l；取 `BART.wolf` 第 0 帧 alpha≥48 的包围盒外扩 2px 裁切，并水平镜像得 `_l`；不可用时退 `c_wolf`）；两只狼 id `pb_wilddog`、`pb_wolf2`。所有 `staticScene:true`（不做待机动画）。
