# 01 主线流程总览（从“从头开始”到“培养模式”）

源：`xiaojianghu-legacy-prologue/js/`（下文路径省略此前缀）。评审脚本与 `review` 参数分支一律不移植。

## 1. 三层状态，按先后接力

| 层 | 存档字段 | 负责文件 | 覆盖区间 |
|---|---|---|---|
| 序章 | `S.prologue`（version 2）| `qihe-map-trial.js` `fresh()`；`prologue-arrival.js` | 后山醒来 → 遇狼 → 进村 → 第一夜过夜 |
| 主线（风起栖河）| `S.qiheChapter`（version 2）| `qihe-chapter.js` `initial()` | 第二天清晨 → 三天 6 个时段 → 起火 → 撤离 → 邻村 → 上山 → 拜师 |
| 培养 | `S.qiheCultivation` 等 | `qihe-cultivation-bridge.js` | `stage==='cultivation'` 之后 |

判定规则：`S.qiheChapter` 不存在 ⇒ 仍在序章/第一夜；存在 ⇒ 按 `stage` 分派。剧本运行时在主线未开始时写 `qiheChapter.*` 标记只记在内存（`story-runtime.js` `isEarly`），不得因此建出 `S.qiheChapter`。

## 2. 总流程（游戏顺序）

1. 标题页 `QiheEntry.render()` → “从头开始” → 新旅程 URL，`qiheTrialStart()`（`qihe-map-trial.js` `start`）。
2. `S.prologue.arrival.stage`：`encounter`（后山相遇+递水 CG）→ `dog`（遇狼战）→ `lodging`（药棚进村第一夜）→ `done`。见 02。
3. 第一夜自由走动：周婶托付“替周婶跑一圈”（可选三件）、叶家收药箱（必做，`relicSeen`）、陈伯客房过夜（`rested`）。见 03。
4. 过夜后在客房榻再交互 → `QiheChapter.begin()` → `fq_morning`，`stage:'opening'→'days'`。见 04。
5. `days`：`halfDay` 0→2→4→5→6，由“主线步骤”确认推进；途中固定事件 `xu-meeting`、`three-meeting`、`packing`；四项可选活动与大量可选内容。见 04–05、07–10。
6. `halfDay>=6` ⇒ `stage:'fire'`：起火、救人、撤离 CG → `escape`：守路战 → `refuge`：邻村、对证 → 商量去处 → `mountain`：上山、安顿、饭局 → `ended` → 拜师 `cultivation`。见 06。
7. `QiheCultivationBridge.enter()` 进入培养模式。见 11。

## 3. 存档与入口（`qihe-startup.js`）

- 原存档键 `original='xjh.qihe-prologue.v2'`；旅程键 `xjh.qihe-prologue.v2.run.<id>`，`id` 匹配 `/^[a-z0-9-]{8,64}$/`；最近旅程指针 `latest='xjh.qihe-prologue.latest.v1'`。
- `read(key)`：JSON 有效且 `s.prologue.version===2`、`SC[s.scene]` 存在、`!s.qiheSave?.archivedAt` 才算有效。
- `runs()`：候选 `[当前URL有journey?当前键:latest指向键, 当前键, original]` 去重后取有效者。
- 新旅程 id：`Date.now().toString(36)+'-'+Math.random().toString(36).slice(2,10)`，与已有键冲突则重生成。URL：`<path>?v=qihe-saves-20261006[&journey=<id>]&play=1#qihe-map`。
- `start()`：URL 带 `play=1` 时，若本键无存档或可读 ⇒ `qiheTrialStart()`；存档存在但不可读 ⇒ 回标题并 toast“这份进度暂时无法读取，原记录已保留。可开始新旅程。”（3200ms）。否则显示标题。
- 标题面板（`openPanel('plain')`，类 `qihe-startup`）：`.logo` “小江湖”；`.qihe-start-version` “栖河试玩 · 四向地图版”；`.qihe-start-note` “从后山初遇，走入栖河与归云谷。”；按钮 `#qh-new-journey.pri` “从头开始”（默认聚焦）；每个有效存档一个按钮：第 0 个“继续进度”，原键“继续原有进度”，其它“继续另一旅程”，`<small>` 为 `QiheMilestones.latest(s)||'初到栖河'` + ` · ` + 场景名；页脚“从头开始保留现有进度 · 新旅程自动保存”。`document.title='小江湖 · 栖河试玩 · 四向地图版'`，HUD 隐藏。
- Godot 对应：用 `user://saves/<key>.json` 映射 localStorage 键；“从头开始”永不覆盖旧档。

## 4. 存档点 `checkpoint`

- 序章：`QihePrologue.checkpoint()` = `S.x=player.x;S.y=player.y;save();hud()`。主线 `savePoint()` 调同一函数。
- 剧本 `~ checkpoint()` 即上述存档。`guarded()` 结束时（finally）总会 `savePoint()` 并 `QiheExpansion.refresh()`。
- 读档：`start()` 若旧档有效，恢复场景与坐标；`arrival.stage!=='done'` ⇒ 续播 `PrologueArrival.play()`（按当前 stage 从段首重播）；`prologue.ending` 为真 ⇒ `rest(true)`（过夜途中续接）；否则 toast“WASD / 方向键移动 · Shift 切换走跑 · E 交谈或进门 · I 江湖 · J 行程”（2600ms）。之后 `QiheChapter.restoreScene()`（见 06 §6）。
