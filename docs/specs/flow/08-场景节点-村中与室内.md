# 08 场景节点表（一）：栖河中央村落与五个室内

源：`qihe-map-trial.js`（建场景与初始节点）、`qihe-expansion.js`（换图、补节点、改 show/act）、`qihe-town.js`、`qihe-aqi.js`、`qihe-lamp-watcher.js`、`qihe-treasure.js`、`qihe-hidden.js`、`qihe-outsiders.js`、`prologue-arrival.js` `bindGreetings`。坐标为世界像素（÷`TS=40` 得格）。

## 0. 包装顺序（决定 act 先后判断）

脚本加载序：map-trial → arrival → expansion → representatives → chapter → outsiders → lamp → town → treasure → aqi → resources → … → bridge → hidden；`bindGreetings` 在 `start()` 运行时最后包。**后包者先判断**，条件不中再落到内层。
- `beforeFire`（expansion）= `!CP || stage∈{opening,days,fire}`；expansion 在加载时把 `qihe_trial`、`prologue_clinic_interior`、`prologue_chen_hall`、`prologue_ye_house` 当时已有的全部节点 show 改为 `beforeFire() && 原show`。town/hidden 等的 `beforeFire` = `!CP || stage∈{opening,days}`（不含 fire）。
- 所有 `X.add` 节点 act 结束都 `checkpoint()+refresh()`。`act(key)` = `QiheChapter.interact(key)`（见 05 §4 与本文 §3）。
- 外来委托分支（outsiders，08 §4 见 10）：名字为 陈伯/药商/周婶/差役 的节点，在有待核对的委托时先问“找我有事？”。

## 3. 室内节点

**药棚 clinic_interior**
- `clinic_interior-out` 药棚前门 · 回村（exit 605,659）→ 村 `clinic` 锚。
- `aunt` 周婶 `c_opening_aunt`（756,443）：act `aunt`（04 §3）；mark `pending().length>0`。外层：问候、药单核对。
- `work` 备药案（859,488）：`qihe_look_work`。
- `daily-ye` 叶蘅 `c_ye`（世界 600,650，朝 l）：show `yeLocation()==='clinic'`（days 且下一主线步骤非 4、非 5）；act `interact('ye')`。

**叶家 ye_house**
- `ye_house-out`（586,664）→ 村 `ye-home`。
- `ye` 叶蘅（805,543）：show `yeLocation()==='house'`（无 chapter，或下一步 to==5）；act：days ⇒ `interact('ye')`，否则 `qihe_relic`；mark `!relicSeen`。
- `night-chen` 陈伯（547,484）、`night-aunt` 周婶（664,520）：show `prologue.ending`；无动作。

**客栈 inn_interior**（town 重建）
- `inn_interior-out`（605,659）→ 村 `inn`。
- `innkeeper` 店家 `c_qh_merchant`（703,238）：无 chapter ⇒ `qihe_errand_cloth`；否则依次：酒钱已了未谢 ⇒ `qh_inn_tab_done`；酒钱可提 ⇒ `qh_inn_tab_offer`；再提一次 ⇒ `qh_inn_tab_again`；风声 ⇒ `qh_inn_rumor`；否则 `interact('innkeeper')` ⇒ `fq_inn`：shop→装备店（05 §7），help→`market` 活动。外层（aqi）：days、h>=2、学会“窃”、未提示 ⇒ 先播 `fq_aqi_hint_name`（一次）。
- `bandit` 帮众 `c_qh_bandit`（400,500）：show 起火前且 h<4。见 12 §3/§4。
- `atan` 新来的/阿炭 `c_qh_atan`（帮众 +46,+6 像素，朝 l）：show beforeFire；12 §3。
- `inn-book` 住客簿（662,310）：CP；`qh_inn_book`。
- `inn-stove` 后厨灶台（902,232）：CP && beforeFire；12 §4。
- `inn-chest` 墙边箱笼（990,470）：CP；12 §4。

**陈伯门厅 chen_hall**
