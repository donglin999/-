# 09 场景节点表（二）：四向外区、邻村、山居与出入口

源：`qihe-expansion.js`（`go/node/add/portal/yeLocation`）、`qihe-town.js`、`qihe-aqi.js`、`qihe-lamp-watcher.js`、`qihe-hidden.js`、`qihe-npc-data.js` `STATIONS`。外区底图 `QIHE_EXPANSION[key].bg`（`m_qh_<key>`），世界 1536×1024，`mapv:2,preciseNav:true,revealPlayer:true,footX:14,arrivalWalk:false,noFollow:true`；有 `props/propImg/propK` 的为模块化地图（道具层深度排序，同 02 §3）。

## 1. 换场 `QiheExpansion.go(key,anchor='entry')`

无 `entry` 锚则用 `start`；锚点未登记抛“未登记入口”。若落点 30px 内有带立绘的可见 NPC，落点 y+45。`goScene`（`fade` 460+60+300ms，`placeName` 2200ms，然后场景 `enter`）→ `cur.dark=null` → 存档。

## 2. 出入口（portal）

成对生成：A 侧标签“前往 · X”，B 侧“返回 · <A 名，central 记作 栖河村>”。

| A(锚) | B(锚) | X |
|---|---|---|
| central(north) | north(south) | 后山采药路 |
| central(south) | south(north) | 南村口 |
| central(west) | west(east) | 西田埂 / 练场 |
| central(east) | east(west) | 栖河东埠 |
| south(east) | east(south) | 沿河装卸路 |
| south(west) | west(south) | 田埂药车道 |

单向：refuge(east)→west(west)“田埂接应路”；refuge(north)“上山道路”（act 改为 `QiheChapter.routes()`）；refuge(south)→west(west)“村后接应小径”；mountain(south)“下山道路”。
portal act：mountain→refuge ⇒ `fq_x_portal_mountain`（不走）；refuge 出非 mountain ⇒ `fq_x_portal_refuge`（不走）；起火后（非 beforeFire）且不在 refuge/mountain ⇒ `QiheChapter.resume()`；否则 `go`。
