# 04 第一夜（进村后 → 过夜 → 交接主线）

源：`qihe-map-trial.js`（`node/wrap/aunt/rest/inviteHome/roundState/questLine`）；`qihe-prologue-actions.js`；`prologue-arrival.js` `bindGreetings`；剧本 `第一夜-*.ink`。此时 `S.qiheChapter` 不存在。

## 1. 节点约定（重要）

`qihe-map-trial.js` `node(scene,id,name,sp,anchor,act,mark)` 的第 7 参是 **mark（头顶“!”）而非 show**；`QiheExpansion.node(...,act,show)` 第 7 参才是 show。节点字段：`{id,name,sp,x,y,dir:'d',fixed:true,idle:false,act,mark,verb:sp?'交谈':'查看 / 进入'}`，坐标 = 锚点世界像素 / `TS(40)`。
`wrap(name,fn)`：`DialogueStage.begin` 站位萧白 `c_hero` 左（name 为叶蘅时加右侧 `c_ye`），结束清键并 `checkpoint()`。
“!” 绘制（`scene.js`）：头顶 `ty-6+sin(t/200)*2` 处半径 10 的圆，填 `#e9a23b`、描边 `#2a1a0a` 2px，中间 `bold 16px serif` 黑色“!”；靠近时改画名字标签。

## 2. 剧本运行器（序章版 `story()`）

`StoryRuntime.play(knot,{line:(id,w,t)=>say(w,t), externals:{checkpoint, toast_for(t,ms), carry(k,n)⇒S.prologue.carry[k]=n, uncarry(k)⇒delete carry[k], go_scene(scene,anchor)⇒goLocal(去掉'prologue_'前缀,anchor)}})`。
`goLocal(scene,key)`：`village`→`qihe_trial`（默认锚 `start`），其它→`prologue_<scene>`（默认 `entry`）；锚点未登记抛“未登记的序章门口”；`goScene` 后存档。

## 3. 替周婶跑一圈（可选，一次接三件）

状态 `S.prologue.errands.{bowls,cloth,medicine}` ∈ `none|accepted|collected|delivered|done|closed`。
- **接取** `qihe_errand_aunt`（药棚周婶 act=`aunt`）：已过夜 ⇒ 一句结束；`round_ready()`（bowls done 且 cloth∈{collected,done} 且 medicine∈{delivered,done}）⇒ `hand_in`；三件全 done ⇒ 一句结束；三件全 none ⇒ `offer`：“三样都交给我，我跑一趟。”⇒ 三键置 `accepted`、`carry(bowls,2)`、`carry(medicine,1)`、存档、toast“已接：替周婶跑一圈”1600ms；“我先四处转转。”⇒结束；否则 `aunt_catch_up`（把仍 none 的补成 accepted）。
- **交差** `hand_in`：cloth、medicine 置 `done`，`uncarry(cloth)`、`uncarry(basket)`，`prologue.errandGift=true`，toast“替周婶跑一圈 · 办完了”1400ms。JS 随后：`errandGift && !errandGiftPaid` ⇒ `errandGiftPaid=true`、`giveItem('pill',1)`（金创药）。若听过任一闲话，周婶多问一句（P-S0-ret-03/04）。
- **还碗** `qihe_errand_chen`（陈伯家门厅陈伯；mark `bowls==='accepted'`）：非 accepted ⇒ 一句结束；选“站在门边听一会儿”⇒ `heard.skill=true` ⇒ `received`；“先把碗送进去”⇒ `received_leave`；两者都：bowls `done`、`uncarry(bowls)`、存档、toast“碗送到了”1300ms。
- **取布** `qihe_errand_cloth`（客栈店家 [703,238]；mark `cloth==='accepted'`）：“在门口听一会儿”⇒ `heard.box=true`；“上前找掌柜取布”；之后 cloth `collected`、`carry(cloth,1)`、toast“拿到布包”1500ms。
- **送药** `qihe_errand_elder`（村口老人，位置 `elder-home`+(45,0)；mark `medicine==='accepted'`）：“在一旁听一会儿”⇒ `heard.inspection=true`；`deliver`：medicine `delivered`、`uncarry(medicine)`、`carry(basket,1)`、toast“带回竹篮”1500ms。
- 任务面板 `mnQuests()`：一条 `{t:'替周婶跑一圈',giver:'周婶',d:roundText()}`；`roundState()`：全 none→`none`；全 done→`done`；全∈{done,closed,none}→含 done 则 `partial` 否则 `closed`；满足交差条件→`return`；其余 `taken`。`done/partial/closed` 计为完成，`closed` 另标。`roundText()` 逐步写“第一步 陈伯家还碗（已办/没办，已收尾/未办）；第二步 客栈取布…；第三步 村南老人家送药、带回竹篮…”+结尾句。

## 4. 叶家收药箱（必做）

- 村中 `ye-door`“叶家 · 应邀帮忙收药箱”（锚 `ye-home` 523,550；mark `!relicSeen`）→ `qihe_ye_invite`：已过夜 ⇒ 一句结束；`!yeHousePermission` ⇒（未问候过叶蘅先播 `greet_ye_lines` 并记 `greeted.叶蘅`）“好，我来。”⇒ `yeHousePermission=true` 存档 ⇒ `go_scene(prologue_ye_house,entry)`；“我晚点再来。”结束。已允许则直接进门。
- 叶家内 `ye`（锚 `relic` 805,543；mark `!relicSeen`）→ `qihe_relic`：已收 ⇒ 一句；选“你父亲也是大夫？”/“我帮你把东西收好。”（问父亲且 `heard.skill` 时台词不同）→ `relicSeen=true`、存档、toast“药箱已经收好 · 可以继续小事，或收拾歇息”1800ms。

## 5. 首次搭话问候（`bindGreetings`）

在 `start()` 时，给所有 `prologue_*` 场景中名为 周婶/陈伯/叶蘅 的节点外包一层：`arrival.stage==='done' && !greeted[name] && !legacy && !bypassed` ⇒ 先播 `qihe_greet_aunt / qihe_greet_chen / qihe_greet_ye`（剧本内记 `prologue.arrival.greeted.<名>=true` 并存档），再执行原 act。

## 6. 过夜 `qihe_first_night`（陈伯客房榻 `rest`，锚 555,372；mark `relicSeen && !rested`）

act：有 `S.qiheChapter` ⇒ `QiheChapter.rest()`，否则 `QihePrologue.rest()`：已 `rested` ⇒ `QiheChapter.begin()`（**第二天由此开始**，见 05）；否则播剧本，VAR `resuming`。
1. `rested` ⇒“【第一夜 · 完。进度已保存。】”；`!relicSeen` ⇒ 心里话提示先去叶家，结束。
2. `resuming` ⇒ 直接跳 `first_night_hall`。
3. 有未办（accepted/collected/delivered）⇒ 列出“碗还没送/布还没取/布还没交给周婶/药还没送/竹篮还没还”；选“躺下睡觉。”⇒ `ending=true` 存档；“再出去转转。”结束。
4. `first_night_hall`：陈伯叫人 → `go_scene(prologue_ye_house,entry)`（此时显示 `night-chen` 陈伯[700,620]、`night-aunt` 周婶[850,665]，×0.78125，show=`ending`）→ 门缝字条 → 按 `heard.skill/box/inspection` 逐条可问（菜单项可多选，问完三条走 `all_three`）→ `wrap_up`（未办完的由陈伯/周婶收尾的台词）。
5. `first_night_guest`：`go_scene(prologue_chen_guest,entry)` → 按 `originExpression` B/C/其它 一句心里话 → `night_falls()`（`fade` 内 `cur.dark='rgba(13,22,32,.32)'`）→ 三件未 done 者置 `closed` → `rested=true`、`ending=false` → `hand_off_first_night()`：`carry={}`，`handoff={chapter:'风起栖河',origin:originExpression,heard:{...heard},noteOwner:'叶蘅',relicOwner:'叶蘅',lodging:'陈伯独立客房'}` → 存档 →“【江湖经历记下一笔：栖河第一夜。进度已保存。】”。
- 自定义 `go_scene`：换场后 `busy=true`（防止玩家在剧情中走动）。读档时若 `ending` 为真，`start()` 自动 `rest(true)`，出错 toast“过夜片段未完成，回客房可继续。”。

## 7. 行程文字 `questLine()`（无 chapter 时）

`rested`→“回陈伯家客房歇息，第二天在村里走访”；`arrival.stage!=='done'`→“与叶蘅一起下山，到村里歇脚”；`ending`→“与叶蘅道别，回陈伯客房过夜”；`!relicSeen`→“去西北叶家帮忙收药箱 · ”+（none“替周婶跑一圈（可不做）”｜return“…：回药棚交差”｜有未办“…：”+未办列表｜否则“…已办完”）；`return`→“回药棚找周婶交差，或回陈伯独立客房歇息”；有未办→“替周婶跑一圈：…· 也可回陈伯客房歇息”；否则“回东北陈伯家，经门厅东侧进客房歇息”。
`questLog()`：未过夜时首行 `{t:'眼下',d:questLine()}`，其后为里程碑（group“江湖经历”）。

## 8. 行程菜单 J（序章版 `journal()`）

仅 `mode==='scene'` 且不忙。`choose('行程', questLine()+任务行, ['继续游玩','保存进度','从头重新开始'])`；保存 ⇒ toast“进度已保存”1200ms；重开需二次确认 `['保留进度','重新开始']`，确认后删除本键存档并 `start(true)`。有 chapter 或 `QiheOutsiders.available()` 时改开 `QiheJianghuUI.open('quest')`。
