## 4. 外来委托（`S.prologue.outsiders.quests`）

`available()` = 序章 `arrival.stage==='done'` && `!prologue.ending` && (无 CP 或 stage∈{opening,days})。
`questOpen(k)` = CP 存在且 `opens[k] <= halfDay < deadlines[k]`：`opens={letter:2,account:4,ledger:4}`，`deadlines={letter:4,account:6,ledger:6}`；时限标签 `{4:'第二天傍晚前',6:'第三天傍晚前'}`。

| 键 | 名称 | 委托人 | 核对人 | 路费 | 记 heard |
|---|---|---|---|---|---|
| letter | 一封未落款的拜帖 | 徐令仪 | 陈伯 | 6 文 | skill |
| account | 旧罐与玉匣 | 岑霜 | 药商 | 8 文 | box |
| ledger | 药单上的两道数 | 沈雁回 | 周婶 → 差役 | 6 文 | inspection |

状态 `stage`：`none → accepted → checked →（仅 ledger）witnessed → done`；另 `choice`、`rewarded`、`evidence`（摘要文本）。

`owner(k)`（找委托人）：
1. done ⇒ `qihe_errand_<k>_done`；未开放 ⇒ 无反应。
2. ledger 且 checked ⇒ 先 `check(k,'差役',true)`（委托人当场请差役见证）。
3. none ⇒ `_offer`（“行，我去。”⇒ `errand_accept()`：`stage='accepted'`）→ toast“已接：<名>”1600ms。
4. 未到可交状态（letter/account 需 checked，ledger 需 witnessed）⇒ `_wait`（ledger 带 VAR `checked`）。
5. `_turnin`：`errand_choice(n)`（拜帖：0“话我带到了，别的我不掺和。”/1“这帖子，您还是收回去吧。”）→ `choice=n`、`stage='done'`、首次 `S.silver+=reward`、`rewarded=true` → toast“<名> · 已完成 · 路费 N 文”2000ms。

`check(k,role)`：差役：需 checked ⇒ `_witness`（VAR `from_owner`）→ `witnessed`、`heard.inspection=true`；其他核对人：需 accepted ⇒ `_check` → `checked`，非 ledger 记 `heard[flag]=true`。写 `evidence`（ledger checked 时为“周婶说一篓是病人药包，且无人查验；还需向差役核实签字。”，否则为该委托 summary），toast“行程已更新：<名>”1500ms。

核对人入口：加载时包装所有名为 陈伯/药商/周婶/差役 的节点：`available()` 且有待核对（`questOpen` 且 stage 为 accepted；差役为 checked）⇒ `ask(名,'找我有事？',[每项“我来问问「名」的事。”,'“没别的，就来看看。”','“打扰了。”'])`：选委托项 ⇒ `check`；“没别的”⇒ 原 act；“打扰了”⇒ 结束。

任务面板追加（`mnQuests`）：stage≠none 的委托，`closed` = 未 done 且（已离村或过时限），文字分别为 summary / “随撤离中止；已知线索保留，不影响主线。” / “过了时限没办成；已知线索保留，不影响主线。” / `steps[stage]+'（时限：…）'`；`where` 与追踪目标 `chapterNpc`：accepted 时 letter→`chen-door`、account→`merchant`、ledger→`clinic-door`，否则委托人 id。
“三方对接”记录（`contactRecords`）：已登场者各一条，标题 `正道盟/归烬堂/巡江司对接 · 名`，地点：徐令仪“南村口 · 联络院门前”，沈雁回“东埠 · 采办核货点”，岑霜 h>=4“东埠 · 装卸路”否则“南村口 · 车道旁”。
