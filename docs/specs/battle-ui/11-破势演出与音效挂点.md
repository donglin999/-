# 11 破势（bposhi）演出 + 盾碎/闪屏 + 音效挂点 + 配音开关

源：`js/bposhi.js`（`window.POSHI={banner,seal,draw}`，并设 `BUI.breakBanner=POSHI.banner`）；`js/bfx.js` `doBreak / shieldShatter / breakBanner(回退) / drawBreakFlash`；`js/vfx.js` `brk`；`js/audio.js` `sfx`；`js/battle-voice.js`。

## 1. 触发链 `doBreak(t)`（护盾被弱点打到 0）
同一时刻：`VFX.brk(t)`（冰色冲击环+40 碎片，闪白 .12 `#e0f4ff`，顿帧 100，见 08）；状态 broken=true，brokenUntil=round+1，清蓄力与意图；`t.breakT=performance.now()`；`B.shake=14`；sfx `whoosh` 1/.6；`POSHI.banner(t)`；26 颗碎片粒子（B.parts：速度 2–7 向四周、vy-2，重力 .25，大小 3–9，旋转，寿命 40–70 帧，色 `#bfe6ff`/`#ffe7a0` 各半，画成 3px 像素块带暗边 `rgba(10,16,30,.8)`）；`t._brkFx=BT.now()`；`BT.stop(250)` 顿帧；`CAM.punch(1.12,320)`。

## 2. `drawBreakFlash`（每帧，世界坐标内）
- 屏幕闪：breakT 后 300ms（真实时间）全屏 `rgba(255,244,214, .22*(1-e/300))`。
- 盾碎 `shieldShatter`（BT 时间，0–760ms）：11×11 盾形位图（行：`01111111110`,`11111111111`×5,`01111111110`,`00111111100`,`00011111000`,`00001110000`,`00000100000`），每格 4px，中心 (u.x+ox, u.y+oy-unitH*.62)。颜色：e<50 全白；边缘 `#bfe6ff`；左上(r<4,c<5) `#7ab8e8`；其余 `#3a78b0`；e≥40 裂纹格 [(5,0),(5,1),(4,2),(5,3),(6,4),(5,5),(4,6),(5,7),(5,8)]（列,行）为 `#0a1a2a`。e<90 缩放 1+.25(1-e/90)。e≥110 左右两半飞散：x+=方向×(.1+.06×(r%3))×k，y+=方向y×.05k-.12k+.00045k²，alpha 在 k=260–480 淡出。每格先画 1px 暗边 `#08101c`。
- 无 POSHI 时的回退横幅（正式版有 POSHI，不触发）：墨色斜带宽 220×grow，高 48，红边 `#b8231c`，44px “破势”。
- 最后调用 `POSHI.draw()`。

## 3. POSHI 局部破势提示（真实时间 performance.now）
常量：`DUR=1150, T_POP=40, T_SET=130, T_SEAL=190, T_OUT=880`；像素尺度 Q=1.5（所有点吸附到 1.5px 网格）。
- `banner(u)`：记录 `u._psT=t+DUR-120`（头顶小印出现时刻），同一单位只保留最新一份；sfx `whoosh` .8/1.4。
- 尺寸：size=clamp(h*.34,54,96)（h=unitH）；中心 cx=u.x+ox；cy=max(78+size/2, 头顶+h*.42)。
- 淡出：e≥880 后 4 档阶梯 fo=ceil((1-(e-880)/270)*4)/4。
- e≥40 首次：`B.shake=max(,5)`，sfx `advance` .9/.5。
- 0–240ms 刀光：长 L=max(90,size*1.6)，角度 -.42rad，从 (cx-dx·L, cy+6-dy·L) 出发；头 head=easeOutCubic(e/100)×2L，尾 e≥100 后 (e-100)/140×2L；每 1.5px 一截，半宽 w=max(1,round(2sin(π·min(1,f*1.05))))，中心 `#fff4c8`、最外 `#ffb448`。
- 40ms 起“破”字：素材 `fx_poshi_po`，加 1px 描边 `#d9ccae`；按 art=round(size/1.5) 美术像素宽平滑缩小后 alpha 二值化（<110→0，否则 255）。缩放 40–130ms 1.5→1（easeInCubic），之后 70ms 回弹 1+.07sin；位置 x=cx-w/2-size*.12。先画投影偏 1.5px，再画本体；前 70ms lighter 叠两次闪白递减。6 粒墨点（`#1a0e08`，第 2 粒 `#b0241a`）150ms 内向外 d=size*(.45~.8)，x 方向×1.2，y×.7；fo<.5 时只留偶数粒。
- 190ms 起朱印“势”：素材 `fx_poshi_seal` + 1px 描边 `#1a0806`，art=round(size*.5/1.5)；70ms 内 1.4→1，alpha .6→1；中心 (cx+size*.3, cy+size*.32)。
- 头顶小印 `drawSeals`：破势存活敌人在 t≥_psT 后，`seal(24)`（素材 `fx_poshi_seal_s`，缺失则程序画：外框 `#8a1a14`、内 `#c4261c`、白字“破” bold 72%），110ms 内 1.6→1 alpha .6→1；位置 (x, max(76, 头顶-22)+上下跳 2px/400ms)，带 2px 投影 `rgba(8,4,2,.55)`。
- `seal(size)` 还供行动顺序条菱形与脚标使用。
- 回退：无“破”素材则 112px FONT 画字（`#141010`，描边 PAPER `#ece2c8`）；无印素材 40×40 `#c4261c`+“势”。
- 素材：`assets/production/shared/fx_poshi_po.webp`、`fx_poshi_band.webp`、`fx_poshi_seal.webp`、`fx_poshi_seal_s.webp`、`fx_poshi_ink.webp`（band/ink 当前版本未在绘制中使用，仅派生缓存）。
