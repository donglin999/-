# 01 总览：战斗表现与界面移植规格

适用对象：《小江湖》栖河试玩版（`xiaojianghu-legacy-prologue`，入口 `index.html`，8792 端口）的 Godot 4 一比一重做。
本册范围：战斗 UI（DOM/CSS 与画布 UI）、特效系统、招式时间轴、战斗精灵、破势、门派特效与领队交锋、音效挂点。**不含**伤害结算规则本身（`js/battle.js` 归规则册）。
排除：文件名带 `review` 的脚本，以及 URL 参数里的 review 开关。这些只给评审页用，正式游戏不加载。

## 2. 分层与加载顺序（来自 index.html 的 script 顺序）
`battle.js`（规则与基础绘制）→ `vfx.js`（像素特效层 VFX）→ `bart.js`（战斗精灵 BART）→ `bstage.js` → `bui.js`（覆盖 UI）→ `battle-auto.js` → `bfx.js`（覆盖演出）→ `bposhi.js`（破势）→ … → `qihe-battle-art.js`、`qihe-chapter-battle-art.js`（栖河精灵与背景登记）→ … → `faction-fx/wuxia-fx.js`、`fx-am.js`、`fx-gj.js`、`fx-qihe-clash-v2.js` → `qihe-faction-clash-data.js`、`-rules.js`、`-art.js`、`qihe-faction-clash.js` → … → `qihe-acc-fx.js` → `voice.js`、`audio.js`、`battle-voice.js`。

**覆盖规则**：这些都是全局脚本。同名函数以后加载的为准，例如 `bui.js`、`bfx.js` 会重新定义 `battle.js` 里的绘制和菜单函数。移植时只实现最终生效的版本，即各节标注的“生效版本”。
- 主题只用 ink（水墨），布局只用 v4。scroll 主题仅作备用，要点见 04。
- `qihe-acc-fx.js` 不是视觉特效：功能类佩饰改的是买价、银两、掉落、战后回复和保命，不改表现，交给规则册处理。
- `battle-voice.js` 已关闭（`js/voice.js` 中 `ENABLED=false`），只需保留开关，见 11。

## 3. 全局坐标与尺度
- 战斗画布逻辑尺寸 **960×540**（`W=960,H=540`），地面线 `GROUND=470`；DOM UI 叠在同一 960×540 舞台上，整体按 `ui-scale.js` 缩放。
- 像素特效层：640×360，比例 `Q=1.5`（舞台坐标 ÷1.5 得到特效像素），见 07。
- 门派特效：640×360 加 overlay 留白 200/120，见 12；交锋层坐标映射见 13.3。
- 时间以毫秒计，统一走战斗时钟 `BT.now()`。顿帧和慢放靠它实现，详见 07。

## 4. 字体
- `Ma Shan Zheng`：招式横幅、胜/败大字等毛笔大字。
- `Zhi Mang Xing`：印章、行书点缀。
- `Liu Jian Mao Cao`：草书大字（单处）。
- `Noto Serif SC`：正文、菜单、数值的兜底衬线字。
Godot 中建议把这四种字体放进 `FontVariation`，并保留回退链 `Noto Serif SC → serif`。

## 5. Godot 落地建议
- 画布 UI（05、06）和特效（07、08、12）用 `_draw()` 加 SubViewport 实现：640×360 像素层关闭过滤，整数放大。
- DOM 面板（03、04、06 结算页）用 Control 加 StyleBox 复现，CSS 的数值照抄。
- 所有时间轴都用 `win(t,a,b)` 线性窗口配合缓动函数（定义见 12.3），一律以毫秒驱动，不要用 Tween 近似。
