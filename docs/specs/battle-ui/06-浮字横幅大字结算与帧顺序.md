# 06 伤害数字/浮字、招式横幅、胜败大字、胜利结算、帧绘制顺序

源：`js/bui.js` → `floatTxt / bpop / bigText / showName / drawFloats / drawBanner / drawBig / victory`；`js/battle.js` → `drawBattle / shakeStep`；`js/core.js` → `vignette`。

## 1. 每帧绘制顺序 `drawBattle(t)`（battle.js）
1. `CAM.update(now)`；`g.save(); CAM.apply(); shakeStep(now)`（相机+震屏，见 07）
2. `drawBattleBg()` 背景（bstage.js）

4. 单位：bfx `drawAll()` 一次画全部（按站位 y+位移 y 升序）
5. `VFX.draw(now)` 特效像素层（含 overlay：蓄势光柱等）
6. `drawParts(now)` 旧粒子（破势碎片、治疗光点）
7. `drawStageFront(now)` 前景（雾/尘），bstage
8. 每个单位 `ghostTick`；存活者 `drawUnitUI`（脚标/意图/箭头）
9. `drawFloats(now)` 浮字
10. `drawBreakFlash(now)` 破势闪屏/盾碎/POSHI.draw
11. `g.restore()`（以下无相机）

14. `drawOrderBar`、`drawBanner`、`drawBig`
15. 鼠标悬停切换目标（非全体时）

## 2. 浮字数据 `B.fx[]`
`floatTxt(u,t,c,size=26,slow)`：x=u.x+rand(-14,14)；y=u.y-unitH(u)*0.7-（该单位 300ms 内已有浮字数×22，向上堆叠）；life=slow?1500:1000。
`bpop(u,t,c,big)`：文本含“破势/破防/BREAK”→转 `BUI.breakBanner(u)`（=POSHI.banner，见 11）；否则 y=u.y-unitH*(big?.5:1.12)，size=big?38:22，life=big?1300:800，pop=1，含 WEAK→kind='weak'。

### `drawFloats` 四种渲染（k=经过/life，e=经过毫秒，fade=k>.72?(1-k)/.28:1）
- **弱点**（kind weak）：y=f.y-min(3k,1)*16；缩放 e<90 时 1.35→1；文字 `text('弱点','#ffe25a',30,{edge:'#5a1606'})`；e<260 画扩散圆环 半径 16+e/7，`rgba(255,226,90,.55*(1-e/260))` 线宽 2。
- **蓄势**（文本 `蓄势 ◆◆`）：y=f.y-k*30；`text('蓄势','#ffcf73',size)` 后接 n 枚 `coin('use',18)`，间距 2px，整体居中。
- **数字**（/^\+?\d+$/）：size≥34 为大号（字号 44）否则 34，字体 FB。y 偏移按 50ms 一档查表 `BO=[0,-12,-20,-24,-22,-20]`（前 300ms 弹跳），之后 `-20-(e-300)*.025` 缓升。缩放 e<70 为 1.3 否则 1。e<90 内每 30ms 交替显示纯白版本（白闪 3 次）。颜色：受伤数字由调用方给（敌方打我 `#ff9c80`；我方打敌见 battle.js `strike` 的 col），治疗 `'+N'` `#7fe0a0` 28。
- **普通文字**：y=f.y-k*30；pop 时 y=f.y-min(3k,1)*16，缩放 k<.15: .6→1.2，之后 1.2-min(.2,k-.15)；字号 round(size*1.05)，默认色 `#f3e6c8`。
常见调用：防御`#9fd4ee`22；闪`#bcd`24；眩晕`#e0c0ff`18/20；蓄力！`#ffe25a`24；定神 · 攻防提升`#ffe7a0`20；内力+N `#8cf`22；护身 · 减伤15% `#d8e6b3`18。

## 3. 招式名横幅 `drawBanner`（`showName(u,名)` 触发，`B.banner={t,side,t0}`）
- 时长 1100ms（k=e/1100）。缓存画布宽 = 文字宽(26px FB)+140（ink）/+96（scroll），高 48。
- ink：底 swash(w,40,{seed:(len*13)%50+3,halo:敌?'#e07050':'#d8c49a',haloA:.38,col:敌?'#2e0806':'#0d0806',a:.92,dry:.42,head:.05,tail:.3,thick:.86}) 画在 y=4；文字右侧 10px 处朱印 `seal(敌?'煞':'招',20,20)`，y=14；文字色 我`#f6dca0` 敌`#ffb49a`，26px，竖直中心 24。
- 展开：grow=min(1,k/.08)（88ms 从中心横向展开，按源中心裁剪）；淡出 k>.82 时 a=(1-k)/.18。屏幕位置：水平居中，y=78。
- 文本：攻击时 `atkName` + 连击 `×n`；武学为技能名；敌方为技能名。

## 4. 胜/败/脱身大字 `drawBig`（`bigText(t,c,ms)` 设置并 await ms）
- 可见到 k=1.4（即 ms×1.4）；a=min(1,5k)×(k>1 ? (1.4-k)/.4 : 1)。
- 满宽墨带：swash(960,170,{seed:33,halo:'#d8c49a',haloA:.3,a:.86,dry:.5,head:.03,tail:.28,thick:.8,wave:.05})，中心 y=270，从左向右展开 gw=min(1,e/180)。
- 大字：字体 FC（Zhi Mang Xing），单字 136px / 多字 112px，色 mix(c,'#fff4e0',.25)，边 `#0d0604`；缩放 e<90:1.6，<150:1.18，<200:.96，之后 1（砸入）。e<120 叠白字 alpha 1-e/120。
- e>260 后朱印 `seal('小江湖',26,70)`：位置 (480+字宽/2+14, 274)，旋转 .06rad，ss=min(1,(e-260)/140)，缩放 1.7→1，alpha=ss。
- 胜：`bigText('胜','#f3d58e',900)`，前置 sfx `chime`；若有胜利姿势先 `BFX.victoryPose()`（全员 cast/win，相机 camOn(全员,1.2,450ms)，成员间隔 90ms，总 900ms）。

## 5. 胜利结算 `#bt-win`（victory）
- 容器：居中，宽 372px，padding 16px 30px 14px，文本居中，色 `#2a1a0e`，背景宣纸 paper(360,320,{seed:13}) 拉伸，阴影 `0 12px 30px rgba(0,0,0,.65)`；上下木轴 `rod(392,16)`：left/right -16px，高 16，top/bottom -8px，阴影 drop-shadow(0 3px 3px rgba(0,0,0,.6))。
- 展开动画 `unrollw .45s ease-out`：clip-path 从 `inset(calc(50% - 8px) -20px calc(50% - 8px) -20px)` 到 `inset(-10px -20px -10px -20px)`（从中线向上下展开）。
- 标题 `.wt` 高 92：`h2` “胜” FC 92px/92px `#140a05`；朱印 `seal('大捷',30,30)` 绝对定位 right 62 top 14 旋转 6°，动画 `stamp .35s` 延迟 .35s，`cubic-bezier(.3,1.6,.5,1)`，从 scale1.8/透明到 1。
- 行 `.ln`：flex gap 8，padding 5px 4px，底部 1px 渐隐分隔线 `rgba(60,36,18,.45)`（10%–90%）。左字徽 blot 22px；`span` FB 18px `#3a2412` letter-spacing .15em；`b` FB 19px `#1a0f08` 右对齐。
  1. blot('修','#6ccf8a') 修为 · 历练领悟：满级“已满级”，否则 `+N`
  2. blot('钱','#c8d0dc') 铜钱：`+N 文`
  3. blot('物','#d9b36c') 战利品：每项 `buiItem(k,24)+名×n`（13px 衬线），无则“—”
  4. 每名同伴：`名 修为 +N（· 共同研习）`
  5. 每次升层：`.lv` “境界突破 · 第 L 层” + small “属性点 +3”；margin 8px -12px 0，padding 6px 0，FB 20px `#fff0d8`，letter-spacing .2em，背景 swash(320,34,{seed:66,col:'#9a2216',a:.9,dry:.4,head:.05,tail:.3,thick:.86})；small 衬线 12px `#ffe0c0`。
- `.go` “点击或按 Enter 继续”：12px `#6a5236`，`wkp .7s alternate` 闪烁。
- 数字滚动：`.cnt` 500ms 线性 0→目标。出现 350ms 后才接受输入：Enter/空格/Z/Esc 或点击 → sfx `select`，移除。
- 数值：exp=Σ敌 exp（教学战×0.5）；银两 Σsilver（经 `QiheAccFx.silver`）；掉落概率经 `QiheAccFx.drop(p)`；有银两播 `coin`。
