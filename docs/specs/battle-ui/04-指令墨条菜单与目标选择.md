## 4. 菜单内容与逻辑
主菜单（标题 `第 ${B.round} 回合`）：
1. 攻击 val=atk，字徽=武器类型 `u.atkType`，右侧 `u.atkName`，说明 `以{atkName}出手（类型）· 蓄势可连击 {1+bpUse} 次`。
2. 武学 sk，字徽“武”，无武学则 dis，说明“施展武学，消耗内力”。
3. 道具 it，字徽“药”，背包无 heal/mp 道具则 dis。
4. 防御 def，字徽“守”，“本回合受伤减半，下回合率先行动”；执行：`u.defend=u.prio=true; floatTxt(u,'防御','#9fd4ee',22); wait 450ms`。
5. 逃跑 run（非 boss/教学/noFlee 才有），字徽“走”。成功率 `clamp(55+(我方平均spd-敌方平均spd)*6,20,90)`；成功 sfx `whoosh`；失败 `floatTxt('逃跑失败','#aaa',22)` + 600ms。
武学子菜单：字徽=BSK[k].t（无则治疗/增益“医”，否则“内”）+可选元素字徽 BSK[k].e；右侧消耗 `<mpc>cost</mpc>内`；不足→why“内力不足”且 dis；需特定兵刃→why“需装备X”。
道具子菜单：图标 `buiItem(k,22)`，右侧 `×n`；无蓄势栏。道具使用：`lunge(u,x,.3)`，治疗走 `heal()`，回内 `floatTxt('内力+N','#8cf',22)`，500ms。
- 初始选中：第一个非 dis 行（教学战为 0）。上下循环跳过 dis；悬停即选中；点击=确认；dis 行确认播 `menu_close` 音量 .5。
- 蓄势：`setBp(d)` 范围 0..min(3,u.bp)，变化时 sfx `select` 音量 .6、音高 1+n*.15。点第 i 枚铜钱=投入 bp-i（再点同档归零）。
- 音效：移动 `blip` .6；确认 `select`；返回 `menu_close` .6。
- 提交 `done()`：隐藏菜单、清 key/click/tgtList/pv、hint 清空；`u.bp-=use; u.boosted=true`。

## 5. 菜单定位（v4 最终）
每帧（rAF + MutationObserver）计算三个候选，取得分最低（同分偏右）：
- 右：`(u.x+uh*.26+8, u.y-uh*.95)`；左：`(u.x-uh*.26-8-w, 同)`；上：`(u.x-w/2, u.y-uh-h-8)`；均 clamp 到 x∈[8,952-w]、y∈[70,532-h]。
- 得分 = 序号×50 + Σ与其他存活单位身体框（宽 vh*.5、高 vh）重叠面积×(我方3/敌方1) + 与 `#bt-cards` 重叠×2 + 与自己身体框重叠×4。uh=unitH(u)。

## 6. 目标选择 `target(side,all,back,go,desc)`
- 列表=该阵营存活单位；敌方默认第 0 个，我方默认自己。左/上 前一个，右/下 后一个（全体时不切换）；ok 确认；back 返回上一菜单；Q/E 仍可调蓄势。
- 点击画布单位 `unitAt`：点已选中/全体→确认，否则切换；鼠标悬停也切换选中。我方也可点卡片。
- 选中敌方：脚下展开弱点/血条，头顶出箭头（见 05）；选中我方：卡片 `.tgt`。

## 7. 说明条 `#bt-hint`
- 位置 `left:50%; top:82px; translateX(-50%)`，14px/24px，nowrap，letter-spacing .06em，flex gap 4px。ink：padding 5px 34px，色 `#f0e2c4`，背景 `--swhint`=swash(420,34,{seed:52,halo:'#d8c49a',haloA:.3,a:.88,dry:.42,head:.05,tail:.22,thick:.9,wave:.05}) 拉伸。`.pv #fff3e0`、`.dm #a8987c 12px`、`.hl #f3d58e`、`.wk #ffe25a` 闪烁 `wkp .35s alternate`（opacity .45↔1）。
- 菜单中显示当前行 desc。目标选择时：`<hl FB 17px>{招式名}</hl>·{目标名 + 弱点字徽18px(未知为?)}·预计 {min}~{max} ×{hits} 弱点！· 蓄势 n`；辅助技能显示“· 辅助 · 不造成伤害”。
