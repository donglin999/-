# 08 招式特效时间轴（攻击/武学/敌方行动 + 各招式 VFX）

源：`js/bfx.js` 下半（`doAttack / playAttackPose / doSkill / foeAct / boostFx / hurt / heal / doBreak`），`js/vfx.js`（`hitFx / SK / sigil / hit / touch / needleStreak / needleFlight / needleImpact / cast / brk`）。时间均为 BT 毫秒（顿帧顺延）；“k”为实例进度 0..1，几何以层像素计（×1.5 为屏幕像素），Z=2。

## 1. 我方普攻 `doAttack(u,t,bp)`
1. bp>0：`boostFx(u,bp)`：浮字“蓄势 ◆×bp” `#ffcf73`22；sfx `chime` 音量.6 音高 1+bp*.1；`u._boT,_boL=min(3,bp)` 触发蓄势光柱（09 节）；act cast；bp≥3 震屏4 + `cam.punch(1.04,220)`；等待 380+min(3,bp)*70 ms。
2. `showName(u, atkName+' ×hits')`（hits=1+bp）；`camOn([u,t],1.18)`（260ms）。
3. 近战：`dashTo(u,t)`（10 节）；远程（动作表有 projectile）：act dash + 前踏 18px（170ms）。
4. 每击 h：动作 h==0?'atk':'atk2'，`playAttackPose`：
   - 远程：等 releaseMs → sfx `needle_release_20261012` .45 → 每个目标 `VFX.needleFlight`（手部点→目标中心，亮线长 7 层像素 `#bfe6ef` .9 + 白头）→ 等 flightMs → 结算 + `needleImpact`（环 1+5k，粒子 key?7:4，震 key?2:1，顿帧 key?35:20）→ 等 recovery。
   - 近战：按动作表 contacts 逐个接触点：先 `aimReach` 在 lead(≤120ms) 内贴近；到点时 resolve 接触=`strike`+`VFX.hit`；非结算接触（轻触）：目标 act hurt、击退 firm?14:6、轻白 `_tapT` 力度 firm?.85:.45，`VFX.touch`，sfx `staff_hit_20261010` firm?1.05:.65 音高 firm?1:1.15，firm 再 `punch(1.045,130)`；多接触时结算接触 `punch(1.035,150)`。末尾等 recovery（fallback：多击 150 / 单击 230）。
5. `camReset()`（380ms）；近战 `hopBack`（300ms，抛物线高 30，io 缓动），远程 stepBack（220ms）；再 wait 120。

## 2. 结算命中 `strike` → `hurt`（受击表现）
- 弱点命中：`bpop(t,'WEAK','#ffe25a')`（“弱点”浮字），护盾-1，`shieldHit` 计时；归零 → `doBreak`。
- 伤害数字色：暴击 `#ffd24a`（大号 34），破势中 `#ff6a4a`，普通 `#fff3e0`（28）。
- `hurt`：`t.flash/ghT`=now（卡片抖动、残血起算）；act hurt；击退 `kbT`（针击 6px，其余 12px；曲线 0–40ms 快出，40–260ms io 回）；`_flT` 白闪（0–70ms 纯白，120–190ms 白 .7）；震屏 针击 big?3:2 / 其余 big?5:2；sfx=impact 名（`advance` / `staff_hit_20261010` / `needle_hit_20261012`），音量 针.65 其余.9，音高 针1 其余 .7–.9 随机。
- `heal`：浮字 `+n` `#7fe0a0`28；`_hlT` 绿白 `#b0ffc8` 320ms 0.35→0；10 颗发光粒子 `#9ff0b0`（B.parts，vy -.6~-1.6，life 30–50 帧）；sfx `chime` .5。

## 3. 我方武学 `doSkill(u,k,tgs,bp)`
1. `beginSkillPose`（原地，act cast hold）；扣内力；bp>0 → boostFx；`showName(技能名)`。
2. `camOn([u,...tgs], 多目标?1.08:1.12)`；`await VFX.cast`：先 `sigil`（辅助类 T≥1 脚下法阵，jingxin 除外），再 SK[k].cast 返回的前摇 ms。
3. 治疗：每目标 heal(mhp×比例)，等 280，结束。增益（定神）：`buffs.ding`=2+bp 回合，浮字“定神 · 攻防提升”，等 280。
4. 伤害：等 180；每击：每目标 strike + `VFX.hit`（看破 reveal、流血 bleedN=3、眩晕 概率 sk.stun||25 浮字“眩晕 · 失去行动”）；击间等 hits>1?200:300。
5. `qh_hulu_staff` 额外“护身 · 减伤15%”。finally：anim 清空 + camReset；wait 150。

## 4. 敌方行动 `foeAct(u)`
- 蓄力意图：`u.charging=true`，“蓄力！”`#ffe25a`24，sfx `whoosh` .8/.7，act cast，wait 700，下回合意图改为 `ghost` 全体。
- 基础招（blade fist bite peck palm_m staff gy_dou_basic 或 basicAttack）：dashTo 目标；否则原地 cast + `VFX.cast` + 等 180。`camOn([u,目标],全体?1.08:1.16)`。
- 每击：近战 act atk/atk2 等 impactMs；闪避概率 dodge*.6 → “闪”`#bcd`24 + 侧闪 `dgT`（340ms，横移 34px 半正弦、抬起 12）；伤害数字 `#ff9c80`；击间等 recovery(260)。结束 camReset，近战 hopBack，wait 100。

## 5. 通用命中特效 `hitFx(it,t,ty,dir)`（T0，按兵刃类型；每次都附 shake(T.shake)、hitStop(T.stop)）
- 刀/啄：弯月 R=22，中心偏 dir*10，朝向 dir>0?.15π:.85π，张角 1.1π，厚 7，sweep=min(1,3k)，a=1-.9k；火花 10。
- 剑：直线长 2×34 斜角 -.4*dir，宽 5/3/1 三层（主/亮/白），g=min(1,4k)，a=max(0,1-1.3k)；k<.4 十字星 r=8(1-k/.4)；火花 8。
- 棍：脚上方椭圆冲击环 (4+13k)Z×(2+4k)Z 两层；尘土 8（色 #e8dcc8,#b8a898,#887868）；火花 6。
- 音律：3 层虚线环（gap .55）。暗器：三道交叉斜线 q=1-2k；火花 6 速 1–3。
- 咬：上下各 5 颗牙线合拢（o=12(1-min(1,3k))）；火花用血色 8。毒：旋转虚线环 + 内环；motes 8。
- 拳/其他：冲击环 r=(2+10k)Z 宽3 + 内白环；k<.5 8 条放射线；火花 10。
- `VFX.hit`：若 SK[key].hit 存在用专属；否则 key 映射 FXDEF.hit||ty||'拳'；暗器且非自身时加 `needleStreak`（180ms 三枚针光）。
- `touch`（轻接触）：dur firm?210:170，环 1+k*(9|6)，火花 8|4，震 3|1.5，顿帧 30|18。
