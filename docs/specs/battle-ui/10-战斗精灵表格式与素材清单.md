# 10 战斗精灵表格式与素材清单

源：`js/bart.js`（`window.BART`、`FOE_ANIM`、`foe()`）、`js/qihe-battle-art.js`（ye_initial、wilddog）、`js/qihe-chapter-battle-art.js`（第一章：`QiheChapterBattleArt`）、`js/qihe-faction-clash-art.js`（`QiheClashArt`）、`js/bfx.js` `HERO_LEGACY`。路径映射见 `js/production-assets.js`：键 `b_xxx` → `assets/production/battle/b_xxx.webp`。

## 1. 条目格式
```
BART[art] = { file, cell:[格宽,格高], cols, facing:'l'|'r', h:格高, tier:'party'|'minion'|'elite'|'boss',
  px?:[美术宽,美术高], body?:待机身体美术高, anchor?:[脚点x,脚点y](格内像素), pixelScale?:2|3, faceCrop?:[x,y,w,h],
  frames?:[帧名…], anim:{ 动作:{ f:[帧号], ms:数|[逐帧], loop?, hit?:命中帧在f中的序号, complete?,
      projectile?:{kind,release:放出帧序号,flightMs,hand:[x,y]}, contacts?:[{frame,resolve,point:[x,y],reach,weight?}] } } }
```
- 单行横排：帧 i 在 `(i%cols)*cw, floor(i/cols)*ch`；校验：图宽=cw×cols、高=ch（第一章/交锋加载时不符即报错）。
- 脚底贴格子底边（有 anchor 时以 anchor 为脚点），水平按锚点/中心对齐；美术像素 ×3（旧表）或 ×2（hd 表）最近邻放大存储。
- 动作键：idle dash atk atk2 hurt cast brk dead win（+ 交锋专用 guard、叶蘅 needle_skill）。
