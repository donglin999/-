# 09 战斗单位绘制：动作状态机、着色、阴影、光环、残影、死亡碎散、蓄势光柱

源：`js/bfx.js` `BFXI` IIFE：`artOf/spec/fidx/impactMs/recoveryMs/contacts/stateOf/frameOf/prep/blit/artScale/sharpFrame/rimFrame/shadow/offOf/moveTo/dashTo/aimReach/hopBack/stepFwd/stepBack/camOn/lunge/drawAll/drawOne/rings/trail/snap/foeDeath/aura/chargeAura/stars/shieldBack/overlay/drawParts/onTurnStart/victoryPose`；高度 `js/bstage.js` `unitH/battleBodyBounds`。

## 1. 朝向与高度
- 敌人在左、我方在右。`face(u)`：敌 +1，我 -1（朝向对方的屏幕方向）。表内朝向 `facing`；需要 `want=敌?'r':'l'`，不一致则水平翻转。
- `unitH(u)`（屏幕像素，身体可见高）：成人基准 `BATTLE_ADULT_H=105`×`BATTLE_ADULT_RATIO`（suzhi .99, ye .98, ye_initial .90, monk 1.03, soldier 1.02, gossip .97, oldman .96, smith 1.05, lady .98, beggar .98, boatman 1.02, liu 1.04, langli 1.04）×头目 `BATTLE_BOSS_RATIO`（chief 1.75, liu 1.14, langli 1.14, soldier 1.06, monk 1.08, beggar 1.08）×`dscale`；chief 非头目 1.14；兽 `BATTLE_BEAST_H`：dog 45, wolf 76, wilddog 70, rooster 72, snake 99；其他 105×clamp(h/170,.8,1.2)。
- `battleBodyBounds(A)`：第 0 格中间 24%–76% 列 alpha≥48 的行范围 → {height,bottom}。绘制高 dh=unitH×cell高/body.height；脚偏移 foot=(cell高-bottom)×dh/cell高；水平原点 `anchor[0]*dh/ch`（无锚点则居中）。

## 2. 动作状态 `stateOf(u,t)`（优先级）
1. hp≤0 → `dead`（hold，t0=_dT）
2. `u.anim`={k,t0,hold}：hold 或未播完（时长=表内 ms 之和；无表用 `STATIC_DUR` atk380 atk2 220 hurt300 cast420 win700 dash200）→ 该动作；否则清除
3. `broken` → `brk` 循环；4. `charging` → `cast` hold；5. 默认 `idle` 循环，相位偏移 -((id*7919)%1)*4000。
- 缺动作回退 `FALL`：dash→idle；atk2→atk→idle；brk/dead→hurt→idle；win/hurt/cast/atk→idle。
- 帧索引 `fidx`：ms 可为数或数组；loop 取模；非 loop 播完停最后一帧。
- `impactMs(u,k)`：有 projectile = releaseMs+flightMs；否则 hit 帧之前帧时长和（hit 缺省=中间帧），最少 40；无表 atk2 50 / 其他 90。`recoveryMs`：`complete` 动作=max(fallback,总时长-impact)，否则 fallback。

## 3. 每帧 `drawAll` → `drawOne`
- 同帧只画一次；单位按 `u.y+位移gy` 升序（冲到目标前方者 y+4 画在目标前）。
- 位移 `offOf`：`u.mv` 缓动（EASE out=1-(1-k)³，io，lin，in）；抛物线 lift=arc×4k(1-k)；击退 kbT（0–40ms out 出，40–260ms io 回，量 `_kbAmt` 默认 12，方向 敌-1/我+1）；闪避 dgT 340ms：x±34sin(kπ)、lift 12sin。
- 写回 u.ox/u.oy/u.goy 供特效跟随。
- 层序：阴影 → 光环 rings → 残影 trail → 本体 blit。
- 程序化补姿（无表或缺该动作）：idle 呼吸 sy=1+sin(t/420+id*9)*.012；dash rot .1dir；atk：命中前 dx=-5dir·e/im rot -.05dir，命中后 250ms 内 dx=10dir·q sx=1+.06q rot .06dir·q；hurt rot -.12dir 300ms 回；cast 上浮 3px 且白 .1+.06sin(t/60) `#fff4c0`；dead rot -.32dir。

## 4. 像素清晰缩放（blit）
- `artScale(im)`：检测图是否为 3 或 2 倍最近邻放大（随机采样 4000 点、≥200 不透明点都满足 k×k 同色）。
- 每美术像素占屏幕像素 a=dh×缩放/sh×k；a 接近整数（差≤.04）用最近邻；否则先整数倍 ceil(a) 最近邻放大缓存（LRU 96），再平滑缩放（a<1 用 high）。Godot：精灵用 nearest 过滤 + 整数倍时直接画，非整数时使用“sharp bilinear” shader。
- 氛围背景（`BSTAGE.atmo().rim`）：边缘光 `rimFrame`——向光方向（左上，翻转时右上）偏移 k 像素处透明的边缘像素与 rim 色 50% 混合（缓存 160）。阴影改径向柔影（见下）。

## 5. 阴影 `shadow(x,y,h,lift,a)`
rx=max(15,h*.19)×(1-min(.45,lift/110))，ry=max(4,h*.042)。像素版：3px 网格逐行椭圆，黑 alpha .34a(1-min(.5,lift/140))，y-2。氛围版：径向渐变 R=rx*1.45，纵向压到 ry*1.6，`rgba(8,5,3,.55ak)`→.32(55%)→0，k=1-min(.5,lift/140)。

## 6. 当前行动者光环 `rings`
rx=max(30,h*.24)，ry=rx*.28，3px 像素椭圆。当前者：色 敌`#ff7a5a`/我`#ffd24a`，p=.62+.22sin(t/220)；内环 .78 倍、alpha p*.45、虚线 gap .5、旋转 t/500。回合开始 `_tT`（`onTurnStart`，250ms 内不重复）560ms 扩散：半径×(1+1.2k)，色 敌`#ffb09a`/我`#fff0b8` alpha (1-k)*.95；k<.5 内白环 .7 倍 alpha (1-2k)*.6。

## 7. 冲刺残影 `trail`
冲刺中每 38ms 记录一帧，最多 3 个；alpha [.5,.34,.2]×淡出 f=1-(age-110)/150；整体着色 white .85，敌 `#ff8a70` 我 `#8fd0ff`。停止且都 >260ms 清空。
- `dashTo`：gap=max(目标h*.2+自身h*.16+14, 接触 reach 换算)，目标点 x=t.x-dir*gap、y=t.y+4；act dash hold；sfx `whoosh` .45/1.35；时长 170+min(110,|dx|*.18) ms，out 缓动。

## 8. 敌人死亡 `foeDeath`
- 0–260ms（FL）：抖动 x+sin(e*.9)*2，每 65ms 交替白/红 `#ff3a2a` 着色 .88。
- 之后 `snap`：块大小 bs=max(1,round(格高/44)) 采样 alpha≥110 的块；每块延迟 rel=(自上而下 0..1)*560+rand(110)，速度 vx=(x/半宽)*.05±.03，vy=-.03~-.09 px/ms，寿命 420–720ms；颜色 5 阶向 (255,170,90) 过渡。未到 rel 的块原位画（最后 70ms 白），之后 lighter 混合飞散，y 加 -.00006a² 上浮，k<.1 用 `#fff4e0`，k>.55 缩小 1px。阴影 600ms 淡出。取样失败则 600ms 红白淡出。

## 9. 覆盖层（画进 VFX 层，层坐标）
- 蓄势光柱 `aura(L,k,pre)`：金色板；s=√(unitH/150)；q：预览=.55+.15sin(clock/160)，爆发 k<.1 渐入、k>.72 渐出。脚环 rx=(9+3.5L)s ry=.3rx（L>1 宽2）+内环；L≥2 加 .7 倍旋转虚线环；L≥3 加 1.3 倍反向虚线环。光柱高 hh(.55+.28L)×grow(爆发 min(1,5k))×(预览.8)，宽 hh(.14+.04L)；两层 pillar（逐列抛物线强度，向上衰减）；上升光条 streaks (预览2/爆发3)+L×(2|4) 条；motes 4+4L。L≥3 爆发前半段两道冲击扩环（3.6 倍）。预览档位增加时 320ms 闪环+白光柱。
- 头目蓄力 `chargeAura`：血色，q=.6+.25sin(clock/90)，光柱 hh*.2 宽、hh*.95 高，双环 + 7 条光条 + 8 motes。
- 破势星 `stars`：头顶 3 颗绕转星（周期 clock/300，半径 8s），背面时 .55。
- 回盾 `shieldBack` 620ms：冰色扩散环 (6+16k)s + 白虚线环 + 8 点。
