# 05 画布 UI：行动顺序条、敌人脚标、意图、目标箭头

源：`js/bui.js`。注意同一文件中 `drawOrderBar`、`drawShieldRow` 各定义两次，**后定义的 v4 版（文件末尾，`buiDia` 之后）为实际生效版本**；`drawUnitUI`、`drawIntentLines` 只有一版。调用顺序见 06 节帧绘制顺序。坐标均为 960×540 屏幕坐标；`drawUnitUI/drawIntentLines` 在相机变换内（世界坐标），`drawOrderBar` 在相机外。

## 1. 行动顺序条 `drawOrderBar(now)`（v4，左上）
- 仅 `B.round>0` 绘制。基线 `y=44, x0=46`。
- 列表：`cur`=当前存活行动者；`rest`=本回合 `B.order` 中存活、未行动（不在 `B.done`）、非 cur；`nxt`=`B.next` 中存活且非“破势且 brokenUntil≥round+1 的敌人”。
- 引线：从 `x0+30` 到 `xe=x0+46+rest.length*32+30+nxt.length*28+12`，y=44.5，1px，水平渐变 `rgba(240,228,200,.75)`→`rgba(240,228,200,.12)`。
- 当前者：`buiDia(cur, 46, 44, s=58+sin(now/300)*1.5, dim=false, big=true)`（呼吸缩放）。
- 其余：x 从 `x0+48`，每个 `buiDia(u,x,44,28)`，x+=32。
- 分隔：x+=4，画“››”（14px 衬线，`rgba(240,228,200,.7)`，居中于 x+6，y+5），x+=24。
- 若有 nxt：在 (x-12, y-22) 写“下一回合”（11px 衬线，左对齐，`rgba(240,228,200,.75)`），其下 y-17.5 画 1px 横线 `rgba(240,228,200,.45)` 长 nxt.length*28；之后每个 `buiDia(u,x,44,24,dim=true)`，x+=28。

### `buiDia(u,cx,cy,s,dim,big)` 菱形头像
- 正方形边长 hh=s/√2，旋转 45°。底色：敌 `rgba(64,18,16,.92)`，我 `rgba(16,38,56,.92)`。
- 裁剪到菱形内，反转回正，画 `BUI.face(u, round(s*1.1))`，区域 (-s*.55,-s*.52, s*1.1, s*1.1)，平滑。无头像写名字首字（s*.4 衬线 #ddd）。dim 时叠 `rgba(0,0,0,.5)`。
- 描边：big `#f4e2b0` 2px，外再框一圈（偏 5px）`rgba(244,226,176,.45)` 1px；否则敌 `#e08a74`、我 `#9fd0e8` 1.2px。
- 敌人破势：右下角叠破势印 `POSHI.seal(round(s*.46))`，位置 (cx-s*.1, cy+s*.02)，尺寸 s*.46。

## 2. 敌人脚标 `drawShieldRow(u,t)`（v4）
锚点 x=u.x，y=u.y+8；n=弱点数，格子 cs=15、gap=3，w=n*18-3；`bx=round(x-w/2+10)`，`by=y+14`。
- 盾牌：中心 (bx-20+6, by-4+8)，缩放 1.3×(1+hit*.35)，hit=受击后 300ms 线性 1→0（`u.shieldHit` 时刻）。路径：(-9,-10)→(9,-10)→(9,1)→二次曲线经(9,8)到(0,12)→经(-9,8)到(-9,1)闭合。填 `rgba(40,84,130,.82)`（破势 `rgba(80,70,70,.8)`），描边 1.2 `rgba(200,232,255,.9)`（破势 `#aaa`）。中间白字 bold 12px：护盾值或“破”，基线 y=4。
- “弱点”二字：11px 衬线，(bx, by-4)，`rgba(240,230,210,.9)`，阴影黑 blur 3。
- 每格 (bx+i*18, by)：底 `rgba(14,12,18,.78)`（破势 `rgba(40,40,40,.75)`）；描边 1px：已知用 `WCOL[类型]`，未知 `rgba(200,200,200,.55)`；若该弱点被当前预估招式命中（`pv.t===wk||pv.e===wk`）描边 2px `rgba(255,226,90,.6+.4*sin(t/110))`。已知画 `BUI.weakIcon(wk)`（20px blot 缩到 13×13，偏 1px）；未知画 bold 11px “?” `rgba(230,230,230,.85)`。
- 细血条：选中/悬停/受击后 1500ms 内显示，(bx, by+18) 宽 w 高 3：底 `rgba(0,0,0,.7)`，前景 `#d0402c` 宽 w*hp/mhp。
- `WCOL`（battle.js）：刀#d8d2c0 剑#9fd4ee 拳#f0a868 棍#c89a60 暗器#b6c2d6 音律#8dd8c5 阳#ff8a3a 阴#9aa6ff 毒#86d65e 雷#ffe25a。`WTYPES` 即这 10 种。

## 3. 意图字徽与目标箭头 `drawUnitUI(u,now)`
- `u._buiHov`=鼠标悬停于该单位；top 初值 y-h（h=unitH(u)）。
- 敌人存活：先 `drawShieldRow`；若有 `u.intent` 且未破势：hot=蓄力或全体；尺寸 bs=hot?22:19；`iy=round(max(96, y-h-bs-8))`。
  - 蓄力：blot('蓄', 每 220ms 交替 `#e0402a`/`#b3261e`)；全体：blot('群','#b3261e')；单体：blot(招式兵刃类型简字，`暗器`→`暗`，默认“刀”，底 `#2a1d14`，字 `#eadcbc`，环 `rgba(200,170,120,.7)`)。教学战野狗写“扑”。hot 加发光 `rgba(255,80,40,.6)` blur 8。
  - 选中或悬停时上方标签：文本 `intentLabel(u)`（蓄力“蓄力中 · 下回合全体攻击”；全体“‼ 招式 · 全体”；单体“招式 → 目标名”），`text(lab, hot?'#ffc8b0':'#eee2c6', 14, {font:FS})`；底墨 swash(宽=文字宽+26, 26, {seed:91,halo:hot?'#e07050':'#d8c49a',haloA:.3,col:hot?'#3a0a06':'#0d0806',a:.86,dry:.35,head:.06,tail:.25,thick:.86})；标签 y=iy-30（若 <90 则放在字徽下方 iy+bs+4）。
- 被选为目标：箭头色 敌 `#e8402a` / 我 `#8fe0a8`，22px 向下 pointer，y=`top-28-((now/180|0)%2)*3`（180ms 跳动 3px），最小 70；敌人若 y<86 改为向右箭头放在单位左侧 (x-46-抖动, top+10)。

## 4. 意图连线 `drawIntentLines(now)`
仅我方回合。虚线 [3,7]，`lineDashOffset=-now/40`（流动），宽 2，圆头。对每个存活、未破势、非蓄力敌人：只画“全体意图”或当前选中/悬停者。起点 (f.x, f.y-unitH(f)*.95)，终点目标同高度，二次贝塞尔控制点 (中点x, min(y0,y1)-60)。颜色全体 `rgba(214,58,34,.5)`，单体 `rgba(230,110,80,.42)`。
