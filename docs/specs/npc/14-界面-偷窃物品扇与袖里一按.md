# 14 界面：偷窃物品扇、袖里一按小游戏

源：`js/qihe-steal-ui.js`（`steal`、`context`、`pick`、`display`、`iconHTML`、`qtyText`、`minigame`、`zones`、`judge`、`combine`、`params`、`boost`）、`js/qihe-steal-ui.css`。导出 `window.QiheStealUI`。

## 1. 图层与按键
`#qs-layer`：1600×900，`z-index:62`（最上层），`user-select:none`，宋体，字色 `#f2e5c9`。整层 zoom＝游戏区宽/1600；另有放大系数 `boost = clamp(0.72/Z, 1, 1.45)`（窄窗口时扇子与刻度弧放大）。
按键 capture 拦截；长按重复忽略；**打开 180ms 内忽略 E/空格/回车**（`arm()`）。

## 2. 主流程 `steal(id,p,npc)`
1. `context` → `pick` 物品扇；返回 null（罢手）→ 墨印 again。
2. 重新取语境，`chance`、`tier`、`display`；`minigame` → `fail|ok|great`；异常按 fail。
3. `shut()` 先收起界面，再 `resolve` 结算（失手台词、开战在界面收起后演）。
4. 成功 toast；`checkpoint`。

## 3. 物品显示 `display(it,p)`
- `it.money` → `{kind:'money', name: it.n||'钱袋'}`
- `p.disguised` 或 `p.conceal==='allButMoney'` → `{kind:'unseen', name:'看不清的一件'}`（宋先生、算命先生）
- 品阶 precious 且 `recognize(key||n, g)` 未认出 → `{kind:'unknown', name:'未知物品'}`
- 其他 → 名称。
图标：unknown 用 `r_qh_song_bundle_v1`（像素 30px）；unseen 写“？”（暗）；银两（非银铤）用 `assets/production/cultivation/mail-v7/pouch.png`；有 ITEMS 用 `mnIco(id,40)`；否则 glyph 或首字。
数量：unseen/unknown 不写；银两 `银两 N`，银铤 `一枚`；`q>1` → `N 份`；否则 `一件`。

## 4. 物品扇 `pick`
- 锚点：NPC 脚点上 `h×0.55`（`anchorOf`），主角点 `y−20`；取不到用 (900,430)。
- 选边：主角在 NPC 右边 → 扇在左（背对主角），否则右；需要宽 `470×boost`，放不下换边。
- 几何：`n` 件，`GAP=62`，`OFF=92`，`R=max(150, ((n−1)×62/2)/sin50°)`；`cy=clamp(A.y, 120+(n−1)×31×B, 780−(n−1)×31×B)`；第 i 件 `dy=(i−(n−1)/2)×62`，`t=asin(dy/R)`，`x = A.x + dir×(92 + R(1−cos t)×0.6)`，`y = cy+dy`。条目 56 高，top=y−28；左侧用 `right:1600−x−28`，右侧 `left:x−28`（左侧整行反向排列）。
- 金线弧 SVG：二次贝塞尔 `M(x0−dir36, y0−31) Q(A.x+dir(92−36−0.12R), cy) (xn−dir36, yn+31)`，先 `rgba(10,12,10,.55)` 3.4 宽，再 `#e2c27c` 1.2；两端菱形 8px 暗底 + 5px 金。
- 遮罩 `.qs-dim`：以 NPC 为圆心 `rgba(8,10,8,0) 130px → .36 300px → .55 640px`，淡入 0.14s。
- 每条 `.qs-it`：
  - 铜钱框图标 52×52（背景图 `ui_qh_steal_coin_20261027`，内图 38px）；
  - 百分比 `.qs-pct` 26px 粗 `#f3dfa6` 写 `chance%`；门槛不够则 14px 写 `窃术N级`；
  - 纸签 `.qs-slip` 高 38：名 18px 字距 3；品阶小框（`#3d6f62`；unknown 写红“？”；unseen 不写）；难度章 `难一..难六`（底 `#8a3a2b`，难一/二 `#7d7464`，难六 `#5e1c14`+金边）；数量 12.5px 小注；靠扇心一侧 4px `#a33f2f` 竖条；撕边 clip 与墨印小签同款。
  - 入场 `qs-in` 0.16s，第 3～8 个子元素依次延迟 0.02s。
  - 焦点：图标 60px+呼吸红框，签高 42，名 20px，百分比 32px `#ffe7a8`；灰件（off）：图标灰度，签底淡，名 `#7d7464`。
- 扇头（首件上方 72）：“窃”小朱印 24px + “挑一件下手”。扇脚（末件下方 44）：`下手把握 G% · 窃术 N级 · 身法 A · 他高你 D 级`（D>0 才写）；有戒心时红字 `他起了戒心（被你失手惊动过 N 回 | 被你得手过 N 回） · 成功率打 X 折`（X＝round(mult×100)/10）；按键 `[W][S]选 · [E]下手 · [Esc]罢手`；提示行。扇头/脚/标题底：`radial-gradient(ellipse closest-side, rgba(12,14,12,.84) 62%, 透明)`。
- 初始焦点：第一件非灰。按键：W/↑、S/↓ 循环；E/空格/回车 下手；Esc/Q 罢手；右键罢手。下手灰件：nudge 抖动并提示 `这一件要窃术N级才下得了手`。

## 5. 袖里一按 `minigame`
- 没有界面环境：`random×100 < chance` 判 ok/fail。
- 位置：`R=200`；`cx=clamp((A.x+A.px)/2, (R+90)B, 1600−(R+90)B)`，`cy=clamp(max(A.y,A.py)+30, (R+110)B, 900−160B)`。
- 弧框图 `ui_qh_steal_dial_20261027`（原图宽 1536，圆心 (767.7,833.8)，槽半径 640），按 `DK=200/640` 缩放并使圆心对齐 (cx,cy)。行程角 `a0=188° → a1=352°`，`ang(p)=188+164p`。“起”“止”标在半径 172 处。
- 标题（cy−280）：物品图标 + 名 20px + 小字 `甲级以上贵重 · 一手/两手 · 成功率 N%`。
- 说明（cy+48）：两手时先列“伸手/收手”两枚节拍印；规则“墨针从“起”扫到“止”，只扫一趟。看准时机按下去（，连按两手都中才到手）：”；图例 金段＝得手、红点＝妙手（窃术经验多 1）、段外或没按＝失手；按键“E／空格／点击 落手 · Esc 缩手（算失手）”。
- 区段 `zones(gold, red, rnd)`：`w=gold; g0=(1−w)·rnd; g1=g0+w; rw=w·red; r0=g0+(w−rw)/2; r1=r0+rw`（每手重新随机）。绘制：金段 `rgba(236,196,104,.95)` 宽 9 + 高光 `rgba(255,244,210,.7)` 1.5；朱心 `#c23b26` 宽 10 + `rgba(255,214,190,.7)` 1.2；最小角宽 金 0.8°、朱 0.6°。标签（半径 166）：金段角宽≥34° 时写“金区”与“朱心”，≥10° 只写“金区”。
- 针：`ui_qh_steal_needle_20261027` 高 74，放在半径 200、旋转 `角+90°`；后方 4 条残影线（每条落后 3°，透明度 `.4−k×.08`，宽 `3−k×.5`）。
- 时序：每手开始先画区段、针归零；首手等 **420ms**、第二手等 **160ms** 后起针；`p=(now−t0)/(needle×1000)`，p≥1 视为没按（fail）。按下（E/空格/回车/鼠标左键）→ `judge(p)`：在朱心 → great，金段 → ok，否则 fail（容差 1e−9）。fail 或最后一手：fail 后 120ms、否则 200ms 进入结算；否则 500ms 后下一手。Esc 或点“缩手”：本手记 fail 立即结算。
- 多手合并 `combine`：有 fail → fail；全 great → great；否则 ok。
- 结算演出：印章 `妙/妙手/到手 · 窃术经验多 1`（朱）、`得/得手/东西到手`（墨）、`失/失手/被他发觉了`（空心）；印 60px，`qs-stamp` 0.18s；成功物品图标 `qs-sleeve` 0.32s 收入袖中，失败弧框抖 0.26s；命中金段闪 0.3s。fail 760ms、成功 820ms 后自动收起，期间再按 E/空格/回车/Esc 或点击立即收起。
- 看门狗：`hands×(needle×1000+900)+2600` ms 后强制结束。外部 `close()` 时按失手（物品扇按罢手）。
