# 12 界面：易物秤、买卖挂轴（易）

源：`js/qihe-gift-ui.js` `yi`、`trade`、`hold`、`frame`、`shop`；`js/qihe-gift-ui.css`（`.qg-head/.qg-tg/.qg-sl/.qg-paper/.qg-scale/.qg-zone/.qg-deal`、`.qs2*`）。台词：`story/01-开始/人物-收礼与易物.ink`（`qh_trade_line`）、`人物-收礼与易物-补.ink`（`qh_trade_line_more`）、`人物-易物开口.ink`（`qh_trade_hero`：`萧白：让我看看你都有什么！`）。

## 1. 入口 `yi(npc,p)`
- 无 `p.shop`（寻常人 barter）：barterState off/hidden → `'again'`；否则直接 `trade`。
- 有 shop：系统对话 `choose('', '跟{名}以物易物，还是买卖？', ['以物易物','买卖','算了'], 默认 2)`。
  - 以物易物：off → again，否则 trade。
  - 买卖：有 `QiheTown.shop` 且有 SHOPS 货单 → `QiheTown.shop(p.id)`（其内部调本文件 `shop()` 挂轴），回 again；否则返回 `'buy'`，由墨印层走 NPC 原 act。
  - 算了 → again。

## 3. 秤的物理与绘制 `frame`（每帧 requestAnimationFrame）
素材（`assetImagePath`）：`ui_qh_trade_scale_stand`、`ui_qh_trade_scale_beam`、`ui_qh_trade_scale_panL`、`ui_qh_trade_scale_panR`，原图 768×512。
```
S0=0.86; OX=(720-768*S0)/2=49.76; OY=44
PV(支点,原图坐标)=(385,117.5); HK(挂钩)=左(155,129) 右(612.5,129)
TH=6°（最大倾角）
dt=min(0.033, 帧间隔秒)
a=玩家价值, b=对方价值×tradeRate
target = (a+b) ? TH·tanh((b−a)/max(4,(a+b)·0.35)) : 0     // 正＝顺时针，对方重则右盘下沉
弹簧阻尼 ω=3.2, ζ=0.55:  w += (ω²(target−θ) − 2ζω·w)·dt ;  θ += w·dt
```
绘制（全部 globalAlpha 0.5，画布 720×640，先 clear）：
1. stand 画在 (OX,OY,768S0,512S0)。
2. beam：平移到支点 `(OX+385S0, OY+117.5S0)`，旋转 θ，再画整张图（偏移回原点）。
3. 每侧盘：`dy=(HK.x−385)·S0·sin θ`，盘图整张下移 dy；对应托区 DOM `translate(440+OX+HK.x·S0−131, 120+OY+322·S0+dy)`（托区中心对准挂钩，322 为盘面 y）。

## 4. 心情句 kind
`look`（都空）`ask`（只放自己的）`want`（只挑了他的）`far`/`near`/`ok`/`over`（见 10 的阈值）`done`（成交后）。每人每 kind 一句，ink 里 `pid == "x" && kind == "y"` 分支；示例 店家 far：“客官，您这些东西，可换不起我这些货。”

## 5. 买卖挂轴 `shop(npc,p,opts)`（由 `qihe-town.js` 调）
按 **1920×1080** 写，`transform:scale(.83334)` 缩到 1600×900。opts：`{list:[{id,price}], buys:{id:收价}, off:{id:折后价}, offNote, say}`。CSS 变量：`--paper1 #3a2b1f --paper2 #241a11 --row1 #3f2e20 --row2 #2b2016 --line #4e3a26 --gold #d9b46a --gold2 #ffe7b0 --txt #efe2c2 --dim #a8957a --mute #7d6a52 --g-d #e3cc94 --g-c #6fd0b4 --g-b #c9a0f0 --g-m #e9dfc8 --bad #e8735a`，按钮蓝 `#4f97c9→#255d86`、橙 `#d4774a→#8d3f1f`。
- 遮罩 `radial-gradient(ellipse at 55% 50%, rgba(16,11,7,.78), rgba(4,3,2,.94) 80%)`。
- 店主立绘 left 40 bottom 0 660×900（下缘 80% 渐隐）；无立绘：放大像素小人 left 170 bottom 150 宽 300。对话框 left 100 top 150 宽 460，`#efe6cf` 21px，首行名字 16px `#7a5a2a`；内容 `msg||opts.say`。
- 页签（竖排木牌 58×100，选中高 112 金边）left 720 top 0：买入；有 buys 时再加卖出。
- 挂轴：上下轴 left 640 宽 1140 高 30（top 132 / 940），纸面 left 668 top 150 1084×796；表头 4 列 `1fr 170px 120px 300px`：名称/价格/持有(数量)/操作。行高 ≥100，图标 80 框（丙 `#3f9a80`、乙以上 `#8a64b8`），名 26px，价格 26px 金币图标；买不起整行变暗，价格 `--bad`；有折扣显示删除线原价。
- 行操作 `acts`：卖出页：有→“出售”(蓝,1)＋多于 1 件“全部”(橙)，无→“没有”；买入页：钱不够“不足”；否则“买入”(1)，可装备的加“装上”，可堆叠且 5 份买得起加“买五”。主操作＝第一个。
- 确认层 620 宽：标题 买入/买下并装上/出售/全部出售；`共需/可得 N 两 · 剩/之后有 M 两`；装上时“替下「X」，放回行囊”或“这一格现在空着”；按钮“再想想”/标题。
- 结算：买 `S.silver-=单价×n`，`S.bag+=n`，装上调用 `mnEquip('hero',id)`，提示“X，穿戴好了。”/“X（n 份），您拿好。”；卖 `S.bag-=m`，`S.silver+=收价×m`，“X（m 件）收下了，N 两。”；钱不够“银两不够。”
- 底部：银两木牌 left 96 bottom 40“萧白持有银两：N”；关系横幅 left 800 top 984 宽 880“与X的关系：档（好感 N）| offNote”；按键“[↑↓]选 [Enter]买入/出售 [Q E]换页 [Esc]离开”。悬停浮层 left 330 top 560（无立绘 top 330）宽 330，含装备对比 `属性 旧→新 ▲/▼`（最多 3 行）。
- 按键：↑↓/WS 循环选择；Enter/空格 主操作；Q/1 买入页，E/2 卖出页；确认层 Enter/空格/E 确定、Esc 取消；Esc 离开。
