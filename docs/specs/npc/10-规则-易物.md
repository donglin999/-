# 10 规则：易物（易）

源：`js/qihe-gift.js`（`canSwap`、`barterState`、`stockOf`、`tradeRate`、`accepts`、`valueOf`、`mood`、`dealOk`、`deal`）。界面见 12。做法照“大侠立志传”：两边放东西，秤按价值倾斜，对方一句心情话，不报数。

## 1. 谁能易
`barterState(p)`：
- 既无 `trade` 也无 `barter` → hidden（不出“易”印）。
- 档为厌恶/仇视 → off，“他厌恶你”/“已成仇”。
- 非 trade 且 score<20 → off “熟络之后才肯换”（trade 人物仍出印，因为还能买卖）。
- 否则可用。
菜单 note：trade “以物易物 · 买卖”，否则 “以物易物”。

## 2. 对方能拿出来换的 `canSwap(p,it)`
全部满足：有 `it.id`；非银两；类别缺省或“普”；`use!=='任'`；`swap!==false`；`ITEMS[id]` 存在；不在该人商店货单 `SHOPS[p.id]` 里（只有 `p.shop` 时查）。查看页“可换”角标同用此函数。

## 3. 库存 `stockOf(p)`
- `stockVer!==2` 时清空全部 stock（旧档重算）。
- 首次访问：遍历 bag，`canSwap && live(when/until) && 未被偷走(S.steal.taken[p][id||n])`，累加 `q||1`。之后持久化，交易增减。

## 4. 汇率 `tradeRate(p)`（对方物品的价值倍率）
```
own = 冷淡 → 1.2
      trade 且档 ∈ {熟络,信赖,托付} → 0.9
      否则 1
rate = max(own, QiheJianghu.priceMul(p.id) || own)   // 个人、门派、声誉取较差一档
```

## 5. 是否收 `accepts(p,id)`
物品既不在 GOODS 也不在 ITEMS → 否；在 GOODS 且类别在该人 `LIKES.no` → 否；否则是。（玩家侧可上秤物品受此过滤。）

## 6. 秤与心情
```
a = Σ priceOf(id)×k                (玩家放的)
b = Σ priceOf(id)×k × tradeRate    (对方的)
mood:
  a=0 且 b=0 → 'look'
  b=0       → 'ask'   (只放了自己的)
  a=0       → 'want'  (只挑了他的)
  a ≥ 1.25b → 'over'
  a ≥ 0.95b → 'ok'
  a ≥ 0.70b → 'near'
  否则      → 'far'
dealOk = a>0 && b>0 && a ≥ 0.95b
```

## 7. 成交 `deal(p,mine,theirs)`
不 dealOk 返回 false。玩家物品：`S.bag` 扣，加进对方 stock；对方物品：stock 扣，扣到 0 时删除并写 `S.steal.taken[p.id][id]=true`（偷窃清单也不再有）；`S.bag` 加。存档。易物**不改关系分**。
