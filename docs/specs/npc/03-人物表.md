# 03 人物表 PEOPLE

源：`js/qihe-npc-data.js`（PEOPLE、TEACH）（PEOPLE）。

## 1. 人物字段约定

- `name` 显示名；`npc` 地图 NPC 名数组（按名认人）；`chapter` 给 `QiheChapter.interact` 的 id；`faction` 门派；`role` 身份；`portrait` 立绘 key。
- `special` 特殊人物（未解锁前关系上限 19）；`unlock` 解锁条件（条件语法见 04）；`unlock:'never'` 永不解锁；`bondFloor` 关系下限（缺省 −100）。
- `civilian` 不习武（无战斗档、不出“比”）；`disguised` 乔装（可见度固定第 3 档“不透”）。
- `battle`：`{party}` 同伴｜`{clash,art,weaponName,acc}` 取 `QiheClashData.profiles`｜`{spar}` 取 `QiheSparFoes`｜`{lv,weapon,weaponGrade,acc,accGrade,arts}` 只写等级。
- `story` 托来源数组；`teach` 请教表键；`spar`：`{}` 普通可切磋｜`{deny:'companion'}` 隐藏｜`{deny:'disguised'}` 灰印“X推说不会这个”｜`{noProfile:true}` 灰印“战斗档待补”｜`{first:true,firstNote,firstWhen}` 剧情首场。
- `trade` 有易印且有买卖；`shop` 货单键；`barter` 熟络后肯以物易物；`gear` 穿戴；`bag` 随身物；`stealLv` 无战斗档时偷窃用等级；`flags.breaksLine` 偷他失手断线。
- bag 条目：`n` 名｜`id` 物品 id｜`q` 数量｜`c` 类别（缺省普通；`贵` 甲/绝级未知物品｜`锁` 奇遇奖励｜`贴` 贴身｜`剧` 剧情物）｜`g` 品阶｜`glyph` 无图标的字｜`diff` 偷窃难度 1～6（无＝不可偷）｜`gate` 窃术门槛｜`money` 银两｜`stealable` 剧情物例外可偷｜`swap:false` 不肯换｜`use:'任'` 任务用具｜`ret` 熟络回礼挑这件｜`look` 只可见｜`when`/`until` 条件｜`key` 认物键。
