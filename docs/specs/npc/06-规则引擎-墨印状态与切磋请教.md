# 06 规则引擎（二）：各墨印状态、请教与切磋执行

源：`js/qihe-npc-core.js` 中 `menuFor`、`storyHook`、`teachState`、`sparState`、`stealState`、`factionOff`、`doTeach`、`sparQuote`、`runSpar`。

## 1. `menuFor(p,npc)` 总流程

1. `syncUnlocks()`；取 `bst=bond.get(p.id).stage`，`neg=BOND.effects[bst]||{}`。
2. 按 MENU 顺序生成项 `{...M, st:'normal', note:M.note||''}`，`st` ∈ `normal|off|story`；`continue` 表示该印不出现。
3. 每项处理完后，若 `st!=='off'` 再做门派门槛 `factionOff`：命中则 `st='off', note='门派敌对'|'门派不睦'`，并且若 ink 里有 `npc_<id>_faction_no` 这个 knot，写 `it.say=该 knot`（点灰印时播这句）。
4. 返回数组（交给 UI 布局）。

### factionOff
映射 `FACTION_ACT={yi:'trade',jiao:'teach',bi:'spar'}`（托/谈/观/礼/窃不受门派门槛）。调 `QiheJianghu.gate(p.id,act)`：`g.ok` 或 `g.why` 以 `bond_` 开头 → 不封；`why==='faction_hostile'` → “门派敌对”，否则“门派不睦”。

## 2. 每枚印的条件

| 印 | 出现条件 | 灰印（off）条件与小签 | 正常/剧情时 | run |
|---|---|---|---|---|
| 托 tuo | `storyHook` 有结果才出现 | hook.off（见下） | st=`story`，lab/note 取 hook | `act` 或 `errand` |
| 谈 tan | `npc.talk!==false` | — | note '' | `act` |
| 观 guan | 恒有 | — | note `装备 · 随身 · 武学` | `profile` |
| 礼 li | 恒有 | 无 `QiheGift`→“尚未开放”；档位仇视→“要请中人说和” | score<0：lab `赔礼`，note `只收厚礼或他/她喜欢的`；否则 lab `赠礼`，note '' | `gift` |
| 教 jiao | `TEACH[p.teach]` 存在 | 见 teachState | note `title · grade` | `teach` |
| 比 bi | 非 hidden | 见 sparState | story 首场 st=`story` | `spar` |
| 易 yi | `p.trade||p.barter` 且 `QiheGift.barterState(p)` 非 hidden | `neg.yi`（厌恶/仇视）；或 `bs.off && !p.trade` → bs.note | note `以物易物 · 买卖`(trade) / `以物易物` | 有 `QiheGiftUI` → `yi`，否则 `act` |
| 窃 qie | 有 `QiheSteal` | 见 stealState | note `下手把握与可窃物品` | `steal` |

注意：`BOND.effects.tuo` 只在 errand 钩子里使用；“托”的 main/errandCheck/stranger 不受关系封锁。

### storyHook(p,npc)：按 `p.story` 顺序取第一个命中
- `main`：`QiheChapter.mainStep()` 的 `npc===p.chapter` → `{lab:'托付', note:主线这一步 title, run:'act'}`。
- `errand`：`QiheOutsiders.available()`，`k=representativeKey(p.chapter)`，`questOpen(k)`，阶段≠done：
  - 阶段 none 且关系为厌恶/仇视 → `{off:true, note:effects[档].tuo}`；
  - 否则 lab＝none 时“托付”、进行中“回话”；note＝`notes[k]`（拜帖跑腿/旧货账跑腿/药单跑腿）；run `errand`。
- `errandCheck`：`QiheOutsiders.pendingFor(npc.name||p.name)` 非空 → `{lab:'回话', note:'问「'+defs[ks[0]].name+'」', run:'act'}`。
- `stranger`：`QiheChapter.strangerPending()` → `{lab:'回话', note:'后山的事', run:'act'}`。

### teachState(p)
1. 已请教（`S.qiheNpc.teach[id]`）或 `t.skill` 已学 → off，note `t.closedNote||'已请教过'`。
2. `effects[档].jiao`（冷淡起）→ off。
3. `req` 中第一个不满足的 → off，note＝`miss[2]||miss[1]`（小签短句）。
4. 否则 normal，note `t.title+' · '+t.grade`。

### sparState(p)（顺序判断，首个命中即返回）
1. 无 `p.spar` 或 civilian → hidden；`deny:'companion'` → hidden。
2. `deny:'disguised'` → off “他/她推说不会这个”。
3. 剧情首场：`spar.first && !rec.first && test(firstWhen) && test('stage:refuge')` → story，note firstNote（护院：徐令仪已点头）。
4. `!S.qiheNpc.skills.spar` → off “还不懂讨教的规矩”。
5. `noProfile` → off “战斗档待补”。
6. `S.qiheChapter.pendingEvent || QiheChapter.running` → off “有事在身”。
7. `effects[档].bi` → off。
8. `d=b.lv−S.lv`：`d>=15` → “差距过大 · 他不接”；`d<=-10` → “你太强 · 他不接”。
9. 本人本时段 ≥1 → “这个时段打过了”；本时段全局 ≥3 → “这个时段打够了”。
10. `S.hp < derived().mhp*0.5` → “你带着伤”。
11. 否则 normal “点到为止”。

### stealState(p)
无 `QiheSteal` → hidden；`!skills.steal` → off “还不会偷窃”；`QiheSteal.isAlert(id)` → off “他正盯着你”；`listItems` 为空 → off “身上没什么可窃的了”；否则 normal。

## 3. 请教执行 `doTeach(p)`
- 状态 off 直接返回 false。
- `fx.activity`：`await QiheChapter.activity(fx.activity)`（陆衡走既有学棍活动 `practice`）。
- `fx.zy`：`S.zy[键]=min(200, 原值+n)`；`teach[id]=true`；存档；`toast(gain, 2200ms)`。

## 4. 切磋报价 `sparQuote(p)`
```
d     = b.lv − S.lv
base  = 8 + 2×b.lv
weak  = d<0 ? max(0, 1 + d/10) : 1
decay = [1,.6,.3,0][min(3, rec.count||0)]
显示经验 exp[r] = round(base × result[r] × weak × decay × 1.2)   // 1.2 仅显示“历练领悟 +20%”
结算原值 raw(r) = base × result[r] × weak × decay
首次领悟 insight.first   = rec.first ? 0 : 10
首胜领悟 insight.firstWin= rec.firstWin ? 0 : max(10, round5(b.lv/2))   // round5(v)=round(v/5)*5
spent = decay===0；story = spar.first && !rec.first；left = max(0, 3 − slots[当前时段])
```

## 5. 切磋执行 `runSpar(p)`
1. 记下 `S.hp,S.mp`。对手 spec＝战斗档 spec，`name=(门派名不在名里时前缀门派)+p.name+' · 切磋'`，`exp:0,silver:0,drops:{}`。
2. 临时替换全局：`endCheck` 顺序：敌全灭→win；所有敌 `hp<=mhp*0.3`→win；任一主角 `hp<=mhp*0.3`→lose；我方全灭→lose；`B.round>8`→draw。`victory`＝胜利姿势后 `bigText('胜','#f3d58e',900)`（不弹结算）。`bigText` 把“脱身”替换为“平”。
3. `battle({allowAuto:true, solo:true, heroArt:'hero_village', heroPor:'opening_hero_village', bg:QiheChapterBattleArt.backgrounds.road, foes:[spec]})`；finally 还原三个函数并恢复 hp/mp（切磋不掉血）。
4. 结果 r＝win/lose/其余 draw。`raw=round(q.raw(r))`；>0 时 `CharacterGrowth.awardBattle(S,raw,[],…)` 取主角实际经验，`rec.count++`。
5. 领悟（写入 `SharedInsightPool`，以 receipt id 去重：`balance+=,earned+=,ledger` 留最后 100 条）：未 first → `spar:<id>:first:<stage>` +10 “初次切磋 · 名”；胜且未 firstWin → `spar:<id>:firstWin:<stage>` +firstWin “首胜 · 名”，并在 `对手lv>=S.lv` 时 `QiheJianghu.settle('spar_first_win',{npcId})`（声誉 +1）。
6. `rec.first=true`；剧情首场：`skills.spar=true`（学会切磋，不计次数），否则本人与全局时段次数各 +1。存档，返回 `{result,exp,insight,learned}`。
