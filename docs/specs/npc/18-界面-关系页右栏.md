# 18 界面：关系页右栏（势力详情、成员、近事）

源文件：`js/qihe-jianghu-rep-ui.js` 的 `render / outlook / gateText / members / metOf / avatar / faceCrop / placeFace / recent`，以及 `js/qihe-jianghu-rep-ui.css`。左栏、声誉条与颜色变量见 17。

## 5 右栏：选中的势力
默认选中：`s.repSel` 无效时，取第一个展开且非空的组的第一项。
1. 标题条 `.qjr-title`：最小高 62，背景渐变 `#2b2925 → #3a3631 70% → #2b2925`，`clip-path: polygon(0 0,100% 0,96% 100%,0 100%)`，右内边距 92。内容：lg 印、h2 势力名（楷体 22px，字距 6px，#f6ecd6）、小字“组名 · tag · 地区”。右侧大圆章 `.qjr-big`：66px 圆，`radial-gradient(#8a6d47, #5c4730)`，`3px #c9a45c` 边框，里面是档名（16px）和分数（11px，#f0d9a7）。
2. 展望 `outlook`：每行一个标签（11px，#a8352a 底；“再落”用 #2f2a26 底）加一句文字。
   - 眼下：`gateText(当前档, group)`。
   - 再升：上一档 `up` 存在时显示“到「名」（+min）：…”；若 `up.min > L[1]`，追加 em 注释“开始部分最高到 +14，这一档要到培养才开。”
   - 再落：下一档 `dn` 存在时，`dmax` 在当前为 chu 且分 ≥ 0 时取 −1，否则取 当前档 min − 1；`floor = max(L[0], 势力 floor ?? −100)`；`dmax < floor` 时追加注释“开始部分最低到 X，落不到这一档。”
   - `gateText(id, grp)`：称呼 `who` 为 town 乡里人、guan 公人、其他门人。按顺序拼句子：有 trade 拦截时写“who不肯交易、请教、切磋、托事”；priceMul > 1 写“买卖贵一成”，0.9 写“九折”，0.85 写“八五折”；firstMeet 非 0 时写“who初见 ±n”。各句以“，”连接，末尾加“。”；一句都没有时为“who初见照常，买卖原价。”
3. 成员区：标题为“村中人物 / 司中人物 / 门中人物”，附小字“各人和你的私交另算；只列见过的人”。网格 3 列，gap 8。`members(fid)` 取 faction 等于本势力（或 shownIn 为本势力）的成员，hidden 成员在未揭示时不列出。名字取 PEOPLE.name，没有时依次查 {guanshi 管事, wukui 乌魁, caibanshi 采办使}，最后用 id；副标题为“称谓 · role”（伪装中的隐藏成员不显示 role）。个人档 `memberStage` 用 `QIHE_NPC_DATA.BOND.stages`，从高到低查（备用值为 80/50/20/0/−19/−49/−100）。
   - 见过的人显示卡片 `.qjr-mc`：56×56 头像、名字 15px、副标题、档名加分数；主事在右上角加红签“主事”（10px）。
   - 没见过的合并成一张虚线卡：“？”加“另有 N 人 / 还未相识”。一个都没有时显示“还没有见过这里的人”。
   - `metOf(id)` 满足任一条件即为见过：在 `S.party` 或 `S.qiheRoster.members` 中；`QiheJournal.knowledge(S).met[JOURNAL_ID[id] || id]`（innkeeper→merchant、aide→procurement_aide、guanshi→steward、caibanshi→procurement）；qiheBond 有 score、gifts、unlocked 或 bonus；有切磋次数、切磋首胜或请教记录；qiheGift 的 given、known 或 returned 中有此人；peddler 的 `qiheTown.pole.stage` 或 innkeeper 的 `qiheTown.tab.stage` 不为 'none'；在 `S.encounteredNpcs` 或 `S.qiheEncountered` 中。
   - 头像 `avatar`：① 有立绘 `portrait` 时显示 `.qjr-av-por`，裁出脸部：`faceCrop` 把立绘缩到 120×160，从上往下找第一行不透明像素 ≥ 3 个（alpha > 110）的行作为头顶 top；在 top 到 top+22 行之间收集不透明像素的 x，取中位数作为 cx；`cy = (top+24)/160`。`placeFace`：以 400px 宽窗口为准，`s = 56/400`，背景尺寸为 960s × 1280s，`position = (28 − cx·W, 28 − cy·H)`，未算出时 cx 用 0.5、cy 用 0.2。② 没有立绘时用像素小人 `miniSprite(dialogueSprite(name))`，按 56px 显示，`image-rendering: pixelated`。③ 都没有时显示姓氏首字印（底 #6f5a45，24px）。
4. 近事 `.qjr-recent`（`margin-top: auto`，贴在底部，上边框）：标签“近事”（红色），取 log 倒序，默认 2 条，展开时 8 条；每条为“<b>声誉/势力名 ±n</b> 原因”。总数 > 2 时，右端显示按钮“…全部”或“收起”。没有记录时显示“尚无近事”。
