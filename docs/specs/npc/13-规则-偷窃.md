# 13 规则：偷窃（窃）

源：`js/qihe-steal-data.js`（导出 `window.QIHE_STEAL_DATA={DIFFICULTY,TIERS,SKILL,GRIP_TERMS,GAP,WARY,CAUGHT_PENALTY,OUTCOME_RULES,DISPLAY_RULES,OVERRIDES}`）、`js/qihe-steal.js`（`window.QiheSteal={state,stealLv,addExp,isAlert,rumor,grip,listItems,chance,wary,minigame,resolve,teach}`）。失手台词 ink：`story/01-开始/人物-失手.ink`，knot `<人id>_steal_caught`（ye…xiaohe 共 23 个）。

## 3. 下手把握 `grip(ctx)`
语境（`qihe-steal-ui.js context`）：`hero={lv:S.lv||1, agi:S.agi||4, stealLv, perks:S.steal.perks||{}}`；`target={lv: p.battle.lv || p.stealLv || 0, state:'normal', fighter:!!p.battle, villain, flags, patron}`；`bond=bond.get(id)`；`rumor.here=S.steal.rumor[S.scene||'m_qh_central']`。
> 注意原版行为：`target.lv` 读的是**人物表原始 `battle.lv`**，clash/spar/party 档未写 lv 的人（护院、帮众、徐令仪、岑霜、差役、叶蘅以外）取 0；宋先生取 stealLv 72；沈雁回 24、陆衡 16、周砚 88、叶蘅 3。一比一复刻须保留。

```
sum = 40                                   base
    + SKILL[stealLv-1].bonus               skill
    + 3 × (agi − 4)                        agi
    + clamp(hero.lv − target.lv, 0, 10)    lvAdv
    + (state==drunk|busy ? 15 : 0)，但关系档为厌恶/仇视时 0   occasion（当前 state 恒 normal）
    + (perks.thiefTip ? 5 : 0)             tip
    + (rumor.here ≥ 3 ? −15 : 0)           rumor
d = target.lv − hero.lv
gap = d ≤ 0 ? 1 : 1 / (1 + (d / (5 + 0.5×stealLv))²)
grip = clamp(round(sum × gap), 5, 95)
```

## 4. 单件成功率 `chance(id,item,grip,p)`
- `OVERRIDES[id+'_'+item.id]`（`aqi_lesson_coin` 70%、`aqi_lesson_purse` 100%，ruleset `teach`）优先。
- 戒心 `wary`：`lv = min(6, 已偷走件数×1 + 失手次数×2)`，`mult = 0.85^lv`。
- `chance = clamp(round(grip × DIFFICULTY[diff] × mult), 5, 95)`。
- `gate = item.gate ?? p.gate ?? tier.gate`；`gate > stealLv` 则该件灰掉（显示“窃术N级”）。

## 5. 可窃清单 `listItems(id,p)`
`p.noSteal` → 空。从原始 bag 取（无名的银两条目命名“钱袋”），过滤掉：
1. `c:'剧'` 且无 `stealable`；2. `look` 或 `worn`；3. `c:'贴'` 且未到 5 级；4. `c:'贵'` 且未到 7 级且 `gate!==0`；5. 已偷过（`taken[id][it.id||it.n]`）；6. `when` 不满足或 `until` 已满足。
> 原版不按“没有 diff＝不可偷”过滤（数据注释如此写，代码未实现）；无 diff 的条目按难 1 出现。

## 6. 小游戏参数 `minigame(chance,tier,perks)`
```
hands = (tier.hands==2 且 有 perk hands甲) ? 1 : tier.hands
goldRatio = hands==1 ? chance/100 : (chance/100)^(1/hands)     // 两手都中的概率 ≈ chance
redRatio  = 有 redCore ? 1/3 : 0.25
needle    = tier.needle（UI 下限 0.6 秒）
```

## 7. 结算 `resolve(ctx)`
ctx：`{npcId,item,target,result:'fail'|'ok'|'great',ruleset,ctx:{phase:'opening',mapId:S.scene||'m_qh_central',fixedScene:false},bond(偷之前的快照),tier,caught:{count: 以前失手次数+1}}`。
规则表按顺序筛出 `set` 相同且 `when` 全命中的规则，收集 effects，遇到命中的 `final` 规则即停；再按序执行（`skipWhen` 命中的跳过）。

| 组 | when | effects |
|---|---|---|
| teach | fail | 无（final） |
| teach | ok/great | `aqiTeach.step += 1`；exp +1（final） |
| main | ok/great | take；moral(tier.moral，villain 跳过)；exp(tier.exp)；diff≥5 再 exp +3；firstFrom（空） |
| main | great | exp +1；stamp '妙'（空） |
| main | fail 且 `flags.breaksLine=='song'` | 扣关系（首次 −10，其后 −15）；`S.qiheSong.broken=true`；`brokenAt=qiheSong.step`；播 `song_steal_caught`（final：不警觉、不开战） |
| main | fail | 播 `<id>_steal_caught`；alert（本半日警觉，`caught.count++`）；扣关系 −10/−15；`target.patron` −3（reason `steal_caught_kin`，当前无人有 patron）；moral −2（villain 跳过）；本地图风声 +1（0～3）；`QiheJianghu.emit('steal_caught',{npcId,mapId,tier,repeat:count>1,victimIsVillain})` |
| main | fail 且 bond.hostile 且 fighter 且 phase opening 且 count≥2 且非固定剧情 且无 `noHostileInOpening` | 开战：`battle({allowAuto:false,solo:true,heroArt:'hero_village',heroPor:'opening_hero_village',foes:[{...spec,name:名+' · 失手被发现',exp:0,silver:0,drops:{}}]})`；败：`S.hp=max(1,floor((S.mhp||20)×0.3))`，`S.silver=floor(silver×0.9)` |
| main | fail 且 bond.hostile 且非 fighter | 风声设满 3；`caught[id].hostile=true` |

- take：`taken[id][it.id||it.n]=true`；有 id → `S.bag[id]+=q||1`；否则银两 → `S.silver+=money`（银铤 600）。
- moral 调全局 `moral(v)`；exp 调 `addExp`（升级返回 `{levelUp,lv}`）。
- 警觉 `isAlert`：`alert[id].at === 当前 halfDay` 即警觉（无章节存档时永不警觉）→“窃”印灰“他正盯着你”。
- 成功后 `toast('得手 · 银两 N' 或 '得手 · 物品名 ×q', 1800)`；无论成败都 `QihePrologue.checkpoint()`（防读档刷）。
- 易物换光的随身物同样写入 `taken`（见 10）。
- `DISPLAY_RULES` 数据存在但 UI 未读；实际显示规则见 14。
