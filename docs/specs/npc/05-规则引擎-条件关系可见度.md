# 05 规则引擎（一）：存档、条件、关系轴、可见度、随身物

源：`js/qihe-npc-core.js`，导出 `window.QiheNpc={data,state,test,bond,syncUnlocks,battleOf,view,bagOf,menuFor,teachState,sparState,sparQuote,doTeach,runSpar,personFor,slot,heroWis,insightK,recognize,stealState,people}`。

## 1. 存档字段（`state()` / `bonds()`）

```
S.qiheNpc = { version:1, seed:<int>, skills:{spar?:true, steal?:true},
              spar:{<人id>:{count, first, firstWin, stage:'opening', slots:{<时段>:次}}},
              slots:{<时段>:次},           // 当时段全局切磋次数
              teach:{<人id>:true} }
S.qiheBond = { <人id>:{score, gifts:[], unlocked, hostile, bonus},
               known:{<认物键>:true}, rolled:{<认物键>:上次判定时的悟性} }
```
- `seed` 缺失时 `Math.floor(Math.random()*2**31)||1`，写入后永久固定。
- `bond.raw(id)` 懒建 `{score:0,gifts:[],unlocked:false,hostile:false}`。

## 2. 条件语法 `test(expr)`

空串/空值＝真。按空白切分，每个 token 都为真才真（AND）。前缀 `!` 取反。

| token | 判定 |
|---|---|
| `halfDay<n` / `halfDay>=n` | `S.qiheChapter.halfDay||0` |
| `bond:<id>>=n`（n 可负） | `bond.get(id).score>=n` |
| `event:<id>` | `S.qiheChapter.events[id]` 真 |
| `stage:a\|b` | `S.qiheChapter.stage` ∈ {a,b} |
| `choice:<活动>` | `S.qiheChapter.choices[活动]` |
| `learned:<招式>` | `S.skills[招式]` |
| `has:<物品>` | 行囊 `S.bag[id]>0`，或主角/任一同伴的 weapon/armor/acc 等于 id |
| `errand:<键>:<阶段>` | `S.prologue.outsiders.quests[键].stage`（缺省 `'none'`）＝阶段 |
| `prologueErrand:<键>` | `S.prologue.errands[键]==='done'` |
| `sparred:<id>` | `S.qiheNpc.spar[id].first` |
| `skill:<k>` | `S.qiheNpc.skills[k]` |
| `chapter` | 有 `S.qiheChapter` |
| `never` | 恒假 |
| 其他 | 抛错“人物交互条件写错了：” |

## 3. 关系轴 `bond`

- `cap(id)`：非 special → 49；special 且 `unlocked` → 49，否则 19。
- `floor(id)`：`PEOPLE[id].bondFloor ?? -100`。
- `get(id)` → `{score,stage,cap,unlocked,hostile}`。
- `add(id,delta,opts)` 算法（逐字照做）：
  1. `v = before + delta`。
  2. 若 `delta>0`：若 `opts.amends`（赔礼）`v=min(v, max(before,0))`（最多补回到 0）；再 `v=min(v, max(cap,before))`（已超上限的不被拉回，但不再涨）。
  3. `v = max(floor, min(100, round(v)))`。负 delta 不受 cap 约束。
  4. `hostile = v <= -50`。
  5. 若 v≠before 且非 `opts.quiet`：调头顶小签 `QiheJianghuSlips.head(id, 文本, v<before?'neg':'pos')`，文本＝`sign(Δ)+' '+新档名`；`opts.reason==='steal_caught_kin'` 时为 `sign(Δ)+' 牵连'`。
  6. 若 v≠before：`QiheJianghu.settle('bond',{npcId:id,delta:v-before,reason:opts.reason||'bond'})`（折入门派声望，见 14）。
  7. 返回 `{before,after:v,stage}`。
- `opts.story` 字段在代码里未改变计算（仅语义标注）。
- `syncUnlocks()`：每次 `menuFor` 时调用。对每个 special 且 unlock≠'never' 的人，若 `!r.bonus && test(unlock)`：`unlocked=true; bonus=true; add(id, +8)`（只一次，读档也成立）。

## 4. 战斗档 `battleOf(p)`

`!p.battle || p.civilian` → null。
- `clash`：读 `QiheClashData.profiles[key]`（lv、st、weapon、artLevels、skillLevels）。arts＝每个 artLevels 条目 `{name,grade,lv,moves:[skillLevels>0 的招名]}`；weapon 名优先 `b.weaponName`；acc 名 `b.acc`。spec（用于开打）：`{name:p.name, sp:b.art||'c_qh_clash_guard', lv, st, weapon, skills:skillLevels 或 {blade:1}, weak:['棍','暗器'], shield:3, h:170}`。
- `spar`：读 `QiheSparFoes[key]`，spec＝该对象拷贝。
- `party`：lv＝`CharacterGrowth.level(S,id)`（无则 b.lv），st＝同伴存档 st，weapon＝`ITEMS[同伴 equip.weapon]`；标 `party:true`。
- 其余：只给 `{lv, st:null, weapon:{name,grade}, acc, arts}`。

## 5. 可见度 `view(p)` → `view0` + `gear`

```
b = battleOf(p); 无 → {civil:true}
p.disguised           → index 3（不透），d:null，eye:false
同伴在队 (S.party 含 battle.party) → index 0，party:true
否则：
  d    = b.lv − (S.lv||1)
  base = tierIndex(d)
  k    = insightK(heroWis())        // wis≥12→5，≥8→3，否则 0
  adj  = max(tierIndex(d−k), base−1)  // 眼力最多好一档
  i    = min(base, adj)
  eye  = i < base                    // 是否因眼力提档（UI 显示“眼力”标记）
```
`heroWis()=derived().st.wis`，失败退 `S.st.wis||0`。

### gearOf(p,b)
三格 weapon/armor/acc；`p.gear` 优先，weapon 缺省取战斗档兵器，acc 缺省取战斗档佩饰。每格 `{name, id, grade, glyph(缺省名首字，无名'？'), look, atk(ITEMS[id].weapon.atk ?? c.atk), def(ITEMS[id].armor 为数字时)}`。装备不可偷、不上易物秤。

## 6. 随身物显示 `bagOf(p,v)` 与认物 `recognize`

逐条（跳过 `when` 不满足或 `until` 已满足）：
- 纯银两（money 且无 n）：`{name:'银两',glyph:'银',qty:'<money> 两',money:true}`。
- `c:'贴'`：仅当 `p.disguised` 且 view.index===3 时，整人只出一条 `{name:'贴身收着一件',glyph:'？',dim:true}`；否则不显示。
- `c:'锁'`：`{name:'未知物品',glyph:'？',dim,locked}`。
- `c:'贵'`：key＝`it.key||it.n`；认出 → 正常显示＋`valuable`；没认出 → `未知物品`/`？`/dim，若 `wis >= RECOG[g].grade` 仍显示品阶。
- 其他：`{name,id,glyph,grade,qty:(money?'N 两':q>1?'×q':''),story:c==='剧',look,use,swap:QiheGift.canSwap(p,it)}`。

认物常量 `RECOG={甲:{line:24,grade:12},绝:{line:30,grade:15}}`。`recognize(key,grade)`：
1. 已 known → 真；grade 不在 RECOG → 真。
2. 若 `rolled[key]` 存在且 `>= 当前 wis` → 假（悟性没涨不重判）。
3. `rolled[key]=wis`；若 `wis>=line` 或 `hash(seed+':'+key+':'+wis) < wis/line` → known=真。
`hash` 为 FNV-1a 32 位：`h=2166136261; 每字符 h^=code; h=imul(h,16777619)`；返回 `(h>>>0)/4294967296`。Godot 需按 UTF-16 码元遍历（JS charCodeAt）以保证一致。

## 7. 时段 `slot()`

无章节存档 → `'night'`；`stage==='days'` → `'d'+halfDay`；否则 stage 本身（如 `'refuge'`）。

## 8. 认人 `personFor(npc)`

地图 npc 有 `resource`/`loot` 或无 `sp` → null；否则 `npc.person || byName[npc.name]` 查 PEOPLE。启动时为每个 PEOPLE 写 `p.id`，并按 `she` 集合写 `p.she`。
