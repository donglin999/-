# 17 界面：江湖菜单「关系」页（门派与声誉）

源文件：`js/qihe-jianghu-rep-ui.js`（`QiheJianghuRepUI.render / handleClick`）、`js/qihe-jianghu-rep-ui.css`。宿主是江湖菜单 `js/qihe-jianghu-ui.js`：只有 `QiheJianghuRepUI` 存在时，`TABS_UI` 才追加 `['rep','关系','rep']` 标签；该页里 `[data-qjr]` 的点击交给 `handleClick(e, s, draw)` 处理。选中的势力保存在菜单状态 `s.repSel`；页内状态 `ui = {closed:{组:bool}, logAll:false}` 不进存档。

## 1 颜色变量（:root）
`--qjr-ink #2e2a25`、`--qjr-paper #f7f1e3`、`--qjr-line #cdb98f`、`--qjr-red #a8352a`；各档颜色：tuo #a8352a、xin #a24a30、shu #9a6a3c、chu #857865、leng #6d5f51、yan #4c3f36、chou #2f2925。档名文字一律用 `var(--qjr-<档id>)` 着色。

## 2 总布局 `.qjr-rep`
CSS Grid 布局：`columns: minmax(300px,36%) 1fr`；`rows: auto minmax(0,1fr)`；areas 为 `'fame fame' / 'aside main'`；`gap 12px 16px`；`padding 8px 20px 12px`；`font-size 13px`；`overflow hidden`。
左右两栏的公共样式：背景 `#fbf7ee`，`1px solid --qjr-line` 边框，`inset 0 0 0 3px #f2e8d3` 内描边；aside 的 padding 为 `10px 12px`，main 为 `12px 14px`，main 可纵向滚动。

**印 `.qjr-seal`**：40×40，圆角 4，背景 `var(--fc)`（默认 #7a5a44），字色 #f8efdc，楷体 700 22px，阴影为 `inset 0 0 0 2px #0000002e, inset 0 0 10px #00000045`。尺寸变体：sm 26/15px，row 38/21px，lg 50/28px；fame 头部用 44/25px。`-red` 背景 #a8352a，`-ink` 背景 #2f2a26。

## 3 声誉行 `fameBar(score, lock)`
`lock` 只在 `part() === 'kaishi'` 时为 'kaishi'，其他部分为 null。
1. 头部：朱印「名」，右侧小字“声誉 · 江湖人称”（11px、#8a7f6a、字距 2px）；下面是档名（楷体 21px、红色）加 `<em>±分</em>`（14px、#6f6655）。分数格式 `sg`：正数加“+”，负数用全角“−”。
2. 秤杆区：墨印「恶」(sm)、`.qjr-fscale`（flex:1，高 54）、朱印「侠」(sm)。
   - 杆 `.qjr-rod`：top 24，高 6，圆角 3，渐变 `90deg #2f2a26 → #8a7a66 30% → #c9b48c 50% → #b8754e 70% → #a8352a`。
   - 7 段等宽，从左到右为 e3…xia3（`FAME_ASC` 按 min 升序，每段 `lo = min`，`hi = 下一段 min − 1`，最后一段 hi = 100）。
   - 刻度 `.qjr-tick`：画在 k/7 处（k = 1..6），top 21，1×12，颜色 #6f6655。
   - 段名 `.qjr-seg`：在 (k+0.5)/7 处，top 36，11px，#8a7f6a；当前档加 `.qjr-cur`（红色、加粗）。
   - `famePos(v, edge) = (k + (v − lo + off)/(hi − lo + 1)) / 7 × 100`，off 为 lo 边缘 0、hi 边缘 1、其他情况 0.5。**也就是说，一段之内按分数线性映射**；标记位置取 `famePos(score)`。
   - 上下限：`L = PART_LIMITS[lock].fame`；`a = famePos(L[0],'lo')` 大于 0 时，在 [0,a] 画雾区 `.qjr-fog`（top 22，高 10，`repeating-linear-gradient(135deg, #f7f1e3d9 0 3px, transparent 3px 6px)`），并在 a 处标注“◂ 开始部分到此”（向左对齐）；`b = famePos(L[1],'hi')` 小于 100 时，在 [b,100] 画雾区并标注“到此 ▸”。标注样式：top 2，10px，#a8352a。
   - 标记 `.qjr-mk`：top 27，14×14 菱形（rotate 45°），#a8352a，`2px solid #f7f1e3` 边框，外加一圈 1px #6b2018；title 为“档名 ±分”。
3. 注释 `.qjr-fnote`（宽度 flex 230px，左边框，11px，行高 1.6）：“声誉只记被人看见的事；门派、村镇各记各的账。”宽度 ≤ 1180px 时隐藏。

## 4 左栏：势力列表
- 标题：“势力”（楷体 17px、字距 4px）+ 小字“见过才列出 · 组内按关系高低”。
- `groups()`：只取 `S.jianghu.faction[id].met` 为真的势力；排序时 pin 优先，然后按分数降序；按 sect/town/guan/other 分组，组名取 `GROUP_NAME`。
- 跳转条 `jumps`：每组一个按钮“组名 <em>数</em>”（12px，`1px #cdb98f` 边框，背景 #fffaf0，悬停时反色为 #2f2a26 底 #f7f1e3 字）；组内为空的加 `.qjr-off`（透明度 .45，disabled）；右端写“共 N 方”。点击后展开该组并选中组内第一项。
- 组头 `.qjr-grp`：18×18 墨色菱形，里面显示“−”（展开）或“+”（折叠），组名 14px，人数（#a89b85）；空组附注“尚无”，other 组附注“帮会、山寨、江湖散人（尚无）”。点击切换 `ui.closed[k]`。
- 势力行 `.qjr-row`：外边距 `2px 0 6px 18px`，内边距 `8px 10px`，背景 #fffdf7，边框 #e6dac0，悬停时边框变 #cdb98f。选中加 `.qjr-sel`（背景 #fff8e6，边框 #c9a45c，左侧 −16px 处有 8px 红色菱形）。行内依次为：row 印（`--fc` 取势力色）、名称 15px、pin 时加“本门”签（10px，底 #d4c5a8）否则显示 tag 小字、右对齐的档名（档色）加“（±分）”。
- 细墨条 `rbar(v, lock)`：高 5，底色 #ece3d0；中线在 50%（1px #6f6655，上下各伸出 3px）。v ≥ 0 时从 50% 起向右画 v/2 % 宽，颜色 #a8352a；v < 0 时从 50+v/2 % 起画 −v/2 % 宽，颜色 #2f2a26。kaishi 时在 `50 + L/2 %` 处画两条 1px 虚线（#8a7f6a），对应 faction 的上下限。
- 一个势力都没有时显示空状态：62px 圆环、“还没有和哪一方打过交道。”，以及说明“在江湖上见过的门派、村镇、官府会列在这里；和其中的人往来、结怨，都会记到这一方头上。”
