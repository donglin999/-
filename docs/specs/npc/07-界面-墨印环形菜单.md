# 07 界面（一）：接管交互、墨印环形菜单

源：`js/qihe-npc-ui.js`（`install`、`session`、`execute`、`ring`、`ringGeom`、`arcSVG`、`sealEl`、`edge`、`plaque`、`anchorOf`、`captureKeys`）、`js/qihe-npc-ui.css`。

## 1. 图层与坐标
- 设计分辨率 **1600×900**。图层 `#qn-layer`：`position:absolute;left:0;top:0;width:1600px;height:900px;z-index:58;pointer-events:none`；字体 `"Songti SC","Noto Serif SC","STSong",serif`，主色 `#1f1c16`。`fit()` 用 `zoom = 游戏区宽/1600` 整层缩放。Godot：一个 1600×900 的 CanvasLayer（layer 58 等价），随窗口等比缩放。
- `toDesign(wx,wy)`：世界坐标→设计坐标（扣相机 `cam`，按画布缩放）。
- `anchorOf(npc)`：`cx,cy` = NPC 脚点向上 `h*0.5` 处；`headY` = 向上 `h`（精灵 key 为 `zhou` 时 `h*0.42`）；`px` = 主角 x。

## 2. 接管与会话
- `install()` 包一层全局 `interact(target)`：非场景模式/忙/对话中 → 原函数。最近目标是 NPC、非 loot、`personFor` 有人物 → 进入 `session`；否则原函数。进入前：隐藏提示、清掉寻路、`keys={}`、主角面向 NPC。异常：`toast('人物交互出错，已收起',2200)`。结束：释放按键、清层、刷新 NPC 与 HUD。
- `session(npc,p)`：最多循环 40 次：`items=menuFor`；空 → 直接走 NPC 原 act；`ring` 选中 → `execute`；返回 `'again'` 则再开墨印且焦点停在上次那枚。
- `execute(it)` 按 `run`：
  - `say`：清层，`QiheChapter.play(it.say)`（门派拒绝一句），可重开则 again。
  - `act`：主角转向后 `await npc.act(npc)`（原 ink 场次）；只有 `tan` 结束后回墨印。
  - `errand`：`QiheOutsiders.talk(p.chapter)`，结束。
  - `profile`：查看页；Esc→again；换人→切换 p/npc 后执行在查看页选的印。
  - `teach`：请教卷，作罢→again；确定→`doTeach`→结束。
  - `spar`：切磋卷，作罢→again；确定→`runSpar`→结果小卷→结束。
  - `gift`：`QiheGiftUI.gift`；`yi`：`QiheGiftUI.yi`，返回 `'buy'` 则走 NPC 原 act（商店）；`steal`：`QiheStealUI.steal(p.id,p,npc)`，取消→again。
- `canReopen`：仍在同场景、无对话、无待发事件、面板关闭、NPC 可见且距主角 `<130` 世界像素。

## 3. 按键（`captureKeys`，capture 阶段拦截，阻止冒泡；E/Enter/空格/Esc 的长按重复忽略）
墨印：`W/↑/A/←` 上一枚；`S/↓/D/→` 下一枚；`E/Enter/空格` 确定；`Esc/Q/X/Backspace` 收起。鼠标：悬停即焦点；点击即选；滚轮 deltaY>0 下一枚；点空白处收起。
提示条文字：`[W][S]转 · [E]定 · [Esc]收`。

## 4. 布局几何 `ring` / `ringGeom(n,side)`
常量 `R=96`（印所在圆半径），`R2=122`（外弧半径），`STEP=29`（度）。
```
step = n>1 ? min(29, 135/(n-1)) : 0
top  = min(220, 160 + (n-1)*step/2)
left 侧角度 = [top, top-step, top-2step, ...]（度，0°=右，顺时针为正 y 向下）
right 侧角度 = 180 - left
印 i 中心 = (cx + 96cos a, cy + 96sin a)
```
选边：`cx>1120` → left；`cx<480` → right；否则主角在 NPC 右边（px≥cx）→ left，否则 right。若任一印 x<70 或 >1530，翻边重算。
- 初始焦点：给了 focusId 就用；否则第一个 `story` 印；否则第一个非 off 印；否则 0。
- 名牌：中心 x=cx，top=`headY-2-44`。
- 提示条：top = 最低印 y+44；left 侧 left=最左印x−20；right 侧 left=最右印x+10−150。
- 小签 `.qn-lab`：top=焦点印 y−17；left 侧放在印左（`x-24-14-宽`），right 侧放在印右（`x+38`）。

## 5. 弧线装饰 `arcSVG(cx,cy,angles,fa)`（每次换焦点重绘）
- `a0=min(角)-24, a1=max(角)+24`；SVG 尺寸 `S=2R+80=272`，以 (cx,cy) 为中心。
- 内弧 R：a0→a1。外弧 R2：从 a0−6 到 a1+6，在焦点角 fa 的 ±14° 内断开。
- 刻度：每 5° 一根（跳过焦点 ±14°），15° 倍数长 6，否则长 3，从 R2 向内。
- 端点菱形（旋转 d+45°）：外弧两端与内弧两端各一，先画 8px `rgba(10,12,10,.6)` 底再画 5px `#e2c27c`。
- 先画暗描边底：弧 `rgba(10,12,10,.5)` 宽 3.4，刻度 `rgba(10,12,10,.55)` 宽 3；再画金线：内弧 `#e2c27c` 1.3（`class=draw`，首次打开 0.2s ease-out 描出，dasharray=弧长），外弧 0.9 不透明 .85，刻度 1。

## 6. 单枚印 `.qn-seal`
- 36×36（居中 margin −18），字体 `"Weibei SC","STKaiti","Kaiti SC"` 21px，字色 `#f1e3c2`；`drop-shadow(0 2px 1.5px rgba(0,0,0,.55))`。
- 旋转 `--rot` 按序号取 `[-3,2,-1.5,3,-2,1,-2.5,2.5][i%8]` 度。
- 残边：`edge(seed,amp)` 线性同余 `s=(s*9301+49297)%233280`（初值 `seed*9301+49297`），四条边各 4 点，抖动 `(rnd-.5)*amp`，25% 概率额外 `amp*1.6` 缺口，生成 clip-path 多边形；外沿 `seed=ch码+i*7, amp 5`，内框 `seed+3, amp 2.5`。
- 底色 `#1e231f` 带高光与 37° 细斜纹；内框 inset 3.5px，`1px #c4aa76`。
- 状态：`story` 底 `#96302a`，内框 `#f3e6cc`，字 `#fbefd6`；`off` 底 `rgba(244,236,216,.3)`+内描 2.4px `rgba(24,28,24,.86)`，字 `rgba(30,34,30,.78)`，无投影。
- 焦点 `focus`：48×48，字 28px，外发光 `rgba(239,206,131,.65)`；外框 inset −6px `1.5px #c4553d` 圆角 4，呼吸动画 1.6s（不透明 .7↔.5）；off 焦点框改虚线。
- 出场 `qn-stamp` 0.12s `cubic-bezier(.3,1.6,.6,1)`（从 scale1.15、透明），第 i 枚延迟 `i*30ms`。
- 尺寸切换过渡 0.1s。按下 `press`：scale .92，100ms 后关闭。点灰印：`nudge` 0.22s 左右抖 3px（不关闭，除非有 say）。
- 关闭：`.closing` 全部 0.15s 淡出；选中后等 120ms、取消等 150ms 再清层。
