## 1. 按键共通
capture 阶段拦截全部按键；长按重复忽略；**打开后 200ms 内忽略 E/Enter/空格**（防止墨印上按住 E 误送）。关闭时用 `setTimeout(0)` 再把结果交回，避免同一次 Esc 又关掉重开的墨印。

## 3. 物品格 `.qg-it`
74×74 圆角 12，底 `radial-gradient(rgba(56,50,40,.95),rgba(24,22,18,.95))`，外框 2px 价值档色：寻常 q0 `#8b8a78`、像样 q1 `#5f9a78`、厚礼 q2 `#5d86b8`。图标 56px（`mnIco`，无则魏碑 28px 首字 `#e9d7ad`）。右下数量 14px 粗；左上“喜”红圆章 20px（已知 xi）；焦点 `.hov` 金框 `#efce83` 发光。不可送 `.off`：图标不透明 .28 灰度，下方“不收”11px `#e9a78f`。
- 排序：`bagFor` 已知喜好的在前，同档按 tier 降序。
- 不可送判定：赔礼时 `judge.keep`；否则已知为 no。

## 4. 详情浮窗 `.qg-tip`（焦点物品）
宽 250，`rgba(18,16,13,.97)` 描金。位置：`left = 1000+(列×90) > 1180 ? 880 : 1000`，`top = 300 + 行×90`。标题名 18px + `价值档名 · 类别`；描述 `ITEMS.desc`；虚线下：有 preview → `他喜欢的：送了好感约 ＋N`（绿 `#9fd3b2`），否则 `送了才知道他喜不喜欢`（`#b9ab8a`）。

## 5. 操作流程 `pick(i)`
1. 仇视直接无效。
2. tier≥3 先弹确认 `.qg-confirm`（left 600 top 360 宽 400，`真要把X送/赔给他？`，按钮“送”(`#8a3428`)／“算了”；E/Enter/空格＝送，Esc＝算了）。
3. `give` → 取 ink 台词 `lineFor('qh_gift_line',{pid, kind, why, who:p.name})`，kind ∈ `xi|ke|meh|again|no|hostile|amend-ok|amend-no`，`why` ∈ `no|heavy|cheap|''` → 放进气泡。
4. 日志：送出时 `失去 1 个<物品>`；关系变化 `与X关系提升/下降 N 点`；换档 `与X关系到了<档>`；首次摸清喜欢 `摸清了：X喜欢<类别>`；回赠 `X回赠你 1 个<物品>`。被退回且首次摸清 → `摸清了：X不收<类别>`。卡上显示本次 delta。
按键：方向键/WASD 左右 ±1、上下 ±5（夹在 0～n−1）；E/Enter/空格 送；Esc 关闭（回墨印）。鼠标悬停换焦点，点击即送。
