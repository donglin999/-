### 功力印 `powerHTML`
62px 圆印 `radial-gradient(#a8473a→#7c2a20)`，竖排写 `tier.seal`（看透/看出/大概/不透）；眼力提档时右上角 20px 绿圆 `#2f5a4f` 写“眼”。右侧大字 24px + 小字：
- 不习武：印“常人”（灰黑底），“不习武”／“看不出武功，本就不会”。
- 乔装：“深不可测”／`你 N 级 · 看不透`。

### 门派行 `factionRowHTML`
读 `QiheJianghuData.MEMBERS[p.id]`（隐藏成员需 `S.flags.jianghuLinguanshiRevealed`）。44px 方块底色 `f.color` 写 `f.glyph`；门派名 22px；档名 20px（score<0 `#a3392b`，否则 `#3f6a45`）；带符号分数；`rank==='boss'` 显示“此行主事”（`#9b2f25` 底）。效果小字：敌对或 `GATE.trade` → “不肯和你换东西、指点、过招”；否则拼 `门人初见 ±N` 与 `买卖贵/便宜X成`；都没有 → “还没有什么来往”。

### 根基雷达 `radar(v)`（SVG 300×262，中心 150,128，半径 92，五轴从 −90° 起每 72°：臂力 str、根骨 con、身法 agi、定力 wil、悟性 wis）

- tri：半径按 低.35/中.62/高.9，宽 9 模糊；标签低/中/高。

### 按键
`Esc/X/Backspace/Q` 返回；`Z`/`C` 在 320 世界像素内的人物间切换（`nearbyPeople`，去重）；`A/←/W/↑` 与 `D/→/S/↓` 选底部印；`E/Enter/空格`：未选时先落到第一枚，已选则确定。灰印同墨印规则（有 say 则播，无则 nudge）。

## 2. 卷 `scrollBox(npc,w,h,html)`
暗角遮罩 `.qn-catch.dim`：以 NPC 为中心 `radial-gradient(rgba(10,12,10,0) 26% → .34 80%)`。卷位置：主角在 NPC 右边则 `left=cx+150`，否则 `cx−150−w`；夹在 `[40, 1560−w]`；`top=clamp(cy−h/2, 40, 860−h)`。撕边宣纸（多点 clip-path、background.webp、`drop-shadow(0 6px 14px rgba(0,0,0,.35))`），展开 0.16s（scaleX .96→1）。标题 28px 字距 12。
两按钮 `twoButtons`：左/上选第 0，右/下选第 1；E 确定，Esc 或点遮罩＝作罢。按钮 36px 印 + 16px 字距 4。

### 请教卷 580×330，padding `44 52 0 58`
标题“请教”+“{名}肯教你的”。图标（有 skill 用 `qh_staff_notes`，否则 title 首字）。`title`+品阶+`sub`；描述＝技能 desc（去掉 BP 之后与首句“…第一式。”）或 `line`。条件行：时限类（stage/halfDay）满足时不显示，其余 `文字 够/未够`（够 `#2f5a4f`，未够 `#8a3a2b`）；技能五维要求前置 `悟性 现值 / 需 n`；再接 info；`gain`（自动补“学会得：”）。按钮“学”（story 红）拜请指点 / “罢”作罢；右下 tip，缺省 `每人只教一次\n请教不耗时`。

### 切磋卷 640×410，padding `42 54 0 60`
- 标题“切磋”+“点到为止 · 不伤和气”。
- 对手行：（门派≤4 字且名中不含时前缀门派）名 19px；等级（exact 写 `L 级`，否则 高你许多/深不可测）；档框（一眼看穿/看得出/看个大概/看不透，`#3d6f62` 框）；`你 N 级 · 他高你 d 级/你高他 d 级/同级`（非 exact 不写差）。
- 规则文：“单人上场。谁先掉到三成气血、或打满八回合，就收手。打完气血内力复原，用掉的药不还；不掉对方物品。”
- 经验：`胜 X · 平 Y · 败 Z`；decay=0 时“他已摸透你的路数，这一场没有收益”。江湖历练：`初次与他切磋 +10 · 第一次赢他再 +F`，都没有“已领过”。
- 剧情首场且未学会：红字“打完这一场，学会「切磋」：此后可向大多数习武的人讨教。”
- 按钮“比”抱拳请教 / “罢”作罢；tip `本时段还可切磋 N 次`（首场前加 `firstNote · 本场不占次数\n`）。
