## 2 模块与加载顺序（index.html）
实际 `<script>` 顺序（只列相关项）：`qihe-npc-items.js` → `qihe-npc-data.js` → … → `qihe-jianghu-data.js` → `qihe-jianghu-slips.js` → `qihe-jianghu-rep.js` → `qihe-jianghu-rep-ui.js` → `qihe-jianghu-ui.js` → `qihe-npc-pixel-art.js` → … → `qihe-banter.js` → … → `qihe-npc-core.js` → `qihe-gift.js` → `qihe-gift-ui.js` → `qihe-steal-data.js` → `qihe-acc-fx.js` → `qihe-steal.js` → `qihe-steal-ui.js` → `qihe-npc-ui.js`。
- 依赖关系：npc-items 往 ITEMS 里补物品，并被 npc-data 引用；npc-core 依赖 npc-data、QiheJianghu、QiheGift（在调用时取）；npc-ui 最后加载，并调用 gift-ui 和 steal-ui 的入口。
- banter 必须在 `battle.js` 之后加载（它包装 `window.battle`）。
- 以上多数模块开头都有 `if(typeof isQiheEntry!=='function'||!isQiheEntry())return;`，只在栖河入口生效。
- 建议的 Godot 对应：数据表放 `Resource` 或 `const Dictionary`；规则层用 autoload 单例 `QiheNpc`、`QiheGift`、`QiheSteal`、`QiheJianghu`、`QiheBanter`；界面用 `CanvasLayer` 场景。

## 3 图层与分辨率
- 设计分辨率 1600×900（买卖挂轴单独按 1920×1080 设计，缩放 0.83334，见 12）。
- z-index：墨印菜单 `qn` 58，赠礼/易物 `qg` 60，偷窃 `qs` 62；江湖菜单「关系」页嵌在江湖菜单面板中。Godot 中用 CanvasLayer.layer 保持相同的相对顺序。
- 字体：标题与印字用楷体（`'KaiTi','STKaiti',serif`），正文用系统无衬线体；移植时请指定一款中文楷体与一款黑体。

## 5 ink 剧本（`story/01-开始/`，由 `tools_story/build_ink.cjs` 编译成 `js/story-data/*.js`，每个 ink 文件生成一个 js，其中的 knot 存到 `STORY_DATA[knot]`）
- `人物-收礼与易物.ink`：knot `qh_gift_line`、`qh_trade_line`，变量为 pid、kind、why、who；编译为 `qh_gift_line.js`，由 `QiheGift.lineFor` **按需**插入 `<script>` 加载，加载失败时气泡留空。
- `人物-收礼与易物-补.ink`：`qh_gift_line_more`、`qh_trade_line_more`，同样按需加载。
- `人物-易物开口.ink`：`qh_trade_hero`。
- `人物-失手.ink`：`<id>_steal_caught`，共 23 人（ye、aunt、chen、elder、innkeeper、ashuan、apothecary、aide、bailiff、retainer、bandit、xulingyi、censhuang、shenyanhui、luheng、zhouyan、song、fortune、boatman、peddler、aqi、atan、xiaohe），编译为 `ye_steal_caught.js`。
- `人物-门派不睦.ink`：`npc_<id>_faction_no`，只有 aide、bailiff、retainer、bandit 四人有；其他人的门派灰印点击后没有台词（npc-core 会先检查 `STORY_DATA[k]` 是否存在）。播放用 `QiheChapter.play`。
- 谈、托两枚印调用的是各 NPC 原有的对话 act（见 06）。

## 7 已知原版怪行为（一比一时保留）
- 偷窃中的 target.lv 读的是原始 `battle.lv`；没有 diff 的物品不会被过滤（13）。
- `priceMul` 取各项最大值，任意一项涨价都会盖掉折扣；`IMPLICATE_DEFAULT` 没有被使用，非 hostile_win 的个人关系变化不会牵连主事（16）。
- 05、13 两份文件略超 4000 字。
