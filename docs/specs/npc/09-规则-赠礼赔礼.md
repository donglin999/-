## 4. 判定 `judge(p,id)`（times＝已送该物品次数）
1. `hostile` 或档为仇视 → `{kind:'hostile',score:0,keep:true}`。
2. 类别在 no，或 `noHeavy` 且 tier=3 → `kind = score<0 ? 'amend-no' : 'no'`，`why='no'|'heavy'`，keep。
3. 赔礼（score<0）且既非喜好又非厚礼 → `amend-no`，`why:'cheap'`，keep。
4. `s = TIER_SCORE[tier] × (xi?2 : ke?1 : 0)`；ke 且 tier3 且有 heavyBonus 再 `+heavyBonus`。
5. `decay = times 0→1, 1→0.5, ≥2→0`；`s=round(s*decay)`（JS Math.round，.5 向上）。
6. `kind = amends?'amend-ok' : times>=2?'again' : xi?'xi' : ke?'ke' : 'meh'`；`keep = (kind==='again')`（重复第三次退回不扣）。

示例：给叶蘅野草药（药材喜，tier1）：首次 2×2=4，第二次 2，第三起 again 退回。

## 5. 送出 `give(p,id)`
1. 非 keep：`S.bag[id]--`（0 删除），`given[p][id]++`。
2. 已知态度更新：xi 或（amend-ok 且 xi）→ `'xi'`；no 或（amend-no 且 why=no）→ `'no'`；否则若非 keep 且未知 → `ke?'ke':'meh'`。`firstKnown`＝首次得知 xi/no 时返回类别名。
3. `score>0` → `bond.add(p.id, score, {amends, reason: amends?'amends':'gift'})`（赔礼最多回到 0；正向受 49/19 上限）。
4. 回赠：非 keep、`after>=20`、未回赠过、非 noReturn → `returnGift`：挑 bag 里第一件 `ret` 且合格的，否则第一件合格的（合格：有 id、类别缺省或“普”、非银两、非任务用具、ITEMS 有、`when/until` 生效）；`S.bag[id]+=1`，`returned[p]=true`。
5. 存档。返回 `{...judge, id, name, before, after, stageBefore, stage, firstKnown, returned}`。

## 6. 预告 `preview(p,id)`
只有该类别已知为 xi 且不会被退回时才显示：赔礼 `"{档} {分} → 约 {min(0,分+s)}"`，否则 `"送了好感约 ＋{s}"`。

## 7. 提示 `hint(p)`
- score<0：仇视“要请中人说和”，否则“赔礼最多回到 0（初识）”。
- special、未解锁、score≥19 且有 UNLOCK_HINT → `再要熟络：` + 提示：ye 去药棚帮她分一回药｜luheng 跟他修一辆车、认一回路｜xulingyi 替她把那封拜帖送到陈伯那里问一句｜censhuang 替她去药商那里对一回旧货账｜shenyanhui 替她把采办单的三篓药对清｜song 替他把进村的人说一回。

## 8. 关系能换来什么 `perks(p)`（礼卷右侧表）
verbs＝[trade 易物, teach 请教, 可切磋 切磋]。
- 初识（min 0）：有 verbs → `照常跟他{verbs 顿号连}`；否则 `照常收礼、托事`。
- 熟络（20）：trade → `易物九折`；barter → `肯拿身上的东西跟你换`。
- 熟络（20）：非 noReturn → `他回赠一件随身带的东西（只一次）`。
- 冷淡（−19～−1）：[trade 易物贵两成, teach 不肯指点你] 逗号连，空则 `收礼照常，话少了`。
- 厌恶（−49～−20）：[trade 不跟你换东西, 可切磋 不切磋, 也不托你办事] 顿号连，“、也”换成“，也”。
