# 05 触屏方向键 #tpad、交互提示 #prompt、按键说明与全局键位

源文件：`index.html`（`#tpad` DOM 与样式、`#prompt` 样式、`.hint`、`@media (pointer:coarse)`）、`js/main.js`（键盘/指针输入、`#tpad` 按钮绑定）、`js/scene.js`（`updateScene` 末尾的 prompt 刷新、`setPath`、`interact`/`takeExit` 隐藏 prompt）、`js/battle.js`（开战隐藏 tpad）、`js/qh-mode-cultivation.js`、`js/qihe-hud.js`（`.qh-controls`）。

## 1. #tpad 结构

```
div#tpad.ui                         z-index:3
  div.dp                            3列×2行网格
    button#tu  ▲  aria=向上走   grid-column:2           （第1行中）
    button#tl  ◀  aria=向左走   grid-column:1; row:2
    button#td  ▼  aria=向下走   grid-column:2; row:2
    button#tr  ▶  aria=向右走   grid-column:3; row:2
  button#te  互  aria=互动      align-self:flex-end
```
即左下角“倒 T”方向键，右下角单个“互”键。

## 2. 何时出现

- 默认 `#tpad{display:none}`；仅 `@media (pointer:coarse)`（主指针为触摸：手机/平板）时 `display:flex`。桌面鼠标永不出现。
- 以下任一成立时强制隐藏（`display:none!important`）：对话 `#dlg` 可见；面板 `#panel` 可见（含标题页、江湖菜单）；`#mapui` 可见；`#hud` 隐藏（即 `mode≠'scene'` 或无存档，标题页亦然）。→ 只在**自由探索**画面出现。
- 战斗：`battle.js` 开战时 `tp.style.display='none'`，结束后恢复原内联值。
- 培养模式：进入时 `#tpad.hidden=true`，且代码中**没有任何地方再改回 false** → 一旦进入过培养模式，本次页面会话内触屏方向键不再出现（原版行为；Godot 若要“一比一”应复刻，否则建议改为离开培养模式时恢复，并在差异表注明）。

Godot：`TouchPad` 节点 `visible = is_touch_device && mode==SCENE && !dialog.visible && !panel.visible && !map_ui.visible && !touchpad_disabled_by_cultivation`。触屏判定可用 `DisplayServer.is_touchscreen_available()` 且平台为 Android/iOS。

## 3. 布局与样式（UI 缩放前数值，em 以 17px 计）

- `#tpad`：`position:absolute; bottom:4%; left:2%; right:2%; display:flex; justify-content:space-between; align-items:center; gap:.4em; pointer-events:none`（容器不吃点击，只有按钮吃）。
- `#tpad .dp`：`display:grid; grid-template-columns:repeat(3, max(44px,3.4em)); grid-template-rows:repeat(2, max(44px,3.4em)); gap:.2em`。3.4em=57.8px，≥44 → 每格 57.8px，间距 3.4px；方向键区总宽 57.8×3+3.4×2=180.2px，高 119px。
- `#tpad button`：`pointer-events:auto; width/height:max(44px,3.4em); font-size:1.05em; opacity:.75; border-radius:50%`（圆形）；`padding:0; background:rgba(20,15,11,.7); touch-action:none`；边框与内阴影沿用通用按钮（1px `#6e5a3e`、inset 2px `rgba(0,0,0,.45)` + inset 3px `rgba(163,138,94,.15)`）；文字色 `#e9dcc0`。
  - 按下 `:active`：`opacity:1; background:#4a3a28; border-color:var(--gold)#e0bf78`。
- `#tpad #te`：`font-family:var(--serif); margin-left:.6em`；`align-self:flex-end` → 与方向键底边对齐（位于右下角，右距 2%）。
- 整个 #tpad 受 UI 缩放（01 §6），上述 px 都会再乘 zoom。

## 4. 触屏行为（main.js）

- 方向键：`pointerdown` → `keys[方向]=1`；`pointerup` 与 `pointerleave` → `keys[方向]=0`。可同时按多个（斜走）。方向键本身不会触发跑步：`keys.run` 只由键盘双击设定，触屏又按不到 Shift，所以触屏用方向键只能步行，要跑只能靠点地寻路（§4 自动跑规则）。
- 互动键 `#te`：`click` → `interact()`（与 E 键同）。
- 画布点击（触屏与鼠标共用 `pointerdown`，只在 `mode==='scene' && !busy && !dlgBusy && 面板关闭`）：
  - 点中 NPC（命中盒：有精灵的 NPC 半宽 `max(20, h×.28)`，资源点 32，其余 24；纵向 `p.y−h < y < p.y+10`）：距离主角 <80px 直接交谈；否则寻路到 NPC 旁（候选点：靠近主角一侧 `off=max(34, h×.4)`（无精灵 20），然后另一侧、下方 `off×.8`、上方 `off×.6`，都不行则 `(p.x, p.y+40)`），到达后自动交谈。
  - 点地面：寻路。双击（两次间隔 <320ms 且距离 <60 画面像素）强制跑；触屏单击时路径长 >`RUN_PATH_TOUCH=5×40=200px` 自动跑，鼠标为 `RUN_PATH=8×40=320px`。
- 跑步速度：`SPEED=.27` px/ms，`RUN_MUL=1.88`（移动规格见场景册）。

## 5. 交互提示 #prompt

- 刷新（scene.js `updateScene` 末，每个固定步）：非冻结状态下，若站在出口格则直接 `takeExit`；否则取最近可交互对象 `nearest()`：
  - 同伴：`<kbd>E</kbd> 交谈 · {同伴名}`
  - 其他：`<kbd>E</kbd> {o.verb || '交谈'} · {o.name}`（如“E 进门 · 陈伯家”）
  - 无对象则隐藏。文本未变不重写（避免重复播入场动画）。
- 交互开始 / 走出口时立即隐藏。对话或面板打开时 CSS 强制隐藏。
- 样式：`.ui.frame`（01 §5 描边框）+ `bottom:5%; left:50%; width:max-content; transform:translateX(-50%); padding:.4em 1.3em .4em .8em; color:var(--paper); white-space:nowrap; font-family:var(--serif); letter-spacing:.12em; pointer-events:none`。
- 出现动画 `pin .22s ease-out`：从 `opacity:0; translate(-50%, .4em)` 上浮到位（每次从隐藏变可见时播放）。
- 触屏（pointer:coarse）：`#prompt kbd{display:none}`（不显示 E 键帽），位置改为 `bottom:auto; top:13%`（移到上方，避开方向键）。

## 6. 按键说明

- 页面底部 `.hint`（#game 外）：“WASD / 方向键 行走 · E / 空格 互动 · 点击地面寻路、点击人物交谈 · I 打开江湖菜单 · Esc 关闭”；`color:var(--faint)#6d5f4b; font-size:12px; margin-top:6px; text-align:center; letter-spacing:.05em`。栖河 HUD 出现后（`body:has(#hud.qh-hud)`）隐藏；触屏或窗口高 ≤460px 也隐藏。Godot 可省略。
- HUD 左下 `.qh-controls`：“WASD 移动 · Shift 走跑 · E 交谈 · M 地图”；`left:2.5%; bottom:3%; font-size:11px; color:#e5d8b9; background:#121b167a; padding:4px 9px; letter-spacing:.08em`，分隔点左右 5px 内边距；对话时隐藏（HUD 其余部分另册）。
- 进入游戏 toast：“WASD / 方向键移动 · Shift 切换走跑 · E 交谈或进门 · I 江湖 · J 行程”（2600ms）。

## 7. 全局键位表（探索层，`e.key` 小写比较；焦点在输入框时忽略）

| 键 | 条件 | 作用 | 源 |
|---|---|---|---|
| W/A/S/D、方向键 | `mode==='scene'` | 按下置 `keys[dir]=1`，松开置 0；`preventDefault` | main.js |
| 同一方向键 280ms 内按两次 | 同上，非长按重复 | `keys.run=1`，直到四个方向全部松开 | main.js |
| Shift | scene、非 busy/dlgBusy、面板关 | 切换步行/跑步常驻开关 `walkRunToggle`；toast“步法：跑步/步法：步行”850ms | main.js |
| E、空格 | scene、非 dlgBusy、面板关 | `interact()` | main.js |
| I | scene、非 dlgBusy/busy、非长按 | 面板为菜单则关闭，面板关则打开江湖菜单 | main.js |
| J | scene、非 busy/dlgBusy、面板关、无修饰键 | 行程（02 §6） | qihe-menu.js |
| M | 见 04 §3 | 探索=小地图，其他=静音 | qihe-navigation.js / audio.js |
| Esc | 面板开且可关、非 dlgBusy | `closePanel()`；地图开时关地图 | ui.js / qihe-navigation.js |
| 1~9 / Esc | 对话选项中 | 直接选第 n 项 / 选“取消”项 | ui.js（对话册） |
| B/K/L | HUD 按钮提示键（行囊/武学/行记），处理见菜单册 | | qihe-hud.js |

窗口失焦（`blur`）：清空所有 `keys`，`walkRunToggle=false`。
