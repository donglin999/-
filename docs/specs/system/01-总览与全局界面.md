## 2. 页面与游戏区尺寸

- `body`：`margin:0; background:var(--ink)=#0d0a08; color:var(--paper)=#e9dcc0; font-family:var(--sans); display:flex; flex-direction:column; align-items:center; justify-content:center; padding:8px 16px; overflow:hidden; -webkit-font-smoothing:antialiased`。
- `#game`：`position:relative; width:min(100%, calc((100vh - 36px)*16/9)); aspect-ratio:16/9; max-width:100%; background:#000; box-shadow:0 0 0 1px #2a2119, 0 0 40px rgba(0,0,0,.7); user-select:none; container-type:inline-size; overflow:hidden`。即：16:9 信箱，按“宽度不超出窗口、高度不超过 视口高−36px”取较小者，水平垂直居中。
- `@media (max-height:460px)`：`body{padding:4px 8px}`，`.hint{display:none}`，`#game{width:min(100%,calc((100vh - 8px)*16/9))}`。
- `.ui{position:absolute; font-size:17px; letter-spacing:.04em; line-height:1.5}`——所有界面层的基准字号 17px。
- `#cv{position:absolute; inset:0; width:100%; height:100%}`。

Godot 对应建议：窗口 stretch 模式 `canvas_items`/aspect `keep`，16:9；画面逻辑坐标 960×540；UI 层另按“1280 宽设计”缩放（见 §6）。

## 3. 画布逻辑分辨率（core.js `fitCanvas`，main.js `frame`）

- 常量 `W=960, H=540, GROUND=470`。
- 每帧 `fitCanvas()`：`w=round(cssWidth*devicePixelRatio)`，`PXS=w/960`，`h=round(540*PXS)`；尺寸变化才重设 canvas 大小；`setTransform(PXS,0,0,PXS,0,0)`；`imageSmoothingEnabled=false`（像素画最近邻）。
- 主循环 `frame(t)`（requestAnimationFrame）：
  - `mode==='title'||'end'`：`drawBg('bg_title')` 再 `vignette()`（标题背景，见 03）。
  - `mode==='scene'`：固定步长 `SCENE_STEP=1000/60` ms 推进 `updateScene`，单帧累计上限 250ms；页面隐藏时 elapsed 记 0；然后 `drawScene(t)`，并把 `player.x/y` 写回 `S.x/S.y`。
  - `visibilitychange`：重置 `last` 与累计时间（回到页面不补走）。

## 4. 字体（index.html 第 10 行 Google Fonts）

加载：`ZCOOL XiaoWei`、`Noto Sans SC` 400/500/700、`Noto Serif SC` 500/700，`display=swap`。

| 变量 | 字体栈 | 用途 |
|---|---|---|
| `--sans` | "Noto Sans SC","PingFang SC","Microsoft YaHei","Hiragino Sans GB",sans-serif | 默认正文、按键帽 |
| `--serif` | "Noto Serif SC","Songti SC","STSong",serif | 提示、toast、对话、按钮标签 |
| `--brush` | "ZCOOL XiaoWei","Noto Serif SC",serif | 标题“小江湖”、地名大字、载入层标题 |

Godot：把三种字体打包进工程（ZCOOL XiaoWei、Noto Sans SC Regular/Medium/Bold、Noto Serif SC Medium/Bold），建三个 FontVariation 对应 sans/serif/brush。

## 6. UI 等比缩放（js/ui-scale.js）

- 常量：`BASE=1280, MIN=.62, MAX=2.4`。
- `zoom = clamp(#game 实际 CSS 宽度 / 1280, .62, 2.4)`，保留 4 位小数，写入 `#game` 的 CSS 变量 `--ui-zoom`；用 ResizeObserver（无则 window resize）在游戏区尺寸变化时重算。
- 作用范围（index.html 末尾）：
  - `#game > :not(#cv):not(#cultivation):not(#fade):not(#loading):not(#panel):not(#bt):not(#prologue-cg):not(.qh-fire-cg) { zoom: var(--ui-zoom) }`——即 #place、#hud、#prompt、#tpad、#dlg、#mapui、#toast、#sndbtn 等整体缩放。
  - `#panel` 本身不缩放（全屏铺满），而 `#game > #panel > *` 的每个子块缩放（标题页 `.tt` 因此被缩放）。
  - 不缩放：画布、黑场 #fade、载入层 #loading、战斗层 #bt、培养模式 #cultivation、全屏 CG。
- Godot 实现：UI 根 Control 的 `scale = zoom`（或用一个 1280×720 参考尺寸的 SubViewport/Control 树），所有 px/em 数值按“游戏区宽 1280 时”的数值做；em 以 17px 计。

## 7. 容器查询与指针类型

- `@container (max-width:760px)`（以 #game 宽为准）：标题 `.tt .logo{font-size:4em}`、`.tt .menu{margin-top:1.6em}`；对话框等其他条目见对话规格。
- `@media (pointer:coarse)`（触屏）：见 05。
- `@media (prefers-reduced-motion:reduce)`：`#fade,#place,#toast` 去掉 transition；`.tt *` 等去掉动画。Godot 可做成设置项“减少动态”。
