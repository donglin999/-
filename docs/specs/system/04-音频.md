## 2. 音量

- 总线基准 `VOL = {bgm:.25, amb:.35, sfx:.5}`。
- 音效单条增益 `GAIN = {blip:.35, advance:.6, select:.7, menu_open:.6, menu_close:.6, chime:.7, whoosh:.35, coin:.8}`，未列出为 1。
- 音效最终线性音量 `= clamp(.5 × GAIN[name] × vol参数, 0, 1)`；`playbackRate = rate`，且 `preservesPitch=false`（变速即变调）。Godot：`AudioStreamPlayer.volume_db = linear_to_db(v)`，`pitch_scale = rate`。
- BGM 最终音量 `= clamp(.25 × level × gain × edge, 0, 1)`（见 §4）。

## 3. 开声条件与静音

- **首次用户手势前完全无声**：`started=false`，在 window 捕获阶段监听 `pointerdown`/`keydown`/`touchstart`，任一发生即 `started=true`。Godot 桌面可直接视为已开始；如需一致，第一次输入前不播放。
- 页面隐藏（`document.hidden`）：暂停 BGM 与所有音效；音效调用直接忽略。回到前台 BGM 从暂停处以 `level` 0 重新淡入。
- 静音状态 `muted` 初值读 `localStorage['xjh.mute']==='1'`。`setMute(m)`：写回 `'1'/'0'`；刷新声音按钮；静音时停止配音、暂停 BGM（level 置 0）与全部音效；取消静音时同时视为开声手势。
- 切换入口：① **M 键**（keydown、非长按重复、焦点不在 INPUT/TEXTAREA）；② 设置页“声音”按钮（命令 `setMute`，文案“已静音/已开启”）；③ 培养模式设置里的声音项；④ 声音按钮 `#sndbtn`（见 §7，栖河版实际不可见）。
- **M 键冲突（须复刻）**：`qihe-navigation.js` 在 window 捕获阶段监听 M，条件 `S && mode==='scene' && !busy && !dlgBusy && 面板关闭 && 无覆盖层` 成立时切换小地图并 `stopImmediatePropagation`，静音处理不会执行。所以：**自由探索时 M=地图；标题页、对话中、面板打开、战斗中 M=静音开关**。Esc 在地图打开时关闭地图。

## 4. BGM 播放器（栖河版 `MusicLoop`，每帧 `tick(dt)`，dt 秒，上限 .1）

- 每首曲目一个独立循环播放器（`loop=true`），按名缓存复用；**切走时只暂停不归零**，切回同曲从原位置继续。战斗曲每场新战斗例外：`restart` 归零。
- 状态：`name`（目标曲）、`playingName`（在放曲）、`level`（0~1 淡入淡出包络）、`gain`（压低系数）。
- 每帧逻辑：
  1. 未开声 / 静音 / 页面隐藏 → 暂停全部，`level=0`，结束。
  2. 若 `name ≠ playingName`（换曲或变静音）：`level -= dt / T_out`，`T_out = 目标名含 'battle' ? 0.6s : 0.8s`；旧曲按新 level 设音量；level 未到 0 则本帧结束；到 0 后暂停旧曲，`playingName = name`。目标在淡出中途再变，以最新目标为准。
  3. 若 `playingName` 为空或该曲加载失败 → 结束（静默）。
  4. 淡入：`level += dt / T_in`，`T_in = 曲名含 'battle' ? 0.2s : 1.2s`，封顶 1。
  5. 接缝包络 `edge = clamp(min(t/0.06, (dur−t)/0.06), 0, 1)`（t 为当前播放秒数）：每次循环首尾各 60ms 线性渐变，掩盖循环爆音。
  6. 音量 = `.25 × level × gain × edge`；若处于暂停则调用播放。
- 线性包络：淡出 0.8s/0.6s，淡入 1.2s/0.2s。即“探索→战斗”= 0.6s 淡出 + 0.2s 淡入；“战斗→探索”= 0.8s 淡出 + 1.2s 淡入。

### 压低（ducking）
每帧目标 `targetGain = (曲目 gain 或 1) × k`，`k = 配音播放中 ? 0.5 : (对话框 #dlg 可见 或 面板 #panel 可见) ? 0.708 : 1`。`gain` 以每秒 3 的速度线性逼近目标（`±dt×3`）。

## 5. BGM 选择规则（`qiheSoundscape(mode, sceneId, S, B)`，每帧求值）

按顺序：
1. `mode==='battle'`：无战斗对象，或该战斗已结算（`battleLoop` 结束后记为 `settledBattle`）→ 无曲（结算画面期间静音淡出）。若是新战斗对象 → 战斗曲归零重播。曲目 `bgm_qh_battle_v2`；战斗背景 `bb_qh_training_v1`（训练战）时曲目 gain=0.8，否则 1。
2. `mode==='cultivation'` → `bgm_qh_cultivation_v5_short`。
3. 其他非 `scene` 模式（含 **标题页 `title`**、`end`）→ 无曲。**标题页无音乐**。
4. `scene`：`stage = S.qiheChapter.stage`
   - 场景 `qh_mountain` 且 `stage==='cultivation'` → 培养曲；
   - `S.prologue.ending` 为真，或 `stage ∈ {fire, escape, refuge, mountain, ended}` → 无曲（剧情段落静场）；
   - 场景 id 以 `qihe_` / `qh_` / `prologue_` 开头 → `bgm_qh_daily_v2`；
   - 其他 → 无曲。
场景切换黑场期间 mode 仍是 scene，所以同曲不中断。

## 6. 音效触发点

**全局（audio.js 包裹全局函数，自动触发）**
| 事件 | 音效 | 细节 |
|---|---|---|
| 对话打字 `say` | `blip`，rate 0.95~1.10 随机 | 每 45ms 查一次已显示字数 L（上次为 n）：`L>n+1` 或（`L>n` 且 n 为偶数）时响一声 → 约每 2 字一声；若该句有配音则不响 |
| 对话推进（`say` 结束） | `advance` | |
| 选项确定（`choose` 结束） | `select` | |
| `toast` 调用 | `chime` | 文案以“购得”开头除外；**在调用时响**，不等排队显示 |
| `openPanel`（面板原先关闭） | `menu_open` | 标题页打开时亦触发 |
| `closePanel`（面板原先打开） | `menu_close` | |
| `fade` 黑场开始 | `whoosh` | 仅 `mode==='scene'`；同时停止配音 |
| 银两减少 | `coin` | 每帧比较 `S.silver`，变小即响 |

**战斗/菜单（显式调用，参数为 `(名, vol, rate)`）**：开战 `whoosh`；胜利 `chime`（大字“胜”前）；结算有银两 `coin`、关闭结算 `select`；光标移动 `blip,.6`；确定 `select`；不可选 `menu_close,.5`；返回 `menu_close,.6`；蓄势档位变化 `select,.6,1+n×.15`；蓄势发动 `chime,.6,1+bp×.1`；回气 `chime,.5`；敌蓄力 `whoosh,.8,.7`；破势 `whoosh,1,.6`；受击 `advance,.9,.7~.9`；冲刺 `whoosh,.45,1.35`；棍击 `staff_hit_20261010` 重击 `1.05,1`/轻击 `.65,1.15`；飞针 `needle_release_20261012,.45`；破势特写 `whoosh,.8,1.4` 与 `advance,.9,.5`；门派对决刀中 `clash_blade_hit_20261012,.6`、传气 `clash_qi_transfer_20261012,.55`、鞭 `whoosh` 甲 `.8,1.9`/否 `.55,2.2`；逃跑成功 `whoosh`；精进界面 `chime,.6,1.2`；服药 `chime,.5`。具体时序见战斗册。

**音效池**：每个音效名最多 4 个播放器；优先复用已停的，满 4 个时抢占第 1 个并从头播。Godot：每名一个 `AudioStreamPlayer` 池（max_polyphony=4 亦可）。
