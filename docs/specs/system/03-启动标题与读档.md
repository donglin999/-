# 03 启动流程、载入层、标题页与选档、读档恢复

源文件：`js/main.js`（末段启动、`startupError`、`frame`）、`js/core.js`（`loadAll` 看门狗、`ensureSceneAssets`、`drawBg` `vignette`）、`js/qihe-startup.js`（`QiheEntry`：`runs` `description` `url` `newJourneyURL` `render` `start`）、`js/qihe-startup.css`、`index.html`（`.tt` 系列样式）、`js/qihe-map-trial.js`（`start` 即 `qiheTrialStart`）、`js/qihe-cultivation-bridge.js`（包裹 `qiheTrialStart`）、`js/qihe-milestones.js`（`latest`）。

## 1. 启动时序

1. 页面载入，`#loading` 默认可见（见 06 §4 样式）。`mode='title'`（ui.js 初值）。
2. `loadAll(p => #lbar.style.width = p*100+'%')`：基础素材并行加载，每完成一项进度条前进（宽度过渡 .2s）。地图 `m_*`、立绘 `p_*` 不挡进度条，后台排队。
3. **看门狗**：每 1000ms 检查一次；距上次进度 >15000ms 或总时长 >25000ms，就不再等待，直接进入下一步（其余素材后台继续，下完后重切图）。
4. 加载完成（或看门狗放行）→ `QiheEntry.start()`；随后（以及兜底 `setTimeout 1500ms`）开始后台下载地图 `loadDeferredInBackground`。
5. 在下一个动画帧先 `frame(t)` 画出首帧（标题背景或场景），再下一帧把 `#loading.hidden=true`——保证撤下载入层时画布已有内容，不露黑屏。没有淡出，是直接消失。
6. 出错 `startupError`：载入层重新显示，最后一行文字改为“画卷未能载入，请刷新重试。”，追加按钮【重新载入】（点击整页重载）。
7. 切换场景时若目标地图未到：500ms 后仍未到则 `toast('载入地图中……',1600)`，并等待下载完再进入黑场。

Godot：用一个 Boot 场景，ResourceLoader.load_threaded_request 预载，进度条同样映射；看门狗 15s/25s 可保留；首帧画好后再隐藏 Loading 节点。

## 2. 进入哪个画面（`QiheEntry.start`）

- URL 无 `play=1` → 显示标题页 `render()`。
- `play=1`：读当前旅程键（02 §1）的原始字符串：
  - 不存在 → 新开局（`qiheTrialStart()`）；
  - 存在且有效 → 读档继续（`qiheTrialStart()`）；
  - 存在但无效 → 显示标题页，并 `toast('这份进度暂时无法读取，原记录已保留。可开始新旅程。',3200)`（不删除原记录）。

Godot 等价：标题页按钮直接设置 `current_journey_key` 后调用“开始游戏”，无需 URL；“返回首页”即回到标题场景。原版的跳转 URL 形如 `index.html?v=qihe-saves-20261006&journey=<id>&play=1#qihe-map`（原有旅程不带 journey），返回首页为 `...?v=qihe-saves-20261006[&journey=<id>]#qihe-map`。

## 3. 标题页（`render`）

**状态**：`mode='title'; busy=false; keys={}`；`#hud.hidden=true`（于是 #tpad 也隐藏）；窗口标题“小江湖 · 栖河试玩 · 四向地图版”；`openPanel('plain')` 并加 class `qihe-startup`；`panelClose=null`（Esc 不能关闭）。声音按钮因面板打开被隐藏（04 §7），M 键仍可静音。打开面板会触发 `menu_open` 音效，但首次手势前无声（04）。

**背景（画布，main.js `frame`）**：`mode==='title'` 每帧 `drawBg('bg_title')` 把 `assets/production/shared/bg_title.webp`（回退 `assets/bg_title.webp`）拉伸铺满 960×540；缺图填 `#1d1812`。再画暗角 `vignette()`：径向渐变圆心 (480,270)，内半径 189（H×.35）透明，外半径 513（H×.95）为 `rgba(0,0,0,.55)`，铺满全屏。

**面板层**：`.panel.plain` 透明无模糊，`inset:0; z-index:4`。其子块 `.tt` 受 UI 缩放（01 §6）。

**DOM**：

## 4. 选档列表（`runs`）

候选键依次为：[有 journey 参数时为当前键，否则为 `xjh.qihe-prologue.latest.v1` 指向的键]、当前键、`xjh.qihe-prologue.v2`；去重后逐个 `read`，丢弃不存在/无效/在回收站的。标题页无 journey 参数时，实际最多两项：“最近写入的旅程”和“原有旅程”。

按钮文字：第 0 项“继续进度”；其余若是原始键“继续原有进度”，否则“继续另一旅程”。小字描述 `description(s) = (QiheMilestones.latest(s) || '初到栖河') + ' · ' + SC[s.scene].name`。`latest` 取已达成“江湖经历”列表最后一条标题，按顺序判定：后山遇狼 → 栖河第一夜 → 正道盟上门要谱 → 玉匣与药样 → 栖河起火 → 护送乡邻离村 → 对证三张附页 → 山居安身（判定条件见剧情册 `qihe-milestones.js`）。

点击：“从头开始”→新建旅程 id（02 §1）并以空存档进入（=新开局，旧进度不动）；“继续…”→进入该旅程。无键盘上下导航的特别处理，靠浏览器 Tab/焦点；Godot 应支持 ↑↓ 切换焦点、Enter/空格确认。

## 5. 读档恢复流程（`qiheTrialStart` = qihe-map-trial.js `start(force=false)`）

1. `old = force ? null : loadSave()`；`S = (old.prologue.version===2 && SC[old.scene]) ? old : newState()`；`S.name='萧白'`。
2. 新开局：`S.prologue = fresh()`（`{version:2, errands:{bowls/cloth/medicine:'none'}, carry:{}, heard:{}, relicSeen:false, rested:false, ending:false, yeHousePermission:false, arrival:{version:1, stage:'encounter', borrowed:false, originExpression:null, dogResult:null, greeted:{}}}`）；`scene='prologue_backhill'; party=[]; pet=null; unlocked={}`；`hp/mp` 取派生上限。
3. `mode='scene'`；`cur=SC[S.scene] || SC.qihe_trial`；`buildGrid(cur)`。
4. 主角位置：读档且 `S.x/S.y` 为有限数 → 用存档像素坐标；否则 `cur.start × TS`。重置 `dir:'d', vx/vy:0, path/goal/talkTo:null, trail:[], anim:null, alpha:1`；`keys={}`；关闭面板。
5. `spawnWanderers()`；`snapCam()`（镜头直接对准，无平移）；夜间色调 `cur.dark = prologue.rested ? 'rgba(13,22,32,.32)' : null`。
6. `hud()`；`placeName(cur.name)`（地名大字，06 §2）。
7. 绑定问候 `PrologueArrival.bindGreetings()`；`QiheChapter.restoreScene()`（章节场景状态还原）；`checkpoint()`（立即存一次）。
8. 分支：后山开场未完成 → 播放开场 `PrologueArrival.play()`；`prologue.ending` → `busy=true` 播放过夜 `rest(true)`（失败 toast“过夜片段未完成，回客房可继续。”）；否则 `toast('WASD / 方向键移动 · Shift 切换走跑 · E 交谈或进门 · I 江湖 · J 行程', 2600)`。
9. 外层包裹（cultivation-bridge）：上述完成后若 `S.qiheChapter.stage==='cultivation'` → 进入培养模式界面。

注意：读档不走 `goScene`，因此**没有黑场淡入**，载入层撤下后直接是场景首帧 + 地名大字淡入。
