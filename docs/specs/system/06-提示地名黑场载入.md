# 06 toast / placeName / fade / loading / 写档警示 的样式与时序

源文件：`js/core.js`（`fade` `placeName` `toastQueue` `showNextToast` `toast` `showSaveWarning`）、`index.html`（`#toast` `#place` `#fade` `#loading` `.bar` 样式与 DOM、`prefers-reduced-motion`）、`js/main.js`（`startupError`）、`js/audio.js`（对 `toast`/`fade` 的音效包裹）、`js/scene.js`（`goScene`）。

所有数值为 UI 缩放前（`.ui` 基准 17px）；#toast、#place 受 `--ui-zoom` 缩放，#fade、#loading 不缩放（01 §6）。

## 1. toast 浮动提示

**调用** `toast(text, ms=1400)`：入队 `[String(text), max(0, Number(ms)||0)]`；若当前无提示在显示则立刻显示队首。**立即返回已完成的 Promise**——剧情不等待提示。音效：调用瞬间响 `chime`（文案以“购得”开头除外，04 §6），即连发 3 条会立刻连响 3 声、但文字排队依次出现。

**显示序列**（`showNextToast`）：
1. 取队首，写入 `#toast.textContent`，加 class `on`。
2. 停留 `ms` 毫秒后去掉 `on`（开始 0.35s 淡出）。
3. 再过 180ms 显示下一条；队列空则标记空闲。
→ 每条占用 `ms + 180`ms；下一条在上一条淡出开始 180ms 后就开始淡入，两者有约 170ms 交叠（同一节点，实际是文字瞬间替换后重新淡入：替换发生时上一条已淡出约一半）。Godot：用单个 Label + Tween，替换文字时 alpha 从当前值继续升到 1 即可还原观感。

**样式** `#toast`：
- 位置：`top:17%; left:50%; transform:translate(-50%, -.6em)`（隐藏态上移 .6em）；`z-index:8`；`pointer-events:none`；`white-space:nowrap`（单行，不换行）。
- 文字：`font-family:var(--serif); font-size:1.05em`(17.85px)`; letter-spacing:.2em; color:var(--hi)#f3d58e`。
- 内边距 `.45em 2.4em`。
- 背景：横向渐变 `linear-gradient(90deg, transparent, rgba(16,12,9,.92) 18%, rgba(16,12,9,.92) 82%, transparent)`——两端各 18% 渐隐的深色条。
- 上下边线：各 1px，`border-image: linear-gradient(90deg, transparent, var(--bz2)#a38a5e, transparent) 1`（中间亮、两端透明）；无左右边。
- 动画：`opacity:0 → 1`，`transform: translate(-50%,-.6em) → translate(-50%,0)`，`transition: opacity .35s, transform .35s`（浏览器默认 ease）。即“自上方 10px 处下落淡入”，消失时反向上浮淡出。
- 场景覆盖：商店面板（`#panel.shopx`）打开时 `top:3.2%`；江湖行卷某些页（`#panel.qj .qjc`）打开时 `top:auto; bottom:36px; max-width:90%; font-size:14px; white-space:normal`；悟性分配表单打开时隐藏。

常见调用时长：默认 1400；步法 850；进度已保存 1200；进入游戏说明 2600；历练 2400；新任务 3000；读档失败 3200；载入地图 1600。

## 2. placeName 地名大字

**调用** `placeName(t)`：写文本、加 `on`，2200ms 后去掉 `on`。不排队；短时间内重复调用会叠加多个计时器（前一个计时器会提前移走新文字的 `on`）——Godot 复刻时用“最后一次调用后 2200ms 隐藏”更稳，观感一致。

**触发**：`goScene` 黑场结束、入场走动完成后（§3 时序）；读档/开局 `start()` 中（03 §5）。

**样式** `#place`：
- `top:22%; left:50%; transform:translate(-50%,-50%)`；`pointer-events:none; white-space:nowrap`。
- 竖排 flex：`display:flex; flex-direction:column; align-items:center; gap:.2em`。
- 文字：`font-family:var(--brush)`(ZCOOL XiaoWei)`; font-size:40px; letter-spacing:.35em; color:var(--paper)#e9dcc0; text-shadow:0 2px 10px #000, 0 0 3px #000`。
- 上下装饰线（`::before` 上、`::after` 下）：`width:9em; height:1px; font-size:.6em` → 宽 9×24=216px；`background:linear-gradient(90deg, transparent, var(--gold)#e0bf78, transparent)`。
- 显隐：`opacity:0 ↔ 1`，`transition:opacity .9s`。总观感：0.9s 淡入 → 保持 → 2200ms 时开始 0.9s 淡出（完全消失约在 3.1s）。
- 注：`letter-spacing` 会在末字后多留 .35em，使文字视觉略偏左；Godot 用居中 Label 时可加等量左侧偏移或忽略。

## 3. fade 黑场

**调用** `await fade(fn)`：
1. `#fade` 加 `on`（0.45s 变黑）；同时停止配音，若 `mode==='scene'` 响 `whoosh`。
2. 等 460ms（全黑）。
3. `await fn()`（在全黑中换场景、放主角、存档）。
4. 等 60ms。
5. 去掉 `on`（0.45s 变亮）。
6. 等 300ms 后 `fade` 返回（此时仍有约 150ms 淡出未完成；调用方的后续动作与淡出末段重叠）。

**样式** `#fade`：`inset:0; background:#000; opacity:0; pointer-events:none; transition:opacity .45s; z-index:9`。`pointer-events:none`——黑场期间点击会穿透（由 busy 状态挡住逻辑）。

**goScene 完整时序**（scene.js，供对照）：确保地图已载（未到 500ms 后 toast“载入地图中……”）→ `fade`：全黑时换 `cur`、建格、放主角于入口后方 `ENTER_WALK` 距离、`alpha=0`、镜头直接对准、`save()` → “入场走动” 520ms（alpha 0→1，向入口内走 `ENTER_WALK`）在全黑回调里就已启动，与随后 60ms 等待和 0.45s 淡出重叠→ 走完 `placeName(cur.name)`、`hud()` → 若场景有 `enter` 剧情则执行。出口 `takeExit`：先朝出口方向走 300ms 并淡出（alpha 1→0）再 `goScene`。

## 4. loading 载入层

**DOM**：
```
div#loading.ui
  div.title   style="font-size:2.4em;color:var(--paper);letter-spacing:.3em"  小江湖
  div.bar > i#lbar
  div         style="color:var(--dim);letter-spacing:.2em"                     载入画卷中……
```
**样式**：`#loading{inset:0; display:flex; flex-direction:column; align-items:center; justify-content:center; gap:.8em; background:#0b0907; z-index:10}`；`.title{font-family:var(--brush); font-weight:400}` → 标题 40.8px、字色 `#e9dcc0`；`.bar{width:36%; height:3px; background:#2b2118}`（宽为游戏区 36%，不缩放）；`.bar i{display:block; height:100%; background:var(--gold)#e0bf78; width:0; transition:width .2s}`；底行文字 17px、`#9c8b70`。
**时序**：进度 = 已完成数/总数（03 §1）；完成后首帧绘制、下一帧直接隐藏（无淡出）。失败：重新显示，底行改为“画卷未能载入，请刷新重试。”并追加通用样式按钮【重新载入】（位于底行之下，gap .8em）。

## 5. 写档失败警示 #save-warning

`showSaveWarning(e)`：e 为空 → 移除；否则创建（若无）`div#save-warning[role=alert]` 挂到 `body`：
`position:fixed; left:50%; top:12px; transform:translateX(-50%); z-index:90; max-width:min(92vw,560px); padding:8px 14px; background:rgba(80,24,20,.94); border:1px solid #e0a080; border-radius:6px; color:#fbe9dc; font-size:15px; line-height:1.5; pointer-events:none`。
文案：错误名或消息含 quota（不分大小写）→“进度未能保存：浏览器存储空间已满。腾出空间、下次保存成功前的进度可能丢失。”；否则“进度未能保存：{错误消息}。下次保存成功前的进度可能丢失。”。常驻、无动画，直到下一次写档成功被移除。Godot：写文件失败（`FileAccess` 返回 null 或磁盘满）时显示同样的顶部红条。

## 6. 减少动态

`prefers-reduced-motion:reduce`：#fade、#place、#toast 的 transition 取消（瞬时显隐），等待时间（460/60/300、2200、ms+180）不变。
