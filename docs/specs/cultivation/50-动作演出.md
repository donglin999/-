## 50.2 时间→帧 `loopPhase(elapsed, clip)`

```
ms = clip.durations; total = Σms; pos = ((elapsed % total)+total) % total
逐段扣减，落在第 i 段：frame = clip.order?.[i] ?? i，beat=i，mix = t/ms[i]
```
- elapsed：画框处于 `.cu-playing` 时 = `now - frame.dataset.startedAt`（与存档 `animation.startedAt` 同源）；否则用画布首次绘制时间 `_start`。
- 帧选择：减少动效 → 0；playing 或剧情框 → phase.frame；已播完 `data-finished=true` → `restFrame ?? 5`（六帧片段停在第 5 帧“收势”，往返片段停在 0）；其余（静态缩略）→ 0。
- 动画总长 2000ms 恰好一个循环，结束时结算。

## 50.3 绘制 `fitLoop`

- 画布实际像素：`clip.presentation` 存在或 `Story.enabled` 时，按显示尺寸×`min(devicePixelRatio, 2048/max(w,h))` 重设 width/height。
- 无 presentation：`fit(ctx, im, 帧rect, w, h, commonScale||1, offset)`：`unit=min(w/sw,h/sh)`，`k=unit*scale`，绘制框 `x=(w-sw*k)/2+dx*unit`，`y=(h-sh*k)/2+dy*unit`，尺寸 `sw*k × sh*k`。高质量平滑。
- 有 presentation（固定机位）：`[bx,by,bw,bh]=bounds`，`unit=min(w/bw,h/bh)`，`k=unit*scale`，
  `x=(w-bw*unit)/2 - bx*unit + (sw - sw*scale)/2*unit + dx*unit`，
  `y=(h-bh*unit)/2 - by*unit + (sh - sh*scale)/2*unit + dy*unit`，尺寸 `sw*k × sh*k`。即以全部帧并集框适配画布，人物大小不随透明边变化。
- 仅在帧号或图片变化时重画（`_frame` `_drawn` 缓存）。图片加载失败 → 加 `cu-art-missing`，aria-label 追加“（画面暂缺）”，活动照常结算。

## 50.4 B01 吐纳光效 `environment()`

- 画框内对 `data-action="B01"` 追加 `<canvas class="cu-environment" width=544 height=462>` 覆盖整个画框。
- 强度：`levels=[.16,.45,1,.9,.4,.16]`，`gain = levels[f] + (levels[(f+1)%6]-levels[f])*mix`。
- 掌心锚点（相对人物绘制框的比例）`qiHandAnchors=[[.5389,.7437],[.5417,.6909],[.5385,.6609],[.5457,.6177],[.5401,.6833],[.5382,.7310]]`，换算到环境画布坐标。
- 裁剪区 `rect(4%,4%,92%,92%)`。先画光晕：径向渐变半径 `w*.14`，停点 0 `rgba(247,204,78, .035+.18g)`、.55 `rgba(239,188,49, .02+.13g)`、1 透明；再画光心：半径 `w*(.012+.024g)`，停点 0 `rgba(255,254,215,.30+.65g)`、.25 `rgba(255,241,143,.24+.56g)`、1 `rgba(232,167,33,0)`。人物静止时不画。
