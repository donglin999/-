# 04 交互、键位、时序

源：`js/qh-mode-cultivation.js`（keydown 监听、`onClick`、`tick`、`finishResult`、`closeView`、`renderPending`、`renderSettings`），`js/qh-mode-cultivation-presentation.js`（`mount`）。

## 4.1 键位（捕获阶段监听，只在 `#cultivation` 可见、`mode==='cultivation'`、未损坏时生效）

| 键 | 条件 | 行为 |
|---|---|---|
| `1`–`7` | 无 pending、无对话框、home | 打开第 n 个栏目子菜单（顺序 basic, skill, production, arts, chores, mail, stroll），焦点到“返回”（邮箱到 `.cu-mail-header button`） |
| `R` | 同上 | 打开「结束本期」确认面板（view='rest'） |
| `←→↑↓` | view=picker 且焦点在子菜单 | 在可用按钮间循环移动焦点（右/下 +1，左/上 −1） |
| `Space` / `Enter` | 对话框中存在 `.cu-dialogue-next`（▾），焦点不在其它按钮/输入上，非长按重复 | 推进对白（点击 ▾） |
| `Esc` | 无 pending/summary，view ∈ picker/gift-npc/letter-npc/walk-review/rest/settings/games/training-record | `closeView()`；总是 preventDefault |
| `Tab` | 有对话框 | 焦点在对话框内循环（首尾环绕） |
| `M` | view=settings | 下一帧重绘，焦点到声音按钮 |
| 小游戏中 | view=games | 除 Esc/Tab 外全部交给小游戏 |

## 4.2 `closeView()` 返回规则

邮件包裹打开时先关包裹。gift-npc/letter-npc → 回 picker 并聚焦对应 C01/C02 卡；walk-review → 回 picker；其它 → `view=null` 并聚焦当前栏目按钮。清空 `message`、`recipient`。

## 4.3 click 动作表（`data-cu` 值）

pending 时只响应：`lesson-next`（`lessonCursor+1`）、`visitor-next`（推进来客/谷内剧情，`linear` 动作结算后立即 closeResult）、`visitor-choice`(索引)、`visitor-fight`、`visitor-training`、`activity-story-next`（storyLine+1，读完后 `storyStep=1` 进入选择）、`story-result-close`（closeResult；auto 剧情回主界面，其它回 picker）、`result-close`、`resolve`(索引)。动画未完成时其它点击忽略。推进对白时先 `CharacterVoice.stop()`。

非 pending：`category` `walk-review` `practice` `mail-select` `gift-npc` `letter-npc` `mail-inbox` `mail-read` `mail-send` `gift-item` `close` `martial-menu` `debug-schedule` `jianghu` `notice-close` `arrival-next` `offer-next` `delivery-next` `teach` `offer-later` `rest|settings|games|training-record|return-preview|completion-record`（设 view）`return-cancel` `sound` `rest-confirm`（advance）`summary-close` `story-complete` `depart` `gate-title` `return-confirm`（`PeiCompanion.returnLoan(S)` 后 returnJourney）。

## 4.4 传艺对白（renderOffer）

1. 第一屏：周砚说话。若可学中有 `TR_` 进阶课：“旧课练得如何，我都看过了。\n今天可以往下学了，选好一门，我带你练。”；否则“今天的新课已经可以开始了。\n选好要学的，我带你拆开练。”；按钮 ▾ → `s.dialogue={id:'weapon-offer',period}`。
2. 第二屏：萧白“师父，我想学……”（进阶时“我想请教……”），每门可学招式一个答案按钮（附体力），另加「改日受教」。选课 → `facts.weapon_offer_period=period`，`dialogue=null`，`begin(id, teaching=true)`。改日 → 同样记 period，本期不再弹。
人物表情：`moods:{hero:'serious', zhou:'serious'}`。

## 4.5 三月中旬同行送药（renderDelivery）

陆衡开场：已学步法 “你练过落脚，前面那段跟我走。别光盯着脚下，也看看同伴在哪儿。”；未学 “步法还没练过，就先帮着分包。路上拿不准，叫我一声，别硬撑。”；cast `['hero','ye','lu']`。▾ → `dialogue={id:'delivery'}` → 萧白“这段路，我想……”，两答案：「留意落脚，协同行路」(`协同行路`)、「请陆衡指出稳妥的路」(`请陆衡指导`) → `completeStory`。

## 4.6 普通修习时序（ms）

```
t0  点卡片 → start()：扣体力/物资，pending.stage=ready|choice，animation={startedAt:now,duration:2000,presented:false}
    render：底栏保持子菜单（锁定），画框 board(playing) 出现
t1  画布首次画出动作帧 → animation.startedAt=t1, presented=true, 存盘
t1+0..2000  播放循环动画（见 50 节），帧由 (now - startedAt) 决定
t1+2000  finishAnimation → resolve(directResult=true) → reconcileWorld → 存盘
         显示 .cu-gain：「{成果名} +g（累计 b → a）」、物资「普通药材 +1」、属性变化行、功法层变化行、关系变化行 ♡，按钮「继续培养」
         若结果没有 courseBeat/lesson/属性变化/提示/关系变化 → resolvedAt+1000ms 自动关闭
关闭  closeResult → view='picker'（首次学会且仍可传艺则回传艺对白）
```
- `RigTrial.enabled`（栖河入口恒为 true）时 `directResult`：跳过首学两选一，直接结算。旧档停在 choice 时动画后直接结算。
- 结果条文本组成（`trainingResult`）：courseBeat 段落；每个属性变化 `{名} +Δ{单位}（培养累计 x → y）`（crit/dodge 单位 %）；`nextEffect` 小字；新学/升层 `《X》 a → b重|层`（首学附“，去招式栏修习”/“，去基本功栏修习”）；关系 `♡ {名} a → b（{阶段} · {原因}）`。
- 有 `result.lesson`（PreHangao 课后对白，见 60 节）时，结果改为逐句对白，`lesson-next` 推进，末句按钮 `result-close`。

## 4.7 剧情（once 活动）流程 `renderActivityStory`

`introByDelivery[first_delivery.method] || introLines || [{speaker:授课人, text:task}]` 逐句（storyLine 0..n-1）→ 选择屏（萧白“我想先……”，按钮为 `a.choice`）→ resolve → 结果屏（授课人说 `resultLine||feedback`，按钮「结束这段剧情」）。speaker 键：`hero`萧白 `zhou`周砚 `ye`叶蘅 `lu`陆衡，其他用 `neighbor`。

## 4.8 设置面板 renderSettings

按钮依次：`开启声音/关闭声音`（`__audio.setMute`）、`武学与装备`（bridge.openMartial）、`调试：谷中日程 开|关`、`查看修习成果`、`小游戏候选试玩`；注释 `候选试玩不推进行程，不计入剧情与修习成果。`（`#7c6748`，.85em）。

## 4.9 修习成果 record()

先画 `trainingResult({before: growth(initial()), after: growth(s)})`（即全部累计加成），然后每个 progress 键一行：`{名} **值**` + 小字 `{用途 use} · {hints}`；空时“本次以休养为主。”

## 4.10 帧循环 `Presentation.mount(root, tick)`

每次 render 结束挂载一个 requestAnimationFrame 循环：对所有 `canvas[data-art]` 调 `draw()`；对 `.cu-environment` 调 `environment()`；再调主控 `tick(now)`，其返回 true 时停止循环（因为已经触发 render 重挂）。宿主隐藏或脱离文档即停止。
