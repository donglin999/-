# 30 师承传艺与三方代表

源：`js/qh-mode-cultivation-mentors.js`（全局 `CultivationMentors`：`definitions repDefinitions REPS_ART_READY scripts bonds effects actors moods`）；额度判定 `js/qh-mode-cultivation-core.js` `strollPool / stroll`。定义经 `CultivationHousehold` 合并进谷内剧情引擎（20 节），所以 once/notice/立绘/对白规则相同。

## 1. 定义构造
- `M(id,place,time,window,name,teacher,actor,cast,gain,amount,extra)` → 追加 `mentor:true`。
- `S(...)` → 追加 `quiet:true, side:true`（ys_* 三段，普通闲逛）。
- `REPS_ART_READY=true` 时把 `repDefinitions`（rep_* 六段，也是 mentor:true）追加到 definitions。

## 2. 闲逛额度（源：core `strollPool`、`stroll`）
每个时段（`period(s)`）各类最多遇一段，用 facts 里的时段号记录：
| 额度键 | 适用 |
|---|---|
| `mentor_met` | `a.mentor` 的剧情（师承 + 三方代表），不占其他额度 |
| `visit_met` | 地点键属于 NEIGHBOR=`{bookhouse,bookhouse_inside,terraces,watermill}`（串门） |
| `stroll_met` | 其他门内地点 |
`strollPool(s,place)` = `D.actions` 中 `category==='stroll' && once && !auto && !hidden && !strollPlace && doorOf(placeOf(a))===key && 额度未用 && availability(s,a)===''`；`doorOf('bookhouse_inside')='bookhouse'`（书屋内剧情从“溪东书屋”进）。抽中后 `start(s,id,{story:true})` 并写 `facts[额度键]=period(s)`；抽不到则 `s.selection={category:'stroll',action:id}`，显示地点的 `idle` 文本（纯逛）。抽取权重与 FNV 散列见 13 节。前置检查顺序：`s.pending` → `请先完成或关闭当前活动结果。`；`mode!=='home'` → `本期用于行程，不能闲逛。`；`!joined` → `先与周砚正式拜师。`
