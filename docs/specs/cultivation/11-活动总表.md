# 11 活动总表（常规活动）

源：`js/qh-mode-cultivation-data.js`（`categories` `actions` `courseBeats` `strollIntro` 闲逛地点循环），`js/qh-mode-cultivation-balance.js`（`install`），`js/qihe-cultivation-bridge.js`（追加 QH01）。

数据经三次改写后才是最终表：① data.js 定义；② `CultivationDialogue.activities(data)`（活动台词，见 42 节）；③ `CultivationBalance.install(data)`：给每个动作记 `legacyAmount/legacyGain`，把 B04 的 gain 改成 `coordination`，剧情类 amount 乘 legacyScale，并为每门功法追加 `TR_*` 传艺动作；④ 栖河入口 bridge 再 push QH01。最终共 **173+1** 条：basic 10、skill 18、production 3、arts 6、chores 5、mail 2、stroll 129（其中 11 个闲逛地点 `SP_*`、W01–W07 剧情、111 个来客/谷内剧情，见 21/31/46 节）。

## 11.1 动作字段

| 字段 | 含义 |
|---|---|
| id / category / name | 编号、栏目、显示名（UI 短名见 03 节 `names`） |
| teacher / place / task | 授课人、地点（中文或地点键）、任务说明 |
| requires | 前置：`joined` `ye` `lu` `village_visit` 或 `learned` 键 |
| factRequires / factHint | 需要的 facts 及未满足提示 |
| learn | 首次完成写 `learned[learn]` |
| gain / amount | 成果键、配置值（常规课实际收益按 13.5 公式，不读 amount） |
| inputs / outputs | 消耗/产出资源 |
| quota / quotaMessage | 每期一次 |
| choice | 首次学习时的两项选择文本 |
| feedback / beats / resultLine | 结果卡文本、课程短剧（首次用 beats[0]，之后 beats[1]）、结果台词 |
| once / window / auto / main / hidden | 一次性 fact 键、可遇期区间 [period起, period止]、自动开场、主线、隐藏 |
| costOverride | 覆盖栏目费用 |
| storyPortrait / portraitRect / icon | 立绘图与裁切矩形 [x,y,w,h]、地点图标 |
| introLines / introByDelivery | 开场逐句台词 `{speaker,text}`；W06 按首次送药 method 分版本 |
