# 60 出发前剧本（PreHangao：第一年正月–四月）

源：`js/qh-pre-hangao.js`（全局 `PreHangao`：`data has context extra apply definitions effects due advanceGate lesson`，纯状态无 DOM）、`js/qh-pre-hangao-data.js`（`PreHangaoData`，只述结构）。

## 1. 数据结构 `PreHangaoData`
`{version:'PRE-HANGAO-RUNTIME-1', adoption:'user_authorized_2026-10-13', scenes[24], contexts[384], lessons[6]}`
- **scene**：`id name place time window[a,b] cast[] gain amount requires[] factRequires relNeed adultOnly intent numerical_result status('候选修订'|'新增候选') skillRequires auto fight cost effects[] expiry staging opening[] ending[] choices[] letters?[{author,text}] productionChoices?`（intent/staging/expiry/numerical_result 为设计说明文字，运行不用）。
- **台词块**（opening/ending/choice.lines）：`{id, speaker, text, cast?, mood?, moods?, motion?, duo?, duoCast?, place?, phase?('intro'|'closing'|'choice:key'), when?{injury|delivery|route|weapon|pei: 值或值数组}, whenSeen?[剧情id], whenUnseen?[剧情id], contextIndices?}`。
- **choice**：`{id, label, when?, lines[]}`。
- **contexts**：384 条 `'未成年／关系0／{light|rest|unknown}／送药{方式|未发生}／已学{…剑拳步法}'`，供 `contextIndices` 精确匹配（当前数据无块使用）。
- **lessons**：`{id,name,actor,first:[[speaker,text]…],repeat:[…],milestone:[…],gate(说明)}`；id ∈ lesson_stance(zhong) lesson_sword(zhou) lesson_fist(zhong) lesson_breath(zhou) lesson_footwork(zhou) lesson_notes(ye)；first 3 句（notes 2 句），milestone/repeat 各 1 句。

**场景 id 清单**（window）：gy_noodles[0,4] gy_prelude_xinfa[0,0] gy_m02[2,4] gn_lamp[4,11] gn_spring[5,11] gn_cook[10,11] gn_letter[13,14] gy_m03[5,7] gy_bamboo_wolves[6,11] **hg_aftercare**[8,9] visitor_songfeng_route[8,9] gy_m06[13,14] visitor_whiteheron_records[13,14] gy_spar_zhong[14,16] **hg_trace_reply**[14,16] gy_m07[15,16] visitor_zhaochuan_greeting[15,17] gy_zhong_kit[16,19] **hg_pack_review**[17,18] gy_zhou_test[18,18] gn_depart[19,19] gy_m08[19,19] **hg_road**[20,20] **hg_gate**[20,20]。粗体为 `status:'新增候选'`（新剧情，由 `definitions()` 追加）；其余是对 household 已有剧情的**台词整体替换**。

## 2. 上下文
- `extra(s)` → `{preHangao:{facts:深拷贝, weapon:s.preHangao?.weapon||null, pei: gn_letter_seen?'close':gn_lamp_seen?'known':'new', participants, route: 学剑?'sword':学拳?'fist':'life'}}`（household extra 会并入）。
- `context(c)` → `{facts, route, pei, delivery: c.delivery||c.first_delivery.method||null, injury: c.opening.chen_injury||'unknown', weapon: preHangao.weapon?'ready':'missing', footwork:!!c.footwork}`。
- `match(b,c)`：`seenOk`（whenSeen 全看过、whenUnseen 全没看过）→ `when` 每项：数组则包含、否则相等 → 有 contextIndices 时按 contexts 表匹配。

## 3. `apply(id,base,c0)`（替换剧本）
1. 每块补 `place/time`（缺省用场景的）、`cast`（缺省场景 cast）。
2. `opening`、`ending` 过滤 `match`；`letters` 逐封追加到 opening：`{speaker:'narrator', text, letterAuthor:作者, id:id+':letter:'+i}`（主控显示为 `作者 · 署名信件`，加类 `cu-letter-scene`）。
3. choices：自身 match 且至少一行 match 的；`{key:ch.id, text:ch.label, lines:过滤后, effects: 沿用 base 同 key 的 effects}`。`gn_depart` 特例：用 `productionChoices`（join `“书箱我背，你只管看路。”` / roster `“你跟着我师父，慢慢走、慢慢看。”`）。
4. 无选项 → 线性：`intro=all[..-2]`，`{key:'linear',auto:true,lines:[倒数第二]}`，`closing=[最后]`；ending 为空补旁白 `……`。

## 4. `definitions(list)`（在 household 定义上就地修订）
- 有对应 scene：覆盖 `name cast place time`。
- gy_spar_dou / gy_fang_spar / gy_spar_zhong：敌人 `worldLevel` = c_gy_luxiaodou 10 / c_gy_fangchi 36 / c_gy_zhongzhuo 80，`teachingStatsLevel=lv`。
- gy_m09：`hidden=true, auto=false`（不再单独播放）。
- gn_depart：`auto=true, window=[19,19], relNeed=null, factRequires=['gy_m08_seen']`。
- gy_zhou_test：`needSkill=false, training=true, fight=false`（改为考校小游戏，见 02 节）。
- 追加新增候选：`{id,name,cast,place,time,window,auto:true,main:true,actor:cast 中第一个非 hero,teacher:'师门',gain:'understanding',amount:0,requires:['joined'],factRequires:scene.requires}`，hg_road、hg_gate 另加 `storyMode:'journey_ready'`。
- 最后按 `window[0]` 升序，同起点按 rank `gy_m08:1, gn_depart:2, hg_road:4, hg_gate:5` 排序（决定 due 的先后）。

## 5. `due(s,actions,availability)`（household.due 先调用它）
条件：`s.joined && !s.pending && !s.summary && s.month≤5`。slot=(month-1)*5+phase。返回第一个：`auto && !hidden && !(gy_m05 且已有 first_delivery) && 未 seen && slot≥window[0] && (main 剧情过窗口仍补播；非 main 过窗口则不播) && availability(s,{...a,window:undefined})===''`。
`advanceGate`：有 due 时结束本期被拦截，提示 `先完成{名}，再结束本期。`

## 7. 修习课 `lesson(s,a,first,before,after)`
动作→课：B03 stance、K01 sword、K02 fist、B01 breath、B02 footwork、A03 notes。
- kind：首次学 → `first`；达到里程碑且 `s.preHangao.lessonMilestones[id]` 未记 → `milestone`（并记下）；否则 `repeat`。
- 里程碑：B03 `progress.foundation≥160`；B02 `progress.footwork≥300`；A03 做过 ≥3 次且 `facts.herb_labels`；K01/K02/B01 结算后对应 martial level ≥2。
- 返回 `{id,kind,lines,speaker:actor}`，存入 `p.result.lesson`；主控 `renderPending` 在结果阶段逐句用 `Q.render` 播放（cast `['hero',actor]`，按钮 `lesson-next`，末句 `result-close`），`data-lesson=kind`。例 lesson_stance first：zhong `脚别急着往外撇。先站住，我推你一下试试。` / hero `刚才是脚跟先晃的？` / zhong `对，记住那一下。`
