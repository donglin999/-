# 14 存档字段（S.cultivation 与相关世界字段）

源：`js/qh-mode-cultivation-core.js`（`initial` `validate` `restore` `recover` `migrateEconomy` `reconcileWorld`），`js/qh-mode-cultivation-growth.js`（`ensure` `reconcile`），`js/qh-mode-cultivation.js`（`persist` `quarantine`），`js/qihe-cultivation-bridge.js`（`migrate`）。

## 14.1 存储位置

- 培养状态挂在全局存档对象 `S.cultivation`，随主存档 `persistState(S)` 一起写（主存档键由全局 saveKey 决定，不在本模块）。
- 会话副本：`sessionStorage['xjh.qihe.cultivation.save.v1']` = 整份 `JSON.stringify(S)`。
- 本机偏好：`localStorage['cu.debugSchedule']` = `'on'|'off'`（调试“谷中日程”公告板，缺省视为开）。
- 损坏备份：`S.cultivationQuarantine` 数组，最多 3 条 `{at, error, repairs[], original}`。

## 14.2 `initial()` 字段树

| 字段 | 类型 / 默认 | 校验 & 含义 |
|---|---|---|
| version | 1 | 必须为 1 |
| preHangao | `{version:1}` | 出发前剧情状态（见 60 节）；`month>=5` 且缺失的旧档补 `{version:1,legacyFirstCity:true}` |
| balanceVersion | 2 | 与 `CultivationBalance.version` 不等时 `Growth.ensure` 迁移 |
| martialXp | `{}` | `{artId: xp}` 功法熟练（一位小数） |
| economyVersion | 2 | 允许 1..2，缺省视为 1；strict 校验下非 pending 必须=2 |
| route | `'mountain'` | 必须 `mountain`（`D.routes` 另有未开放的 guijintang/patrol） |
| month | 1 | 1..36 |
| phase | 0 | 0..4 |
| energy | 12 | 0..energyCap |
| mood | 60 | 0..100 整数 |
| mode | `'home'` | `home/story/journey_ready/journey/complete` |
| joined | false | 布尔，是否正式拜师 |
| learned | `{}` | `{key:{source, period, skillId?, systemId?}}` 已受教课程/功法 |
| progress | `{}` | `{成果键: 累计值}`（见 13.7） |
| resources | `{grain:2,cloth:2,herb:0,food:0,pouch:0}` | 五种都必须为非负整数 |
| facts | `{}` | 剧情事实（见 14.4） |
| quotas | `{}` | `{actionId:true}` 本期份额 |
| history | `[]` | 结算记录（14.3） |
| letters | `[]` | 信件/通知（14.5） |
| pending | null | 进行中活动（14.6） |
| summary | null | 月底小结 `{month, entries[], remaining}` |
| sequence | 0 | 自增序号，pending id = `'cultivation-'+sequence` |
| relations | `{}` | `{profileId:{score:0..100, interactions[], returnOffered:bool, …}}`（见 33 节） |
| selection | `{category:'basic', action:'B03'}` | 当前栏目与项目；action 可为 null |
| journey | null | 历练 `{month, returnMonth, returnRoute, visited[], place, kind?}`，visited ∈ gate/street/alley/ferry |
| screen | `'hub'` | `hub/world` |

运行中追加的可选字段：`dialogue`（`{id:'weapon-offer', period}` 或 `{id:'delivery'}`）、`qhImported` `qhOrigin` `staffApplied`（bridge）、`balanceLegacy` `balanceLegacyCaps` `balanceWorldImported` `trainingBaseStats`（growth 迁移）。

`mode==='complete'` 时必须 `month=36, phase=4, energy=0`；`mode==='journey'` 时 `journey.month===month`、`returnMonth===month+1`、`returnRoute===route`。

## 14.3 history 条目

```
{id:'cultivation-17', balanceVersion:2, artXp, artId, action:'B03', name, period,
 cost, freePractice:cost===0, nominalCost, gain, gainKey, skillId, systemId, choice,
 recipient?, gift?}
```
特殊条目：`{id:'story-delivery',name:'首次同行送药',period,cost:0,gain:0}`、`{id:'journey-'+月,name:'整月历练',period:(月-1)*5,cost:0,gain:0}`。`period<0` 的条目不计数。`Growth.counters` 只在 progress 缺键时用 history 补算（防止重复加）。

## 14.4 常用 facts 键

- 系统：`joined`、`weapon_offer_period`（本期已看过传艺）、`stroll_met` `visit_met` `mentor_met`（=period）、`first_delivery{choice,month,method,training}`、`gy_martial_major{path:'sword'|'fist',source,period}`、`journey_{月}`、`hg.pre.gate_handoff`。
- 通知：`D.notices` 的 id → `{period:slot}`（如 `village_news` `lu_visit_notice` `escort_notice` `xiangyang_invitation` 及 `*_notice`）。
- 一次性活动：动作 `once` 值 → `{period, choice}`（`herb_labels` `visit_neighbors` `promise_scope` `escort_review` `departure_goals` …）。
- 剧情已看：`{eventId}_seen`（如 `gy_noodles_seen` `gy_night_return_seen` `gy_ledger_seen` `gn_lamp_seen` `gy_year_exam_seen` `hg_aftercare_seen`），选择 `{eventId}_choice`（如 `gy_fist_or_sword_choice`）。
- 同伴：`gy_yin_recruit` `gy_yin_party_offered` `gy_pei_join` `met_pei` `pei_party_preference`、切磋 `spar_log`。

## 14.5 letters 条目

- 通知：`{id:'notice-'+noticeId, recipient:'谷中消息', theme:'日程', due:slot, read:silent, body}`；底栏邮箱未读数排除 `notice-` 开头。
- 寄出：`{id:pending.id, theme, recipient, author, gift, due:period+1, read:false, body, returnItems:{资源:数量}, returnClaimed:false}`；`due>period` 时不可读（“来信尚未送达。”）。

## 14.6 pending

```
{id, economyVersion, action, period(0..179), cost, energyBefore, moodBefore, balanceVersion,
 stage:'choice'|'ready'|'result', theme, recipient, gift, inputs, result,
 guidance?, animation?{startedAt, duration:2000, done, presented},
 story?:true, storyStep:0|1, storyLine:0..9, lessonCursor?,
 visitor?{…见31节}, legacyBalance?, resolvedAt?, relationship?}
```
约束：stage=result 必须有 result 对象；story 只用于有 once 的动作且不可同时有 animation；visitor 动作必须有 `pending.visitor`。

## 14.7 读档流程

`recover(raw)`：先 `restore`（`validate` 宽松 → 补 preHangao → `migrateEconomy` → strict `validate` → `Growth.ensure`）。失败时只做安全修复：selection 无效→重置；relations 中未知人物删除；journey.visited 去掉非法地点；pending 指向不存在的动作→清除（不退体力）。有修复项再 restore 一次；仍失败返回 `{state:null}`。

`migrateEconomy`：economy 1→2 且无 pending；若当前为 home 普通期（非历练月、非 3 月中旬）补体力 `min(12, energy+(12-10))`。
