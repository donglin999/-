# 03 主界面布局（DOM、尺寸、颜色）

源：`js/qh-mode-cultivation.js`（`render` `art` `icon` `ornament` `thumbnail` `footer` `board` `panel` `story`），`js/qh-mode-cultivation.css`，`js/qh-mode-cultivation-story.css`（`.cu-place-tag` `.cu-time-card` `.cu-visitor-bulletin`），`index.html` 第 438 行 zoom 规则。

## 3.1 画布与单位

- `body.cultivation-view`：`padding:0; background:#171b16`；`#game` 宽 `min(100vw, 100vh*16/9)`，即固定 **16:9** 画面，`overflow:clip`。
- `#game` 下除 `#cv #cultivation #fade #loading #panel #bt #prologue-cg .qh-fire-cg` 外的子元素才吃 `zoom:var(--ui-zoom)`；`#cultivation` 不缩放，全部用 `cqw`（容器宽的 1%）与百分比布局。Godot 中建议以 1920×1080 为基准：**1cqw = 19.2px**。
- `#cultivation`：`position:absolute; inset:0; z-index:10; color:#362b1c; background:#272b20; font: clamp(14px,1.35cqw,26px)/1.45 "Kaiti SC","STKaiti",serif`（楷体）。
- 通用按钮：`min-height:44px; padding:.4em .8em; border:2px solid #967448; border-radius:2px; background:#eee0bd; color:#392918; box-shadow: inset 0 0 0 1px #f9edce, 0 2px 4px #30231133`；hover `brightness(1.08)`；焦点 `outline:3px solid #d18d39; offset 2px`；禁用 `opacity:.48`。主按钮 `.cu-primary`：`background:#536942; color:#fff1c8; border-color:#88965e`。

## 3.11 断点

- `≤900px`：`.cu-overlay` 改 `20%/20%/21%/25%`；games `6%`；字幕 `16%`；tooltip `18–35cqw`；选择条 `18%`。
- `≤640px`：栏目按钮取消 44px 最小高。
- `prefers-reduced-motion`：关闭全部动画与过渡；画布只画第 0 帧。
