# 61 裴知古同行、借剑与培养→世界同步

源：`js/pei-companion.js`（全局 `PeiCompanion`：`id skills fresh ensure recruit witness sync returnLoan reveal cast consumeIncoming defend expire actionStart`）、`js/pei-companion-runtime.js`（浏览器战斗接入，仅 `isQiheEntry()` 时生效）、`js/qh-mode-cultivation-core.js` `reconcileWorld / syncNotices / CULT_GIFTS`、主控 `return-confirm` 动作。
培养模式只用到 **sync / recruit / witness / returnLoan**；战斗技能部分列出供战斗系统移植时对照。

## 1. 同伴模板 `fresh()`（id=`peizhigu`）
`{st:{str:1,con:3,agi:3,wil:5,wis:7}, lv:3, exp:0, pts:0, skills:{pei_zhi:1}, weapon:'pei_sujian', armor:null, equip:{weapon:'pei_sujian',armor:null,acc:null}, load:['pei_zhi'], xinfa:{known:['tuna'],lv:{tuna:1},prog:{},main:'tuna',subs:[]}, growthMode:'witness', witness:{}, book:{id:'pei_sujian',grade:'丁',witnessCount:0}, peiVersion:1}`，存于 `world.mates.peizhigu`。`ensure` 补齐缺字段并强制武器为素笺。

## 2. 入队 `recruit(world, preference='join')`
- `world.qiheRoster ||= {version:1, members:['hero',...party], availability:{}, revision:0, commands:[]}`；不在名册则 push `peizhigu`、`revision++`。
- 仅首次（`m.partyChoiceApplied` 未设）：preference 为 `join` 且队伍 <3 人 → 加入 `world.party`；`roster` 只进名册。返回 `{id,level,inParty,full}`。
- preference 来自 `facts.pei_party_preference`（gn_depart 选项：join / roster，见 60 节）。

## 3. 见闻成长 `witness(world,event,{participants,outcome,note,completed})`
允许事件：`hg.pre.road_help hg.m01 hg.m03 hg.m05 hg.m06 hg.m07 hg.m08`。条件：已存在、completed、事件允许、participants 含 peizhigu、当前在队、未记录过。写 `m.witness[event]={version:1,completedAt,outcome,note}`；n=见闻数；`book.witnessCount=n`；`lv=max(lv,min(100,3+floor(n/3)))`。
品阶：n≥10 且有 hg.m08 → 丙、得 pei_wen；n≥30 且 `cultivation.mode==='complete'` → 乙、得 pei_shen；n≥60 且 `flags.pei_three_descendants` → 甲、得 pei_jiao。

## 4. `sync(world)`（每次 reconcileWorld 最先调用）
1. `s.preHangao.weapon` = 当前 `world.weapon` 的武器类型为 `剑` 则该 id，否则 null。
2. `facts['hg.pre.loan_request']` 且未 `loan_committed`：若无剑 → `bag.guiyun_wood_loan+1`，装备之，`world.equipmentLoans.guiyun_wood_loan={owner:'guiyun',event:'hg_pack_review'}`；记 `loan_committed=true`，`preHangao.weapon=world.weapon`。
3. `facts.gy_pei_join` → `recruit(world, pei_party_preference||'roster')`。
4. `s.preHangao.participants = party 副本`（hg_road 剧本据此决定谁在场）。
5. `facts['hg.pre.road_help']` → `witness('hg.pre.road_help', {participants: preHangao.roadParticipants, outcome: 选项 key, note: key==='bind'?'绳子比我以为的要紧。':'接书的人先站稳了脚。'})`。
`returnLoan(world)`：有借用记录 → 删背包借剑、若装备中则卸下、删记录；主控 `return-confirm`（返谷确认）时先调用，再 `C.returnJourney(s)`。

## 5. 物品（runtime 注册）
- `pei_sujian` 素笺：`weapon:{kind:'书',atk:0}`，`boundTo:'peizhigu'`，`key:true`，图标 `assets/production/pre-hangao/sujian-icon.png`；不可卸下/替换/出售（`此册只属于裴知古`、`素笺为绑定书册，不能替换`）。
- `guiyun_wood_loan` 桃木剑（归云谷借用）：复制 `ITEMS.wood`，`price:0,key:true,loanOwner:'guiyun'`，描述 `归云谷教学借用，返谷时归还；不可出售、送礼或拆解。`
- 队伍定义：名 裴知古，initialLevel 3，立绘 `household-v1/pei_normal.png`，普攻 `护书轻触`（atk 2，伤害 1–2，BP 每档 +1 段）。

## 6. 技能（战斗用）
| id | 名 | 内力 | 目标 | 效果（bp 0–3） |
|---|---|---|---|---|
| pei_zhi | 指瑕 | 4 | 敌 | 揭示一个未知弱点；目标下次受击 ×(1.1+0.05bp) |
| pei_wen | 温故 | 6 | 敌 | 锁定下一条意图并显示；若曾见此敌类，其下次伤害 ×(0.9−0.05bp) |
| pei_shen | 慎行 | 6 | 友 | 下次受击 ×(0.8−0.05bp)，免疫一次位移 |
| pei_jiao | 校雠 | 10 | 全敌 | 各揭示一弱点，全知者给破绽 ×(1.1+0.05bp)；冷却 3 次自身行动 |
防御时给自己 `peiCover ×0.75`。增益按 `peiActionSerial` 计时、在行动开始/结束边界过期；受击时 `consumeIncoming` 依次乘 peiCover/peiCare/peiFlaw 后取整（≥1）。

## 7. 世界同步 `reconcileWorld(world)`（core）
1. `PEI.sync(world)`。
2. 台词赠物（每样一次，记 `world.cultGifts[id]`，`bag[id]+1`）：

| 物品 | 条件（facts） |
|---|---|
| gy_wood_bird | gy_ledger_seen |
| gy_hand_cloth | gy_fist_or_sword_choice==='sword' |
| gy_wrist_guard | gy_zhong_kit_seen |
| gy_wood_bird_sale | hg_pack_review_seen |
| pei_lens | gn_depart_seen |
| needles | ms_thread_seen |
| wood | my_twig_seen |
3. `Growth.reconcile(world, actions)`（属性/武学写回世界，见 13 节）。
4. 殷红缨：`facts.gy_yin_recruit` → 名册加 `yinhongying`；未提供过（`gy_yin_party_offered`）且队伍 <3 → 入队；之后置 `gy_yin_party_offered=true`。
5. `world.qiheRoutes = household.routes(s)`。
6. 学会吐纳 → `world.xinfa` 加 `tuna`，`lv.tuna=max(原, 吐纳等级)`，无主修则设为主修。

`syncNotices(s)`：对每条 notice（`slot≤period` 且未写过 `facts[id]`；`escort_return` 需 first_delivery）写 `facts[id]={period:slot}` 并 push 信件 `{id:'notice-'+id, recipient:'谷中消息', theme:'日程', due:slot, read:!!silent, body:text}`；主页“谷中消息”面板显示未读且 `due≤period` 的 notice 信（`renderNotices`，按钮 `知道了 · 继续培养`）。
