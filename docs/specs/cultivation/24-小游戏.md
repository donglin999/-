# 24 小游戏（候选试玩）

源：`js/qh-mode-cultivation-minigames.js`（全局 `CultivationMinigames`：`catalog / initial / act / mount`）；入口 `js/qh-mode-cultivation.js` `renderGames()`；样式 `js/qh-mode-cultivation.css` 中 `.mg-*`、`.cu-games`、`.cu-game-host`。

**定位**：状态与主存档隔离，不接剧情、不给养成奖励、不耗体力、不写行卷。入口在“设置”面板按钮 `data-cu="games"`（文案 `小游戏候选试玩`，下附说明 `候选试玩不推进行程，不计入剧情与修习成果。`）。render 分支 `view==='games'` → `panel('小游戏候选试玩','<div class="cu-game-host"></div>')`，面板加类 `cu-games`，然后 `mount(host)`。

## 1. 目录 catalog
| id | code | name | category | tip（原文） |
|---|---|---|---|---|
| stance | MG01 | 站位踏步 | basic | 用方向键移动到脚印，按回车站稳。完成五次落脚；没有限时。 |
| moves | MG02 | 招式拆解 | skill | 把起势、转身、出手、收势排好。可点击或拖入；排错可以撤回。 |
| sort | MG03 | 材料整理 | production | 按形状把六份练习材料归入叶、籽、根三篮。点材料，再点竹篮；数字1—3选篮。 |
| trail | MG04 | 行路观察 | stroll | 从左上角沿浅色石路走到渡口，途经两个歇脚点。方向键或点相邻格；走入泥地可重试。 |

常量：`kinds=['leaf','seed','root']`，`names={leaf:'叶',seed:'籽',root:'根'}`，`moveNames=['起势','转身','出手','收势']`，`targets=[4,3,6,7,4]`，`road=[0,1,5,9,10,14,15]`。

## 2. 状态 `initial(id)`
`{id, status:'playing', position: id==='trail'?0:4, step:0, misses:0, order:[], sorted:[], selected:0, visited:[0], message:''}`；status 取 `playing|won|lost`。未知 id 抛 `没有这个小游戏`。

## 3. 规则 `act(s,type,value)`（status≠playing 时忽略）
- **stance（3×3，格号 0–8 行优先）**：`move` 方向 left -1/right +1/up -3/down +3，越界或跨行不动。点格 `stance-cell`：仅相邻（差 3，或同行差 1）可移。`confirm`：`position===targets[step]` → step++，消息 `这一步站稳了。`，step=5 胜；否则 misses++，`重心还没落在脚印上，移动后再试。`
- **moves**：`add v`（0–3 且未用过）追加到 order；`undo` 弹出最后一个；`check`：order 为 `0,1,2,3` 胜；否则 misses++，长度<4 `先把四步排齐。`，否则 `动作没接上，撤回后重新排一排。`。招式池显示顺序固定 `[2,0,3,1]`（出手、起势、收势、转身）。
- **sort**：6 份材料，材料 i 的种类 `kinds[i%3]`。`select i`（未归）设 selected。`bin k`：`kinds[selected%3]===k` → 加入 sorted，selected 跳到第一个未归的（无则 -1），`这一份归好了。`，6 份胜；否则 misses++，`看一看材料形状，再选竹篮。`
- **trail（4×4，格号 0–15）**：`move` 方向 ±1/±4 或直接格号；必须相邻。走到非 road 格 → `lost`，`踩进泥地了。观察浅色石路，再试一次。`；road 格记入 visited；到 15：已经过 5 和 10 才胜，否则 `先途经两个歇脚点。`。格 5、10 标“歇”，15 标“渡”。

## 4. 界面 `mount(host).render()`
- **目录页**：`<p class="mg-intro">四个候选，先试玩再决定。</p>` + `.mg-catalog` 4 列按钮（图标 + `<strong>name</strong>` + `<small>code · tip</small>`）+ `<p class="mg-note">试玩不消耗体力，不写入行卷，也不决定剧情走向。</p>`。
- **游戏页**：`.mg-top`（h3 名称 + `.mg-count` 进度：stance `step / 5步`，sort `n / 6份`，trail `n / 2处歇脚`，moves 无；small 为 tip；右侧 `返回候选` data-mg=back）→ `.mg-play.mg-{id}` 棋盘 → `footer.mg-footer`（状态文字：胜 `完成了！本次只作试玩记录。`，负显示 message，进行中显示 message；misses>0 追加 ` · 可继续尝试`；右侧 `重新试玩` retry）。结束后 `.mg-play` 内按钮全部禁用。
- 棋盘：stance `.mg-board.mg-grid3` 9 格，当前格 `.mg-current` 内放 `<i class="mg-player">`，目标格 `.mg-target` 内放 `<i class="mg-footprint">`；下方 `站稳 · 回车`（cu-primary）。moves：`.mg-move-pool` 4 按钮（disabled 已用）+ `.mg-move-tray`（4 槽，空槽显示序号 1–4）+ `.mg-buttons`（`撤回一步` / `演练这一套`）。sort：`.mg-materials` 6 个（`.mg-material.mg-{kind}` + `<small>叶形</small>`）+ `.mg-baskets` 3 个 `叶篮 · 1` 等。trail：`.mg-board.mg-grid4` 16 格 `.mg-road`/`.mg-mud`。
- 图标 `painted(cat)`：`dock_icons_v2.png`（`assets/production/cultivation/ui/`）4×2 图集，`background-size:400% 200%`，索引按 `['basic','skill','production','arts','chores','mail','stroll','rest']`，位置 `(i%4)*33.33% , floor(i/4)*100%`。
- 焦点：结束→retry；sort→当前 selected；stance→confirm；moves→首个可用 add；trail→首个格子。

## 5. 输入
- 键盘（host.onkeydown，游戏中）：方向键（stance/trail）移动；Enter（stance）=confirm；`1`–`3`（sort）=放入第 n 篮。均 preventDefault+stopPropagation。
- 点击 `[data-mg]`：add/select/stance-cell/trail-cell 的 value 转数字。
- 拖放：dragstart 写 `type:value`；`[data-drop]` 接收：moves 的 add → add；sort 的 select → 先 select 再 bin(目标 data-drop)。
