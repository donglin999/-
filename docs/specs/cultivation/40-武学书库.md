## 4. 受教活动生成（`install(D)`）
除 K01/K02/B01/QH01 外，每门功法生成活动 `{id:action, category: inner?'basic':'skill', name, teacher: art.teacher||(art_gy_p2?'殷红缨':'周砚'), place: inner?'竹径':'练武场', requires:['stance'], learn:key, sceneTaught, gain: inner?'breathing':暗器?'hidden':拳?'fist':'sword', amount:0, artAlias: inner?'B01':拳?'K02':'K01'（借用该动作的动画）, task:'正式受教《名》，首次学会后才能独练；X级，使用已有招式。', feedback:'《名》的起手与收势已经练过。', beats:['{teacherCall||(p2?'殷师叔':'师父')}把《名》的起手放慢，让你跟着走了一遍。','本次只练已受教的部分，进度与实战共用。']}`。
`gate` 判定顺序（未学时）：sceneTaught → `《名》要{称呼}亲自教，闲逛时去找{称呼}。`；`month<art.month` → `《名》最早在第N个月传授。`；外功非丁级且非护路棍法、主修路线不符 → `须先选定对应主修路线。`；前置不足 → `先把《X》练到N重/层。`；乙级且未看 gy_year_exam → `先完成第一年的师门考校。`；属性不足 → `根基不足：身法需6，当前4。`。另 QH01 每时段一次：`本期笔记已复盘，下期再来。`
