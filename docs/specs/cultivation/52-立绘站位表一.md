# 52 立绘站位表（一）：规则与 cen–pei

源：`js/qh-mode-cultivation-actors.css`（由 `tools_scene/qihe/build_actor_layout.py` 生成，“脸一样高、脸中线对齐、按脸居中”）。加载顺序（index.html）：`qh-mode-cultivation.css` → `qh-mode-cultivation-story.css` → **`qh-mode-cultivation-actors.css`** → `qh-mode-cultivation-mail.css`，选择器带 `#cultivation`，因此**本表覆盖 48 节 §6 的站位数值**；48 节中的数值只在本表缺项时生效。

## 1. 通用规则（覆盖 story.css）
- 前景 actor（任意人数）：`top:var(--visitor-top)`，`height:var(--visitor-height)`（相对 stage 高度，可超过 100%，下半身被 stage `overflow:hidden` 裁掉），`width:auto`（按图片原比例），`object-fit:fill`，`transform:translateX(calc(-50% + var(--face-dx,0%)))`（以 left 为脸中线，再按 face-dx 修正；百分比相对图片自身宽度），无遮罩。
- 水平锚点 left：1–2 人 `28% + i×44%`；3 人 `21% + i×29%`；4 人 `13% + i×24.6%`；只有一人 `50%`；只有萧白一人（`data-solo="hero"`，story.css 选择器更具体）`28%`。
- 头像条（roster）裁脸：`--avatar-height` / `--avatar-top` 写在同一角色类上，供 `.cu-story-avatar img` 使用（48 节）。
- 匹配优先级：`.cu-story-{id}[data-mood=X][data-facing="left"]` > `[data-mood=X]` > 仅角色类（表中 `*` 行）。`data-mood` 为解析后的表情档（20 节 resolveMood）。选项画面（`[data-choice=true]`）只改 top/height，face-dx 与头像沿用普通行。
- 萧白三形态同时带 `.cu-story-hero` 与 `.cu-story-hero_{short|mid|long}`，后者行在后，覆盖前者。
- Godot 实现：每个立绘节点按（角色, 表情, 是否朝左）查本表得 top、height（乘舞台 stage 高度，stage = 视口高 × 85%）、face-dx（乘纹理显示宽度），left 锚点按人数公式；纹理按高度等比缩放。
