## 3. 对白状态机（`p.visitor`，存于 `s.pending.visitor`）
- `init(s,id)` → `{version:2, phase:'intro', cursor:0, selected:null, context:{...snapshot(s), ...(household? H.extra(s))}, scriptSnapshot:深拷贝(script(id,context))}`。`snapshot(s)={footwork,fist,sword:布尔, delivery: facts.first_delivery.method ∈ ['guided_footwork','assisted_carry','asked_for_guidance'] 否则 null}`。**剧本在开场时快照**，读档不重算。
- `script(id,c)`：PreHangao 管的 id 走 `PH.apply`；household 的 id 走 `CultivationDialogue.apply(id,x)`；来客补齐 cast（分支里只留说话的人 + hero + actor）。
- phase：`intro → choice → branch → closing → commit`。
- `next(p)`：choice/commit 下抛错 `请先选择或结束当前剧情。`；cursor+1 < 行数则 cursor++；intro 读完：若只有一个 `auto` 选项（linear）直接 `selected=0, phase='branch'`，否则 `phase='choice'`；branch 读完→closing；closing 读完→`commit` 并返回 true（主控随后结算）。
- `choose(p,i)`：仅 choice 阶段，`selected=i, phase='branch', cursor=0`；非法抛 `请选择当前可用的回答。`
- `current(p)`：choice 阶段返回 `{speaker: cast 中第一个 hero*, text:'这次我想……', choices, cast, 场景}`；其他阶段返回当前行（cursor 夹到末行）；closing 行的场景从所选分支最后一句续推。
- `validate(p)`：version∈{1,2}、phase 合法、cursor 为非负整数且 < 当前段长度、context 三个布尔、delivery 合法；否则抛 `来访剧情存档格式不正确。` / `来访选择不正确。` / `缺少来访选择。` / `来访对白位置不正确。`
- `effects(s,p)`：`facts[action+'_choice']=key`；所有出现过的非 hero/title/narrator 说话人写 `facts['met_'+speaker] ||= {source,period}`；household 的再调 `H.effects`。

## 4. 主控渲染 `renderVisitorStory(a,p)`
1. `x=V.current(p)`；result=`p.stage==='result'`；choice=有 choices 且非 result。
2. 场景：`applyScene(lineScene(x,a))` 换背景（46 节）。
3. `speaker==='title'`：插入 `section.cu-time-card`（role=dialog，全屏水墨字幕卡）`<p>text</p>` + `Q.next('visitor-next','继续')`，返回。
4. 按钮：result → `story-result-close`，household `结束这段剧情`，来客 `结束来访，继续培养`；choice 时：`a.training` 且非 life 路线→`visitor-training` `开始考校：按师父口令收招`；`a.fight`→`visitor-fight` `开始切磋`(sparWith)/`迎战`，台词改为 `（摆开架势。）`/`（握紧手里的家伙。）`；否则每个选项 `visitor-choice` 序号。非 choice→`Q.next('visitor-next')`。
5. `Q.render(root,{title:a.name,text,speaker,cast,choice,buttons,event:a.id,line})`（48 节），加类 `cu-visitor-story`、`dataset.visitor/phase/line`；`x.letterAuthor` 时加 `cu-letter-scene`，标题改 `作者 · 署名信件`；result 且有收益/传艺/关系变化时追加 `div.cu-story-outcome`（`✦ gainSummary` + trainingResult）。
