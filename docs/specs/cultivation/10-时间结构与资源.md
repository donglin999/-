# 10 时间结构、体力、心情、资源

源：`js/qh-mode-cultivation-core.js`（`initial` `period` `syncMode` `advance` `closeResult` `completeStory` `depart` `returnJourney`），`js/qh-mode-cultivation-data.js`（`data` 对象），`js/qh-mode-cultivation-balance.js`（`moods` `mood`）。

## 10.1 时间单位

| 概念 | 规则 |
|---|---|
| 月 `s.month` | 整数 1–36（三年）。第 N 年 = `Math.floor((month-1)/12)`，月份 = `(month-1)%12+1` |
| 时段 `s.phase` | 整数 0–4，名称 `D.phases=['月初','上旬','中旬','下旬','月底']` |
| 期序号 `period(s)` | `(month-1)*5+phase`，范围 0–179；history/letters/notices/window 全用它 |
| 季节 | `['spring','summer','autumn','winter'][Math.floor(((month-1)%12)/3)]`（主控 `season()`，供背景用） |
| 日期文本 | `第{一/二/三}年{1–12}月{时段名}`，例：`第一年3月中旬`（主控 `date()`） |

## 10.2 体力（energy）

- 每期上限 `D.energyPerPeriod = 12`（economyVersion 2）。旧版本 economyVersion 1 上限 10（`ENERGY_CAP={1:10}`）。
- 栏目基础费用（`D.categories`）：

| id | 名称 | 费用 |
|---|---|---|
| basic | 基本功 | 5 |
| skill | 招式 | 5 |
| production | 生产 | 3 |
| arts | 学艺 | 3 |
| chores | 打杂 | 2 |
| mail | 通信 | 1 |
| stroll | 闲逛 | 4 |

- `nominalCost(a) = a.costOverride ?? category.cost`；必须是 1..12 的整数，否则抛错。
- `actionCost(a)`：返回 0 的情况——`a.strollPlace`（闲逛地点）、`a.once`、`a.auto`、`a.visitor`、`a.household`、`a.id==='QH01'`。其余 = `nominalCost`。即：所有剧情不耗体力；去地点闲逛/串门不耗体力。
- 特例：`W04` 溪畔 `costOverride:3`（但因无 once，实际扣 3）。

## 10.3 每期开始 `syncMode(s)`

依次：
1. `s.screen='hub'`；`s.economyVersion=2`。
2. 若 `D.journeyMonths=[5,10,16,22,28,33]` 包含当前月 → `mode='journey_ready'`，`energy=0`（整月外出历练）。
3. 否则若 `month===3 && phase===2`（三月中旬）→ `mode='story'`，`energy=0`（首次同行送药，占整期）。
4. 否则 `mode='home'`，`energy=12`。
5. `s.quotas={}`（每期份额清零）。
6. `syncNotices(s)`：对 `D.notices` 中 `slot<=period` 且 `facts[id]` 不存在的条目，写 `facts[id]={period:slot}` 并推入一封信 `{id:'notice-'+id, recipient:'谷中消息', theme:'日程', due:slot, read:!!silent, body:text}`；`escort_return` 需 `facts.first_delivery` 存在才发。

## 10.4 推进 `advance(s)`（玩家点“结束本期/下一时段”）

前置检查顺序（任一失败抛错，错误文本即提示）：
1. `PreHangao.advanceGate(s, D.actions, availability)` 返回非空 → 抛该文本（必看剧情未完成时阻止推进）。
2. `s.pending` 存在 → `请先结束当前活动。`
3. `s.mode!=='home'` → `请先完成本期行程。`

结算：
- 心情回升：剩余体力 `remaining=s.energy`；`mood += remaining>=6?6 : remaining>=3?3 : remaining>0?1 : 0`，夹在 0–100。
- 若 `phase===4`（月底）：写 `s.summary={month:旧月, entries: 该月全部 history（Math.floor(h.period/5)+1===旧月）, remaining}`（月报弹窗数据）；若 `month===36` → `mode='complete'`, `energy=0`，结束（不再 syncMode）；否则 `month++`，`phase=0`。
- 否则 `phase++`。
- 最后 `syncMode(s)`。

## 10.5 心情 mood

- 字段 `s.mood` 整数 0–100，初始 60。
- 五档（`balance.moods`，按 min 从高到低匹配第一个 `mood>=min`）：

| id | 名称 | min | index |
|---|---|---|---|
| happy | 高兴 | 80 | 5 |
| comfortable | 舒畅 | 60 | 4 |
| calm | 平静 | 40 | 3 |
| low | 低落 | 20 | 2 |
| annoyed | 烦躁 | 0 | 1 |

- 每次结算后按栏目变化 `MOOD_DELTA={basic:-5,chores:-7,skill:-4,production:4,arts:2,mail:4,stroll:4}`（行动开始时的心情决定本次效率，结算后再改）。若该动作 id 属于 `PreHangao.data.scenes` 中 `status==='新增候选'` 的场景，变化为 0。
- 期末按剩余体力回升（见 10.4）。

## 10.6 物资 resources

`D.resources`：`grain` 普通食材、`cloth` 普通布料、`herb` 普通药材、`food` 干粮、`pouch` 日用布包。初始 `{grain:2,cloth:2,herb:0,food:0,pouch:0}`。均为非负整数。
- 消耗：动作 `inputs`（开始时扣），送物 C02 扣 `{[gift]:1}`，gift 只能是 `food/herb/pouch`。
- 产出：动作 `outputs`（结算时加）；P02 干粮额外 `+growth.craft.food`，P03 布包额外 `+growth.craft.pouch`。
- 回信回物：`readLetter` 首次读信时把 `returnItems` 加入资源，置 `returnClaimed=true`。

## 10.7 模式 mode 与特殊期

| mode | 含义 | 进入 | 离开 |
|---|---|---|---|
| home | 正常谷中一期 | syncMode | advance |
| story | 三月中旬首次送药（整期） | month3 phase2 | `completeStory(choice)`（choice ∈ `协同行路`/`请陆衡指导`）或 storyMode='story' 的动作 closeResult → `phase++`→syncMode |
| journey_ready | 历练月待出发 | journeyMonths | `depart` 或 storyMode='journey_ready' 的动作（非 `hg_road`）closeResult 时自动 depart |
| journey | 外出整月 | depart | `returnJourney` |
| complete | 三年结束 | 36 月月底 advance | — |

`completeStory`：写 `facts.first_delivery={choice, month, method, training:growth(s)}`；method：选`协同行路`时已学 footwork→`guided_footwork`，否则 `assisted_carry`；选`请陆衡指导`→`asked_for_guidance`。推入 history `{id:'story-delivery',name:'首次同行送药',period,cost:0,gain:0}`。

`depart`：`mode='journey'`, `energy=0`, `journey={month, returnMonth:month+1, returnRoute:s.route, visited:[], place:null}`；若 `month===5` 且 `facts['hg.pre.gate_handoff']`，加 `kind:'hangao_gate'`（赴汉皋）。
`visit(s,id)`：id ∈ `gate/street/alley/ferry`，记入 visited，`place=id`，`screen='world'`。
`returnJourney`：写 `facts['journey_'+month]={visited, returnRoute}`，history 推 `{id:'journey-'+month,name:'整月历练',period:(month-1)*5,cost:0,gain:0}`，`month++`, `phase=0`, `journey=null`, syncMode。

## 10.8 每期次数限制

- 无“行动次数”上限，只受体力约束；同一普通动作可在同期重复（扣体力）。
- `quota:true` 动作每期一次（`s.quotas[id]=true`，syncMode 清空）；`W04` 另以“本期 history 已有 W04”判断。
- 闲逛剧情：门派内 `facts.stroll_met`、串门 `facts.visit_met`、师承 `facts.mentor_met` 各记录最近一次遇到的 period，每期各最多遇一段（见 13 节）。
- 通信：同一收件人每期 C01 一封、C02 一份；`period>=179` 不能寄。
- QH01 护路棍法每期一次。
