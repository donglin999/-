# 13 活动开始→结算流程与成长公式

源：`js/qh-mode-cultivation-core.js`（`availability` `start` `beginAnimation` `finishAnimation` `resolve` `closeResult` `strollPool` `strollPick` `stroll` `grudge`），`js/qh-mode-cultivation-balance.js`（`preview` `efficiency` `stats` `gate` `level` `cap` `thresholds` `addXp` `courseHint`），`js/qh-mode-cultivation-growth.js`（`growth` `reconcile` `hints` `outcome`）。

## 13.1 `availability(s,a,options)` 判定顺序（返回 '' 表示可行，否则为提示文本）

1. C02 且给了 gift：gift 不在 `food/herb/pouch` → `此物品不能投递。`；否则把 a 视为 `inputs:{[gift]:1}`。
2. `!a` → `没有这个培养项目。`
3. `s.pending` → `请先完成或关闭当前活动结果。`
4. `mode!=='home'` 且不满足 `a.storyMode===s.mode` → complete 时 `三年培养已结束。`，否则 `本期用于行程，不能领取据点体力。`
5. `a.locked` → 返回其文本。
6. `Balance.gate(s,a)`（见 13.4）。
7. 交叉修习：`a.learn∈{sword,fist}` 且未学它而已学另一门 → `先练好已学的基础功法；交叉修习需要另一次传艺，目前尚未开放。`
8. `grudge(a)`：非 auto/main 动作，若 `teacher/heart/personal/bottleneck/cast` 中任一人在 `S.qiheBond[id].hostile` → `和{名}闹翻了，这段不会发生。`
9. `requires` 逐项：`joined`→`先与周砚正式拜师，再接受武学指导。`；`ye` 且 month>12 → `叶蘅第二年的学习日程尚待剧情编排。`；`lu` 仅在 (2月 phase≥3) 或 (3月 phase≤1) 有效，否则 `陆衡尚未到谷；来访窗口为二月下旬至三月上旬。`；`village_visit` 需 period≥2；其它键需 `s.learned[k]`，否则 `尚未受过前置指导，请查看学艺或基本功课程。`
10. `window:[a,b]`：period<a 或 period>b（`main` 动作在 month≤5 时不受上界限制）→ `此邀约的可参与窗口已注明，当前不在窗口内。`
11. `factRequires` 任一缺 → `a.factHint || '先完成相关行程或收到邀请。'`
12. `Household.gate(s,a)`（谷内剧情额外门槛，见 21 节）。
13. `adultOnly` 且 month<13 → `萧白满十八岁（第二年正月初一）后才会出现。`
14. `artNeed:{id,level}`：功法未学或层数不足 → `先把《X》练到N层/重。`（内功称“层”，外功称“重”）。
15. `relNeed:{id,min}`：`relations[id].score<min` → `与{bottleneck|heart|teacher}的关系还不够。`
16. `once` 且 `facts[once]` → `这段经历已完成，不能重复触发。`
17. `quota` 且已用（W04 看本期 history）→ `quotaMessage || '本期可采份额已用完；下期再来。'`
18. mail 且 period≥179 → `三年修习即将收束，本期没有下一期投递窗口。`；mail 再查 `contactReason`（见 32 节）。
19. inputs 不足 → `缺少{资源名} {差额}份。`
20. 体力不足 → `还差{n}点体力。`

## 13.2 `start(s,id,options)`

- 先 `Growth.ensure`；mail 默认 `recipient='陆衡'`；availability 非空则抛错。
- `options.story` 但动作无 once → 抛 `此项目不是独立剧情。`；mail 的 `theme` 必须 ∈ `近况/问候乡邻/外出准备`。
- 扣体力 `cost=actionCost(a)`，扣 inputs。
- `needsChoice = !directResult && a.choice && (!a.learn || !learned[a.learn])`（只有首次学习的课才出两选一）。
- 写 `s.pending={id:'cultivation-'+(++sequence), economyVersion, action, period, cost, energyBefore, moodBefore, balanceVersion:2, stage:needsChoice?'choice':'ready', theme, recipient, gift, inputs, result:null}`；剧情/来客加 `story:true, storyStep:0`；来客加 `visitor:Visitors.init(s,id)`。
- `s.selection={category, action:id}`；`options.animate` 时 `beginAnimation`。

## 13.3 动作计时

`beginAnimation(s,now)`：仅非剧情、未结算的 pending；`pending.animation={startedAt:now, duration:2000, done:false}`。`finishAnimation` 在 `now-startedAt>=2000` 时置 done。`resolve` 在动画未 done 时抛 `请等待本次动作完成。`（即每次修习动作演出固定 **2000ms**，演出细节见 50 节）。

## 13.4 `Balance.gate(s,a)`（功法课门槛）

art = 以 `a.id` 为 action 的功法（见 41 节）。
- QH01 本期已做 → `本期笔记已复盘，下期再来。`
- 无 art 或已学 → 通过。
- `sceneTaught` → `《X》要{teacherCall}亲自教，闲逛时去找{teacherCall}。`
- month<art.month → `《X》最早在第N个月传授。`
- 外功且 grade≠丁 且非护路棍法：`facts.gy_martial_major.path` 必须与 art.path（剑→sword，其它→fist）一致，否则 `须先选定对应主修路线。`
- prerequisite 未达 → `先把《P》练到N层/重。`
- grade 乙 需 `facts.gy_year_exam_seen` → `先完成第一年的师门考校。`
- learn_req 逐项对比 `stats(s)` → `根基不足：{臂力/根骨/身法/定力/悟性}需v，当前x。`

## 13.5 收益公式 `Balance.preview(s,a,first,fg)`

- 五维 `stats(s)`：基值 `s.trainingBaseStats`（缺省 str/con/agi/wil/wis 各 3）+ 培养加成；`str` 加成 = `min(9, floor((progress.sword+progress.fist)/750))`；其余按 13.7 规则表。
- 学习效率 `e = min(10, stats.wis) + min(10, floor(min(200, progress.understanding)/20)) + mood.index`。
- 本次成果 gain（写入 `progress[key]`，key = `fg?.gain || a.gain`）：

| 条件 | 系数 coefficient | gain |
|---|---|---|
| once/visitor/auto（剧情） | — | fg 存在：`round(fg.amount*legacyScale[key]||1)`；否则 `a.amount`（install 时已乘 legacyScale） |
| QH01 | 0.4 | `round(e*2)` |
| W04 | 1.4 | `round(e*7)` |
| basic：B03/B04 | 1.6 | `round(5*e*1.6)` |
| basic：B01 或内功课 | 1 | `5*e` |
| basic：其他 | 2 | `round(5*e*2)` |
| skill | 1 | `5*e` |
| arts | 1 | `e` |
| production | 0.7 | `round(e*0.7)` |
| chores：D01 | 0.2 | `round(e*0.2)`；其它 chores 0.4 |

- 功法熟练 xp：有对应 art 且非首次 → QH01 为 gain，其余 `5*e`；首次传授 xp=0。
- `legacyScale={foundation:6,coordination:8,footwork:7.5,breathing:3.75,observation:10,listening:10,sword:3.75,fist:3.75}`。
- 旧存档 `pending.legacyBalance` 的结算：`gain=round(amount * 心情倍率)*legacyScale`，倍率 mood≥75:1.15，≥45:1，≥20:0.9，否则 0.75（fixedGain 时 1），xp 非首次 25。

## 13.6 功法层级

- 曲线 `curves`：A `[0,25,75,150,250,375,525,700,900,1150]`；B `[0,25,75,175,325,525,775,1075,1425,1850]`；C `[0,50,125,275,500,800,1175,1625,2150,2750]`。
- 外功 10 重用整条；内功 5 层取 `[c0,c2,c4,c6,c9]`。
- `level = min(cap, 1 + 满足 xp>=阈值 的阈值个数(去掉第0项))`。
- `cap`：有 earlyCap 且 month≤5：丁级 → 内2/外3，否则 earlyCap；有 `balanceLegacyCaps[id]`：取 max(旧上限, 早期3/2 或 10/5)；丁级 month≤5：内2/外3；否则 内5/外10。
- `addXp`：xp 累加后夹到 `thresholds[cap-1]`，保留一位小数。
- 精通：外功 10 重时 `mastery.effect` 生效（如 `{mp:-1}` 内力−1，`{pow:0.05}` 威力+5%）。

## 13.8 `resolve(s,choice)` 结算顺序

1. 来客须 `visitor.phase==='commit'`；choice 取 `visitor.selected`。stage 为 choice 时 choice 必须是合法索引。
2. 首次学习：`learned[learn]={source:a.id, period}`；sword/fist 首学写 `facts.gy_martial_major={path, source, period}`（主修路线）。
3. 算 learning（13.5）；`progress=counters()`；`progress[key]+=gain`；`addXp`。
4. outputs 入库（P02/P03 额外）；`once`→`facts[once]={period, choice}`；来客 `Visitors.effects`；quota 标记。
5. mail：`Relations.record` 生成事件，推入 letters `{id, theme, recipient, author, gift, due:period+1, read:false, body, returnItems, returnClaimed:false}`。
6. 心情按 MOOD_DELTA 改。
7. `p.stage='result'`，`p.result={id,name,feedback,gain,gainName,first,cost,energyBefore,energyAfter,moodBefore,moodAfter,learning,outputs,choice,recipient,gift,relationship,training:{before,after},gainKey,effectChanges(Growth.outcome),nextEffect(Growth.hints+courseHint),relationshipChanges[{id,name,before,after,delta,reason,stage}],courseBeat:beats[first?0:min(1,len-1)],lesson:PreHangao.lesson(...)}`。C02 feedback 改为 `给{收件人}的{物名}已交给捎物人，下一期查看回复。`
8. history 推入 `{id, balanceVersion, artXp, artId, action, name, period, cost, freePractice:cost===0, nominalCost, gain, gainKey, skillId, systemId, choice, [recipient, gift]}`。

`closeResult`：清 pending、`migrateEconomy`；storyMode='story' 时推 story-delivery history 并 `phase++`+syncMode；storyMode='journey_ready' 且非 `hg_road` 时 depart。

## 13.9 闲逛抽取 `strollPick(s,place)`

- 候选池：category=stroll、有 once、非 auto/hidden/strollPlace，地点（`Scenes.placeKey`，`bookhouse_inside` 归为 `bookhouse`）等于所选地点，本期该类额度未用（mentor 用 `facts.mentor_met`，书屋/梯田/水碓用 `visit_met`，其余 `stroll_met`），且 availability 为 ''。
- 权重：`window` 存在且 `window[1]-period<=5` 为 3，否则 1。
- 确定性随机：FNV-1a，种子字符串 `period+'|'+place+'|'+sequence+'|'+history.length`，`h=2166136261`；每字符 `h^=code; h=Math.imul(h,16777619)>>>0`；`r=h%总权重`，按权重落点。
- `stroll(s,id)`：抽中则 `start(s,pick,{story:true})` 并写对应 met 键=period，返回 `{story:id}`；未抽中返回 `{story:null,text:a.idle}`（地点的闲置文本），不扣体力。
