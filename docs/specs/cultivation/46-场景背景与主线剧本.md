- `placeKey(p)`：键或别名→键；**对不上一律 `courtyard`**。
- `resolve(scene,season)`：time 非法→day；该地点无此时间的图→用 day 图（`shown='day'`）；返回 `{place,time,shown,src,alt,name,timeName}`，`timeName` 白天为空，否则 `傍晚`/`夜`。注意 dusk 无专图，全部落回白天图（地点牌仍写“傍晚”）。
- `season(s)=['spring','summer','autumn','winter'][floor(((month-1)%12)/3)]`：1–3 月 spring、4–6 summer、7–9 autumn、10–12 winter。
- `carry(prev,line)`：句子写了 place/time 就换，否则沿用。

## 2. 主控接入
- `applyScene(scene)`：`r=resolve(scene,season(state))`，把 `.cu-background` 的 src/alt 换掉（全屏背景，见 03 节）。普通活动也用动作的 place 调一次。
- `lineScene(x,a)`：句子有 place/time 用句子的，否则用动作定义的。
- `sceneTag(el,r)`：剧情根节点 `data-place=r.place`、`data-time=r.shown`（夜间立绘压暗靠它）；追加 `p.cu-place-tag`：文本 `r.name`，非白天再加 `<small>timeName</small>`。样式见 48 节。

## 4. 展开算法 `expand(id,c0)`
1. 上下文补默认：`learned:{}`、`opening.chen_injury='unknown'`、`first_delivery.method=null`、`facts:{}`。
2. `pick(blocks,c)`：顺序遍历；`main` 且 `when(c)` → 全部行；其他按 group 只处理一次：该组（非 branch）先找第一个 `variant` 且 when 为真，否则第一个 `fallback` 且 when 为真，取其行。
3. 无 branch：`all=pick(全部)`，少于 3 行抛 `剧本过短：id`；返回 `intro=all[0..-3]`、唯一线性选项 `{key:'linear',text:'',auto:true,lines:[倒数第二行]}`、`closing=[最后一行]`。
4. 有 branch：first/last 为第一个与最后一个 branch 块下标；`intro=pick(first 之前)`，`closing=pick(last 之后)`；选项按 branch 的 `choice` 去重，每个选项：`cc={...c,choice:k}`，命中块 = 同 choice 且 `when(cc)` 的 branch 块；`text = 首块 label 按全角冒号 '：' 切取前半`；`lines`、`effects` 为命中块拼接。
5. closing 为空补 `{speaker:'narrator',text:'……'}`；intro 为空用 `{speaker:'narrator',text:stage}`。
6. 结果再经 household 的 enter/form/scene/relLines/stageCast 与 Dialogue.apply（20、42 节）。effects 在 household `effects` 中写入 facts。
