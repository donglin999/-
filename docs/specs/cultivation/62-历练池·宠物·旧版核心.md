# 62 历练（共享心得池）、宠物、旧版养成核心与出发前战斗图

## 1. 历练池 `SharedInsightPool`（源：`js/shared-insight-pool.js`）
培养修习按月折算成“历练”，可在江湖侧消费提升等级。调用：`js/core.js` 与 `js/qihe-ui-model.js` 的 `SharedInsightPool.sync(s)`、`state(s)`。存档 `S.jianghuInsight={version:1,balance,earned,spent,receipts:{来源id:数额},ledger:[]}`，校验 `balance===earned-spent`、均为非负安全整数，失败抛 `历练记录无法读取，原存档已保留`。

`rewards(s)` 收入表（每个 id 只领一次，记在 receipts）：
| id | 数额 | 名称 | 条件 |
|---|---|---|---|
| errand:bowls / cloth / medicine | 20 | 送碗 / 备布 / 送药 | `s.prologue.errands[key]==='done'` |
| item:qh_escort_notes | 360 | 走镖手札 | `s.itemInsight.qh_escort_notes===true` |
| story:rescue / evidence-v2 / settle / apprenticeship | 80 / 80 / 40 / 100 | 栖河救援 / 邻村对证 / 归云谷安顿 / 正式拜师 | `s.qiheChapter.events[key]===true` |
| month:m | m≤12 → 80；≤24 → 120；其余 180 | `修习第m月` | m ≤ 已完成月数（`mode==='complete'` 为 36，否则 `clamp(month-1,0,35)`），且该月 history 中至少有一条 `period∈[0,180)` 的记录（`floor(period/5)+1===m`） |
| year:y（1–3） | y×300 | `第y年修习回顾` | 完成月数 ≥ 12y，且该年 12 个月每月都有记录 |
- `sync(s)`：新行写 receipts，`balance += amount`、`earned += amount`，ledger 追加 `{...row,kind:'gain'}`，ledger 只保留最后 100 条；返回本次新增。
- `debit(s,amount,detail)`：1 ≤ amount ≤ balance，否则抛 `历练不足或消耗不正确`；`balance-=`、`spent+=`，ledger 记 `{kind:'spend',amount,...detail}`。
- `levelNeed(lv,exp)`：lv≥100 → 0；否则 `max(0, 50*(100*99 - lv*(lv-1)) - exp)`（升到 100 级所需总量；每级需 `lv*100`）。
- `levelQuote(lv,exp,balance,request)`：request 须正整数（`请输入正整数历练`）；`cost=min(request,balance,levelNeed)`，为 0 抛 `已满级`/`历练不足`；循环 `while(after<100 && remaining≥after*100){remaining-=after*100; after++}`，满级时 remaining=0；返回 `{cost,before,after,exp,points:(after-lv)*3}`（每升一级 3 属性点）。

## 2. 宠物（源：`js/pets.js`，战斗外挂，培养模式不直接调用）
- `PET_DEF={dog:{guardMp:6,guardRatio:.5,healRatio:.3,growth:['str','agi','con']}}`。存档 `S.pet`（当前宠物 id）、`S.pets[id]={st,lvSeen,hp,mp,equip:{acc}}`。
- `petEnsure()`：旧档 party 中的 `dog` 移出队伍改为 `S.pet='dog'`；从 `S.mates[id]` 迁移属性后删除；按主角等级差 `(S.lv - lvSeen)*3 + 旧未分配点` 轮流投入 str→agi→con；升级后 hp/mp 置 null（=满）。
- `adoptPet(id)`：设 `S.pet`、ensure、`resetFollowers()`、`save()`。
- 宠物回合 `petTurn`：目标为血量比例最低的敌人；主角 HP ≤50% 且 MP≥6 且无有效护主 → `护主`（`hero.guardBy=宠物, guardUntil=round+1`，飘字 `大黄护主` `#9fe0b5`，等待 450ms）；HP ≤30% 且够蓝 → 技能 `lick` 治疗主角；敌人还有未知弱点 → `sniff`；否则普攻。
- 护主期间敌方对主角的直接伤害（>1）：宠物承受 `floor(dmg/2)`，主角承受余下。
- 战后：败且非 noLose → 宠物 hp/mp 重置为满；否则满值记 null、未满记实际值；`save()`。

## 4. 旧版首版核心（源：`js/qihe-cultivation-data.js`、`js/qihe-cultivation-core.js`）
index.html 里这两个文件**先**加载并注册 `CultivationData` / `CultivationCore`，随后 `qh-mode-cultivation-data.js` / `-core.js` 用同名全局覆盖。现行逻辑以后者为准（10–14 节）；首版只用于理解字段来源，Godot 不需要单独实现。首版要点（与现行差异）：
- 栏目费用 basic 5、skill 5、production 3、arts 3、chores 2、mail 4、stroll 6；体力上限 10（现行 12）；`journeyMonths=[5,10,16,22,28,33]`；3 月 phase 2 为 `story`（送药）。
- 初始存档 `{version:1,route:'mountain',month:1,phase:0,energy:10,mood:60,mode:'home',joined:false,learned:{},progress:{},resources:{grain:2,cloth:2,herb:0,food:0,pouch:0},facts:{},quotas:{},history:[],letters:[],pending:null,summary:null,sequence:0,selection:{category:'basic',action:'B03'},journey:null,screen:'hub'}`。
- 收益心情系数：mood≥80 ×1.1，<30 ×0.9；闲逛 +3 心情；结束本期按剩余体力 ≥3 +3、>0 +1 心情。动画时长固定 2000ms。
- 资源名：grain 普通食材、cloth 普通布料、herb 普通药材、food 干粮、pouch 日用布包；进度名表 `progressNames`（foundation 站位与基础、footwork 步法、breathing 吐纳、observation 察势、coordination 协调、sword 入门剑式、fist 粗浅拳脚、understanding 武学理解、medical_notes 医案记录、herbs 辨药、cooking 炊事、sewing 缝补、travel 行路、correspondence 通信）——现行版沿用这些名称。
