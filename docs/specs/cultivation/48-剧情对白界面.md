## 2. 构图 `composition(cast,speaker,primary,heroSide)`
1. 去重后 `heroFirst`：萧白（hero*）排最前；定义写 `heroSide:'right'` 时排最后。说话人有立绘但不在 cast 则追加。
2. 总数 ≤3：全部前景。
3. >3：前景选 3 人，优先 `speaker`、萧白、`primary`（定义的 actor），不足按 cast 顺序补；其余进 roster（头像条）。前景再 heroFirst 排序。
- 说话人位置 → 气泡尾巴：index 0 `left`，最后 `right`，其余 `center`；整幅双人图为 `center`。

## 3. 双人图 duo
- 句子 `duo:'路径'`：只写 duo → 整句只显示这张图（`img.cu-story-duo`，居中，高 82%，max-width 72%，底对齐）。再写 `duoCast:[...]` → 这张图只占一个站位（`data-character="duo"`，类 `cu-story-duo-actor cu-story-{文件名}`），cast 中属于 duoCast 的人折叠到 duo。
- 选项画面沿用同一 encounter 的上一句 duo。

## 4. DOM 结构 `render(host,opts)`
```
section.cu-story-scene.cu-visitor-story[role=dialog][data-speaker][data-choice][data-narrator][data-time]
 ├ div.cu-story-stage[data-solo="hero"?]   ← 只有萧白一人时
 │   └ img.cu-story-actor.cu-story-{id}(.cu-story-hero_{form}) style="--actor-index:i;--actor-count:n"
 │       data-mood data-character data-speaking [data-facing=left] [data-motion]
 ├ aside.cu-story-roster > div.cu-story-roster-person.cu-story-{id} > span.cu-story-avatar>img + span 名字
 └ div.cu-speech.cu-speech-{left|center|right}(.cu-speech-choice)
     ├ span.cu-speech-tail  ├ h2 说话人名  ├ p 台词(pre-line)
     └ div.cu-speech-answers(.cu-speech-continue) ← 按钮
```
主控追加：`p.cu-place-tag`（地点牌，46 节）、`div.cu-story-outcome`（结算）。`data-mood` = `resolveMood(...)`（hurt_ 前缀去掉后解析）。
- `next(action,label='继续对白')`：`button.cu-dialogue-next[data-cu=action]` 内 `<span>▾</span>`，铺满整个气泡（inset:0），点气泡任意处继续。
- `answer(action,id,label,cost)`：`button.cu-dialogue-answer[data-cu][data-id]` `<span>label</span>`，cost 非 0 时加 `<small>体力 N</small>`。
- 语音：签名 `encounter|speaker|text` 变化时 `CharacterVoice.stop()`；换剧情时 `beginInteraction()`；非选项、非旁白、非信件且 speaker ∈ voiceIds（ye→ye，pei→pei-zhigu，zhou→zhouyan，lu→lu-heng）时 `begin(名字,台词,voiceId)`。

## 5. 立绘动作 motion
`line.motion` 为字符串（作用于说话人）或 `{who,move}`（who 可为 `duo`）；一句最多一个；选项画面不播；同签名重绘不重播。方向变量：每个 actor `--away` = 单人 0 / 最左 -1 / 最右 1 / 中间按所在半边；`--toward = -away`。

| move | 时长 / 缓动 | 关键帧（translate 以自身宽高 % 计） |
|---|---|---|
| knock | .62s cubic-bezier(.2,.9,.25,1) | 14% (away·16%, 1.2%) rot away·7° → 30% (away·13%,0) rot away·3° → 100% 归零 |
| flee | .5s (.3,0,.2,1) | 12% toward·3% rot toward·2° → 100% away·28% rot away·4°（停在外面） |
| startle | .42s (.3,1.6,.5,1) | 35% y -5% scale 1.03/.97 → 70% scale .98/1.02 → 100% 1 |
| step | .38s (.2,.8,.3,1) | 60% (toward·7%,-1%) → 100% toward·6%（保持） |
| drag | .9s (.5,0,.75,.2) | 15% away·-2% rot away·-6° → 100% (away·70%, 9%) rot away·-14° opacity 0 |
| shake | .4s linear | x: -1.6,1.6,-1.2,1.2,-.6,.6 %（15% 间隔）→0 |
| slump | .7s ease-out | → y 3%，scale 1 / .975（保持） |
| nod | .5s ease-in-out | 30% y 1.6% → 60% y -.4% → 0 |
| enter | .45s (.15,.85,.3,1) | 从 away·45% 透明 → 原位不透明 |
全部 `both` 填充；`prefers-reduced-motion` 时关闭。
