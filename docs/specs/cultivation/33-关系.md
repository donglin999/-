# 33 人物关系（好感）

源：`js/qh-mode-cultivation-relations.js`（`profiles` `stages` `inspect` `record` `story`），`js/qh-mode-cultivation-household.js`（`bonds` `MORE_BONDS` `effects`），`js/qh-mode-cultivation-core.js`（`grudge` 及 `relNeed` 判定），`js/qh-mode-cultivation-dialogue.js`（`relations(r)` 用 `D.correspondence` 覆盖台词）。

## 33.1 存档

`s.relations[profileId] = {score: 0..100 整数, interactions: [event…], returnOffered: bool}`。event：`{id(=pending.id 或剧情id), period, kind:'letter'|'gift'|'story', gift, delta, relation(inspect 快照), reason, author, body, returns}`。同一 id 只记一次（读档/重放幂等）。

## 33.2 阶段与上限 `inspect(s,name)`

- 阶段名 `['初识','熟络','信赖','托付']`；按 score：<20 初识、<50 熟络、<80 信赖、否则托付。
- “瓶颈门”`gates`：从第 0 道起依次检查，连续满足的门数 g（最多 3）。上限 `cap=[19,49,79,100][g]`。
- `atCap = score>=cap`；`requirement`：若该门设有 `missed:{until, text}` 且 `period>until` 则显示错过文本，否则 `hints[g]`。
- 返回 `{id,name,score,cap,stage,atCap,requirement,missed}`。

## 33.4 通信涨幅 `record(s,pending)`

```
kind   = C02 ? 'gift' : 'letter'；gift = pending.gift || 'food'
monthly= 本月(同 floor(period/5))同 kind 已获 delta 之和
repeat = gift 时：最近 5 期内（period >= 当前-5）送过同一物品的次数
requested = letter ? 1 : repeat>=2 ? 0 : repeat===1 ? 1 : gift===fav ? 3 : 1
remaining = max(0, (gift?4:2) - monthly)          // 每人每月：礼物上限 4、信件上限 2
delta = min(requested, remaining, max(0, cap - score))
reason = 已到上限 '需关键剧情突破' | remaining==0 '本月日常往来贡献已达上限' | requested==0 '近期重复送同类物品' | delta<requested '达到当前阶段上限' | ''
returns = (gift && gift===fav && !repeat && !returnOffered) ? profile.returns : {}   // 每人一生只回一次物
body  = letter ? letter文本 : repeat ? repeat文本 : gifts[gift]；有回物则追加 '\n'+returnText
author= 乡邻：pouch 或重复时 '周婶'，否则 '陈伯'；其他=收件人名
```
`giftPreview` 在拷贝上调用 record，用于包裹格子上显示“关系 +n”。

## 33.6 关系门槛与敌对

- 动作 `relNeed:{id,min}` 需 `relations[id].score>=min`（如心意剧情）。
- 开始部分（栖河章节）`S.qiheBond[npcId].hostile` 为真时，该人参与的闲逛/串门/来客剧情全部不触发（`grudge`），提示“和{名}闹翻了，这段不会发生。”；三方代表 xu/cen/shen 敌对时也不出现在收件人中。

## 33.7 展示

- 邮件人物页右下 `.cu-mail-relation`：`{阶段} · {score} / {cap}` + 换行 + `关系暂止于此阶段。`（atCap）或 `下一阶段条件：{requirement}`。
- 结算条：`♡ {名} before → after（{阶段} · {reason}）`。
