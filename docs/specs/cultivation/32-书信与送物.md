源：`js/qh-mode-cultivation-mail.js`（`mount` `controls` `roster` `inbox` `openBag` `closeBag` `inventory` `bagPage` `cells` `drawAvatars`），`js/qh-mode-cultivation-mail.css`，`js/qh-mode-cultivation-core.js`（`giftRecipients` `letterRecipients` `contactReason` `readLetter`），主控 `onClick` 中 mail-* 分支。

## 32.1 收件人

- 周砚 joined；叶蘅 month≤12；陆衡 总是；乡邻 period≥2；江采薇 gy_noodles_seen；殷红缨 gy_night_return_seen；裴知古 met_pei‖gn_lamp_seen；钟拙 gy_prelude_tour_seen‖gy_noodles_seen；方迟 gy_fang_back_seen；卢小豆、周小满 gy_noodles_seen；徐令仪/岑霜/沈雁回 hg_aftercare_seen 且 `S.qiheBond[xulingyi|censhuang|shenyanhui].hostile` 不为真。

`letterRecipients(s)`（送信，只寄给不在谷里的人）：上表中 `lu neighbor pei xu cen shen`，以及方迟（gy_fang_leaves_seen 且未 gy_brother_hurt_seen，即下山期间）。

`contactReason`：收件人不在名单 → `尚未认识或不能投递给这位收件人。`；本期已对此人做过同一动作 → `{名}本期已收到一封近况信，下期再寄信。` / `…已收到一份礼物，下期再赠送。`

## 32.2 操作流

1. 底栏“邮箱”（mail 栏）→ `view='picker'`，Mail 以 kind='mail' 挂载：左侧插画 `mail-classic/mail-brush.png`，右侧“送物”入口。
2. 标签：`送物`(C02 → view gift-npc) / `送信`(C01 → view letter-npc) / `回信 N`（未读回信数，→ view mail-inbox）。
3. 人物页：左列花名册，点人物 → `recipient=名`；中间显示该人大立绘；右侧操作区与关系框。
4. 送信：按钮「送信 / 寄给 X 的近况信 / 确认寄出」→ `begin('C01')`，theme 固定 `近况`。不可寄时按钮禁用并在下方显示原因。
5. 送物：「送物 / 从包裹中挑选一份物品 / 选择物品」→ 打开包裹弹窗；点可赠物品 → `gift=id; begin('C02')`。
6. 演出：kind='motion'，画框 `.cu-training-frame.cu-mail-motion` 播放 C01/C02 片段 2000ms，下方文字“封好近况信”/“包扎赠送物品”。
7. 回执 kind='result'：印章“寄出/托送”，标题（送物为 feedback，信为“信已寄出”），送物行 `{物名} n+1 → n`，`本期通信成果已记录`，`关系 +d · {阶段} score / cap`，原因与要求，`下一期查看对方回信[与回物]。`，按钮「继续」。
8. 下一期：回信 `due=period+1` 到达；收件箱 `mail-read` → `readLetter`（首次领取回物入 resources），提示“回信已读，回物已收进培养包裹。”或“回信已读。”。

## 32.3 包裹 inventory

- 可赠三格固定在前：`food 干粮(药食)`、`herb 普通药材(杂物)`、`pouch 日用布包(杂物)`，图 `mail-v7/{id}.png`。
- 不可赠：grain、cloth（有库存时列出）、世界背包 `S.bag` 物品（按定义归类：兵器/护具/佩饰/要物/药食/杂物）。
- 分类下拉 `['全部','可赠送','兵器','护具','佩饰','药食','杂物','要物']`；搜索框 maxlength 80，按名称包含匹配（IME 组字期间不刷新）；每页 `PAGE_SIZE=36`（12 列×3 行），不足补空格；`‹ n / m ›` 翻页（只有 1 页时隐藏）；计数 `N 件 · 每页36格`。
- 格子：图 3.35cqw，名称，右上角 `数量[ · 关系 +d]`；不可点原因：`无库存`/`不可赠送`/availability 文本。
- 底部提示：contactReason ‖ `体力不足 · 当前e / 需要2` ‖ `点击赠送1份；卡片显示实际关系增量，达到瓶颈时不会提升`；「取消」。
- 打开包裹时外壳设 `inert`，遮罩 `.cu-mail-backdrop`（`#312d236e`，z8）点击关闭。
