# 20 谷内剧情引擎（household）

源：`js/qh-mode-cultivation-household.js`（全局 `CultivationHousehold`；Node 下由 `qh-mode-cultivation-visitors.js` 的 `.household` 带出）。家务 D01–D05 的数值见 `11-活动总表.md`，这里只讲“谷中人家”剧情。

## 1. 定义 → 动作（源：`const actions` / `const notices`）
`definitions` 共 108 条（明细见 21–23 节）。每条定义转成活动时统一追加：

定义字段：`id place time name teacher actor window[a,b] cast[] gain amount notice auto prelude linear main mentor teaches artNeed{id,level} neighbor side quiet hidden training bottleneck afterMentor requires[] factRequires[] factHint relNeed{id,min} adultOnly personal heart fight{bg,foes[]} sparWith needSkill storyMode src heroForm enters{actor:句序} state{actor:'hurt'}`。

**预告**（notices）：有 `notice` 的定义生成 `{slot:max(0,window[0]-(auto?1:2)), id:id+'_notice', text:(auto?'【师门】':'【师门·支线】')+notice}`，在 slot 时段起显示在消息栏。

## 2. 何时开场（源：`due` / `upcoming` / `gate`）
- `due(s, availability)`：先问 `PreHangao.due(s,actions,availability)`（见 60 节），有就返回；否则返回第一条 `auto && window[0]≤now≤window[1] && !facts[once] && !availability(s,a)` 的动作（availability 返回空串=可用）。主控每次 render 前调用，有则直接进剧情（不耗体力）。
- 非 auto：玩家在“闲逛”里去 `place` 且当前时段 = `time`（day/dusk/night）时遇到；同样过 availability（requires、factRequires、relNeed、artNeed、adultOnly=`month≥13` 等，见 13 节判定顺序）。factRequires 不满足时显示 `factHint`。
- `upcoming(s)`：`!prelude && !seen && window[1]≥now && window[0]≤now+5`，供“近期动静”列表。
- `gate(s,a)`：`needSkill` 且 `learned.sword`、`learned.fist` 都无 → 文本 `先学会一门招式（入门剑式或粗浅拳脚）。`
- 入谷 prelude：`gy_noodles`[0,4] 之后 `gy_prelude_tour→stance→xinfa→hair` 都是 window [0,0]，以 factRequires 串成一条线依次自动连播（不设选择、不结算，`title` 行为全屏字幕卡）。

## 3. 剧本组装（源：`script(id,c)` = `stageCast(relLines(scene(form(enter(raw(id,c),d),d),d),id,c),d)`）
剧本对象：`{intro:[line], choices:[{key,text,lines:[line],effects?:['k=v']}], closing:[line]}`；line：`{speaker,text,cast?,mood?,moods?,form?,place?,time?}`。`speaker:'title'` 为字幕卡，`'narrator'` 为旁白，`'hero'` 为萧白。linear 剧情为 `[{key:'linear',text:'',auto:true,lines}]`（一条自动分支）。

1. `raw`：脚本来源优先级 `CultivationSide.scripts` → `CultivationNeighbors.scripts` → `CultivationMentors.scripts` → 有 `src`（如 `M-02`）时 `CultivationScripts.expand(src,c)` → 本文件 `EXTRA[id]` → PRELUDE → 内联。
2. `enter`：`enters={人物:第几句起}`，intro 第 i 句若未写 cast，则 cast=`d.cast` 去掉 `i<at` 的人。
3. `form`：有 `heroForm` 时把 cast/speaker 中 `hero*` 换成 `hero_{l.form||d.heroForm}`。
4. `scene`：每句继承上一句 place/time，起点为定义的 `place/time`（缺省 courtyard/day）；分支从 intro 最后一句的场景起；closing 不改，由对白引擎按所选分支最后场景续接。
5. `relLines`：`REL_ALT[id][原句]=[{who,min,text,mood?,adult?}]` 依次判断取**最后一个**满足 `rel[who]≥min` 且（非 adult 或 c.adult）的替换文本；`CHOICE_NEED`：`gy_go_in_stead.go_with_yin` 需 yin≥30、`gy_mid_autumn.moon_yin` 需 yin≥55，筛空时保留最后一个选项。
6. `stageCast`：`CAST_CUTS[id]={intro:{句序:[cast]},branches:{key:{}},closing:{}}` 从某句起切镜，之后沿用。

`extra(s)` 上下文：`{...PreHangao.extra(s), rel:{id:score}, adult:month≥13, pei:{chests}, yinJoined, sparWins, learned:{footwork,fist,sword}, opening:{chen_injury:'light'|'rest'|'unknown'}, first_delivery:{method}, facts:{pre_departure_talk_seen, first_ye_work_seen}, yinScore, major:(gy_martial_major.path||单学剑→sword|单学拳→fist||gy_fist_or_sword_choice), go, footwork, ledger, ...}`。

## 4. 立绘与表情（源：`portraitFor` / `resolveMood` / `moodsFor`）
- 萧白发型 `heroForm(s)`：`facts.gy_hair_long` 或不在 1 月 phase0 → `long`；否则看过 stance → `mid`，否则 `short`。
- 路径：萧白 `assets/production/cultivation/hero-empty/hero_{form}_empty_{state}.png`，state 映射 angry→serious、awkward→worry、laugh→smile、fun→smile；short/mid 无 hurt/sleep（hurt→worry，sleep→normal）。他人 `household-v1/{id}_{mood}.png`，mood=fun 用原图 `household-v1/{id}.png`。`recipient` 别名 `neighbor`。
- 表情档 MOODS：hero_long `normal smile serious surprise worry angry sad awkward sleep laugh hurt`；hero_short/mid 去掉 laugh/hurt；zhou/shimu/yin/zhong 八档（含 fun）；fang 加 `hurt_normal hurt_serious hurt_smile hurt_sad`；dou 加 sleep；man `normal smile surprise worry sad fun`；ye 七档无 fun；goose `normal fun`；lu 六档；pei/peishu 七档；xu/cen/shen `normal smile serious worry sad surprise`；访客 mo_songnian/meng_zhiwei/zhaochuan_courier 四档。
- 回落 FALLBACK：worry→sad,serious,normal；angry→serious；sad→worry；fun→laugh,smile；laugh→fun,smile；awkward→worry；hurt_* 在 hurt 档内回落到 hurt_normal；最后 normal。
- `moodsFor(eventId,line,cast)`：每人保持上一句表情；只有 `line.mood`（说话人）/`line.moods`（任意人）指定才换。STRONG=`surprise angry sad fun laugh awkward` 立即换，且两句后无新指示回到 `TONE[eventId][人]||'normal'`；轻微变化需距上次换 ≥2 句。`state:{fang:'hurt'}` 时该人用 `hurt_` 前缀档。

## 5. 结算（源：`effects(s,p,key)`，p.action=剧情 id，key=所选分支）
1. `bonds[id][key]=[人名,值]` 或二维数组 → `CultivationRelations.story(s,人名,值,p.id)`（与 `MORE_BONDS`、Side/Neighbors/Mentors 的 bonds 合并）。`gn_depart` 的 join/roster 固定 裴知古+4。
2. 殷红缨入队：`gy_go_in_stead` 选 `go_with_yin` → `facts.gy_yin_recruit={period,source}`；否则 `gy_new_year` 时 yin≥40 入队，不足记 `facts.if_yin={missed,period}`。`gn_depart` → `facts.gy_pei_join`。
3. 战斗：`facts.spar_log={wins,fights}` 累加；sparWith 首胜 `facts.spar_first_{who}` 并 `resources.food+1`。
4. `gy_yin_bond`：bond_yin → `facts.gy_bond_yin`；not_yet → 删除 `gy_yin_bond_seen`（可再遇）。
5. 有 src 的剧情：所选分支 `effects:['k=v']` 写入 facts（`'true'`→true），`first_delivery.method` 特例写 `{choice:key==='guidance'?'请陆衡指导':'协同行路',month,method,source}`。
6. prelude：stance → `learned.stance`；xinfa → `learned.breathing`；hair → `facts.gy_hair_long`。
7. 再调 `CultivationMentors.effects`、`PreHangao.effects`。收益 `gain/amount` 由主控固定收益发放（fixedGain）。
