# 05 我方指令菜单、目标选择与输入

源：`js/bui.js` `allyTurn()`（现行，覆盖 battle.js 同名，逻辑一致并加入 storyLesson 回调、BattleAuto、防重入）、`js/battle.js` 键盘监听与 `unitAt()`、`js/main.js` 指针分发、`js/bui.js` `renderCards()` 末尾帮助条。

## 1. 菜单层级
```
主菜单 menu('第 N 回合')
 ├ 攻击  atk  ico=[atkType]  right=atkName  desc=`以${atkName}出手（${atkType}）· 蓄势可连击 ${1+bpUse} 次`
 │    → B.pv = bp=>({t:atkType,pow:1,hits:1+bp}) → 目标选择(敌,单体) → doAttack(u,t,bp)
 ├ 武学  sk   ico=[武]  dis=!skills.length  desc='施展武学，消耗内力'  → 武学子菜单
 ├ 道具  it   ico=[药]  dis=背包无 heal/mp 物品  desc='使用行囊中的药物' → 道具子菜单
 ├ 防御  def  ico=[守]  desc='本回合受伤减半，下回合率先行动'
 └ 逃跑  run  ico=[走]  desc='试图脱离战斗'   仅当 !boss && !tutorial && !noFlee
```
- 主菜单无“返回”。默认选中第一个非禁用行（storyLesson 时固定 0）。
- 禁用行：可悬停（仅 storyLesson），点按播 `menu_close(.5)`，并回调 `storyLesson.wrong(u,row)`。

### 武学子菜单 `menu('武学', …, back=main)`
每行：`label=sk.name`；ico=`tyTag(bi.t || (heal||buff?'医':'内'))` + 有 `bi.e` 再加 `tyTag(bi.e)`；`right` = 内力消耗 `<cost>内`（不足时数字标红 class `no`）；`why` = skillWhy 或 `内力不足`；`dis = lack || need`；desc = `sk.desc + （need）`。
选中后：`B.pv = bp=>skillPv(u,k,bp)`；目标类型 `tg = bi.tgt || (heal?'ally':'foe')`：
- `self` → 直接执行
- `foe`/`foes` → 选敌（foes 为全体）
- `ally`/`allies` → 选友（allies 为全体）
返回键回武学菜单。

### 道具子菜单 `menu('道具', …, back=main)`
可用物品：`S.bag` 中数量>0 且 `ITEMS[k].heal||ITEMS[k].mp`。行 `label=名`，`ico=物品图标`，`right='×n'`，`desc=物品描述`。无蓄势控件。
→ 选我方单体（返回回道具菜单）→ 执行（强制 bp=0）：`S.bag[k]--`；`lunge(u,x,.3)`（前踏半步）；heal 物品 `heal(x, QiheAccFx.heal(持有者id, it.heal))`（固定值，非百分比）；mp 物品 `mp=min(mmp,mp+it.mp)`，浮字 `内力+N` `#8cf` 22；wait 500。

### 防御（bp=0）
`defend=true; prio=true`；浮字 `防御` `#9fd4ee` 22；wait 450。

### 逃跑（bp=0）
`p = clamp(55 + (我方存活平均spd - 敌方存活平均spd)*6, 20, 90)`；成功 `whoosh` 返回 `'flee'`；失败浮字 `逃跑失败` `#aaa` 22，wait 600。

## 2. 蓄势控件（非道具菜单底部）
- 结构：`蓄势` `[Q]` 5 枚铜钱 pips `[E]` `投入 <b>N</b>`。
- `setBp(d)`：`n=clamp(bpUse+d,0,min(3,u.bp))`，变化则 `select` 音效（音高 `1+n*0.15`）、重绘卡片与当前菜单/目标提示。
- 点第 i 枚铜钱（i<bp）：目标投入 `want=bp-i`，再点同档归零。
- pips 显示：前 `bp-use` 枚为 on（橙 #d88a2c），末尾 `use` 枚为 use（亮 #fff1b0），其余空。
- 目标选择阶段仍可 Q/E 调整（左右键此时用于切目标）。

## 3. 目标选择 `target(side,all,back,go,desc)`
- `list = 存活的敌 / 存活的友`；空则直接 back。
- 初始：敌方 `tsel=0`；友方为自己的下标。隐藏菜单，`B.tgtList=list`，`B.tgtAll=all`。
- 提示条 `#bt-hint` 内容：`<desc> · <目标名> <弱点图标串>`（已知显示弱点字，未知显示“？”）；全体时写 `全体敌人/全体同伴`；对敌且 `B.pv(bpUse)` 非空：`· 预计 min[~max][ ×hits]`，若命中已知弱点追加 `弱点！`（#ffe25a 闪烁 .6s alternate）；pv 为空 `· 辅助 · 不造成伤害`；结尾 `· 蓄势 N`；storyLesson 追加 `· Enter 确认 / Esc 返回`。
- 键：左/上 = 上一个；右/下 = 下一个（全体时不动）；ok = 确认；back = 返回；Q/E 调蓄势。
- 鼠标：点击画布命中 `unitAt` 且在 list 中：已选中（或全体）→ 确认，否则改选；点击我方卡片同理（`B.pickCard`）；悬停（`B.hover`）自动切换选中（非全体）。
- `unitAt(x,y)`：对每个存活单位，`h=unitH(u)`，`w=max(40,h*0.32)`；`|x-u.x|<w && y<u.y+30 && y>u.y-h` 命中，多个取 `u.y` 最大（最靠前）。坐标须先经 `CAM.toWorld`。

## 4. 提交 `done(fn,nob)`
防重入；`BattleAuto.clear()`；隐藏菜单、清 key/click/pickCard/redraw/tgtList/pv、清提示；`nob` 时 bpUse=0；`use=clamp(bpUse,0,min(3,bp))`；`use>0` 时 `bp-=use; boosted=true`；执行 `fn(use)`；`storyLesson.afterAction(u,use)`；结果作为 allyTurn 返回值。

## 5. 键位（battle.js 全局 keydown；`mode==='battle'`、`B.key` 存在、对话未占用时）
| 键 | 指令 |
|---|---|
| ArrowUp / W | up |
| ArrowDown / S | down |
| ArrowLeft / A | left（菜单中=蓄势−1；目标中=上一个） |
| ArrowRight / D | right（菜单中=蓄势+1；目标中=下一个） |
| Enter / 空格 / Z / J | ok |
| Escape / X / Backspace / K | back |
| Q / PageUp | bm 蓄势−1 |
| E / PageDown | bp 蓄势+1 |
| 1–9 | n1..n9 直选第 i 行并立即确认 |
按键大小写不敏感；`e.repeat` 时忽略 ok/back。菜单上下移动跳过禁用行（循环），音效 `blip(.6)`；确认 `select`；返回 `menu_close(.6)`。

## 6. 帮助条 `#bt-help`
- 普通战：内容 `[↑][↓]选择 [Enter]确定 [Esc]返回 [Q][E]蓄势 [1]–[9]直选`；仅在**我方非宠物行动且（第 1 回合或 tutorial）**时显示（opacity 0→1，过渡 .8s）。
- storyLesson：`↑↓ / W/S 选择 · Enter / 空格 确认 · Esc 返回 · Q / E 蓄势 · 鼠标点击`，常显。

## 7. 菜单位置（bui.js `place()`，默认 `BUI.dock='left'`、主题 ink）
贴在当前行动者状态卡左侧：`left = cards.offsetLeft - 20 - 4 - cmd宽`，`top = clamp(当前卡 top - 4, 84, 540-6-cmd高)`。菜单宽 210px（ink），行高 30px，左内边距 26px，字号 16px；打开动画 `inkin .22s ease-out`。
状态卡列：`#bt-cards` 绝对定位 `right:2px; bottom:4px; width:252px`，纵向排列，每张高 62px，当前者 `translateX(-20px)`（过渡 .24s cubic-bezier(.3,1.5,.5,1)）；头像圆 52×52 于 (5,5)。
提示条 `#bt-hint`：水平居中，`top:82px`，14px，行高 24px。
DOM 层 `#bt` 960×540，按 `#game` 宽度 `/960` 等比缩放。
