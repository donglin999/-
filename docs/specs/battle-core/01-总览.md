# 01 战斗核心 · 总览与加载覆盖关系

源：`xiaojianghu-legacy-prologue/index.html`（脚本顺序）、`js/battle.js` 文件头注释、各覆盖文件头部。

## 1. 一句话
横版回合制（敌左我右），960×540 逻辑画布。核心机制三件：**护盾/弱点/破势**、**蓄势 BP**、**敌人出手意图预告**。入口 `await battle(opt)` 返回 `'win' | 'lose' | 'flee'`；循环内抛异常时回滚并向上抛。

## 3. 全局状态 `B`（battle.js `battle()` 内 fade 回调构造）
```
B = { opt, allies, foes, units:[...allies,...foes], bg:bgKey, round:0,
      fx:[], parts:[], shake:0, cur:null, order:[], next:[], done:new Set(), bpUse:0,
      jit:new Map(), key:null, click:null, hover:null, tgtList:null, tsel:0,
      t0:performance.now(), log:'' }
```
运行期追加字段：`B.banner`（招式名横幅 {t,side,t0}）、`B.big`（大字 {t,c,t0,ms}）、`B.pv`（伤害预估函数 bp→{t,e,hits,pow}|null）、`B.tgtAll`、`B.pickCard`、`B.redraw`、`B.lastHover`、`B.boostT/B.boostU`、`B._stT`。
`mode` 全局切到 `'battle'`；结束恢复为原 mode（原 mode 为 `'map'` 或 `'battle'` 时改为 `'scene'`）。

## 4. 常量（battle.js 顶部）
- `WTYPES=['刀','剑','拳','棍','暗器','音律','阳','阴','毒','雷']`（前 6 兵刃、后 4 内劲）
- `WCOL`：刀 `#d8d2c0` 剑 `#9fd4ee` 拳 `#f0a868` 棍 `#c89a60` 暗器 `#b6c2d6` 音律 `#8dd8c5` 阳 `#ff8a3a` 阴 `#9aa6ff` 毒 `#86d65e` 雷 `#ffe25a`
- `FOE_DEF`（敌种默认）：
  - bandit：shield 3，weak [拳,棍,暗器,阳]，drops {bun:25}
  - wolf：shield 2，weak [刀,剑,暗器,阳]，drops {bun:10}
  - snake：shield 5，weak [刀,暗器,雷]
  - chief：shield 6，weak [刀,暗器,阳]
- `BSK` 战斗武学类别表（t 兵刃 / e 内劲 / tgt 目标 / hits 段数 / reveal 揭示数 / stun / bleed / buff）见 04。
