# 02 单位数据结构与构造

源：`js/menu.js` `derived()` `mkHero()` `mkAlly()`（覆盖 battle.js 同名）；`js/battle.js` `statUnit()` `mkFoe()` `PARTY_DEF`；`js/qihe-characters.js`（叶蘅）；`js/character-growth-state.js` `CharacterCondition.apply`；`js/hero-multiweapon.js`。

## 1. 派生属性 `derived(u=S)`（menu.js 现行版）
输入：`u.st`（五维 str 臂力/con 根骨/agi 身法/wil 定力/wis 悟性）、`u.lv`、`u.weapon/armor/acc`（物品键）、`u.mpBonus`、`u.atkBonus`、`u.conditions`。
1. `b` = 三件装备 `ITEMS[k].fx` 各字段相加（`mnFx`）。
2. `s[k] = st[k] + b[k]`（五维也可被装备加）。
3. 公式：
```
mhp   = 60 + s.con*14 + lv*12 + b.mhp
mmp   = 30 + s.wil*7 + s.wis*2 + lv*5 + mpBonus + b.mmp
atk   = 8 + s.str*3 + lv*2 + b.atk + atkBonus
def   = s.con + s.wil*2 + b.def
spd   = s.agi + b.spd
crit  = 5 + s.wis*2 + b.crit          （百分比）
dodge = round(s.agi*1.5) + b.dodge    （百分比）
block = min(30, s.con + b.block)      （百分比，格挡）
move  = 2 + floor(s.agi/5)            （战斗不用）
```
4. 心法（`S.chapter>=2` 才开启，`mnXfOn`）：对 `MN_DK=['atk','def','mhp','mmp','crit','dodge','spd','block']` 每项 `d[k]=round((d[k]+X.add[k])*(1+X.pct[k]))`。
5. 状态（`CharacterCondition.apply`）：每项取所有状态里 <1 的最小倍率 × >1 的最大倍率，`round`，下限 1（mmp 下限 0）。状态表：
   - fatigue 疲惫：atk×0.9 spd×0.9（cleanse rest）
   - minor_wound 轻伤：mhp×0.85（treatment）
   - rested 休整充足：def×1.1（cleanse `battle_end`，战后消退）
   - yin_old_injury 旧伤三阶：{mhp .45,mmp .35,atk .4,spd .8} / {.65,.6,.65,.9} / {.85,.8,.85,1}

## 2. `statUnit(src, side)`（battle.js）
用 `derived({st,lv,weapon,armor,atkBonus,mpBonus,conditions})` 生成：
```
{ side:'ally'|'foe', name, conditions(深拷贝), lv, mhp, mmp, atk, def, spd, crit, dodge,
  bp:1, boosted:false, buffs:{}, alpha:1, id:Math.random() }
```
注意 hp/mp 不在这里赋，由各构造器设。

## 3. 主角 `mkHero()`（menu.js 现行版）
- 属性取 `derived()`（含 block）。`hp=clamp(S.hp,1,mhp)`，`mp=clamp(S.mp,0,mmp)`。
- `isHero=true`，`art=pickArt(['hero'])`，`por='hero'`。
- `atkType`：装备武器则 `mnWeaponType(kind)`（琴/箫/笛/音律→'音律'，其余原样），否则 `'拳'`；`atkName` 武器名或 `'拳脚'`。
- `skills = S.load.filter(k=>S.skills[k]&&SKILLS[k])`（装配栏顺序）；`skLv = mnEffLv('hero')`（等效重数，见 10）；`mw='hero'`；`xf=mnXfSum('hero')`。
- hero-multiweapon 再包一层：归云阶段（`inStage(S)`：`cultivation.facts.gy_hair_long` 或 已入门且 `month>1||phase>0`）时 `art=artFor(S,ITEMS)`（`gy_hero_`+家族），`por='gy_hero_long'`。
- `opt.heroArt / opt.heroPor` 在 battle() 内再覆盖 `art/por`。

## 4. 同伴 `mkAlly(key)`（menu.js 现行版）
- 无 `S.mates[key]` 记录：`statUnit({name,st:P.st,lv:key==='ye'?3:(P.initialLevel||1)})`，满血满蓝，`skills=P.skills`，`skLv={}`。
- 有记录：`statUnit({name,st:m.st,conditions:m.conditions,lv:max(1,m.lv)})` 后用 `mnD(key)`（含装备与心法）覆盖属性；`hp = m.hp==null?mhp:clamp(m.hp,1,mhp)`，`mp` 同理（null 表示满）。
- `art=pickArt(P.art)`，`por`=P.por 中第一个已加载立绘；`key`；武器决定 `atkType/atkName`（无武器用 P 的默认）；`skills=m.load` 过滤；`skLv=mnEffLv(key)`；`mw=key`；`xf`。进入 `mnLive` 供战后回写残血。
- `PARTY_DEF`：
  - suzhi 苏芷：st{3,4,6,6,6}，skills [jinzhen,huichun,baicao,dingshen]，atkType 暗器，atkName 飞针，art/por ['suzhi','lady']
  - dog 大黄：st{4,5,7,3,2}，skills [sniff,lick]，刀/撕咬，art ['dog']
  - ye 叶蘅：st{3,4,5,5,6}，skills [huichun,baicao]，暗器/药针，art ['ye']
  - yinhongying 殷红缨：st{6,4,8,5,5}，skills [liuye]，剑/软剑
- 队伍组装（battle()）：`allies=[mkHero()]`；若非 `opt.tutorial` 且非 `opt.solo`：`S.party.slice(0,3)` 依次 mkAlly（可被 `opt.allyArts[k]/opt.allyPorts[k]` 换造型），再加宠物 `mkPet(S.pet)`；`opt.temporaryDou` 追加 `GuiyunCombat.temporaryDou()`。最多 1+3+宠物+豆。

## 5. 敌人 `mkFoe(t,i)`（battle.js）
模板字段 `t`：`name sp lv st weapon armor skills{} hpMul atkMul shield weak[] drops{} exp silver boss h`。
```
k = t.sp 去掉前缀 'c_'；D = FOE_DEF[k] || {}
u = statUnit(t,'foe')
mhp = round(mhp * (t.hpMul || 0.45) * 1.8)；hp = mhp
atk = round(atk * (t.atkMul ?? 0.62))
art = key = k
maxShield = shield = t.shield || D.shield || 3
weak = (t.weak || D.weak || ['拳','刀']).slice()；known = new Set()
skills = Object.keys(t.skills || {blade:1}).filter(在 SKILLS 中)
drops = t.drops || D.drops || {}；exp = t.exp ?? lv*20；silver = t.silver || 0
bossy = !!t.boss || k==='chief'；h = t.h || 160
```
注：`hpMul` 缺省 0.45 → 实际血量系数 0.81；`hpMul:1` → 1.8 倍。`atkMul` 用 `??`，可写 0（练场周砚）。`weak:[]` 合法（无弱点）。
附加包裹：guiyun-combat-runtime 若 `t.guiyunGuardOnly` 置 `u.guiyunGuardOnly=true`；若 `t.worldLevel`：`u.lv=worldLevel`，`u.teachingStatsLevel`，`name += ' · 收力切磋'`。qh-mode-cultivation-martial 对 `combatProfile===DOU_PROFILE` 加 `atkType:'剑',atkName:'桃木剑',mp:mmp,sparActions:0`。

## 6. 运行期单位字段一览
| 字段 | 含义 |
|---|---|
| hp/mhp/mp/mmp | 气血/内力 |
| atk def spd crit dodge block | 战斗属性 |
| bp | 蓄势 0..5，初值 1 |
| boosted | 本回合是否投入过蓄势（投入则下回合不+1） |
| buffs.ding | 定神剩余回合；buffs.qhGuard 护身（减伤15%）；peiWeaken/peiCare 裴伴读钩子 |
| defend | 防御中（受伤×0.5） |
| prio | 防御后下回合排序 +100 |
| stun | 眩晕，下次轮到时跳过 |
| bleedN | 中毒剩余次数（每次行动后结算） |
| shield/maxShield/weak/known | 敌：护盾与弱点 |
| broken/brokenUntil/breakT | 敌：破势 |
| charging | 敌：蓄力中（下回合全体） |
| intent | 敌：{sk,tgt} / {sk:'ghost',all:true} / {charge:true} |
| bossy | 头目：半血后每回合追加一次行动 |
| x,y,bx,stepO,depth,dscale | 站位（见 11） |
| lunge kb flash ghT gh dieT shieldHit revealT | 演出时间戳 |
| stationarySkill | 本次是武学（不前踏） |
| levelUpThisBattle | 本场升级（战后同伴满血） |
