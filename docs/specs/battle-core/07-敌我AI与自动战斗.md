## 1. 意图规划 `planIntent(u)`（回合开始时对每个存活敌人调用；头目半血追加行动前再调用一次）
```
al = 存活我方；空则返回
if u.charging:                       intent = {sk:'ghost', all:true}; return     // 上回合蓄力 → 本回合全体斩
if 有 ghost 且 !broken 且 round>1 且 random < (hp<mhp*0.6 ? 0.5 : 0.3):
                                     intent = {charge:true}; return              // 本回合蓄力
sk = 从 skills 去掉 ghost 后随机一个（ri 均匀）；若空 'blade'
tgt:
  若 art==='wolf' 或 BSK[sk].stun → 气血比例最低的我方
  否则 → 随机我方
  若 art==='wolf' 且 random<0.4 → 改为随机我方
intent = {sk, tgt}
```
陪练包裹（陆小豆 `combatProfile===DOU_PROFILE`）：非蓄力时 `next = sparActions 为奇数 ? 'gy_s1' : 'gy_dou_basic'`，内力不足回落 `gy_dou_basic`。

## 2. 意图标签 `intentLabel(u)`（敌人头顶，破势时不显示）
- `{charge}` → `蓄力中 · 下回合全体攻击`
- `{all}` → `‼ <招名> · 全体`
- 单体 → `<招名> → <目标名>`
- training 中 → `示范 · 等你收招`；`guiyunGuardOnly` → `守住中线 · 陪练`
- 标签底色：蓄力/全体 `rgba(90,20,12,.88)` 边 `#ff7a3a`；其余 `rgba(10,8,6,.78)` 边 `rgba(163,138,94,.6)`；字 13px `#eee2c6`，位于 `y - unitH - 26`。（bui.js 改为“小墨点字徽”表现，文字语义同上）
- 我方选指令时绘制意图虚线：敌头顶 `(f.x, f.y-unitH*0.95)` → 目标头顶，二次贝塞尔，控制点 `(中点x, min(y0,y1)-60)`；虚线 [6,6]，`lineDashOffset=-now/40`，线宽 2；全体色 `rgba(255,90,60,.5)`，单体 `rgba(255,140,110,.38)`；破势/蓄力敌不画。

## 5. 宠物 AI `petTurn(u)`（大黄，PET_DEF.dog = {guardMp:6, guardRatio:.5, healRatio:.3}）
```
foe = 气血比例最低的存活敌人；无则返回
主角死亡 → doAttack(u,foe,0)
ratio = hero.hp/hero.mhp
1) ratio<=0.5 且 mp>=6 且（hero 无护卫 或 护卫已死 或 guardUntil<round）:
     mp-=6; hero.guardBy=u; hero.guardUntil=round+1; showName「护主」; 浮字(主角)「大黄护主」#9fe0b5 21; wait 450
2) ratio<=0.3 且 mp>=lick.mp(8) 且 hero 未满 → doSkill(u,'lick',[hero],0)
3) mp>=sniff.mp(4) 且 foe 还有未知弱点 → doSkill(u,'sniff',[foe],0)
4) doAttack(u,foe,0)
```
护主伤害分摊见 04 §10。宠物不用蓄势、无手动菜单。

## 6. 智能自动战斗 `BattleAuto`
- 可用：非 storyLesson，或 `opt.allowAuto===true`。
- 按钮 `#bt-auto`：右下 `right:44px; bottom:18px; min-width:150px; padding:9px 16px`；字 16px，`color:#e9d8b4`，边 `1px solid #967746`，背景 `linear-gradient(135deg,rgba(30,23,16,.96),rgba(8,8,12,.92))`；开启态 `color:#ffe1a0; border-color:#d9ac57; background:linear-gradient(135deg,#50351deb,#1c1714f5)`。文案：关 `智能自动战斗` / 开 `暂停自动 · 手动接管`。`round<1`、已结束或不允许时隐藏。title：`优先救急治疗、已知弱点破势和残血收尾；自动选择武学与蓄势，不使用背包药品、不逃跑。暂停后下一次行动由你操作。`
- 绑定：每次我方行动 `allyTurn` 结尾 `bind(u,submit)`；开启时 **450ms** 后 `choose(u)`，提示条显示 `自动 · <reason>`，以 `B.bpUse=action.bp` 走 `done()` 提交。关闭即清计时器。战斗结束 `finish()`。
- `choose(u)`：
  - usable：skillWhy 为空的武学。`maxBP=min(3,bp)`。
  - **救急**：对每个治疗武学 × 目标组（self/全体/每个友方）× bp 0..maxBP：组中有人 `hp/mhp<0.45` 才算；`amount = heal*(1+0.15(lv-1))*(1+0.5bp)`；`gain = Σ min(缺血, mhp*amount) * (hp比<0.3 ? 2 : 1)`；`score = 1000 + gain - bp*20 - mp*2`；reason `救急治疗`。有任何救急候选即取最高分。
  - **攻击**：候选 = 普攻(null) + 非治疗非 buff 武学；目标组 = foes 全体技为全体，否则每个敌人；每个 bp：
    ```
    v = skillPv 或 {t:atkType,pow:1,hits:1+bp}
    对每个目标: dmg = estDmg*v.hits
      score += min(t.hp,dmg); dmg>=t.hp → +50
      已知弱点命中且未破势: +min(shield,hits)*22; 若 hits>=shield: +85(+60 若蓄力中/将蓄力), breaking=true
      bi.reveal 且仍有未知弱点: +18
    score -= bp*(有目标已破势?10 : breaking?25 : 32) + mp*2
    ```
    reason：`弱点破势` / `破势追击` / `群攻压制` / `集中攻击`。取最高分。
