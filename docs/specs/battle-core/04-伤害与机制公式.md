## 1. 随机函数（core.js）
```
rnd(a,b)  = a + random()*(b-a)            连续均匀
ri(a,b)   = floor(rnd(a,b+1))             含两端整数
chance(p) = random()*100 < p              p 为百分数
```

## 3. 我方出手 `strike(u,t,{pow,t:ty,e})`
```
weakHit = t 为敌 且 (ty ∈ t.weak 或 e ∈ t.weak)
  命中的未知弱点立即加入 t.known（revealT=now）
dmg = u.atk*pow*(u.buffs.ding?1.3:1) - t.def*0.5
if weakHit:  dmg *= 1.25
if t.broken: dmg *= 2
cr = chance(u.crit); if cr: dmg *= 1.5
dmg = max(1, round(dmg * rnd(0.92,1.08)))
if weakHit: 浮字 WEAK #ffe25a；if !t.broken && t.shield>0: shield--, shieldHit=now; shield==0 → doBreak(t)
hurt(t,dmg, 颜色: cr?#ffd24a : t.broken?#ff6a4a : #fff3e0, big=cr, 音效键)
```
- 我方出手**不判闪避**。
- 弱点 ty 与 e 同时命中只扣 **1** 盾（一次 strike 一盾）；多段/连击每段各扣。
- 扣盾发生在 hurt 之前，因此刚破势的这一下**不吃** ×2（判断在前）。
- menu.js 包裹：我方有 `mw` 且 ty 是兵刃（刀剑拳棍暗器音律）→ 记造诣，`pow *= 1+mnZyBonus(zy[ty])`，`mnZyBonus(v)=min(10,floor(v/20))/100`。
- 音效：叶蘅初始(`ye_initial`)暗器→`needle_hit_20261012`；棍→`staff_hit_20261010`；其余 `advance`。

## 4. 普攻 `doAttack(u,t,bp)`
`hits = 1+bp`（bp 0..3）；每段 `strike(u,t,{pow:1,t:u.atkType})`；目标死亡则停。

## 5. 武学 `doSkill(u,k,tgs,bp)`
前置：我方且 `QiheUIModel.skillWhy(u,k)` 非空 → 直接返回（不扣内）。扣内 `skillCost`。
```
lvM = 1 + 0.15*((u.skLv[k]||1) - 1)
治疗：每个活着目标 n = round(t.mhp * sk.heal*lvM*(1+bp*0.5)) → heal（我方再经 QiheAccFx.skillHeal）
定神(buff)：t.buffs.ding = 2+bp；浮字「定神 · 攻防提升」#ffe7a0 20
伤害：
  hits = (bi.hits||1) + (bi.hits ? bp : 0)          多段武学：蓄势加段
  pow  = sk.pow*lvM * (bi.hits ? 1/sqrt(bi.hits) : 1) * (bi.hits ? 1 : 1+bp*0.8)
  每段对每个活着目标 strike(u,t,{pow,t:bi.t,e:bi.e})，然后：
    h==0 且 bi.reveal 且存活 → reveal(t, bi.reveal + (bp?1:0))
    bi.bleed 且存活 → t.bleedN = 3
    bi.stun 且存活且未破势 且 chance(sk.stun||25) → t.stun=true; t.intent=null; 浮字「眩晕 · 失去行动」#e0c0ff 18
qh_hulu_staff 结束后：u.buffs.qhGuard=true，浮字「护身 · 减伤15%」#d8e6b3 18
```
`QiheUIModel.skillEffects` 与上式相同（bp 截断到 0..3），若 `CultivationBalance.skillEffects` 有正式招式数据（修习武学 `L.moves`）则改用：`power=b[0]*lvM/max(1,b[1])`，`hits=b[1]`，其中 `b=d.b.bp[bp]`——该数据表属养成范围，另册。
`skillCost(u,k) = max(0, SKILLS[k].mp + 火候mp(重数≥5/≥10 的 at5/at10.mp) + mastery.mp)`。
`skillWhy`：未习得 `尚未习得`；`needWeapon` 不符 `需装备<剑>`；五维不足 `需<属性名> <值>`；`内力不足`；其余由 CultivationBalance。
menu.js `doSkill` 包裹（战后熟练用）：记录熟练 `1+weak+brk`；火候 `reveal` 额外揭示。

## 6. 揭示 `reveal(t,n)`
从未知弱点中随机取 n 个加入 known，每个浮字 `看破：<w>`（WCOL 色，20，慢速 1500ms）。

## 7. 伤害预估（目标选择提示）
`estDmg(u,t,v) = max(1, round((u.atk*v.pow*(ding?1.3:1) - t.def*0.5) * (hitsWeak?1.25:1) * (broken?2:1)))`
`hitsWeak` 只看**已知**弱点。不含暴击与浮动。普攻 `v={t:atkType,pow:1,hits:1+bp}`。

## 8. 破势 `doBreak(t)`
`broken=true`，`brokenUntil=B.round+1`，`charging=false`，`intent=null`，`breakT=now`，`B.shake=14`，`whoosh(1,.6)`，横幅 `POSHI.banner(t)`，26 颗碎片粒子，顿帧 `BT.stop(250)`，镜头 `punch(1.12,320)`。
效果：本回合剩余与下回合**跳过行动**；受伤 ×2；蓄力被打断；回合开始时 `round>brokenUntil` 恢复，盾回满。

## 9. 敌方出手（foeAct 伤害段）
```
每段 h<hits(info.hits||1)，对每个活着目标:
  单体时闪避：chance(t.dodge*0.6) → 浮字「闪」#bcd 24，跳过（全体攻击不可闪）
  dmg = u.atk*sk.pow*(hits>1?0.65:1)*(all?0.85:1) - t.def*0.5
  if t.buffs.ding: ×0.8 ；if t.defend: ×0.5
  dmg = max(1, round(dmg*rnd(0.9,1.1)))；hurt(t,dmg,'#ff9c80')
  info.stun 且存活 且 chance(sk.stun||25) → t.stun=true，浮字「眩晕」
```
敌方无暴击、不吃弱点。

## 10. `hurt(t,dmg,...)` 包裹链（外→内，最终顺序）
1. QiheAccFx.lastStand：我方、本场未用、`dmg>=hp` 且 `hp>1`、佩戴 lastStand → dmg=hp-1，浮字「平安符」。
2. guiyun：training 中敌方单位 `dmg=min(dmg,max(0,hp-1))`（永不击倒）。
3. menu.js 格挡：我方、当前行动者为敌、`dmg>1`、`chance(t.block)` → `dmg=max(1,round(dmg*0.5))`，浮字「格挡」#cfe3ff 18。
4. pets.js 护主：主角受敌方伤害且 `guardBy` 存活、`guardUntil>=round`、dmg>1 → 宠物承受 `floor(dmg/2)`，主角承受余下。
5. 本体：`qhGuard` → `max(1,round(dmg*0.85))`；`hp=max(0,hp-dmg)`；hp≤0 → `dieT`，`intent=null`，我方还清 `bp=0, defend=false, stun=false`。
（pei-companion-runtime 另有 peiWeaken/peiCare 钩子。）

## 11. 治疗 `heal(t,n)`
`h=min(n,mhp-hp)`，加血，浮字 `+h` `#7fe0a0` 28，10 颗绿色上升粒子，`chime(.5)`。

## 12. 蓄势 BP 规则汇总
- 初值 1，上限 5；每回合开始 `round>1` 且上回合未投入则 +1。
- 单次投入 `0..min(3,bp)`；投入后 `bp-=use; boosted=true`（本回合不再自增）。
- 防御/逃跑/道具：强制 `use=0`（`done(fn,nob=1)`）。
- 阵亡清零。
- 效果：普攻段数 1+use；单段武学 pow×(1+0.8use)；多段武学段数 +use；治疗 ×(1+0.5use)；定神回合 2+use；揭示 +1（use>0）。
