# 10 黑场、地名卡、全屏 CG 与庭院背景卡

源：`js/core.js` `fade`、`placeName`；`js/scene.js` `goScene`；`js/prologue-water.js` `play`；`js/qihe-fire-cinematic.js` `play`/`shots`；`js/qihe-chapter.js` `courtyard`；CSS `index.html`（`#fade`、`#place`）、`js/qihe-chapter-presentation.css`（`.qh-fire-cg`）。

## 1. 黑场 `fade(fn)`

时序（ms）：
```
t=0     #fade 加 .on（opacity 0→1，CSS transition .45s）
t=460   await fn()           ← 画面已全黑，切图/摆人在此
+60     #fade 去 .on（opacity 1→0，.45s）
+300    Promise 结束         ← 此时黑场还剩约 150ms 在淡出，后续台词会与之重叠
```
`#fade`：`inset:0;background:#000;opacity:0;pointer-events:none;z-index:9`，不参与 UI 缩放。`prefers-reduced-motion` 时无过渡。

## 2. 地名卡 `placeName(t)`

- 设文本、加 `.on`，**2200ms** 后去 `.on`；淡入淡出均 `opacity .9s`。不阻塞。
- 样式 `#place`：`top:22%;left:50%;transform:translate(-50%,-50%)`；`display:flex;flex-direction:column;align-items:center;gap:.2em`；`font-family:var(--brush)`（站酷小薇）`;font-size:40px;letter-spacing:.35em;color:#e9dcc0;white-space:nowrap`；`text-shadow:0 2px 10px #000, 0 0 3px #000`。
- 上下装饰线（`::before`/`::after`）：`font-size:.6em`（24px）下 `width:9em`（216px）、高 1px，`linear-gradient(90deg, transparent, #e0bf78, transparent)`。即：金线 / 地名 / 金线 三行。
- 调用点：`goScene` 末尾 `placeName(cur.name)`（每次换场都出）。

## 3. 换场 `goScene(id, at, dir)` 中与演出相关的时序

1. 等目标场景素材加载。
2. `fade()` 黑场内：换场景、放主角、重刷路人与气泡；若给了落点且场景允许入场步行（`arrivalWalk!==false`），主角退到落点后方 `ENTER_WALK=52` 世界像素、`alpha=0`，准备 520ms 步行入场；镜头直接定位到 `(落点x, 落点y − CHAR_H·0.45)`，`CHAR_H=92`；存档。
3. 黑场结束后：有入场步行则 `busy=true` 等 520ms 走完；`alpha=1`。
4. `placeName(cur.name)`；刷新 HUD；若场景有 `enter()` 钩子则 `busy` 执行。
5. 剧情站位（11）包了一层：换场前先撤销临时站位，换场后若有待摆的戏且地图对得上，再摆。

## 4. 递水 CG（序章唯一剧情 CG，`PrologueWater.play`）

- 前置：未在运行、（非 owned 时）`!busy`、`!dlgBusy`、`mode==='scene'`、场景以 `prologue_` 开头，否则返回 false。
- 素材：`assets/production/shared/cg_p_water_v1.webp`（1672×941）。解码等待 `Promise.race([decode, 2500ms])`。加载失败且 `fallback` 时 toast `递水图暂未加载，先以立绘与对白继续。` 1800ms，跳过图片。
- 显示：复用/新建 `div#prologue-cg`：`position:absolute;inset:0;z-index:50;background:#181c1a center/contain no-repeat;pointer-events:none`，`role=img`，`aria-label=后山初遇：叶蘅递水给现代短发的萧白`。**无淡入，立即出现**。
- 同时：`body.qh-cinematic`（隐藏 HUD/日志/技艺按钮，抑制立绘）、`#dlg` z=60、加 `.cg-story`、`modernEvent=true`、`busy=true`、清按键与寻路。
- 剧本 `prologue_water`：CG 下演 P-01-08、09、10 三句 → `hide_water_cg()`（立即隐藏图、去 `.cg-story`、恢复 z、去 `qh-cinematic`）→ 之后的提问、三选一及分支在普通场景中演（立绘恢复）。
- `finally`：再次 `hideImage`、恢复 `modernEvent`、`busy`；返回 `{branch, asset}`。
- 每句 `mark(id)` 派发 `prologue-cg-step` 事件 `{id, visible}`。

7. 解码失败且尚未建节点：toast `火灾画面暂未加载，继续剧情。` 2400ms，逐句 `say`。

样式：`.qh-fire-cg{position:absolute;inset:0;z-index:55;overflow:hidden;background:#101514;display:grid;place-items:center;pointer-events:none;animation:qh-cg-enter .5s ease-out both}`，`@keyframes qh-cg-enter{from{opacity:0}to{opacity:1}}`；`img{width:100%;height:100%;object-fit:contain}`（16:9 图在 16:9 画面中正好铺满，比例不同时上下/左右留 `#101514`）。不参与 UI 缩放。CG 期间对白框样式见 03 §7。

**CG 时序小结**：进入 = 0.5s 淡入（与第一句打字机同时开始）；台词逐句；离开 = 瞬间消失，下一句普通台词直接接上。

## 7. 其他“字幕卡”

- ink 中 `【……】` 行 → 旁白对白框居中显示（03 §1），逐字打出，需玩家推进。例：`【第一日傍晚 · 药棚门外】`、`【第三夜 · 药棚装卸侧口】`、`【次日清晨 · 邻村】`。
- 地名卡（§2）由换场自动触发，与 ink 无关。
