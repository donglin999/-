# 11 剧情临时站位与镜头

源：`js/qihe-staging.js`（`QiheStaging`：`apply`、`within`、`mount`、`restore`、`look`、`applyRest`）、`js/qihe-staging-data.js`（`QIHE_STAGING`，表见 12）、`js/qihe-chapter.js` `placeCast`/`sayAll`、`js/prologue-backhill.js`（`poses`、`show`、`camera`、`clinic`）、`js/scene.js`（`snapCam`、`updateCam`、`OCCLUSION`）。只改显示，不写存档。坐标单位：世界像素（地图源图 1600×900 绘到 1920×1080 世界），NPC 节点存格坐标 `x/TS`（`TS=40`）。

## 1. 站位表驱动的整场站位（`QiheStaging`）

数据：`scenes[key] = {label, at:地图id, story, knots:[剧本段], hero:[x,y,朝向], cast:{名字:[x,y,朝向,选项]}}`。朝向 `d/l/r/u`；选项 `'late'`＝第一次开口才上图，`'free'`＝可站在不可走处（柜台后、桌边，数据标记，摆放逻辑不区分）。

### 1.1 挂钩

- 包 `StoryRuntime.play`：knot 属于某站位 key → `within(key, 原play)`；属于 `offstage` 列表 → 播放期间 `muted++`（不转身）；否则原样。
- 包 `goScene`：换场前 `restore()`；换场后记 `lastGo=now`；若有 `pending` 戏且新地图 = 该戏 `at`，`apply(pending)`。
- 包 `say`：每句先 `look(who)`。
- 包 `npcsOf`：应用平时站位（§3）。

### 1.2 `within(key, fn)`

- 已在同一 key 中 → 直接 `fn()`（嵌套不重摆）。
- 否则 `pending=key`；当前地图 = `entry.at` 时 `apply(key)`；执行 `fn()`；finally 恢复外层 pending，若仍是本 key 则 `restore()`。

### 1.3 `apply(key)`

1. 先 `restore()` 上一场。
2. `far = hero 存在 && 距离(hero, 玩家) > 70 && now − lastGo > 900ms`（刚换完图 0.9s 内不再黑场）。
3. `put()`：记录原 NPC 列表；把每个非 `late` 的人 `mount`；萧白瞬移到 `hero` 坐标与朝向，清寻路，`snapCam()`。
4. `far` 时 `await fade(put)`（10 §1），否则直接 `put()`。

`mount(name)`：该名字有站位、尚未上图、不在 `QiheOffstage`（隔门说话的人）→ 从场景 NPC 中移除同名（含别名：蔺管事↔算命先生、阿炭↔新来的）的原 NPC，加入临时节点：
```
{id:'staged-'+name, name, sp:QiheChapter.spriteFor(name), x:x/TS, y:y/TS, dir,
 fixed:true, idle:false, cast:true, act:空}
```
`restore()`：NPC 列表还原（NPC 回平时站位），**萧白留在戏里的位置**。

## 2. 说话转身 `look(who)`

- `who` 空或为萧白 → 不处理。
- 名字取 `' · '` 前部分；若该人在当前戏的站位表中且尚未上图（`late`），此刻 `mount`（“第一次开口才上图”，瞬间出现，无动画）。
- `muted>0`（画外音剧本）→ 不转身。
- 找场景中同名带精灵的 NPC，若与萧白距离 < 420 → `player.dir = faceTo(dx, dy)`（|dx|>|dy| 取左右，否则上下）。

## 3. 平时站位 `rest`

按地图分组的规则 `{at, id, when?, x?, y?, dir?, talkR?, hide?}`，同一 NPC 取第一条条件满足的（`when:'firstNight'` ＝ `!S.qiheChapter`）。首次处理时备份原坐标/朝向/显示条件到 `n._rested`；规则给出的字段覆盖，缺省回落备份；`hide:true` 时该 NPC 不显示；`talkR` 设交谈半径。`staged-*` 节点不处理。完整规则见 12 §2。

## 4. 无站位表时的临时站位 `placeCast(names)`（`qihe-chapter.js`）

`sayAll(rows)` 每段先调用；若 `QiheStaging.active()` 则不做。否则：
- 取本段说话人中 `castSprites` 有的、不在 `QiheOffstage` 的名字，去重，**最多 5 人**。
- 每人：若场景里同名 NPC（显示中）离玩家 < 250 → 用其原位置；否则依次试偏移（相对玩家，世界像素）
  `[-110,-25],[110,-30],[-190,70],[180,75],[0,-125],[-80,110],[90,120],[-210,-100],[210,-90]`，
  取第一个可站立（`standOk`）且离已摆者 > 55 的点；都不行则不摆。
- 节点同 §1.3（宋先生沿用原 NPC 的 sp），`dir = x<玩家x ? 'r' : 'l'`（面向萧白）。
- 段落演完立即还原 NPC 列表。萧白不移动。

## 5. 序章定点戏（`PrologueBackhill`）

- 场景 `prologue_backhill`，底图 `m_prologue_backhill_v1`（+道具层），`playerSp:'opening_hero_modern'`，`noFollow`，不步行入场。
- 站位（屏幕像素，乘 `1/ZOOM` 转世界）：
  - `encounter`：萧白 `[490,330]`，叶蘅 `[620,315]`（朝左）。
  - `dog`：萧白 `[300,262]`，叶蘅 `[405,275]`（朝右，挡在前面），狼 `[610,235]`、`[640,365]`（朝左，`h:52`，取战斗灰狼待机第 0 帧裁边）。
- `show(next)`：锁定、预载素材；不在后山则 `goScene` 过去，否则（`transition`）黑场中移位；主角朝向 dog 为 `r`、相遇为 `l`；`encounter` 时叶蘅先不显示，`backhill_ye()` 才出现并让萧白朝右。
- **镜头固定**：`camera()` 置 `cam=(0,0)`、`camC=(W/ZOOM/2, H/ZOOM/2)`，整张图一屏显示，不跟随。
- 锁定期间清空按键、寻路，禁止点地寻路；底部提示文字改为 `点击对白 / 空格推进 · 点击选项或按数字选择`，解除时还原。
- 持棍：主角 `alpha=0`，用底图旁边土路像素 `[540,348]` 盖住木杆区域 `[424,348,92,42]`，再画战斗持棍站姿第 0 帧（按 58px 身高缩放、水平翻转）。
- 药棚 `clinic()`：萧白到 `anchors.cot_side×3`、朝右；叶蘅 `[400,600]×缩放` 朝上，陈伯 `[650,670]×缩放` 朝左（缩放 = 世界宽/1536）；`snapCam()`。

## 6. 镜头

- `snapCam()`：`camC=(player.x, player.y − 92×0.45)`；若场景有 `intro`（且 `when` 成立），先定在 `intro.at`，停 `hold`（默认 1500ms）后用 easeInOutQuad 在 `pan`（默认 2500ms）内移到主角；玩家一动即结束。`cam = clamp(camC − 视口/2, 0, 世界 − 视口)`，视口 1152×648。
- 跟随 `updateCam(dt)`：前瞻点 `(x + vx·260, focusY + vy·200)`；死区 X=视口宽×7%、Y=视口高×6%；平滑系数 `1 − exp(−dt/170)`。
- 剧情中没有推拉/震屏镜头；戏的“镜头”就是瞬移主角 + `snapCam` + 可选黑场。

## 7. 遮挡

临时站位节点带 `cast:true`，按 `OCCLUSION` 参与遮挡补画：被前景/道具挡住的部分以原像素 50% 不透明度补画（`style:'ghost'`），覆盖比例 < 4% 不画，每帧最多 16 人。
