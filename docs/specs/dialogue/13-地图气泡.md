# 13 地图气泡

本篇覆盖地图上不打断操作的轻量对白：路人闲话气泡、NPC 待机与表情气泡。都不走对话框，不阻塞输入。

## 1. 路人闲话气泡

源：`js/scene.js`，`updBark(w, dt)`（第 564 行，由路人更新循环第 192 行调用）、`drawBubbles(dt)`（第 568 行，在 `drawParticles`、`drawBirds` 之后调用，第 397 行）；全局 `const bubbles=[]`。

### 1.1 路人数据

`wanderers` 每项由场景 `extras` 生成（第 70 行）：含 `sp, x, y, barks, bt:rnd(1500,6000), wait:rnd(300,2500)` 等。无 `barks` 或为空则不冒泡。
`charH(sp) = CHAR_H(92) * (ART.scale[k] || SIZE[k] || 1)`。视口 `VW = W/ZOOM`，`ZOOM = 5/6`，`TS = 40`。

### 1.2 计时（`updBark`）

| 步骤 | 规则 |
|---|---|
| 每帧 | `w.bt -= dt`；`> 0` 返回 |
| 放弃（任一） | `hypot(w-player) > 230`；`bubbles.length >= 2`；`busy`；`dlgBusy` → `w.bt = rnd(600,1500)` |
| 冒泡 | push `{w, txt: barks[ri(0,len-1)], t:0, dur:3400}`；`w.bt = rnd(9000,16000)` |
| 移除（`drawBubbles` 内） | 先 `b.t += dt`；`b.t > b.dur` 或 `!wanderers.includes(b.w)` 删除 |

### 1.3 绘制（`drawBubbles`）

- `font = 15px "Noto Serif SC",serif`，`textAlign center`，`textBaseline middle`；倒序遍历。
- `a = min(1, t/180, (dur-t)/300)` → `globalAlpha`。
- `tw = ceil(measureText(txt).width) + 18`，`th = 26`，`h = charH(w.sp)`。
- `x = round(clamp(w.x, cam.x+tw/2+6, cam.x+VW-tw/2-6))`
- `y = round(w.y - h - 24 - (1 - min(1, t/180)) * 6)`（出现 180ms 内上浮 6px）
- `x0 = round(x - tw/2)`，`y0 = y - th/2`
- 绘制顺序：
  1. `#1b130c`：`rect(x0-2, y0, tw+4, th)`、`rect(x0, y0-2, tw, th+4)`（切角外框）
  2. `#efe2c4`：`rect(x0, y0, tw, th)`；`#d8c7a2`：`rect(x0, y0+th-3, tw, 3)`
  3. 尾巴中心 `tx = round(clamp(w.x, x0+10, x0+tw-10))`（路人被夹到边时尾巴仍指向路人）。
     `#1b130c`：`rect(tx-5, y0+th+2, 10, 2)`、`rect(tx-3, y0+th+4, 6, 2)`、`rect(tx-1, y0+th+6, 2, 2)`
     `#efe2c4`：`rect(tx-3, y0+th, 6, 2)`、`rect(tx-1, y0+th+2, 2, 2)`
  4. `#3a2616` 文字 `fillText(txt, x, y+1)`
- 结束恢复 `globalAlpha=1`、`textBaseline alphabetic`。

## 2. NPC 待机与表情气泡

源：`js/idle.js`。`scene.js` 的 `drawNpc()`（第 352 行）先调 `npcIdle(n, t, near)` 取姿态 `{dir, dx, dy, moving, walk}`，画完角色后调 `npcIdleFx(n, t, x, y, h, near, id)` 画粒子与气泡。

### 2.1 状态（`idleOf`，按 `n.id||n.name||spKey` 存于 `idleSt`）

`{k, role: IDLE_ROLE[k]||IDLE_ROLE._, act:null, t0:0, next: now+rnd(800,3000), dir:null, parts:[], emo:null, lastT:0, cycle: rnd(0,1400)}`
`NOIDLE = {snake, rooster, dog, chief, wolf}`：不做待机。剧情临时站位节点带 `idle:false`。

### 2.2 `npcIdle` 行为

1. `pd < 110` 或 `near.o === n`：`act=null, dir=null`，面向主角（`faceTo`），返回。
2. 无动作且 `t > next`：`pickW(role.w)` 加权选：
   - `look`：从 `['l','r','d']` 去掉原朝向后随机一个，`dur = rnd(1200,2400)`
   - `step`：`dur=560`，`moving=true, walk=e*.09`
   - `nod`：`dur=700`，`dy = max(0, sin(e/700*2π))*3`
   - `emo`：`emo={txt: 随机一句, t0:t}`，`dur=10`
3. `e > dur`：结束，`next = t + rnd(2500,6000)`。
4. 职业动作叠加（`cy=(t+cycle)%1400`）：`hammer` 在 `cy<140` 时 `dy=3`；`bead` `dy += sin(t/900)>.6?2:0`；`doze` `dy += sin(t/1100)>0?1.5:0`；`sway` `dx = round(sin(t/800)*2)`；`tell` 在 `(t+cycle)%4200<160` 时 `dy=2`。

### 2.3 `npcIdleFx` 粒子与自动气泡

`dt = min(50, t-lastT)`。粒子按 3×3 世界像素画（`ipx`：坐标 `round(v/3)*3`）。
- `hammer`：`cy<dt+1` 时生 7 颗火星，起点 `(x+fx*h*.28, y-h*.3)`，`vy=-rnd(1.5,3.5)`，重力 `.18`，寿命 `rnd(260,480)`，色随寿命 `#fff4c0→#ffc050→#ff7a2a`，`alpha=1-k*.5`。
- `steam`：概率 `dt/260` 生热气，起点 `(x+(fx||.6)*h*.22±4, y-h*.42)`，`vy=-.35`，寿命 `rnd(1200,1800)`，白色 `alpha=.35*(1-k)`，横摆 `sin(age/300+ph)*.3`。
- `doze`：每 5200ms 周期自动冒 `Zz…`；`tell`：每 4200ms 自动冒 `啪！`/`话说……`（各半）。
- 速度按 `dt/16` 缩放。

### 2.4 表情气泡绘制

- `D=1900`；消失条件：`e > D`、`near.o === n`、`n.mark && n.mark()`（头顶任务标记）。
- `al = e<150 ? e/150 : e>D-300 ? (D-e)/300 : 1`
- `by = y - h - 16 - min(e,200)/200*6`
- `font 15px "Noto Serif SC",serif`，居中；`tw = measureText+14`
- 圆角矩形 `(x-tw/2, by-18, tw, 22, r=6)`，填 `rgba(250,244,228,.94)`，描 `#3a2a1a` 线宽 2（填+描）。
- 尖角 `(x-4,by+4)→(x+4,by+4)→(x,by+10)` **只填充不描边**。
- 文字 `#2a1a0a`，`fillText(txt, x, by-2)`（alphabetic 基线）。
