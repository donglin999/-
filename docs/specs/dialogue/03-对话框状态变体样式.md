# 03 对话框状态变体样式（按 CSS 层叠的最终结果）

源：`index.html` 内联 CSS、`js/dialogue-stage.css`、`js/qihe-chapter-presentation.css`。下文是按选择器优先级与加载顺序算出的**实际生效值**；有几处“看似写了却被更高优先级覆盖”的情况已标注，移植时以生效值为准。

## 1. 旁白 `.narr`（`who` 为空）

- `.box`：`left:1.2%;right:1.2%;bottom:2%;height:27%`（固定高，非 auto）`;padding:1.6em 2.2em 1em`。
- 布局：`display:flex;flex-direction:column;justify-content:center;align-items:center;text-align:center`。
- 背景：`linear-gradient(90deg, transparent, rgba(14,10,7,.95) 15%, rgba(14,10,7,.95) 85%, transparent)`；无边框无阴影。
- 装饰线（`::before`，`inset:0 15%`）：顶边与底边各 1px，`linear-gradient(90deg, transparent, #a38a5e, transparent)`。
- `.txt`：serif，`color:#e6d6b3;letter-spacing:.14em;max-width:40em;font-size:20.5px;line-height:1.5`。
- 名牌隐藏；无立绘、无小头像（DialogueStage 在 `who` 为空时隐藏全部立绘）。
- 旁白 + 选择（`choose('',...)`）：`.box height:auto;min-height:27%`，选项居中排列。
- StoryRuntime 在选项前没有提问句时会调 `choose('',' ',...)`，txt 为一个空格。

## 2. 有大立绘 `.dialogue-staged.hasface`（非旁白）

- `.box`：`left:2%;right:2%`（不给立绘让位，框横跨全宽，立绘在框后面透出）`;min-height:15%;max-height:40%;padding:1.2em 2.2em .7em;box-shadow:none`。
- 背景：自上而下透明渐变 `linear-gradient(180deg, rgba(14,10,7,0) 0, rgba(14,10,7,.55) 2.2em, rgba(12,9,6,.78) 100%)`。
- 顶线：1px，`linear-gradient(90deg, transparent, rgba(224,191,120,.45) 10%, rgba(224,191,120,.45) 80%, transparent)`。
- `.txt`：`18.5px/1.45`，`text-shadow:0 1px 2px #000, 0 0 6px rgba(0,0,0,.8)`。
- `.who` 背景：`linear-gradient(90deg, rgba(14,10,7,.85), rgba(14,10,7,.55))`，`min-width:0`（原 10em 被覆盖）。
- `.choices`：`margin-top:.3em;gap:0`；按钮 `17px/1.35;min-height:1.75em;padding:.12em .8em .12em 1.6em`，同 txt 的 text-shadow。
- 暗角（`#dlg::before`，z0）：`inset:20% 0 0`（上 20% 以下铺满）`;background:linear-gradient(90deg, rgba(10,8,6,.24), transparent 32%, transparent 68%, rgba(10,8,6,.24))`。
- 地图模糊压暗见 02 §10。
- 若同时有小头像（极少见）：`.box padding-left:7.2em;min-height:6.4em`，`.mini left:1.2em;width:4.6em;height:4.6em`，`.who left:6.4em`。

## 3. 立绘元素 `.face.dialogue-portrait`

- 位置尺寸全部由 JS 写行内样式（公式见 07），CSS 只给：`animation:none;aspect-ratio:auto;pointer-events:none;transition:filter .15s ease`。
- 正在说话（`data-speaking="true"`）：`filter: drop-shadow(0 0 1px rgba(8,5,2,.95)) drop-shadow(0 0 2px rgba(8,5,2,.9)) drop-shadow(0 6px 14px rgba(0,0,0,.75))`（描边 + 投影）。
- 未说话（`false`）：`filter: brightness(.72) drop-shadow(0 6px 14px rgba(0,0,0,.75))`。切换 0.15s 过渡。
- 背景：`background-size:auto 100%;background-position:center top;no-repeat`。
- 遮罩：行内 `mask-image` 下沿渐隐（07 §4）。
- `.face` 原入场动画 `facein .32s cubic-bezier(.2,.7,.3,1)`（从 `opacity:0;translateX(8%)`）被 `.dialogue-portrait{animation:none}` 关掉——**立绘无入场动画**，说话人变化时只是瞬切。但 `dlgSetup` 在说话人变化时重置 `.mini` 动画，小头像的 `minin` 仍会播放。

## 4. 小头像条 `.dialogue-cast-rail`（第 4 位起）

- 容器：`top:3%;left:29%;right:29%;display:flex;gap:.5em;justify-content:center;flex-wrap:wrap;z-index:2`；无成员时隐藏。
- 每格 `.dialogue-cast-tile`：`display:flex;align-items:center;gap:.35em;padding:.25em .5em;background:rgba(18,15,10,.88);border:1px solid #a38a5e;color:#e9dcc0;font-size:max(13px,.8em)`。
- 头像 `.dialogue-cast-avatar`：`2.8em` 正方，`background:center/cover no-repeat`；回退整幅立绘时 `background-size:auto 260%;background-position:center 12%`。右侧 `<span>` 写人名。

## 5. 选择模式 `.choose`

- 非旁白：`.box` 变纵向 flex，`height:auto;max-height:75%`，选项区可滚动（02 §8）。
- `.more` 隐藏；`#dlg.onclick=null`（点空白不推进）。

## 6. 递水 CG 对白 `.cg-story`（`js/dialogue-stage.css`）

- 未选择：`.box height:auto;min-height:20%;padding:1em 2.2em;left:2%;right:2%`。
- 选择：`.box height:auto;min-height:34%;max-height:45%`。
- 背景沿用棕色渐变（02 §4）。立绘、小头像、多人立绘全部隐藏（`body.qh-cinematic` 规则 + `fullscreenCGActive()` 抑制）。

## 7. 章节 CG 对白 `.qh-cg-dialogue`（`js/qihe-chapter-presentation.css`）

规则本意是青灰底 + 左金线，但非旁白时被 `#dlg:not(.narr) .box.frame`（优先级更高）覆盖。生效值：

| 属性 | 非旁白（有人说话） | 旁白 |
|---|---|---|
| left/right | 2% / 2% | 4% / 4% |
| bottom | 3% | 3% |
| height / min / max | auto / 0 / 40% | auto / 0 / 25% |
| padding | 14px 24px | 14px 24px |
| display | block | block（txt 左对齐） |
| 背景 | 棕色渐变（02 §4） | `linear-gradient(90deg, #101817e8, #101817bc)` |
| 边框 | 无 | `border-left:2px solid #d0a66d` |

- `.txt`：`font: clamp(15px, 1.25vw, 20px)/1.6 var(--serif);padding:0`；非旁白 `max-width:58em`，旁白 `none`。`vw` 指浏览器窗口宽；Godot 取“窗口宽×1.25%，夹在 15–20px”，换算到 1280 设计宽约 16px。
- `.who`：`font-size:15px;left:24px`。
- `#dlg::before` 暗角隐藏；立绘、小头像、头像条全部隐藏。

## 8. 窄屏（容器宽 ≤760px）

`@container (max-width:760px)`：`#dlg .box{height:31%;padding:1.2em 1.6em .8em}`、`.hasmini .box{padding-left:7.4em}`、`.mini{width:4.8em;height:4.8em;left:1.1em}`。这些选择器优先级低，在 `.dialogue-staged` 下大多被覆盖，仅旁白框高 31% 实际生效。Godot 若只出桌面/横屏可忽略。

## 9. 庭院背景卡 `qh-backdrop`

`body.qh-backdrop` 只隐藏 HUD、日志、技艺按钮；**不**隐藏立绘（与 CG 不同）。对白框保持普通样式，z 改 65。详见 10。
