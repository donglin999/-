# 05 立绘选择与表情切换规则

源：`js/ui.js` `face()`、`js/core.js`（`PORTS`、`EXPR`、`OPT_PORTS`）、`js/qihe-characters.js` `OpeningCharacters.dialogueSprite`、`js/qihe-representatives-art.js`、`js/qihe-guiyun-household-art.js`、`js/qihe-chapter.js` 第 10–11 行、`js/qihe-cast-art.js`、`js/qihe-dialogue-portraits.js`。

## 1. 精灵键 `sp` 格式

`c_<立绘键>[:<表情>]`，如 `c_ye`、`c_qh_song_story:worry`。`c_` 前缀可有可无（一律先去掉）。立绘图键为 `p_<立绘键>`，表情图键为 `p_<立绘键>_<表情>`；路径由 `assetImagePath(key)` 查 `PRODUCTION_ASSET_PATHS`，查不到时用 `assets/<key>.webp`。

## 2. `face(sp)` 判定（返回 CSS `url(...)` 或 `'none'`）

1. `sp` 空 → `none`。
2. `[k, e] = sp去c_.split(':')`。
3. `k` 不在 `DIALOGUE_LEADS` **或** 不在 `PORTS` → `none`（改用小头像）。
4. `k ∈ OPT_PORTS(['suzhi'])` 且 `p_k` 未加载 → `none`。
5. 表情 `emotion`：`e==='neutral'` → 空；`e==='firm'` 且 `EXPR[k]` 不含 `firm` → `angry`；否则 `e`。
6. `emotion` 非空且 `p_k_emotion` 已加载 → 用表情图；否则用本体 `p_k`。**缺表情图时静默回退本体**，不报错。

“已加载”判定 `ok(IMG[key])`：图片对象存在且解码完成。Godot 用 `ResourceLoader.exists` 即可。

## 3. 名字 → 精灵键的改写链

`say`/`choose`/`DialogueStage` 都先调 `OpeningCharacters.dialogueSprite(who, text, sp)`。它被包了四层，**外层先判断**，不处理就交给内层：

1. 外层（`qihe-chapter.js`）：`who==='宋先生'`：表情 = `sp` 冒号后部分；若没给，按台词正则推断：`/走不走|侧口|动手了没有|站在哪|谁先伸手/` → `firm`；`/疑你|他也来了|当然好|今晚……|没签……/` → `worry`；都不中 → 无表情。返回 `c_qh_song_story[:表情]`。
2. `qihe-guiyun-household-art.js`：先调内层；若 `S.cultivation.facts.gy_hair_long` 为真且结果以 `c_opening_hero_village` 或 `c_opening_hero_modern` 开头，替换为 `c_gy_hero_long`（培养期两个月后长发）。
3. `qihe-representatives-art.js`：`who ∈ {徐令仪, 岑霜, 沈雁回}` 且序章激活时：
   - 表情先取 `sp` 冒号后；没给且有台词，按顺序匹配：
     - `/署名|我仍|我让|我核错|记我|限制.*记录|赔偿/` → 徐令仪 `awkward`、沈雁回 `skeptical`、岑霜 `sad`；
     - `/收剑|不许|松手|停下|手收|先救|扣箱.*停/` → `angry`；
     - `/附页|第十七|同一|转件|核实|验讫/` → 沈雁回 `skeptical`，其余 `neutral`；
     - `/伤者|伤处|病人|别逞强/` → `sad`；
     - 否则 `neutral`。
   - 返回 `c_<key>`（`neutral` 时不带冒号）或 `c_<key>:<表情>`。
4. 内层（`qihe-characters.js`）：
   - 序章未激活（`S.prologue.version!==2`）→ 原样返回 `sp`。
   - `who` 以 `'叶蘅 ·'` 开头（如“叶蘅 · 心想”）→ `c_ye`。
   - `who === (S.name||'萧白')` → 未借衣（`S.prologue.arrival.borrowed` 为假）时 `c_opening_hero_modern`，否则 `c_opening_hero_village`。
   - 否则查名字表（06 §1），查到返回表中值，否则返回传入的 `sp`。

**重要副作用（照抄）**：内层对萧白、叶蘅及名字表里的人**直接返回不带表情的键**，丢弃调用方传入的 `:表情`。因此在栖河版中，只有宋先生、徐令仪、岑霜、沈雁回会换表情；萧白、叶蘅等始终显示本体立绘。ink 里目前 13 处 `#mood` 全部属于宋先生（`firm` 8、`worry` 5）。

## 4. 表情如何从 ink 传到 `say`

- `StoryRuntime.parse` 取标签 `mood:xxx`，交给 `line(id, who, text, {mood})`。
- 主线 `QiheChapter.play`：`spriteWithMood(who, mood) = castSprites[who] ? castSprites[who]+':'+mood : undefined`，与台词一起放进 `rows` 第 3 列，`sayAll` 逐句 `say(w, t, sp)`。
- 选择题干：`play` 用 `moodsOf(knot)` 从编译 JSON 中正则 `"\^id:([^" ]+) ?","\/#","#","\^mood:([^" ]+)` 建 `id→mood` 表；`mark(id)` 记下题干编号，`choose` 时取对应表情。
- 三方剧本 `QiheRepresentatives.play` 的 `line` 不传表情（只靠 §3.3 正则）。
- 序章剧本（后山/递水/第一夜）的 `line` 直接 `say(who, text)`，不传表情。

## 6. 换人与入场

- 说话人变化（`who|立绘键` 变）才视为“换人”，只换表情不算。
- 换人时 `.face`、`.mini` 的 CSS 动画重置；但 `.dialogue-portrait` 已关闭动画，所以**大立绘瞬切**，小头像有 0.28s 从左滑入淡入。
- 未说话者立绘压暗为 72% 亮度，0.15s 过渡（03 §3）——这是唯一的“说话人切换”视觉反馈。

## 7. 抑制立绘的条件

- 全屏 CG（`body.qh-cinematic` 或 `#prologue-cg` 可见）：不显示任何立绘、小头像（`data-cg-portrait-suppressed="true"`）。
- 旁白（`who` 空）：DialogueStage 隐藏全部大立绘。
- 说话人没有立绘、又不是萧白（路人/孩子/景物）：本句隐藏全部大立绘，只显示说话人小头像（07 §3 `speakerless`）。
