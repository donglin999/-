## 2. 画面坐标与缩放

- 画布 `#cv` 逻辑尺寸 960×540（`core.js` `W=960,H=540`），铺满 `#game`（16:9，`width:min(100%,calc((100vh - 36px)*16/9))`）。
- 地图：`TS=40`，`ZOOM=5/6`，可视世界 `VW=W/ZOOM=1152`、`VH=648`（`scene.js`）。
- DOM 界面：`js/ui-scale.js` 以游戏区宽 **1280** 为基准，`--ui-zoom = clamp(实际宽/1280, 0.62, 2.4)`（保留 4 位小数），由 `ResizeObserver` 更新；`#game` 下除 `#cv,#cultivation,#fade,#loading,#panel,#bt,#prologue-cg,.qh-fire-cg` 外的子元素都 `zoom:var(--ui-zoom)`。
- **Godot 对应**：UI 根节点设计分辨率 1280×720，按宽度等比缩放（`stretch aspect=keep`），字号直接用 02/03 中的 px 值即为 1280 宽下的像素；画布层另设 960×540 视口拉伸到同一屏幕。CG 层和黑场不缩放、铺满。

## 4. 一句台词的完整调用链

`ink 文本` → `StoryRuntime.play` 解析出 `{who,text,id,mood}` → 场景的 `line()`（通常把台词攒进 `buf`）→ `sayAll(rows)`：`placeCast` 摆地图站位 + `DialogueStage.withCast` 登记在场立绘 → 逐句 `say(who,text,sp)` → `staging.look(who)` 让萧白转向 → `OpeningCharacters.dialogueSprite` 把名字换成立绘键 → `dlgSetup` 设名牌/立绘/小头像/类型 → `DialogueStage.render` 排多人立绘 → 打字机 → 玩家推进 → `closeLine`，隐藏 `#dlg`，Promise 结束。

选项：`choose(who,text,opts,sp,escIndex)` 返回所选下标（0 起）。
