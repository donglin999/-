### 1.2 中栏 `.qj-martial-main`
竖排 flex，`padding:16px 12px 10px; gap:10px; background:#faf7eeed`。
1. `header.qj-catalog-header`（竖排 gap 8）：`h2` `已学武学 <small>{N} 门</small>`（18px；small 11px `#7d725c`），N = 非 fist 外功数 + 已开放内功中层数>0 的数量；下方整宽搜索框，占位 `搜索功法或招式`（12px）。
2. 分类签：`全部 all / 外功 active / 内功 inner / 常驻效果 passive`，按钮 11px `padding:5px 8px`。
3. `.qj-skill-grid`：两列网格 `repeat(2,minmax(0,1fr)); gap:8px`，独立滚动。卡片 `.qj-skill-card`：两列小网格 `44px | 1fr`，三行，`gap:2px 7px; padding:10px 7px; 左对齐; background:#faf6eccc; border-bottom:1px solid --qj-rule`；图标 44×44 占三行；`strong` 名称 13px；`span` 第二行、`small` 第三行均 10px `#403a30`。选中 `.on`：`background:#eaddbfee; border-color:#8d7341; box-shadow:inset 3px 0 #8d7341`（左侧 3px 竖线）。
   - 外功卡：名 = `martialName`（有 `SKILLS[id].artName` 时 `{artName} · {name}`；`qh_hulu_staff` 为 `护路棍法`）；第二行 `{grade}级 · {level} 重 · {kind||外功}`（无 grade 省略前缀）；第三行 `可施展` / `条件不足`（`qh_hulu_staff` 前加 `横杆护身 · `）。
   - 内功卡：第二行 `{grade}级 · {level} 层 · 内功`；第三行 `当前主修/当前辅修/未运转`。
   - 常驻效果卡（已装备物品 + 运转中的内功）：第二行 `兵器/护具/佩饰`，第三行 `已装备`。
   - 空状态：有搜索词 `没有匹配的武学`；内功签且未开放 `内功修习暂未开放`；否则 `此分类暂无已学武学`。
   - 搜索：小写包含匹配 `displayName + name`（qh_hulu_staff 另含 `横杆护身`）；输入（非 IME 组合中）即清选择并重绘，焦点回搜索框。
4. `.qj-current-practice`（上边线 `#88775366`，`padding-top:10px`，12px）：
   - 选中外功：`当前修习 · {名}` 右侧 `{prof} / {profNeed||6}`；`<progress>` 高 6px、色 `#827047`；右对齐小按钮 `提升条件`。
   - 选中内功：`当前修习 · {名} · {N} 层`，`内功进度 {progress} / {progressNeed||当前已满} · 运转中/尚未运转`，可选 `learningHint`。
   - 其他：`选择已学武学，查看当前修习进度`。
5. 若有 `v.basicAttack`：底部链接按钮 `基础操作 · {名}`（11px，透明，上边线）。
