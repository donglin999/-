# 35 江湖纸签与头顶小签

源文件：`js/qihe-jianghu-slips.js`（`window.QiheJianghuSlips={slips,head,sign}`）、`js/qihe-jianghu-rep.js` `notify`、`js/qihe-npc-core.js`（头顶小签调用）、`js/qihe-jianghu-rep-ui.css`。数据表见 33 号文件。

## 2. 右上纸签 `slips(rows)`

- 调用方：`qihe-jianghu-rep.js notify(fresh,before,fameBefore)`：同一次结算按势力（声誉键 'fame'）合并 delta，去掉 0。每行 `{glyph: 声誉'名'/势力 glyph/'？', name: '声誉'/势力名/'关系', delta, reason: REASON_TEXT[reason]||'', cross: 跨档时 (delta<0?'落入':'升至')+新档名, color: 声誉'#3a3a32'/势力 color}`。没有签条模块时退回 `toast("名 +n · 原因", 2100)`。
- 容器：`#qj-slips`，首次调用时 append 到 `#game`（断开后重建）。
- 每条 DOM：`div.qj-slip(.neg|.pos)` > `i.qj-g`(style background=color||#3a3a32，文字 glyph) + `b`名称 + `em` 数值（`sign(n)`：n>0 用 `+`，否则用全角减号 `−`，后接绝对值）+ `span`原因 + 可选 `u`朱印文字。delta<0 为 neg，否则 pos。
- 时序：append → 下一帧（rAF）加 `.on` → 4000ms 后去 `.on` 加 `.off` → 再 400ms 删除。每次插入后若子节点 >4，从最早一条删起。整个过程 try/catch 吞错，地图不暂停。

## 3. 头顶小签 `head(npcId,text,kind)`

- 调用方：`js/qihe-npc-core.js` 好感变化时（非 `opts.quiet`）：text = `sign(v-before)+' '+stageOf(v)`；原因为 `steal_caught_kin` 时用 `' 牵连'`；kind = 下降 `'neg'` 否则 `'pos'`。
- 定位：NPC 在 `cur._npcs||cur.npcs` 里按 id 或 `PEOPLE[npcId].npc` 名单匹配。`c=#cv 矩形, r=#game 矩形, s=c.width/(W/ZOOM)`；`p=npcPos(n)`（缺省 `{x:n.x*TS,y:n.y*TS}`），`h=npcH(n)`（缺省 80）；`k=UIScale.zoom||1`。
  `left=(c.left-r.left+(p.x-cam.x)*s)/k`；`top=(c.top-r.top+(p.y-h-cam.y)*s)/k-18`。只取一次位置，不跟随。
- 时序：rAF 加 `.on`；2600ms 去 `.on`；再 400ms 删除。
- CSS：`.qj-head{position:absolute;transform:translate(-50%,-6px);padding:2px 8px;font-size:14px;letter-spacing:1px;color:#f1e6cf;background:rgba(22,24,20,.86);border:1px solid rgba(226,194,124,.65);white-space:nowrap;pointer-events:none;opacity:0;transition:opacity .25s,transform .25s;z-index:39}`；`.on{opacity:1;transform:translate(-50%,-14px)}`；`.neg{color:#ffd5c8}`；`.pos{color:#d8f0c8}`。

## Godot 对应
- 纸签：`#game` 层上的 `VBoxContainer`（右 3.2%、上 22%，右对齐，间距 8）；每条用 `PanelContainer` 加燕尾多边形遮罩，Tween 处理 x+40→0、透明度 0→1，0.3s ease。
- 头顶小签：世界坐标转屏幕坐标后放一个 `Label`，Tween 在 0.25s 内上移 8px 并淡入。
