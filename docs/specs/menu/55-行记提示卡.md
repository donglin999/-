# 55 行记提示卡（人物图鉴更新通知）

源文件：`js/qihe-journal-notices.js`（`window.QiheJournalNotices={reset,observe,flush,openCurrent,pending,version:1}`）、`js/qihe-journal.css`（`#qh-journal-notice`）。toast 见 54 号文件。

## 2. 行记提示卡（js/qihe-journal-notices.js，`window.QiheJournalNotices`）
仅在当前会话内有效，**不写存档**。

### 2.1 变化检测
- `snapshot(s)`：对 `QiheJournal.people(s)` 中每个人生成事实集合 facts，元素为 JSON 字符串：
  - `['profile',identity,bio,role,faction]`
  - 每条 `['event',e.text]`
  - 每条 `['relation',...r]`
  - 涉及此人的任务 `['task',q.id,q.status,[已完成步骤 [title,detail]],q.paper.fields]`
- `observe(s)`：无 `s.prologue` 时 reset。存档键 `saveKey()` 变化或没有 baseline 时也 reset（以当前状态作为新基线，不报变化）。否则逐人比较：baseline 中没有此人记为 `'new'`；有新增事实记为 `'updated'`。写入 `pending`（已是 new 的保持 new）；新快照中已不存在的人从 pending 删除；更新 baseline；调 `schedule()`。
- 触发点（包装原函数）：`say`、`choose` 前后各调一次 observe（Promise 结束后再调一次）；`loadSave` 后 reset；`persistState(s)` 在 s 为当前 S 时 observe；`hud()` 结束时依次 observe、flush。

### 2.2 显示调度
- 常量 `duration=4800`ms；`schedule()` 每 200ms 轮询一次 flush，直到 pending 和 current 都为空。
- `ready()` 需同时满足：页面可见、`S.prologue` 存在、`mode==='scene'`、不 busy、不 dlgBusy、`QiheChapter.running` 与 `QiheOutsiders.running` 为假、`DialogueStage.snapshot().scope` 为空、`#panel` 隐藏、`#fade` 没有 `.on`、`toastShowing` 为假。
- `flush()`：
  1. 存档键变化时 reset。
  2. 未 ready：若卡片正在显示，记下剩余时间 `remaining=until-now` 并隐藏，**暂停倒计时**，之后继续轮询。
  3. 有 current：恢复显示时 `until=now+remaining`；时间未到继续等；到时隐藏，current 置空，remaining 恢复 4800。
  4. 没有 current 且 pending 非空：只要有 new 就取 type='new'，否则取 'updated'；同类型最多取 3 人，从 pending 移出；设 `current={type,people}`、`until=now+4800`，然后 render。
- `dismiss()`：立即隐藏，进入下一轮。`view()`（即 `openCurrent`）：仅在卡片可见且 ready 时执行，调 `QiheJianghuUI.openPerson(people[0].id)` 后 dismiss，返回 true。
- 键 L：江湖菜单热键处理中，`key==='l'` 时先尝试 `QiheJournalNotices.openCurrent()`，返回 false 才打开行记页（qihe-jianghu-ui.js 热键段）。

### 2.3 DOM（render）
`aside#qh-journal-notice.qh-journal-notice[role=status][aria-live=polite]` 挂在 `#game` 下，`data-kind=type`，`data-people=id,…`。
- 头像：`p.art` 存在时为 `span.qhn-face`（`p.full` 为假时加 `.qhn-pixel`，id 为 ye 时加 `.qhn-ye`）> img；否则为 `span.qhn-badge`。
- `strong` 标题：
  - new：「结识了{label}」。
  - updated：「{label}的」+ `span.qhn-story`「故事，又添一笔」（不换行）。
  - `label`：≤2 人用「、」连接，否则「{第一人}等 N 人」。
- `p` 正文：new 为「这段相识，已记入人物图鉴。」；updated 为「最新见闻已记入人物图鉴。」
- 按钮 `[data-qjn=view]`「查看图鉴 L ›」；右上角 `button.qhn-dismiss[data-qjn=dismiss]`「×」。
