# 13 物品使用、图标生成与旧版菜单复用关系

源文件：`js/menu.js`（`mnUse` 第 497 行、`mnIco/mnSkIco/mnXfIco/mnAtlasIco` 第 425–430 行、`mnPor/mnFace/mnSideGear/mnBar`、`mnQuests` 第 618 行、`bagPanel/mnDraw` 第 436–457 行）、`js/menu-icons.js`、`js/item-icons-v4.js`。

## 1. 使用物品 `mnUse(k, w)`（w = 使用者）
前提 `S.bag[k] > 0`，按字段优先级分支：
1. `book` 武学残页：候选 = w 已学（除 fist）中 `mnUpWhy(w,s,true)` 为空者（可越过突破关）。无候选：toast `无法参悟 · {第一门名}：{原因}` 或 `尚无可参悟的武学`（1600ms）。有则弹选 `{名}参悟哪门武学？`，选项 `{武学名}（N 重 → N+1 重）`… + `算了`；选定后 `skills[s]++`、`bag[k]--`、toast `「名」突破至第 N 重`。
2. `xfbook` 心法残卷：候选 = 已知且层 < 5；未开放 toast `心法【入谷培养后开放】`、无候选 `尚无可精进的心法`（1200ms）；弹选 `{名}参悟哪门心法？`，选项 `{心法名}（第 N 层）`；层+1、prog=0、toast `「名」进至第 N 层`。
3. `insight` 历练手札：确认 `翻读{名}？读完得江湖历练 {insight}，全队共用，在队伍里分给谁都行。只能读这一回。` 选项 `读/先留着`（默认焦点第 2 项）；读后 `bag--`、`S.itemInsight[k]=true`、存档。
4. `gall`：`mpBonus += 30`，toast `{名} 内力上限 +30`（1000ms）。
5. 药食 `heal/mp`：若无对应可回复量（气血满且无 mp，或内力满且无 heal）→ toast `{名}无需服用`（900ms）。否则：
   - 医术系数 `hk = 1 + min(队中最高 ji.yi, 200)/200`（只作用于 heal）；
   - 药香荷包 `af = 1 + QiheAccFx.of(w).heal`（heal 与 mp 都乘）；
   - `新hp = min(mhp, hp + round(heal*hk*af))`，`新mp = min(mmp, mp + round(mp*af))`；同伴达上限写 null；
   - 音效 `__audio.sfx('chime', .5)`，toast `{名} 服下 {物品名}`（900ms）。
栖河新界面经 `QiheUIModel` 调用使用命令，效果与上述一致（见 41）。

## 2. 图标查找顺序 `mnIco(k, sz=30)`（像素边长）
1. `ITEM_ICONS_V4.html(k, sz)`（v4 手绘图集，命中即返回）；
2. `mnAtlasIco('item', k, sz)`（`MENU_ICONS` 旧图集）；
3. `ART.icons[k]`（art.js 程序图集，class `ico img jm-ai`，尺寸 `sz/16 em`）；
4. 墨迹单字 `mnBlot(ICO[k] || 名称首字, 品质色, sz)`，由 `BUI.blot` 程序生成并缓存为 dataURL。
武学 `mnSkIco(k)`：`MENU_ICONS.skill` → 墨迹字（武学名首字，`MN_KCOL[kind]` 色）。心法 `mnXfIco(k)`：`MENU_ICONS.xinfa` → 墨迹字 `心`、色 `#3a4f8a`。

### 2.1 v4 物品图集（`js/item-icons-v4.js`，`window.ITEM_ICONS_V4`）
- 素材：`assets/production/icons-and-props/i_qh_items_v4_20261030.webp`，网格 `cols:8, rows:8`。
- `item:{id:[列,行]}`，共 64 项，如 `book[0,0] bun[1,0] canglong_map[2,0] charm[3,0] cloth[4,0] club[5,0] collar[6,0] gall[7,0]`、`iron[1,1] jade[2,1] knife[3,1] mianjia[4,1]`、`needles[0,2] pelt[2,2] pill[3,2]`、`qh_*` 栖河物品（qh_candy、qh_herb_pouch、qh_hidden_dagger、qh_escort_notes、qh_medical_kit、qh_storm_lantern…）、`rusty[3,6] shovel[4,6] token[5,6] vest[6,6] wine[7,6] wood[0,7] xf_can[1,7]`、`gy_wood_bird[2,7]`（与 `gy_wood_bird_sale` 同格）`gy_hand_cloth[3,7] gy_wrist_guard[4,7] pei_lens[5,7]`。移植时直接按源文件该表逐项拷贝坐标。
- `style(k)`：`background-image:url(src); background-size:800% 800%; background-position:{c/(cols-1)*100}% {r/(rows-1)*100}%; background-repeat:no-repeat; image-rendering:auto`。等价于：把图集均分 8×8，取 (列,行) 格，缩放到 sz×sz，线性过滤（不是像素最近邻）。
- `html(k,sz)`：`<span class="jm-blot" style="display:inline-block;width:{sz}px;height:{sz}px;…" aria-hidden="true">`。

## 3. 人物图像
- `mnPor(w)`：先 `QiheMenu.portraitKey(w)`（主角：长发→`gy_hero_long`；借住→`opening_hero_village`；否则 `opening_hero_modern`，见 43），经 `assetImagePath('p_'+key)` 取立绘路径；主角兜底 `assets/production/portraits/p_hero.webp`；同伴取 `PARTY_DEF[w].por` 中第一个已加载的 `p_{por}`，最后兜底行走小图。
- `mnFace(w)`：`BUI.face(u,72)` 生成 72px 头像（同样优先 portraitKey），失败用 `miniSprite('c_'+art)`。

## 4. 旧版菜单界面（栖河中不显示）
`bagPanel/mnDraw/MN_TAB/mnClick/mnHover/mnTip*/mnSkillCard/mnBagTile/mnXinfaCard/mnDimsHTML/mnCSS`（第 436–1052 行）是旧“江湖行卷”水墨界面（7 页：属性/武学/行囊/装备/队伍/任务/设置，键位 Q/E 翻页、1–7 直达、Esc 返回）。栖河入口下 `bagPanel` 被 `js/qihe-jianghu-ui.js` 第 270 行覆盖，这套 DOM 与 CSS 不会出现，**不需要移植其布局**。
