# 22 立绘、抽屉、确认框与悬浮提示

源文件：`js/qihe-jianghu-ui.js`（`image`、`portrait`、`portraitHit`、`face`、`detail`、`renderDetail`、`closeDetail`、`confirm`、`renderConfirm`、`hover`、`leave`、`tipContent`）、`js/qihe-jianghu-ui.css`。

## 1. 立绘
`image(v)`：键 = 主角 `hero-guiyun`（`GuiyunHero.longHair()`）/`hero-village`（`S.prologue.arrival.borrowed`）/`hero-modern`，同伴用 id。路径取 `assets/ui/jianghu-v4/manifest.json` 的 `portraits[键].file`，缺省 `assets/ui/jianghu-v4/portraits/{键}.webp`；备用 `mnPor(id)`。有包围盒（`displayBounds` 或 `measurements.visibleBoundsAlpha1/64`）时，以 SVG `viewBox` 裁到包围盒外扩 8px，`preserveAspectRatio:xMidYMax meet`（底对齐等比），最大显示高 `maxDisplayHeightPx`（缺省 768）。清单数据（宽×高，包围盒 x0,y0,x1,y1）：hero-modern 1024×1536 [299,13,750,1514]；hero-village 1024×1536 [257,15,771,1495]；hero-guiyun 1024×1536 [164,6,815,1499]；ye（文件 `ye-menu-v2.png`）1024×1536 displayBounds [265,5,748,1509]；suzhi 512×768 [96,5,405,765]；censhuang 512×768 [34,8,481,753]。
点击立绘时做像素级命中（`portraitHit`）：只有点在 alpha 不透明处才算选中（键盘与名字条不受限）。Godot 可用 `BitMap` 从纹理 alpha 生成点击掩码。
头像 `face(v)` = `mnFace(id)`（72px 程序头像），失败用 `p_{id}` 立绘。

## 2. 抽屉 `detail(title, html, actions)` 与确认框 `confirm(text, run)`
- `.qj-overlay`：铺满，`background:#24291e4a; backdrop-filter:blur(5px); z-index:30`，flex 右对齐（抽屉从右侧贴边）。
- 抽屉 `.qj-drawer`：宽 `min(560px,92vw)`、满高，竖排；`background:#f0ecdf; border-left:1px solid --qj-rule; box-shadow:-8px 0 35px #24221926`。头部 `padding:20px 25px`、底线 `--qj-rule`，标题 21px `letter-spacing:3px`，右侧 `×` 按钮（无框 25px）。正文 `.qj-detail-body`：滚动，`padding:25px; 15px; line-height:1.8`；正文内 h2 29px、h3 18px、首图 84×84。正文末尾 `.qj-detail-status`（非空时 `margin-top:12px; #785622; 13px`）。页脚 `padding:18px 24px`、右对齐、`gap:10px`，按钮 = 传入 actions + 固定「返回」。打开后焦点到第一个按钮；关闭恢复打开前焦点。
- 确认框 `.qj-confirm`：居中，`max-width:520px; width:90%; padding:30px; background:#f0ecdf; box-shadow:0 12px 60px #0004`；标题固定 `确认操作`（23px），正文 `line-height:1.8; margin:20px 0 30px`；按钮 `取消`、`确认`(primary)。打开后焦点在「取消」。
- 确认框可叠在抽屉之上（同一 overlay 重绘），取消后回到抽屉。
- 江湖历练抽屉打开时隐藏全局 `#toast`。
## 3. 悬浮提示 `hover`
触摸不显示。目标 `[data-tip="kind:id"]`；有抽屉或确认框时不显示。延迟：pointer 180ms，键盘聚焦 0ms；离开 120ms 后隐藏，移入浮签本身取消隐藏。定位：放在目标右侧 +12px，超出则放左侧 -宽度-12px；上沿对齐目标顶部；四周夹在面板内 12px 边距（宽缺省 280、高缺省 160）。内容 `tipContent`：
- `actor`：名字（strong）、身份（缺省 `江湖同伴`）、`已出战/候补`+` · 锁定原因`。
- `stat`：`{属性名} {值}` + `STAT_HELP`。
- `item`：`名 · 品级`、说明、最多 3 行非零变化 `名 旧 → 新 (+差)`、不可用原因。
- `slot`：`{部位}` + `未装备 · 点击挑选器物`。
- `inner`：`名 · 品级级`、描述、`N 层 · 运转中/未运转`。
- `skill`：名称、描述（缺省 `点击查看招式详情`）。
`STAT_HELP`：臂力 `影响攻击强度与兵器使用要求`；根骨 `影响气血与防御`；身法 `影响身速、暴击与闪避`；定力 `影响内力与格挡`；悟性 `影响武学学习与熟练成长`。

## 4. 导出接口 `window.QiheJianghuUI`
`open, close, draw, trackedQuests, mainTracked, newQuests, setTracked, openQuest(key), openPerson(id), state()`（深拷贝界面态，detail 只留 title，confirm 转 bool）, `version:1`。HUD、通知模块使用 `trackedQuests/mainTracked/newQuests/openQuest`（见 50–54）。
启动时 `fetch('assets/ui/jianghu-v4/manifest.json?v=hero-guiyun-1')` 读立绘清单，到达后若菜单开着则重绘。

浮签样式（`.qj-tooltip` 最终值）：【.qj-tooltip】position:absolute;z-index:25;pointer-events:auto;width:280px;max-width:calc(100% - 24px);padding:16px 18px;border:1px solid #17171288;border-radius:5px;box-shadow:0 4px 16px #24221933;background:#2b2b22f2;color:#efe6cc;font-size:13px;line-height:1.65;border-color:#b4975c
标题 `strong` 17px `#ecd49a`；`p` 最多 3 行截断；`small` `#d0b989`。
