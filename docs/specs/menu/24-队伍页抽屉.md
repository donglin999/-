# 24 队伍页抽屉：编成、加点、江湖历练、宠物

源文件：`js/qihe-jianghu-ui.js`（`formation`、`formationRender`、`pointsRender`、`insightPanel`、`bindInsight`、`insightPreview`、`petDetail`，click 分支 `candidate/formationSlot/formationRemove/formationApply/allocate/pointPlus/pointMinus/pointReset/pointApply/insight*/pet*`）。抽屉通用样式见 22。

## 1. 抽屉：调整编成 `formation()`
草稿 `s.draft = active().slice()`，`s.candidate=null`。正文：`选择候补，再点要替换的位置；应用后才改变出战名单。`；4 列位格（每格按钮：头像 50px 圆 + 名字 + `剧情锁定` 或 `第N位`；空位 `＋ 空位`；非锁定者下方 `换下`）；小标题 `已结伴人物`；候选按钮（头像 54px 圆 + 名 + `已编入/不在场/可编入`，选中 `.on`，min-width 90px，`padding:12px`）。页脚 `应用编成`(primary)。
规则：点不在场者 → 提示 `lockReason||'该人物不在场'`；未选候选点位 → `先选择要编入的人物`；锁定的候选只能留在原位 → `剧情锁定人物必须保留当前位置`；位上原为锁定者 → `lockReason||'剧情需要此人同行'`；候选已在别的位则两者互换，之后压缩空位；换下锁定者 → `剧情人物不能换下`。应用 = `commit('applyFormation',{active:draft})`。

## 2. 抽屉：分配根基 `pointsRender()`
`s.points={}`。正文：`剩余 {v.points - Σ草稿} 点`；五行 `{属性名} [－] <b>{原值+草稿}</b> [＋]`（每行 `padding:10px 0`，数值最小宽 30px 居中）；下方数据格 4 项 `攻击/防御/气血上限/内力上限：before → after`（来自 `model().previewStats(actor, points)`，不改档）。＋ 前先用 `previewStats` 试算，`!allowed` 则提示 reason 且不加；－ 下限 0。页脚 `重置`、`确认分配`(primary) → `commit('allocateStats',{stats:points})`。

## 3. 抽屉：江湖历练 `insightPanel()`
草稿 `{actorId:s.actor, target:'level', amount:100}`。正文：eyebrow `全队共享 · 可用 {balance} 点`；说明 `历练来自已完成的差事、剧情和月度修习。1点兑换1修为；5点兑换1功法熟练，不叠战斗经验加成。`；两列表单：`培养人物`（下拉）、`培养内容`（下拉，`selected.options` 的 key/label）、`计划投入`（数字 1–1000000）；预设按钮 `100 / 500 / 1000`；预览区；`<details>收支记录 · 累计获得 {earned} / 使用 {spent}`，列最近 10 条倒序 `+/−{amount} · {name||修习}`，空时 `完成栖河差事、救援或每月修习后会记录在这里。`。
预览 `model().insightQuote(actorId,target,amount)`：允许时数据格 `实际消耗 {cost} 点`、`剩余历练 {balanceAfter} 点`、`{label} {before} → {after}级/重`、`获得修为/熟练 +{gain 保留1位}`、等级类加 `投入后修为 {已满级 | experienceAfter / after*100}`、`攻击/防御/气血上限/内力上限 before→after`，附注 `按实际可吸收数量扣除；不自动补血、疗伤或传授新功法。`；不允许时显示 reason 并禁用确认。
确认文案：`为{name}投入{cost}点历练，培养「{label}」（{before}→{after}），剩余{balanceAfter}点？` → `commit('spendInsight',{actorId,target,amount,expectedCost:cost})`。

## 4. 抽屉：同行宠物 `petDetail()`
无宠物：`尚未结伴` + `宠物跟在队伍末尾，自主行动。`。有：立绘（`p.portrait` 或 `assets/p_{id}.webp`）、名、气血内力条、`自动参战 · 不占人类出战位`、描述、`佩饰：{名|未装备}`；按钮 `喂食馒头`（确认 `消耗 1 个馒头喂食同行宠物？` → `feedPet{itemId:'bun'}`）、`戴上项圈`（`equipPet{itemId:'collar'}`）、`卸下项圈`（`equipPet{itemId:null}`）。
