# 54 通知与提示（toast、行记提示卡）

画面上共有四种提示，互相独立：
1. `#toast`：屏幕中上方的单行横幅，按队列逐条显示（本文件 §1）。
2. 行记提示卡 `#qh-journal-notice`：右上角的人物图鉴提示（§2）。
3. 江湖纸签 `#qj-slips` 与头顶小签 `.qj-head`：见 33 号文件。
4. 新任务 toast：`hud()` 中调用 `toast('新任务 · …',3000)`，见 50 号文件。

## 1. toast 队列（js/core.js `toast`、`showNextToast`；样式在 index.html）
- `toast(t, ms=1400)`：把 `[String(t), max(0,ms)]` 推入 `toastQueue`；当前没有显示时立即调 `showNextToast()`。返回已 resolve 的 Promise，**不会阻塞剧情**。
- `showNextToast`：队列为空时 `toastShowing=false`。否则设 `toastShowing=true`，取队首写入 `#toast.textContent`，加 `.on`；`ms` 后去掉 `.on`；再过 **180ms** 显示下一条。
- 全局变量 `toastShowing` 会被行记提示卡读取：toast 显示期间提示卡等待。
- 常用时长：一般 1400；纸签退回 2100；获得材料 2200；交换 1600；新任务、存盘失败 3000。
- 样式（`index.html`）：
  - `#toast{position:absolute(.ui);top:17%;left:50%;transform:translate(-50%,-.6em);padding:.45em 2.4em;font-family:var(--serif);font-size:1.05em(基准17px);letter-spacing:.2em;color:var(--hi)=#f3d58e;white-space:nowrap;`
  - `background:linear-gradient(90deg,transparent,rgba(16,12,9,.92) 18%,rgba(16,12,9,.92) 82%,transparent);border-top/bottom:1px solid;border-image:linear-gradient(90deg,transparent,var(--bz2)=#a38a5e,transparent) 1;pointer-events:none;opacity:0;transition:opacity .35s,transform .35s;z-index:8}`
  - `#toast.on{opacity:1;transform:translate(-50%,0)}`：淡入并下移 .6em，耗时 350ms。
  - 场景变体：商店面板 `.shopx` 打开时 `top:3.2%`；江湖菜单旧版人物录（`#panel.qj` 内含 `.qjc`）打开时 `top:auto;bottom:36px;max-width:90%;font-size:14px;white-space:normal`；分配根基表单 `.qj-insight-form` 打开时 `visibility:hidden`；`prefers-reduced-motion` 下无过渡。
- Godot：用一个 `Label` 加 `StyleBoxTexture`（两端透明的横向渐变）做 toast 节点，队列由 autoload 管理；Tween 0.35s 处理透明度和 y 偏移；两条之间间隔 0.18s。
