## 2. 原版脚本加载顺序（index.html 第 470 行，后加载的包装先加载的）
`item-icons-v4.js` → `menu-icons.js` → `menu.js`（旧菜单与 mn* 工具）→ `qihe-resources.js` → `qihe-menu.js` → `qihe-ui-model.js` → `qihe-journal.js` → `qihe-jianghu-data.js` → `qihe-jianghu-slips.js` → `qihe-jianghu-rep.js` → `qihe-jianghu-rep-ui.js` → `qihe-jianghu-ui.js` → `qihe-hud.js` → `qihe-journal-notices.js`。`qihe-grades.js` 也在同一行加载。
CSS：`qihe-jianghu-ui.css`、`qihe-journal.css`、`qihe-hud.css`、`qihe-chapter-presentation.css`、`qihe-npc-ui.css`、`qihe-jianghu-rep-ui.css`。
原版通过“函数覆盖链”扩展：`hud()` 依次被 resources → qihe-hud → journal-notices 包装；`say/choose` 被 journal 和 notices 包装；`persistState`、`loadSave` 被 notices 包装。在 Godot 中改为信号：`state_saved`、`state_loaded`、`dialogue_line(who,text)`、`hud_refresh`。

## 3. 坐标系与舞台
- `#game`：`position:relative; width:min(100%, (100vh-8px)*16/9); aspect-ratio:16/9; background:#000; overflow:hidden`。内部 `canvas#cv` 为 960×540 逻辑像素。
- HUD、toast、纸签、提示卡都是 `#game` 的绝对定位子元素，百分比相对 16:9 舞台计算，px 值随 `--ui-zoom`（`UIScale.zoom`）缩放。
- 江湖菜单 `#panel.qj` 用 `position:fixed` 铺满整个浏览器窗口，不受 16:9 舞台限制；其媒体查询断点（1800/1350/1000/760/650/600）按窗口宽度判断。
- Godot 建议：基准分辨率 1920×1080，stretch 模式 `canvas_items`，aspect `keep`。HUD 放在 CanvasLayer(layer=10)，用锚点百分比还原；菜单放在 CanvasLayer(layer=20)，全屏 Control。断点用 `get_viewport().size.x` 在 `_on_resized` 中切换主题变体。

## 4. 叠放顺序（低→高）
地图 canvas → `#hud`（`visibility:hidden`，菜单打开时隐藏）→ `#dlg` 对话框 → `#toast`(z 8) → 行记提示卡(z 9) → 头顶小签(z 39) → 纸签(z 40) → `#panel`（江湖菜单）→ 菜单内抽屉、确认框、悬浮提示。

## 5. 全局状态（存档 S 中与本范围相关的字段）
`S.name, lv, exp, pts, hp, mp, st, skills, prof, xinfa, weapon/armor/acc, bag{id:n}, silver, party[], mates{}, pet, pets{}, qiheRoster{version,members,availability,revision,commands}, questTrack{off,seen,init}, qiheCodex{version,people}, jianghu{ver,fame,faction,log…}, qiheResources{version,nodes,exchanges}, qiheChapter{stage,halfDay,events,choices,records…}, prologue{…}, cultivation{…}`。
运行时全局变量：`mode`（'scene'|'battle'|'menu'|'panel'）、`busy`、`dlgBusy`、`cur`（当前场景）、`cam`、`player`、`toastShowing`。

## 6. Godot 节点结构建议
```
Main
├ World (Node2D, 960×540 逻辑)
├ HUDLayer (CanvasLayer 10)
│ └ ExploreHUD: Status / Nav(6 钮) / Location / Tracker / Minimap / Controls
├ NoticeLayer (CanvasLayer 15): Toast, JournalNotice, Slips(VBox), HeadTags
└ MenuLayer (CanvasLayer 20)
  └ JianghuMenu: Backdrop / Header(Tab×6, Exit) / Main(页面容器) / Footer / Overlay(抽屉、确认框、提示)
Autoload: GameState(S)、UIModel(40–43)、Journal(52)、Jianghu(33)、ToastQueue(54)
```
页面切换时只替换 Main 下的子场景（`party.tscn`、`skill.tscn`、`bag.tscn`、`equip.tscn`、`quest.tscn`、`sys.tscn`）。所有写操作都走 `UIModel.command()`，成功后发出 `state_saved` 信号，HUD 和菜单据此重绘。
