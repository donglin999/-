## 5. 穿戴 `wearEquipment(id)`
单击仅选中（`s.selected`，切换 `.on`，不重绘）。双击或焦点在格上按 Enter（非重复）→ 若已穿在当前人物该部位：提示 `已装备此物`；`inspectItem` 不是 equip 或不允许：提示 `reason||'当前无法装备'`；否则 `commit('equip',{itemId})`（**无确认框**）。悬停浮签显示属性变化前 3 项。

## 6. 装备校验（model `equipWhy`，与 menu.js `mnCan` 文案不同，以此为准）
顺序：`角色不在场` → `不可装备` → `无法装备此部位`（部位不在 `mnDef(id).slots`）→ `此角色不使{kind}`（兵器类别经 `mnWeaponType` 归一后不在 wk 内）→ `需{属性} {v}`（裸五维 `rec.st`）。另外背包数量 <1 时 `数量不足`。
变化 `deltas`：在深拷贝上换装后用 `calc` 对比 `MN_DK` 各键，仅列有变化的 `{key,name,before,after,delta}`。
执行：原部位物品回包 +1，部位=新物品，包内 -1，`clampHealth`（气血内力截到新上限）。
