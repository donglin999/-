# 27 武学详解：外功、内功与内功运转

源文件：`js/qihe-jianghu-ui.js`（`skillDetail`、`innerDetail`、`martialInnerOverview`；click 分支 `skillBP/skillConditions/innerMain/innerSub/innerOverview/basicAttack`）。所在位置为武学页右栏 `.qj-martial-reader`（见 25）。

## 1. 外功详解 `skillDetail(id)`
- 图标；h2 名；（qh_hulu_staff 加 eyebrow `招式 · 横杆护身`）；三列事实格 `.qj-skill-facts`（上下边线，`padding:12px 0`）：`功法：{grade}级 · {kind||招式} · {level} 重`、`内力消耗：{k.mp ?? mnSkMp}`、`兵器条件：{needWeapon||不限}`；描述；不可用原因（红 `.qj-warning`）。
- BP 预览签 `BP 0 / BP 1 / BP 2 / BP 3`（`s.bp`）；说明行 = `info.bpDescription`，否则 `威力 {power 两位小数} · {hits||1} 段[ · 恢复 {heal}][ · 持续 {duration} 回合]`，无数据 `按战斗规则强化`；脚注 `仅预览，不消耗 BP 或内力。`。数据 `model().inspectSkill(actor,id,bp)`。
- 基本攻击（fist，经「基础操作」进入）：标题 `基本攻击`，图标为当前兵器或 fist；BP 签同上；说明 `{1+bp} 次攻击 · 内力消耗 0`。
- `提升条件` 抽屉：`<h2>{名} · {N} 重</h2>`、`熟练 {prof} / {profNeed||6}`、`mnUpWhy` 结果或 `熟练积累到门槛后自动提升。`、注 `实战、秘籍或师父指点可积累熟练；不消耗资源进行预览。`。

## 2. 内功详解 `innerDetail(id)`（`model().inspectInner`）
图标；h2；`{grade}级 · 主修心法/辅修心法 · {level} 层 · {xing||中性}`；描述；每条特性 `{level} 层 · {description}`（未实装加 `（尚未生效）`）；红字 `mainReason/subReason`。按钮：主修类 `当前主修`/`设为主修`；辅修类 `停止辅修`/`设为辅修`（不满足时 aria-disabled）。
- 设为主修：`!canMain` 提示 mainReason；有 `swapCost` 时确认 `改修主修心法将清空内力，并有 {unstableBattles} 场气脉不稳。确认改修？`，否则 `设「{名}」为主修？` → `commit('setMainInner',{innerId,confirmCost:true})`。
- 辅修：未运转且 `!canSub` 提示 subReason；否则直接 `commit('setSubInner',{innerId})`（切换）。

## 3. 内功运转概览 `martialInnerOverview(v)`
未开放：`内功运转` + `暂未开放修习与主辅配置`。开放：`主修` 一行按钮 `<small>主修</small><strong>{名}</strong><span>{N} 层</span>`（按钮整宽，`background:#eee6d3; border:1px solid #9d8d6866; padding:7px 4px`），未配置 `主修 · 尚未配置`；辅修列表（无则 `尚未运转辅修心法`）；脚注 `辅修 {n} / {capacity}`（capacity 缺省为等级达到 13/25/39 的个数）`[ · 13级开启首位][ · 气脉未稳 {k} 场]`。点击条目 → 切到内功签并选中。
