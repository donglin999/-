# 36 行记页：人物图鉴详情

源文件：`js/qihe-journal-ui.js` `renderPerson`、`relation`、`face`；`js/qihe-journal.css`。目录结构、badge/face 规格见 32 号文件，类名同样带 `qjc-` 前缀。

## 5. 人物详情 renderPerson(p,people,tasks)
空态：h2「人物图鉴」，p「相识的人物会记在这里，经历随行程补充。」
`div.codex-layout`，grid 为 `minmax(270px,31%) minmax(0,1fr)`，gap 30，min-height 580；宽度 ≥1001 时 dossier 区单独滚动。
- `figure.portrait-pane`：背景 `radial-gradient(ellipse at 50% 70%,rgba(158,171,139,.13),transparent 64%)`。
  - p.full 时显示 `img.portrait-art`：宽 124%（ye-menu 为 110%），高 `calc(100% - 38px)`，contain，底部居中，max-height 630。
  - 否则加 `.avatar-only`（padding-top 94），显示 face.big。
  - figcaption 高 38：small badge4 +「人物图鉴 · {name}」（13px muted）。
- `div.dossier`：
  - eyebrow「人物档案 ／ 江湖相识」。
  - person-title：h2 name（36px 宋体）+ faction-chip（15px 绿色，左分隔线，padding-left 17）。
  - person-role：18px 绿色。
  - 有 affection 时显示 `section.affection`：背景 `linear-gradient(110deg,#ebe0bb70,#f4ebd330)`，左边框 `2px solid #8d9170`，padding `10px 14px`。内容为「♡ {stage}」与「{score} / 100」、`progress`（高 5，accent `#748266`）、small「当前阶段上限 {cap}」（atCap 时追加「 · 需要新的共同经历」）、最近 3 条 `li`（source + 「＋n」或「关系未增加」）；没有记录时显示「刚相识，往后的经历会记在这里。」
  - facts：pin +「初识」+ p.first，上下边框，padding 12，16px。
  - section「人物小传」(badge12)：bio，18px/1.85，max-width 45em。
  - section「已知经历」(badge5)：`ol.timeline`，li 左边框 `1px solid #c5cdbb`，padding-left 22，前面一个 7px 绿点（left -4, top 8）；small(phase) + text，17px/1.65。
  - `div.codex-links`，两栏：
    - 「相关人物」(badge4)：relationship-grid（flex wrap），relation 按钮最小宽 138，内含 face.sm、strong 16px、small 说明、›。无人时「尚无已记录的往来人物。」
    - 「关联任务」(badge1)：`p.tasks` 映射为任务，`out:` 开头的排在前面，最多 3 条。按钮 `related-task[data-qj=journalTask]`，背景 `#e2e7d88c`，左边框 `2px solid #97aa8a`，padding 10；内容为 badge5 + short(title) + small(kind) + 状态（「✓ 已完成」或「正在进行」）。无任务时「暂无已承办的关联任务。」

页面级 CSS、交互分支与任务追踪见 34-行记页样式交互与追踪.md。
