# 43 界面模型：技能视图、物品视图与其他读接口

源文件：`js/qihe-ui-model.js`（`skillView`、`skillMultiplier`、`skillEffects`、`category`、`item`、`inspect`、`upgradeWhy`、导出对象）。normalize/calc/actor 见 40 号文件。

## 6. skillView(s,id,k,bp)
- `mp = max(0, sk.mp + mnHuo(k,n).mp + mastery.mp)`。
- `reason` 按优先级取第一个：角色不在场 → `需装备{needWeapon}`（武器类型 `mnWeaponType` 不符）→ `需{STATN} {v}`（遍历 req，**后写覆盖前写**）→ 内力不足。
- `skillMultiplier`：`bonus = mnHuo.pow + mastery.pow + eb[元素] + (治疗技 ? heal : 0)`；主修心法阳对阴、阴对阳时 bonus 减 .1；`eff=max(.1, round((1+(mnLvM(n)*(1+bonus)-1)/.15)*1e4)/1e4)`；返回 `1+.15*(eff-1)`。
- `bpDescription`：有正式效果时为「威力 {power*hits 保留 2 位} · {hits} 段；{desc}」；治疗技为「恢复目标气血上限的 N%」；buff 为「定神持续 {2+bp} 回合」；其余为「威力 x.xx · n 段」，qh_hulu_staff 另附「；护身减伤15%，至下次本人行动前」。
- 返回 `{id,name,kind,level,grade,mp,desc,available,reason,prof,profNeed:mnProfNeed(n,k),needWeapon,bp:[0..3 的 skillEffects],icon:mnSkIco(k,64)}`。
- `skillEffects`（无正式值时）：`lvM=1+.15*(lv-1)`；`power=pow*lvM*(hits ? 1/√hits : 1+bp*.8)`；`hits=(hits||1)+(hits?bp:0)`；`heal=heal*lvM*(1+bp*.5)`；`duration=buff ? 2+bp : null`。

## 7. 物品
- `category(k)` 依次判断：无定义→'其他'；mnSlot→'装备'；book/xfbook→'秘籍'；heal/mp/gall→'药食'；mat 或三种野外材料（qh_dry_branch/qh_wild_herb/qh_river_reed）→'材料'；key→'要物'；否则'其他'。
- `item(s,k)={id,name||'暂无法识别',desc||k,count,category,grade:装备取 mnQ(k)[0],slot,icon:mnIco(k,64),known}`。
- `inventory({category,search,sort})`：只取 count>0 的物品。category≠'全部' 时按分类、中文部位名或 slot 过滤；search 对 name+desc 做小写包含匹配；sort 为 'count' 时按数量降序，否则按 `localeCompare(name,'zh-CN')` 排序，再以 id 兜底。
- `inspect(s,id,k)`：
  - 装备：action 为 'equip'，reason 取 equipWhy；`deltas` 列出 `MN_DK` 中前后不同的项 `{key,name:MN_FXN,before,after,delta}`。
  - 书：'learnFromItem'。book 的 targets 为已学技能（reason 取 upgradeWhy）；xfbook 在 chapter<2 时 reason 为「入谷培养后开启」，否则 targets 为已知心法（≥5 层为「已达五层」）。没有可用目标时 reason 为「暂无可参悟武学」。
  - 药食：'useItem'。`yi` = 全队最大 ji.yi；`heal=min(缺血, round(it.heal*(1+min(yi,200)/200)))`；`mp=min(缺蓝, it.mp)`；非 gall 且两者都为 0 时 reason 为「气血内力已满」。
  - 其他：「此物品需在剧情或指定地点使用」。数量 <1 时为「数量不足」。
- `upgradeWhy`：章节重数上限 `cap=[0,4,6,7,8,9,10][min(6,chapter)]`；需求属性 `a=sk.key||'wis'`，`v=max(3,req[a])+floor(1.5*n)`；兵刃造诣 `zy[t] < mnZyUp(n+1)` 时为「兵刃造诣不足」；hero 授课上限时为「已达授课上限，进阶须另行传授」。

## 8. 其他读接口
`snapshot()={revision,active:['hero',...party],roster,pet,chapter,silver}`；`roster()`；`active()`；`view(id)`；`inspectItem(id,k)`；`inspectSkill(id,k,bp)`；`previewStats(id,delta)`（每项上限 `8+lv`，返回 `{allowed,reason,cap,spent,remaining,before,after,stats}`）；`inspectInner(id,k)`（含 `canMain/canSub/mainReason/subReason/swapCost:{mp:'全部',unstableBattles:MN_XF_SWAP}/traits[3,5]`）；`pet()`（description：「自动参战，固定队尾；主角气血不高于一半时优先护主。」）；`settings()={muted,theme:'ink'|'scroll'}`；`insight()`、`insightQuote()` 见 41 号文件。
