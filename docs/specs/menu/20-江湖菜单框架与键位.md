# 20 江湖菜单框架：开关、状态、页签、键位

源文件：`js/qihe-jianghu-ui.js`（IIFE，全局导出 `window.QiheJianghuUI`）。函数：`open`、`close`、`go`、`back`、`draw`、`guard`、`dirty`、`commit`、`notify`、`onKey`、`click`、`hover/leave/hideTip`、`tipContent`。容器为 `#panel`（`js/ui.js` 的 `openPanel('qj')` / `closePanel()`）。界面只读 `QiheUIModel` 快照，**所有改档都经 `commit()` → `QiheUIModel.command()`**（见 41）。

## 1. 页签 `TABS_UI`
顺序（编号即数字键）：
| # | id | 名称 | 图标键 |
|---|---|---|---|
| 1 | party | 队伍 | party |
| 2 | skill | 武学 | skill |
| 3 | bag | 行囊 | bag |
| 4 | equip | 装备 | equip |
| 5 | quest | 行记 | quest |
| 6 | rep | 关系 | rep（仅 `window.QiheJianghuRepUI` 存在时插入，否则设置为第 6） |
| 7 | sys | 设置 | sys |
`tabId('attr') → 'party'`（旧属性页并入队伍页）。

## 2. 状态对象 `s`（仅界面态，不入存档）
`open:false, page:'party', actor:'hero'`（当前查看人物）, `category:'全部', search:'', sort:'name', slot:null, selected:null`（行囊）, `stack:[]`（返回栈）, `draft:null`（编成草稿：出战 id 数组）, `points:null`（加点草稿 `{str:n…}`）, `detail:null`（抽屉 `{title,html,actions}`）, `confirm:null`（`{text,run,focus}`）, `skillTab:'all', skillSearch:'', skillKind:null, skillId:null, bp:0`（武学）, `equipCategory:'all', equipSearch:'', equipType:'all', equipSort:'name', equipScroll:0`（装备）, `questFilter:'active', questId:null, journalView, journalPersonId, journalCollapsed, journalNarrow`（行记）, `repSel`（关系）, `busy:false, revision:0, scroll:0`, `insightDraft, insightQuote, saveView, saveEdit, candidate, guard`。
模块变量：`manifest`（立绘清单）、`hoverTimer/hideTimer`、`focusBefore`、`detailFocus`、`opSeq`、`lastPointerType`。

## 3. 打开 `open(tab, who)`
前置（任一不满足则不开）：`QiheUIModel` 存在、`S` 存在、`mode==='scene'`、`!busy`、`!dlgBusy`；若 `#panel` 已被别的面板占用（非 hidden 且 `!s.open`）也不开。已打开时传 tab 则 `go(tab)`。
步骤：记 `focusBefore`；`s.open=true`；tab 合法则 `s.page=tab`；`who` 设 actor；清 `stack/detail/confirm/draft/points/selected`；清所有移动按键；玩家停步（`S.x/S.y` 同步，path/goal/talkTo 清空，速度 0）；`openPanel('qj')`，`panelKind='qihe-jianghu'`，`panelRedraw=draw`；`panelClose` = 关闭标志 + 隐藏浮签 + 清按键 + `hud()`；绑定 click / dblclick / pointerover / pointerout / focusin / focusout，pointerleave 120ms 后隐藏浮签；`draw()`；焦点到当前页签按钮。
`bagPanel(tab, who)` 在栖河入口下被覆盖为 `open(tab, who)`。

## 4. 关闭 / 返回
- `close()`：清 open/detail/confirm/draft/points，隐藏浮签，清按键，`closePanel()`，焦点还给 `focusBefore`。
- `back()` 逐层：有确认框→关确认框并恢复焦点；有抽屉→若有草稿走 `guard`，否则关抽屉；`stack` 非空→弹出恢复 `{page,actor,category,scroll,slot,search,sort}` 并重绘；否则 `guard(close)`。
- `go(page)`：`guard` 后清 detail/selected/slot/stack/scroll，切页重绘。
- `guard(fn)`：`dirty()`（编成草稿与当前出战不同，或加点草稿有非零）时弹抽屉「尚有未应用的调整」，正文 `应用更改后离开，或放弃本次草稿。`，按钮 `应用并继续`(主)、`放弃更改`、`继续编辑`；否则清草稿后直接执行。

## 5. 重绘 `draw()`
1. 若 actor 不在名单，回到 `active()[0]||'hero'`；队伍页只允许出战者为 actor。
2. 取不到人物视图时整页显示 `人物状态暂不可用` + 返回按钮。
3. `readRevision()`：从快照读 `revision`（乐观锁）。
4. 整体 DOM（绘制顺序自底向上）：
```
.qj-backdrop                    背景画 + 白雾
header.qj-header
  span.qj-brand                 武学页不显示；行记页文字「江湖行记」，其余「江湖」
  nav > button[data-qj=page]×N  图标 + <span>名称</span> + <small>序号</small>；当前页 .on
  button.qj-exit                「返回 <small>Esc</small>」
main.qj-main                    当前页内容（见 22–33）
footer.qj-footer                三段：「{人物名} · 出战/候补」｜操作提示｜.qj-live 状态播报
.qj-tooltip（hidden）
.qj-overlay（hidden）           抽屉/确认框容器
```
操作提示：行记页 `点击条目查看 · L 打开行记 · Esc 返回游戏`，其余 `悬停查看 · 点击选择 · Q / E 翻页 · Z / C 切人`。
5. 图片 `data-fallback` 加载失败时换备用图并加 `.fallback`；绑定各页（行囊 `bindInventory/renderGrid/renderItemAction`，装备 `bindEquipment`，武学 `bindMartialSearch/renderMartialReader`）；恢复抽屉/确认框；否则恢复先前焦点（按 `data-qj/id/slot/index` 匹配）。

## 6. 提交与播报
- `commit(type, payload, after)`：`busy` 时忽略；调用 `model().command({type, actorId:s.actor, ...payload, expectedRevision:s.revision, commandId:'ui-'+Date.now()+'-'+(++opSeq)})`，异常视为 `{ok:false, reason:'操作未完成，请重试'}`。成功：关抽屉与确认框、读 revision、执行 `after`、选中物品若已不在包内则清空、`draw()`、`notify(message||'已完成')`。失败：关确认框、抽屉仍在则重绘、读 revision、`notify(reason||'当前不可操作')`。
- `notify(t)`：写入抽屉内 `.qj-detail-status` 和页脚 `.qj-live`；页脚不存在时退化为 `toast(t, 1400)`。

## 7. 键位 `onKey`（window keydown，捕获阶段）
**菜单未开时**（热键，需在场景、无对话、无面板、无覆盖层 `qiheOverlayOpen()`、非输入框、非重复、非 IME、无修饰键）：`I`→打开（上次页）；`B`→行囊；`K`→武学；`L`→先尝试 `QiheJournalNotices.openCurrent()`，未处理则打开行记；`Esc`→设置页（地图导航 `QiheNavigation.isOpen()` 时不抢）。

> Godot 版 2026-11-05 起：培养模式里没开着小窗、对白时按 `Esc`（或点右上角齿轮）也打开这一个设置页，设置页另加培养专有的几项；见 [2026-11-05-esc-menu.md](../../updates/2026-11-05-esc-menu.md)。
**菜单已开时**（阻止事件继续传播；带 Ctrl/Meta/Alt 忽略）：
- 焦点在输入框：只处理 `Esc`=失焦并聚焦当前页签。
- `Esc` / `I`：`back()`。
- `Tab`：在可见可用的 `button,input,select,[tabindex=0]` 中首尾循环（有弹层时限定在弹层内）。
- 有抽屉/确认框时：仅当存在草稿，`Q/E` 翻页、`Z/C` 切人（经 guard）；其余键不处理。
- `Q`/`E`：上/下一页签（循环）。`1`–`9`：直达第 n 页。
- `Z`/`C`：上/下一人（队伍页在出战名单内循环，其他页在全名单内循环），经 guard，清选中。
- `B/K/L`：行囊/武学/行记。
- 方向键：焦点在物品格时按网格移动（左右 ±1，上下 ±列数），滚动到 `floor(next/cols)*96` 并聚焦；否则在可见按钮列表中前后移动（左/上 -1，右/下 +1，循环）。
- `Enter`：装备页焦点在候选装备时直接穿戴（非重复）。
- `F1`：物品格→物品详情；武学→武学详情；人物→属性详情。
- keyup：菜单打开时吞掉方向键/WASD/Shift 并清按键，防止人物走动。
- resize：行囊页重算网格；行记页宽度 ≤1000 时自动折叠侧栏；隐藏浮签。

（悬浮提示与导出接口见 21。）
