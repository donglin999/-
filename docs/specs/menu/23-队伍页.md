## 2. 左栏 `.qj-summary`（`summary(v)`）
自上而下：
1. `p.qj-eyebrow`：`QiheMenu.title()`（最新里程碑名，缺省 `江湖行卷`，见 43）；10px，`letter-spacing:1.5px; color:#7d6440; margin:2px 0 9px`。
2. `h1` 人名：`clamp(30px,3.3vw,56px)`，`letter-spacing:8px; line-height:1.1; color:#30271d; font-weight:800`。
3. `p.qj-role`：`{主角为「异乡来客」，否则 v.role||「江湖同伴」} · {level}级`，15px，`letter-spacing:3px`，下边距 16px。
4. 若有 `v.relationship`：`.qj-relation-summary` `♡ {stage} {score}/100`（15px，`padding:10px`，背景 `linear-gradient(110deg,#ede2bc80,transparent)`）。
5. `vitals(v)`：气血、内力两条（样式见 21）。
6. `.qj-exp`：`v.level>=100` 显示 `已满级 · 100级`，否则 `修为 {exp} / {expMax||100}`；13px `#6d6251`，上下 14px。
7. 每个状态异常 `v.conditions[]` 一个可展开 `<details>`：摘要 `{icon} {name}`；展开三段：来源 `source`；倍率 `气血上限 80% · 攻击 90%…`（键名映射 mhp气血上限 mmp内力上限 atk攻击 spd速度 def防御，值 `round(mul*100)%`）；恢复方式 `recovery`。
8. `.qj-stats` 五维图标：上方 1px 分隔线（左右缩 5%），`padding-top:16px; gap:12px 8px`，居中换行；每项 `.qj-stat` 竖排、`flex-basis:29%`（即每行 3 个，共两行 3+2），图标 `clamp(44px,4.7vw,72px)` 方形，文字 `{属性名} <b>{值}</b>`。点击 → 抽屉 `{属性名}`：`<h2>{属性名} {值}</h2><p>{STAT_HELP}</p>`。悬停浮签同内容。
9. `.qj-summary-actions`：上边 1px 线，`padding-top:14px; gap:8px` 居中换行；按钮 13px `padding:5px 12px; min-height:38px`：`属性详情`；`江湖历练 {pool.balance}`；若 `v.points>0` 加 `分配 {n} 点`。
左栏自身 `overflow:auto`，右内边距 10px，细滚动条。

## 3. 右栏 `.qj-cast-stage`（出战人物立绘）
- 容器 `display:flex; justify-content:center; align-items:end`，作为尺寸容器。
- 内部 `.qj-cast` 网格：列宽按各人立绘**可见包围盒宽高比**分配：`weight = (min(W,x1+8)-max(0,x0-8)) / (min(H,y1+8)-max(0,y0-8))`，无数据取 0.45；`grid-template-columns: {w1*100}fr {w2*100}fr…`；总宽 `min(100%, (min(容器高,700px) - 34px) * Σweight + (人数-1)*24px)`，`gap:24px`，高 100%，最大 700px。
- 每人 `.qj-cast-person`：两行网格 `minmax(0,1fr) 34px`；第 1 行立绘（底对齐、等比包含，`drop-shadow(0 3px 2px #56402529)`，选中 `drop-shadow(0 2px 3px #9a702541)`），第 2 行名字（15px，`letter-spacing:2px; color:#30291f; text-shadow:0 1px 3px #fff`，单行），剧情锁定者名下加 `<small>剧情同行</small>`（9px）。选中者整格 `box-shadow: inset 0 -3px #a38540`（底部 3px 金线）。
- 点击（需命中不透明像素）→ 切换 actor（经 guard，清选中、武学选择、bp、抽屉）。

## 4. 底栏 `.qj-party-bottom`
`display:flex; align-items:center; gap:14px; padding:14px 0 18px; min-height:74px; background:#faf7eeed; border-top:1px solid --qj-rule`。从左到右：
1. `出战编成`（15px，`letter-spacing:3px; #69512e`）。
2. 4 个圆形位 `.qj-mini`（54×54，`border:2px solid #ad8c4e; border-radius:50%; background:#ded0ad; box-shadow:0 0 0 2px #f1e1b9`；选中 `0 0 0 2px #fbefb9, 0 0 13px #a1813b`）：有人显示头像 + 下方 11px 名字（`bottom:-17px`）；空位显示 `＋`（28px `#9b926e`），点空位 = 打开编成。间距 14px。
3. `出战 {n} / 4`（13px `#78623c`）。
4. 按钮 `调整编成`（14px，`padding:7px 20px`）。
5. 右推到底 `.qj-pet-button`：painted 图标 pet（34×34）+ `同行宠物`，高 44px。
`max-height:780px` 时 `.qj-mini` 48×48。
