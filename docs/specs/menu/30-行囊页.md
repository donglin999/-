# 30 行囊页（bag）

源文件：`js/qihe-jianghu-ui.js`（`bagPage`、`inventory`、`bindInventory`、`renderGrid`、`renderItemAction`、`inspect`、`itemDetails`、`showItemDetails`、`chooseSlot`；click 分支 `category/slotFilter/resetFilter/item/itemDetail/itemCommit/learn`；`onKey` 方向键分支）、`js/qihe-jianghu-ui.css`、`js/qihe-ui-model.js`（`inventory`、`category`、`item`、`inspect`，见 40/41）。

## 1. 布局
`.qj-inventory`：单列网格，`height:100%; padding:20px 3.5%`。内含 `.qj-bag-main`（竖排 flex，`background:#faf7eeed`，无边框）：
```
.qj-bag-tools        搜索 | 排序 | 使用对象 | {N} 类器物
.qj-categories       全部 装备 秘籍 药食 材料 要物 其他
.qj-subcategories    （仅「装备」时）全部 兵器 护具 佩饰
.qj-grid-scroll      虚拟滚动网格（flex:1）
.qj-item-action      选中物品操作条
```
标题 `随身行囊`（`.qj-region-title`）最终 `display:none`。

## 2. 工具条 `.qj-bag-tools`
flex，`gap:24px; min-height:42px; padding:2px 0 12px`，底边 1px `--qj-rule`。
- 搜索框（占位 `查找器物`）：输入即 `s.search=值; selected=null; scroll=0`，重画网格与操作条（不整页重绘，保持输入焦点）。匹配：`(name+desc).toLowerCase()` 包含搜索词小写。
- `排序` 下拉：`name 名称` / `count 数量` / `category 类别`。model 端只区分 `count`（数量降序，同数按 id），其余都按 `name.localeCompare(zh-CN)` 再按 id（**「类别」在 model 中等同名称排序**，照原版实现）。
- `使用对象` 下拉：全部结伴人物，不在场者后缀 ` · 不在场`；改变即 `s.actor` 并整页重绘。
- `.qj-bag-count`：`{列表长度} 类器物`（12px）。
- 标签字 12px；下拉 `border:0; border-bottom:1px solid #8e7f60; background:#f8f2df88; padding:7px; color:#413b2e; font-size:13px`。

## 3. 分类
- 一级（`s.category`，切换时清 slot/selected/scroll 并重绘）：`全部 / 装备 / 秘籍 / 药食 / 材料 / 要物 / 其他`。
- 物品归类 `category(k)`（qihe-ui-model.js）顺序判定：无定义→`其他`；`mnSlot` 有→`装备`；`book||xfbook`→`秘籍`；`heal||mp||gall`→`药食`；`mat` 或 id ∈ {qh_dry_branch, qh_wild_herb, qh_river_reed}→`材料`；`key`→`要物`；否则 `其他`。
- 二级（仅装备，`s.slot`）：`全部(null) / 兵器 weapon / 护具 armor / 佩饰 acc`；按钮 `min-height:36px; padding:4px 12px; 12px`，容器 `gap:8px; padding:7px 0`。查询时 `category = s.slot || s.category`；model 过滤条件 `i.category===c || 部位中文===c || i.slot===c`。
- 只列 `S.bag[k] > 0` 的条目。

## 4. 网格 `renderGrid()`（虚拟滚动）
- 常量：格高 `cell = 96px`；列数 `cols = clamp(floor(容器宽/96), 3, 12)`（容器宽缺省 800）。
- 可见行：`first = max(0, floor(scrollTop/96) - 1)`；`visible = ceil(容器高/96) + 2`（高缺省 480）；渲染下标 `[first*cols, min(n,(first+visible)*cols))`。
- 占位高 `.qj-grid-space height = max(160, ceil(n/cols)*96)px`；`.qj-grid` 绝对定位 `top = first*96px`，`grid-template-columns: repeat(cols, minmax(0,1fr)); grid-auto-rows:96px`。滚动即重算；记录 `s.scroll`。
- 滚动区 `.qj-grid-scroll`：`margin:15px 0 14px; background:#f5f0e6cc; border-radius:4px`，细滚动条 `#a18752 / #e7d9b8`。
- 格子 `.qj-item`：宽 `calc(100% - 10px)`、高 86px、`margin:0 5px 10px; padding:10px`，居中，`border:1px solid #1818132e; background:#fbf8eff0`；悬停 `border-color:#967439; background:#ede0b4`；选中 `.selected`：`border:1px solid #705927; box-shadow:inset 0 -2px #705927; background:#e9dec4`。
  - 图标：`mnIco(k,56)`，图集图标显示 60×60（`.jm-pxi`）、其他 56×56。
  - 数量角标 `.qj-count`：右下（`bottom:3px; right:6px`），12px `#524831`，底 `#f4ead3c9`，圆角 3，`padding:0 3px`，总是显示（含 1）。
  - 未知物品（`known===false`）：中间 `?`，左下 9px `暂无法识别`。
- 空列表：`没有匹配的器物` + 按钮 `清空筛选`（重置 category=全部、slot、search、scroll）。
- 方向键（焦点在格子）：左右 ±1，上下 ±cols，夹在 [0,n-1]，`scrollTop = floor(next/cols)*96` 后聚焦该格。

## 5. 选择与操作条 `renderItemAction()`
- 点击格子：`s.selected=id`，重画网格+操作条；触摸输入时直接打开详情抽屉（带执行按钮）。
- 操作条 `.qj-item-action`：flex，`gap:12px; min-height:64px; padding-top:10px; 14px`，上边线。未选中：`选择器物后操作`。选中：
  - 左（flex:1）：`<strong>{名}</strong><small>当前对象：{人物名}[ · 气血 +{heal} / 内力 +{mp}]</small>`（仅 useItem 且非蟒蛇胆时显示恢复值；small 11px `#675c43`）。
  - 按钮 `查看详情`。
  - 有 action 时主按钮：`装备给{人物}` / `由{人物}参悟` / `对{人物}使用 1 份`；不允许时 `aria-disabled=true`（仍可点，点后提示原因）；`busy` 时禁用。
  - 不允许时右侧红字 small（最大宽 30%，`#985542`）显示 reason。
- 执行（`itemCommit`）：不允许→`notify(reason||'当前不可使用')`。`learnFromItem`→抽屉 `选择参悟招式`，每个候选一个按钮 `{名}<small>{不可原因}</small>`（有原因 aria-disabled），无候选 `没有符合条件的招式。`；点候选：有原因提示，否则确认 `消耗一份{物品名}，由{人物}参悟？` → `commit('learnFromItem',{itemId,skillId})`。其他 → 确认 `{装备/使用}「{名}」给{人物}[，消耗 1 份（实际恢复气血 {heal}、内力 {mp}）]？` → `commit(action,{itemId})`。

## 6. 物品详情抽屉 `itemDetails(it)`
`<h2>{名}</h2>`；eyebrow `{category||器物} · 持有 {count}`；`<p>{desc||暂无详细记录}</p>`；若有非零变化 `.qj-deltas`：每行 `名称 | before → after | ±delta`（行 flex 两端，`padding:10px 0`，底线 `#99845a44`，14px；增 `.up #347153`，减 `.down #9a483d`）；有 reason 时红字。触摸打开时页脚附执行按钮（文案同上，参悟为 `参悟秘籍`）。

## 7. 从装备栏进入（`chooseSlot(slot)`）
队伍页旧装备栏位为空时调用：把 `{page,actor,category,scroll,slot,search,sort}` 压入 `s.stack`，切到 bag、`category='装备'`、`slot=该部位`、清搜索，提示 `为{人物}选择{部位}`；`Esc/返回` 弹栈回原页。
