# 32 行记页（任务 / 人物图鉴）与任务追踪

源文件：`js/qihe-journal-ui.js`（`QiheJournalUI.render`）、`js/qihe-journal.css`、`js/qihe-jianghu-ui.js`（`questPage`、`questEntriesUI`、追踪函数、click 分支）。数据来自 `QiheJournal`（见 52 号文件）。

## 1. 入口与状态
- 江湖菜单 tab 'quest'（热键 L），`questPage()` 返回 `QiheJournalUI.render(s, questEntriesUI(), QiheJournal.people(S), isTracked, QiheJournal.phase(S))`。
- `questEntriesUI()` = `QiheJournal.tasks(S,{mainLine:questLine()})`。
- 菜单状态 s 上的字段：
  - `journalView` 为 'tasks' 或 'people'，缺省 'tasks'。
  - `questFilter` 为 'active' 或 'done'，非 'done' 一律当作 active。
  - `questId`、`journalPersonId`。
  - `journalCollapsed`：首次渲染时取 `innerWidth<=1000`。
  - `journalNarrow`。
- 当前条目：`rows = tasks.filter(status===questFilter)`，选中 questId 对应项，找不到取 `rows[0]`；人物同理，找不到取 `people[0]`。选中结果回写到 s。
- **类名作用域**：render 输出前用 `scope()` 给所有 class 加前缀 `qjc-`（`qjc` 本身除外）。下文写的是去前缀后的类名，CSS 中实际为 `.qjc-xxx`。

## 2. 结构（render）
```
section.qjc.app(.collapsed)
├ div.pagebar
│ ├ div.tabs[role=tablist]：button[journalTab=tasks] badge5+"任务"，button[journalTab=people] badge4+"人物图鉴"
│ └ span.chapter：phase.chapter + span(phase.date)
└ div.workspace
  ├ aside.directory
  │ ├ div.directory-head：span.directory-title（"任务目录 · N" / "已识人物 · N"）+ button.collapse-control（‹ / ›）
  │ ├ div.filters（仅任务视图）：[active 正在进行 b数量][done 已完成 b数量]
  │ ├ div.index-list：entry 按钮列表，无条目时 p.empty-note「暂无条目」
  │ └ p.directory-note：「只收录已承办的事项。」/「相识后记录，随经历补充。」
  └ article.reader：renderTask(q) 或 renderPerson(p)
```
- 任务条目 `button.entry[data-qj=quest]`：badge（done 用 12，否则 5）+ `span.entry-copy>strong(short(title))+small(kind)`。
- 人物条目 `button.entry[data-qj=journalPerson]`：face + strong(name) + small(faction)。
- `short(t)`：固定映射「一封未落款的拜帖→未落款的拜帖」「三份来件与第十七号底单→三份来件对证」「学习丙级《护路棍法》→护路棍法」；其余去掉 `开始|培养|游历|终局|序章|第…章 ·` 前缀。

## 3. 小图标 badge 与头像 face
- `i.badge`：图集 `assets/ui/jianghu-v5/icons-atlas.png`，`background-size:400% 400%`，4×4 格；第 i 格的位置为 `(i%4)/3*100%  floor(i/4)/3*100%`。用到的格：1 文书、2 赏银、4 人物、5 任务、12 已完成/小传。尺寸：默认 35；`.large` 64；`.small` 26；目录条目内 39；节标题与侧卡内 27。
- `span.face`（有 p.art 时，否则显示 badge4）：48×48 圆形，背景 `#dfe3d7`，边框 `1px solid #cbd1c2`。img 绝对定位、宽 184、水平居中、top -2（取立绘头部）。
  - `.ye`：宽 190、top -15。
  - `.pixel`（p.full 为假，即小头像素材）：铺满、contain、pixelated。
  - `.sm`：38×38，img 宽 146（ye 为 150 / top -12）。
  - `.big`：120×120。
  - 带 `data-portrait-actor` 时（山居人物）：img `height:var(--avatar-height);top:var(--avatar-top);left:50%;transform:translateX(calc(-50% + var(--face-dx)))`。各人参数：zhou(-0.88%,369%,-61.62%)、shimu(-8.6%,381.68%,-75.57%)、yin(-10.7%,446.43%,-90.18%)、zhong(8.74%,366.3%,-96.34%)、fang(-10.11%,375.94%,-96.99%)、dou(0.49%,448.43%,-83.86%)、man(-4.59%,438.6%,-107.46%)、pei(-3.5%,543.48%,-115.76%)。

## 4. 任务详情 renderTask(q,people,tracked)
空态：h2「此类暂无任务」，p「已承办和完成的事项会记在行记里。」
`div.task-layout`，grid 为 `minmax(0,1fr) 250px`，gap 34：
- `div.task-main`：
  - `p.eyebrow`：small badge + kind。
  - `h2`：short(title)。
  - `div.task-meta`：「● 已完成 / 正在进行」；未完成时加 `button.track-control[data-qj=questTrack]`，文字「◆ 已追踪」或「◇ 追踪任务」（14px 绿色）。
  - `section.objective`：背景 `rgba(227,232,217,.7)`，左边框 3px 绿色，padding `14px 17px`（task-main 内覆盖值）。h3 为「下一步」或「事项结果」（15px 绿色），p 19px/1.55。`objective-row` 两端对齐：左侧为 pin 图标 + where，右侧有 q.action 时显示 `button.primary[data-qj=journalAction]`（action.type 为 npc 时带 pin，否则带 badge5）+ action.label。
  - `section`「事情缘起」（badge12）：origin 文本。
  - `section`「进展记录」（badge5），标题右侧 small「已完成数 / 总数」；`ol.progress>li`：`span.check` 23px 圆形（完成为 ✓，背景 `#dde6d5`；未完成为 ○，边框 `#a4b198`）+ title + small(detail)；li 下边框为 line，padding 8，17px。
- `aside.task-side`：左边框 1px line，padding-left 25。
  - 侧卡「相关人物」（badge4）：每人一个 relation 按钮，说明取 `role.split(' · ')[0]`；无人时「尚无已识人物记录。」
  - 有 paper 时，侧卡「已见文书」（badge1）：`button.paper-card[data-qj=journalPaper]`，背景 `rgba(236,229,211,.5)`，上边框 `2px solid #c2b498`，padding `14px 12px`。内含 paper-head（badge 35 + title，16px）、paper-fields（每项 label + `b` 22px 金色 `#957950`，两端对齐，上边框 `#d8d1be`）、paper-foot「摘录 / 展开 ›」（13px）。卡下方 p.paper-note。
  - 有 reward 时，侧卡「已领取」（badge2）：`div.reward`「{reward} 文」（20px 金色）+ small「委托路费」。
- 点击 paper：调 `detail(title, h2+body+small(note))` 打开浮签抽屉（见 22 号文件）。
