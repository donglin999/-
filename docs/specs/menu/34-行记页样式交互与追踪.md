## 7. 交互（qihe-jianghu-ui.js click 分支，data-qj 加 data-id）
| data-qj | 行为 |
|---|---|
| quest | view 设为 tasks，questId=id，重绘 |
| questFilter | 设置 filter，questId 置 null |
| journalTab | 切换 view |
| journalPerson | view 设为 people，personId=id |
| journalCollapse | 切换 journalCollapsed |
| journalTask | 跳到该任务，并把 filter 设为其 status |
| journalPaper | 打开文书浮签 |
| journalAction | 先关闭菜单，再按类型执行：continue→`QiheChapter.rest()`，npc→`QiheNavigation.trackNpc(id)`，evidence→`QiheChapter.evidence()` |
| questTrack | `setTracked(key, !isTracked(q))` 后重绘 |
| chapterNpc / chapterEvidence / chapterContinue / chapterTrack / journal | 关闭菜单后分别调 trackNpc / evidence / rest / trackActivity / `QihePrologue.journal()` |

## 8. 任务追踪（qihe-jianghu-ui.js）
- 键名 `qKey(q)=q.t||q.name`，即任务标题。存档字段 `S.questTrack={off:{key:1},seen:{key:1},init:true}`。
- `MAIN_QUEST=/^(眼下$|(开始|培养|游历|终局|序章|第.+章)\s*·)/`。
- `isTracked(q)`：status 为 'active' 且 `off[key]` 不为真。新任务默认追踪。
- `trackedQuests()`：返回 `[{key,title,where,main:MAIN_QUEST.test(key),activity:chapterActivity,npc:chapterNpc}]`。
- `newQuests()`：首次调用（init 为假）只记录 seen 并返回 `[]`；之后返回新出现、且未被 off 的 active 任务键。
- `mainTracked()`：有主线任务被 off 时返回 false，HUD 隐藏「当前行程」。
- `setTracked(key,on)`：修改 off，然后 `save()` 与 `hud()`。
- `openQuest(key)`：打开行记页，定位到该任务及其 status 对应的 filter。`openPerson(id)`：人物存在时切换到图鉴并定位。
