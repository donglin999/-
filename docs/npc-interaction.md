状态：现行　最后核对：2026-10-23

本页记**运行代码现在怎么做**。目标设计在主目录：[人物交互 v2](../../xiaojianghu/docs/design/npc-interaction-v2.md)（第 2.1 节甲「金石朱印」、第 3 节可见度四档、第 4 节查看页、第 5 节请教、第 10 节拍板）、[切磋、眼力与请教](../../xiaojianghu/docs/design/npc-spar-and-insight.md)、[赠礼、关系与随身物品](../../xiaojianghu/docs/design/npc-gifts-and-inventory.md)、[开始部分跑腿整改](../../xiaojianghu/docs/design/opening-errands-rework.md) 0.3 节。两边冲突时以设计稿为准，再回来改这里。

验收截图与脚本：[2026-10-23-npc-interact](updates/evidence/2026-10-23-npc-interact/)（`node shots.cjs` 重拍，结果写 `verification.json`）。

## 1. 文件

| 文件 | 管什么 |
| --- | --- |
| `js/qihe-npc-data.js` | 只有数据表：菜单项、可见度四档、眼力、切磋规则、关系轴、请教表、人物表（随身物品在人物表里）、托的来源、邻村站位 |
| `js/qihe-npc-core.js` | 规则引擎 `window.QiheNpc`：条件解析、关系轴读写、战斗档与可见度、随身物品显示、菜单项状态、请教与切磋的执行 |
| `js/qihe-npc-ui.js` | 界面 `window.QiheNpcUI`：墨印菜单、查看页、请教卷、切磋卷与结果；包一层全局 `interact()` 接入 E 键 |
| `js/qihe-npc-ui.css` | 上面界面的样式（按 1600×900 写，整层按游戏区宽度缩放） |
| `js/qihe-expansion.js` | 三方三人登场条件（0.3 节）；邻村护院、差役两个站位（读数据表 `STATIONS`） |
| `js/qihe-outsiders.js` | 三方跑腿托付时间后移（0.3 节）；“三方对接”记录只列已登场的人 |

加载顺序（`index.html`）：`qihe-npc-data.js` 在 `qihe-expansion.js` 前；`qihe-npc-core.js`、`qihe-npc-ui.js` 在 `main.js` 前；样式 `qihe-npc-ui.css`。版本号 `v=20261023-npc1`。

## 2. 怎么接入地图

- `qihe-npc-ui.js` 包一层全局 `interact()`：最近的 NPC 按名字（或 `npc.person`）对上人物表里的人，就先弹墨印；对不上的（门、物件、路人、资源点）照原样走 `interact()`。
- 墨印里“谈”“托”（主线这一步、跑腿问话、宋先生回话）调用该 NPC 原来的 `act`，即现有 ink 场次，台词仍只在 ink（R-剧情-04）；三方的“托”直接调 `QiheOutsiders.talk()`。
- “谈”说完，人还在、没有剧情接着演时回到墨印；“托”办完不回。
- 不在浏览器里（VM 测试框架）或地址带 `npcRing=0` 时不接管，行为与原来一样。
- 打开墨印、查看页、卷时，本框架在捕获阶段截住按键（W/S/↑↓ 转、E/Enter 定、Esc 收），地图不会同时走动。

## 3. 数据表（`js/qihe-npc-data.js`）

| 表 | 说明 |
| --- | --- |
| `MENU` | 托／谈／观／礼／教／比／易／窃，顺序即排列顺序；“窃”`reserved:true`，本轮一律不出 |
| `TIERS` | 一眼看穿 ≤4、看得出 5～14、看个大概 15～29、看不透 ≥30；每档写清等级、外功、内功、根基怎么显示。不设“亲眼见过”例外 |
| `INSIGHT` | 眼力只看悟性：≥12 提前 5 级、≥8 提前 3 级；最多比原档好一档；乔装、不习武不受影响 |
| `SPAR` | 拒绝阈值 d≥15、d≤−10；每时段每人 1 次、合计 3 次；气血低于五成不接；三成或八回合收手；经验 8+2×等级，胜平败 1／.7／.4，对同一人 100／60／30／0；历练初次 10、首胜 max(10, 等级÷2 取整到 5) |
| `BOND` | 关系轴七档（托付…仇视），开始部分正向上限 49，特殊人物未解锁 19，−50 起敌对；各档对墨印的影响（冷淡不教；厌恶、仇视不易、不教、不比、不托） |
| `TEACH` | 请教：陆衡走现有学棍（`activity:'practice'`）；叶蘅暗器 +10、徐令仪剑 +25、沈雁回长兵 +25、差役长兵 +10（加 `S.zy`，代码键 `棍`＝长兵） |
| `PEOPLE` | 开始部分 16 人：所属、身份、立绘、战斗档来源、可否切磋、请教项、托的来源、逐人随身物品（含条件出现与消失） |
| `STORY` | 托的来源：主线这一步、三方跑腿、跑腿问话、宋先生回话；小注用短名（如“拜帖跑腿”） |
| `STATIONS` | 邻村对证之后：护院 R2 (1015,580)、差役 R3 (540,615)，不出“谈” |

条件写法（`QiheNpc.test`，空格分隔、全部满足）：`event:<id>`、`!event:<id>`、`stage:a|b`、`halfDay<n`、`halfDay>=n`、`choice:<活动>`、`learned:<招式>`、`has:<物品>`、`errand:<键>:<阶段>`、`prologueErrand:<键>`、`bond:<人>>=n`、`sparred:<人>`、`skill:spar`、`chapter`、`never`。写错会直接报错，不会静默当成满足。

**加一个人**：在 `PEOPLE` 加一行（`npc` 写地图上的名字），需要请教就在 `TEACH` 加一项并引用；不用改引擎。**加一枚印**：`MENU` 加一项，在 `qihe-npc-core.js` 的 `menuFor` 里加这一项的通用规则。

## 4. 规则（`js/qihe-npc-core.js`）

- **等级与战斗档**：`clash`＝`js/qihe-faction-clash-data.js` 的 profiles（徐令仪、岑霜、护院、帮众）；`spar`＝`window.QiheSparFoes`（差役）；`party`＝同伴自己的成长记录（叶蘅，`S.mates.ye`）；其余只写设计稿已定的等级（陆衡 16、沈雁回 24、周砚 88），五维、武学“未登记”，不编。徐令仪兵器显示名“青锋剑”（同 id `iron`）。
- **可见度**：d＝对方等级−萧白等级；入队同伴一律一眼看穿；乔装（宋先生）一律看不透；不习武只写“不习武”。
- **随身物品**：普通显示名与数量；剧情物盖“剧情”；乙级以上标“只可见”；贴身不显示，只有乔装者在看不透时写“贴身收着一件”；贵重（甲、绝）显示“未知物品”，悟性认：概率＝悟性÷认出线（甲 24、绝 30），第一次看到判一次、悟性涨了再判，种子固定（`S.qiheNpc.seed`），读档不变；认出记 `S.qiheBond.known`。奇遇、支线奖励（旧羊鞭、《扬灰手》）随奇遇拍板再放，本轮不列。
- **关系轴读写**：`QiheNpc.bond.get(id)`、`bond.add(id, delta, {amends})`（赔礼最多回到 0）、`bond.unlock(id)`。特殊人物做完解锁小事（叶蘅药棚帮忙、陆衡修车认路、三方各自跑腿、宋先生后山回话一）时补算放开与 +8（打开菜单或查看页时补，读档后同样成立）。周砚最低 −49。存档 `S.qiheBond[人]={score,gifts,unlocked,hostile,bonus}`。
- **切磋**：剧情首场是邻村对证之后的护院（朱印“比”，不占次数）；打完（胜平败都算）学会切磋，记 `S.qiheNpc.skills.spar`。之后有战斗档、不是同伴、不是乔装的人按 `SPAR` 判定。开打借现有 `battle()`：只在这一场临时换掉胜负判定（三成、八回合）和胜利结算演出，打完换回，气血内力复原，用掉的药不还，不掉物品；经验走 `CharacterGrowth.awardBattle`（主角 +20% 照常乘一次），历练按收据写进共享历练池（`spar:<人>:first|firstWin:<阶段>`，每人一次）。
- **请教**：每人一次（`S.qiheNpc.teach`），不耗时，不给历练。

## 5. 界面（`js/qihe-npc-ui.js`）

- **墨印**：以人物身体中心为圆心、半径 96 绕在远离主角的一侧（贴屏边自动换边）；最上一枚不高过 220°（右侧 −40°），项多时收紧间距；内弧金线、外刻度环在聚焦印两侧 ±14° 断开；名牌乌木描金挂匾（不挂穗、不加身份字）；四态：墨印、聚焦（48、朱砂框、暖金光晕呼吸）、朱印（剧情，永远第一）、淡墨空心（只留残边内框，聚焦时虚线框、小签两字改朱色写条件）；展开逐枚盖出（间隔 30 毫秒）。按淡墨项只抖一下，不收起。
- **查看页**：逸剑观察页式，左立绘（无立绘的用地图像素小人放大）、竖排名字与身份；中：实力印（档位两字，眼力生效时带“眼”角标）、装备三环、根基五边形（精确实线／范围与高中低晕开／看不透一团淡墨）；右：武学、随身物品；底：一排交互印，Q/E 换身边的人，Esc 返回墨印。不放关系条、行程、情报。
- **请教卷、切磋卷**：撕边宣纸，放在主角外侧，不遮主角与对方；两个印“拜请指点／抱拳请教”“作罢”。切磋卷写对手档位、收手规则、经验三档、历练、本时段剩余次数；首场写“打完这一场，学会「切磋」”。打完出结果小卷。

## 6. 三方三人登场与托付后移（errands 0.3）

- 第一夜（还没有主线存档）与第一天白天，南村口、东埠都没有徐令仪、岑霜、沈雁回；护院、帮众、采办随从、差役照旧在。
- 徐令仪在《徐令仪上门》（`xu-meeting`）之后才站到南村口；岑霜、沈雁回在《装卸路》（`three-meeting`）之后才出现在东埠（岑霜因此不再出现在南村口）。
- 托付：拜帖半日 2～3（第二天傍晚前），旧货账、药单半日 4～5（第三天傍晚前）；第一夜接不到。“三方对接”行程只列已登场的人。

## 7. 与设计稿、渲染图不同的地方

| 项 | 现在 | 原因 |
| --- | --- | --- |
| 印、名牌、宣纸的质感 | CSS 与 SVG 画的残边方印、挂匾、撕边纸 | 装饰概念图（`art_sources/npc-ring-menu-concept-20261022/` 等）标“概念，未采用”，不能直接进运行；正式化按 R-画风-04 另出图集 |
| 印面字体 | 先用系统魏碑／楷体，退到宋体 | 设计稿要求正式化时做成图集，不依赖系统字体 |
| “礼” | 淡墨，小签“尚未开放” | 赠礼卷渲染图用户还没看过，本轮只做数据与关系轴 |
| “比”按下被拒 | 印抖一下，不说推辞 | 推辞台词（`npc_<人>_spar_no_*`）还没写进 ink，不在本轮范围 |
| 陆衡的“比” | 淡墨“战斗档待补” | 陆衡、沈雁回、周砚没有正式战斗档，不编数值 |
| 店家、药商的“易” | 进现有对话（里面有买卖、集市帮忙） | 现有商店入口在 `qihe-chapter.js` 内部，不在本框架改 |
| 管事、采办使的随身物品 | 没录 | 他们不在栖河地图上；赠礼稿管事一行的“安行符”是 2026-10-09 已删除的旧物，以后录时换成现行物品表里的物品 |
| 请教卷、切磋卷打开时 | 墨印收起 | 渲染图 05b 里墨印仍在左侧；卷里时限类条件满足时不写 |
| 陆衡“拜请指点” | 进现有“学习护路棍法”流程，会再问一次“现在开始／再想想” | 现有流程自带确认，未改 `qihe-chapter.js` |
