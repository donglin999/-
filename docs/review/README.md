状态：进行中　最后核对：2026-11-03

做法：原版（本机 8792）与 Godot 版在同一场景、同一状态各截 1280×720，`tools/compare.py` 左右拼图并算逐像素差（0–255 的平均差、差 >24 的像素占比）。截图工具：原版 `tools/capture_web.cjs`（直接摆到场景某点）、`tools/capture_web_line.cjs`（推进到某句台词；`--rects` 打印原版对白框各元素的实测位置）；Godot `--scene/--at/--capture`、`--click-new --until=台词`。
