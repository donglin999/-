# 命中特效动作分析

坐标按画面百分比（横向从左算，纵向从上算）。主角在左、面朝右；强盗、公鸡、蛇在右、面朝左。

## 拳（fist）
- **兵器 / 轨迹**：空手右直拳。前一帧双拳护胸、弓步蓄力；命中帧右臂完全伸直，拳头水平向右送出，在胸口高度（约横向 52%、纵向 53%）。
- **接触点**：强盗前胸正中，就在拳头正前方。强盗上身后仰、头后甩、一手甩起，说明受力是**水平向右、略向上**。
- **设计理由**：拳是钝器，要的是“砸实了”的感觉，不是爆。甲：只在受击点放一个只朝右张开的半扇短闪（朝拳头那侧被拳挡住，不画），再加身后两三道弧口朝左的冲击线。乙：前胸画一道压扁的透明震波环表示胸口被砸凹，背后上扬的速度线表示劲力透背，强盗后脚扬尘对应他滑退。
- **更好的一版**：**乙**。后仰姿势本身很大，甲的小闪配不上这个动作；乙的“前凹—透背—脚滑”把力从进入到泄出完整讲了一遍，用的全是冲击线和扬尘，没有越线。

## 剑（sword）
- **兵器 / 轨迹**：钢剑上撩。前一帧剑在腰前、剑尖指右下贴地；命中帧手臂伸向右上，剑尖到约横向 72%、纵向 35%。剑尖走的是一段**从右下低处向右上兜起的弧**。
- **接触点**：剑身中段压在强盗胸口偏上到肩头（约横向 64%、纵向 42%）。受力**左下→右上**，强盗被撩得仰身。
- **设计理由**：利器的关键是刃口方向。甲：只画一条与剑身同向的细刃口线加一个顺刃口的菱形闪点，布屑顺撩势往右上飞。乙：把剑尖实际走过的弧画成钢色月牙残像（只是刃扫过的残影，不发光、不是剑气），在穿过身体处叠更亮的切口，加少量布屑、暗红点和肩后速度线。
- **更好的一版**：**乙**。“上撩”的特点就在那道由低到高的弧，单帧里只有残像能把这道弧交代清楚；甲虽然准，单看一帧容易被理解成直刺。乙要盯住月牙宽度和颜色，避免被画成剑气。

## 暗器 · 银针（needle）
- **兵器 / 轨迹**：前一帧两指捏针收在下巴前；命中帧右臂向正右方甩直、五指张开（约横向 50%、纵向 49%），针已脱手。针路几乎水平，跨约三分之一屏宽。
- **接触点**：强盗胸口偏上、近左肩前侧（约横向 77%、纵向 47%）。受力**水平向右、点状**，强盗后仰。
- **设计理由**：暗器又细又快，特效必须是“点”，绝不能有面。甲：一根扎进一半的针尾、一个 3–5 像素的闪点、一条断续的极细轨迹。乙：按张开五指的撒针手型画三针窄扇连珠，三条虚线越近越实，三个十字小闪，身后各穿出一两粒布屑。
- **更好的一版**：**甲**。远处一根针扎进去，画面最干净，也最像“暗器”；乙信息更多，但三条长线横穿半个屏幕，容易读成光束，和“细小高速”有点冲突。乙适合当连发技能的特效。

## 公鸡 · 啄（rooster）
- **兵器 / 轨迹**：喙。前一帧公鸡昂首站立、头在高处；命中帧压低身子、脖子向左前下方猛伸、尾羽翘起，是一记**右上→左下的短促点啄**。
- **接触点**：少年前腿大腿近膝处（约横向 45%、纵向 66%）。少年后仰护头。
- **设计理由**：动物攻击要从动物本身的动作出发。喙是尖的，所以受击点做成尖朝左下的小楔形，而不是圆闪；猛伸脖子会甩动颈羽，所以飘几根鸡毛。甲：一个楔形点闪、几道短线、几根鸡毛。乙：公鸡本来就是连着啄，画三个逐渐变淡的啄痕排在腿上，加脖子的速度弧、爪后扬尘。
- **更好的一版**：**乙**。连啄余痕是公鸡独有的动作特点，一眼就能读出“啄”而不是“戳”；体积仍然很小，都贴在腿上。甲稳妥，但和一般的“刺”区别不大。

## 蛇 · 毒（snake）
- **兵器 / 轨迹**：毒牙。前一帧蛇盘着、前半身高竖、头在高处张口；命中帧前半身从盘圈贴地向左平射，身体拉成一条线，**由高落低后水平扑出**。
- **接触点**：张嘴从侧面咬在少年腰胯到大腿根（约横向 35%、纵向 65%），毒牙扎入。受力**从右向左**，少年后仰。
- **设计理由**：毒是“牙带进去的”，所以毒只从牙孔开始，贴着布料洇开或沿腿走，不起雾、不发光。甲：两个牙尖刺点、一小片暗紫绿渗染斑、一滴毒液。乙：蛇身上下的速度线和颈后冲击弧表现扑击，上下对合的钳形闪表现两排牙一合，再从牙孔引出几条细细的毒脉，加一缕毒涎。
- **更好的一版**：**甲**。“毒”最怕画过头，甲的渗染斑加一滴毒液克制、准，也最好做成游戏帧；乙的钳形闪很好地体现了“咬”，但毒脉加速度线加冲击弧，内容偏满，生图模型容易把毒脉画成发光纹。可以考虑把乙的钳形闪移到甲里，作为折中。

## 总结
| 种 | 更好的一版 |
|---|---|
| 拳 | 乙 |
| 剑 | 乙 |
| 银针 | 甲 |
| 公鸡 | 乙 |
| 蛇 | 甲 |

规律：动作本身幅度大、轨迹有特点的（拳的后仰、剑的撩弧、鸡的连啄）用乙，把轨迹讲清楚；本质是“小而准”的（银针、毒牙）用甲，越克制越像。
