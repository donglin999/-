# 队员列专属头像 v1（2026-11-06）

状态：现行　最后核对：2026-11-06

用户：“乙方案，然后为了这个样式每个人专门出一个 icon 去放上去，不然太单调了，你自己去设计一下怎么 icon 会更适合在这里”。乙方案指切角印框（`K.rail_shape("chamfer")`）。

- 生图源：302ai-sunburst-2.6，提示词请求 gpt-image-2.6，1024×1280，不透明背景（R-生图-02）。提示词在 `p_<键>.txt`，参考图在 `ref/`（各人现有立绘）。
- 设计：胸像，4:5 竖幅，身子微侧朝右、看向菜单一侧，头顶留约 8%。米白纸底上一团淡墨晕，每人一个主色加一个若有若无的意象：
  - 萧白：灰青、灰蓝，远山（村衣版加柳条）；
  - 叶蘅：淡青绿，草药叶；
  - 苏芷：青绿，兰草；
  - 殷红缨：淡朱红，红缨；
  - 裴知古：赭黄，书卷。
- 不画框、不写字，框和朱印由代码画。
- 采用：6 张全部采用，缩成 312×390 webp，放在 `game/assets/ui/jianghu-v4/rail/<立绘键>.webp`。萧白按 `portrait_key` 分 hero-modern、hero-village 两张。
- 没做：萧白归云谷造型（hero-guiyun）菜单目前不用，没出。以后新的可入队角色要补一张同规格头像，没有专属头像的人会退回从小立绘裁切。
