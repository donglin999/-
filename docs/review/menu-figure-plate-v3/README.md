状态：现行　最后核对：2026-11-08

用户（评审台第四十一轮第 1 题，继续改）：“背景没有差异化，很多都只是一些小修改而已，这些提示词是不是也应该有一些量化指标才可以，不然生成的质量太统一了”。

## 为什么前两版都一个样

前两版提示词都写“完全照参考图这幅山水”，配色、光线和构图都被同一张参考图拉齐，只换了中景的东西。量化结果（`measure.py`，`measure_menu-figure-plate-v2.json`）：八张主色相全在 27°～36°，饱和度 7～11，明度 79～81，28 对两两比较没有一对达到差异门槛。

## 这一版怎么写提示词

`spec.json` 给每人写死七项，提示词由它生成（`prompts/`）：

| 项 | 写法 |
| --- | --- |
| 主色相 | 角度＋两个色值，例如“春绿（色相约 100°，#8fb46a、#6f9a52）” |
| 饱和度、明度 | 百分比 |
| 冷暖 | 暖色大约占多少 |
| 时辰与光线 | 时辰、光从哪边来、色温 K、有没有雾 |
| 地平线 | 在画面高度百分之几 |
| 主景 | 在左还是右、占画面宽多少 |
| 近景 | 放什么、留白在哪 |

共同要求：正中宽 30% 的竖条不放高大物体，正中下方平地约占 25% 高，四边 12% 淡成纸色。参考图只学笔法，提示词里明说不照它的配色和构图。

## 量化检查

`python3 measure.py raw .png`：量主色相（按饱和度加权）、饱和度、明度、暖色占比、上下明暗差、左右重心，只量中间 76%。两张至少满足一条才算“不一样”：色相差 ≥25°，或明度差 ≥8，或饱和度差 ≥8，或冷暖比差 ≥0.25，或左右重心差 ≥0.12。

- 第一次出图：27／28 对达标，只有现代装和苏芷太像（现代装要求明度约 64%，出成 80%）。把现代装的阴天写重后重出（旧图在 `raw/try1/`）。
- 最终：28／28 对达标，结果在 `measure_final.md`。

以后加新角色的背景板：在 `spec.json` 加一条，和现有八条的主色相至少差 25°，或明度、冷暖拉开，出图后跑 `measure.py`。
