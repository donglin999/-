# 第二批招式特效概念图 · 提示词复核（opus）

复核对象：`提示词/fable/` 下 fuhu_A、fuhu_B、hulu_A、hulu_B 与 分析.md。改定版在本目录同名文件。

## 看图结论（与 Fable 动作描述的出入）

- **两张命中帧里，拳头／棍头都没有碰到山贼**。fuhu_ref 拳头在约 x≈800，山贼胸口在约 x≈1000，中间约三四个拳头宽的空地；hulu_ref 棍头在约 x≈975，山贼胸腹前缘约 x≈1050，中间约两三个拳头宽。Fable 写“拳头停在山贼胸口前约一拳半”“棍头停在山贼胸腹前方不远处”，距离偏小。改定版写明空地宽度，接触点改成“山贼胸口／胸腹正前缘”，特效画在中间这段空地上把两人接起来。
- **山贼的刀不是“垂到身后”**。两张命中帧里刀都横在山贼身前腰下、刀尖朝左指向萧白，一眼就能看到。写“刀垂到身后”会让模型去挪刀、重画山贼。改定版按图写，并在禁止项加上“不改动山贼的刀”“特效不要盖住刀”。
- **左右手、左右脚不写死**。像素精灵分辨不清哪只是左手、哪只是左脚，Fable 写的“右臂”“左腿弓步”“后脚（右脚）”在图上无法核实；写错了模型可能去改姿势来对上文字。改定版统一用“前伸的那只手臂／另一只拳”“前腿／后腿”“一只手臂向后上方甩起，另一只手握刀”。
- **hulu 前一帧不是“棍斜举、棍头朝右上方”**。hulu_windup 里棍几乎是平的，只是棍头略高、双手在胸前，和命中帧差别主要在送出的长度，不是从高处压下来。Fable 写的“棍头从右上方压平”会把方案乙第 1 条的四分之一圆弧带出来，实际上没有这个弧。另外棍约在胸口高，不是“与肩同高”。改定版按图改了。
- 方向都对：萧白在左、面朝右；山贼在右、面朝左；力水平向右。

## 通用改动（四份都加）

- “设计必须符合实际动作”一段加一句：特效只画在人物之间和人物周围的空地上，不要叠在人物身上（命中短闪除外）。理由：拳影、残影、热气线原来写在“手臂下方”“前臂袖口”“萧白胸前”，模型很容易把这些画到身上、甚至重画手臂。
- 首行 Model 行、任务行、画风行与任务说明逐字核对，原样保留。

## fuhu_A.txt —— 小改

- 动作段按上面改：山贼刀的位置、空地宽度、不写死左右手脚。
- 第 2 条第二段月牙高度从“山贼的半个身高”改成“山贼身高的三分之一”。理由：甲是克制版，原来的月牙加上第一段月牙、冲击线、拳影、扬尘，总面积会顶到“不超过山贼身体一半”的上限；也去掉“比普通拳击的月牙更厚”这种模型看不到参照物的比较。
- 第 4 条拳影：原来写“靠近他胸前出拳起点”，这个位置在萧白身上。改成在伸出手臂正下方、胸口和拳头之间的空地，只画拳形不画手臂，不叠到身上。
- 第 1 条“竖向十字闪”改成“十字闪”（竖向十字说法不清）。
- 独有的形（两段：消散的旧月牙 + 新月牙，冲击线连成一条线）清楚，和通用命中拉得开，保留。

## fuhu_B.txt —— 改

- 动作段同 A。
- 第 1 条主震波：原来写“从萧白的拳头前方一直推到山贼胸口”“比普通拳击的月牙高一倍、厚两倍，像一面厚土墙”“上角压到山贼胸口上方”。问题：一是空地本来就有三四个拳头宽，一道月牙从拳头铺到胸口再高一倍，面积很容易超过山贼半身；二是“高一倍、厚两倍”模型看不到参照；三是“土墙”会被画成土石质感的实体墙，偏离拳劲；四是上角压到山贼身上会挡住他扬起的手臂。改成：紧贴拳头、在空地里，高约山贼半身（上限）、厚约一个拳头，“厚浪”，上角不碰手臂、下角不碰刀。
- 第 1 条虎纹：原来是“三道斜向的深赭红粗条纹”。三道平行斜条在像素图上最容易读成爪痕，和自己禁止项里的“爪痕”冲突。改成两道顺着月牙弧线走、粗细不一、断续错开的深色色块，并在禁止项里写明“不是几道平行的斜划痕”。这是“虎势”这一独有的形，保留但改形。
- 第 3 条拳影：同 A，挪到空地上、只画拳形。
- 第 4 条热劲：原来写在“右前臂袖口和拳背上方”“从手臂冒出的热气”，暖金竖短线贴手臂很容易被画成火苗，还会改手臂像素。改成在前臂上方紧挨着的空地里，并明确“不画在手臂上、不画成火苗或火焰形状”。
- 第 5 条命中点：“十字右侧带三条向右发散的冲击线”保留，改成“十字周围”避免全挤在山贼身体里。
- 第 6 条删掉“脚下地面像素略被压暗一格”：这是改地面，和“地面保持不变”冲突。
- “条纹”统一改叫“色带／斑纹”。

## hulu_A.txt —— 小改

- 动作段按图改：棍约在胸口高、几乎水平棍头略高；前一帧棍头只是略高一些，轨迹是“微微压平再顶出”；棍头和山贼之间约两三个拳头宽；山贼的刀横在身前。
- 第 1 条土黄带：通用棍击的土黄和后山地面土色几乎一样，直带横在地面背景上会看不见。加“比地面土色更亮更饱和、外圈一像素深褐描边”。
- 第 3 条顿挫：原来写“棍头后方、棍身上下”，位置含糊。改成棍身前半段（靠近棍头）上下。
- 第 5 条守势：原来写“萧白胸前、棍身正下方约半个棍身粗细，长度从后手到前手再往前一点”。问题：萧白双手都在胸前，这段残影几乎整条压在他身上，模型会把它画成第二根实心棍或改他的手；离木棍只有半个棍粗，也会和木棍粘在一起。改成：在萧白身体前缘和山贼刀尖之间的空地、腰的高度（木棍下方、刀的上方，互不相碰），只画露在身体前方的一段，长约一个半前臂。顺带交代它的意思：“正好挡在对方刀路上”，和图里刀尖指向萧白对得上，守势就有了来由，不是凭空一条线。
- 禁止项加“不画第二根实心木棍”“不改山贼的刀”。
- 独有的形（横向一线直带 + 扁十字 + 身前横杆残影）清楚，和通用棍击的弧带拉得开，思路照用。

## hulu_B.txt —— 改

- 动作段同 A。
- 第 1 条“压平的轨迹”：原来是“从前一帧棍头所在的右上方位置画四分之一圆弧土黄色带”。图里前一帧棍头只比现在略高，没有这么大的弧；画四分之一圆弧就回到了通用棍击的弧形扫带，和这招“横向一线”冲突。改成棍头上方一道很短、很扁的楔形残迹（倾角几度，长不超过一个拳头），禁止项加“不画大弧形扫带”。
- 第 2 条：删去“钝头处山贼衣服像素略被压进去一格”（改人物）；直带同 A 加亮度和描边。
- 第 3 条：原来“四条冲击线穿过山贼腰侧”，会画在山贼身上。改成命中闪上下短线 + 山贼后背右侧空地两三条短横线接着向右，不横穿身体。
- 第 4 条：震棍线限定在棍身前半段，不碰萧白的手。
- 第 6 条守势：原来是“横杆残影 + 两端竖直短粗线，高约一个拳头，像横杆架在两根短桩上”。Fable 自己也说有读成栅栏的风险；两根短桩加一根横杆，模型几乎一定会画成栏杆／拒马。改成：位置同 A（空地、腰高、木棍下方刀上方），用两层错开的残影表现“正在横回来”，右端朝刀尖加两三条竖向顿挫短线表示“挡住来刀”。比甲更明确（两层 + 挡刀顿挫），但不加立柱；禁止项加“不要在残影下面加立柱”“第二根实心木棍”。
- 配色加深褐（描边用）。

## 分析.md 的结论

- 伏虎拳选乙：同意，前提是用改定版（虎纹改成顺弧色带、热劲移到空地且禁火形、主震波限高）。原版乙有爪痕和超面积两个风险，不建议直接出。
- 横杆护身选甲：同意。改定版乙去掉了短桩，栅栏风险降下来了，可以和甲一起出图对比。
