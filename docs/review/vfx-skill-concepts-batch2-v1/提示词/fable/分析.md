# 第二批招式特效概念图 · 动作分析（fable）

参考图：`参考图/fuhu_windup.png`、`fuhu_ref.png`、`hulu_windup.png`、`hulu_ref.png`。两招用的都是同一张山贼受击帧（仰头后倒、右臂扬起、刀垂在身后），区别只在萧白这边的出手帧和山贼的站位。

## 伏虎拳（fuhu）

**兵器与轨迹**：拳。前一帧双拳收在胸前、马步蓄力；命中帧变成左腿深弓步、右臂水平全伸的直拳，拳头在画面正中偏右、与肩同高。轨迹是一条从胸前到拳头的水平直线，没有弧度。

**接触点与受力**：拳头停在山贼胸口前约一拳半的位置（游戏里击退后的站位），接触点应画在山贼胸口正前方、与拳同高。山贼上身后仰、头后甩，受力方向是水平向右；伏虎的“伏”字再补一点向下的沉劲，所以震波的上角比下角长、略向前下卷。

**这招独有的形**：两样。一是“两段”：画面里只能有一帧，所以用两道月牙的新旧对比（甲）或两道月牙叠在一起加两个拳影（乙）来表达“第一拳刚打实、第二拳追到”。二是“虎势”：不画虎，只借“伏”字的下压形（厚月牙、上角前卷）和虎纹样的深赭红条纹（乙）来给气势；配色全用暖金、赭红表现阳性内劲，灼热感靠配色和前臂的几段热气短线，不靠发光。

**与通用拳击拉开层次**：通用拳击是一道月牙加拳影加扬尘；伏虎拳在此之上多了第二道月牙（两段）、更厚更压的形（伏）、暖金赭红的内劲配色，以及山贼胸口的命中短闪。没有新增别的兵器形状，仍然只是拳头的震波。

**甲乙差异**：甲把两段放在两个位置（旧的在山贼胸口消散，新的在拳前），靠时间差讲两段；乙把两段叠在拳前，靠厚度和条纹讲重量，另加拳影轨迹和热气短线。

## 横杆护身（hulu）

**兵器与轨迹**：练习木棍，双手持。前一帧棍斜举、棍头指右上；命中帧棍身完全端平、与肩同高、整根向右送出，棍头停在山贼胸腹前。所以轨迹分两步：棍头从右上压平，再整根沿水平线顶出去。“横杆”指的就是这根端平的杆。

**接触点与受力**：棍头顶在山贼胸腹正前方、与棍身同高，受力水平向右，山贼被顶得后仰。这是端头的顶推，不是横扫，所以特效主体必须是一条贴着棍身延长线的水平带，而不是弧形扫带。

**这招独有的形**：也是两样。一是“横向一线”：通用棍击的土黄带是弧形扫过去的，这招把它压成一条直直的水平带，从棍头顶到山贼胸腹，命中闪也做成横长竖短的扁十字呼应“横”字。二是“收势护身”：在萧白胸前、棍身下方画一根与棍身平行的半透明横杆残影，表示打完棍要横回身前；甲只给一条淡线加两端小收口，乙给更明确的残影加两截短桩，像一道横杆架在门前。两版都不画圈、不画罩、不发光，守势只是“身前横着一根杆”这一个形。

**与通用棍击拉开层次**：通用棍击是土黄弧带、砸中闪白、冲击、扬尘；横杆护身把弧带改成直线带（乙保留一小段压平的弧作为起手），加了棍身的震棍短线（顿挫）和身前的护身残影。木棍形状不变，不会读成枪或矛。

**甲乙差异**：甲只画顶出这一下和一条守势淡线，最省、最清楚；乙多了压平的起手弧、更粗的直带、更多扬尘和带短桩的横杆残影，气势足但元素多，有被生成器画成栅栏的风险，所以禁止项里专门点了。

## 我认为更好的版本

- **伏虎拳：乙**。伏虎拳要和普通拳击拉开差距，差距主要靠“重”；甲的两道月牙分开放容易被读成普通拳击打了两次，乙的厚月牙加条纹加拳影轨迹一眼就能看出是招式。热气短线如果生成器画成火，可以在二次迭代里删掉第 4 条。
- **横杆护身：甲**。这招的要点是“克制的守势”，甲的一条淡线最符合“横杆护住”又不会变成护盾；乙的短桩有读成栅栏或门板的风险，而且元素多了容易超过山贼半身的面积。乙可以作为备选，看出图后再决定是否保留压平的起手弧。
